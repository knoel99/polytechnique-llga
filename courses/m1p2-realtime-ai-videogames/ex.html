Exercices

  1. Pas fixe. Simuler à la main la boucle à accumulateur avec \(\Delta t = 1/30\) s et des frames réelles de 40, 25, 50 ms ; combien de ticks par frame ; que se passe-t-il si l'on supprime la borne anti-spirale quand une frame dure 200 ms ?
  2. Admissibilité. Sur une grille 8-connexe (droits 1, diagonales \(\sqrt 2\)), montrer que Manhattan peut surestimer \(h^*\) (donner un exemple à une case) et démontrer que l'heuristique octile est admissible.
  3. A* sur grille. Grille 6×6 avec murs \(\{(1,2),(1,3),(2,3),(3,3),(4,3)\}\), départ \((0,0)\), but \((5,5)\) ; exécuter A* octile à la main (tableau open/fermé), puis vérifier avec le code du chapitre ; que change un poids de terrain 2 sur la colonne 4 ?
  4. FSM → BT. Une FSM Garde : Patrouille → (bruit) → Inspecter → (rien) → Patrouille ; Patrouille → (voit joueur) → Attaque → (hp bas) → Fuir. Dessiner le BT équivalent (sélecteur + séquences de garde) ; y ajouter l'interruption « allumé par un camarade » — pourquoi est-elle plus simple dans le BT ?
  5. Tick d'un BT. Sur le BT du code du chapitre 3, tracer le statut de chaque nœud pour un agent (hp = 50, ennemi visible, attaque en cours) sur trois ticks, dont celui où l'ennemi meurt ; identifier les nœuds « running » et la ré-évaluation du sélecteur.
  6. UCT à la main. Racine 15 visites ; enfants A (n=10, w=7), B (n=3, w=3), C (n=2, w=0) ; c = 0,7, \(\ln 15 \approx 2{,}71\). Calculer les trois UCT, dire lequel est exploré ; après un rollout gagnant sur ce nœud, recalculer et commenter le « resserrement ».
  7. Rollouts. Pour tic-tac-toe : implémenter MCTS (1000 itérations) et mesurer le taux de parties nulles contre un joueur aléatoire ; comparer budget 10 / 100 / 1000 / 10000 itérations ; à partir de quel budget l'agent devient-il imbattable ?
  8. Steering. Un agent à \(p = (0,0)\), \(v = (2,0)\) m/s, \(a_{\max} = 6\) m/s², cible immobile en \((8, 0)\), \(r_{\mathrm{arriv}} = 3\) m, \(\tau = 0{,}2\) s ; calculer \(v_{\mathrm{dés}}\), la force d'arrive et la position/vitesse après un tick de 0,1 s (intégration d'Euler) ; pourquoi le seek pur oscillerait-il ici ?
  9. Formations. Formation en triangle d'offsets \(\{(0,0), (-2,1), (-2,-1)\}\) ; meneur en \((10, 5)\), cap \(\theta = 90°\). Calculer les positions monde des slots ; puis attribuer par l'algorithme hongrois à trois agents en \((8,4), (7,7), (12,3)\) (coût euclidien) ; que se passe-t-il si l'attribution est gloutonne ?
  10. Aide dynamique. Concevoir un contrôleur de rubber-banding : entrée = distance normalisée \(d\) au joueur ; sortie = bonus de vitesse \(v \in [0{,}9, 1{,}15]\) ; imposer une hystérésis (seuils montée/descente distincts) et une inertie — écrire les équations et discuter le réglage pour qu'un joueur moyen ne détecte rien.
  11. Budget IA. 300 agents ; réévaluation des décisions à 5 Hz (répartie uniformément sur les frames), voisinage par grille spatiale (\(O(1)\) amorti), 60 fps ; estimer le coût par frame (agents décidant par frame × coût d'un BT) et la mémoire des données de navigation ; comparer à l'option « tous les agents chaque frame ».
  12. Projet. En Python (bac à sable fourni) : monde en grille avec obstacles, 20 agents boids-navmesh ; implémenter (a) A* + follow de chemin, (b) BT de survie (fuir un prédateur, manger, errer), (c) un prédateur MCTS (5 ms par décision) sur une version discrétisée du jeu ; mesurer taux de survie par configuration et temps de calcul par frame — livrer un rapport avec la checklist du chapitre 9.
