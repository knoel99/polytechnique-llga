Références

  • J. Kajiya, The Rendering Equation, SIGGRAPH 1986 — l'article fondateur ; T. Whitted, An Improved Illumination Model for Shaded Display, CACM 1980.
  • E. Veach, Robust Monte Carlo Methods for Light Transport Simulation, thèse Stanford, 1997 (MIS, MLT — la référence MC du chapitre 6).
  • M. Pharr, W. Jakob, G. Humphreys, Physically Based Rendering: From Theory to Implementation (pbrt, 4e éd. en ligne) ; tutoriels : Ray Tracing in One Weekend ; Scratchapixel.
  • B. Phong, Illumination for Computer Generated Pictures, CACM 1975 ; R. Cook, K. Torrance, A Reflectance Model for Computer Graphics, SIGGRAPH 1981 ; C. Schlick, An Inexpensive BRDF Model for Physically-based Rendering, CGF 1994 ; B. Burley, Physically-Based Shading at Disney, SIGGRAPH Course 2012.
  • T. Möller, B. Trumbore, Fast, Minimum Storage Ray-Triangle Intersection, JGT 1997 ; I. Wald, On fast Construction of SAH-based Bounding Volume Hierarchies, EGSR 2007.
  • B. Mildenhall, P. Srinivasan, M. Tancik, J. Barron, R. Ramamoorthi, N. Ng, NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis, ECCV 2020 ; B. Kerbl, G. Kopanas, T. Leimkühler, G. Drettakis, 3D Gaussian Splatting for Real-Time Radiance Field Rendering, SIGGRAPH 2023.
  • A. Tewari et al., State of the Art on Neural Rendering, Computer Graphics Forum (EG STAR), 2020 — la synthèse du chapitre 9 (suivi par Advances in Neural Rendering, 2021).
  • C. Chaitanya, A. Kaplanyan, C. Schied, M. Salvi, A. Lefohn, D. Nowrouzezahrai, T. Aila, Interactive Reconstruction of Monte Carlo Image Sequences Using a Recurrent Denoising Autoencoder, SIGGRAPH 2017 ; Open Image Denoise pour les TP.
  • T. Boubekeur, M. Alexa, Phong Tessellation, TOG 2008 ; J.-M. Thiery, E. Guy, T. Boubekeur, Sphere-Meshes: Shape Approximation using Spherical Quadric Error Metrics, TOG 2013 ; T. Groueix, S. Chaudhuri, D. Ceylan, et al., AtlasNet: A Papier-Mâché Approach to Learning 3D Surface Generation, CVPR 2018 ; tutoriel CreativeAI.
