5. Lissage : du laplacien uniforme aux cotangentes

Définition 5.1 — Laplacien combinatoire et schéma de lissage Sur un maillage fermé, le laplacien uniforme (combinatoire) d'un sommet \(i\) de voisinage \(\mathcal{N}(i)\) est \(\delta_i = \dfrac{1}{|\mathcal{N}(i)|}\sum_{j \in \mathcal{N}(i)} p_j - p_i\), et le lissage laplacien itère $$p_i \leftarrow p_i + \lambda\,\delta_i, \qquad \lambda \in (0, 1].$$ C'est une méthode de projection locale ; version « flux de courbure moyenne » : \(p_i \leftarrow p_i + \lambda\,H_i \mathbf{n}_i\) (chapitre 7 pour \(H_i\)). En matriciel : \(\mathbf{x} \leftarrow (I - \lambda L)\,\mathbf{x}\) avec \(L = D^{-1}A - I\) (normalisé) ou \(L = D - A\) (non normalisé).
Théorème 5.2 — Le lissage uniforme rétrécit : preuve spectrale 1D Sur un anneau de \(n\) sommets (cycle) de positions \(x_i\), l'itération \(x_i \leftarrow (1-\lambda)x_i + \lambda \bar{x}_{\mathcal{N}(i)}\) conserve la moyenne \(\bar{x}\) et fait décroître toute composante non constante : \(x^{(k)} \to \bar{x}\mathbf{1}\) — le maillage 1D rétrécit jusqu'au barycentre. Le taux de décroissance d'un mode de fréquence \(j\) vaut \(\rho_j = 1 - \lambda\big(1 - \cos\tfrac{2\pi j}{n}\big) \in [0, 1)\).
Décomposons \(x\) sur la base orthogonale des modes de Fourier discrets \(u^{(j)}_i = e^{2i\pi ji/n}\). La moyenne des voisins multiplie \(u^{(j)}\) par \(\frac{1}{2}(e^{2i\pi j/n} + e^{-2i\pi j/n}) = \cos\frac{2\pi j}{n}\) ; donc l'itération multiplie le mode \(j\) par \((1-\lambda) + \lambda\cos\frac{2\pi j}{n}\). Pour \(j = 0\) (constant) : facteur 1 — conservation de la moyenne. Pour \(j \neq 0\) : \(\cos\frac{2\pi j}{n} < 1\) donne \(\rho_j < 1\) (et \(\geq -1\) pour \(\lambda \leq 1\)) : tous les modes non constants décroissent géométriquement, le plus vite les hautes fréquences. Limite = composante constante = barycentre. ∎
Définition 5.3 — Remèdes : Taubin λ|μ, cotangentes
  • Taubin λ|μ : alterner un pas lissant (\(\lambda \approx 0{,}5\)) et un pas « délissant » (\(\mu \approx -0{,}53\)) ; les fréquences dans la bande de transmission \((\rho_\mu, \rho_\lambda)\) sont préservées — le volume moyen est conservé au lieu de s'effondrer ;
  • Laplacien cotangent (géométrique) : $$\delta_i = \frac{1}{2 A_i}\sum_{j \in \mathcal{N}(i)} \big(\cot \alpha_{ij} + \cot \beta_{ij}\big)\,(p_j - p_i),$$ où \(\alpha_{ij}, \beta_{ij}\) sont les angles opposés à l'arête \((i,j)\) et \(A_i\) l'aire de Voronoï mixte du sommet — c'est l'opérateur convergent vers le laplacien-Beltrami (théorie des formes de fonctions chapeau ; cf. module Geometric Deep Learning, chapitre opérateurs) ;
  • Ordre du filtrage : le lissage en position régularise la géométrie ; le lissage des normales puis ré-projection (ou shrink-and-grow) sépare le débruitage de la déformation — les deux familles coexistent dans les DCC.
Exemple 5.4 — Cotangentes sur un triangle rectangle isocèle Triangle unique \(A = (0,0)\), \(B = (1,0)\), \(C = (0,1)\), sommet \(A\). Ses deux arêtes voisines sont \((A,B)\) et \((A,C)\) : pour l'arête \((A,B)\), l'angle opposé est \(\angle ACB = 90°\), de cotangente nulle ; pour l'arête \((A,C)\), l'opposé \(\angle ABC = 90°\), cotangente nulle également. L'arête \((B,C)\) n'est pas voisine de \(A\) : la somme de cotangentes autour de \(A\) est nulle, \(\delta_A = 0\) — cohérent, un maillage réduit à un triangle est « tout bord ». Le vrai test de l'implémentation est le test du plan : plonger un maillage plan dans son plan ⟹ tous les \(\delta_i\) intérieurs sont nuls (équivalent discret de \(\Delta f = 0\) pour les fonctions harmoniques). La preuve vient de la formule de Green discrète : \(\sum_i A_i\, f_i\, \delta_i = -\sum_{(i,j)} w_{ij}(f_j - f_i)^2 \leq 0\), avec égalité ssi \(f\) est constante sur chaque composante.
Du lissage au deep learning géométrique La matrice de cotangentes est l'objet central du module M2 Geometric Deep Learning : diffusion de descripteurs (HKS), convolutions spectrales (bases de fonctions propres, chapitre 8 ci-dessous), DiffusionNet. Le lissage de ce chapitre en est la version « déterministe » : même opérateur, sans données apprises — et déjà non trivial : choix aire/Voronoï mixte, poids négatifs sur maillages obtus (à tronquer ou régulariser).
