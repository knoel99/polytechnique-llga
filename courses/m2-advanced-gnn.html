0. Rappels : le socle message passing

Rappels du module Graph ML (M1 P2) — ce qui est supposé acquis
  • Couche générique (M1, ch. 5) : \(h_v^{(\ell+1)} = \phi\big(h_v, \mathrm{AGG}_{u \in \mathcal{N}(v)}\{\psi(h_v, h_u)\}\big)\) ; GCN (moyenne renormalisée, dérivation spectrale), GraphSAGE (échantillonnage, inductif), GAT (attention d'arête) ;
  • Spectral (M1, ch. 4) : laplacien \(L = D - A\), caractérisation variationnelle de \(\lambda_2\), spectral clustering comme relaxation de RatioCut, convolution par polynômes de Tchebychev — filtrer = polynôme de \(L\) ;
  • Embeddings (M1, ch. 3) : DeepWalk/node2vec et leur lecture NetMF (factorisation de matrices de marches) ; les PathNN du ch. 8 en sont la généralisation ;
  • Link prediction / GAE (M1, ch. 6) et échelle (M1, ch. 7 : NeighborSampler, Cluster-GCN, GraphSAINT) — ce ch. 6 ci-dessous prolonge le second ;
  • Over-smoothing (M1, ch. 5) : après beaucoup de couches, tous les embeddings convergent (démontré sur graphe régulier : convergence géométrique vers la moyenne) — pourquoi on s'arrête à 2-4 couches… et pourquoi ce module existe.
Les quatre questions de recherche du module (1) Jusqu'où un GNN peut-il voir ? — expressivité (ch. 1) ; (2) Jusqu'où l'information peut-elle voyager ? — over-squashing et profondeur (ch. 2) ; (3) Où suis-je dans le graphe ? — position et structure (ch. 3) ; (4) À quelle échelle et sous quelles attaques ? — systèmes (ch. 6) et robustesse (ch. 7). Les transformers (ch. 4) et le temporel (ch. 5) répondent « tous-tous » et « au fil du temps » à ces mêmes questions.

1. Expressivité : le test de Weisfeiler-Lehman

Définition 1.1 — 1-WL (color refinement) Initialiser une couleur \(c_v^{(0)}\) par les features ; itérer : $$c_v^{(k+1)} = \mathrm{HASH}\Big(c_v^{(k)},\ \mathrm{SORT}\big\{c_u^{(k)} : u \in \mathcal{N}(v)\big\}\Big).$$ Deux graphes sont 1-WL-équivalents si les multisets de couleurs coïncident à convergence. Le 1-WL distingue presque tous les graphes aléatoires (Babai-Erdős-Selkow) ; mais échoue sur des familles simples : graphes réguliers de même degré, cycles, paires de molécules discutées depuis les années 60 (CIR : chemical identity recognition).
Théorème 1.2 — GNN ≤ 1-WL (Xu et al., 2019 ; Morris et al., 2019) Tout GNN de message passing dont l'agrégation et l'update sont des fonctions (continues, calculables) ne peut pas distinguer deux graphes 1-WL-équivalents : si les couleurs initiales coïncident et que les couches saturent le test, les embeddings coïncident à chaque profondeur.
Par récurrence sur \(\ell\). Initialisation : couleurs initiales = features, identiques par hypothèse, donc \(h_v^{(0)} = h_{v'}^{(0)}\) pour tout couple \((v, v')\) de même couleur. Hérédité : si tous les nœuds de couleur \(c\) ont même représentation \(h_c\), alors l'entrée de l'agrégation en \(v\) est le multiset \(\{h_c : c \in \mathrm{multicol}_v\}\) ; or 1-WL-équivalence = égalité des multisets de couleurs et des multisets de couleurs de voisins à chaque itération — donc AGG reçoit des entrées identiques, et \(h_v^{(\ell+1)} = h_{v'}^{(\ell+1)}\). À la fin, les readouts (permutation-invariants par construction, M1 ch. 2) ne voient que le multiset des \(h_v\) — identique sur les deux graphes. ∎
Théorème 1.3 — GIN atteint exactement 1-WL (Xu et al., 2019) Avec somme + MLP et features discrètes, $$h_v^{(k+1)} = \mathrm{MLP}^{(k)}\Big((1 + \epsilon^{(k)})\, h_v^{(k)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k)}\Big)$$ le GNN distingue exactement ce que 1-WL distingue.
L'ingrédient : sur un domaine dénombrable, il existe une fonction \(f : \text{multisets finis} \to \mathbb{R}\) injective : encoder chaque élément par un entier (log canonique d'un prime : \(c \mapsto \log p_c\)) donne \(\sum_i \log p_{c_i}\), et l'unicité de la décomposition en facteurs premiers assure l'injectivité ; un MLP universel l'approxime. Alors la couche somme+MLP est injective en \((h_v, \mathrm{multiset}(h_u))\) — le couple (couleur propre, multiset de voisins) est encodé sans collision : par récurrence, deux nœuds ont même embedding \(\iff\) même couleur 1-WL. Le readout par somme injective conclut : GIN = 1-WL. ∎
Conséquences immédiates : moyenne et max ne sont pas injectives — \(\{a, a, a\}\) et \(\{a\}\) ont même moyenne ; \(\{a, a\}\) et \(\{a\}\) même max — donc GCN/GraphSAGE (moyenne) sont strictement moins puissants que GIN sur les features catégorielles ; en pratique la différence se voit surtout sur les tâches où compter les voisins compte (molécules : \(\mathrm{CH}_4\) vs \(\mathrm{CH}_3\)-\(\mathrm{CH}_3\)).
Exemple 1.4 — C6 vs 2×C3 : 1-WL échoue, 2-WL sépare (démonstration) 1-WL : tous les nœuds sont de degré 2 ; par récurrence, à chaque tour chaque nœud voit (sa couleur, {sa couleur, sa couleur}) — les couleurs restent uniformes sur chaque graphe, et identiques entre les deux graphes : indistinguables. 2-WL (coloration des paires) : considérons une paire adjacente \((u, v)\). Dans le triangle, \(\{w : w \sim u, w \sim v\}\) compte 1 sommet commun ; dans C6, ce compte vaut 0 (pas de triangles) ; la règle de mise à jour du 2-WL, qui agrège pour la paire \((u,v)\) les couleurs des paires \((u, w)\) et \((w, v)\) pour tous les \(w\), encode le nombre de triangles — les histogrammes de paires diffèrent : séparés. ∎ Moralité : le 2-WL (donc un 2-GNN) « compte les moments » que la somme locale ne voit pas. À coder en TP (exercice 1).
Hiérarchie k-WL et k-GNN Le k-WL colore les k-uplets de nœuds : \(k = 2\) : paires (ci-dessus) ; la hiérarchie est stricte : (k+1)-WL distingue des paires que k-WL confond (pour \(k \geq 1\), le 2-WL étant déjà strictement plus fort que le 1-WL) ; au sommet, k = n+1 → test d'isomorphisme exact (exponentiel). Les k-GNN (Morris et al., 2019) implémentent (une variante locale de) k-WL : messages entre k-uplets voisins — coût mémoire et calcul \(\mathcal{O}(n^k)\) : k = 2 praticable, k = 3 réservé aux petits graphes (molécules). Le survey de Morris et al. (2023) dresse la carte complète (Weisfeiler-Lehman « go machine learning »).

Alternatives pragmatiques : sous-graphes et comptage de motifs
  • ESGNN (Equivariant Subgraph Aggregation, Bevilacqua et al., 2022) : chaque nœud est décrit par la collection de sous-graphes (ego-nets de rayon croissant, ou « node-deletion » — le graphe privé de \(v\)) ; un GNN 1-WL partagé les encode, l'agrégation entre sous-graphes ajoute de l'expressivité sans coût \(\mathcal{O}(n^k)\) complet — strictement entre 1-WL et 3-WL ;
  • Comptage de motifs (Bouritsas et al., 2020) : pré-calculer des comptages de sous-graphes isomorphes (triangles, chemins, cycles) et les injecter comme features — « les moments comptent » : lever expressivité par pré-traitement plutôt que par architecture ; lien direct avec l'exemple 1.4 (triangles) et avec les MMD de l'évaluation générative (M1, ch. 9.6) ;
  • Limites pratiques : plus d'expressivité = plus de variance d'estimation et de coût ; sur les benchmarks réels (Dwivedi et al., 2023), GIN vs GCN se joue à quelques dixièmes — l'expressivité n'est le goulot que sur les tâches structurelles (compter, distinguer) — cf. ch. 6.

2. Over-squashing et GNN profonds

Définition 2.1 — Over-squashing (Alon & Yahav, 2021) — définition formelle par les Jacobiennes Soit \(\mathcal{G}\) le graphe de calcul d'un GNN ; l'influence d'un nœud \(u\) sur la représentation finale d'un nœud \(v\) se mesure par la Jacobienne \(\big\| \partial h_v^{(L)} / \partial h_u^{(0)} \big\|\). Il y a over-squashing quand cette grandeur s'écrase exponentiellement avec la distance \(d(u, v)\) — précisément, quand la borne \(\big\| \partial h_v^{(L)} / \partial h_u^{(0)} \big\| \leq c\, (f \, r(\lambda_{\max}))^{-d(u,v)}\) devient petite parce que le rayon de convergence \(r(\lambda_{\max})\) de la propagation (une fonction croissante de la plus grande valeur propre de l'opérateur de propagation, ex. \(2\tilde L_{\mathrm{sym}} / \lambda_{\max}\)) est proche de 1 : quantité exponentiellement grande d'information (\(\sim\) taux de croissance \(\mu\) du voisinage) devant passer par un canal qui se contracte exponentiellement vite. Les bottlenecks (arêtes de coupe, ponts entre communautés) sont les points physiques du phénomène.
Proposition 2.2 — Le lien expansion / \(\lambda_{\max}\) (esquisse de démonstration) Les arêtes traversées par l'information de \(u\) vers \(v\) forment un cut ; le « débit » du message passing à travers une coupe est borné par la conductance de la coupe, elle-même contrôlée par le spectre : par Cheeger (inversé pour le haut du spectre, la borne de Tanner pour \(\lambda_{\max}\)), une conductance faible force \(\lambda_{\max}\) grand… c'est-à-dire des composantes hautement oscillantes qui, dans la récurrence de Tchebychev (M1, ch. 4), font diverger le facteur \(\big( \frac{\lambda_{\max}}{2} \big)^k\) et écrasent le rayon de convergence : goulot topologique ⇔ mauvais conditionnement spectral. D'où les deux familles de remèdes : changer la topologie (rewiring, ci-dessous) ou changer l'opérateur (normalisation, propagation implicite, ch. 2.4).
2.3 — Courbure de Ricci discrète et SDRF (Topping et al., 2022) La courbure d'Ollivier-Ricci d'une arête \((u,v)\) compare les voisinages par transport optimal : $$\kappa(u, v) = 1 - \frac{W_1(\mu_u, \mu_v)}{d(u, v)}, \qquad \mu_u = \text{loi uniforme sur } \mathcal{N}(u),$$ \(W_1\) = distance de Wasserstein-1 (module Optimal Transport) : arêtes « denses localement » (triangles) → \(\kappa\) grand ; ponts → \(\kappa\) négatif. Exemple calculé (à la main) :
  • arête d'un triangle : \(\mu_u = \{\frac12 v, \frac12 w\}\), \(\mu_v = \{\frac12 u, \frac12 w\}\) ; plan de transport : garder \(w\) (coût 0), transporter \(\frac12\) de \(v\) vers \(u\) (coût 1) → \(W_1 = \frac12\), \(\kappa = +\frac12\) ;
  • arête d'un hexagone C6 : le meilleur plan transporte \(v \to t\), \(s \to u\) (coût 1 chacun) → \(W_1 = 1\), \(\kappa = 0\) ;
  • arête-pont entre deux triangles (barbell) : le meilleur plan paie \(W_1 = \frac{1}{3}(1 + 1 + 3) = \frac53\), donc \(\kappa = -\frac23 < 0\) — le pont est « hyperbolique » : c'est lui le bottleneck.
SDRF (Spectral-De-Ricci-Flattening) : à chaque itération, (1) trouver l'arête \((u,v)\) de courbure minimale ; (2) ajouter l'arête \((x, y)\) entre deux voisins de l'arête (pas encore présentes) qui maximise la somme des courbures — trianguler le goulot ; (3) retirer l'arête de courbure maximale si elle dépasse un seuil (éviter la densification) ; effet : la distribution des courbures s'aplatit, \(\lambda_{\max}\) baisse, la borne de la définition 2.1 s'améliore. Regarder le graphe comme un objet géométrique — courbures, distances, volumes — est l'un des grands tournants du domaine (cf. ch. 9 et le module Geometric DL).
DIGL — rewiring par diffusion (Gasteiger et al., 2021) Alternative « filtrage » : remplacer \(A\) par \(\tilde A = \mathrm{top}\text{-}k\big(\sum_{i=0}^{K} \beta_i T_i(L)\big)\) — un noyau de chaleur (somme de polynômes de Tchebychev, M1 ch. 4) sparsifié : chaque nœud gagne des arêtes « virtuelles » vers ses voisins multihops pondérés par la diffusion ; simple, différentiable, et le GNN final s'entraîne sur le graphe rewiré. Comparaison : SDRF est topologique (courbure locale, ajouts ciblés) ; DIGL est spectral (diffusion globale) ; les deux visent \(r(\lambda_{\max})\) — et les deux détruisent éventuellement de l'information de motif : mesurer l'arbitrage en TP (exercice 4).
2.4 — GNN profonds : APPNP et GCNII APPNP (Klicpera et al., 2019) sépare prédire et propager : un réseau (souvent simple) prédit \(H = f_\theta(X)\) ; la propagation suit le PageRank personnalisé : $$Z^{(k+1)} = (1 - \alpha)\, \hat P\, Z^{(k)} + \alpha H, \qquad \hat P = \tilde D^{-1/2} \tilde A \tilde D^{-1/2}.$$ Point fixe : \(Z^* = \alpha \big(I - (1 - \alpha)\hat P\big)^{-1} H\) — le développement en série \(\sum_{k} \alpha(1-\alpha)^k \hat P^k\) montre que la profondeur effective est infinie sans empiler de paramètres ; le teleport \(\alpha H\) borne les gains (comme le damping de PageRank, M1 ch. 0) et tue l'over-smoothing (M1, ch. 5.3) ; \(K\) itérations = troncature de la série. GCNII (Chen et al., 2020) rend le GCN réellement profond par deux mécanismes : $$h^{(\ell+1)} = \sigma\Big( \big[(1-\gamma_\ell) I + \gamma_\ell \hat P\big]\big[(1-\beta_\ell) I + \beta_\ell W_\ell\big] h^{(\ell)} + \gamma_\ell \hat P h^{(0)} \Big)$$ — résidu initial vers \(h^{(0)}\) (même remède que le teleport d'APPNP) et identité mappée \((1 - \beta_\ell) I\) (comme ResNet) ; avec \(\beta_\ell\) croissant en profondeur, 64 couches deviennent entraînables. Positionnement : rewiring (2.3) change le canal ; APPNP/GCNII changent la dynamique ; les graph transformers (ch. 4) suppriment le goulot en rendant le canal tous-tous ; over-smoothing (représentation) et over-squashing (canal) restent deux limites distinctes qu'il faut diagnostiquer séparément.

3. Encodages de position et de structure

Problème : les GNN « ne savent pas où ils sont » Le message passing est équivariant (M1, ch. 2) : deux nœuds aux voisinages isomorphes ont le même embedding — correct… mais insuffisant : la position globale (distance au centre, appartenance à un cycle, rôle de pont) est informative. Les transformers avaient le même problème (ordre des tokens) et l'ont résolu par des positional encodings — on réimporte l'idée (et ses pathologies).

3.1 — LapEig : les ambiguïtés, et SignNet pour les lever Prendre \(p_v = [u_2(v), \dots, u_k(v)]\) (coordonnées de \(v\) sur les vecteurs propres) souffre de trois pathologies : (i) signe : \(-u_i\) est aussi vecteur propre — deux exécutions donnent des encodages opposés ; (ii) base : si \(\lambda_i\) est multiple, toute rotation de la base est admissible ; (iii) instabilité : une petite perturbation du graphe croise les valeurs propres et fait sauter la base. SignNet (Lim et al., 2022) construit des fonctions invariantes de signe et de base : $$\rho(V) = h\Big( \sum_{i=1}^{k} \phi(v_i) + \phi(-v_i) \Big),$$ avec \(\phi, h\) des MLP : forcer la parité \(\phi(v) + \phi(-v)\) rend \(\rho\) paire (invariance de signe), et la somme sur la base rend invariance par rotation ; le théorème de complétude (dans l'esprit des résultats sur les invariants d'orbites) : SignNet universellement représente les fonctions invariantes continues des vecteurs propres — l'analogue exact du « tri avant somme » de Deep Sets (ch. 1). En pratique : LapEig + SignNet est le PE par défaut des graph transformers spectraux.
Exemple 3.2 — RWPE calculé à la main (et pourquoi ça compte) Le random-walk positional encoding (RWSE, Dwivedi et al., 2020) d'un nœud \(v\) est le vecteur des probabilités de retour \(\big[ (P)_{vv}, (P^2)_{vv}, \dots, (P^K)_{vv} \big]\), \(P = D^{-1} A\). Calcul :
  • nœud d'un triangle : \((P^2)_{vv} = \frac{1}{2}\cdot\frac{1}{2} + \frac{1}{2}\cdot\frac{1}{2} = \frac12\) (allers-retours) ; \((P^3)_{vv} = 2 \times (\frac12)^3 = \frac14\) (faire le tour du triangle, dans les deux sens) ;
  • nœud d'un hexagone C6 : \((P^2)_{vv} = \frac12\) — identique (mêmes allers-retours) ; mais \((P^3)_{vv} = 0\) : un retour de longueur impaire exige un cycle impair, et C6 n'en a pas ; le premier « tour complet » n'apparaît qu'à \(k = 6\), avec \((P^6)_{vv} = 2 \times (1/2)^6 = \frac{1}{32}\).
Or C3 et C6 sont exactement la paire que 1-WL ne distingue pas (exemple 1.4) : le RWSE — un seul scalaire, \(p_3\), suffit ici (\(\frac14\) contre \(0\)) — la sépare immédiatement. Les PE structurels « achètent » de l'expressivité à coût \(\mathcal{O}(|E| K)\) ; c'est la raison pour laquelle les modèles gagnants des benchmarks de position (ch. 4) embarquent systématiquement un PE.
3.3 — Invariants SE(3) pour les molécules, et la théorie des positions En 3D (ch. 9), l'encodage doit respecter rotations/translations/réflexions : invariants = distances inter-atomiques \(\|x_i - x_j\|\), angles, dièdres ; c'est la version continue du principe « n'utiliser que ce qui est invariant ». La question théorique : combien de coordonnées injecter sans briser l'invariance d'isomorphisme ? Un encodage de position parfait devrait distinguer les nœuds d'un graphe régulier (où 1-WL est constant) tout en restant invariant par automorphisme — les encodages canoniques (numérotation canonique) font exploser la variance d'apprentissage ; le compromis pratique : encodages relatifs (RWSE, distances d'ancrage, biais SPD du ch. 4) — jamais de coordonnées absolues.
Le débat inductif vs expressif Les encodages de position « cassent » partiellement l'équivariance — un choix délicat entre information de position et garanties d'invariance. En entreprise (graphes évolutifs), on privilégie les PE inductifs (généralisables à de nouveaux nœuds/graphes — RWSE, ancrage) ; en chimie, les invariants exacts dominent. Référence croisée : le biais SPD de Graphormer (ch. 4) est un PE relatif — la seule catégorie qui survive aux deux contraintes.

4. Graph transformers

Idée : attention tous-tous + biais de structure L'attention globale \(\mathcal{O}(n^2)\) supprime d'un coup bottlenecks et over-squashing (ch. 2) ; mais sans codage du graphe, un transformer sur les seules features est aveugle à la structure : il faut réinjecter la topologie par (i) des positional encodings (ch. 3) et (ii) des biais d'attention additifs dans les scores — la structure pilote l'attention au lieu de la masquer.
4.1 — Graphormer (Ying et al., 2021) — les trois encodeurs structurels
  1. centrality encoding : embedding du degré (entrant/sortant si orienté) additionné aux features — le degré est le premier « où suis-je » ;
  2. spatial encoding : biais appris par distance de plus court chemin : $$\mathrm{Attention}(Q, K)_{ij} = \frac{q_i^\top k_j}{\sqrt{d}} + b_{\phi(d_{ij})}, \qquad d_{ij} = \mathrm{SPD}(i, j), \quad b_{\phi(\cdot)} \text{ appris (table)},$$ avec une valeur dédiée pour \(d_{ij} = \infty\) (nœuds déconnectés) ; le biais est additif avant le softmax — la structure conditionne l'attention ;
  3. edge encoding : sur le plus court chemin \(i \rightsquigarrow j\), la moyenne des embeddings des arêtes traversées est ajoutée au score — pour les molécules, le type des liaisons le long du chemin compte.
Plus un nœud virtuel global (connecté à tous) pour le readout. Résultat : 1er rang sur OGB-LSC PCQM4M (3,7 M molécules) à sa sortie. Implémentation : 
import torch, torch.nn as nn
from torch_geometric.utils import shortest_path_distance   # PyG >= 2.6 (ou BFS maison)

class GraphormerLayer(nn.Module):
    def __init__(self, d, h, max_spd=5):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, h, batch_first=True)
        self.bias = nn.Embedding(max_spd + 2, h)     # table b_phi : SPD -> h tetes
        self.ffn = nn.Sequential(nn.Linear(d, 2*d), nn.GELU(), nn.Linear(2*d, d))
    def forward(self, x, spd):                       # spd : (n, n) distances entieres
        b = self.bias(spd.clamp(max=5).long()).permute(2, 0, 1)  # (h, n, n)
        x = self.attn(x, x, x, attn_bias=b)[0] + x
        return self.ffn(x) + x
Astuce PyG : le biais par tête se fabrique avec une embedding-table indexée par la matrice des distances (exercice 5).
4.2 — GPS (Rampasek et al., 2022) : les deux canaux, couche par couche $$H^{(\ell+1)} = \mathrm{MLP}\Big( \mathrm{BN}\big(\underbrace{\mathrm{MSA}(H^{(\ell)} + \mathrm{PE})}_{\text{canal global}} \;+\; \underbrace{\mathrm{MPNN}(H^{(\ell)}, A)}_{\text{canal local}}\big) \Big)$$ — attention globale (tous-tous ; tue l'over-squashing) + message passing local (biais de localité, convolution) ; PE injecté en entrée (ch. 3) ; batchs de graphes par concaténation-padding. Complexité par couche : \(\mathcal{O}(n^2 d)\) (attention) + \(\mathcal{O}(|E| d)\) (MPNN) — le canal global domine. GPS est une recette : on y branche n'importe quel MPNN (GCN, GINE, GAT) et n'importe quel PE (RWSE, LapEig+SignNet) — d'où son statut de framework de référence.
4.3 — Transformers efficaces : Exphormer et l'attention échantillonnée Pour \(n\) grand (ogbn-products…), \(\mathcal{O}(n^2)\) ne passe plus ; Exphormer (Shirzad et al., 2023) remplace l'attention complète par un graphe d'attention creux : (i) les arêtes du graphe réel ; (ii) les voisins d'un graphe expanseur aléatoire \(d\)-régulier — un expander a un diamètre logarithmique : l'information traverse le graphe en \(\mathcal{O}(\log n)\) couches, précisément ce que le ch. 2 demande (expansion !) ; (iii) des nœuds virtuels globaux. Complexité linéaire en \(n + |E|\) ; combiné au MPNN local, cela donne « Exphormer-GPS », l'état de l'art scalable. Généralisation : l'attention échantillonnée (voisinage, noyaux, hashing) — les mêmes recettes que les transformers longs-contexte du module LLMs M2, transposées : le graph transformer et le LLM vivent la même vie algorithmique.
4.4 — Quand un MPNN suffit-il ? (guide de décision)
  • graphe homophile, dépendances locales (Cora, fraude transactionnelle) : GCN/GAT 2-3 couches — inutile de payer \(n^2\) ;
  • motifs, distances, dépendances longues (molécules, QA sur KG) : transformer ou ESGNN (ch. 1) — la structure dépasse le voisinage ;
  • grands \(n\) : MPNN + échantillonnage (ch. 6) ou Exphormer ;
  • règle empirique des benchmarks (Dwivedi et al., 2023) : à taille égale, le gain du transformer sur MPNN+PE est réel mais modeste — l'hybride (GPS) gagne le plus souvent ; le PE est le facteur dominant, l'architecture le second.
Connexion LLGA : « attention = graphe dynamique complet » vs « GNN = attention sur graphe donné » (M1, ch. 5) ; Graphormer est la synthèse — une attention donnée et apprise — la convergence transformers ↔ GNN est LE fil rouge du master.

5. Graphes dynamiques et temporels

Deux formalismes : snapshots vs événementiel
  • snapshots : \(G_1, G_2, \dots, G_T\) (graphe agrégé par fenêtre) ; modèles : GCN+RNN (encoder chaque snapshot, récurrenter) ; simple, mais la granularité perd l'ordre dans la fenêtre ;
  • événementiel : le flux d'interactions horodatées \((u, v, t_1), (u, w, t_2), \dots\) — le « droit » du problème ; c'est le régime de la fraude (milliseconde) et de la recommandation séquentielle.
5.1 — TGAT (Xu et al., 2020) : l'encodage du temps La première architecture événementielle notable injecte le temps dans l'attention : encodage temporel sinusoïdal appris (dans l'esprit de Time2Vec) $$\phi(\Delta t) = \big[\cos(\omega_1 \Delta t), \sin(\omega_1 \Delta t), \dots, \cos(\omega_d \Delta t), \sin(\omega_d \Delta t)\big], \qquad \omega_i \text{ apprises},$$ concaténé aux features ; l'attention se calcule sur le voisinage strictement passé \(\mathcal{N}(v; t) = \{u : (u, v, t') \in E, t' \leq t\}\) — un GAT causal ; inductif par construction (nouveaux nœuds = nouveaux temps).
5.2 — TGN (Rossi et al., 2020) : les modules et leurs équations TGN factorise la mémoire temporelle :
  1. mémoire \(s_i(t) \in \mathbb{R}^d\) : état récurrent par nœud, résumant son histoire ;
  2. message : à chaque événement \((i, j, t)\), \(m_i^t = \mathrm{msg}(s_i(t^-), s_j(t^-), \Delta t, e_{ij})\) (idem pour \(j\), symétrique) ;
  3. update : \(s_i(t) = \mathrm{GRU}\big(s_i(t^-),\ \mathrm{agg}(\{m_i^{t'} : t' \leq t\})\big)\) — seuls les nœuds touchés par le batch sont mis à jour ; les nœuds « au repos » reçoivent un message placeholder pour vieillir leur mémoire ;
  4. embedding : \(z_i(t)\) calculé par un module de type TGAT sur la mémoire \(\{s_u(t^-) : u \in \mathcal{N}(i; t)\}\) + encodage \(\phi\) du temps — la mémoire est un résumé compressé, l'embedding une lecture attentive.
Entraînement : strictement causal — les batchs sont ordonnés par temps, et la technique du teacher forcing masqué (mémoriser les états entre batchs sans backprop à travers toute l'histoire, mais re-« rejouer » les états stockés) rend le gradient praticable ; loss de link prediction future : scorer \((i, j, t)\) vs négatifs (M1, ch. 6, version temporelle). L'ablation du papier : chaque module compte — retirez la mémoire, tout s'effondre sur les interactions distantes.
5.3 — Application LLGA : la fraude en temps réel Le graphe de transactions est événementiel par nature : une carte frauduleuse doit être bloquée en secondes ; le pipeline : (i) TGN encode les comptes (mémoire = comportement passé) ; (ii) un classifieur tête lit \(z_i(t)\) au moment de la transaction ; (iii) les négatifs sont d'anciennes transactions légitimes — attention à la contamination temporelle (entraîner strictement avant \(t\) : l'hygiène des splits temporels du module Emerging ML) ; (iv) en production : mise à jour incrémentale de la mémoire, dérive du modèle à surveiller. Datasets TP : Wikipedia edits / Reddit (standards TGN), et les banques de transactions anonymisées. Variantes : CAWN (attention par marches causales), memorisation compressée ; le survey de l'état de l'art vit côté temporal graph learning.
