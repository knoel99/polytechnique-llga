0. Rappels : le socle message passing

Rappels du module Graph ML (M1 P2)
  • Couche générique : \(h_v^{(\ell+1)} = \phi\big(h_v, \mathrm{AGG}_{u \in \mathcal{N}(v)}\{\psi(h_v, h_u)\}\big)\) ;
  • GCN (moyenne renormalisée), GraphSAGE (échantillonnage, inductif), GAT (poids par attention) ;
  • Laplacien \(L = D - A\), convolution spectrale, polynômes de Tchebychev ;
  • Over-smoothing : après beaucoup de couches, tous les embeddings convergent — pourquoi on s'arrête à 2-4 couches… et pourquoi ce module existe.

1. Expressivité : le test de Weisfeiler-Lehman

Définition 1.1 — 1-WL (color refinement) Initialiser une couleur \(c_v^{(0)}\) par les features ; itérer : $$c_v^{(k+1)} = \mathrm{HASH}\Big(c_v^{(k)},\ \mathrm{SORT}\big\{c_u^{(k)} : u \in \mathcal{N}(v)\big\}\Big).$$ Deux graphes sont 1-WL-équivalents si les multisets de couleurs coïncident à convergence. Le 1-WL distingue presque tous les graphes aléatoires… mais échoue sur des familles simples : cycles de même taille, graphes réguliers, molécules chimiques discutées depuis les années 60.
Théorème 1.2 — Puissance des GNN de message passing (Xu et al., 2019 ; Morris et al., 2019) Un GNN avec agrégation injective est au plus aussi puissant que 1-WL (il ne distingue jamais deux graphes 1-WL-équivalents). Réciproquement, le GIN (Graph Isomorphism Network) — $$h_v^{(k+1)} = \mathrm{MLP}\Big((1 + \epsilon)\, h_v^{(k)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k)}\Big)$$ (somme + MLP = injection sur les multisets) — atteint exactement 1-WL. Conséquence : GCN/GraphSAGE (moyenne) sont strictement moins puissants.
Monter en puissance : k-WL et k-GNN Le k-WL colore les k-uplets de nœuds (k=2 : paires — détecte les cycles) ; hiérarchie stricte : (k+1)-WL > k-WL. Les k-GNN (Morris et al.) implémentent k-WL en pratique ; coût \(\mathcal{O}(n^k)\) ; compromise expressivité/calcul. Alternative : sous-graphes (ESGNN), comptage de motifs (motif-parameters) ; et les Path Neural Networks (Michoel/Vazirgiannis et al.) — remplacer les marches (1-WL) par des chemins et des opérateurs plus riches que la somme : un axe de recherche du master.
Exemple 1.3 — C6 vs 2×C3 L'hexagone et deux triangles sont 1-WL-indistinguables (tous les nœuds de degré 2, voisinages identiques à chaque tour). Le 2-WL les sépare (les paires à distance 2 diffèrent). À coder en TP : vérifier qu'un GCN produit des embeddings identiques et qu'un k-GNN non.

2. Over-squashing et GNN profonds

Définition 2.1 — Over-squashing (Alon & Yahav, 2021) Faire passer les informations de \(2^k\) nœuds d'un « réceptive field » exponentiel dans des vecteurs de dimension fixe via des bottlenecks (arêtes de coupe) : la capacité de communication sature. Formellement : lié à la connectivité spectrale — le nombre de marches et la courbure des arêtes ; \(\lambda_{\max}\) de l'opérateur de propagation borne la contraction.
  • Diagnostic : la performance dégrade sur les nœuds « loin » de leur communauté ; visualiser le flux par le spectre ;
  • Remèdes structurels (graph rewiring) : ajouter des arêtes virtuelles (diffusion \(\tilde A = A + \beta A^2\) — SDRF, DIGL) ; dilater les voisinages (adaptative) ; courbure (Ricci) — regarder le graphe comme un objet géométrique ;
  • Remèdes algorithmiques : résidus/normalisation (GCNII, APPNP — propagation initiale), all-pairs communication (graph transformers, ch. 4) ;
  • Over-smoothing vs over-squashing : deux limites distinctes de la profondeur ; l'une sur la représentation (tout devient pareil), l'autre sur le canal (tout ne peut pas passer) ; le deep graph learning = les gérer ensemble.

3. Encodages de position et de structure

Problème : les GNN « ne savent pas où ils sont » Le message passing est équivariant — deux nœuds isomorphes ont le même embedding : correct… mais insuffisant : la position globale (distance au centre, appartenance à un cycle) est informative. Les transformers avaient le même problème (ordre des tokens) et l'ont résolu par des positional encodings — on réimporte l'idée.

Le débat inductif vs expressif Les encodages de position « cassent » partiellement l'équivariance — un choix délicat entre information de position et garanties d'invariance. En entreprise (graphes évolutifs), on privilégie les PE inductifs (généralisables à de nouveaux nœuds/graphes) ; en chimie, les invariants exacts dominent. Référence croisée : « position/structure » dans Graphormer (ch. 4).

4. Graph transformers

Architecture 4.1 — GPS : General, Powerful, Scalable (Rampasek et al., 2022) Hybridation couche par couche : $$H^{(\ell+1)} = \mathrm{Transformer}\big(H^{(\ell)} + \mathrm{PE}\big) \;\Big\|\; \mathrm{MPNN}\big(H^{(\ell)}, A\big)$$ — attention globale (communication tous-tous ; résout over-squashing) + message passing local (biais de localité) ; + encodage de position (ch. 3). Graphormer (Ying et al., 2021) : biais d'attention appris par distance de plus court chemin (descente aux plus courts chemins = encodeur structurel) ; SOTA sur les benchmarks moléculaires.
  • Complexité : l'attention globale est \(\mathcal{O}(n^2)\) — grands graphes : attention par voisinage échantillonné (GraphGPS+), kernel & linear attention, ou découpe en sous-graphes ;
  • Connexion LLGA : le transformer du module LLMs et le graph transformer sont la même architecture ; « attention = graphe dynamique complet » vs « GNN = attention sur graphe donné » — la convergence transformers ↔ GNN est LE fil rouge du master.
from torch_geometric.nn import GPSConv
conv = GPSConv(channels=64, conv=None, heads=4)   # conv=None -> attention pure locale+globale
# x : (n, 64), edge_index : (2, e), pe : encodage de position (n, k)
out = conv(x, edge_index, batch=None, pe=pe)

5. Graphes dynamiques et temporels

  • Motivation : transactions, interactions sociales, réseaux de communication — les arêtes ont des horodatages ; prédire la prochaine interaction (TGN, Rossi et al. : mémoire par nœud + modules temporels) ;
  • Discrétisation par snapshots : GCN+RNN ; événementiels : mises à jour à chaque interaction (TGAT, CAWN) ; mémoire + attention ;
  • Pré-entraînement temporel : masquer des arêtes futures (l'analogue du MLM pour graphes) ;
  • Application LLGA typique : détection de fraude en temps réel (le graphe de transactions évolue à la seconde), systèmes de recommandation séquentiels — TP sur dataset Wikipedia edits / Reddit.

6. Échelle : sampling, systèmes

  • Mini-batching sur graphes : NeighborSampler (k-hops), cluster-GCN (partitionner), GraphSAINT (échantillonner des sous-graphes) ; biais vs efficacité ;
  • Pipelining GPU : PinSage ; partitionnement de graphe multi-GPU ; distributed training (lien avec le module Emerging ML) ;
  • Benchmarks : OGB (ogbn-arxiv ~170k nœuds ; ogbg-mol ; PCQM4M) ; « leaderboard » ; protocole expérimental rigoureux (Dwivedi et al. : reproductibilité des GNN — le papier « benchmarking graph networks » du cours) ;
  • Bonne pratique recherche : hyperparamètres par recherche (Bayésienne), seeds multiples, intervalles de confiance — l'hygiène du M1 devient indispensable (les gains SOTA sont parfois < 1 point).

7. Robustesse et privacy sur graphes

  • Attaques adverses : modifier quelques arêtes/features change la prédiction (Nettack, Zügner et al. ; attaques par re-wiring discrètes) ; impacted : détection de fraude (l'attaquant connaît le modèle) ; défenses : entraînement robuste, prétraitement (janitor), certification ;
  • Empoisonnement : faux comptes qui s'insèrent (attaques par influence) ; lien byzantin du module Emerging ML (clients malveillants = nœuds malveillants) ;
  • Privacy : node-DP / edge-DP (bruit sur les comptages d'arêtes) ; réidentification par embeddings ; les LLMs sur graphes fuient-ils des nœuds ? — les questions ouvertes du « privacy of graph data » ; croisement avec le module M2 sécurité des LLMs ;
  • Équité : biais de degré (les nœuds à faible degré sont moins bien prédits) ; fairness structurelle — lien avec le module OT/fairness (transporter des distributions de nœuds).

8. Frontières : molécules 3D, Path NN, GraphRAG

  • Géométrie 3D & équivariance : les molécules vivent en 3D ; les réseaux équivariants à l'action E(n) (EGNN, Satorras et al.) respectent rotations et translations — pont direct avec le module « Analysis and Deep Learning on Geometric Data » (M2) et Geometric DL (Bronstein et al.) ;
  • Path Neural Networks (équipe du master) : remplacer l'agrégation par marches aléatoires (1-WL) par des chemins (plus courts chemins) : expressivité supérieure, coût maîtrisé ; un article de recherche à lire et présenter en cours ;
  • GNN × LLM : GNN comme encodeur structurel injecté dans un LLM ; LLM comme zéro-shot graph reasoner ; benchmarks (NLGraph) ; le GraphRAG industriel comme produit : la spécialité rare que le master fabrique ;
  • Neural algorithmic reasoning : apprendre à exécuter des algorithmes (tri, plus courts chemins) par GNN — la boucle avec le Refresher CS se referme : qu'est-ce qu'un « algorithme appris » peut de plus qu'un algorithme ?

Exercices

  1. 1-WL à la main. Exécuter 1-WL sur C6 et 2×C3 et vérifier l'indistinguabilité ; puis sur le graphe « maison » vs pentagone ; conclure sur la famille exacte des paires indiscernables (graphes réguliers de même degré).
  2. GIN vs GCN. Montrer que la moyenne (GCN) n'est pas injective sur les multisets (donner un contre-exemple {a, a, a} vs {a}) et que somme+MLP l'est (cas des features discrètes) ; vérifier expérimentalement sur les paires 1-WL.
  3. Over-squashing. Construire deux « communautés » reliées par un seul nœud-bottleneck ; mesurer la performance de classification d'un GCN en fonction de la distance au bottleneck ; comparer avec GPS et un GCN + arêtes virtuelles.
  4. LapEig. Calculer les 2 premiers vecteurs propres non triviaux du laplacien du graphe du club de karaté ; projeter les nœuds ; vérifier que la séparation visualisée ≈ la partition réelle ; discuter l'ambiguïté de signe et une mitigation (sign-flip consistent).
  5. Graphormer-PE. Implémenter un biais d'attention par distance de plus court chemin (matrice de distances par BFS ; table de biais apprise) ; entraîner sur une tâche de classification moléculaire (ogbg-molhiv) et comparer avec un GCN.
  6. Attaque. Implémenter une attaque par retrait/ajout de \(k\) arêtes ciblant un nœud (gradient sur les arêtes non existantes) ; mesurer le flip de prédiction ; tester une défense (entraînement sur graphes perturbés).
  7. Projet recherche. Reproduire une expérience d'un article parmi (PathNN / GPS / TGN) sur OGB ; rapport : protocole, seeds, comparaison aux chiffres publiés — l'exercice « papier » du M2.
