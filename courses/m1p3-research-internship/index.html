Enjeux (Extrapolons)

Notes extrapolées. Le stage recherche M1 (20 ECTS) est le premier grand test hors salle de cours : formuler une question, lire la littérature, expérimenter, et rendre compte. Empiriquement, c’est là que le track Graph×LLM devient un sujet plutôt qu’une collection de modules.

Ce n’est pas encore le stage de fin d’études (24 ECTS en M2) : ici l’accent est recherche-oriented — labo académique, équipe R&D industrielle, ou mixtes — avec un livrable de type rapport / poster / code reproductible selon l’encadrement.

Place dans le parcours 2 ans

Amont : P1–P2 (ML, DL, RL, Graph ML, NLP, options). Ici : immersion P3. Aval : spécialisation M2 (LLMs, GNN avancés, géométrie, sûreté) puis stage de fin d’études. Beaucoup de sujets M2 se lisent mieux après avoir « touché » un paper bout-en-bout en M1.

Voir aussi la page Capacités de sortie pour des questions de synthèse Graph×LLM utiles à cadrer un sujet.

Lien industrie et recherche

Recherche : méthode expérimentale, baselines, ablation, écriture. Industrie R&D : même exigence de preuve, avec contraintes data/prod. Le stage aide à trancher pour M2 : plutôt recherche doctorale, plutôt engineering ML, ou frontière CIFRE.

Comment l’aborder

  • Une question, une métrique, une baseline — avant d’empiler des modèles.
  • Journal de bord hebdomadaire : hypothèse → essai → résultat → prochaine question.
  • Gardez un lien explicite avec au moins un module du dépôt (ex. Graph ML, OT, LLM).
