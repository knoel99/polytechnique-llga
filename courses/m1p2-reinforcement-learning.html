0. Rappels : chaînes de Markov

Rappels L3 — chaînes de Markov
  • Chaîne de Markov : \(X_{t+1} \sim P(\cdot \mid X_t)\) — le futur ne dépend que du présent. Matrice de transition stochastique (lignes sommant à 1).
  • Distribution stationnaire : \(\pi = \pi P\) ; existe et est unique pour une chaîne irréductible apériodique (théorème de Perron-Frobenius).
  • Marches aléatoires sur graphes : \(P = D^{-1}A\) — le promeneur aléatoire ; \(\pi(v) \propto \deg(v)\) ; à relier à PageRank et aux node embeddings (module Graph ML).
  • Espérance conditionnelle : \(\mathbb{E}[X \mid Y]\) (Refresher Statistics) — la fonction de valeur en est une.

1. Processus de décision markovien

Définition 1.1 — MDP Un MDP est un tuple \((\mathcal{S}, \mathcal{A}, P, r, \gamma)\) : états \(\mathcal{S}\), actions \(\mathcal{A}\), noyau de transition \(P(s' \mid s, a)\), récompense \(r(s, a, s')\), facteur d'actualisation \(\gamma \in [0, 1)\). Une politique \(\pi(a \mid s)\) règle le choix des actions ; l'objectif est le retour espéré actualisé $$J(\pi) = \mathbb{E}_\pi\Big[\sum_{t=0}^{\infty} \gamma^t R_t\Big].$$
Définition 1.2 — Fonctions de valeur $$V^\pi(s) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s\Big], \qquad Q^\pi(s, a) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s, A_0 = a\Big].$$ \(V^\pi\) = « combien vaut l'état » ; \(Q^\pi\) = « combien vaut le couple état-action ». On a \(V^\pi(s) = \sum_a \pi(a\mid s)\, Q^\pi(s,a)\).
Théorème 1.3 — Équations de Bellman (évaluation) $$Q^\pi(s, a) = r(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s'), \qquad V^\pi(s) = \sum_a \pi(a \mid s)\Big[r(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s')\Big].$$ C'est la programmation dynamique appliquée au temps : la valeur d'aujourd'hui = gain immédiat + valeur actualisée de demain.
Théorème 1.4 — Optimalité Il existe une politique optimale déterministe \(\pi^\star\) telle que $$Q^\star(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, \max_{a'} Q^\star(s', a'),$$ et \(\pi^\star(s) \in \arg\max_a Q^\star(s, a)\). L'opérateur de Bellman \((\mathcal{T}Q)(s,a) = r + \gamma\, \mathbb{E}[\max_{a'} Q(s', a')]\) est une contraction de module \(\gamma\) ⇒ existence et unicité de \(Q^\star\) (point fixe de Banach — rappel L3).

2. Programmation dynamique (modèle connu)

Algorithme 2.1 — Value iteration Répéter jusqu'à convergence : $$V_{k+1}(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V_k(s')\Big\}.$$ Convergence géométrique (\(\|V_{k+1} - V^\star\| \leq \gamma \|V_k - V^\star\|\)). Policy iteration : alterner évaluation exacte de \(\pi\) (résolution linéaire) et amélioration gloutonne \(\pi' = \arg\max_a Q^\pi\) ; converge en un nombre fini de politiques. 
import numpy as np

# Gridworld 4x4 : etats 0..15, actions 0..3 (haut, bas, gauche, droite)
S, A, gamma = 16, 4, 0.95
goal = 15
P = np.zeros((S, A, S)); r = -np.ones((S, A))
def step(s, a):
    i, j = divmod(s, 4)
    di, dj = [(-1,0),(1,0),(0,-1),(0,1)][a]
    return 4*min(max(i+di,0),3) + min(max(j+dj,0),3)
for s in range(S):
    for a in range(A):
        s2 = step(s, a)
        P[s, a, s2] = 1.0
        if s2 == goal or s == goal: r[s, a] = 0.0
r[goal] = 0.0

V = np.zeros(S)
for _ in range(200):                       # value iteration
    Q = r + gamma * (P @ V)                # (S, A)
    V = Q.max(axis=1)
pi = Q.argmax(axis=1)
print(V.reshape(4, 4).round(2))

3. Learning : TD, SARSA, Q-learning (modèle inconnu)

En pratique on ne connaît ni \(P\) ni \(r\) : on interagit. Le temporal-difference learning apprend en corrigeant chaque prédiction vers l'observation :

Algorithme 3.1 — TD(0), SARSA, Q-learning
  • TD(0) (évaluation) : \(V(S_t) \leftarrow V(S_t) + \alpha\big[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\big]\) ; le bracket est l'erreur TD.
  • SARSA (on-policy) : \(Q(S_t, A_t) \leftarrow Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t,A_t)\big]\).
  • Q-learning (off-policy) : $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\Big[R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t)\Big].$$ Convergence vers \(Q^\star\) si toutes les paires sont visitées infiniment souvent et \(\alpha\) décroît (conditions de Robbins-Monro — rappel : SGD stochastique sur l'équation de Bellman).
Exploration : politique \(\varepsilon\)-gloutonne Avec probabilité \(\varepsilon\) : action aléatoire ; sinon \(\arg\max_a Q(s, a)\). Sans exploration, le signal d'apprentissage s'éteint ; \(\varepsilon\) décroissant est le réglage standard.
Q-learning ≠ SARSA en une phrase Q-learning apprend la politique optimale quelle que soit la politique d'exploration (off-policy) ; SARSA évalue la politique effectivement suivie (y compris l'exploration) — plus prudent près des falaises ! (TP classique : Cliff Walking.)

4. Policy gradients et actor-critic

4.1 REINFORCE

Théorème 4.1 — Gradient de politique Pour \(\pi_\theta\) différentiable : $$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\Big[\Big(\sum_{t=0}^{T} \nabla_\theta \log \pi_\theta(A_t \mid S_t)\Big) \, G(\tau)\Big],$$ où \(G(\tau)\) est le retour de la trajectoire. Preuve (esquisse) : dériver la vraisemblance \(\pi_\theta(\tau) = \mu(S_0)\prod_t \pi_\theta(A_t \mid S_t) P(S_{t+1}\mid S_t, A_t)\) — le log annule la dynamique, qui ne dépend pas de \(\theta\).
  • Variance : le retour brut est très bruité ⇒ baseline \(b(s)\) : \(\nabla J = \mathbb{E}[\nabla \log \pi \,(G - b(S))]\) — sans biais, variance réduite ; le meilleur choix de baseline mène à l'avantage \(A^\pi(s, a) = Q^\pi(s,a) - V^\pi(s)\) ;
  • Actor-critic (A2C) : un acteur \(\pi_\theta\) + un critique \(V_w\) appris par TD ; l'avantage estimé \(\hat A_t = R_{t+1} + \gamma V_w(S_{t+1}) - V_w(S_t)\) ;
  • PPO (Schulman et al., 2017) : tronquer le ratio d'importance $$r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_\text{old}}(a_t \mid s_t)}, \qquad L^{\mathrm{CLIP}} = \mathbb{E}\big[\min\big(r_t \hat A_t,\ \mathrm{clip}(r_t, 1{-}\epsilon, 1{+}\epsilon)\hat A_t\big)\big]$$ — pas de confiance implicite ; c'est la méthode derrière l'alignement des LLMs (RLHF/PPO, module M2).
# Squelette REINFORCE avec baseline (PyTorch, probleme CartPole)

5. Deep RL : DQN et au-delà

Algorithme 5.1 — DQN (Mnih et al., 2015) Q-learning où \(Q(s, a; \theta)\) est un réseau ; stabilisé par :
  • experience replay : rééchantillonner des transitions passées (casse la corrélation temporelle) ;
  • réseau cible \(\theta^-\) gelé et synchronisé périodiquement : cible \(y = r + \gamma \max_{a'} Q(s', a'; \theta^-)\) (évite la poursuite d'une cible mouvante) ;
  • perte \(\big(y - Q(s, a; \theta)\big)^2\).
Variantes : Double DQN (sur-estimation), Dueling, distributional (C51), Rainbow.
  • Enjeux deep RL : instabilité, sample efficiency, hyperparamètres ; benchmarks : Gymnasium (CartPole, LunarLander), Atari ;
  • Off-policy vs on-policy : DQN réutilise tout le passé (économe en interactions, instable) ; PPO jette les données après chaque lot (stable, gourmand) ; le choix se retrouve dans le post-training des LLMs ;
  • Model-based RL : apprendre la dynamique et planifier (MPC, world models) — lien avec les « agents qui raisonnent ».

6. Bandits et exploration

Définition 6.1 — Bandit à K bras MDP à un seul état : à chaque pas choisir un bras \(a\) et recevoir \(r \sim \nu_a\). Objectif : minimiser le regret cumulé $$R_T = T\,\mu^\star - \mathbb{E}\Big[\sum_{t=1}^T \mu_{A_t}\Big].$$
Algorithmes classiques \(\varepsilon\)-greedy (baseline simple) ; UCB : jouer \(A_t = \arg\max_a \big[\hat\mu_a + \sqrt{2\log t / N_a}\big]\) (« optimisme face à l'incertitude ») ; Thompson sampling : échantillonner \(\tilde\mu_a\) du posterior et jouer le meilleur — regret \(\mathcal{O}(\log T)\) optimal en bandits gaussiens/beta. Contextuel : \(\hat \mu(a \mid x)\) — le cœur des systèmes de recommandation ; linéaire (LinUCB) ou par réseau.
Exploration chez les LLMs Le RLHF et l'évaluation des LLMs (best-of-n, vote) sont des problèmes de bandit ; RLVR (RL from verifiable rewards) utilise l'exploration pour la recherche de chaînes de raisonnement — chapitre repris au module M2.

7. Agents autonomes à l'ère des LLMs

  • Définir un agent : percevoir → décider → agir → observer, en boucle (l'agent = politique \(\pi\) sur un MDT — « processus de décision avec outils ») ; perception = contexte (texte, mémoire), action = tool calls, API, code ;
  • LLM + outils : le LLM est le moteur de décision ; le « prompt » = état ; function calling = espace d'actions ; boucle ReAct (Reason + Act) ; la recherche web et l'exécution de code étendent l'espace d'états ;
  • Mémoire et RAG : l'état dépasse la fenêtre de contexte ⇒ mémoire externe (vector stores, GraphRAG sur graphes de connaissances — intersection exacte du master : NLP × Graph ML × LLM) ;
  • Multi-agents : systèmes d'agents = graphes — nœuds : agents spécialisés (contexte et prompt propres), arêtes : flux d'information, topologie DAG ou cyclique (orchestrateur-travailleurs, débats, vérificateurs). Les workflows « deep research » actuels orchestrent >100 agents en phases parallèles ; ce « graph engineering » est l'un des débouchés du master (cf. LangGraph, AutoGen) ;
  • Évaluation des agents : environnements (benchmarks tool-use), récompenses vérifiables, coûts (tokens, appels) ; sûreté : permissions, sandboxing, supervision humaine.
TP fil rouge Coder un mini-agent « deep research » : un orchestrateur (LLM) qui décompose une question en sous-tâches, des travailleurs qui cherchent et résument, un vérificateur qui exige des sources, un rédacteur qui compile — le tout représenté et exécuté comme un DAG d'agents (cf. Refresher CS, tri topologique).

Exercices

  1. Bellman papier. Résoudre analytiquement un MDP à 2 états (continuer à coût \(c\), s'arrêter à récompense 0) : écrire les équations de Bellman et calculer \(V^\star\) en fonction de \(\gamma\) et \(c\) ; interpréter le seuil \(c = \gamma\).
  2. Value vs policy iteration. Sur le gridworld du chapitre 2, comparer le nombre d'itérations et le coût par itération ; vérifier que les politiques coïncident.
  3. Q-learning tabulaire. Implémenter Q-learning avec \(\varepsilon\)-greedy sur Cliff Walking (Sutton & Barto, ex. 6.6) : comparer les trajectoires apprises par Q-learning (optimal, bord de falaise) et SARSA (prudent) ; tracer le retour par épisode.
  4. REINFORCE, variance. Sur CartPole, comparer REINFORCE avec et sans baseline ; tracer la variance des gradients empiriques et la courbe d'apprentissage.
  5. Bandits. Simuler un bandit à 3 bras bernoulli (0.2, 0.5, 0.7) ; comparer \(\varepsilon\)-greedy, UCB, Thompson ; tracer le regret cumulé sur 5000 pas et vérifier le comportement en \(\log T\) des deux derniers.
  6. Projet agent. Étendre le TP fil rouge : ajouter une boucle de vérification (agent critique) et mesurer l'impact sur la qualité des rapports (notation humaine ou LLM-judge) et sur le coût total en tokens.
