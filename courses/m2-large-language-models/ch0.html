0. Rappels : de word2vec aux transformers

Prérequis (modules M1)
  • Embeddings (NLP ch. 3) : word2vec/GloVe — un mot = un vecteur statique, perte skip-gram et negative sampling dérivées ;
  • Attention & transformers (Deep Learning ch. 6) : \(\mathrm{softmax}(QK^\top/\sqrt{d_k})V\), multi-tête, résidus, LayerNorm ; lecture « graphe de tokens » ; BERT/GPT vus en application (NLP ch. 7) ;
  • Repêchage (NLP ch. 2) : TF-IDF et BM25 — les baselines du retrieval de ce module (ch. 7) ; embeddings de phrases SBERT (NLP ch. 7) pour la recherche dense ;
  • RL (module RL) : politiques, gradients de politique, PPO (ch. 4 du module RL — le moteur de l'alignement, ch. 5), bandits (ch. 6) ;
  • Cross-entropy et perplexité (ML ch. 3, NLP ch. 0) : la perte de pré-entraînement est exactement la maximisation de vraisemblance du token suivant ; \(\mathrm{PPL}=\exp(\mathcal{L})\) en base e.

La trajectoire : n-grammes → embeddings statiques → réseaux récurrents (LSTM) → attention (Bahdanau 2014) → transformer (Vaswani 2017) → BERT/GPT (2018-2019) → scaling (GPT-3, 2020) → alignement (InstructGPT 2022, RLHF) → LLMs généralistes multimodaux, de raisonnement et agentiques (2023-2026). Ce module couvre chaque étage technique de cette pile, du tokenizer (ch. 1) à la sûreté (ch. 9), en démontrant les résultats que le M1 laissait en affirmation.

Méthode du module Chaque chapitre alterne théorie démontrée (boîtes thm/prop avec preuves) et labs (nanoGPT, DPO jouet, RAG, agent). Les renvois « NLP ch. N » pointent vers le module M1 Introduction to Text Mining and NLP, dont ce cours est le prolongement direct : la tokenisation (NLP ch. 1 → ch. 1), le BM25 (NLP ch. 2 → ch. 7), les embeddings de phrases (NLP ch. 7 → ch. 7), les transformers (NLP ch. 7 → ch. 2).
