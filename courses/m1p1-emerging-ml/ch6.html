6. Collaboration, personalisation, équité

  • Personnalisation : un modèle global + des têtes locales (fine-tuning léger par client) ; interprétation bayésienne (mélange de posteriors) ; formalisation multi-tâches (Ditto, ch. 3) ;
  • Model fusion et mode connectivity : deux réseaux entraînés depuis la même initialisation sont reliés par un chemin quasi plat dans la surface de perte (barrière faible le long du segment — Frankle et al., 2020) ; conséquence pour la collaboration : on peut moyenner des modèles locaux… s'ils restent dans le même bassin ; le réalignement des permutations de neurones entre deux modèles est la clé des fusions récentes (esquisse) ; ce sont les fondements théoriques de FedAvg (la moyenne de chapitre 3 n'a de sens que dans ce régime) ;
  • Marchés de la donnée : valoriser une source de données par sa contribution marginale — valeur de Shapley \(\phi_i = \sum_{S \ni i}\) [gain du modèle avec \(S\) moins sans \(i\)] (estimée par permutations Monte-Carlo) ; acheteurs/vendeurs de données, incitations à la qualité — la théorie des jeux rencontre le ML ;
  • FL vertical : les clients détiennent des features différentes sur les mêmes individus (banque × revendeur) : split learning, échanges de représentations intermédiaires protégées — complément du FL « horizontal » du ch. 3 ;
  • Équité : performance par sous-groupes (demographic parity, equalized odds) ; en fédéré, l'équité croise les clients ; le module Computational Optimal Transport donne des outils (barycentres, fairness via OT) ;
  • Vers les systèmes multi-agents : quand les « workers » deviennent des agents LLM, la collaboration devient orchestration (rôles, votes, vérification) — la boucle est bouclée avec le module Reinforcement Learning and Autonomous Agents, chapitre 7 ; les mécanismes de ce module (agrégation robuste, budgets, incitations) s'y transposent directement.
