9. Foules et comportements

Définition 9.1 — Boids (Reynolds, 1987) Chaque agent (boid) est une particule munie de trois forces comportementales locales (voisinage de perception) :
  • séparation : \(\mathbf{f}_s = \sum_{j \in \mathcal{N}} \dfrac{\mathbf{x}_i - \mathbf{x}_j}{\|\mathbf{x}_i - \mathbf{x}_j\|^2}\) — anti-collision ;
  • alignement : \(\mathbf{f}_a = \overline{\mathbf{v}}_{\mathcal{N}} - \mathbf{v}_i\) — même direction que le voisinage ;
  • cohésion : \(\mathbf{f}_c = \overline{\mathbf{x}}_{\mathcal{N}} - \mathbf{x}_i\) — rester avec le groupe.
L'émergence (nuées, bancs) vient de règles locales sans chef ni plan ; coût \(O(n \cdot k)\) avec \(k\) voisins, voisinage trouvé par grille spatiale ou kd-tree — cf. module Refresher CS, chapitre structures de données spatiales.
Définition 9.2 — Forces sociales (Helbing–Molnár) Pour les foules humaines, chaque agent a une vitesse désirée \(\mathbf{v}_i^0\) (vers son but, par un graphe de navigation) et subit $$m_i\dot{\mathbf{v}}_i = \underbrace{m_i\tfrac{1}{\tau}\big(\mathbf{v}_i^0 - \mathbf{v}_i\big)}_{\text{atteinte du but}} + \underbrace{\sum_{j\neq i} \mathbf{f}_{ij}^{soc}}_{\text{répulsion psycho.}} + \underbrace{\mathbf{f}_{i}^{murs}}_{\text{bords}}, \qquad \mathbf{f}_{ij}^{soc} = A\,e^{-\|\mathbf{x}_j - \mathbf{x}_i\|/B}\,\mathbf{n}_{ij}.$$ Paramètres typiques \(A = 2 \times 10^3\) N, \(B = 0{,}08\) m, \(\tau = 0{,}5\) s. Phénomènes émergents documentés : formation de voies opposées dans les couloirs, arches devant les portes, « faster-is-slower » (pousser plus ralentit l'évacuation).
Exemple 9.3 — Deux flux, une porte, une brigade 60 agents, moitié vers la droite, moitié vers la gauche, porte de largeur \(1{,}2\) m dans un mur. Débit mesuré en fonction de l'« impatience » (gain sur \(\|\mathbf{v}^0\|\)) : à \(v^0 = 1\) m/s, débit 1,1 agent/s, files ordonnées ; à \(v^0 = 2{,}5\) m/s, arches instables, débit chute à 0,6 agent/s. Vérification analytique approchée : débit \(\approx \rho\,v\,w_{eff}\) avec \(w_{eff}\) la largeur utile ; l'arche bloque la section (\(w_{eff}\) chute de moitié), la densité ne compense pas — le résumé qualitatif de « faster-is-slower ». Un moteur d'animation s'en sert pour réguler les foules de fond (level of detail : simulation complète < 30 m, sprites au-delà).
Navigation : graphe, grille, champs Le but \(\mathbf{v}^0\) vient d'une couche de navigation : graphe de waypoints (A*, Dijkstra — cf. module Refresher CS, chapitre graphes), maillage de navigation (navmesh) avec recherche hiérarchique, ou champs de potentiel précalculés par équation eikonale (fast marching — la même équation que les distances géodésiques du module de géométrie). Les techniques RVO/ORCA (reciprocal velocity obstacles) remplacent les forces par une vitesse choisie évitant les collisions à horizon court : plus stable à haute densité que les forces sociales, standard des simulations urbaines temps réel.
