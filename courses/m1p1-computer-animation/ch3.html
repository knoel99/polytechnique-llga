3. Stabilité : le théorème de l'oscillateur

Définition 3.1 — Amplification et stabilité Appliqués au système linéaire \(\dot{\mathbf{y}} = A\mathbf{y}\), les schémas du chapitre 2 s'écrivent \(\mathbf{y}_{n+1} = G\,\mathbf{y}_n\) avec \(G\) linéaire. Le schéma est stable sur ce système si le rayon spectral \(\rho(G) \leq 1\) (toute composante reste bornée), instable si \(\rho(G) > 1\) (divergence géométrique). Pour EE et EI, \(G = I \pm hA\) : la stabilité dépend du produit \(h\lambda\) pour chaque valeur propre \(\lambda\) de \(A\). L'ensemble \(\{z \in \mathbb{C} : |1 + z| \leq 1\}\) (resp. \(\{|1 - z|^{-1} \leq 1\}\)) est la région de stabilité d'EE (resp. EI).
Théorème 3.2 — Euler explicite diverge sur l'oscillateur, pour tout pas Pour l'oscillateur \(\ddot{x} = -\omega^2 x\) (valeurs propres \(\lambda = \pm i\omega\)), EE donne \(x_{n+1} = x_n + h v_n\), \(v_{n+1} = v_n - h\omega^2 x_n\), soit $$G_{EE} = \begin{pmatrix} 1 & h \\ -h\omega^2 & 1 \end{pmatrix}, \qquad \det(G_{EE} - \lambda I) = (1-\lambda)^2 + h^2\omega^2,$$ dont les racines sont \(\lambda_\pm = 1 \pm i\,h\omega\). Donc \(\rho(G_{EE}) = \sqrt{1 + h^2\omega^2} > 1\) pour tout \(h > 0\) : l'énergie croît de \(\rho^2 = 1 + h^2\omega^2\) par pas, indépendamment de la finesse du pas.
Le polynôme caractéristique se calcule directement. Les racines s'obtiennent en résolvant \((1 - \lambda)^2 = -(h\omega)^2\), i.e. \(1 - \lambda = \pm i h\omega\). Le module de \(1 \pm i h\omega\) vaut \(\sqrt{1 + h^2\omega^2}\), strictement supérieur à 1 dès que \(h\omega \neq 0\). La composante de \(\mathbf{y}_0\) sur un vecteur propre croît comme \(\rho^n\) : après \(n\) pas, \(\|\mathbf{y}_n\| \gtrsim \rho^n\). ∎
Exemple 3.3 — Explosion mesurée Avec \(\omega = 1\), \(h = 0{,}1\) (100 pas par période, pourtant « fin ») : \(\rho = \sqrt{1{,}01} \approx 1{,}005\). L'énergie croît de 0,5 % par pas : ×1,64 après 100 pas (1 période !), ×145 après 1000 pas. À l'écran : un ballon qui rebondit de plus en plus haut sans aucune énergie injectée — l'artefact classique du stagiaire qui code EE sur un ressort.
Théorème 3.4 — Euler implicite est inconditionnellement stable (A-stable) Sur le même oscillateur, EI s'écrit \(G_{EI} = (I - hA)^{-1}\), de valeurs propres \(\dfrac{1}{1 \mp i h\omega}\), de module \(\dfrac{1}{\sqrt{1 + h^2\omega^2}} < 1\) : stable pour tout \(h\), avec un amortissement numérique croissant avec \(h\). Plus généralement, \(\rho(G_{EI}) < 1\) dès que toutes les valeurs propres de \(A\) sont à partie réelle \(< 0\) — propriété dite de A-stabilité (Dahlquist, 1963).
\((I - hA)\mathbf{u} = (1 - h\lambda)\mathbf{u}\) pour tout vecteur propre \(\mathbf{u}\), donc les valeurs propres de l'inverse sont les inverses \((1 - h\lambda)^{-1}\). Si \(\lambda = i\omega\), \(|1 - i h\omega| = \sqrt{1 + h^2\omega^2} > 1\) donc l'inverse est \(< 1\). Si \(\mathrm{Re}\,\lambda < 0\), alors \(|1 - h\lambda|^2 = (1 - h\mathrm{Re}\lambda)^2 + (h\mathrm{Im}\lambda)^2 > 1\), d'où le résultat pour tout \(h > 0\). ∎
Théorème 3.5 — Euler symplectique : stabilité conditionnelle et énergie bornée Avec ES, \(v_{n+1} = v_n - h\omega^2 x_n\), \(x_{n+1} = x_n + h v_{n+1}\) : $$G_{ES} = \begin{pmatrix} 1 - h^2\omega^2 & h \\ -h\omega^2 & 1 \end{pmatrix}, \qquad \det G_{ES} = 1, \qquad \mathrm{tr}\, G_{ES} = 2 - h^2\omega^2.$$ Le schéma est stable si et seulement si \(h\omega \leq 2\). De plus \(\det G_{ES} = 1\) (conservation des aires dans le plan de phase) : sous cette condition l'énergie oscille autour de sa valeur initiale au lieu de dériver.
\(\lambda_+ \lambda_- = \det = 1\) et \(\lambda_+ + \lambda_- = \mathrm{tr} = 2 - h^2\omega^2\). Posons \(c = 1 - \tfrac{h^2\omega^2}{2} = \tfrac{\mathrm{tr}}{2}\). Si \(|c| \leq 1\) (i.e. \(h\omega \leq 2\)), les racines de \(\lambda^2 - 2c\lambda + 1\) sont \(\lambda_\pm = c \pm i\sqrt{1 - c^2}\), de module \(\sqrt{c^2 + 1 - c^2} = 1\) : borné. Si \(h\omega > 2\), alors \(c < -1\), les racines sont réelles, \(\lambda_\pm = c \pm \sqrt{c^2 - 1}\), et \(\max|\lambda_\pm| = |c| + \sqrt{c^2 - 1} > 1\) avec changement de signe (divergence en zigzag). La conservation des aires est le déterminant : c'est la trace d'une propriété géométrique (symplecticité) que EE et EI n'ont pas. ∎

Systèmes raides : pourquoi les vêtements sont « instables » Un réseau masse-ressort de tissu contient des ressorts de flexion très raides : ses pulsations propres vont de \(\omega_{\min}\) à \(\omega_{\max} \gg \omega_{\min}\). La contrainte \(h \leq 2/\omega_{\max}\) impose alors un pas minuscule dicté par les modes les plus rapides alors que le mouvement visible est lent : c'est la raideur. Deux issues : l'implicite (résoudre un système à chaque pas, chapitre 4) ou abandonner les forces pour des contraintes en position (PBD, chapitre 6). Le lien avec les schémas symplectiques et les méthodes variationnelles est un thème de recherche de l'équipe pédagogique (chapitre 11).
