6. Collisions et contraintes

Définition 6.1 — Détection : phases large et fine Phase large (broad phase) : éliminer les paires éloignées via volumes englobants alignés sur les axes (AABB, coût \(O(1)\) par paire, accélération par balayage — sweep and prune — ou grilles spatiales) ; typiquement \(O(n \log n)\) pour n particules. Phase fine (narrow phase) : test exact du couple (sphère-sphère : distance ; sphère-plan : distance signée ; boîte-boîte : separating axis test ; convexes quelconques : GJK, qui maximise la distance par simplex sur la différence de Minkowski). En animation par la physique, on détecte aussi entre les pas (collision continue : segment balayé contre triangles, ou conservative advancement) pour éviter les traversées de parois aux grandes vitesses.
Théorème 6.2 — Réponse impulsionnelle : formule et cohérence Deux corps \(a, b\) de masses \(m_a, m_b\) entrent en contact au point de normale unitaire \(\mathbf{n}\) (de \(a\) vers \(b\)), vitesse relative \(\mathbf{v}_{rel} = \mathbf{v}_b - \mathbf{v}_a\), coefficient de restitution \(e \in [0, 1]\). L'impulsion scalaire qui résout le contact est $$j = -\,\frac{(1 + e)\,(\mathbf{v}_{rel} \cdot \mathbf{n})}{\dfrac{1}{m_a} + \dfrac{1}{m_b}}, \qquad \mathbf{v}_a^+ = \mathbf{v}_a - \frac{j}{m_a}\mathbf{n}, \quad \mathbf{v}_b^+ = \mathbf{v}_b + \frac{j}{m_b}\mathbf{n}.$$ Elle conserve la quantité de mouvement et réalise exactement la loi de restitution \((\mathbf{v}_{rel}^+ \cdot \mathbf{n}) = -e\,(\mathbf{v}_{rel} \cdot \mathbf{n})\).
Écrivons \(\Delta\mathbf{v}_a = -\tfrac{j}{m_a}\mathbf{n}\), \(\Delta\mathbf{v}_b = +\tfrac{j}{m_b}\mathbf{n}\) : la quantité de mouvement totale varie de \(m_a \Delta\mathbf{v}_a + m_b \Delta\mathbf{v}_b = -j\mathbf{n} + j\mathbf{n} = 0\). La vitesse relative normale évolue de \(\mathbf{v}_{rel}^+ \cdot \mathbf{n} = \mathbf{v}_{rel}\cdot\mathbf{n} + j\big(\tfrac{1}{m_a} + \tfrac{1}{m_b}\big)\). Imposer la loi de restitution, \(\mathbf{v}_{rel}^+\cdot\mathbf{n} = -e\,\mathbf{v}_{rel}\cdot\mathbf{n}\), donne \((1 + e)\,\mathbf{v}_{rel}\cdot\mathbf{n} + j\big(\tfrac{1}{m_a} + \tfrac{1}{m_b}\big) = 0\), c'est-à-dire la formule annoncée. ∎
Exemple 6.3 — Bilboquet de billard Boule \(a\) (\(m_a = 2\) kg, \(v_a = 3\) m/s) sur boule \(b\) (\(m_b = 1\) kg, au repos), choc frontal, \(e = 0{,}5\), \(\mathbf{n}\) porté par la vitesse : \(\mathbf{v}_{rel}\cdot\mathbf{n} = -3\), \(j = \tfrac{1{,}5 \times 3}{0{,}5 + 1} = 3\) N·s. D'où \(v_a^+ = 3 - \tfrac{3}{2} = 1{,}5\) m/s, \(v_b^+ = 0 + 3 = 3\) m/s. Vérifications : restitution \((3 - 1{,}5)/3 = 0{,}5\) ✓ ; quantité de mouvement \(2 \times 1{,}5 + 1 \times 3 = 6 = 2 \times 3\) ✓. Énergie : de 9 à \(6{,}75\) J (2,25 J dissipés en déformation et son), conforme à \(e < 1\).
Définition 6.4 — Trois traitements des contraintes
  • Pénalité : ressort de raideur \(k\) sur l'interpénétration \(\delta\) : simple mais raide (contrainte \(h \leq 2/\sqrt{k/m}\), cf. ch. 4) ; compliant contacts : choisir \(k = m/(h^2)\) exactement pour la rigidité du schéma ;
  • Impulsion / projection : résoudre les contacts en vitesses par complémentarité linéaire (LCP) : \(\delta \geq 0\) (pas d'interpénétration), \(j \geq 0\), \(\delta \cdot j = 0\) : résoluble par itérations de Gauss-Seidel projeté — approche des moteurs jeux ;
  • Position Based Dynamics (PBD) : déplacer directement les positions pour satisfaire chaque contrainte (distance, volume, pli), puis déduire les vitesses \(\mathbf{v} = (\mathbf{x}^+ - \mathbf{x}^-)/h\). Stable, rapide, contrôlable par l'artiste (raideur en paramètre ad hoc) : XPBD rétablit une rigidité physiquement calibrée via un compliant solveur.
Friction, un mot honnête La friction de Coulomb (\(\|\mathbf{f}_t\| \leq \mu\,j\)) transforme le LCP en problème de complémentarité non linéaire, sans solution unique garantie : les moteurs trichent par projection tangentielle itérative. Conséquence pratique : un tas de sable PBD « trop raide » glisse ; ajuster \(\mu\) et le nombre d'itérations relève du réglage artistique autant que de la physique.
