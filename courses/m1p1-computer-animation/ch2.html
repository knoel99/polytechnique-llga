2. Intégration numérique des EDO

Définition 2.1 — Un pas d'intégration Un intégrateur (ou schéma) construit une suite \(\mathbf{y}_{n} \approx \mathbf{y}(t_n)\), \(t_n = n h\), par une application \(\mathbf{y}_{n+1} = \Phi_h(\mathbf{y}_n)\). Les trois schémas de référence du module, pour \(\dot{\mathbf{y}} = f(\mathbf{y})\) : $$\text{Euler explicite}\ (EE)\ : \quad \mathbf{y}_{n+1} = \mathbf{y}_n + h f(\mathbf{y}_n)$$ $$\text{Euler symplectique}\ (ES)\ : \quad \begin{cases} \mathbf{v}_{n+1} = \mathbf{v}_n + h\, \mathbf{a}(\mathbf{x}_n, \mathbf{v}_n)\\ \mathbf{x}_{n+1} = \mathbf{x}_n + h\, \mathbf{v}_{n+1} \end{cases}$$ $$\text{Euler implicite}\ (EI)\ : \quad \mathbf{y}_{n+1} = \mathbf{y}_n + h f(\mathbf{y}_{n+1}) \ \ \text{(à résoudre, p.ex. par Newton)}$$ Pour la seconde loi de Newton \(\dot{\mathbf{x}} = \mathbf{v},\ \dot{\mathbf{v}} = \mathbf{a}(\mathbf{x})\), ES met à jour la vitesse d'abord, puis la position avec la nouvelle vitesse — une seule ligne de code de différence avec EE, et un comportement qualitativement différent (chapitre 3).
Définition 2.2 — Erreur locale et ordre L'erreur locale d'un schéma est \(e(h) = \|\Phi_h(\mathbf{y}(t_n)) - \mathbf{y}(t_n + h)\|\) (une seule étape depuis la solution exacte). Le schéma est d'ordre \(p\) si \(e(h) = O(h^{p+1})\) ; l'erreur globale accumulée sur un intervalle de temps fixé est alors \(O(h^p)\).
Théorème 2.3 — Euler explicite est d'ordre 1 Si \(f\) est \(C^2\), l'erreur locale d'Euler explicite vaut \(\mathbf{y}(t_n + h) - \Phi_h(\mathbf{y}(t_n)) = \tfrac{h^2}{2}\ddot{\mathbf{y}}(t_n) + O(h^3)\) : le schéma est d'ordre 1 (erreur globale en \(O(h)\)).
Taylor : \(\mathbf{y}(t_n + h) = \mathbf{y}(t_n) + h\dot{\mathbf{y}}(t_n) + \tfrac{h^2}{2}\ddot{\mathbf{y}}(t_n) + O(h^3)\). Or \(\dot{\mathbf{y}}(t_n) = f(\mathbf{y}(t_n))\) et \(\Phi_h(\mathbf{y}(t_n)) = \mathbf{y}(t_n) + h f(\mathbf{y}(t_n))\) : la différence est exactement le terme \(\tfrac{h^2}{2}\ddot{\mathbf{y}} + O(h^3)\). ∎
Exemple 2.4 — Chute avec frottement : EE contre exacte \(\dot{v} = g - \tfrac{c}{m} v\) avec \(g = 9{,}8\), \(c/m = 2\) (vitesse limite \(v_\infty = 4{,}9\) m/s), \(v_0 = 0\). Solution exacte : \(v(t) = v_\infty (1 - e^{-2t})\). Avec EE, \(v_{n+1} = v_n(1 - 2h) + 9{,}8h\) :

L'erreur décroît quand on approche l'équilibre (le système est dissipatif) ; mais si \(h > 2/(c/m) = 1\) s, le facteur \(1 - 2h < -1\) et la suite oscille en divergeant — prélude du chapitre 3. Noter que RK4 (ordre 4, quatre évaluations de \(f\) par pas) divise l'erreur par \(\sim 10^3\) à \(h\) égal sur cet exemple lisse, sans changer la condition de stabilité de façon décisive.
Quel schéma pour quelle animation ? En production : Euler symplectique pour les particules et vêtements (gratuit, stable, légèrement amortissant), Euler implicite (ou semi-implicite par Newton, quelques itérations) pour les systèmes raides — cheveux, tissus fins, fluides —, Verlet « leapfrog » (ordre 2, symplectique) en jeux vidéo, RK4 rarement, car cher et non symplectique. L'ordre n'est pas le premier critère en animation ; la stabilité et la conservation qualitative (énergie bornée) le devancent — c'est l'objet du chapitre suivant.
