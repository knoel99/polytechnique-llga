4. Particules, forces, ressorts-masses

Définition 4.1 — Système de particules Un système de \(n\) particules est l'état \((\mathbf{x}_i, \mathbf{v}_i)_{i=1}^n \in \mathbb{R}^{6n}\) muni d'un champ de forces \(\mathbf{F}_i(\mathbf{x}, \mathbf{v})\). La dynamique \(\dot{\mathbf{x}}_i = \mathbf{v}_i,\ m_i \dot{\mathbf{v}}_i = \mathbf{F}_i\) est intégrée par l'un des schémas du chapitre 2. Forces usuelles : gravité \(m_i \mathbf{g}\) ; traînée linéaire \(-c_d \mathbf{v}_i\) ou quadratique \(-c_q \|\mathbf{v}_i\| \mathbf{v}_i\) ; ressort \(\mathbf{F}_{i\leftarrow j} = k(\|\ell\| - r_{ij})\,\hat{\ell}\) avec \(\ell = \mathbf{x}_j - \mathbf{x}_i\), longueur au repos \(r_{ij}\) ; amortisseur axial \(-c\,(\mathbf{v}_j - \mathbf{v}_i)\cdot \hat{\ell}\,\hat{\ell}\). C'est le modèle de base des effets « magiques » (feu, fumée, poussière) et le précurseur de la SPH du chapitre 11.
Proposition 4.2 — Modes propres d'un réseau masse-ressort En petits déplacements autour du repos, un réseau avec masses \(M\) (diagonale) et matrice de rigidité \(K\) (symétrique, définie positive si le réseau est ancré) se linéarise en \(M\ddot{\mathbf{u}} = -K\mathbf{u}\). Les pulsations propres sont $$\omega_k^2 = \lambda_k(M^{-1}K), \qquad k = 1, \dots, 3n,$$ et la condition de stabilité d'Euler symplectique (théorème 3.5) devient \(h \leq 2/\omega_{\max} = 2/\sqrt{\lambda_{\max}(M^{-1}K)}\).
Exemple 4.3 — Choisir le pas d'un vêtement Tissu discret en \(20 \times 20\) points, maille \(d = 1\) cm, ressorts structuraux \(k_s = 50\) N/m, masse par point \(m = 2\) g. Le mode le plus rapide couple deux points voisins : \(\omega \approx \sqrt{2k_s/m} = \sqrt{2 \cdot 50 / 0{,}002} \approx 224\) rad/s, d'où \(h \leq 2/\omega \approx 9\) ms (≈ 110 Hz). Avec des ressorts de flexion « 2-hop » cinq fois plus raides, \(\omega\) est multiplié par \(\sqrt{5}\) et le pas autorisé divisé d'autant — d'où l'intérêt de l'implicite. Retenir l'ordre de grandeur : simulation de vêtement temps réel : \(h \sim 2\)–5 ms, implicite ; particules d'effets : \(h \sim 16\)–33 ms, symplectique.
Définition 4.4 — Implicite : le système à résoudre Le pas implicite (ou semi-implicite) linéarisé s'écrit $$\Big(\,I - h\,J\,\Big)\,\Delta\mathbf{v} = h\,\big(\mathbf{F}(\mathbf{x}_n) + h\,J\,\mathbf{v}_n\big), \qquad J = \frac{\partial \mathbf{F}}{\partial \mathbf{x}} \ \ \text{(jacobienne des forces,}\ \sphericalangle\ \text{système défini négatif)},$$ puis \(\mathbf{v}_{n+1} = \mathbf{v}_n + \Delta\mathbf{v}\), \(\mathbf{x}_{n+1} = \mathbf{x}_n + h\,\mathbf{v}_{n+1}\). En pratique on résout par gradient conjugué sans assembler \(J\) explicitement (produits matrice-vecteur par passage sur les ressorts) — le même tour d'écriture que le gradient de rétro-propagation, cf. module Machine Learning, chapitre rétro-propagation.
Au-delà des ressorts : sphères et densité Les systèmes de particules interactionnels (fluides SPH, sable MPM) remplacent les liens fixes par des interactions à portée : chaque particule porte une densité \(\rho_i = \sum_j m_j W(\|\mathbf{x}_j - \mathbf{x}_i\|)\) (noyau \(W\)), et les forces dérivent d'un potentiel d'énergie de compression. La surface libre est l'isosurface \(\rho = \rho_0\) — c'est le paradigme des smoothed particles de Desbrun & Cani (1996), chapitre 11 : fusion, éclaboussures et séparation d'objets émergent sans aucune topologie imposée. 
import numpy as np

# ------------- Simulateur de particules : Euler symplectique -------------
# n particules, gravite, chaine de ressorts, sol imprenetrable (restitution 0.8)
def simulate(n=40, steps=1200, h=1/240, seed=0):
    rng = np.random.default_rng(seed)
    x = rng.uniform(-1, 1, (n, 3)); x[:, 2] += 1.5   # positions initiales
    v = np.zeros((n, 3))
    m = np.full(n, 0.05)                             # 50 g par particule
    g = np.array([0, 0, -9.81]); mu = 0.7            # gravite, drag lineaire
    # ressorts (i, j, raideur k, amortissement c, longueur au repos r)
    edges = [(i, i + 1, 80.0, 0.4, 0.15) for i in range(n - 1)]
    for _ in range(steps):
        F = m[:, None] * g[None, :]                  # gravite
        for (i, j, k, c, r) in edges:                # ressort + amortisseur
            d = x[j] - x[i]; L = np.linalg.norm(d); u = d / L
            Fij = (k * (L - r) + c * np.dot(v[j] - v[i], u)) * u
            F[i] += Fij; F[j] -= Fij
        v += h * F / m[:, None]     # (1) vitesse d'abord   -- Euler symplectique
        v *= (1 - mu * h)           # drag lineaire global
        x += h * v                  # (2) position ensuite
        hit = x[:, 2] < 0           # sol z = 0 : projection + rebond
        x[hit, 2] = 0
        v[hit, 2] = -0.8 * v[hit, 2]
        yield x.copy(), v.copy()

# energie mecanique : doit rester bornee (cf. theoreme 3.5)
for k, (x, v) in enumerate(simulate()):
    if k % 240 == 0:
        E = 0.5 * 0.05 * (v ** 2).sum() + 0.05 * 9.81 * x[:, 2].sum()
        print(f"t = {k/240:5.2f} s   E = {E:7.3f} J")
Lecture du code Deux détails comptent plus que tout le reste : (i) l'ordre des lignes « vitesse puis position » — permuter ces deux lignes redonne Euler explicite et fait exploser la chaîne (essayer avec \(k = 500\)) ; (ii) la gestion du sol par projection (position corrigée, vitesse réfléchie) préfigure les contraintes du chapitre 6 : aucun ressort de contact, donc aucune raideur ajoutée. La boucle d'énergie doit osciller bornée — le diagnostic le plus utile d'un moteur physique.
