4. Échantillonnage : le théorème de Shannon

Théorème 4.1 — Shannon-Nyquist (démontré) Soit \(x\) à bande limitée : \(\hat x(\nu) = 0\) pour \(|\nu| \geq B\), et \(f_s = 1/T_e > 2B\). Alors les échantillons \(x_n = x(nT_e)\) suffisent à reconstruire exactement \(x\) : $$x(t) = \sum_{n \in \mathbb{Z}} x_n\, \mathrm{sinc}\Big(\frac{t}{T_e} - n\Big), \qquad \mathrm{sinc}(u) = \frac{\sin(\pi u)}{\pi u}.$$
Étape 1 (échantillonner = périodiser le spectre). L'échantillonnage idéal s'écrit \(x_s(t) = x(t)\cdot\Sha_{T_e}(t) = \sum_n x_n\,\delta(t - nT_e)\). Produit en temps ⇒ convolution en fréquence (prop. 3.2) : $$\hat x_s(\nu) = \hat x * \widehat{\Sha_{T_e}}(\nu) = \frac{1}{T_e}\sum_{k \in \mathbb{Z}} \hat x\Big(\nu - \frac{k}{T_e}\Big).$$ Le spectre de \(x_s\) est la périodisation du spectre de \(x\), de période \(f_s\). Étape 2 (pas de chevauchement). Si \(f_s > 2B\), les copies (centrées en \(0, \pm f_s, \pm 2f_s, \dots\), chacune de demi-largeur \(B\)) sont disjointes : dans la bande centrale \(|\nu| < f_s/2\) on lit \(\hat x = T_e\,\hat x_s\). Étape 3 (filtrage passe-bas idéal). Multiplions par \(R(\nu) = T_e\,\mathbf{1}_{|\nu| < f_s/2}\) : \(\hat x = R\,\hat x_s\), c'est-à-dire \(x = r * x_s\) où \(r = \check R\) est la transformée inverse du rectangle — calculée par intégration directe : \(r(t) = T_e\int_{-f_s/2}^{f_s/2} e^{i2\pi\nu t}d\nu = \frac{\sin(\pi f_s t)}{\pi f_s t}\cdot f_s T_e = \mathrm{sinc}(f_s t)\). Étape 4 (formule d'interpolation). Convoluer sinc avec le peigne d'échantillons donne, puisque \(\mathrm{sinc}\big(f_s(t - nT_e)\big) = \mathrm{sinc}(f_st - n)\) et que la sinc vaut 1 en 0 et 0 sur les autres entiers (les échantillons ne se « parlent » pas) : $$x(t) = \sum_n x_n\, \mathrm{sinc}(f_s t - n).\qquad\qquad \square$$ Si \(f_s \leq 2B\), les copies se chevauchent : l'information est perdue sans retour (deux signaux différents ont les mêmes échantillons).∎
Proposition 4.2 — Le repliement, en formules Après échantillonnage à \(f_s\), toute fréquence \(\nu\) est vue à la fréquence apparente $$\nu_{\text{app}} = \min_{k \in \mathbb{Z}}\ \big|\nu - k f_s\big| \ \in\ \Big[0, \frac{f_s}{2}\Big],$$ l'image de \(\nu\) dans la bande fondamentale \([-f_s/2, f_s/2]\) modulo \(f_s\). Exemple : \(f_s = 80\) Hz, \(\nu = 60\) Hz ⇒ \(\nu_{\text{app}} = |60 - 80| = 20\) Hz (la raie « recule ») ; un chirp montant dépasse \(f_s/2\), puis redescend — la trace fantôme du spectrogramme de l'exercice 6. Roues qui semblent tourner à l'envers au cinéma, moiré des images : même phénomène.
Échantillonnage en bande passante (bandpass sampling) Pour un signal ne modulant qu'une bande étroite \([f_c - B, f_c + B]\) (radio, capteurs), la condition utile porte sur la largeur \(2B\) et non sur la plus haute fréquence : il suffit de choisir \(f_s\) tel que les copies de la bande ne se chevauchent pas. Exemple : bande \([19, 21]\) MHz (\(f_c = 20\), \(B = 1\)), \(f_s = 4\) MHz : chaque fréquence \(f\) se replie en \(|f - 20|\) MHz, sans collision — le spectre est transposé en bande de base, éventuellement retourné (renversement spectral selon la parité du multiple de \(f_s\)). C'est la base des récepteurs logiciels (SDR).
Exemple 4.3 — Chaîne d'acquisition et reconstruction pratique Chaîne : signal analogique → filtre anti-repliement analogique (coupe à \(f_s/2\), indispensable avant l'échantillonnage) → échantillonnage \(f_s\) → quantification (\(b\) bits : bruit de quantification à \(\approx 6b\) dB de dynamique) → numérique. CD audio : \(B = 20\) kHz ⇒ \(f_s = 44{,}1\) kHz, 16 bits. La sinc de Shannon est parfaitement localisée en fréquence mais infiniment longue en temps : on la tronque et la fenêtre (sinc × Hann sur \(M\) points) — d'où un léger repliement et une transition douce, chiffrables avec les outils du ch. 5 ; l'interpolation linéaire (triangle) est sa version bon marché. 
import numpy as np
fs = 200                       # frequence d'echantillonnage
t  = np.arange(0, 1, 1/fs)
f0 = 60                        # signal 60 Hz
x  = np.sin(2*np.pi*f0*t)

X = np.fft.rfft(x)             # spectre (frequences positives)
freqs = np.fft.rfftfreq(len(x), 1/fs)
peak = freqs[np.argmax(np.abs(X))]
print("frequence dominante :", peak, "Hz")

# Aliasing : echantillonner a 80 Hz un signal de 60 Hz le "voit" a 20 Hz
fs2 = 80; t2 = np.arange(0, 1, 1/fs2)
x2 = np.sin(2*np.pi*f0*t2)
print("vu a :", np.fft.rfftfreq(len(x2),1/fs2)[np.argmax(np.abs(np.fft.rfft(x2)))], "Hz")

# Reconstruction de Shannon sur une grille fine (sinc tronquee aux 21 voisins)
tr = np.arange(0, 1, 1/2000); xr = np.zeros_like(tr)
for n in range(len(x)):
    xr += x[n]*np.sinc(fs*tr - n)
print("erreur max apres reconstruction :", np.abs(np.sin(2*np.pi*f0*tr) - xr).max())
