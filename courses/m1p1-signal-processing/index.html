0. Review: Fourier series in the L² sense, Fubini

L3 background used

  • The Hilbert space L^2: hermitian inner product \langle f, g\rangle = \int f(t)\,\overline{g(t)}\,dt, Cauchy-Schwarz inequality, orthogonal projection onto a finite-dimensional subspace — Fourier = a change of basis in an infinite orthonormal basis;
  • Fubini’s theorem: if \iint \|f(x,y)\|\,dx\,dy < \infty (or for positive functions), the order of integration is free — it justifies all the convolution computations of chapter 3;
  • Integration by parts and changes of variable;
  • Complex geometric sequences, which give the orthogonality of the exponentials.

Proposition 0.1 — The exponentials form an orthogonal system On [0, T_0], set e_k(t) = e^{ik\omega_0 t} with \omega_0 = 2\pi/T_0. Then \langle e_k, e_\ell\rangle = \int_0^{T_0} e^{i(k-\ell)\omega_0 t}\,dt = \begin{cases} T_0 & \text{if } k = \ell,\\[2pt] \dfrac{e^{i(k-\ell)\omega_0 T_0} - 1}{i(k-\ell)\omega_0} = 0 & \text{if } k \neq \ell,\end{cases} since e^{i(k-\ell)\omega_0 T_0} = e^{2i\pi(k-\ell)} = 1. The e_k / \sqrt{T_0} therefore form an orthonormal system of L^2([0,T_0]).

Definition 0.2 — The Dirichlet and Fejér kernels The partial sum of order N of a Fourier series can be written as a convolution with the Dirichlet kernel D_N(\theta) = \sum_{k=-N}^{N} e^{ik\theta} = \frac{\sin\big((N+\tfrac12)\theta\big)}{\sin(\theta/2)}, while the Cesàro mean of the partial sums (arithmetic mean S_0, \dots, S_{N-1}) is written with the Fejér kernel F_N = \frac{1}{N}\sum_{n<N} D_n, which has the decisive property of being positive (F_N \geq 0) and of mass 1.

Theorem 0.3 — Fejér convergence, density, completeness

  • Fejér: for f continuous and T_0-periodic, \sigma_N f = f \* F_N \to f uniformly. The proof uses F_N \geq 0, \int F_N = 1 and the concentration of the mass of F_N near 0.
  • Consequence (density): the trigonometric polynomials \sum_{\|k\| \leq N} c_k e^{ik\omega_0 t} are dense in L^2([0,T_0]).
  • Consequence (Hilbert basis): the orthonormal system \{e_k/\sqrt{T_0}\} is complete: it is a Hilbert basis of L^2. The whole theory of Fourier series “in the L^2 sense” follows from it.

Dirichlet versus Fejér — the message to remember The partial sums themselves (Dirichlet kernel, which changes sign) do not converge uniformly for every continuous function: they “oscillate” near discontinuities (Gibbs phenomenon, quantified in ch. 2). The Cesàro average smooths these oscillations. Moral: in L^2, everything converges nicely; uniformly, one must regularize (averaging, windows) — exactly the role of the Hann windows of ch. 5.

1. Signals and linear systems

Concrete scene: a fine-tuned speech model that drops because Mel was poorly parameterized upstream. This chapter fixes signal and LTI.

What breaks Undersampling below Nyquist; too short a window (resolution); treating filtering as an ML black box.

Definition 1.1 — Signal, LTI system A signal is a function x : \mathbb{R} \to \mathbb{R} (or \mathbb{C}), or a sequence x : \mathbb{Z} \to \mathbb{R} (discrete signal). A system transforms one signal into another; it is LTI (linear time-invariant) if x \mapsto y = T(x) satisfies: linearity, and x(\cdot - \tau) \mapsto y(\cdot - \tau) for every delay \tau. We write \delta_\tau for the Dirac mass at \tau (discrete: \delta_{n} = the sequence equal to 1 at n, 0 elsewhere).

Proposition 1.2 — Convolution representation (proved) Every LTI system (discrete, and continuous subject to a continuity condition) is entirely described by its impulse response h = T(\delta_0): y(t) = (x \* h)(t) = \int_{\mathbb{R}} x(\tau)\, h(t - \tau)\, d\tau \qquad \Big(\text{discrete: } y[n] = \sum_k x[k]\,h[n-k]\Big).

Proof. Discrete version (the continuous argument replaces the sums by integrals against Dirac masses, x = \int x(\tau)\,\delta_\tau\,d\tau, which requires a minimum of distribution theory — admitted here). In discrete time, x = \sum_k x[k]\,\delta_k (a sum of “column” sequences). By linearity, T(x) = \sum_k x[k]\,T(\delta_k). By invariance, T(\delta_k) = \tau_k h, where (\tau_k h)[n] = h[n-k]. Hence y[n] = \sum_k x[k]\,h[n-k]. Commutativity follows from the change of variable \tau' = t - \tau (Fubini: the integral is absolutely convergent under the stability assumptions below).∎

Theorem 1.3 — BIBO stability and causality (proved) The LTI system with impulse response h is:

  • BIBO stable (bounded input ⇒ bounded output) if and only if \sum_n \|h[n]\| < \infty (continuous: \int \|h\| < \infty);
  • causal (the output at time t depends only on the past) if and only if h[n] = 0 for n < 0.

Proof. Stability. (⇐) If \|x\|_\infty \leq M then \|y[n]\| \leq \sum_k \|x[k]\|\,\|h[n-k]\| \leq M \sum_k \|h[k]\|: the convolution series converges absolutely. (⇒) Suppose \sum \|h[n]\| = \infty and take the bounded input x[k] = \mathrm{sign}(h[-k]) (\|x\| \leq 1). Then y[0] = \sum_k x[k]\,h[-k] = \sum_k \|h[k]\| = \infty: the output explodes. Causality. (⇒) If h[n_0] \neq 0 for some n_0 < 0, the response to \delta_0 (a causal input, zero for t < 0) would be nonzero at n_0 < 0, before the impulse: contradiction. (⇐) If h[n] = 0 for n < 0, the sum y[n] = \sum_{k \leq n} x[k]\,h[n-k] involves only x[0], \dots, x[n].∎

Proposition 1.4 — Frequency response: the exponentials are eigenvectors (proved) For a stable LTI system, the input x(t) = e^{i2\pi\nu t} (a pure frequency) produces y(t) = H(\nu)\,e^{i2\pi\nu t} with H(\nu) = \hat h(\nu) = \int h(\tau)\, e^{-i2\pi\nu\tau}\,d\tau. H is the frequency response: the system merely multiplies each frequency by a complex number (gain \|H(\nu)\|, phase \arg H(\nu)).

Proof. y(t) = \int h(\tau)\,x(t-\tau)\,d\tau = \int h(\tau)\,e^{i2\pi\nu(t-\tau)}\,d\tau = e^{i2\pi\nu t} \int h(\tau)\,e^{-i2\pi\nu\tau}\,d\tau. The exponential comes out unchanged up to a complex factor: it is an eigenvector, with eigenvalue H(\nu). This computational triviality is the heart of the whole course: filtering = multiplying the spectrum.∎

Example 1.5 — Elementary convolutions Moving average (h = \frac1M \mathbf{1}_{[0,M]}): smooths, frequency response in \mathrm{sinc}; discrete differentiation (h = \delta_{1} - \delta_0): H(\nu) = e^{-i2\pi\nu} - 1, amplifies the high frequencies; integrator (h = \mathbf{1}_{t \geq 0}): unstable in the BIBO sense (\int\|h\| = \infty). A filter = a choice of h (or of H); the whole of chapter 5 consists in designing h from a desired H.

2. The Fourier series

Theorem 2.1 — Fourier series decomposition (coefficients by projection) Let f be T_0-periodic, square integrable over one period. Then f = \sum_{k \in \mathbb{Z}} c_k\, e^{ik\omega_0 t} \quad \text{in } L^2, \qquad c_k = \frac{1}{T_0}\int_0^{T_0} f(t)\, e^{-ik\omega_0 t}\, dt, the convergence taking place in L^2 norm (and pointwise toward \frac{f(x^+)+f(x^-)}{2} at discontinuity points if f is piecewise C^1: Dirichlet’s theorem). The c_k form the spectrum: \|c_k\| magnitude, \arg c_k phase.

Proof. The e_k = e^{ik\omega_0t} are orthogonal (prop. 0.1) and form a Hilbert basis (completeness, th. 0.3). The decomposition in an infinite orthonormal basis follows the logic of finite dimension: the partial sum S_N f = \sum_{\|k\|\leq N} c_k e_k is the orthogonal projection of f onto \mathrm{Vect}\{e_k\}_{\|k\|\leq N}, since \langle f - S_Nf, e_j\rangle = 0 for \|j\| \leq N. Since the basis is complete, \|f - S_N f\|_{L^2} \to 0. Explicitly: for every trigonometric polynomial p = \sum_{\|k\|\leq N} d_k e_k, Pythagoras gives \|f - p\|^2 = \|f - S_Nf\|^2 + \|S_Nf - p\|^2 \geq \|f - S_Nf\|^2: the projection is the best approximation — and the d_k that cancel the cross terms are exactly d_k = \langle f, e_k\rangle / \|e_k\|^2 = c_k.∎

Theorem 2.2 — Parseval’s identity (proved by density) \frac{1}{T_0}\int_0^{T_0} \|f(t)\|^2\,dt = \sum_{k \in \mathbb{Z}} \|c_k\|^2.

Proof. Pythagoras on f = S_N f + (f - S_N f) with \langle S_Nf, f - S_Nf\rangle = 0: \|f\|^2 = \|S_Nf\|^2 + \|f - S_Nf\|^2. Now \|S_Nf\|^2 = \sum_{\|k\|\leq N}\|c_k\|^2\|e_k\|^2 = T_0 \sum_{\|k\|\leq N}\|c_k\|^2, and \|f - S_Nf\|^2 \to 0 by theorem 2.1 (whose proof rests on Fejér density, th. 0.3). Dividing by T_0 and passing to the limit, the “time” energy equals the “frequency” energy.∎

Lemma 2.3 — Regularity and decay of the coefficients (by integrations by parts) If f is T_0-periodic, piecewise C^p, with f^{(p)} integrable, then c_k = \frac{1}{(ik\omega_0)^p}\, c_k\big(f^{(p)}\big), \qquad k \neq 0. In particular: a jump discontinuity [f] ⇒ c_k \sim \frac{[f]}{T_0\,ik\omega_0} = \frac{[f]}{2i\pi k} (decay in 1/k); f piecewise C^1 ⇒ c_k = O(1/k^2); f C^p ⇒ c_k = o(1/k^p).

Proof. Integration by parts over one period (f piecewise C^1, the boundary terms cancel by periodicity): c_k(f) = \frac{1}{T_0}\big[ f e^{-ik\omega_0t}\big]_0^{T_0} + \frac{ik\omega_0}{T_0}\int f(t)\,e^{-ik\omega_0t}dt = \frac{1}{ik\omega_0}c_k(f'). One iterates p times. The last term is a Fourier coefficient of an L^2 function (or of a jump if f is discontinuous); Parseval (th. 2.2) applied to f^{(p)} bounds \sum \|c_k(f^{(p)})\|^2, hence c_k = o(k^{-p}) since the series \sum 1/k^{2p} must converge… and a residual jump imposes the exact 1/k.∎

Example 2.4 — The square wave: explicit coefficients and the Gibbs phenomenon For the odd square wave f = \mathrm{sign}(\sin) (value ±1, jump of height 2): the direct computation (exercise 1, with solution) gives c_k = 0 \ (k \text{ even}), \qquad c_k = \frac{-2i}{\pi k} \ (k \text{ odd}) \quad\Longleftrightarrow\quad f(t) = \frac{4}{\pi}\sum_{m \geq 0} \frac{\sin\big((2m+1)\omega_0 t\big)}{2m+1}. Decay in 1/k, consistent with lemma 2.3 (discontinuity). The Gibbs phenomenon: near the jump, the partial sum S_N f overshoots the target by about \Big(\frac{1}{\pi}\int_0^{\pi} \frac{\sin u}{u}\,du\Big) - \frac12 \approx 8.95\,\% of the height of the jump, whatever N: the oscillation concentrates (width in O(1/N)) but its amplitude does not tend to 0. Origin: the Dirichlet kernel changes sign (ch. 0); by averaging (Fejér) or by windowing (ch. 5), the overshoot disappears — at the price of a widened transition.

Why these three results structure the whole course Parseval: the energy can be read in the spectrum (noise, filtering, SNR). Lemma 2.3: a smooth signal has a fast-decaying spectrum — the foundation of compression (one throws away the high frequencies) and of sampling (a fast-decaying spectrum is quickly negligible: ch. 4). Gibbs: any abrupt cutoff in frequency costs oscillations in time — hence the soft windows of ch. 5.

3. The Fourier transform

Definition 3.1 — The Fourier transform For x \in L^1(\mathbb{R}) (then L^2 by density): \hat x(\nu) = \int_{\mathbb{R}} x(t)\, e^{-i 2\pi \nu t}\, dt, \qquad x(t) = \int_{\mathbb{R}} \hat x(\nu)\, e^{i 2\pi \nu t}\, d\nu. \nu in Hz (or \omega in rad/s with a factor 2\pi); the “continuous” transform generalizes the Fourier coefficients to non- periodic signals: a signal of infinite duration has a continuous spectrum.

Proposition 3.3 — The Gaussian is its own transform (computed) \mathcal{F}\big(e^{-\pi t^2}\big)(\nu) = e^{-\pi \nu^2}.

Proof. Set g(t) = e^{-\pi t^2} and consider \hat g. We exploit the differential equation g' = -2\pi t\,g. Integrating by parts, \int t\,g(t)\,e^{-i2\pi\nu t}dt = -\frac{1}{2\pi}\int g'(t)\,e^{-i2\pi\nu t}dt = -\frac{1}{2\pi}\,i2\pi\nu\,\hat g = -i\nu\,\hat g. Hence \hat g'(\nu) = -i2\pi \int t g e^{-i2\pi\nu t} = -i2\pi(-i\nu)\hat g = -2\pi\nu\,\hat g — the same differential equation. Solution: \hat g(\nu) = \hat g(0)\,e^{-\pi\nu^2}, and \hat g(0) = \int g = 1 (Gaussian integral).∎

The key duo: convolution ↔︎ multiplication Filtering = convolving in time = multiplying in frequency: y = x\*h \iff \hat y = \hat x\,H, where H(\nu) = \hat h(\nu) is the frequency response (prop. 1.4). Low-pass: H \approx 1 for \|\nu\| < \nu_c, \approx 0 beyond. This is also why the FFT speeds up the convolutions of CNNs: complexity \mathcal{O}(n \log n) instead of \mathcal{O}(n^2) (see the Deep Learning module). With proposition 3.3, a “narrow” Gaussian in time is “wide” in frequency — a foretaste of the next theorem.

Theorem 3.4 — Heisenberg-Gabor uncertainty (proved) For x of energy 1, with standard deviations \sigma_t (time, around t_0) and \sigma_\nu (frequency): \sigma_t \, \sigma_\nu \ \geq\ \frac{1}{4\pi}, with equality if and only if x is a Gaussian (modulated and translated).

Proof. Time translations and frequency modulations do not change the product \sigma_t\sigma_\nu (delay = pure phase; modulation = a translation of the spectrum): one assumes t_0 = \nu_0 = 0, \|x\|_2 = 1. Let us derive the key identity by parts (vanishing boundary terms): \int t\,\frac{d}{dt}\|x\|^2 dt = -\int \|x\|^2 = -1, and \frac{d}{dt}\|x\|^2 = 2\mathrm{Re}(x\,\overline{x'}), hence 2\,\mathrm{Re}\langle t\,x, x'\rangle = 1, i.e. \|\langle tx, x'\rangle\| \geq 1/2. Cauchy-Schwarz: \tfrac12 \leq \|t x\|_2\,\|x'\|_2 = \sigma_t\,\|x'\|_2. Finally \|x'\|_2^2 = \|\widehat{x'}\|_2^2 = \|i2\pi\nu\,\hat x\|_2^2 = (2\pi\sigma_\nu)^2 (Parseval + differentiation). Hence \sigma_t\sigma_\nu \geq 1/(4\pi). Equality: Cauchy-Schwarz must be saturated, x' = \lambda t x: the solutions are the Gaussians e^{-\pi t^2/\sigma^2} (up to a linear phase and a translation).∎

Definition 3.5 — Useful distributions: Dirac and comb Without formalism: the Dirac mass \delta is “the function” of mass 1 concentrated at 0, defined by \int f\,\delta = f(0) (a distribution, i.e. a continuous linear form on test functions). We admit: \hat\delta = 1, \hat 1 = \delta (duality), and the Dirac comb \,\Sha_{T_e}(t) = \sum_n \delta(t - nT_e), whose transform is a comb: \widehat{\Sha_{T_e}}(\nu) = \frac{1}{T_e}\,\Sha_{1/T_e}(\nu). These objects make rigorous: the spectrum of a sinusoid (two \delta lines), sampling (a product with a comb, ch. 4), white noise (ch. 7).

4. Sampling: the Shannon theorem

Theorem 4.1 — Shannon-Nyquist (proved) Let x be band-limited: \hat x(\nu) = 0 for \|\nu\| \geq B, and f_s = 1/T_e > 2B. Then the samples x_n = x(nT_e) suffice to reconstruct exactly x: x(t) = \sum_{n \in \mathbb{Z}} x_n\, \mathrm{sinc}\Big(\frac{t}{T_e} - n\Big), \qquad \mathrm{sinc}(u) = \frac{\sin(\pi u)}{\pi u}.

Proof. Step 1 (sampling = periodizing the spectrum). Ideal sampling is written x_s(t) = x(t)\cdot\Sha_{T_e}(t) = \sum_n x_n\,\delta(t - nT_e). Product in time ⇒ convolution in frequency (prop. 3.2): \hat x_s(\nu) = \hat x \* \widehat{\Sha_{T_e}}(\nu) = \frac{1}{T_e}\sum_{k \in \mathbb{Z}} \hat x\Big(\nu - \frac{k}{T_e}\Big). The spectrum of x_s is the periodization of the spectrum of x, of period f_s. Step 2 (no overlap). If f_s > 2B, the copies (centered at 0, \pm f_s, \pm 2f_s, \dots, each of half-width B) are disjoint: in the central band \|\nu\| < f_s/2 we read \hat x = T_e\,\hat x_s. Step 3 (ideal low-pass filtering). Let us multiply by R(\nu) = T_e\,\mathbf{1}_{\|\nu\| < f_s/2}: \hat x = R\,\hat x_s, that is, x = r \* x_s where r = \check R is the inverse transform of the rectangle — computed by direct integration: r(t) = T_e\int_{-f_s/2}^{f_s/2} e^{i2\pi\nu t}d\nu = \frac{\sin(\pi f_s t)}{\pi f_s t}\cdot f_s T_e = \mathrm{sinc}(f_s t). Step 4 (interpolation formula). Convolving sinc with the comb of samples gives, since \mathrm{sinc}\big(f_s(t - nT_e)\big) = \mathrm{sinc}(f_st - n) and since the sinc equals 1 at 0 and 0 at the other integers (the samples do not “talk” to each other): x(t) = \sum_n x_n\, \mathrm{sinc}(f_s t - n).\qquad\qquad \square If f_s \leq 2B, the copies overlap: the information is lost without return (two different signals have the same samples).∎

Proposition 4.2 — Aliasing, in formulas After sampling at f_s, every frequency \nu is seen at the apparent frequency \nu_{\text{app}} = \min_{k \in \mathbb{Z}}\ \big\|\nu - k f_s\big\| \ \in\ \Big[0, \frac{f_s}{2}\Big], the image of \nu in the fundamental band [-f_s/2, f_s/2] modulo f_s. Example: f_s = 80 Hz, \nu = 60 Hz ⇒ \nu_{\text{app}} = \|60 - 80\| = 20 Hz (the line “moves backward”); a rising chirp passes f_s/2, then goes back down — the ghost trace of the spectrogram of exercise 6. Wheels that seem to turn backward in the movies, moiré of images: the same phenomenon.

Bandpass sampling For a signal modulating only a narrow band [f_c - B, f_c + B] (radio, sensors), the useful condition bears on the width 2B and not on the highest frequency: it suffices to choose f_s such that the copies of the band do not overlap. Example: band [19, 21] MHz (f_c = 20, B = 1), f_s = 4 MHz: every frequency f folds back to \|f - 20\| MHz, without collision — the spectrum is transposed to baseband, possibly flipped (spectral reversal depending on the parity of the multiple of f_s). This is the basis of software receivers (SDR).

Example 4.3 — Acquisition chain and practical reconstruction Chain: analog signal → analog anti-aliasing filter (cuts at f_s/2, indispensable before sampling) → sampling f_s → quantization (b bits: quantization noise at \approx 6b dB of dynamic range) → digital. Audio CD: B = 20 kHz ⇒ f_s = 44.1 kHz, 16 bits. The Shannon sinc is perfectly localized in frequency but infinitely long in time: one truncates and windows it (sinc × Hann over M points) — hence a slight aliasing and a soft transition, quantifiable with the tools of ch. 5; linear interpolation (triangle) is its cheap version.

5. DFT, FFT and digital filtering

Definition 5.1 — The DFT For x_0, \dots, x_{N-1}: X_k = \sum_{n=0}^{N-1} x_n\, e^{-i 2\pi k n / N}, \qquad k = 0, \dots, N-1. The DFT samples the transform of the implicitly periodized signal (k \leftrightarrow \nu_k = k f_s/N). Two links to know:

  • DFT ↔︎ Fourier series: if x is T_0-periodic sampled with N points per period and f_s > 2B: X_k = N\,c_k (for k < N/2, and X_{N-k} = N c_{-k});
  • DFT ↔︎ Fourier transform: for a segment of duration T = NT_e of an aperiodic signal: \hat x(\nu_k) \approx T_e\,X_k (the so-called “rectangular” approximation, with the spectral leakage of prop. 5.4).

Proposition 5.2 — Circular convolution (proved) Let x \circledast h be the circular convolution (indices modulo N): y_n = \sum_{m=0}^{N-1} x_m\,h_{(n-m) \bmod N}. Then \mathrm{DFT}(x \circledast h)_k = X_k\,H_k.

Proof. Y_k = \sum_n \sum_m x_m h_{(n-m) \bmod N}\,\omega^{kn} with \omega = e^{-2\pi i/N}. For m fixed, n \mapsto p = (n-m) \bmod N is a bijection of \mathbb{Z}/N\mathbb{Z} and \omega^{kn} = \omega^{k(m+p)} (since \omega^{kN} = 1). Hence Y_k = \sum_m x_m\omega^{km}\sum_p h_p\omega^{kp} = X_k H_k. The linear convolution is obtained by zero-padding both signals to N' \geq n + m - 1 points: the “circular” wrap-around then no longer has any effect (the overflowing indices fall on zeros).∎

Theorem 5.3 — Radix-2 FFT (proved: the butterfly recurrence) If N = 2^q, the DFT is computed in T(N) = \mathcal{O}(N \log N) operations.

Proof. Separate the even and odd sums: X_k = \underbrace{\sum_{m=0}^{N/2-1} x_{2m}\,\omega^{2mk}}_{E_k} +\ \omega^{k}\,\underbrace{\sum_{m=0}^{N/2-1} x_{2m+1}\,\omega^{2mk}}_{O_k}. Now \omega^2 = e^{-4\pi i/N} is an N/2-th root of unity: E and O are two DFTs of size N/2, periodic with period N/2; and \omega^{k + N/2} = -\omega^k. Hence the butterfly: X_k = E_k + \omega^k O_k, \qquad X_{k+N/2} = E_k - \omega^k O_k, \qquad k = 0,\dots,\tfrac{N}{2}-1, which produces the N outputs from the N inputs in O(N) multiply-adds once E, O are known. Recurrence T(N) = 2T(N/2) + cN = cN\log_2 N. For N = 2^{20} (one second of audio): \approx 2\times10^7 units versus 10^{12} for the definition — a factor of 50,000.∎

Proposition 5.4 — Windows: quantified lobes Analyzing a segment of signal = multiplying it by a window w ⇒ convolving the spectrum with \hat w (prop. 3.2): a pure line becomes the profile \hat w. Characteristics (window of length M, bin = f_s/M, classical values of Harris 1978):

Window Main lobe 1st side lobe Decay
rectangular ±1 bin −13 dB −6 dB/octave
Hann ±2 bins −31 dB −18 dB/octave
Hamming ±2 bins −41 dB −6 dB/octave
Blackman ±3 bins −58 dB −18 dB/octave

Universal trade-off: a narrow window (low side lobes) ⇒ a wide main lobe (resolution lost). The rectangular one “leaks” at −13 dB: a strong line masks a weak neighboring line at −60 dB; Hann is the default choice.

Digital filters: FIR and IIR FIR (finite impulse response): y_n = \sum_{k=0}^{M} b_k x_{n-k} — always stable (Σ|b| finite: th. 1.3), linear phase if the b_k are symmetric, designed by windowing; IIR (infinite): y_n = \sum b_k x_{n-k} - \sum_{j\geq1} a_j y_{n-j}, transfer function H(z) = B(z)/A(z) — more selective at equal coefficient counts, but stability must be checked.

Theorem 5.5 — Stability of an IIR: the poles (proved) For a rational IIR, BIBO stable ⇔ all the poles of H(z) lie in the open disk \|z\| < 1.

Proof. The impulse response of a system with (simple) poles p_1, \dots, p_r is a combination of \mathcal{O}(n^s)\,p_j^n: each mode contributes \sum_n \|p_j\|^n, a geometric series convergent ⇔ \|p_j\| < 1. A pole on the unit disk ⇒ a marginal or divergent mode; outside ⇒ a divergent exponential (the accumulator h = \mathbf{1}, pole at 1, illustrates this).∎

Example 5.6 — Designing a low-pass FIR by windowing, step by step Objective: H_d(\nu) = \mathbf{1}_{\|\nu\| \leq \nu_c} (ν normalized by f_s).

  1. Ideal response in time: h_d[n] = 2\nu_c\,\mathrm{sinc}(2\nu_c n) (inverse FT of the rectangle, cf. proof of th. 4.1) — infinite and non-causal.
  2. Delay of M/2 for causality (and symmetry ⇒ linear phase).
  3. Windowing: h[n] = h_d[n - M/2]\,w[n - M/2], n = 0,\dots,M.
  4. Analysis: H = H_d \* \hat w; the transition band equals the width of the main lobe of \hat w — rule of thumb M \cdot \Delta\nu \approx 4 (Hann), \approx 6 (Blackman); the in-band ripple equals the level of the side lobes (prop. 5.4).

The effective frequency response is the DTFT of h, H(\nu) = \sum_n h[n]e^{-2\pi i\nu n}, evaluated by zero-padding the FFT (trick: a DFT with N_{\text{fft}} \gg M points interpolates the DTFT). A finer alternative: frequency-domain least squares — minimize \sum_{\omega \in \Omega} \|H_b(\omega) - D(\omega)\|^2 over a frequency grid, a quadratic problem in b, hence a linear system (Parks-McClellan equiripple method: the same spirit in infinite norm). For IIRs, one projects an analog prototype via the bilinear transform s \mapsto \frac{2}{T_e}\frac{1 - z^{-1}}{1 + z^{-1}} (Butterworth, Chebyshev…) while keeping the poles inside the disk — the “smooth” filter of example 5.7.

6. Time-frequency analysis and wavelets

Definition 6.1 — STFT and spectrogram \mathrm{STFT}_x(t, \nu) = \int x(\tau)\, w(\tau - t)\, e^{-i2\pi\nu\tau}\, d\tau, with w a short window (Hann). The spectrogram \|\mathrm{STFT}_x\|^2 describes the energy across time and frequency: it is the image of sound that a convolutional network “sees” (ch. 8).

Proposition 6.2 — Exact resolution of the STFT At each instant, the STFT is the FT of the windowed segment x\cdot w(\cdot - t): its frequency resolution is the width of the main lobe of \hat w (prop. 5.4); its time resolution is the duration T of the window. For Hann: main lobe \pm 2/T in frequency, hence \Delta t = T, \qquad \Delta\nu \approx \frac{2}{T} \ \ (\text{Hann}), \qquad \Delta t\,\Delta\nu \approx 2, to be compared with the floor 1/(4\pi) \approx 0.08 (standard deviations) of th. 3.4: the STFT works at a resolution fixed in advance, far from the floor, but with time-frequency cells all identical. Long window ⇒ good frequency resolution, poor time resolution — and conversely: the trade-off is irreversible for a given window.

Gabor frames: sampling the STFT A continuously stored STFT is redundant; one samples it on a grid (t,\nu) = (m\,a,\ n\,b). Results (admitted): if ab < 1 (a fine enough grid), the family of translated-modulated windows w_{m,n} forms a Gabor frame: stable reconstruction by a dual window; at the critical density ab = 1, no well-localized orthonormal basis exists (the Balian-Low theorem): one must accept redundancy (or change the geometry: wavelets below). This is exactly the structure of spectrograms: frames every 10 ms, N frequencies — a frame, not a basis.

Definition 6.3 — Wavelets: analysis at variable scale Mother wavelet \psi (zero mean, localized); \psi_{a,b}(t) = \frac1{\sqrt a}\psi\big(\frac{t-b}{a}\big); the CWT samples (a,b), often in octaves a = 2^{-j} (scalogram, Q = \Delta\nu/\nu constant): good time localization at high frequency, frequency localization at low frequency — suited to sounds (closely spaced harmonics at the bottom of the spectrum, brief transients at the top), where the STFT is uniform.

Example 6.4 — Haar, a complete example down to reconstruction The Haar wavelet: \varphi = \mathbf{1}_{[0,1)} (scale), \psi = \mathbf{1}_{[0,1/2)} - \mathbf{1}_{[1/2,1)} (detail). Signal x = (9, 7, 3, 5):

  • level 1: averages a_1 = (8, 4), details d_1 = (1, -1);
  • level 2: a_2 = (6), d_2 = (2);
  • coding: x \leftrightarrow (a_2, d_2, d_1) = (6, 2, 1, -1); reconstruction: 9 = 6+2+1, 7 = 6+2-1, 3 = 6-2+1, 5 = 6-2-1.

The multiresolution equations: \varphi(t) = \sqrt2\sum_k h_k\varphi(2t-k), \psi(t) = \sqrt2\sum_k g_k\varphi(2t-k); for Haar, h = (\tfrac{1}{\sqrt2}, \tfrac{1}{\sqrt2}), g = (\tfrac{1}{\sqrt2}, -\tfrac{1}{\sqrt2}) — h = averaging filter (low-pass), g = differentiator (high-pass). The Daubechies D_N compactify this scheme with 2N coefficients and N vanishing moments: on a piecewise regular signal, the detail coefficients decay like 2^{-Nj} — this is what makes the coding sparse (a polynomial of degree < N has exactly zero details: Haar = D_1 annihilates constants).

DWT = a filter bank, and the JPEG 2000 link The DWT is implemented without any integral: a cascade of low-pass (h) / high-pass (g) filterings followed by decimation by a factor 2, iterated on the low branch; the “quadrature mirror” conditions on (h,g) cancel the aliasing introduced by the decimations. JPEG 2000 codes the subbands of a biorthogonal DWT (5/3 lossless, 9/7 lossy): an image = a 2D signal, and compression exploits lemma 2.3 (regularity ⇒ small coefficients). Same bank, from denoising to compression: the theory does not change.

7. Random signals and spectral estimation

Definition 7.1 — Process, wide-sense stationarity (WSS) A random signal is a family X(t, \omega) of random variables. It is wide-sense stationary if its mean is constant m = \mathbb{E}[X(t)] and if its autocorrelation R_X(t, t+\tau) = \mathbb{E}\big[(X(t)-m)\,\overline{(X(t+\tau)-m)}\big] depends only on the lag \tau (written R_X(\tau)). This is the right framework for noise, speech, sensors: each realization is a signal of this course, but the interesting quantities are expectations.

Proposition 7.2 — Properties of the autocorrelation R_X(0) = \mathbb{E}\|X - m\|^2 is the average power; \|R_X(\tau)\| \leq R_X(0) (Cauchy-Schwarz: \|\mathbb{E}[X_0\overline{X_\tau}]\| \leq \sqrt{R(0)R(0)}); R_X is hermitian (R_X(-\tau) = \overline{R_X(\tau)}) and positive definite. “Noise” is decorrelated at a distance: R(\tau) \to 0.

Theorem 7.3 — Wiener-Khinchin (statement) and the spectral density For a WSS process, there exists a positive measure S_X, the power spectral density, such that R_X(\tau) = \int e^{i2\pi\nu\tau}\, dS_X(\nu), \qquad\text{and if } R_X \in L^1:\quad S_X(\nu) = \widehat{R_X}(\nu). The power is distributed across the spectrum: \mathbb{E}\|X-m\|^2 = R_X(0) = \int dS_X: Parseval (th. 2.2) becomes a definition. (The proof — Bochner’s theorem — goes beyond the scope of the course; the intuition: a WSS process is an incoherent superposition of sinusoids, each carrying its share of the power.)

  • White noise: decorrelated to all orders, R = \sigma^2\delta ⇒ S = \sigma^2 constant — “all frequencies on equal footing”. A band-limited white noise (physically realizable): S = \sigma^2\mathbf{1}_{\|\nu\| \leq B} ⇒ R(\tau) = 2B\sigma^2\,\mathrm{sinc}(2B\tau): decorrelation at the scale 1/B (direct computation of the FT of the rectangle, cf. th. 4.1).
  • Filtered noise: Y = h \* X ⇒ S_Y = \|H\|^2\,S_X (colored noise): the filter shapes the spectrum squared.
  • AR(1) (auto-regressive model X_n = \rho X_{n-1} + W_n, \|\rho\| < 1): R[\tau] = \frac{\sigma_W^2}{1-\rho^2}\,\rho^{\|\tau\|} and S(\nu) = \frac{\sigma_W^2}{\|1 - \rho e^{-i2\pi\nu}\|^2} — the simplest model of colored noise, ubiquitous in finance and sensors.

Definition 7.4 — The periodogram “Natural” estimator of S_X from N samples: \hat S_N(\nu) = \frac{1}{N}\Big\|\sum_{n<N} X_n\, e^{-i2\pi\nu n}\Big\|^2 \qquad (\text{on the DFT grid: } \|X_k\|^2/N).

Theorem 7.5 — Bias and variance of the periodogram

  • Bias (leakage): \mathbb{E}[\hat S_N] = S \* W_N where W_N is the Dirichlet kernel (prop. 0.2): the expectation “smears” over ±1 bin — a strong line masks a weak line (hence the windows, prop. 5.4). The bias tends to 0 as N \to \infty (W_N \to \delta).
  • Variance: for a Gaussian process, \mathrm{Var}[\hat S_N(\nu)] \approx S_X(\nu)^2 for every N — the relative error is 100% and does not decrease: the periodogram alone is a poor estimator, whatever the observation duration.

Proof. Sketch. Bias: \hat S_N = \widehat{z_N}\,\overline{\widehat{z_N}} with z_N = X\cdot w_N (truncation = rectangular window); the product in time becomes a convolution of the spectrum with \hat w_N = W_N (prop. 3.2), then one takes the expectation. Variance: on the DFT grid, the \hat S_N(\nu_k) are asymptotically decorrelated and, for a Gaussian, \hat S_N(\nu) approximately follows S(\nu)\cdot \chi^2_2/2 (squared modulus of two independent Gaussians); now \mathrm{Var}[\chi^2_2/2] = 1, hence a variance of order S^2, independent of N.∎

Bartlett and Welch methods — reducing the variance by averaging

  • Bartlett: split the N points into L disjoint segments of M = N/L points and average the periodograms: \mathrm{Var} \approx S^2/L… at the price of an increased bias (windows M times shorter ⇒ leakage multiplied) — the central bias/variance trade-off of spectral estimation.
  • Welch: overlapping segments (50%) and Hann windows: the same variance gain (Hann segments overlap “for free”), leakage controlled at −31 dB; this is the default method of instrumentation.
from scipy.signal import welch
n  = 20000; fs = 500.0
t  = np.arange(n)/fs
x  = np.sin(2*np.pi*50*t) + 0.02*np.sin(2*np.pi*80*t) + 0.5*rng.standard_normal(n)

f, S = welch(x, fs=fs, nperseg=1024, window='hann', noverlap=512)
# L = 2*20000/1024 - 1 segments: the line at 80 Hz (-34 dB below the line at 50 Hz)

Complement to the official syllabus: Wiener filtering The detailed syllabus of the course unit explicitly mentions “filtering and prediction of stationary random signals” and “Wiener filtering”: here is the object. We observe Y = X + W (signal X WSS, noise W WSS, with spectra S_X, S_W, assumed uncorrelated) and we seek the LTI filter h that minimizes the mean squared error \mathbb{E}\|X - h \* Y\|^2. The (non-causal) solution is the Wiener filter: H(\nu) = \frac{S_X(\nu)}{S_X(\nu) + S_W(\nu)}. Reading: at frequencies where the signal dominates (S_X \gg S_W) the filter transmits (H \approx 1); where the noise dominates, it cancels out — the spectrum decides, optimally in the L^2 sense. This is exactly the “filtered noise” of Theorem 7.3 (S_Y = \|H\|^2 S_X) inverted: instead of computing the effect of a filter on a spectrum, we design the filter that best separates signal and noise, from their estimated spectral densities (Definition 7.4 and Theorem 7.5 — estimated in practice by Bartlett/Welch). The causal filter is built by spectral factorization (via the transfer function H(z) of ch. 5); the linear prediction of an AR process (the X_n = \rho X_{n-1} + W_n of Theorem 7.3) is its “zero noise” case: predicting is filtering toward the future. The Kalman filter is its recursive state-space variant, seen in the downstream modules of the program.

8. The signal for modern ML

Mel spectrogram and MFCC: the standard pipeline

  1. Frames: 25 ms cuts every 10 ms, Hann window (a Gabor frame, ch. 6); STFT.
  2. Mel scale (perceptive, linear < 1 kHz then logarithmic): m = 2595\,\log_{10}\Big(1 + \frac{f}{700}\Big), \qquad f = 700\,\big(10^{m/2595} - 1\big).
  3. Mel filter bank: 20-80 triangular filters with edges uniformly spaced in Mel — band-pass filters of increasing width in Hz: E_m = \sum_\nu W_m(\nu)\,\|\mathrm{STFT}(\nu)\|^2 (a sparse weighting of the spectrogram).
  4. Log (amplitude perception); DCT along the Mel axis (a DCT = a “real FT”): the c_j are the MFCC; one keeps 13-20 coefficients + derivatives \Delta, \Delta\Delta, and normalizes in mean/variance per speaker.

Historically features for lightweight models (GMM-HMM), the MFCC remain the compact entry point; deep networks rather consume the raw Mel spectrogram.

Networks on spectrograms The Mel spectrogram is the image that 2D CNNs and audio transformers consume: the first layers of audio CNNs learn oriented frequency detectors — Gabor filters (ch. 6), see the Deep Learning module. The emblematic data augmentation (masking of frequency bands and time frames) operates directly in the time-frequency plane: the spectrogram is treated as a texture to be repaired. Speech technology, transcription, audio-multimodal transformers: this whole pipeline is the signal preprocessing of modern ML.

Distances between spectral distributions: FID and OT spectral loss Comparing two sets of signals = comparing two distributions of spectrograms (or of features). Standard: fit a Gaussian to the features of each set and measure the Fréchet distance d^2\big(\mathcal{N}(\mu_1,\Sigma_1), \mathcal{N}(\mu_2,\Sigma_2)\big) = \|\mu_1 - \mu_2\|^2 + \mathrm{tr}\Big(\Sigma_1 + \Sigma_2 - 2\big(\Sigma_1^{1/2}\Sigma_2\Sigma_1^{1/2}\big)^{1/2}\Big). This is nothing but W_2^2 between Gaussians (the Bures metric): the FID of image generators and the “audio Fréchet distance” of audio generators are Wasserstein distances in disguise. The OT spectral loss of audio generative models generalizes the idea: comparing real/generated batches by Gaussian W_2 (closed form above, differentiable) or by Sinkhorn on the spectra: the complete proof of the Bures formula and the Sinkhorn algorithm are on the syllabus of the Computational Optimal Transport module (M1P2, ch. 2 and 3, same instructor) — this chapter is its preparation. In 1D (spectra or one-dimensional signals), everything reduces to the quantile coupling: W_2^2 = \int_0^1\big(F_1^{-1}(u) - F_2^{-1}(u)\big)^2du (proved there).

Example 8.1 — 1D domain adaptation on signals Two sensors measure the same phenomenon with different drifts (offset, gain, frequency response): the distributions of the frames differ, not the semantics. Alignment by 1D OT: transport the quantiles of sensor A onto those of sensor B (monotone transport, computable by sorting); the same principle at d-dimensional scale (feature clouds) is the optimal transport domain adaptation detailed in the OT module (ch. 4), whose instructor is a co-author. The signal provides the spectrum; OT provides the geometry.

Fourier in the architectures: convolutions and positions

  • Convolution of CNNs = the discrete convolution of ch. 1: the learned kernel is a filter whose frequency response (DTFT, ch. 5) explains its behavior — CNNs learn banks of Gabor filters; convolution via FFT in \mathcal{O}(n\log n) when the kernels are large (th. 5.3).
  • Convolution on graphs: the GNN message passing h \leftarrow \sigma(\tilde D^{-1/2}\tilde A \tilde D^{-1/2} h W) is a convolution in the spectral sense — the Kipf & Welling filter is a degree-1 polynomial of the Laplacian; expanded in the Graph ML module.
  • Positional encodings: the sine/cosine of transformers (\mathrm{PE}(p, 2i) = \sin(p/10000^{2i/d})…) = Fourier bases; positional encodings on graphs (LapEig) reuse the eigenvectors of the Laplacian — Fourier again, see the Graph ML module.

Complement to the official syllabus: source separation and the learning dictionary The “Signal representation and learning dictionary” block of the detailed syllabus of the course unit names source separation and the learning dictionary: here is the principle. The idea — officially that of the course — is to move from fixed bases (Fourier, wavelets, ch. 2 and 6) to a learned dictionary: a signal is represented as x \approx D\alpha with D = [d_1 \| \dots \| d_K] a dictionary of waveforms and \alpha sparse (few active coefficients). Learning D (for instance by non-negative matrix factorization — NMF — or K-SVD-type sparse least squares) on spectrograms of mixtures separates the sources: each component d_k\alpha_k concentrates on one source (a speaker, an instrument), since a mixture is a sum of sources and sparsity forces the atoms to specialize. This is the first historical bridge between signal processing and unsupervised learning: a learned dictionary is a latent representation, \alpha a code — the same grammar as the autoencoders of the Deep Learning module, with the added spectral interpretability of the atoms. The “deep learning” signal reconstruction announced by the sheet is the generalization of this scheme in which the decoder becomes a network trained on degraded/clean pairs (denoising, super-resolution).

Bridging lab: optimal transport between two segments of a spectrogram

import numpy as np, ot
import scipy.signal as sig

fs = 8000; t = np.arange(2*fs)/fs
x  = np.sin(2*np.pi*440*t) + 0.5*rng.random(2*fs)      # two "notes" with noise
f, T, S = sig.stft(x, fs=fs, nperseg=512, window='hann')

A = np.abs(S[:, T[0] < 0.5]).ravel()                   # spectra t < 0.5 s
B = np.abs(S[:, T[0] >= 0.5]).ravel()                  # spectra t >= 0.5 s
a, b = np.ones(len(A))/len(A), np.ones(len(B))/len(B)
Ca = A[:, None]*A[:, None] + 1e-9                      # cost: "close" spectra
G  = ot.sinkhorn(a, b, ot.dist(A[:,None], B[:,None]), reg=0.05)
# Matplotlib visualization described: ot.plot.plot1D_mat(A, B, G, "transport plan")
# -- the mass connects the spectra of the same contour; compare with simple correlation

One “transports” the distribution of the spectra of one half toward the other: this is exactly the basic building block of the spectral losses of generative audio ML (ch. 8), and the first lab of the M1P2 module.

A recent bridge: projections, sliced OT and reconstruction Part of the instructor’s recent work deals with sliced transport (random 1D projections): Tanguy, Flamary & Delon, “Reconstructing discrete measures from projections” (C. R. Mathématique, 2024 — arXiv:2304.12029) show how the projections of a discrete measure determine it, with consequences for the empirical sliced Wasserstein distance. The vocabulary is that of the course: projecting a cloud (a measure of spectrograms) onto directions means computing marginal spectra; 1D OT by quantiles (ch. 8) does the rest. Flamary’s other works (FGW, domain adaptation, COOT) are detailed in the Computational Optimal Transport module (M1P2, ch. 7).

Exercises

  1. Square wave series (with solution). Compute the c_k of the odd square wave f = \mathrm{sign}(\sin), check the decay in 1/k and illustrate the Gibbs phenomenon (partial sums at 5, 21, 101 harmonics). Solution. f odd and real ⇒ c_k purely imaginary. For k \neq 0 even, the integral of \sin(k\omega_0 t) over the two half-periods cancels. For k odd: c_k = \frac{1}{T_0}\int_0^{T_0}f e^{-ik\omega_0t}dt = \frac{-2i}{T_0}\int_0^{T_0/2}\sin(k\omega_0 t)dt = \frac{-2i}{T_0}\cdot\frac{2\,(1-(-1)^k)}{2k\omega_0} = \frac{-2i}{\pi k}, that is \|c_k\| = 2/(\pi\|k\|) — consistent with lemma 2.3: the period carries two jumps (of +2 at 0, of -2 at T_0/2), whose contributions \frac{2}{2\pi i k} and \frac{-2\,(-1)^k}{2\pi i k} add up to \frac{2(1-(-1)^k)}{2\pi i k} = \frac{-2i}{\pi k} for k odd and 0 for k even. Recombining: f(t) = \frac{4}{\pi}\sum_{m\geq0}\frac{\sin((2m+1)\omega_0t)}{2m+1}.
  2. Numerical Parseval. Check Parseval’s identity on a sampled periodic signal (compare \sum\|x_n\|^2/N and \sum\|X_k\|^2/N^2), then explain why the DFT preserves the energy up to a factor N (a Vandermonde matrix, unitary up to a factor).
  3. Quantitative Gibbs (with solution). Show that for the square wave of exercise 1, the maximum of the partial sum S_N converges to 1 + \frac{2}{\pi}\int_0^\pi \frac{\sin u}{u}du - 1 \approx 1.0895, i.e. an overshoot of about 9% of the jump. Solution (sketch). Near the jump at 0, S_N f(t) = \frac{2}{\pi}\int_0^{\omega_0 N t}\frac{\sin u}{u}\,du\cdot\frac{\pi}{2} (substitution in the Dirichlet kernel D_N, prop. 0.2: the partial sum is written S_Nf(t) = \frac{2}{\pi}\int_0^{N\omega_0t}\mathrm{sinc} — oscillations concentrated on a width O(1/N)). The maximum of the sinc integral is reached at the first zero of the numerator, u = \pi, and equals \mathrm{Si}(\pi) \approx 1.852 versus \mathrm{Si}(\infty) = \pi/2. The relative overshoot is \frac{\mathrm{Si}(\pi) - \pi/2}{\pi/2} \approx 17.9\,\% of the half-jump, i.e. \approx 8.95\,\% of the full jump — independent of N; only the width \sim 1/N shrinks.
  4. Gaussian (with solution). Re-prove prop. 3.3 by completing the square: show that \int e^{-\pi(t + i\nu)^2}dt = \int e^{-\pi t^2}dt = 1 (move the contour, or differentiate \int e^{-\pi(t+i\nu)^2}dt with respect to \nu and conclude), and deduce the two half-widths (standard deviations) \sigma_t, \sigma_\nu and their product. Solution (key). -\pi t^2 - 2\pi i\nu t = -\pi(t+i\nu)^2 - \pi\nu^2 ⇒ \hat g = e^{-\pi\nu^2}\cdot\int e^{-\pi u^2}du with u = t + i\nu on the horizontal segment — the integral does not depend on \nu (holomorphy + decay at the ends). For g = e^{-\pi t^2}: \sigma_t^2 = 1/(2\pi), \sigma_\nu^2 = 1/(2\pi), product = 1/(4\pi): the Gaussian saturates Heisenberg-Gabor (th. 3.4).
  5. Heisenberg (with solution). Check that equality \sigma_t\sigma_\nu = 1/(4\pi) requires x' = \lambda t x in the proof of th. 3.4, solve this differential equation and conclude that only the Gaussians (translated, modulated, dilated) saturate the inequality. Solution (key). Solve x'(t) = \lambda t\,x(t): x(t) = C e^{\lambda t^2/2} with \lambda < 0 for integrability; x \in L^2 ⇔ \lambda = -2\pi/\sigma^2… then a translation in time (center t_0) and a modulation (center \nu_0), which do not change the standard deviations.
  6. Aliasing. Generate a chirp f(t) = 100 + 400t Hz sampled at f_s = 500 Hz; compute the spectrogram and interpret the “ghost” trace that goes back down; what apparent frequency does f = 350 Hz correspond to? (prop. 4.2: \|350 - 500\| = 150 Hz, and the trace rises up to 250 Hz before going back down.)
  7. Homemade FFT. Implement the butterfly recursion of th. 5.3 (even/odd recursive function), validate it against np.fft.fft, and plot the execution time as a function of q = \log_2 N for N = 2^q, q = 4,\dots,18; check the \log·N slope.
  8. Convolution via FFT. Implement the linear convolution via zero-padding + FFT (prop. 5.2), measure the times against np.convolve for n = m = 2^{14}, and explain the crossing of the complexities.
  9. Hann filter. Low-pass FIR design by windowing (example 5.6): ideal response H(\nu) = \mathbf{1}_{\|\nu\| \leq \nu_c}, multiplication by a Hann window, inverse transform. Plot the frequency response for M = 31 and comment on the transition/aliasing trade-off; compare with Blackman at the same M.
  10. Line detection (with solution). A signal contains x(t) = \sin(2\pi\cdot50t) + A\sin(2\pi\cdot80t) + white noise, with A = 0.01 (a line at −40 dB). Show that the raw periodogram does not detect the line at 80 Hz (th. 7.5), then make it emerge with Welch (Hann, segments of 1024). Solution (key). Periodogram: leakage of the rectangular window at −13 dB (prop. 5.4) + 100% variance ⇒ the line at −40 dB is drowned. Welch: Hann window (first lobe −31 dB, decay −18 dB/octave) ⇒ the leakage of the 50 Hz line falls below −60 dB; L \approx 2N/1024 segments ⇒ the standard deviation of the estimator divided by \sqrt{L}: the line at 80 Hz exceeds the detection threshold. Code: scipy.signal.welch as in ch. 7.
  11. Mel bank (with solution). Implement a bank of 26 triangular Mel filters between 0 and f_s/2 (formulas of ch. 8), apply it to a spectrogram, then the DCT; check that a vowel and a fricative have very different MFCCs. Solution (key). Uniform edges in Mel m_i = i\,2595\log_{10}(1+f_{max}/700)/26, converted to Hz by the inverse formula, triangles of normalized area (the highest ones are wider in Hz); energies E_m = \sum_\nu W_m(\nu)\|S(\nu)\|^2, log, DCT-II: the vowels (formants, low-Mel energy) concentrate on the first MFCCs, the fricatives (high frequencies) on the following ones.
  12. Project — denoising and spectral loss. Denoise a recording (white noise added): spectrogram → time-frequency masking (attenuate the cells below an energy threshold) → reconstruction by ISTFT; SNR before/after, musical artifacts. Then compare the distributions of original/denoised spectrograms by Gaussian W_2 (formula of ch. 8, POT: ot.gaussian.wass2) — direct preparation of the M1P2 module.
