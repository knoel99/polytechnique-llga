9. Les travaux de l'enseignant : du signal au transport optimal

Qui enseigne ce module, et pourquoi ce n'est pas un hasard Rémi Flamary (CMAP, École Polytechnique) est co-directeur du master LLGA et co-créateur de la bibliothèque POT — Python Optimal Transport (JMLR 2021) : l'un des outils les plus utilisés du domaine. Sa recherche relie précisément les deux bouts de ce cours : des signaux et images (télécommunications, imagerie cérébrale) aux distances entre distributions de données — c'est-à-dire des spectrogrammes de ce module aux pertes OT du module M1P2.
POT : une bibliothèque pensée pour la pratique des TP Architecture (séance de présentation) :
  • Solveurs exacts : ot.emd (simplexe de réseau, LP exact) ; régularisés : ot.sinkhorn et sa version stabilisée en log ; structurés : ot.gromov (GW, FGW) ; barycentres ; domain adaptation : ot.da.OTDA — le classifieur transporté du papier TPAMI 2016, empaqueté.
  • Rétro-propagation native : les backends NumPy/PyTorch/JAX — une perte OT (spectral loss incluse) s'insère dans n'importe quelle boucle d'entraînement ; le gradient du coût régularisé est le potentiel dual (démontré au module OT, ch. 3).
  • Impact : ~80 solveurs issus de la littérature, galerie d'exemples, utilisée du médical à l'audio génératif : le « standard de fait » de l'OT numérique.
TP de liaison : transport optimal entre deux segments de spectrogramme 
import numpy as np, ot
import scipy.signal as sig

fs = 8000; t = np.arange(2*fs)/fs
x  = np.sin(2*np.pi*440*t) + 0.5*rng.random(2*fs)      # deux "notes" bruitees
f, T, S = sig.stft(x, fs=fs, nperseg=512, window='hann')

A = np.abs(S[:, T[0] < 0.5]).ravel()                   # spectres t < 0.5 s
B = np.abs(S[:, T[0] >= 0.5]).ravel()                  # spectres t >= 0.5 s
a, b = np.ones(len(A))/len(A), np.ones(len(B))/len(B)
Ca = A[:, None]*A[:, None] + 1e-9                      # cout : spectres "proches"
G  = ot.sinkhorn(a, b, ot.dist(A[:,None], B[:,None]), reg=0.05)
# Visualisation matplotlib decrite : ot.plot.plot1D_mat(A, B, G, "plan de transport")
# -- la masse relie les spectres de meme contour ; comparer a la correlation simple
On « transporte » la distribution des spectres d'une moitié vers l'autre : c'est exactement la brique de base des pertes spectrales du ML génératif audio (ch. 8), et le premier TP du module M1P2.
Un pont récent : projections, sliced OT et reconstruction Une partie des travaux récents de l'enseignant porte sur le transport sliced (projections 1D aléatoires) : Tanguy, Flamary & Delon, « Reconstructing discrete measures from projections » (C. R. Mathématique, 2024 — arXiv:2304.12029) montrent comment les projections d'une mesure discrète la déterminent, avec des conséquences sur la distance de Wasserstein sliced empirique. Le vocabulaire est celui du cours : projeter un nuage (une mesure de spectrogrammes) sur des directions, c'est calculer des spectres marginaux ; l'OT 1D par quantiles (ch. 8) fait le reste. Les autres travaux de Flamary (FGW, adaptation de domaine, COOT) sont détaillés dans le module Computational Optimal Transport (M1P2, ch. 7).
