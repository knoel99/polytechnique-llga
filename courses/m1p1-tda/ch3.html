3. Homologie simpliciale

Programme : transformer la géométrie en algèbre. À chaque dimension \(k\), on fabrique un espace vectoriel de \(k\)-chaînes (combinaisons formelles de \(k\)-simplexes) ; l'opérateur de bord \(\partial_k\) vérifie \(\partial_{k-1} \circ \partial_k = 0\) (proposition 1.3). L'homologie mesure le défaut d'exactitude : des cycles qui ne sont pas des bords.

Définition 3.1 — Chaînes, cycles, bords, homologie Soit \(K\) un complexe fini, \(\mathbb{F}\) un corps (\(\mathbb{F}_2\) sauf mention contraire). Pour \(k \geq 0\), le groupe des \(k\)-chaînes est \(C_k(K) = \mathbb{F}^{f_k(K)}\), engendré par les \(k\)-simplexes. L'application bord \(\partial_k : C_k \to C_{k-1}\) est l'application linéaire qui à un simplexe associe la somme de ses faces (signée sur \(\mathbb{Z}\), brute sur \(\mathbb{F}_2\)). On pose : $$Z_k = \ker \partial_k \;(\text{cycles}), \qquad B_k = \mathrm{im}\, \partial_{k+1} \;(\text{bords}), \qquad H_k(K) = Z_k / B_k.$$ L'inclusion \(B_k \subseteq Z_k\) découle de \(\partial_k \circ \partial_{k+1} = 0\). La dimension \(\beta_k = \dim H_k\) est le \(k\)-ième nombre de Betti. Deux cycles sont homologues si leur différence est un bord.
Lire les nombres de Betti \(\beta_0\) = nombre de composantes connexes (combien de morceaux) ; \(\beta_1\) = nombre de boucles indépendantes (combien de trous « unidimensionnels » : anneau, handle de tore, hiérarchie de communautés cycliques) ; \(\beta_2\) = nombre de cavités (l'intérieur d'une sphère creuse, d'une bulle) ; au-delà, \(\beta_k\) compte les \(k\)-trous. Sur \(\mathbb{F}_2\), « cycle » veut dire : chaque sommet (resp. arête…) est couvert un nombre pair de fois — une union de polygones fermés, sans orientation.
Exemple 3.2 — Calcul complet n°1 : le triangle creux puis plein Triangle creux \(S\) (sommets \(a, b, c\), arêtes \(ab, bc, ca\), aucune face). \(C_0 = \mathbb{F}_2^3\), \(C_1 = \mathbb{F}_2^3\), \(C_2 = 0\). En base des sommets : \(\partial_1(ab) = a + b\), \(\partial_1(bc) = b + c\), \(\partial_1(ca) = c + a\). La matrice de \(\partial_1\) (colonnes = arêtes, lignes = sommets) est $$\partial_1 = \begin{pmatrix} 1 & 0 & 1 \\ 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}, \qquad \mathrm{rg}(\partial_1) = 2.$$ En effet \(\mathrm{col}_1 + \mathrm{col}_2 + \mathrm{col}_3 = (0, 0, 0)^\top\) (chaque sommet apparaît deux fois) et deux colonnes quelconques sont indépendantes. D'où : $$\dim Z_1 = 3 - 2 = 1, \quad B_1 = 0 \Rightarrow H_1 \cong \mathbb{F}_2, \qquad \dim H_0 = 3 - 2 = 1.$$ Lecture : une composante, une boucle — le cercle. Le cycle générateur est \(\gamma = ab + bc + ca\).

Triangle plein \(D\) (on ajoute la face \(abc\)). \(C_2 = \mathbb{F}_2\) et \(\partial_2(abc) = ab + bc + ca = \gamma\) : le rang de \(\partial_2\) vaut 1, donc \(B_1 = \langle \gamma \rangle\) et $$H_1(D) = Z_1 / B_1 = \langle \gamma \rangle / \langle \gamma \rangle = 0, \qquad H_0(D) \cong \mathbb{F}_2.$$ Lecture : le disque n'a pas de trou — la boucle qui le borde est devenue un… bord. Toute la topologie du passage « creux → plein » tient dans le rang d'une matrice \(1 \times 3\).
Exemple 3.3 — Calcul complet n°2 : la sphère creuse (bord du tétraèdre) \(K_{\mathbb{S}^2}\) : 4 sommets, 6 arêtes, 4 faces, aucun 3-simplexe. Étape par étape sur \(\mathbb{F}_2\) :
  1. \(\partial_1 : C_1 = \mathbb{F}_2^6 \to C_0 = \mathbb{F}_2^4\). Le graphe complet \(K_4\) est connexe : \(\mathrm{rg}\, \partial_1 = 3\), donc \(\dim Z_1 = 6 - 3 = 3\) et \(H_0 \cong \mathbb{F}_2\) (une seule composante).
  2. \(\partial_2 : C_2 = \mathbb{F}_2^4 \to C_1 = \mathbb{F}_2^6\). Cycles de dimension 2. Cherchons les familles de faces dont chaque arête est couverte un nombre pair de fois. Chaque arête du tétraèdre appartient à exactement 2 faces. Une face isolée laisse ses 3 arêtes impaires : interdit. Deux faces partagent une arête (paire) mais leurs 4 autres arêtes restent impaires : interdit. Trois faces : l'arête portée par les deux faces parmi les trois qui la contiennent… reste impaire : interdit. Les 4 faces ensemble : chaque arête couverte deux fois — permis. Donc \(Z_2 = \{\emptyset, \Sigma\}\) où \(\Sigma\) est la somme des 4 faces : \(\dim Z_2 = 1\).
  3. \(B_2 = \mathrm{im}\, \partial_3 = 0\) (pas de 3-simplexe), donc \(H_2 \cong \mathbb{F}_2\) — la cavité.
  4. \(\mathrm{rg}\, \partial_2 = \dim C_2 - \dim Z_2 = 4 - 1 = 3\), donc \(B_1\) est de dimension 3 et \(H_1 = Z_1/B_1\) est de dimension \(3 - 3 = 0\) : pas de boucle — sur une sphère, tout lacet se resserre en un point.
Bilan : \(\beta_0 = 1\), \(\beta_1 = 0\), \(\beta_2 = 1\) ; contrôle par la caractéristique : \(\chi = 4 - 6 + 4 = 2 = \beta_0 - \beta_1 + \beta_2\). Le même calcul sur le tore « minimal » de Császár (7 sommets, 21 arêtes, 14 faces) donnerait \((1, 2, 1)\).
Proposition 3.4 — Formule des trous pour les graphes Pour un graphe \(G\) à \(n\) sommets, \(m\) arêtes et \(c\) composantes connexes, considéré comme 1-complexe : \(\beta_0 = c\), \(\beta_1 = m - n + c\) (la nullité ou rang cyclomatique — cf. module Graph ML, ch. 0).
\(\beta_0 = c\) : deux sommets sont homologues (\(a + b = \partial(ab)\)) dans la même composante, et jamais entre composantes. Pour \(\beta_1\) : \(Z_1 = \ker \partial_1\) et \(\mathrm{rg}\, \partial_1 = n - c\) (une relation par arbre couvrant de chaque composante — chaque composante connexe contribue exactement à \(-1\) au rang via son arbre couvrant), d'où \(\beta_1 = m - (n - c) - 0\), car \(B_1 = 0\) pour un 1-complexe. ∎
Théorème 3.7 (Euler–Poincaré) — La caractéristique est topologique Pour tout complexe fini \(K\) : $$\chi(K) \;=\; \sum_{k} (-1)^k \beta_k.$$ En particulier \(\chi\) ne dépend que du type d'homotopie de \(|K|\) — Euler avait \(\chi(\text{polyèdre}) = s - a + f\) pour la sphère, Poincaré a montré que la somme alternée des Betti y suffit toujours.
Pour chaque \(k\), le théorème du rang appliqué à \(\partial_k : C_k \to C_{k-1}\) donne \(f_k = \dim C_k = \mathrm{rg}\, \partial_k + \dim \ker \partial_k = \mathrm{rg}\, \partial_k + \dim Z_k\). Or \(\dim Z_k = \dim B_k + \beta_k\) et \(\mathrm{rg}\, \partial_k = \dim B_{k-1}\) ; donc \(f_k = \dim B_{k-1} + \dim B_k + \beta_k\). En sommant avec les signes \((-1)^k\), les termes \(\dim B_k\) apparaissent deux fois, aux signes opposés, et se compensent (télescopage) ; il reste \(\sum_k (-1)^k \beta_k\). ∎

Coefficients entiers et torsion Calculer sur \(\mathbb{Z}\) (signes actifs) restitue de l'information que \(\mathbb{F}_2\) masque : la torsion, p.ex. \(H_1(\mathbb{RP}^2) \cong \mathbb{Z}/2\mathbb{Z}\) alors que \(\beta_1 = 0\) sur \(\mathbb{F}_2\). Le prix : remplacer l'élimination gaussienne par la forme normale de Smith. En pratique, la TDA appliquée travaille presque toujours sur un corps ; on retiendra que les Betti sur \(\mathbb{F}_2\) minorent l'information homologique entière.
