10. Mise en œuvre : GUDHI, scikit-tda, ripser

Trois outils couvrent le workflow : GUDHI (complexes), ripser (Rips rapide) et scikit-tda (persim : distances, visualisations). Le TME : faire parler les formes canoniques — cercle, deux cercles, sphère, tore, bruit — puis mesurer la stabilité.

# TME 1 -- Rips persistence avec GUDHI : le cercle bruite
import numpy as np, gudhi
from gudhi import RipsComplex

t = np.linspace(0, 2*np.pi, 200, endpoint=False)
X = np.stack([np.cos(t), np.sin(t)], 1) + 0.05*np.random.randn(200, 2)

rips = RipsComplex(points=X, max_edge_length=2.0)
st = rips.create_simplex_tree(max_dimension=2)
st.compute_persistence(homology_coeff_field=2, min_persistence=0)

dgm = {k: st.persistence_intervals_in_dimension(k) for k in (0, 1)}
h1 = dgm[1][np.argsort(dgm[1][:, 1] - dgm[1][:, 0])[-1]]   # barre H1 la plus longue
print("trou principal : naissance %.3f, mort %.3f" % tuple(h1))
# attendu : naissance ~1.0 (rayon), mort ~2.0 (diametre) -- cf. exemple 5.2
gudhi.plot_persistence_barcode(st.persistence()); gudhi.plot_persistence_diagram(st.persistence())
# TME 2 -- ripser + persim : bottleneck et stabilite au reechantillonnage
from ripser import ripser
from persim import plot_diagrams, bottleneck

def sample_circle(n, r, sigma):
    t = np.random.rand(n) * 2*np.pi
    return np.stack([r*np.cos(t), r*np.sin(t)], 1) + sigma*np.random.randn(n, 2)

D0 = ripser(sample_circle(200, 1, .05))['dgms']
D1 = ripser(sample_circle(200, 1, .05))['dgms']
print("d_b(H1) =", round(bottleneck(D0[1], D1[1]), 3))   # ~ 0.05-0.1 : ordre du bruit

# faire varier sigma : d_b croit lineairement -- illustration numerique du th. 6.1
for sigma in (.01, .05, .1, .2):
    D = ripser(sample_circle(200, 1, sigma))['dgms']
    print(f"sigma={sigma:4.2f}  d_b={bottleneck(D0[1], D[1]):.3f}")
# TME 3 -- paysages et classification (sklearn) : cercle vs deux cercles
from gudhi.representations import Landscape, DiagramSelector
from sklearn.svm import SVC
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

def diag(n):
    """renvoie le diagramme H1 d'un nuage : 1 ou 2 cercles aleatoires"""
    k = np.random.randint(2) + 1
    pts = [sample_circle(n, r, .05) + np.random.randn(2)*2.5 for r in (.6, 1.3)][:k]
    return ripser(np.concatenate(pts))['dgms'][1]

X = [diag(100) for _ in range(60)]                 # 60 diagrammes H1
y = [1 if sum(p[1] - p[0] > .3 for p in d) > 1 else 0 for d in X]
                                                  # label = 2 cercles ssi 2 barres longues
vec = make_pipeline(DiagramSelector(), Landscape(num_landscapes=3, resolution=100))
model = make_pipeline(vec, SVC(kernel='rbf'))
print(cross_val_score(model, [[d] for d in X], y, cv=5).mean())  # attendu ~ 1.0
Points d'attention
  1. max_edge_length tronque la filtration : les classes non mortes au bout sont essentielles (mort = inf), pas des bugs.
  2. Mémoire : limiter max_dimension à 2 (voire 3 pour H2) ; le nombre de simplexes croît comme \(n^{k+1}\) ; ripser ne matérialise jamais la matrice de bord — c'est sa force (Bauer, 2021).
  3. Choix du corps : homology_coeff_field=2 par défaut ; essayer 3 pour détecter la torsion sur des exemples exotiques.
  4. Cohérence avec le cours : sur l'exemple 4.5, reconstruire la filtration à la main (gudhi.SimplexTree, insertion ordonnée) et vérifier que persistence() retourne exactement les paires (2,5), (3,6), (4,7), (8,9) et les essentielles 1, 10 — l'exercice 4 du TME.
