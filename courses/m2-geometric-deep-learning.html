0. Rappels : surfaces et algèbre spectrale

Rappels L3/M1 mobilisés
  • Calcul différentiel : gradient, divergence, laplacien en \(\mathbb{R}^2\) (\(\Delta f = \partial_{xx} f + \partial_{yy} f\)) ; formule de Green ;
  • Diagonalisation symétrique : \(L = U\Lambda U^\top\), base orthonormée de fonctions propres — déjà vue pour le laplacien de graphe (module Graph ML, ch. 0) ;
  • Convolution & Fourier (module Signal Processing) : le laplacien est l'opérateur de fréquence ; diffusion de la chaleur \(\partial_t u = \Delta u\) ;
  • GNN (module Graph ML) : un maillage est un graphe — mais géométrique (positions 3D, métrique).

1. Géométrie différentielle discrète

Définition 1.1 — Surface triangulée Un maillage \(M = (V, E, F)\) : sommets \(v_i \in \mathbb{R}^3\), arêtes, faces triangulaires. C'est à la fois un graphe et une approximation de surface lisse ; l'aire de Voronoï mixte \(A_i\) associe une « zone » à chaque sommet.
  • Normale d'une face : \(n_f \propto (v_j - v_i) \times (v_k - v_i)\) ; normale de sommet : moyenne pondérée par les aires (ou angle) ;
  • Courbure discrète : l'angle deficit de Gauss $$K_i = \frac{2\pi - \sum_{f \ni i}\theta_{i,f}}{A_i}$$ (plat ⇒ \(K = 0\) ; cône ⇒ positif ; selle ⇒ négatif) ; courbures moyennes \(H\) par le laplacien des positions ;
  • Descente de gradient sur une surface : la paramétrisation (ch. 5) revient à « aplatir » le maillage en préservant les angles/aires (conforme : harmonic/barycentrique) ;
  • Courbure & convolution : les filtres géodésiques (vs euclidiens) respectent la surface — la « convolution » se fait le long de la géométrie, l'analogue exact des convolutions sur graphes (Graph ML ch. 4-5).

2. L'opérateur de Laplace-Beltrami

Définition 2.1 — Laplace-Beltrami Le laplacien sur la surface (généralisation de \(\Delta\) aux variétés) ; en discret, la matrice de cotangentes : $$L_{ij} = \begin{cases} -\frac{1}{2A_i}\sum_{j \sim i}(\cot\alpha_{ij} + \cot\beta_{ij}) & i = j\\[2pt] \frac{1}{2A_i}(\cot\alpha_{ij} + \cot\beta_{ij}) & j \sim i\\ 0 & \text{sinon} \end{cases}$$ où \(\alpha_{ij}, \beta_{ij}\) sont les angles opposés à l'arête \((i,j)\). Comme le laplacien de graphe : symétrique, semi-défini positif, base de Fourier \(\{\phi_k\}\) avec \(\Delta \phi_k = -\lambda_k \phi_k\), \(\lambda_k\) croissantes (= « fréquences » de la surface).
Pourquoi c'est l'outil central
  • Invariance isométrique : le spectre ne change pas si on « plie » la surface sans l'étirer — comparaison de formes non rigides (humain qui bouge) ;
  • Diffusion : la chaleur \(u(t) = e^{-t\Delta}u_0\) — les fonctions propres amortissent \(\phi_k\) d'un facteur \(e^{-t\lambda_k}\) ; « Entendez la forme d'un tambour » : le spectre code la géométrie ;
  • Dimension réduite : projeter sur les \(k\) premières fonctions propres ≈ ACP de la surface (lissage spectral) ; tout le ch. 4 en découle.
import igl                     # libigl : geometrique discrete "de reference"
import numpy as np

v, f = igl.read_triangle_mesh("bunny.obj")
L = -igl.cotangent_laplacian(v, f)          # laplacien de cotangentes
M = igl.massmatrix(v, f, igl.MASSMATRIX_TYPE_VORONOI)
# probleme generalise : L phi = lambda M phi  -> eigendecomposition
evals, evecs = igl.eigs(-L, M, 20)          # 20 premieres fonctions propres
# visualiser evecs[:, k] comme "texture" sur le maillage -> modes de vibration

3. Descripteurs et distances de formes

Définition 3.1 — Heat Kernel Signature (HKS) La quantité de chaleur résiduelle en \(x\) après \(t\) : $$\mathrm{HKS}(x, t) = \sum_k e^{-t\lambda_k}\, \phi_k(x)^2$$ — descripteur intrinsèque : stable, invariant isométrique ; multi-échelle (\(t\) petit = détails locaux, grand = global) ; la Wave Kernel Signature en est la variante quantique. Ces signatures jouent le rôle des « features » pour la correspondance.
  • Distances intrinsèques : géodésique vs euclidienne ; diffusion distance ; leurs approximations spectrales ;
  • ShapeDNA : le spectre lui-même comme descripteur global de forme (une « empreinte ») ;
  • Aplatissement (embedding) : les \(k\) premières fonctions propres donnent un plongement \(\mathbb{R}^k\) qui « déplie » la forme — l'analogue exact du spectral clustering/LapEig des graphes (Advanced GNN, ch. 3) : même algèbre, autre objet.

4. Cartographies fonctionnelles

Théorème/Concept 4.1 — Functional Maps (Ovsjanikov et al., 2012) Au lieu de chercher la correspondance point-à-point (application discrète combinatoire, coûteuse), transporter des fonctions définies sur les surfaces : $$T_F : \mathcal{F}(M) \to \mathcal{F}(N), \qquad T_F(g) = g \circ T^{-1}$$ Restreinte aux bases spectrales \(\Phi_M, \Phi_N\) (les \(k\) premières fonctions propres), la carte devient une petite matrice \(C \in \mathbb{R}^{k \times k}\) : $$b_N \approx C\, b_M \quad (b = \Phi^\top f).$$ Contraintes : préservation des descripteurs (HKS) ; commutation avec le laplacien \(C\Lambda_M \approx \Lambda_N C\) ; orthogonalité (isométrie) ; résolution : moindres carrés de \(k^2\) inconnues — quelques millisecondes.
  • Pipeline : descripteurs → \(C\) → conversion en correspondance point-à-point (produits matriciels + raffinement) ; robuste et extensible ;
  • Généralisations : maps partielles, avec formes de même famille (faces, corps) ; régularisation par l'opérateur (couplage) ; cartes fonctionnelles apprises (SpectralNet → GeomFMaps, Deep Geometric Functional Maps) ;
  • Lien LLGA : une functional map ≈ un transport optimal entre bases réduites ; l'alignement de formes ≈ l'alignement de graphes par Gromov-Wasserstein (module OT, ch. 5) ; les trois langages — GNN, OT, functional maps — décrivent la même opération de correspondance structurelle.

5. Paramétrisation et traitement

  • Paramétrisation : découpe (cut) → aplatir dans \(\mathbb{R}^2\) (tutte/harmonic — conformal ; ARAP : as-rigid-as-possible) ; texture, UV ;
  • Lissage/filtrage : atténuer les hautes fréquences spectrales (denoise), sharpening — le traitement du signal (M1) transporté aux surfaces ;
  • Remaillage, reconstruction : Poisson reconstruction ; simplification (quadric error) ;
  • Déformation : laplacian editing (préserver \(\Delta\) des positions) ; skinning ; morphing — applications graphics/AR du module ViCAI sœurs.

6. Deep learning sur surfaces

Architecture 6.1 — PointNet (Qi et al., 2017) Nuages de points (sans maillage) : par point : MLP partagé ; agrégation globale max (permutation-invariante — la même exigence que les GNN, module Graph ML ch. 2) ; classification/segmentation de nuages. Limite : pas d'interactions locales — d'où PointNet++ (voisinages) ; DGCNN (graphes dynamiques k-NN : EdgeConv).
  • Convolutions géodésiques/spectrales : patches géodésiques (Geodesic CNN, Boscaini et al.), filtres spectraux sur \(\Delta\) — exactement les filtres de ChebNet sur le laplacien géométrique ;
  • DiffusionNet (Sharp et al., 2020) : apprendre les échelles de diffusion \(t\) + MLP — simple, robuste, SOTA sur la correspondance — le « transformer discret » du domaine ;
  • Transformers sur surfaces : attention entre points/patches avec encodages de position intrinsèques — convergence avec le module Advanced GNN (GPS : global + local) ;
  • Tâches : classification (ModelNet), segmentation (ShapeNet parts), correspondance (FAUST, SCAPE : humains en poses diverses) ; apprentissage auto-supervisé : prédire des descripteurs, rotations, masquage — le pré-entraînement des LLMs appliqué aux surfaces.

7. Applications et passerelles LLGA

  • Industrie : CAO/mesh retrieval, scan 3D (reverse engineering), AR/VR, animation, dentaire/orthopédie ; autonomes (lidars = nuages) ;
  • Sciences : molécules comme surfaces (électrostatique) ; protéines (interface binding) — la géométrie rencontre le pipeline molécules-graphes du master ;
  • Passerelle 1 — graphes : un maillage est un graphe ; les opérateurs (laplacien, diffusion, eigendecomposition) sont partagés avec Graph ML/Advanced GNN ;
  • Passerelle 2 — OT : correspondance de formes ≈ transport ; Gromov-Wasserstein compare des métriques intrinsèques (OT ch. 5) ;
  • Passerelle 3 — LLM : les LLMs multimodaux commencent à « voir » des objets ; les tokens 3D (patches de surfaces) rejoignent les tokens d'images ; un « shape-GPT » générant de la géométrie ? — sujet de projet transverse.

Exercices

  1. Cotangentes. Vérifier que la matrice de cotangentes est symétrique et que \(L\mathbf{1} = 0\) ; comparer sur un maillage plat (le laplacien doit être nul aux points intérieurs)
  2. Spectre = empreinte. Calculer les 20 premières valeurs propres de \(\Delta\) pour deux formes rigides et leurs versions articulées (bend) ; tracer les spectres superposés et commenter l'invariance isométrique.
  3. HKS. Montrer que \(\mathrm{HKS}(x, t)\) est invariant isométrique ; calculer et visualiser HKS multi-échelles sur un humain FAUST — identifier les « points auto-descripteurs » (mains, tête).
  4. Functional map jouet. Deux maillages connus isométres : construire \(C\) par moindres carrés (contraintes descripteurs + commutation) ; reconstruire la correspondance ; mesurer l'erreur géodésique moyenne ; que se passe-t-il si \(k\) est trop petit ?
  5. PointNet invariant. Prouver que le max pooling rend PointNet invariant par permutation, mais que le produit ne le serait pas ; implémenter et vérifier sur un nuage permuté.
  6. DiffusionNet vs GCN. Sur FAUST (correspondance) : comparer un GCN sur le graphe du maillage vs DiffusionNet (échelles apprises) ; discuter pourquoi la diffusion est un bon « mixeur » géométrique.
  7. Projet. Retrieval de formes : extraire (HKS, spectre, courbures) → agrégation → similarité par transport optimal (W_1 sur les distributions de descripteurs) ; évaluer le mAP sur un sous-ensemble de SHREC ; les trois passerelles du cours au travail.
