6. NumPy : algèbre linéaire numérique

Tout le deep learning est de l'algèbre linéaire batchée. Rappels des opérations et de leurs coûts, puis les trois pièges qui coûtent le plus en TP : broadcasting, vues/copies, dtypes.

import numpy as np

A = np.random.randn(1000, 500)
x = np.random.randn(500)

A @ x               # produit matrice-vecteur : O(n^2)
A.T @ A             # produit matrice-matrice : O(n^3) — via BLAS, très optimisé

np.linalg.norm(x)                       # norme euclidienne
np.linalg.solve(A.T @ A, A.T @ x)       # résolution (mieux que inv() @ b !)
w, V = np.linalg.eigh(np.array([[2,1],[1,2]]))   # valeurs/vecteurs propres (symétrique)

6.1. Broadcasting : les règles, démontrées sur exemples

Règles (à connaître par cœur) Deux tableaux de formes \(s\) et \(s'\) sont rendus compatibles en (1) alignant les dimensions à droite ; (2) pour chaque axe, tailles égales, ou l'une vaut 1 (le tableau de taille 1 est alors répliqué virtuellement). Toute autre combinaison : erreur.
FormesRésultatMécanisme
\((n,) + (1,)\)\((n,)\)scalaire répliqué
\((n, d) + (d,)\)\((n, d)\)le vecteur s'applique à chaque ligne (recentrage !)
\((n, 1) + (m,)\)\((n, m)\)colonne + ligne = table de toutes les paires (distance par paires !)
\((n, m) + (n,)\)erreuralignement à droite : il faut \((n,1)\)
 
# Centrer une matrice de donnees : X (n, d) -> X - mean (d,) + (n,d)
Xc = X - X.mean(axis=0)              # regle 2 : (n,d) + (d,)

# Toutes les differences a la puissance 2 entre deux ensembles de points :
a = rng.random((5, 3)); b = rng.random((7, 3))
d2 = ((a[:, None, :] - b[None, :, :])**2).sum(-1)   # (5,1,3)-(1,7,3) -> (5,7,3) -> (5,7)
# Le meme pattern code les matrices de distances des K-means, des kNN,
# du attention score (Q @ K^T : "chaque requete contre chaque cle").

# Le piege du vecteur (n,) vs (n,1) :
v = np.ones(5); w = v[:, None]        # w : (5,1)
v + w                                 # -> (5,5) !! et non (5,1) : alignement a droite

6.2. Vues contre copies

Le piège n°1 des TP y = x[2:5] est une vue : même tampon mémoire, modifier y modifie x. Sont des vues : le slicing de base, reshape (quand c'est possible sans copie), les transposées. Sont des copies : l'indexation avancée (x[mask], x[[1,7,2]]), les opérations arithmétiques. Diagnostic : np.shares_memory(x, y) et y.base is not None. Conséquences : (i) les vues sont gratuites — itérer par tranches ne coûte rien ; (ii) mais un « extrait » modifié en place corrompt la source. Règle de sûreté du TP : après un slicing destiné à être transformé, écrire chunk = x[i:i+B].copy() si le résultat doit survivre.

6.3. axis, reshape, reductions

X = rng.random((4, 3))
X.sum(axis=0)        # collapse l'axe 0 (lignes) -> (3,)   : par colonne
X.sum(axis=1)        # collapse l'axe 1 (colonnes) -> (4,) : par ligne
X.mean(axis=0, keepdims=True)   # (1,3) : garde le nombre d'axes (broadcast-friendly)
X.reshape(2, 6); X.reshape(-1)  # -1 = "deduis cette dimension" (lecture des strides)
X.ravel()[::2]                   # vue aplatie, un element sur deux

6.4. Algèbre : solve, lstsq, SVD et ACP en dix lignes

# Regle : JAMAIS inv(). solve(A, b) factorise puis resout : 2x plus rapide,
# numeriquement plus stable (conditionnement), et lstsq gere le rang deficient.
w = np.linalg.solve(A, B)                       # A w = B
beta, res, rank, sv = np.linalg.lstsq(X, y, rcond=None)   # moindres carres

# ACP par SVD (donnees centrees) : X = U S V^t, composantes = lignes de V^t
Xc = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
Z = U * S                       # projections (scores) sur les composantes
explained = S**2 / (S**2).sum() # variance expliquee par composante
k = int(np.searchsorted(np.cumsum(explained), 0.95) + 1)   # garder 95 %
Zk = Z[:, :k]                   # donnees reduites : le "PCA(n_components=0.95)" de sklearn
Rappels essentiels
  • \(\langle u, v\rangle = u^\top v\), \(\|u\| = \sqrt{u^\top u}\) ; \(u \perp v \iff u^\top v = 0\) ;
  • matrices symétriques : diagonalisables en base orthonormée, valeurs propres réelles — le socle spectral du module Graph ML (Laplacien !) ;
  • décomposition en valeurs singulières \(M = U \Sigma V^\top\) : base de l'ACP et des embeddings, inverse généralisé (lstsq), rang ;
  • diffusion : \((I - \alpha A)^{-1}\), séries de Neumann \(\sum_k \alpha^k A^k\) — c'est PageRank et les marches aléatoires ;
  • stabilité numérique : ne jamais inverser une matrice (np.linalg.solve), soustraire le max avant exp (softmax), travailler en float64 pour le calcul scientifique et float32 pour l'apprentissage profond.

6.5. dtypes, précision et promotion

a = np.array([1, 2, 3])             # int64 par defaut
a.dtype, (a / 2).dtype              # int64, float64 : la division promeut
np.array([1, 2], dtype=np.int32) + np.array([3.0])   # -> float64 (promotion)
np.int8(127) + np.int8(1)           # -128 : overflow silencieux !
np.float32(1e8) + 1.0 == np.float32(1e8)   # True : 1 est sous la precision
# Regles de TP : float64 pour l'analyse, float32 pour le GPU (2x de memoire
# et de bande passante gagnes), jamais d'entier pour accumuler des moyennes.

6.6. Vectorisation : benchmark commenté

# python -m timeit sur une machine de reference (ordres de grandeur) :
#   boucle triple C[i,j] += A[i,k]*B[k,j]     ~ 2 500 ms
#   trois boucles avec np.dot par ligne        ~  120 ms
#   A @ B (BLAS, float64)                       ~    8 ms   # ~300x la boucle naive
# Moralite : en NumPy, la boucle qui reste en Python est le bug de performance.

6.7. scipy.sparse : COO, CSR, matvec

from scipy import sparse
# COO : triplets (ligne, colonne, valeur) — constructeur naturel (par arête)
S = sparse.coo_matrix((data, (rows, cols)), shape=(n, m))
S = S.tocsr()                        # CSR : parcours par ligne rapide, arithmetic
y = S @ x                            # matvec : O(nnz), pas O(n*m)
S.T @ S                              # comptes de co-occurrence (X^t X) creux — NLP
# Combiner avec le chapitre 5 : A du graphe en CSR, degres = A @ np.ones(n),
# normalisation D^-1/2 A D^-1/2 : la propagation d'un GNN est un matvec sparse.

À retenir — chapitre 6

  • Broadcasting : alignement à droite, dimensions 1 répliquées — \((n,1)+(m,) \to (n,m)\) est le pattern « par paires ».
  • Vues (slices, reshape) vs copies (indexation avancée) ; np.shares_memory pour diagnostiquer.
  • solve/lstsq plutôt que inv ; ACP en dix lignes par SVD ; float64 analyse / float32 GPU.
  • Creux : COO pour construire, CSR pour calculer ; un GNN = produit sparse.
