Exercices

  1. Complexité. Classer par complexité croissante : recherche dichotomique, tri fusion, Dijkstra (tas), produit \(A^\top A\), parcours BFS, calcul de toutes les paires de distances. Justifier chaque classe.
    Dichotomie \(\mathcal{O}(\log n)\) < BFS \(\mathcal{O}(|V|+|E|)\) (linéaire en la taille du graphe) < tri fusion \(\mathcal{O}(n\log n)\) < Dijkstra \(\mathcal{O}((|V|+|E|)\log|V|)\) (BFS + un facteur tas par extraction) < \(A^\top A\) \(\mathcal{O}(nd^2)\) — pour \(A \in \mathbb{R}^{n\times d}\), chaque colonne rencontre chaque colonne sur \(n\) lignes < paires de distances \(\mathcal{O}(n^2)\) (et \(\mathcal{O}(n^2 d)\) en coût total en dimension \(d\)).
  2. Master theorem. Résoudre : (a) \(T(n)=2T(n/2)+n\) ; (b) \(T(n)=T(n/9)+n\) ; (c) \(T(n)=7T(n/2)+n^2\) (Strassen-like) ; (d) \(T(n) = 2T(\sqrt n) + \log n\) (indice : poser \(m = \log n\)).
    (a) \(\Theta(n\log n)\) (égalité). (b) \(d=1 > \log_9 1 = 0\) : \(\Theta(n)\) (la racine domine). (c) \(\log_2 7 \approx 2{,}81 > 2\) : \(\Theta(n^{2{,}81})\) (les feuilles dominent). (d) \(S(m) = 2S(m/2) + m\) avec \(m = \log n\) : \(\Theta(m\log m) = \Theta(\log n \log\log n)\).
  3. Tableau dynamique. Si le facteur de croissance était \(c = 1{,}1\) au lieu de 2 (réallocation fréquente), montrer que append reste \(\mathcal{O}(1)\) amorti mais avec une constante ~\(c/(c-1) = 11\) copies par insertion. Quel enseignement pour les list Python ?
    Somme des copies : \(n(c^0 + c^{-1} + c^{-2} + \dots) \leq n\frac{c}{c-1}\) (série géométrique de raison \(1/c\)). Avec \(c=1{,}1\) : 11n copies, contre 2n pour \(c=2\) — amorti constant mais constantes 5× pires. D'où le choix de croissances ~1,125 (Python, sur-allocation progressive) à 2 selon les usages : compromis mémoire gaspillée / copies.
  4. Composantes connexes. Écrire composantes(adj) qui renvoie une liste de composantes (ensembles de sommets) en utilisant DFS. Test sur un graphe à 3 composantes dont une réduite à un sommet isolé. 
    def composantes(adj):
    seen, comps = set(), []
    for s in adj:
        if s in seen: continue
        comp = dfs(adj, s, visited=set())   # dfs du chapitre 5
        seen |= comp; comps.append(sorted(comp))
    return comps

G = {0:[1], 1:[0], 2:[3], 3:[2], 4:[]}
assert composantes(G) == [[0,1], [2,3], [4]]
  5. Chemins de longueur k. Montrer que \((A^k)_{ij}\) compte les chemins de longueur exactement \(k\) de \(i\) à \(j\) (récurrence sur \(k\)). Vérifier en NumPy sur un petit graphe et conclure sur le coût du comptage exact vs. un produit matriciel sparse.
    Récurrence : \((A^{k+1})_{ij} = \sum_l (A^k)_{il} A_{lj}\) : un chemin de longueur \(k+1\) vers \(j\) passe par un avant-dernier sommet \(l\), voisin de \(j\) — on somme sur \(l\). Base \(k=1\) : \(A_{ij}\) = nombre d'arêtes \(i \to j\). 
    A = np.array([[0,1,1,0],[1,0,1,0],[1,1,0,1],[0,0,1,0]])
assert (np.linalg.matrix_power(A, 2))[0,3] == 1   # un seul chemin de longueur 2
    Coût : \(k\) produits denses \(\mathcal{O}(n^3)\), ou sparse \(\mathcal{O}(k \cdot \mathrm{nnz} \cdot \bar d)\) — le comptage exact explose avec \(k\), d'où les walks tronqués et l'encodage positionnel des GNN (module Graph ML).
  6. Détection de cycle et tri topologique. Écrire une fonction détectant si un graphe orienté contient un cycle (couleurs blanc/gris/noir), puis un tri topologique par l'algorithme de Kahn appliqué au workflow : fetch → chunk → embed → index → answer. 
    def has_cycle(adj, n):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE]*n
    def visit(u):
        color[u] = GRAY
        for v in adj[u]:
            if color[v] == GRAY: return True        # arete retour => cycle
            if color[v] == WHITE and visit(v): return True
        color[u] = BLACK; return False
    return any(color[u] == WHITE and visit(u) for u in range(n))

wf = {0:[1], 1:[2], 2:[3], 3:[4], 4:[]}            # fetch -> chunk -> embed -> index -> answer
assert not has_cycle(wf, 5)
assert topo_sort(wf, 5) == [0, 1, 2, 3, 4]
wf[4].append(0)                                      # answer -> fetch : cycle !
assert has_cycle(wf, 5) and topo_sort(wf, 5) is None
    L'arête « gris vers gris » caractérise un cycle parce qu'elle remonte dans la pile de récursion : chemin de retour vers un ancêtre.
  7. Anagrammes. Écrire group_anagrams(words) en \(\mathcal{O}(n\,k\log k)\) via dictionnaire de signatures — et expliquer pourquoi la clé tuple(sorted(w)) donne une complexité en moyenne linéaire en \(n\). 
    from collections import defaultdict
def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:                       # n mots de longueur <= k
        groups[tuple(sorted(w))].append(w)   # signature : O(k log k), hash O(k)
    return list(groups.values())
assert group_anagrams(["chien", "niche", "chine", "chat"]) ==
       [["chien", "niche", "chine"], ["chat"]]
    La signature est la même ssi anagrammes ; l'insertion dans defaultdict est \(\mathcal{O}(1)\) en moyenne (table de hachage, section 3.1) après le calcul de la clé \(\mathcal{O}(k \log k)\) : total \(\mathcal{O}(n k \log k)\), la boucle étant linéaire en \(n\) en moyenne.
  8. Générateurs. Écrire un pipeline à trois générateurs lignes(path) -> tokens -> ngrams(k) produisant les \(k\)-grammes d'un corpus sans jamais charger plus d'une ligne en mémoire. Pourquoi la consommation mémoire est-elle \(\mathcal{O}(k)\) ? 
    def lignes(path):
    with open(path, encoding="utf-8") as f:
        yield from f

def tokens(lines):
    for line in lines:
        yield from line.lower().split()

def ngrams(toks, k):
    window = deque(maxlen=k)              # O(k) en memoire, glissement O(1)
    for t in toks:
        window.append(t)
        if len(window) == k:
            yield tuple(window)

# ngrams(tokens(lignes("corpus.txt")), 3)
    Chaque étape ne stocke que son état minimal (position de fichier, deque de \(k\) éléments) ; les valeurs transitent une à une : mémoire \(\mathcal{O}(k)\) indépendante du corpus — c'est l'architecture des DataLoader de tokenisation en flux (module NLP).

  11. Filtre de Bloom. Implémenter le filtre de l'exemple 3.7 avec \(m/n = 12\) bits par élément : quelle valeur de \(k\) choisir, quel taux de faux positifs théorique ? Vérifier empiriquement sur 100 000 chaînes insérées et 100 000 absentes.
