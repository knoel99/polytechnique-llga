Introduction et vue d'ensemble

ModuleRefresher in Computer Science
CodeCSC_51440_EP
Equipe et volumeEnseignant : Amal Dev Parakkat (Télécom Paris) · 36 h · Python avancé, structures de données, complexité, algorithmes de graphes et outillage logiciel — le socle informatique de tous les modules du master.
Statut dans la formationRappels L3Prérequis du master

Ce module remet à niveau, sur 36 h, le socle informatique du master : Python avancé pour la science des données, structures de données, analyse de complexité, algorithmes de graphes et outillage logiciel (tests, git). C'est ici que se construit la fluence de code exigée partout ailleurs — un TP de Deep Learning où l'on lutte contre NumPy n'est pas un TP d'apprentissage. Le chapitre consacré aux algorithmes de graphes est en outre la porte d'entrée directe du versant « graphes » du master LLGA, jusqu'au Graph ML et aux GNNs.

Ce que vous saurez faire

  • Écrire du Python idiomatique pour la donnée (numpy, structures natives, fonctions, exceptions) et non plus du « Python de première année ».
  • Prévoir le coût d'un algorithme en temps et en mémoire (notation grand O) et choisir en conséquence.
  • Sélectionner la bonne structure de données — tableaux, listes chaînées, piles, files, tables de hachage, arbres — selon les opérations dominantes du problème.
  • Implémenter tri, recherche et récursion, et raisonner sur leur correction par récurrence.
  • Programmer les algorithmes de graphes fondamentaux : parcours BFS/DFS, plus courts chemins, composantes connexes, arbres couvrants.
  • Vectoriser du calcul numérique avec NumPy (algèbre linéaire, broadcasting) au lieu de boucles coûteuses.
  • Structurer un petit projet : classes, tests, git — les réflexes attendus dans tous les projets et stages du master.

Positionnement dans la formation

Module de mise à niveau du tronc commun, en Année 1 · Période 1, sans aucun prérequis. Il se suit en parallèle du module Refresher in Statistics : l'un fournit la langue mathématique du master, l'autre sa langue informatique. Ensemble, ils conditionnent l'entrée dans le module Machine Learning.

Les algorithmes de graphes du chapitre 5 sont le point d'appui du module Graph Machine and Deep Learning for Generative AI (Période 2) : le vocabulaire des parcours, des plus courts chemins et de la connexité y est supposé acquis dès les rappels de théorie des graphes. La maîtrise de NumPy et de l'outillage logiciel sert immédiatement Machine Learning et Deep Learning, dont les TP sont exigeants en code.

Enfin, le chapitre d'analyse de complexité et de structures de données est le prérequis déclaré du module DataBase Management System, où index, tri externe et optimisation de requêtes se raisonnent en coût algorithmique.

Plan du cours

  • Python pour la science des données : le langage, ses idiomes et son écosystème, remis à niveau d'emblée.
  • Analyse de complexité : compter les opérations, comparer des algorithmes, raisonner en grand O.
  • Structures de données fondamentales : quelle structure pour quelles opérations — la décision d'architecture la plus fréquente.
  • Tri, recherche, récursion : les classiques, avec preuves et complexités.
  • Algorithmes de graphes : parcours, plus courts chemins, connexité — le socle du futur module Graph ML.
  • NumPy : algèbre linéaire numérique : vectorisation, broadcasting, stabilité — l'outil quotidien de tous les TP.
  • Génie logiciel minimal (OOP, tests, git) : écrire du code qu'un collègue peut relancer dans un an.
  • Algorithmes géométriques et travaux de l'enseignant : un pont vers la géométrie algorithmique et la recherche d'Amal Dev Parakkat.

Comment travailler ce module

  • Tapez tout le code vous-même : la fluence Python s'acquiert au clavier, pas à la lecture — c'est le critère d'évaluation implicite de tous les TP suivants.
  • Suivez l'ordre des chapitres : complexité et structures conditionnent les algorithmes de graphes, qui conditionnent eux-mêmes une partie de la Période 2.
  • Pour chaque algorithme, connaissez sa complexité par cœur : « quelle structure ? quel coût ? » est la question que vous poserez cent fois dans le master.
  • Poussez vos TP sur git avec des tests qui passent : le chapitre 7 s'apprend en le pratiquant sur les chapitres précédents.
  • Refaites les exercices de graphes jusqu'à savoir réécrire un BFS de mémoire : le module Graph ML démarre dessus.
  • En cas de doute sur les bases mathématiques, le module Refresher in Statistics est le compagnon complémentaire — les deux se suivent en parallèle.
Le mot de l'équipe pédagogique Le master LLGA croise grands modèles de langage et graphes de connaissances : l'un demande du code rapide et fiable, l'autre des algorithmes de graphes solides. Ce module est l'endroit où ces deux exigences se préparent ensemble, bien avant d'entraîner votre premier transformer ou votre premier GNN.
