Références

  • T. Cormen, C. Leiserson, R. Rivest, C. Stein, Introduction to Algorithms (CLRS), 4e éd., MIT Press, 2022 — la bible structures de données + graphes.
  • J. Kleinberg, É. Tardos, Algorithm Design, Pearson, 2005 — la meilleure source d'exercices de modélisation (graphe, greedy, DP).
  • R. Sedgewick, K. Wayne, Algorithms, 4e éd., Addison-Wesley, 2011 — implémentations Java lisibles, transférables en Python.
  • L. Ramalho, Fluent Python, 2e éd., O'Reilly, 2022 — pour les idiomes Python avancés (chapitres 1 et 7).
  • S. Cheng, T. Dey, J. Shewchuk, Delaunay Mesh Generation, CRC Press, 2012 — la référence du chapitre 8 (cercle vide, flips, raffinement).
  • The Python Tutorial, NumPy: the absolute basics et la documentation pytest — à garder ouverts pendant tous les TP.
  • D. Eppstein et al., NetworkX tutorial — l'outil graphes utilisé au master.
  • Travaux de l'enseignant (chapitre 8) : A unified approach towards reconstruction of a planar point set (Computers & Graphics, 2015) · Hole detection in a planar point set: an empty disk approach (SMI 2017) · BallMerge: High-quality Fast Surface Reconstruction via Voronoi Balls (Computer Graphics Forum / Eurographics 2024) · page de l'enseignant : perso.telecom-paristech.fr/parakkat.
