5. Arbres, forêts, boosting

5.1 Arbres de décision (CART)

Partition récursive de \(\mathcal{X}\) par des coupes axées (questions binaires « \(x_j \leq t\) ?»). À chaque feuille, on prédit la moyenne (régression) ou la classe majoritaire (classification). Croissance : à chaque nœud, choisir \((j, t)\) maximisant le gain d'impureté ; puis élagage pour éviter le sur-apprentissage. Les critères d'impureté exacts, pour un nœud \(D\) contenant les classes en proportions \(p_1, \dots, p_K\) :

Définition 5.1 — Impuretés usuelles $$\text{entropie : } H(D) = -\sum_{k=1}^K p_k \log_2 p_k, \qquad \text{Gini : } G(D) = 1 - \sum_{k=1}^K p_k^2 = \sum_k p_k(1 - p_k).$$ En régression, on utilise l'erreur quadratique \(Q(D) = \frac{1}{|D|}\sum_{i \in D}(y_i - \bar y_D)^2\). Pour une coupe \(D = D_L \cup D_R\), le gain vaut $$\Delta(j, t) = I(D) - \frac{|D_L|}{|D|} I(D_L) - \frac{|D_R|}{|D|} I(D_R).$$
Gini et entropie sont presque interchangeables À deux classes (\(p = p_1 = 1 - p_2\)) : \(G(p) = 2p(1-p)\) et \(H(p) = -p\log_2 p - (1-p)\log_2(1-p)\). Toutes deux sont maximales en \(p = 1/2\), nulles en \(0\) et \(1\), et leur développement autour de \(1/2\) coïncide au premier ordre : \(H(p) = 1 - \frac{2}{\ln 2}(p - \tfrac12)^2 + o\big((p-\tfrac12)^2\big)\) et \(G(p) = \frac12 - 2(p - \tfrac12)^2\). CART utilise Gini (pas de logarithme, calcul direct) ; ID3/C4.5 utilisent l'entropie (gain d'information). Le choix est rarement décisif — le élagage l'est. L'élagage coût-complexité de CART minimise \(R_\alpha(T) = R(T) + \alpha\,|\text{feuilles}(T)|\) sur la famille des sous-arbres : encore un compromis ajustement/complexité (chapitre 7).

5.2 Forêts aléatoires (bagging)

Théorème 5.2 — Le bagging réduit la variance Soient \(T_1, \dots, T_B\) des prédicteurs de même variance \(\sigma^2\), deux à deux de corrélation \(\rho\). La moyenne \(A_B = \frac1B\sum_b T_b\) vérifie $$\mathrm{Var}(A_B) = \rho\,\sigma^2 + \frac{1 - \rho}{B}\,\sigma^2.$$
\(\mathrm{Var}(A_B) = \frac{1}{B^2}\big[\sum_b \mathrm{Var}(T_b) + \sum_{b \neq b'} \mathrm{Cov}(T_b, T_{b'})\big] = \frac{1}{B^2}\big[B\sigma^2 + B(B-1)\rho\sigma^2\big] = \frac{\sigma^2}{B} + \frac{B-1}{B}\rho\sigma^2\), qui se réécrit comme annoncé. Cas iid (\(\rho = 0\), par exemple variables gaussiennes de même loi) : \(\mathrm{Var} = \sigma^2/B\) — diviser la variance par \(B\) en moyennant des réplicats indépendants.∎
Pourquoi ça marche si bien pour les arbres Quand \(B \to \infty\), la variance résiduelle tend vers le plancher \(\rho\sigma^2\) : tout l'art consiste à faire baisser \(\rho\). Les forêts aléatoires combinent deux mécanismes : (i) le bootstrap (rééchantillonnage des lignes) ; (ii) la sélection aléatoire de \(m_{\text{try}} < d\) variables candidate à chaque split (decorrelation), qui force les arbres à différer structurellement. Les arbres non élagués ont un biais faible et une variance élevée — exactement le profil que le bagging sait corriger. Bonus : chaque arbre laisse de côté en moyenne \(e^{-1} \approx 37\,\%\) des données (out-of-bag), une estimation du risque gratuite — on y revient au chapitre 9. Les forêts restent une référence tabulaire difficile à battre.

5.3 Boosting : descente de gradient dans l'espace des fonctions

Définition 5.3 — Le problème fonctionnel On cherche \(f : \mathcal{X} \to \mathbb{R}\) minimisant $$\Phi(f) = \frac1n \sum_{i=1}^n \ell\big(y_i, f(x_i)\big),$$ où \(\ell\) est convexe et dérivable en sa seconde variable (quadratique, logistique…). On construit \(f\) comme une somme \(f_M = \sum_{m=0}^M \eta\, h_m\) de fonctions simples (typiquement des petits arbres), choisies une à une — c'est un modèle additif stagewise.
Théorème 5.4 — Le boosting est une descente de gradient fonctionnelle Supposons \(f_{m-1}\) construit et posons \(g_i = \frac{\partial\, \ell}{\partial f}(y_i, f_{m-1}(x_i))\) (pseudo-résidus, signe opposé près). Alors, au premier ordre en \(\eta\) : $$\Phi(f_{m-1} + \eta h) = \Phi(f_{m-1}) - \frac{\eta}{n}\sum_{i=1}^n h(x_i)\,\underbrace{(-g_i)}_{\text{pseudo-résidus}} + o(\eta),$$ si bien que la direction \(h\) qui fait le plus baisser \(\Phi\) est celle alignée sur les pseudo-résidus \(-g_i\). Le gradient boosting ajuste \(h_m\) par régression (arbres) sur les couples \((x_i, -g_i)\).
C'est un développement de Taylor de la fonction d'une variable \(s \mapsto \ell(y_i, f_{m-1}(x_i) + s\,h(x_i))\) autour de \(s = 0\), sommé sur \(i\) et divisé par \(n\) (avec \(s = \eta\)) : \(\ell(y_i, f_{m-1}(x_i) + \eta h(x_i)) = \ell(y_i, f_{m-1}(x_i)) + \eta\, h(x_i)\, \frac{\partial \ell}{\partial f}(y_i, f_{m-1}(x_i)) + o(\eta)\). Cas quadratique \(\ell(y, f) = \frac12(y - f)^2\) : \(g_i = f_{m-1}(x_i) - y_i\), donc \(-g_i = y_i - f_{m-1}(x_i)\) — les vrais résidus : chaque arbre prédit les résidus des précédents, et \(\Phi(f + \eta h)\) est exact (pas de reste) pour \(h\) = résidus. Cas logistique \(\ell(y, p) = -y\log p - (1-y)\log(1-p)\) composée avec la sigmoïde : \(\frac{\partial \ell}{\partial f} = \sigma(f) - y\) (calcul du chapitre 3) ; pseudo-résidus \(y_i - p_i\).∎
Learning rate et early stopping Le pas \(\eta\) (typiquement \(0.01\)–\(0.1\)) n'est pas la constante optimale de descente : on renonce au line search exact pour un petit pas qui (i) limite la variance de chaque arbre, (ii) laisse les arbres suivants corriger les précédents — d'où plus d'itérations nécessaires. Le nombre \(M\) d'itérations joue le rôle de capacité effective : \(\Phi(f_M)\) décroît mécaniquement avec \(M\), mais le risque de généralisation décroît puis remonte ; l'early stopping (choisir \(M\) sur validation) est la vraie régularisation du boosting — même logique que la norme \(\|\theta\|\) en ridge (chapitre 7) : à \(M\) croissant correspond un dictionnaire de directions croissant. Friedman (2001) formalise ce paradigme ; XGBoost/LightGBM le rendent industriel (second ordre, régularisation sur les feuilles, histogrammes) ; le module M2 « From Boosting to Foundation Models » part de là. 
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier
from sklearn.model_selection import cross_val_score
rf  = RandomForestClassifier(n_estimators=300, min_samples_leaf=2, oob_score=True)
gbt = HistGradientBoostingClassifier(max_iter=300, learning_rate=0.06)
print(cross_val_score(rf, X, y, cv=5).mean(), cross_val_score(gbt, X, y, cv=5).mean())
print("erreur OOB de la foret :", 1 - rf.fit(X, y).oob_score_)  # validation gratuite
