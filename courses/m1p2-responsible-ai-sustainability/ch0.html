0. Rappels : optimisation, dualité, complexité

Rappels L3 — le socle (cf. module Machine Learning, ch. 0 ; module Optimal Transport, ch. 0 ; module Optimization for AI, ch. 0)
  • Programme linéaire (PL) : \(\min_x c^\top x\) sous \(Ax \leq b\), \(x \geq 0\) — ensemble admissible = polyèdre ; optimum (s'il existe) atteint en un sommet (élément extrémal) ; résolu en temps polynomial (points intérieurs, simplexe en pratique).
  • Dualité : le dual d'un PL est un PL ; \(d^\star \leq p^\star\) toujours (dualité faible), égalité sous conditions (Slater) ; les variables duales \(\lambda \geq 0\) s'interprètent comme des prix marginaux — combien vaut une unité supplémentaire de chaque ressource. Cette lecture « économique » sera notre outil central : prix du carbone, prix d'un MWh, prix d'une heure GPU.
  • Variables entières (PLNE) : dès qu'une variable est entière (choisir / ne pas choisir), le problème devient NP-difficile en général (cf. module Refresher CS, ch. 2) ; on le traite par relaxation continue + branch and bound (ch. 4).
  • Dérivées partielles, convexité : la convexité distingue « facile » (un minimum local est global) de « dur » — cf. module Optimization for AI, ch. 1.
Proposition 0.1 — Le lemme qui sert tout le module (démontré) Pour un PL \(\min\{c^\top x : Ax = b,\ x \geq 0\}\) et toute solution duale admissible \((\lambda, \mu \geq 0)\) (i.e. \(A^\top \lambda \leq c\) au sens adapté) : \(b^\top \lambda \leq c^\top x\) pour tout \(x\) admissible. Si l'égalité est atteinte, les deux solutions sont optimales.
\(c^\top x \geq (A^\top\lambda)^\top x = \lambda^\top A x = \lambda^\top b\), en utilisant successivement l'admissibilité duale, puis \(Ax = b\). Si \(c^\top x = b^\top\lambda\), alors \(x\) atteint une borne inférieure duale : \(x\) et \(\lambda\) sont optimaux (et l'écart \(c^\top x - b^\top\lambda\), nul, se décompose en \(\mu^\top x\), d'où la complémentarité \(\mu_i x_i = 0\)). ∎
Position du module — le point de vue « décision » Les autres modules du master optimisent des modèles (perte, généralisation). Ici on optimise des décisions : quand lancer quel entraînement, sur quel data center, avec quelle précision numérique, quel compromis performance/énergie accepter. Trois ingrédients nouveaux : plusieurs objectifs incommensurables (ch. 1), des ressources physiques contraintes (ch. 2), et l'exigence de mesurer ce qu'on prétend optimiser (ch. 6–7) — car un kg CO2 mal compté optimise une fable, pas le climat.
