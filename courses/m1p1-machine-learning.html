0. Rappels : outils d'optimisation

Rappels L3 utilisés dans tout le module
  • Gradient : \(\nabla f(x) \in \mathbb{R}^d\) pointe dans la direction de plus forte pente ; pour \(f(x)=\frac12\|Ax - b\|^2\), \(\nabla f(x) = A^\top(Ax - b)\).
  • Convexité : \(f\) convexe si \(f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda) f(y)\). Un minimum local d'une fonction convexe est global — raison pour laquelle tant de pertes de ML sont conçues convexes.
  • Descente de gradient : \(x_{t+1} = x_t - \eta \nabla f(x_t)\), convergence \(\mathcal{O}(1/t)\) pour un pas \(\eta < 1/L\) (\(L\) = constante de Lipschitz du gradient).
  • Matrices symétriques : diagonalisables (\(A = Q \Lambda Q^\top\), \(Q\) orthogonale) ; \(A \succeq 0\) (positive) ssi toutes ses valeurs propres sont \(\geq 0\).

1. Le cadre statistique de l'apprentissage

Définition 1.1 — Cadre iid et risque On observe un échantillon \(D_n = (X_i, Y_i)_{i \leq n}\) iid de loi \(\mathbb{P}\) sur \(\mathcal{X} \times \mathcal{Y}\). Pour une perte \(\ell : \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+\), le risque d'un prédicteur \(f : \mathcal{X} \to \mathcal{Y}\) est $$\mathcal{R}(f) = \mathbb{E}\big[\ell(Y, f(X))\big],$$ et le risque empirique (observable) : \(\hat{\mathcal{R}}_n(f) = \frac1n \sum_{i=1}^n \ell(Y_i, f(X_i))\).
Définition 1.2 — Minimisation du risque empirique (ERM) À une classe de modèles \(\mathcal{F}\) fixée, l'apprentissage résout $$\hat f_n \in \arg\min_{f \in \mathcal{F}} \ \hat{\mathcal{R}}_n(f).$$ Tout le ML consiste à choisir \(\mathcal{F}\) (linéaire ? arborescent ? réseau ?), \(\ell\) (quadratique, logistique, hinge…), et à contrôler l'écart \(\mathcal{R}(\hat f_n) - \inf_{f \in \mathcal{F}} \mathcal{R}(f)\).

1.1 Biais-variance

Décomposition (régression quadratique) Pour \(f^\star(x) = \mathbb{E}[Y \mid X = x]\), l'erreur de \(\hat f_n\) se décompose en $$\mathbb{E}\big[(Y - \hat f_n(X))^2\big] = \underbrace{\sigma^2}_{\text{bruit irréductible}} + \underbrace{\text{biais}^2(\hat f_n)}_{\text{sous-apprentissage}} + \underbrace{\mathrm{Var}(\hat f_n)}_{\text{sur-apprentissage}}.$$ Une classe \(\mathcal{F}\) trop petite ⇒ biais fort ; trop grande ⇒ variance forte.

1.2 Validation croisée

Le risque \(\mathcal{R}\) est inobservable : on l'estime en mettant de côté des données. k-fold : découper en \(k\) blocs, entraîner \(k\) fois en laissant tourner le bloc de test, moyenner. Règles du master : jamais de prétraitement appris sur le jeu de test ; un jeu de test final qu'on ne regarde qu'une fois ; la validation sert à choisir hyperparamètres et modèles.

from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

pipe = make_pipeline(StandardScaler(), Ridge(alpha=1.0))
scores = cross_val_score(pipe, X, y, cv=5, scoring="neg_root_mean_squared_error")
print(-scores.mean(), scores.std())

2. Régression linéaire et régularisation

Modèle linéaire \(f_\theta(x) = \langle \theta, x \rangle\), perte quadratique, risque empirique \(\hat{\mathcal{R}}_n(\theta) = \frac1n \|y - X\theta\|^2\). Solution (éq. normales) : \(\hat\theta = (X^\top X)^{-1} X^\top y\).
Définition 2.1 — Régularisation ridge et lasso $$\hat\theta_{\text{ridge}} = \arg\min_\theta \Big\{\tfrac1n\|y - X\theta\|^2 + \lambda \|\theta\|_2^2\Big\} = (X^\top X + n\lambda I)^{-1} X^\top y,$$ $$\hat\theta_{\text{lasso}} = \arg\min_\theta \Big\{\tfrac1n\|y - X\theta\|^2 + \lambda \|\theta\|_1\Big\}.$$ Ridge contracte tous les coefficients (résolution toujours possible) ; lasso produit des coefficients exactement nuls (sélection de variables).
Géométrie de la régularisation Contrainte \(\|\theta\|_1 \leq t\) = losange : les coins sur les axes expliquent la parcimonie ; \(\|\theta\|_2 \leq t\) = boule : contraction isotrope. La régularisation est le premier outil contre la variance — et l'ancêtre du weight decay des réseaux de neurones (\(\lambda\|\theta\|_2^2\) ajouté à la perte du module Deep Learning). 
from sklearn.linear_model import Ridge, Lasso
for lam in [1e-4, 1e-2, 1.0, 10.0]:
    l = Lasso(alpha=lam).fit(X, y)
    print(f"lambda={lam:8.3f}  coeffs non nuls = {(l.coef_ != 0).sum()}")

3. Classification : régression logistique et SVM

3.1 Régression logistique

Définition 3.1 Pour \(Y \in \{0, 1\}\), on modélise directement $$\mathbb{P}(Y = 1 \mid X = x) = \sigma(\langle \theta, x\rangle) = \frac{1}{1 + e^{-\langle \theta, x\rangle}}.$$ La maximisation de vraisemblance équivaut à minimiser la cross-entropy : $$\hat\theta = \arg\min_\theta \ \frac1n \sum_{i=1}^n \log\!\big(1 + e^{-y'_i \langle\theta, x_i\rangle}\big), \qquad y'_i \in \{-1, +1\}.$$ Convexe, lisse — résolue par descente de gradient. C'est la perte de classification des réseaux de neurones (module Deep Learning) et des LLMs (sortie softmax = généralisation multi-classes).

3.2 SVM à marge

Définition 3.2 — SVM (marge souple, primal) $$\min_{\theta, b} \ \tfrac12 \|\theta\|^2 + C \sum_{i=1}^n \xi_i \quad \text{s.c.} \quad y'_i(\langle\theta, x_i\rangle + b) \geq 1 - \xi_i, \quad \xi_i \geq 0.$$ Maximiser la marge \(\gamma = 1/\|\theta\|\) tout en tolérant les violations \(\xi_i\). La forme duale ne fait intervenir que les produits scalaires \(\langle x_i, x_j\rangle\) — d'où l'astuce à noyaux.
Théorème 3.3 — Classification à marge Pour un classifieur à marge \(\gamma\) en dimension \(d\), le risque est contrôlé en \(\mathcal{O}\big(\sqrt{(d + \log(1/\delta))/n}\big)\) : la marge, pas la dimension, gouverne la généralisation. Ce point de vue « foreground » guette le sur-apprentissage ; il annonce la théorie (module Statistical Learning Theory, option P1).

4. Noyaux

Définition 4.1 — Noyau positif \(k : \mathcal{X} \times \mathcal{X} \to \mathbb{R}\) est un noyau définie positive s'il existe une application \(\phi : \mathcal{X} \to \mathcal{H}\) (espace de Hilbert) telle que \(k(x, x') = \langle \phi(x), \phi(x')\rangle\). Équivalent : pour tout \(n\) et tout \((c_i)\), \(\sum_{ij} c_i c_j k(x_i, x_j) \geq 0\).
Exemples polynomial \(k(x,x') = (\langle x,x'\rangle + c)^p\) ; gaussien (RBF) \(k(x,x') = \exp(-\gamma\|x - x'\|^2)\) ; sur graphes : \(k = \exp(-\beta L)\) (diffusion sur le laplacien, cf. module Graph ML) ou shortest-path kernel — les noyaux sont l'ancêtre des GNN !
L'astuce à noyaux Remplacer \(\langle x_i, x_j\rangle\) par \(k(x_i, x_j)\) dans la duale SVM = travailler dans un espace de dimension infinie sans jamais calculer \(\phi\). Puissant, mais coûteux en \(\mathcal{O}(n^2)\) : c'est cette limite dimensionnelle qui a motivé le deep learning.

5. Arbres, forêts, boosting

5.1 Arbres de décision

Partition récursive de \(\mathcal{X}\) par des coupes axées (questions binaires « \(x_j \leq t\) ?»). À chaque feuille, on prédit la moyenne (régression) ou la classe majoritaire (classification). Croissance : à chaque nœud, choisir \((j, t)\) minimisant l'impureté (Gini ou entropie) des enfants ; puis élagage pour éviter le sur-apprentissage. Interprétables, non linéaires, base de tout ce qui suit.

5.2 Forêts aléatoires (bagging)

Bagging Entraîner \(B\) arbres sur des rééchantillonnages bootstrap + sous-ensembles aléatoires de variables, moyenner. La variance d'une moyenne de prédicteurs décorrélés décroît comme \(\mathrm{Var}/B\) (+ effet décorrélation) : les forêts restent une référence tabulaire difficile à battre.

5.3 Boosting (gradient boosting)

Algorithme : gradient boosting (additive modeling) $$f_0 = \arg\min_c \sum_i \ell(y_i, c); \qquad f_m = f_{m-1} - \eta \sum_i \nabla_{f}\ell(y_i, f_{m-1}(x_i)) \ \text{appris par un arbre}$$ On ajoute, à chaque itération, un arbre qui corrige le gradient de la perte — descente de gradient dans l'espace des fonctions. XGBoost/LightGBM dominent encore les tableaux industriels ; le module M2 « From Boosting to Foundation Models » part de là. 
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier
from sklearn.model_selection import cross_val_score
rf  = RandomForestClassifier(n_estimators=300, min_samples_leaf=2)
gbt = HistGradientBoostingClassifier(max_iter=300, learning_rate=0.06)
print(cross_val_score(rf, X, y, cv=5).mean(), cross_val_score(gbt, X, y, cv=5).mean())

6. Non supervisé : k-moyennes, EM, ACP

6.1 k-moyennes

Algorithme de Lloyd Minimiser \(\sum_{k=1}^K \sum_{i \in C_k} \|x_i - \mu_k\|^2\) en alternant : (i) réassignation de chaque point au centroïde le plus proche, (ii) recentrage des centroïdes. Convergent (décroissance monotone), sensible à l'initialisation (k-means++). Complexité \(\mathcal{O}(n\,k\,d\,T)\).

6.2 Mélanges gaussiens et EM

Modèle 6.1 — GMM $$p(x) = \sum_{k=1}^K \pi_k \, \varphi(x ; \mu_k, \Sigma_k), \qquad \pi_k \geq 0, \sum_k \pi_k = 1.$$
Algorithme EM E-step : calculer les responsabilités \(\gamma_{ik} = \mathbb{P}(z_i = k \mid x_i) \propto \pi_k \varphi(x_i;\mu_k,\Sigma_k)\). M-step : mettre à jour \(\pi_k, \mu_k, \Sigma_k\) comme moyennes pondérées par \(\gamma\). La log-vraisemblance croît à chaque itération vers un point stationnaire (optimum local). EM réapparaîtra dans les HMM (NLP), les VAE (Deep Learning) et le clustering de graphes (stochastic block models).

6.3 Analyse en composantes principales

ACP — double point de vue (i) Variance maximale : les composantes sont les vecteurs propres de la matrice de covariance empirique associés aux plus grandes valeurs propres. (ii) Erreur de reconstruction minimale : projeter sur le sous-espace affine de dimension \(k\) minimisant \(\sum_i \|x_i - P_k x_i\|^2\). Via la SVD de la matrice centrée \(X = U\Sigma V^\top\) : composantes = colonnes de \(V\). 
import numpy as np
Xc = X - X.mean(0)
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
Z = Xc @ Vt[:2].T                  # projection 2D
var_explained = (S**2 / (S**2).sum())[:10]   # variance expliquée par composante
ACP spectrale → graphes L'ACP sur la matrice d'adjacence/laplacien d'un graphe (spectral clustering) est le chaînon historique entre ML classique et Graph ML : on le refera sur le laplacien \(L\) au module Graph ML.

Exercices

  1. Ridge fermée. Montrer que \(\hat\theta_{\text{ridge}}\) est bien donnée par \((X^\top X + n\lambda I)^{-1}X^\top y\) en annulant le gradient, puis que le problème est toujours strictement convexe dès que \(\lambda > 0\).
  2. Cross-entropy. Vérifier que minimiser la cross-entropy logistique revient à maximiser la vraisemblance Bernoulli \(\prod_i \sigma(\theta^\top x_i)^{y_i}(1-\sigma)^{1-y_i}\), et calculer \(\nabla_\theta \hat{\mathcal{R}}_n = \frac1n X^\top(\sigma(X\theta) - y)\).
  3. EM pour un mélange de deux gaussiennes 1D. Écrire les deux étapes, implémenter (NumPy), et vérifier sur un mélange \(0{,}4\,\mathcal{N}(-2, 1) + 0{,}6\,\mathcal{N}(3, 1)\) que la log-vraisemblance est croissante sur 50 itérations.
  4. k-means++. Expliquer pourquoi l'initialisation naïve peut coûter \(\mathcal{O}(\log k)\) fois l'optimum (donner un exemple), et simuler les deux initialisations sur des blobs anisotropes.
  5. Projet fil rouge. Sur le jeu 20 Newsgroups (count vectorizer → TF-IDF → logistic/forêt), construire le pipeline complet avec validation croisée et rapporter matrice de confusion et F1 macro. Ce prétraitement texte sera refait « en version neuronale moderne » au module NLP.
