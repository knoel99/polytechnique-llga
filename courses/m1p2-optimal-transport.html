0. Rappels : convexité et dualité LP

Rappels L3 mobilisés
  • Ensembles/fonctions convexes : pour \(f\) convexe, tout point stationnaire est un minimum global ; l'OT continu est un problème d'optimisation convexe en la mesure ;
  • Programmation linéaire : minimiser \(c^\top x\) sous \(Ax = b\), \(x \geq 0\) ; dualité forte (si réalisable borné, optimaux primal et dual égaux) ; conditions de complémentarité ;
  • Théorie des mesures : mesure de probabilité, espérance \(\mathbb{E}_\mu[f] = \int f\,d\mu\) ; loi d'une variable, loi image (pushforward) : \(T_\#\mu(A) = \mu(T^{-1}(A))\) ;
  • Entropie et KL : \(\mathrm{KL}(p \| q) = \sum p_i \log(p_i / q_i) \geq 0\) (Gibbs) ; la régularisation entropique du ch. 3 en est le moteur.

1. Le problème de transport

Définition 1.1 — Problème de Monge (1781) Étant donné deux mesures de probabilité \(\mu, \nu\) sur \(\mathbb{R}^d\) et un coût \(c(x, y)\) (typiquement \(\|x - y\|^2\)), trouver une application de transport \(T : \mathbb{R}^d \to \mathbb{R}^d\) qui déplace \(\mu\) sur \(\nu\) (\(T_\#\mu = \nu\)) en minimisant le coût total : $$\min_T \ \int c\big(x, T(x)\big)\, d\mu(x).$$ Historique : déblai/remblai (Monge, 1781) ; non convexe en \(T\), pas toujours de solution (p.ex. \(\mu = \delta_0 \to \nu = \tfrac12\delta_{-1} + \tfrac12\delta_{1}\) exige de « casser la masse »).
Formulation de Kantorovich (1942) — le pivot du cours Relâcher « chaque source va vers une unique destination » en un plan de transport \(\gamma\) (couple aléatoire \((X, Y) \sim \gamma\) avec marginales \(\mu, \nu\)) : $$W_c(\mu, \nu) \;=\; \min_{\gamma \in \Pi(\mu, \nu)} \ \int c(x, y)\, d\gamma(x, y),$$ $$\Pi(\mu,\nu) = \big\{\gamma \geq 0 \ :\ \gamma(\cdot \times \mathbb{R}^d) = \mu,\ \gamma(\mathbb{R}^d \times \cdot) = \nu\big\}.$$ Cas discret (\(\mu = \sum_i a_i \delta_{x_i}\), \(\nu = \sum_j b_j \delta_{y_j}\)) : une programmation linéaire sur la matrice de transport \(\Gamma\) : $$\min_{\Gamma \in \mathbb{R}_+^{n \times m}} \ \langle C, \Gamma\rangle \quad \text{s.c.} \quad \Gamma \mathbf{1} = a,\ \Gamma^\top \mathbf{1} = b,$$ où \(C_{ij} = c(x_i, y_j)\). Compact convexe non vide ⇒ minimum atteint ; les solutions extrémales sont « presque » déterministes (\(\leq n + m - 1\) cases non nulles).
Intuition \(\gamma(x, y)\) = « quelle masse de \(x\) va vers \(y\) » ; les contraintes disent « toute la masse part, toute la masse arrive ». C'est exactement le problème logistique : carriers, mines et fours à coke (Hitchcock, Kantorovich)… et aujourd'hui comparer deux distributions de données.

2. Dualité et distance de Wasserstein

Théorème 2.1 — Dualité de Kantorovich $$W_c(\mu, \nu) \;=\; \max_{(f, g) \in \Phi_c} \ \int f\, d\mu + \int g\, d\nu, \qquad \Phi_c = \big\{(f, g) \ :\ f(x) + g(y) \leq c(x, y)\ \forall (x,y)\big\}.$$ En discret : dual LP \(\max_{f, g} \langle a, f\rangle + \langle b, g\rangle\) s.c. \(f_i + g_j \leq C_{ij}\). Les optimaux \(f^\star, g^\star\) (potentiels de Kantorovich) donnent des gradients : \((T_\#\mu\text{-p.s.})\), le transport optimal envoie \(x\) vers les \(y\) où \(f^\star(x) + g^\star(y) = c(x, y)\) (complémentarité) ; pour \(c = \tfrac12\|x-y\|^2\), \(T(x) = x - \nabla f^\star(x)\) (Brenier ; le transport est le gradient d'une fonction convexe !).
Définition 2.2 — Distance de Wasserstein \(p\) Avec \(c = d^p\) : $$W_p(\mu, \nu) = \Big( \min_{\gamma \in \Pi(\mu,\nu)} \int d(x,y)^p\, d\gamma \Big)^{1/p}.$$ \(W_p\) est une distance sur les mesures de moment \(p\) fini ; elle métrise la convergence étroite (+ moments) — alors que la KL « explose » dès que les supports diffèrent.
Proposition 2.3 — Pourquoi \(W\) et pas KL ? 1D : \(W_p(\mu, \nu) = \big(\int_0^1 |F_\mu^{-1}(u) - F_\nu^{-1}(u)|^p du\big)^{1/p}\) (quantiles ; tri en \(\mathcal{O}(n\log n)\)) ; gaussiennes : \(W_2^2(\mathcal{N}(m_1,\Sigma_1), \mathcal{N}(m_2,\Sigma_2)) = \|m_1 - m_2\|^2 + \mathrm{tr}\big(\Sigma_1 + \Sigma_2 - 2(\Sigma_1^{1/2}\Sigma_2\Sigma_1^{1/2})^{1/2}\big)\) (Bures) ; géométrie « plate » : les interpolations \(\mu_t = ((1-t)\,\mathrm{id} + t\,T)_\#\mu\) ont un sens physique (déplacement), à la différence des mélanges. Gradients exploitables en apprentissage.
Exemple 2.4 — En 1D, c'est le matching des quantiles Pour amener \(\mathcal{N}(0, 1)\) sur \(\mathcal{N}(2, 4)\) : \(T(x) = 2x + 2\) ; \(W_2^2 = 4 + 4 = 8\)… à décomposer en « décaler » (\(\|m_1 - m_2\|^2 = 4\)) et « étirer » (termes de covariance = 4). Le plan optimal apparie les quantiles : le \(q\)-quantile de \(\mu\) va sur le \(q\)-quantile de \(\nu\).

3. Régularisation entropique : Sinkhorn

Définition 3.1 — OT entropique (Cuturi, 2013) $$W_\varepsilon(a, b) \;=\; \min_{\Gamma \in U(a, b)}\ \langle C, \Gamma \rangle + \varepsilon \sum_{ij} \Gamma_{ij}\big(\log \Gamma_{ij} - 1\big),$$ strictement convexe ⇒ solution unique de la forme $$\Gamma^\varepsilon = \mathrm{diag}(u)\, K\, \mathrm{diag}(v), \qquad K = e^{-C/\varepsilon}.$$
Algorithme 3.2 — Sinkhorn (projections alternées) $$u \leftarrow a\,/\,(K v), \qquad v \leftarrow b\,/\,(K^\top u)$$ — chaque étape est une projection de KL sur la contrainte de ligne puis de colonne ; convergence géométrique (taux explicites) ; en pratique 20-200 itérations. Propriétés :
  • GPU : que des produits matriciels — des millions de points en parallèle (vs LP exact \(\mathcal{O}(n^3 \log n)\)) ;
  • Différentiable : \(\nabla W_\varepsilon\) via le théorème de l'enveloppe — d'où une perte OT utilisable en deep learning ;
  • Biais \(\varepsilon\) : \(W_\varepsilon \to W\) quand \(\varepsilon \to 0\), mais conditioning numérique se dégrade — compromis ; débias (partial Sinkhorn, dual SGM).
import numpy as np
import ot                              # POT : Python Optimal Transport

n = 200
xs, xt = np.random.RandomState(0).normal(0, 1, (n, 2)), np.random.RandomState(1).normal([2, 0], [0.5, 2], (n, 2))
a, b = np.ones(n) / n, np.ones(n) / n
C = ot.dist(xs, xt)                    # couts carres ||x-y||^2

G = ot.emd(a, b, C)                    # OT exact (LP, transport simplex)
Gs = ot.sinkhorn(a, b, C / C.max(), reg=0.05)
print("exact  :", (G * C).sum())
print("sinkhorn:", (Gs * C).sum())     # leger surcout d'entropie

W2 = ot.dist(np.array([[0., 0.]]), np.array([[2., 0.]]), metric='sqeuclidean')
print("W2 gaussiennes (Bures) vs empirique :",
      ot.wasserstein1d(xs[:,0], xt[:,0])**0.5)
L'« horizon Sinkhorn » Quand \(\varepsilon \to \infty\), \(\Gamma^\varepsilon \to a b^\top\) (indépendance) ; quand \(\varepsilon \to 0\), on retrouve le LP. La figure classique du cours : une galerie de plans de transport qui « concentrent » avec \(\varepsilon\) décroissant — à savoir refaire en TP.

4. OT et machine learning

  • Domain adaptation (spécialité de l'enseignant) : transporter la distribution source \(\mu_S\) vers la cible \(\mu_T\), puis classifier — le plan \(\Gamma\) définit un apprentissage « transporté » (Coupling de labels) ; OT pour données non-plates : nuages, images ;
  • Perte OT en deep learning : comparer distributions de features ; WGAN (le critique apprend une distance Lipschitz — dualité de Kantorovich : \(W_1 = \sup_{\|f\|_L \leq 1} \mathbb{E}_\mu f - \mathbb{E}_\nu f\)) ; spectral loss (module Signal Processing) : \(W_2\) entre spectrogrammes ;
  • Barycentres de Wasserstein : \(\min_\nu \sum_k w_k W_2^2(\nu, \mu_k)\) — « moyennes » de distributions ; applications : agrégation de mesures, interpolation de styles, fairness (ch. 6) ;
  • Embeddings de mots : \(W_1\) entre distributions de mots (WMD — Word Mover's Distance) ; distance entre documents > cosine ;
  • Génération de graphes : la distance MMD entre distributions de graphes se calcule par GW-barycentres (ch. 5).

5. Gromov-Wasserstein et graphes

Définition 5.1 — GW (Mémoli, 2011) Comparer deux espaces métriques \((X, d_X)\), \((Y, d_Y)\) sans correspondance commune (ex. : deux graphes de nœuds différents) : transporter en préservant les distances intrinsèques : $$\mathrm{GW}(X, Y) = \min_{\Gamma \in U(a,b)} \sum_{i,k,j,l} \big| d_X(x_i, x_k) - d_Y(y_j, y_l) \big|^2\ \Gamma_{ij}\, \Gamma_{kl}.$$ Quadratique en \(\Gamma\) (non convexe, optimum local) ; algorithmes : PGW (projected gradient), entropique (Sinkhorn-GW).
Fused Gromov-Wasserstein (Vayer, Flamary et al., 2019) Quand les nœuds portent aussi des features : combiner le transport des features (terme OT classique, matrice \(C_F\)) et le transport de structure (GW) : $$\mathrm{FGW}_\alpha = \min_{\Gamma} \ (1-\alpha)\langle C_F, \Gamma\rangle + \alpha \sum \big|D_X - D_Y\big|^2 \otimes \Gamma \otimes \Gamma.$$ Applications : classification de graphes, alignement de graphes, domaine adaptation structuré, réduction de dimension préservant la structure — travaux de l'enseignant, au programme du master.
GW au cœur du LLGA Les graphes d'entreprise n'ont pas de coordonnées partagées (leurs nœuds = entités propres) : GW est la distance structurelle pour comparer : graphes de connaissances, molécules, réseaux de transactions ; aligner un KG d'entreprise sur un ontologie = un problème GW. Lien direct avec le module Graph ML (génération, évaluation MMD).

6. Fairness par le transport

Cadre : décisions équitables Un modèle \(h(X)\) décide d'un outcome \(Y\) à partir de features incluant un attribut sensible \(S\) (genre, origine). Notions : demographic parity (\(h \perp S\)), equalized odds (\(h \perp S \mid Y\)). L'OT quantifie ces exigences comme des couplages entre distributions conditionnelles.
  • Repair par transport : transformer les features \(X_{s}\) de chaque groupe vers une distribution commune \(\tilde X = T_\# X\) (barycentre de Wasserstein des groupes) — « réparer » les données en préservant l'information utile (repair partiel ; trade-off biais/utility) ;
  • Bicausal OT et equalized odds : le mapping optimal entre les distributions de décisions conditionnelles implémente exactement le post-traitement optimal (théorie : couplage = randomisation optimale) ;
  • Limites et débats : métriques impossibles à satisfaire simultanément ; l'OT donne des outils, le choix normatif reste humain — lien avec le séminaire d'éthique du M2.
TP fairness Sur un jeu de salaires : 1) mesurer \(W_1\) entre distributions de salaires par groupe ; 2) appliquer un repair partiel \(\alpha\) sur la feature sensible ; 3) tracer accuracy vs demographic parity en fonction de \(\alpha\) et discuter le compromis.

Exercices

  1. Monge 1D. Montrer qu'en dimension 1, pour \(c(x,y) = |x - y|^p\), le transport optimal apparie les quantiles, puis retrouver \(W_2^2\big(\mathcal{N}(m_1, \sigma_1^2), \mathcal{N}(m_2, \sigma_2^2)\big) = (m_1 - m_2)^2 + (\sigma_1 - \sigma_2)^2\).
  2. Dualité en discret. Écrire le dual LP de Kantorovich discret, vérifier la dualité faible (\(\leq\)) par sommation des contraintes, et la complémentarité \(\Gamma_{ij} > 0 \Rightarrow f_i + g_j = C_{ij}\) sur la solution de ot.emd.
  3. Sinkhorn à la main. Pour \(a = b = (0{,}5, 0{,}5)\), \(C = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\) : calculer les itérations de Sinkhorn pour \(\varepsilon = 0{,}1\), vérifier la convergence vers \(\Gamma \approx \mathrm{diag}(0{,}5)\) et la majoration \(\langle C, \Gamma_\varepsilon\rangle \leq W + \varepsilon(\log n + \dots)\).
  4. Barycentre 1D. Montrer que le barycentre de Wasserstein de deux gaussiennes 1D est gaussien (moyenne des moyennes, moyenne quadratique des variances pour \(W_2\)) ; illustrer avec ot.gaussian.barycenter.
  5. WMD. Implémenter la Word Mover's Distance entre deux phrases (embeddings GloVe, \(W_1\) sur les mots pondérés par TF) ; comparer les similarités de phrases obtenues vs cosine des moyennes.
  6. GW alignement. Avec ot.gromov.gromov_wasserstein, aligner deux graphes « hérison » (cycles + un hub déplacé) ; visualiser la matrice \(\Gamma\) comme une soft-permutation et le coût GW en fonction de la perturbation.
  7. Projet. Domain adaptation sur MNIST → USPS (ou visages) : transporter les nuages de features par Sinkhorn, mesurer l'accuracy d'un classifieur entraîné sur la source transportée vs sans transport ; rapport avec figures du cours.
