6.2 Le coût de l'annotation

Une boîte COCO coûte de quelques secondes à une minute ; un masque polygonal, nettement plus ; une boîte 3D LiDAR à 25 Hz sur 20 objets, plusieurs minutes d'outillage dédié. Trois leviers industriels :

  • annotation assistée : un modèle pré-entraîné propose, l'humain corrige — la boucle SA-1B du chapitre 3 en est la version à grande échelle ; intérêt supplémentaire : l'apprentissage actif ne fait annoter que les exemples où le modèle est incertain ;
  • données synthétiques : rendu 3D procédural avec domain randomization (textures, éclairages aléatoires pour forcer l'invariance) ; le module P2 « Image Synthesis » (brochure) couvre le rendu ; le sim2real reste le point dur ;
  • augmentation : géométrique (recadrage, rotation, mosaïque) et photométrique (couleur, flou, bruit) ; attention : les transformations géométriques doivent transformer les boîtes/masques et les métadonnées (rotation → boîtes englobantes des masques tournés).

6.3 Pièges d'évaluation

Note — Les trois pièges classiques (1) Fuite de données : images quasi-dupliquées entre train et test (séquences vidéo) ; toujours découper par vidéo/scene, pas par image. (2) Déséquilibre longue traîne : le mAP global masque les classes rares — regarder les AP par classe ; les données d'entraînement doivent être ré-échantillonnées ou re-pondérées (cf. focal loss, chapitre 1). (3) Décalage de domaine : un modèle COCO s'écroule sur vos caméras de production (angle, compression, météo) ; prévoir dès le protocole un jeu « shadow » de données réelles non vues, et un suivi de dérive en exploitation (chapitre 8).
