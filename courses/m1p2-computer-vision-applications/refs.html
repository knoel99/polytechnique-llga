Références

  • R. Szeliski, Computer Vision: Algorithms and Applications, 2e éd., Springer, 2022 — le manuel de référence, gratuit en ligne.
  • O. Ronneberger, P. Fischer, T. Brox, U-Net: Convolutional Networks for Biomedical Image Segmentation, MICCAI 2015.
  • S. Ren, K. He, R. Girshick, J. Sun, Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks, NeurIPS 2015.
  • J. Redmon, S. Divvala, R. Girshick, A. Farhadi, You Only Look Once: Unified, Real-Time Object Detection, CVPR 2016.
  • W. Liu et al., SSD: Single Shot MultiBox Detector, ECCV 2016.
  • T.-Y. Lin, P. Goyal, R. Girshick, K. He, P. Dollár, Focal Loss for Dense Object Detection (RetinaNet), ICCV 2017 ; Feature Pyramid Networks for Object Detection, CVPR 2017.
  • K. He, G. Gkioxari, P. Dollár, R. Girshick, Mask R-CNN, ICCV 2017.
  • S. Bodla et al., Soft-NMS — Improving Object Detection with One Line of Code, ICCV 2017.
  • N. Carion et al., End-to-End Object Detection with Transformers (DETR), ECCV 2020 ; X. Zhu et al., Deformable DETR, ICLR 2021.
  • Z. Tian, C. Shen, H. Chen, T. He, FCOS: Fully Convolutional One-Stage Object Detection, ICCV 2019.
  • A. Kirillov et al., Panoptic Segmentation, CVPR 2019.
  • A. Kirillov et al., Segment Anything (SAM), ICCV 2023.
  • T.-Y. Lin et al., Microsoft COCO: Common Objects in Context, ECCV 2014 — protocole mAP.
  • A. Bewley, Z. Ge, L. Ott, F. Ramos, B. Upcroft, Simple Online and Realtime Tracking (SORT), ICIP 2016 ; N. Wojke, A. Bewley, D. Paulus, Simple Online and Realtime Tracking with a Deep Association Metric (DeepSORT), ICIP 2017.
  • Y. Zhang et al., ByteTrack: Multi-Object Tracking by Associating Every Detection Box, ECCV 2022.
  • D. Hirschmüller, « Stereo Processing by Semiglobal Matching and Mutual Information », IEEE TPAMI 30(2), 2008 (SGM) ; J. Chang, Y. Chen, Pyramid Stereo Matching Network (PSM-Net), CVPR 2018.
  • C. R. Qi et al., PointNet: Deep Learning on Point Sets for 3D Classification and Segmentation, CVPR 2017 ; Y. Zhou, O. Tuzel, VoxelNet, CVPR 2018 ; A. Lang et al., PointPillars, CVPR 2019.
  • T. Yin, X. Zhou, P. Krähenbühl, Center-based 3D Object Detection and Tracking (CenterPoint), CVPR 2021 ; Z. Li et al., BEVFormer, ECCV 2022.
  • H. Caesar et al., nuScenes: A Multimodal Dataset for Autonomous Driving, CVPR 2020 ; A. Geiger, P. Lenz, R. Urtasun, « Are we ready for Autonomous Driving? The KITTI Vision Benchmark Suite », CVPR 2012.
  • P. Bergmann, M. Fauser, D. Sattlegger, C. Steger, « MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection », CVPR 2019 — page du jeu de données.
  • B. Jacob et al., Quantization and Training of Neural Networks for Integer-Arithmetic-Only Inference, CVPR 2018.
  • G. Hinton, O. Vinyals, J. Dean, Distilling the Knowledge in a Neural Network, 2015.
  • I. Goodfellow, J. Shlens, C. Szegedy, Explaining and Harnessing Adversarial Examples (FGSM), ICLR 2015.
  • Outils des TP : torchvision, ONNX et ONNX Runtime, TensorRT, Roboflow/supervision — l'écosystème d'annotation et de métriques.
  • Note enseignant : cours listé comme obligatoire dans la brochure MSc&T (période 2) ; l'enseignant référent et le syllabus officiel seront confirmés en début de période — les références ci-dessus constituent le socle standard du domaine.
