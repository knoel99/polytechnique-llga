0. Rappels : convolution, CNN, boîtes

Rappels L3 — ce qu'on suppose acquis
  • Image numérique : grille \(H \times W\) de pixels à \(C\) canaux (3 en RVB), tenseur \(x \in \mathbb{R}^{C \times H \times W}\) ; niveaux de gris, résolution, échantillonnage (cf. module Signal Processing, chapitre 2).
  • Convolution 2D : \((I * k)(u, v) = \sum_{i,j} I(u-i, v-j)\,k(i, j)\) ; propriétés (commutativité, association avec le produit), filtres de Sobel/pendant passe-bas, corrélation vs convolution (cf. module Signal Processing, chapitre 3).
  • Réseaux convolutifs : champs réceptifs, partage de poids, pooling, architecture ResNet (connexions résiduelles) — cf. module Deep Learning, chapitre 4 ; attention et transformers — cf. module Deep Learning, chapitre 6.
  • Apprentissage supervisé : descente de gradient, SGD/Adam, surapprentissage, régularisation, transfer learning et fine-tuning — cf. module Deep Learning, chapitres 3 et 8 ; validation croisée, courbes ROC — cf. module Machine Learning.

Le cours P1 « Image Analysis and Computer Vision » (CSC_51073_EP) posait les fondements : filtrage, caractéristiques locales, géométrie projective, reconstruction. Le présent module adopte l'orientation systèmes et applications : on y construit le pipeline complet d'un produit de vision — de la donnée annotée au modèle déployé sur un matériel contraint — et on étudie les briques que l'industrie utilise réellement (détecteurs, segmenteurs, trackers, capteurs 3D, runtime d'inférence).

Définition 0.1 — Boîte englobante et IoU Une boîte englobante (bounding box) est un rectangle axis-aligné \(b = (x_1, y_1, x_2, y_2)\) avec \(x_1 < x_2\), \(y_1 < y_2\), codant les coins haut-gauche et bas-droit. Pour deux boîtes \(a\) et \(b\), on note \(A(a)\) l'aire du rectangle. L'intersection-sur-union est $$\mathrm{IoU}(a, b) \;=\; \frac{|a \cap b|}{|a \cup b|} \;=\; \frac{|a \cap b|}{A(a) + A(b) - |a \cap b|},$$ où \(|\cdot|\) désigne l'aire. La boîte d'intersection a pour coins \((\max(x_1^a, x_1^b), \max(y_1^a, y_1^b))\) et \((\min(x_2^a, x_2^b), \min(y_2^a, y_2^b))\) si ces coordonnées sont cohérentes, sinon l'intersection est vide et \(\mathrm{IoU} = 0\).
Proposition 0.2 — Propriétés de l'IoU Pour toutes boîtes \(a, b\) axis-alignées : (i) \(\mathrm{IoU}(a,b) \in [0, 1]\) ; (ii) \(\mathrm{IoU}(a,b) = \mathrm{IoU}(b,a)\) ; (iii) \(\mathrm{IoU}(a,b) = 1\) si et seulement si \(a = b\) (à égalité d'ensemble de pixels) ; (iv) \(\mathrm{IoU}(a,b) = 0\) si et seulement si l'intérieur des deux rectangles est disjoint.
(i) L'aire d'intersection est une aire de rectangle, positive et majorée par chacune des aires, donc \(0 \leq |a \cap b| \leq \min(A(a), A(b)) \leq |a \cup b|\). (ii) Les opérations d'intersection et d'union sont symétriques. (iii) Si \(\mathrm{IoU} = 1\) alors \(|a \cap b| = |a \cup b|\), donc \(|a \setminus b| = |b \setminus a| = 0\) et les rectangles coïncident ; la réciproque est immédiate. (iv) Si l'intersection est vide, le numérateur est nul ; réciproquement un rectangle d'intersection non vide a une aire strictement positive, donc \(\mathrm{IoU} > 0\). ∎
Exemple 0.3 — Un calcul d'IoU Soit la vérité terrain \(g = (0, 0, 10, 10)\) (aire 100) et la prédiction \(p = (5, 5, 15, 15)\) (aire 100). L'intersection est le carré \((5,5,10,10)\) d'aire 25, l'union vaut \(100 + 100 - 25 = 175\), donc \(\mathrm{IoU}(g, p) = 25/175 \approx 0{,}143\) : la prédiction est rejetée au seuil usuel \(\tau = 0{,}5\). Une prédiction décalée de 2 pixels seulement, \(p' = (2, 2, 12, 12)\), donne une intersection de 64 et une union de 136, soit \(\mathrm{IoU} \approx 0{,}47\) — encore sous le seuil : sur de petits objets, la métrique est intraitable, ce qui justifiera les seuils multiples du chapitre 2.
