3. Attaques par optimisation : FGSM, PGD, CW, AutoAttack

Définition 3.1 — Le problème d'évasion Attaque non ciblée de budget \(\varepsilon\) (norme \(p\)) : $$ \max_{\delta}\ \ell(f_\theta(x + \delta),\, y) \quad \text{sous contrainte}\quad \|\delta\|_p \leq \varepsilon,\ x + \delta \in [0,1]^d, $$ où \(\ell\) est l'entropie croisée. Version ciblée : maximiser \(\ell(f(x+\delta), y) - \ell(f(x+\delta), t)\) (faire monter la classe cible \(t\) et descendre la vraie). Toute la difficulté est le max interne non concave — on ne peut l'évaluer exactement, seulement le borner inférieurement (attaques) ou le surestimer.
Théorème 3.2 — FGSM = linéarisation du problème (Goodfellow et al., 2015) Au premier ordre en \(\delta\), \(\ell(x + \delta) \approx \ell(x) + \nabla_x \ell(x)^\top \delta\). Le maximum de cette approximation linéaire sur la boule \(L_\infty\) est atteint en $$ \delta^\star = \varepsilon\, \mathrm{sign}\big(\nabla_x \ell(x)\big) \qquad (\text{Fast Gradient Sign Method}), $$ avec accroissement \(\varepsilon\, \|\nabla_x \ell(x)\|_1\). Sur la boule \(L_2\) : \(\delta^\star = \varepsilon\, \nabla_x \ell(x) / \|\nabla_x \ell(x)\|_2\) (FGM).
Hölder : pour tout \(\delta\) avec \(\|\delta\|_\infty \leq \varepsilon\), \(g^\top \delta \leq \sum_j |g_j|\,|\delta_j| \leq \varepsilon \sum_j |g_j| = \varepsilon \|g\|_1\), avec \(g = \nabla_x \ell(x)\). Il y a égalité ssi \(|\delta_j| = \varepsilon\) et \(\mathrm{sign}(\delta_j) = \mathrm{sign}(g_j)\) pour tout \(j\) non nul — c'est exactement \(\delta^\star\). Pour \(L_2\) : Cauchy-Schwarz \(g^\top\delta \leq \|g\|_2\|\delta\|_2 \leq \varepsilon\|g\|_2\), égalité ssi \(\delta\) colinéaire à \(g\). ∎
Définition 3.3 — PGD (Madry et al., 2018) La linéarisation n'est valable que localement ; on itère en re-projetant sur la boule et sur \([0,1]^d\) (projection \(=\) troncature \(\min(\max(x+\delta - \varepsilon, x - \varepsilon), x + \varepsilon)\) pour \(L_\infty\)) : $$ \delta^{(k+1)} = \Pi_{B_\infty(\varepsilon)}\Big(\delta^{(k)} + \alpha\, \mathrm{sign}\big(\nabla_x \ell(x + \delta^{(k)})\big)\Big), \qquad \delta^{(0)} \in \{\,0,\ \text{ou uniforme dans } B_\infty(\varepsilon)\,\}, $$ avec pas \(\alpha \approx 2{,}5\,\varepsilon/K\) pour \(K\) itérations, et redémarrages multiples (l'objectif interne est non concave : on échantillonne plusieurs départs). PGD est le standard qualitatif : « robuste à PGD » est devenu synonyme (trop commode) de robuste.
Définition 3.4 — CW (Carlini & Wagner, 2017) Attaque optimisée sur la marge des logits \(Z(x)\), avec changement de variable \(\delta = \tfrac{1}{2}(\tanh(w) + 1) - x\) pour s'affranchir des contraintes de boîte : $$ \min_{w}\ \Big\| \tfrac{1}{2}(\tanh(w)+1) - x \Big\|_2^2 + c \cdot \max\big(Z(x+\delta)_y - \max_{t \neq y} Z(x+\delta)_t,\ -\kappa\big), $$ avec recherche dichotomique sur \(c\) et confiance \(\kappa \geq 0\). CW-L2 a longtemps été l'attaque la plus efficace — et l'outil qui a démoli la première génération de défenses (ch. 4).
Boîte noire et évaluation standard Sans gradients : (i) le transfert (ch. 2) ; (ii) les attaques à score (estimation de gradient par requêtes, attaques par carrés aléatoires) ; (iii) les attaques à décision (marche aléatoire sur la frontière). Pour évaluer, on n'utilise plus une attaque isolée mais AutoAttack (Croce & Hein, 2020) : ensemble sans paramètre — APGD-CE, APGD-T, FAB-T, Square — qui réduit de plus de 10 points la « robustesse » affichée de plusieurs modèles défendus. Règle du module : toute mesure de robustesse vaut exactement la pire attaque qu'on a essayée. 
# FGSM et PGD en une dizaine de lignes (PyTorch)
def fgsm(model, x, y, eps):
    x.requires_grad_(True)
    loss = F.cross_entropy(model(x), y)
    loss.backward()
    return (x + eps * x.grad.sign()).clamp(0, 1).detach()

def pgd(model, x, y, eps, alpha, iters, restarts=1):
    worst, worst_loss = None, float("-inf")
    for _ in range(restarts):
        d = torch.zeros_like(x).uniform_(-eps, eps)      # depart aleatoire
        for _ in range(iters):
            d.requires_grad_(True)
            loss = F.cross_entropy(model((x + d).clamp(0, 1)), y)
            g = torch.autograd.grad(loss, d)[0]          # gradient du max interne
            with torch.no_grad():
                d = (d + alpha * g.sign()).clamp(-eps, eps)
        x_adv = (x + d).clamp(0, 1).detach()
        l = F.cross_entropy(model(x_adv), y).item()      # perte du candidat
        if l > worst_loss:                               # garder le pire cas
            worst, worst_loss = x_adv, l
    return worst
