10. Nuages de points 3D : ICP et analyse urbaine

LiDAR mobile ou aéroporté, photogrammétrie, profondeur RGB-D : le monde arrive aussi sous forme de nuages de points — des millions de points 3D, éventuellement colorés, sans topologie. Les questions deviennent géométriques : recaler deux nuages, estimer des normales, segmenter, classer.

Définition 10.1 — LiDAR : mesure du temps de vol Un télémètre laser émet une impulsion et mesure l'écho : \(d = c\,\Delta t/2\) avec \(c \approx 3\times10^8\) m/s. Une précision de 2 cm exige un chronométrage à \(2\times0{,}02/(3\times10^8) \approx 0{,}13\) ns — et l'écho est intégré sur des surfaces à incidences variées, d'où le bruit « en peigne » des bords. Un LiDAR mobile (sur véhicule, le Stéréopolis de l'IGN par exemple) combine télémètres, caméras et centrale inertielle/GNSS : l'odométrie fusionnée (filtre de Kalman) donne la trajectoire, chaque position ajoute un « chapeau » de points au nuage global ; un réseau urbain produit facilement \(10^9\) points.
Proposition 10.2 — Voisinages, normales, complexités Sur un nuage de \(n\) points : le plus proche voisin s'obtient par kd-tree (ou octree en 3D) en \(O(\log n)\) en moyenne (construction \(O(n\log n)\)) contre \(O(n)\) en force brute — avec la même réserve dimensionnelle qu'au ch. 4. La normale locale au point \(p\) s'estime par ACP du voisinage : le vecteur propre associé à la plus petite valeur propre de la matrice de covariance \(\sum_{q \in \mathcal{N}(p)} (q - \bar q)(q - \bar q)^\top\) (la variance résiduelle au plan tangent est minimale — conséquence directe du théorème d'Eckart-Young du ch. 0). Coût par point : \(O(k)\) une fois le voisinage trouvé.
Théorème 10.3 — ICP : transforme rigide optimale (Kabsch) Étant donné deux ensembles appariés \(\{p_i\}, \{q_i\}\), \(i = 1..n\), chercher \(R \in SO(3)\) et \(t\) minimisant \(\sum_i \|R\,p_i + t - q_i\|^2\) a une solution exacte : \(t = \bar q - R\bar p\) (centres de gravité) et, posant \(H = \sum_i (p_i - \bar p)(q_i - \bar q)^\top = U\Lambda V^\top\) (SVD), \(R = V\,U^\top\) (et \(R = V\,\mathrm{diag}(1, 1, \det(VU^\top))\,U^\top\) si \(\det(VU^\top) = -1\), cas « réflexion »).
Le terme en \(t\) est quadratique : annuler la dérivée donne \(t = \bar q - R\bar p\). En remplaçant, la somme devient \(\sum_i \|R\,\tilde p_i - \tilde q_i\|^2 = \sum \|\tilde p_i\|^2 + \sum\|\tilde q_i\|^2 - 2\sum \tilde q_i^\top R\tilde p_i\) où les \(\tilde{}\) désignent les points centrés : minimiser revient à maximiser \(\sum_i \tilde q_i^\top R \tilde p_i = \mathrm{tr}(RH)\). Or \(\mathrm{tr}(RH) = \mathrm{tr}(R\,U\Lambda V^\top) = \mathrm{tr}(\underbrace{V^\top R U}_{=\,Z}\,\Lambda) = \sum_i Z_{ii}\, \lambda_i\) avec \(Z\) orthogonale, donc \(Z_{ii} \leq 1\) et \(\lambda_i \geq 0\) donnent \(\mathrm{tr}(RH) \leq \sum_i \lambda_i\), atteint pour \(Z = I\), i.e. \(R = VU^\top\). La correction de déterminant négatif maximise sous la contrainte \(\det R = +1\) en annulant \(Z_{33}\) (plus petite valeur singulière). ∎
Proposition 10.4 — ICP : l'algorithme et sa convergence locale ICP (Iterative Closest Point, Besl-McKay 1992) alterne : (1) appariement : chaque point de \(P\) est associé à son plus proche voisin dans \(Q\) (kd-tree, \(O(n\log n)\)) ; (2) alignement : transforme rigide optimale des couples (théorème 10.3) ; (3) application — jusqu'à convergence.
La fonction objectif \(E(R, t) = \sum_i \|R p_i + t - \mathrm{nn}_Q(Rp_i + t)\|^2\) décroît à chaque itération : l'étape (1) ne peut qu'améliorer (ou laisser intact) chaque terme en choisissant le plus proche voisin courant, et l'étape (2) minimise exactement la somme sur ces appariements fixés. Combinaison d'une suite décroissante minorée (par 0) : convergence — vers un minimum local, fonction de l'initialisation. ∎
Remèdes : initialisation grossière (GPS, descripteurs globaux, RANSAC sur des quadruplets), appariements rejetés (distance > quantile, normales incompatibles), variante point-plan (minimiser les distances aux plans tangents — linéarisée, elle donne un moindres carrés 6×6 plus précis), ou formulations robustes : ICP tronqué, robust optimal transport (cf. ci-dessous).
Exemple 10.5 — ICP et appariement en Python 
import numpy as np
from scipy.spatial import cKDTree

def best_rigid_transform(P, Q):            # theoreme 10.3 (Kabsch)
    cp, cq = P.mean(0), Q.mean(0)
    H = (P - cp).T @ (Q - cq)              # 3x3
    U, S, Vt = np.linalg.svd(H)
    d = np.sign(np.linalg.det(Vt.T @ U.T))
    R = Vt.T @ np.diag([1, 1, d]) @ U.T
    return R, cq - R @ cp

def icp(P, Q, iters=50, tol=1e-7):
    tree = cKDTree(Q); R = np.eye(3); t = np.zeros(3); prev = np.inf
    for _ in range(iters):
        d, idx = tree.query(P @ R.T + t)          # (1) appariement
        Rk, tk = best_rigid_transform(P, Q[idx])  # (2) Kabsch
        R, t = Rk @ R, Rk @ t + tk                # (3) accumulation
        err = np.mean(d**2)
        if prev - err < tol: break
        prev = err
    return R, t, np.sqrt(err)

# test synthetique : rotation 25 degres + bruit 1 cm
rng = np.random.default_rng(0)
src = rng.normal(size=(3000, 3)) * [10, 10, 1]    # "sol" bruite
a = np.deg2rad(25)
Rt = np.array([[np.cos(a), -np.sin(a), 0],
               [np.sin(a),  np.cos(a), 0],
               [0, 0, 1]])
dst = src @ Rt.T + [2, -1, 0] + rng.normal(scale=.01, size=src.shape)
R, t, rms = icp(src, dst)
print("erreur d'angle (deg):", np.rad2deg(np.arccos((np.trace(R.T @ Rt)-1)/2)))
Note — ICP et transport optimal Remplacer « plus proche voisin » par un appariement global qui minimise un coût de transport, c'est reformuler le recalage comme un problème de transport optimal (module M1P2 du même master, ch. 1-2) : la distance de Wasserstein compare les nuages comme mesures, pas comme points étiquetés — insensible aux densités différentes, robuste au bruit avec des coûts concaves. C'est la voie explorée par la littérature récente de recalage par OT robuste (RobOT, NeurIPS 2021 ; transport partiel pour nuages incomplets). Le même formalisme réapparaît pour comparer des histogrammes de descripteurs ou des cartes de profondeur : un langage commun aux ch. 6-10.
Proposition 10.6 — Représenter un nuage pour l'apprentissage Trois familles d'entrée pour les réseaux : (i) volumes (voxeliser en grille 3D — convolutions 3D possibles mais coût cubique ; arbres creux/octrees pour le pire) ; (ii) points bruts (PointNet : MLP par point + max global = fonction symétrique, invariance par permutation ; ses successeurs ajoutent un voisinage local) ; (iii) images de portée (range images : projeter le nuage sur une image sphérique dont chaque pixel code la distance — les CNN 2D s'appliquent alors tels quels, cf. LU-Net du ch. 11). Le choix est un compromis mémoire/précision/ vitesse — sur \(10^9\) points, la gamme (iii) est imbattable et alimente les systèmes temps réel des véhicules autonomes.
