0. Rappels : probabilités, réseaux, ELBO

Ce module construit tout l'édifice des modèles génératifs multimodaux sur quatre briques : les gaussiennes (le seul objet probabiliste dont la diffusion aura besoin), la borne inférieure de log-vraisemblance (ELBO), le trick de reparamétrage (rendre l'échantillonnage différentiable) et les architectures encodeur-décodeur (CNN, U-Net, attention). Nous les démontrons ici une fois pour toutes : elles seront réutilisées dans les cinq chapitres suivants.

Rappels des modules précédents
  • ELBO / VAE (Deep Learning, ch. 7) : \(\mathbb{E}_q[\log p_\theta(x\mid z)] - \mathrm{KL}(q_\phi(z\mid x) \| p(z))\) ; reparametrization trick ;
  • CNN : convolutions, U-Net (skip connections encodeur-décodeur) ;
  • Transformers & cross-attention : requêtes image, clés/valeurs texte — le mécanisme qui « injecte » le prompt dans un générateur ;
  • Gaussiennes : bruit additif, \(\mathcal{N}(0,1)\), reparamétrage — la diffusion n'est qu'une chaîne de bruits gaussiens (Refresher Statistics, chaînes) ;
  • EM / ACP (module Machine Learning) : le VAE est un cousin probabiliste de l'ACP — maximisation alternée d'une borne inférieure, axes principaux = directions du latent.
Propriété 0.1 — Somme de gaussiennes indépendantes Si \(X \sim \mathcal{N}(\mu_1, \sigma_1^2)\) et \(Y \sim \mathcal{N}(\mu_2, \sigma_2^2)\) sont indépendantes, alors \(X + Y \sim \mathcal{N}(\mu_1 + \mu_2,\ \sigma_1^2 + \sigma_2^2)\). Les moyennes s'additionnent, les variances s'additionnent — c'est cette règle qui rend la diffusion « calculable en un seul pas » (chapitre 3).
Preuve (fonction caractéristique). Pour \(Z \sim \mathcal{N}(\mu, \sigma^2)\), on calcule \(\varphi_Z(t) = \mathbb{E}[e^{itZ}] = e^{i\mu t - \frac{1}{2}\sigma^2 t^2}\) (intégrale gaussienne après complétion du carré). Par indépendance, \(\varphi_{X+Y}(t) = \varphi_X(t)\,\varphi_Y(t) = e^{i(\mu_1+\mu_2)t - \frac{1}{2}(\sigma_1^2+\sigma_2^2)t^2}\), qui est la fonction caractéristique d'une \(\mathcal{N}(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)\) ; le théorème d'unicité de Lévy conclut. ∎
Théorème 0.2 — ELBO (Jensen) Pour tout \(x\), toute distribution de proposition \(q_\phi(z)\) à support contenant celui de \(p_\theta(z \mid x)\) : $$\log p_\theta(x) \;=\; \mathrm{ELBO}_\phi(x) + \mathrm{KL}\big(q_\phi(z) \,\|\, p_\theta(z\mid x)\big) \;\ge\; \mathrm{ELBO}_\phi(x),$$ $$\mathrm{ELBO}_\phi(x) = \mathbb{E}_{q_\phi}\big[\log p_\theta(x \mid z)\big] - \mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big).$$ L'écart entre \(\log p_\theta(x)\) et la borne est exactement la KL : maximiser l'ELBO rapproche \(q_\phi\) du vrai posterior et maximise la vraisemblance.
On écrit l'intégrale comme une espérance sous \(q_\phi\), puis on applique la concavité du logarithme (inégalité de Jensen : \(\log \mathbb{E}[U] \ge \mathbb{E}[\log U]\)) : $$\log p_\theta(x) = \log \int p_\theta(x\mid z)\, p(z)\, dz = \log \mathbb{E}_{q_\phi}\!\left[\frac{p_\theta(x\mid z)\,p(z)}{q_\phi(z\mid x)}\right] \ge \mathbb{E}_{q_\phi}\!\left[\log \frac{p_\theta(x\mid z)\,p(z)}{q_\phi(z\mid x)}\right] = \mathrm{ELBO}_\phi(x).$$ De plus \(\log \frac{p_\theta(x\mid z)p(z)}{q_\phi(z)} = \log p_\theta(x) + \log\frac{p_\theta(z\mid x)}{q_\phi(z)}\) ; en prenant l'espérance sous \(q_\phi\), le second terme devient \(-\mathrm{KL}(q_\phi \| p_\theta(z\mid x))\), d'où la décomposition exacte. ∎
Définition 0.3 — Reparametrization trick Échantillonner \(z \sim q_\phi(z\mid x) = \mathcal{N}(\mu_\phi(x), \mathrm{diag}\,\sigma_\phi^2(x))\) bloque le gradient (\(\nabla_\phi\) d'un tirage aléatoire). On écrit plutôt $$z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I),$$ de sorte que \(\nabla_\phi\, \mathbb{E}_{q_\phi}[f_\phi(z)] = \mathbb{E}_{\epsilon}\big[\nabla_\phi f_\phi(\mu_\phi(x) + \sigma_\phi(x)\odot\epsilon)\big]\) : la loi du bruit ne dépend plus de \(\phi\), le gradient passe sous l'espérance. Le même trick rendra la diffusion différentiable de bout en bout.
Proposition 0.4 — KL entre gaussiennes diagonales (formule fermée) Pour \(q = \mathcal{N}(\mu_1, \mathrm{diag}\,\sigma_1^2)\) et \(p = \mathcal{N}(\mu_2, \mathrm{diag}\,\sigma_2^2)\) : $$\mathrm{KL}(q \| p) = \tfrac{1}{2}\sum_i \left[\frac{\sigma_{1,i}^2 + (\mu_{1,i}-\mu_{2,i})^2}{\sigma_{2,i}^2} + \log\frac{\sigma_{2,i}^2}{\sigma_{1,i}^2} - 1\right].$$ Tout l'entraînement des VAE (et de la diffusion, ch. 3) repose sur le fait que cette quantité s'évalue en forme fermée. La démonstration (calcul direct d'espérance) est l'objet de l'exercice 3, corrigé.

Réseaux. Le CNN applique localement le même filtre ; son champ réceptif croît avec la profondeur, ce qui échange de la résolution contre du contexte. Le U-Net couple un encodeur (sous-échantillonnage, sémantique globale) et un décodeur (sur-échantillonnage, précision locale) par des skip connections qui court-circuitent le goulot d'étranglement : c'est l'architecture de débruitage de référence pour la diffusion. L'attention croisée injecte le texte : $$\mathrm{Attn}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V, \qquad Q = W_Q\,h_{\text{image}}, \quad K = W_K\, e_{\text{texte}}, \quad V = W_V\, e_{\text{texte}},$$ où \(h_{\text{image}}\) sont les activations spatiales du débruiteur et \(e_{\text{texte}}\) les tokens du prompt : chaque position de l'image « interroge » le texte (cf. module Deep Learning, ch. 6).

1. VAE et espaces latents

Définition 1.1 — VAE conditionnel & hiérarchique Conditionner la génération : \(p_\theta(x \mid c)\) avec \(c\) une classe, un texte (encodé), une autre modalité. Les VAE hiérarchiques (HiVAE) empilent des latents \(p(z_1 \mid z_2)\, p(z_2 \mid z_3)\dots\) ; les VQ-VAE quantifient le latent en un dictionnaire appris (codes discrets — l'ancêtre des tokens d'images) ; VQ-VAE-2 atteint la fidélité d'image avant la diffusion.
Ce que le latent achète Compresser \(512 \times 512 \times 3\) en \(64 \times 64\) latents = \(\times 64\) moins de calculs ; tous les gros modèles génératifs d'images (Stable Diffusion, DALL·E 2/3) génèrent en espace latent — l'autoencodeur (léger) et le générateur (lourd) sont découplés. Le même principe s'applique aux graphes : graphe latent, codes discrets (module Graph ML, ch. 7).
Théorème 1.2 — Décomposition de l'ELBO : reconstruction + régularisation $$\mathrm{ELBO}_\phi(x) = \underbrace{\mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x \mid z)\big]}_{\text{reconstruction}} \;-\; \underbrace{\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{régularisation du latent}}.$$ Interprétation des deux forces : le premier terme demande un \(z\) qui explique \(x\) (auto-encodage), le second demande un \(z\) typique sous le prior. La tension entre les deux structure l'espace latent : sans KL, \(q\) peut mémoriser (régions « trous » non couvertes par le prior) ; sans reconstruction, \(z\) ne code rien.
La décomposition est déjà la forme obtenue au thm. 0.2 ; ce qu'il faut voir, c'est d'où vient chaque terme. Développons \(\mathbb{E}_{q}\big[\log \frac{p_\theta(x\mid z)\,p(z)}{q_\phi(z\mid x)}\big]\) : $$\mathbb{E}_q[\log p_\theta(x\mid z)] + \mathbb{E}_q[\log p(z)] - \mathbb{E}_q[\log q_\phi(z\mid x)] = \mathbb{E}_q[\log p_\theta(x\mid z)] - \mathrm{KL}(q_\phi \| p),$$ où l'on reconnaît la définition \(\mathrm{KL}(q\|p) = \mathbb{E}_q[\log q - \log p]\). Quand \(p_\theta(x\mid z)\) est une gaussienne diagonale de moyenne \(D_\theta(z)\) et de variance fixe \(\sigma^2\), le terme de reconstruction vaut \(-\frac{1}{2\sigma^2}\|x - D_\theta(z)\|^2 + \mathrm{cste}\) : la « MSE de reconstruction » des TP n'est que le négatif d'une log-vraisemblance gaussienne. Quand \(q_\phi\) et \(p\) sont gaussiens, le second terme se ferme par la prop. 0.4. ∎
Posterior collapse : diagnostic et remèdes Le décodeur (souvent un transformer autorégressif) devient si puissant qu'il ignore \(z\) : \(q_\phi(z\mid x) \to p(z)\), la KL tombe vers 0 et le VAE dégénère en modèle non conditionnel (le latent « s'effondre »). Causes : décodeur autorégressif fort, KL dominante en début d'entraînement, prior trop simple.
  • KL annealing : pondérer la KL par un coefficient qui monte lentement de 0 à 1 — laisser la reconstruction s'installer d'abord ;
  • \(\beta\)-VAE (Higgins et al., 2017) : maximiser \(\mathbb{E}[\log p(x\mid z)] - \beta\,\mathrm{KL}\) avec \(\beta > 1\) force un latent démêlé (une direction = un facteur de variation) ; en pratique contre le collapse, on utilise plutôt \(\beta < 1\) ;
  • Free bits : ne pénaliser la KL par dimension qu'au-delà d'un budget \(\lambda\) : \(\max(\mathrm{KL}_j, \lambda)\) — chaque dimension reçoit un « droit d'information » gratuit, ce qui l'empêche de mourir.
Construction 1.3 — VQ-VAE : quantifier le latent L'encodeur produit \(z_e(x) \in \mathbb{R}^{H \times W \times D}\) ; un codebook \(\{e_1, \dots, e_K\} \subset \mathbb{R}^D\) est appris ; on quantifie chaque position par le plus proche code : $$z_q(x) = e_k, \qquad k = \arg\min_j \|z_e(x) - e_j\|_2.$$ L'argmin n'est pas différentiable. On utilise l'estimateur straight-through (copie du gradient) et la loss totale : $$\mathcal{L} = \log p_\theta\big(x \mid z_q\big) + \big\|\mathrm{sg}[z_e] - e\big\|_2^2 + \beta\,\big\|z_e - \mathrm{sg}[e]\big\|_2^2,$$ où \(\mathrm{sg}\) est l'opérateur stop-gradient.
Pourquoi cette loss à trois termes ? (i) La reconstruction doit être fonction des codes quantifiés \(z_q\) — mais \(\nabla_{z_e} z_q = 0\) (argmin) : on définit \(\frac{\partial \mathcal{L}}{\partial z_e} \mathrel{:=} \frac{\partial \mathcal{L}}{\partial z_q}\) (straight-through) ; l'estimateur est biaisé mais empiriquement efficace. (ii) Le terme \(\|\mathrm{sg}[z_e] - e\|^2\) est quadratique en \(e\) (les codes migrent vers les encodages produits) ; le stop-gradient empêche, symétriquement, l'encodeur de bouger. (iii) Le terme \(\beta\|z_e - \mathrm{sg}[e]\|^2\) fait l'inverse : tire l'encodeur vers les codes. Les deux termes « pignons » (commitment) synchronisent encodeur et dictionnaire, le premier terme entraîne le décodeur ; ensemble ils réalisent un K-means continu dans la boucle d'apprentissage. ∎

Hiérarchie et échantillonnage. Dans un HiVAE, l'ELBO devient $$\mathbb{E}_{q(z_1, z_2\mid x)}\big[\log p_\theta(x \mid z_1) + \log p(z_1 \mid z_2) + \log p(z_2) - \log q_\phi(z_1 \mid x, z_2) - \log q_\phi(z_2 \mid x)\big],$$ chaque étage comprimant le précédent (les échelles « basses » gouvernent la composition, les « hautes » les détails — exactement les niveaux d'un U-Net). Pour générer : échantillonner \(z \sim \mathcal{N}(0, I)\) (ou les niveaux du prior appris, comme dans VQ-VAE-2), puis décodage en un seul passage réseau ; les traversées latentes (interpoler \(z\) entre deux images) sont le test visuel de la continuité de l'espace appris.

import torch

class MiniVAE(torch.nn.Module):
    """VAE convolutif minimal pour MNIST-like (28x28)."""
    def __init__(self, d=8):
        super().__init__()
        self.enc = torch.nn.Sequential(            # x: (B,1,28,28)
            torch.nn.Conv2d(1, 32, 4, 2, 1), torch.nn.ReLU(),   # 14x14
            torch.nn.Conv2d(32, 64, 4, 2, 1), torch.nn.ReLU(),  # 7x7
            torch.nn.Flatten(), torch.nn.Linear(64*7*7, 2*d))
        self.dec = torch.nn.Sequential(
            torch.nn.Linear(d, 64*7*7), torch.nn.Unflatten(1, (64, 7, 7)),
            torch.nn.ConvTranspose2d(64, 32, 4, 2, 1), torch.nn.ReLU(),
            torch.nn.ConvTranspose2d(32, 1, 4, 2, 1), torch.nn.Sigmoid())
    def forward(self, x):
        h = self.enc(x); mu, logvar = h.chunk(2, dim=1)
        z = mu + torch.exp(0.5*logvar) * torch.randn_like(mu)   # reparametrization
        return self.dec(z), mu, logvar

def vae_loss(x, xh, mu, logvar, beta=1.0):
    rec = torch.nn.functional.binary_cross_entropy(
        xh, x, reduction="sum") / x.size(0)                      # reconstruction
    kl  = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / x.size(0)
    return rec + beta * kl                                      # ELBO (prop. 0.4)

2. GAN : adversaire, équilibre, Wasserstein

Définition 2.1 — Jeu minimax et ses raffinements $$\min_G \max_D\ V(D, G) = \mathbb{E}_{x \sim p_{\mathrm{data}}}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$$ \(D\) classifie « vrai/faux », \(G\) forge des contrefaçons. En pratique on utilise la forme non-saturée \(\max_G \mathbb{E}_z[\log D(G(z))]\) (mêmes équilibres, gradients plus forts en début d'entraînement), ou des pertes alternatives : least-squares GAN, hinge. Version conditionnelle : \(G(z, c)\), \(D(x, c)\) — Pix2Pix (image à image avec contrainte de reconstruction L1).
Théorème 2.2 — Équilibre du jeu
  1. Pour \(G\) fixé, le discriminateur optimal est $$D^*(x) = \frac{p_{\mathrm{data}}(x)}{p_{\mathrm{data}}(x) + p_g(x)}.$$
  2. En ce \(D^*\), \(V(G^*) = -\log 4 + 2\,\mathrm{JS}(p_{\mathrm{data}} \| p_g)\) ; le minimum global est atteint uniquement pour \(p_g = p_{\mathrm{data}}\) : à l'équilibre, le générateur reproduit exactement la loi des données.
(i) Le problème est séparable point par point : pour chaque \(x\), maximiser \(u(D) = p_{\mathrm{data}}(x)\log D + p_g(x)\log(1-D)\) sur \(D \in (0,1)\). La dérivée \(u'(D) = \frac{p_{\mathrm{data}}}{D} - \frac{p_g}{1-D}\) s'annule en \(D^* = \frac{p_{\mathrm{data}}}{p_{\mathrm{data}} + p_g}\) (maximum, car \(u \to -\infty\) aux bords). (ii) On substitue : \(V(D^*) = p\log\frac{p}{p+q} + q\log\frac{q}{p+q}\). En soustrayant et ajoutant \((p+q)\log\frac{1}{2}\), on obtient $$V(D^*) = -\log 4 + \Big[p\log\frac{2p}{p+q} + q\log\frac{2q}{p+q}\Big] = -\log 4 + 2\,\mathrm{JS}(p\|q),$$ où \(\mathrm{JS}(p\|q) = \tfrac12\mathrm{KL}(p\|\tfrac{p+q}{2}) + \tfrac12\mathrm{KL}(q\|\tfrac{p+q}{2})\) (définition ; c'est une KL vers une loi de probabilité, donc toujours finie). Comme \(\mathrm{JS} \ge 0\) avec égalité ssi \(p = q\), le minimax vaut \(-\log 4\), atteint seulement quand le générateur égalise la loi cible. ∎
Exemple 2.3 — Cas gaussien Si \(p_{\mathrm{data}} = \mathcal{N}(\mu, \sigma^2)\) et \(p_g = \mathcal{N}(\mu_g, \sigma_g^2)\), la formule (i) donne un \(D^*\) explicite (via les densités) : le classifieur optimal est une fonction sigmoïde d'un score quadratique — deux gaussiennes se séparent par une frontière quadratique. La rétropropagation de \(\log D^*(G(z))\) pousse \(\mu_g \to \mu\) et \(\sigma_g^2 \to \sigma^2\) : c'est la version jouet (exercice 4) du théorème.
Mode collapse : analyse et mitigations Le théorème décrit l'équilibre global, mais le jeu est non coopératif : \(G\) peut trouver rentable de produire en boucle une image très trompeuse (une mode de la distribution), puis basculer vers une autre — oscillations et perte de diversité. Le gradient de \(G\) ne « voit » que les points générés : les modes jamais échantillonnés ne sont jamais corrigés. Mitigations :
  • Minibatch discrimination : pour chaque \(x_i\) du batch, ajouter à \(D\) des features de similarité intra-batch \(o(x_i) = \sum_{j \ne i} \exp\!\big(-\|f(x_i) - f(x_j)\|\big)\,T_{ij}\) — le discriminateur détecte les batchs « tous identiques » ;
  • Unrolled GAN : \(G\) est entraîné contre le \(D\) qu'il va affronter (k pas d'anticipation du discriminateur), ce qui supprime les cycles purs de poursuite ;
  • Monitoring LLGA : diversité intra-batch (LPIPS moyen), FID sur grandes cohortes — le diagnostic industriel du ch. 8.
Construction 2.4 — WGAN : Wasserstein au secours de la JS Quand les supports de \(p\) et \(q\) sont disjoints ou « presque », JS est constante (valeur \(\log 2\)) et son gradient est nul : plus de signal d'apprentissage. La distance de Wasserstein \(W_1\), elle, reste informative. Par la dualité de Kantorovich–Rubinstein (module OT) : $$W_1(p, q) = \sup_{\|f\|_L \le 1}\ \mathbb{E}_{p}[f(x)] - \mathbb{E}_{q}[f(x)],$$ d'où l'apprentissage adversarial \(\min_G \max_{\|D\|_L \le 1} \mathbb{E}_{p}[D] - \mathbb{E}_{q}[D]\) : \(D\) devient un critique 1-Lipschitz, la loss est continue en les paramètres de \(G\) même à supports disjoints.
Esquisse de la dualité : pour toute \(f\) 1-Lipschitz, \(\mathbb{E}_p[f] - \mathbb{E}_q[f] \le \mathbb{E}_{\gamma}[|x - y|] \le W_1\) (couplage \(\gamma\)), d'où \(\sup \le W_1\) ; la partie difficile (l'égalité, atteinte par un potentiel de Kantorovich optimal) relève de la dualité lagrangienne du transport — hors programme, voir le module OT. Contrainte Lipschitz en pratique : gradient penalty. Le clipping des poids (WGAN original) force une Lipschitzité trop brutale. On pénalise l'écart de la norme du gradient à 1 sur les interpolations \(\tilde x = \epsilon x + (1-\epsilon)\hat x\) entre donnée \(x\) et génération \(\hat x\) : $$\mathcal{L}_{\mathrm{GP}} = \lambda\,\big(\|\nabla_{\tilde x} D(\tilde x)\|_2 - 1\big)^2.$$ Pourquoi \((\|\nabla D\| - 1)^2\) et non \(\max(0, \|\nabla D\| - 1)\) : pénaliser aussi les gradients trop petits évite que \(D\) ne s'aplatisse (perte de signal) ; pourquoi les interpolations : le supremum du dual « vit » le long des segments de transport entre les deux distributions — c'est là que la contrainte compte. ∎
Architecture 2.5 — StyleGAN : du bruit au style
  1. Mapping network : \(w = m(z)\), MLP 8 couches — \(w\) vit dans un espace « désentrelacé » où les directions correspondent à des attributs ;
  2. AdaIN (adaptive instance norm) : à chaque couche du générateur, le style module la normalisation d'instance : $$\mathrm{AdaIN}(x, w) = \sigma(w_s)\,\frac{x - \mu(x)}{\sigma(x)} + w_b,$$ où \((w_s, w_b)\) sont des transformations affines de \(w\) propres à la couche — chaque résolution reçoit son style ;
  3. Style mixing : lors de l'entraînement, injecter deux \(w\) différents selon les couches (l'un pour les résolutions grossières, l'autre pour les fines) — régularise le mapping et découvre la hiérarchie structure/texture ;
  4. Truncation trick : à la génération, \(w' = \bar w + \psi\,(w - \bar w)\) avec \(\psi < 1\), \(\bar w\) la moyenne du mapping — on reste dans les hautes densités : fidélité accrue, diversité réduite (exercice 10).
CycleGAN : la consistance de cycle, démontrée utile Sans paires d'entraînement, traduire \(X \to Y\) par \(G\) et \(Y \to X\) par \(F\) avec $$\mathcal{L}_{\mathrm{cyc}} = \mathbb{E}_x\big[\|F(G(x)) - x\|_1\big] + \mathbb{E}_y\big[\|G(F(y)) - y\|_1\big].$$ Pourquoi c'est la bonne contrainte. La loss adverse seule autorise \(G(x) = y_0\) pour tout \(x\) (une seule image très « réaliste » trompe \(D\) : collapse trans-domaine, et le contenu de \(x\) est perdu). Si \(F(G(x)) = x\) pour tout \(x\) du support, alors \(G\) est injective : elle ne peut ni effondrer les modes, ni détruire l'information de contenu — elle ne peut changer que ce que \(F\) sait restaurer. La consistance de cycle est une contrainte d'information-preserving rendue différentiable ; combinée à la perte adverse (qui impose le style du domaine cible), elle réalise la traduction. Le terme L1 (plutôt que L2) privilégie la netteté (moins de moyennage flou).
Évaluation : IS et FID Inception Score : \(\mathrm{IS} = \exp\big(\mathbb{E}_x\,\mathrm{KL}(\,p(y\mid x)\,\|\,p(y)\,)\big)\) — chaque image doit être nettement classifiable (\(p(y|x)\) piquée) et l'ensemble divers (\(p(y)\) étalé). FID : on ajuste une gaussienne sur les features Inception des vraies \((\mu_r, \Sigma_r)\) et des générées \((\mu_g, \Sigma_g)\), puis $$\mathrm{FID} = \|\mu_r - \mu_g\|^2 + \mathrm{tr}\big(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2}\big) \;=\; W_2^2\ \text{(Bures) entre les deux gaussiennes}$$ — une application directe de la distance de Wasserstein-Bures du module OT ; analyse des biais d'échantillonnage au ch. 8. Pourquoi la diffusion a fini par dominer : perte stable (simple MSE de débruitage), pas d'équilibre à maintenir, diversité naturelle — mais les GAN restent imbattables en vitesse (1 pas) et vivent dans la super-résolution et l'éditing.

3. Diffusion : DDPM et score matching

Modèle 3.1 — Processus avant (bruitage) Chaîne de Markov qui ajoute du bruit gaussien : $$q(x_t \mid x_{t-1}) = \mathcal{N}\big(\sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t I\big), \qquad t = 1, \dots, T,$$ avec \(\beta_t\) croissant. Propriété clé (composition des gaussiennes) : $$q(x_t \mid x_0) = \mathcal{N}\big(\sqrt{\bar\alpha_t}\, x_0,\ (1 - \bar\alpha_t) I\big), \qquad \alpha_t = 1 - \beta_t,\quad \bar\alpha_t = \prod_{s = 1}^{t}\alpha_s.$$ Pour \(T = 1000\), \(\bar\alpha_T \approx 0\) : l'image est devenue du bruit pur.
Par récurrence sur \(t\). Initialisation : \(t = 1\) : \(x_1 = \sqrt{\alpha_1}\,x_0 + \sqrt{1 - \alpha_1}\,\epsilon\), donc \(q(x_1 \mid x_0) = \mathcal{N}(\sqrt{\bar\alpha_1}x_0,\ (1-\bar\alpha_1)I)\) par définition. Hérédité : supposons \(x_{t-1} \mid x_0 \sim \mathcal{N}(\sqrt{\bar\alpha_{t-1}}\,x_0,\ (1-\bar\alpha_{t-1})I)\). Alors $$x_t = \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon, \qquad \epsilon \perp x_{t-1} \mid x_0.$$ Par la propriété 0.1 (somme de gaussiennes indépendantes) : moyenne \(\sqrt{\alpha_t}\cdot\sqrt{\bar\alpha_{t-1}}\,x_0 = \sqrt{\bar\alpha_t}\,x_0\) (car \(\alpha_t \bar\alpha_{t-1} = \bar\alpha_t\)) ; variance \(\alpha_t(1-\bar\alpha_{t-1}) + (1-\alpha_t) = 1 - \bar\alpha_{t-1} + \alpha_t\bar\alpha_{t-1} = 1 - \bar\alpha_t\). ∎
Variance schedule : linéaire ou cosinus Le choix des \(\beta_t\) fixe la vitesse de destruction. Linéaire (\(\beta_t: 10^{-4} \to 0{,}02\), DDPM original) : les hautes fréquences meurent trop vite, la fin de chaîne est inutilement bruitée. Cosine (Nichol & Dhariwal, 2021) : $$\bar\alpha_t = \frac{f(t)}{f(0)}, \qquad f(t) = \cos^2\!\left(\frac{t/T + 0{,}008}{1{,}008}\cdot\frac{\pi}{2}\right),$$ qui donne une décroissance en pente douce de \(\bar\alpha_t\), efficace aussi en basse résolution. Règle pratique : le schedule doit détruire l'information uniformément sur les échelles de l'image.
Modèle 3.2 — Processus inverse appris et ELBO par pas $$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}\big(\mu_\theta(x_t, t),\ \sigma_t^2 I\big), \qquad p(x_T) = \mathcal{N}(0, I),$$ et l'entraînement se réduit à une simple MSE : $$\mathcal{L} = \mathbb{E}_{x_0, \epsilon, t}\big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\big], \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1 - \bar\alpha_t}\,\epsilon.$$
Étape 1 — télescopage. En appliquant le thm. 0.2 à la chaîne \(p_\theta(x_{0:T})\) avec \(q(x_{1:T}\mid x_0)\), l'ELBO se réécrit (chaîne de Markov, produits télescopés) : $$-\mathrm{ELBO} = \mathrm{KL}\big(q(x_T\mid x_0)\,\|\,\mathcal{N}(0,I)\big) + \sum_{t=1}^{T}\mathbb{E}_q\!\left[\mathrm{KL}\big(q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\big)\right] = L_T + \sum_t L_{t-1}.$$ Étape 2 — posterior forward fermé. Par la règle de Bayes \(q(x_{t-1}\mid x_t, x_0) \propto q(x_t \mid x_{t-1})\,q(x_{t-1}\mid x_0)\) : produit de deux gaussiennes en \(x_{t-1}\), donc gaussien ; en complétant le carré : $$q(x_{t-1}\mid x_t, x_0) = \mathcal{N}\big(\tilde\mu_t(x_t, x_0),\ \tilde\beta_t I\big), \quad \tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\,\beta_t,\quad \tilde\mu_t = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,x_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t.$$ Étape 3 — chaque \(L_{t-1}\) est une KL de gaussiennes : fermée par la prop. 0.4. Si l'on fixe \(\sigma_t^2 = \tilde\beta_t\), il reste à aligner les moyennes : \(L_{t-1} = C + \frac{1}{2\sigma_t^2}\|\tilde\mu_t - \mu_\theta\|^2\). Étape 4 — paramétrisation en bruit. On choisit $$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t, t)\Big),$$ ce qui revient (en substituant \(x_0 = (x_t - \sqrt{1-\bar\alpha_t}\,\epsilon)/\sqrt{\bar\alpha_t}\) dans \(\tilde\mu_t\)) à demander \(\epsilon_\theta \approx \epsilon\) ; tous les facteurs restants sont des constantes connues absorbées dans la pondération. D'où la MSE unique du modèle 3.2 — un résultat remarquable : cinq lignes de théorie pour une loss d'une ligne. ∎
Théorème 3.3 — Prédire le bruit = prédire le score $$\epsilon = -\sqrt{1-\bar\alpha_t}\;\nabla_{x_t}\log p(x_t \mid x_0).$$ La MSE de débruitage est donc un score matching conditionnel : le réseau apprend \(\nabla_x \log p\) — exactement l'objet de la famille « score-based » de Song et al. (2021), qui unifie diffusion et SDE (ch. 4).
Pour une densité gaussienne \(p(x_t \mid x_0) = \mathcal{N}(x_t;\ m, s^2 I)\) avec \(m = \sqrt{\bar\alpha_t}\,x_0\), \(s^2 = 1 - \bar\alpha_t\), on calcule $$\nabla_{x_t}\log p(x_t\mid x_0) = \nabla_{x_t}\left[-\frac{\|x_t - m\|^2}{2s^2}\right] + 0 = -\frac{x_t - \sqrt{\bar\alpha_t}\,x_0}{1-\bar\alpha_t}.$$ Or \(x_t - \sqrt{\bar\alpha_t}\,x_0 = \sqrt{1-\bar\alpha_t}\,\epsilon\), donc \(\nabla_{x_t}\log p = -\epsilon/\sqrt{1-\bar\alpha_t}\), c'est-à-dire \(\epsilon = -\sqrt{1-\bar\alpha_t}\,\nabla_{x_t}\log p(x_t \mid x_0)\). ∎ 
import torch

def forward_diffusion(x0, t, alphas_bar, eps=None):
    """x_t = sqrt(a_bar_t) x0 + sqrt(1 - a_bar_t) * eps   (en une etape !)"""
    if eps is None: eps = torch.randn_like(x0)
    return alphas_bar[t].sqrt()[:, None, None, None] * x0 \
         + (1 - alphas_bar[t]).sqrt()[:, None, None, None] * eps, eps

# Entrainement (boucle typique DDPM) :
# x0 = batch d'images ; t ~ U{1..T}
xt, eps = forward_diffusion(x0, t, alphas_bar)
loss = torch.nn.functional.mse_loss(unet(xt, t), eps)   # predire le bruit
loss.backward()

La dérivation « chaîne de Markov → ELBO → KL par pas → MSE » que nous venons de faire est littéralement la même que celle du module Deep Learning ch. 7 pour le VAE — la diffusion est un VAE de profondeur \(T\) aux paramètres partagés.

4. Guidage, DDIM et diffusion latente

Guidage par classifieur (Dhariwal & Nichol, 2021) Par Bayes, \(\log p(x_t \mid y) = \log p(y \mid x_t) + \log p(x_t) - \log p(y)\) ; en prenant le gradient en \(x_t\), le dernier terme disparaît : $$\nabla_{x_t}\log p(x_t \mid y) = \nabla_{x_t}\log p(x_t) + \nabla_{x_t}\log p(y\mid x_t).$$ Via le thm. 3.3 (\(\epsilon \leftrightarrow -\sqrt{1-\bar\alpha_t}\,\nabla\log p\)), le débruiteur guidé est $$\tilde\epsilon = \epsilon_\theta(x_t, t) - \sqrt{1-\bar\alpha_t}\,\nabla_{x_t}\log p_\psi(y \mid x_t),$$ où \(p_\psi\) est un classifieur entraîné sur les \(x_t\) bruités. Puissant mais coûteux : il faut entraîner et évaluer un classifieur à chaque pas.
Théorème 4.1 — Classifier-free guidance (CFG) comme direction combinée Entraîner \(\epsilon_\theta(x_t, t, c)\) avec \(c\) parfois remplacé par \(\varnothing\) (dropout de condition, ~10 %) ; à la génération, extrapoler la direction conditionnelle : $$\tilde\epsilon = \epsilon_\theta(x_t, t, \varnothing) + w\big(\epsilon_\theta(x_t, t, c) - \epsilon_\theta(x_t, t, \varnothing)\big), \qquad w > 1.$$ Interprétation exacte : \(\tilde\epsilon\) est (à la constante \(\sqrt{1-\bar\alpha_t}\) près) le score de la distribution non normalisée $$p_w(x_t \mid c) \;\propto\; p(x_t \mid c)^{w}\, p(x_t)^{1-w}.$$
Toujours par Bayes, \(\nabla\log p(x_t\mid c) = \nabla\log p(c \mid x_t) + \nabla\log p(x_t)\) (le terme \(\log p(c)\) est constant en \(x_t\)). Le score de \(p_w\) vaut donc $$\nabla\log p_w = w\,\nabla\log p(x_t\mid c) + (1-w)\,\nabla\log p(x_t) = \nabla\log p(x_t) + w\big(\nabla\log p(x_t\mid c) - \nabla\log p(x_t)\big).$$ En remplaçant chaque score par le débruiteur correspondant (thm. 3.3), on obtient exactement la règle CFG : elle combine score inconditionnel + \(w\) fois la différence des scores. Pour \(w = 1\) on retrouve le score conditionnel ; pour \(w = 0\) l'inconditionnel ; pour \(w > 1\), la distribution effective \(p(x_t\mid c)^w p(x_t)^{1-w}\) sur-pondère le conditionnement : elle est plus « piquée » (fidélité, prompt-following accrus) et moins diverse. C'est le curseur « créativité » de tous les outils text-to-image — et un objet de recherche à part entière (cf. ch. 9, ordonnances \(w(t)\)). ∎
Construction 4.2 — DDIM : dériver une famille d'échantillonneurs DDPM fixe \(p_\theta(x_{t-1}\mid x_t)\) gaussien markovien. L'astuce DDIM : n'importe quel processus dont les marginales \(q(x_t \mid x_0)\) sont celles du modèle 3.1 et dont l'espérance s'écrit en fonction de \(\hat x_0\) conduit à la même loss. On pose la famille non-markovienne (paramétrée par \(\sigma_t\)) : $$q_\sigma(x_{t-1}\mid x_t, x_0) = \mathcal{N}\big(\sqrt{\bar\alpha_{t-1}}\,x_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\tfrac{x_t - \sqrt{\bar\alpha_t}\,x_0}{\sqrt{1-\bar\alpha_t}},\ \sigma_t^2 I\big).$$
  • \(\sigma_t = \sqrt{\tilde\beta_t}\) redonne DDPM (processus markovien d'origine) ;
  • \(\sigma_t = 0\) donne DDIM déterministe : même bruit initial \(x_T\) ⇒ même image (édition par trajectoire partagée, seed reproductible) ;
  • les marginales \(q(x_t\mid x_0)\) sont inchangées ⇒ la loss d'entraînement (\(\epsilon\)-MSE) est identique ; seul l'échantillonneur change ;
  • Sauts de pas : comme la trajectoire est déterministe, on peut sous-échantillonner \(\tau_1 < \tau_2 < \dots\) — 20 à 50 pas au lieu de 1000.
Vérifions la cohérence des marginales. D'après \(x_{t-1}\mid x_0 \sim \mathcal{N}(\sqrt{\bar\alpha_{t-1}}x_0,\ (1-\bar\alpha_{t-1})I)\) et la définition ci-dessus, la moyenne proposée s'écrit \(a\,x_0 + b\,(x_t - \sqrt{\bar\alpha_t}x_0)\) où \(b = \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}/\sqrt{1-\bar\alpha_t}\) ; conditionnellement à \(x_0\), \(x_t\) est gaussien centré en \(\sqrt{\bar\alpha_t}\,x_0\), donc la moyenne de \(x_{t-1}\) est bien \(\sqrt{\bar\alpha_{t-1}}\,x_0\) et sa variance \(b^2(1-\bar\alpha_t) + \sigma_t^2 = 1-\bar\alpha_{t-1}\) — la marginal voulue. On obtient ainsi une infinité d'échantillonneurs compatibles avec le même \(\epsilon_\theta\) entraîné. ∎
Point de vue SDE (Song et al., 2021) Quand \(T \to \infty\), le processus avant converge vers l'EDS \(dx = f(x, t)\,dt + g(t)\,dw\). Alors toute EDS a un compagnon déterministe de même lois marginales, la probability flow ODE : $$\frac{dx}{dt} = f(x, t) - \tfrac{1}{2}g(t)^2\,\nabla_x \log p_t(x).$$ Générer = intégrer cette ODE en sens inverse : c'est le pont théorique entre DDIM (déterministe) et les solveurs rapides ci-dessous.
  • Solveurs rapides : DPM-Solver traite la prob-flow ODE en séparant la partie linéaire (exactement intégrable : c'est un mouvement brownien bruité) de la partie non linéaire (le score) : schémas « exponentielle intégratrice » à 10–15 pas ; la distillation (consistent models, LCM, adversarial distillation — cf. ch. 9, Di[M]o) vise 1 à 4 pas ; la quantification (fp16, fp8) comprime le calcul — panorama repris en M2 ML Ops ;
  • Latent diffusion (Rombach et al., 2022) : autoencodeur (VQ ou KL, ch. 1) comprimant l'image d'un facteur 4–8 par côté, puis diffusion dans le latent ; le débruiteur (U-Net ou DiT) reçoit le prompt par cross-attention (déf. 0.3) aux niveaux où la résolution est maximale ; text encoder CLIP : c'est l'architecture de Stable Diffusion ;
  • ControlNet (Zhang et al., 2023) : conditionner par contours/profondeur/pose. On copie les blocs de l'encodeur du U-Net gelé (poids « verrouillés » \(\theta_{\mathrm{lock}}\)), on entraîne un clone \(\theta_c\) alimenté par la carte de condition \(c\), et l'on réinjecte $$y_c = \mathrm{ZeroConv}_c\big(\mathcal{F}(\cdot;\theta_c)\ +\ \mathcal{F}(x;\theta_{\mathrm{lock}})\big), \qquad y = y_{\mathrm{base}} + y_c,$$ où les zero-convolutions (convolutions 1×1 initialisées à zéro) garantissent qu'au pas 0, \(y_c = 0\) : ControlNet démarre comme le modèle inchangé et apprend uniquement la correction — même astuce « départ identité » que les résiduels nuls ;
  • Inpainting / img2img : bruiter l'image de départ jusqu'à un pas \(t_0\) (img2img : \(t_0\) règle la fidélité au départ ; fort = liberté), puis débruiter en imposant à chaque pas \(x_t = m\odot x_t^{\mathrm{généré}} + (1-m)\odot x_t^{\mathrm{bruité}}\) où \(m\) est le masque (règle de mélange de RePaint ; les variantes la relaxent en fin de chaîne).
DiT : quand le transformer remplace le U-Net L'image latente est découpée en patches \(2\times2\) « tokenisés » (comme un ViT) ; chaque bloc = self-attention sur les patches + MLP, modulé par le temps et la condition via adaLN-Zero : $$h \leftarrow h + \alpha_1\,\mathrm{Attn}\big(\gamma_1 h + \beta_1\big), \qquad h \leftarrow h + \alpha_2\,\mathrm{MLP}\big(\gamma_2 h + \beta_2\big),$$ où \((\gamma, \beta, \alpha)\) sont des fonctions affines de \(t_{\mathrm{emb}} + c_{\mathrm{emb}}\) et où les \(\alpha\) sont initialisés à zéro (chaque bloc démarre identité). La qualité croît régulièrement avec la profondeur, la largeur et le nombre de tokens — comportement « scaling law » propre aux transformers, et la base des générateurs vidéo modernes (ch. 7). 
# DiT minimal : un bloc modulate par le temps (adaLN-Zero)
class DiTBlock(torch.nn.Module):
    def __init__(self, d, n_heads):
        super().__init__()
        self.norm1 = torch.nn.LayerNorm(d, elementwise_affine=False)
        self.attn  = torch.nn.MultiheadAttention(d, n_heads, batch_first=True)
        self.norm2 = torch.nn.LayerNorm(d, elementwise_affine=False)
        self.mlp   = torch.nn.Sequential(torch.nn.Linear(d, 4*d), torch.nn.GELU(),
                                         torch.nn.Linear(4*d, d))
        self.mod = torch.nn.Sequential(torch.nn.SiLU(), torch.nn.Linear(d, 6*d))
        for m in [self.mod[-1]]:        # zero-init des alpha
            torch.nn.init.zeros_(m.weight); torch.nn.init.zeros_(m.bias)
    def forward(self, h, cond):                     # h: (B, N, d) patches
        g1, b1, a1, g2, b2, a2 = self.mod(cond).unsqueeze(1).chunk(6, dim=-1)
        h = h + a1 * self.attn(self.norm1(h)*g1 + b1, self.norm1(h)*g1 + b1,
                               self.norm1(h)*g1 + b1)[0]
        return h + a2 * self.mlp(self.norm2(h)*g2 + b2)

5. CLIP et l'alignement vision-langage

CLIP (Radford et al., 2021) Encoder conjointement images et textes dans un espace partagé : encodeur image (ViT) et encodeur texte (transformer) ; 400M paires (image, légende) collectées sur le web ; apprentissage contrastif (InfoNCE) sur des batchs massifs (jusqu'à 32k paires).
Loss contrastive : dérivation Dans un batch de \(N\) paires \((v_i, t_i)\) (images et textes encodés et normalisés), on calcule la matrice de similarité \(S_{ij} = \langle v_i, t_j\rangle / \tau\) (\(\tau\) la température). La loss InfoNCE symétrique : $$\mathcal{L} = -\frac{1}{2N}\sum_{i=1}^{N}\Big[\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ij}}} + \log\frac{e^{S_{ii}}}{\sum_j e^{S_{ji}}}\Big].$$ Chaque terme est une entropie croisée : sens image→texte, classifier la bonne légende parmi \(N\) candidates ; sens texte→image, la bonne image parmi \(N\) — deux softmax croisés sur la même matrice.
D'où vient cette forme ? Notons \(p_i(j) = \mathrm{softmax}(S_{i\cdot})_j\) la distribution « quelle légende pour l'image \(i\) ». Le premier terme est \(-\log p_i(i)\) : maximiser la probabilité d'appariement correct. En développant, $$-\log p_i(i) = -S_{ii} + \log\sum_j e^{S_{ij}} \;\ge\; -S_{ii} + \log e^{S_{ii}} = 0,$$ avec égalité ssi la diagonale domine toute la ligne : la loss pousse les paires positives vers le haut et les \(N-1\) négatives vers le bas (softmax = compétition softmax des similarités). Lien avec l'information mutuelle (Oord et al., 2018) : pour des négatifs tirés de la loi produit, on peut montrer l'encadrement $$I(v; t) \;\ge\; \log N - \mathcal{L}_N,$$ où \(I\) est l'information mutuelle entre modalités : InfoNCE maximise une borne inférieure de \(I\), de plus en plus serrée quand \(N\) grandit — d'où l'intérêt des batchs géants (démonstration complète : module NLP, ch. sur les representations contrastives). ∎
Température \(\tau\) (appris, initialisé à 0,07) recale les logits avant le softmax : \(\tau\) petit = distribution piquée = gradient concentré sur les négatifs les plus durs ; \(\tau\) grand = gradients uniformes (exercice 11). Le même paramètre apparaît dans les LLMs (module M2) — même rôle : doser la « sévérité » de la compétition.
Classification zero-shot : démonstration sur exemple Plus de têtes de classification fixes : les classes deviennent des textes. Pour classer une image parmi \(K\) libellés \(\ell_1, \dots, \ell_K\) : $$\hat k = \arg\max_k\ \big\langle v,\ t(\text{« a photo of a }\ell_k\text{ »})\big\rangle.$$ Exemple chiffré. Supposons un espace de dimension 3, trois classes {chien, chat, graphe} et les embeddings textes normalisés \(t_{\mathrm{chien}} = (0{,}8;\ 0{,}6;\ 0)\), \(t_{\mathrm{chat}} = (0{,}6;\ 0{,}8;\ 0)\), \(t_{\mathrm{graphe}} = (0;\ 0;\ 1)\). Pour une image \(v = (0{,}7;\ 0{,}5;\ 0{,}5)\) : produits scalaires \(0{,}56 + 0{,}30 = 0{,}86\) ; \(0{,}42 + 0{,}40 = 0{,}82\) ; \(0{,}5\). Le chien gagne (argmax) — sans qu'aucun classifieur n'ait jamais été entraîné sur ces classes : le transfert passe par le langage. Les prompts enrichis (« a photo of a \(\ell\), a type of pet ») agissent comme un prior textuel qui affine la position des prototypes.
CLIP, le couteau suisse multimodal CLIP sert partout : text encoder des diffusion models ; juge de similarité (R-Precision) ; retrieval image-texte ; modération. CLIPScore pour l'alignement texte-image : \(w\cdot\max(\cos(v, t), 0)\) avec \(w = 2{,}5\) (calibré sur jugements humains ; au-dessus de ~0,3, la légende « colle » à l'image). ImageBind (esquisse) : aligner six modalités (image, texte, audio, profondeur, thermique, IMU) en prenant l'image comme pivot : chaque modalité est contrastée avec l'image seulement, et par transitivité de l'espace partagé, audio ↔ texte émergent sans jamais avoir été appariés. Le pont avec le master : on peut aussi aligner graphes et texte dans un espace commun (embeddings GNN ↔ LLM, Graph ML ch. 8) — la « modalité » graphe entre dans la même machinerie d'alignement contrastif.

  • Prompt engineering, quantitativement : le prompt est un gradient sur le conditionnement : ajouter « photorealistic, 85 mm » déplace les embeddings et donc chaque pas de CFG. Effets mesurables : position (les premiers tokens pèsent plus), saturation (au-delà de ~50 tokens effectifs, rendement décroissant), pondération syntaxique « (mot:1.3) » = rescaling du logit d'attention pendant l'entraînement de l'inférence ;
  • Propmt négatif : la version générale du CFG à deux conditions — on remplace \(\varnothing\) par \(c_-\) : $$\tilde\epsilon = \epsilon_\theta(x_t,t,c_-) + w\big(\epsilon_\theta(x_t,t,c_+) - \epsilon_\theta(x_t,t,c_-)\big),$$ la direction négative est repoussée (thm. 4.1) : « flou, watermark, extra fingers » ;
  • Seeds : la graine fixe \(x_T\) (et les aléas du solveur) ; même seed + même prompt = même image en DDIM déterministe ; on balaye les seeds pour choisir la meilleure réalisation avant d'affiner le prompt — le flux de travail réel des praticiens ;
  • Coût d'inférence : (nombre de pas) × (coût du débruiteur) + décodage ; la latence gouverne le choix industriel (solveurs rapides, distillation 1-pas quand la diversité importe moins).

7. Au-delà de l'image : vidéo, 3D, LLMs multimodaux

  • Vidéo : latents spatio-temporels (le VAE comprime aussi le temps : 2–4 frames par token latent), le débruiteur entrelace attention spatiale (intra-frame) et attention temporelle (inter-frames) ; le coût croît comme (frames × résolution²), d'où les cascades (basse résolution → upsampling temporel) ; contrôle caméra et cohérence longue : sujets ouverts (cf. ch. 9, AKiRa) ;
  • Captioning / VQA : encodeur image (ViT) + décodeur texte (transformer) ; entraînés sur des paires ; les VQA graphiques (« quel est le plus court chemin ? ») — raisonnement visuel ;
  • LLMs multimodaux : comment faire « voir » un LLM ?
    • Projecteur linéaire (LLaVA) : \(h_v = W\,p_i + b\) sur chaque patch ViT — les « mots » de l'image sont projetés dans l'espace d'embedding du LLM : simple, efficace, beaucoup de tokens ;
    • Q-Former (BLIP-2) : 32 vecteurs-requêtes appris qui cross-attendent les features image et produisent 32 embeddings — un « résumé visuel » compact ; gèle le LLM pendant le pré-entraînement du pont ;
    • Protocole d'entraînement en deux temps : (1) alignment pretraining sur d'immenses corpus (image, légende) — apprendre la correspondance ; (2) instruction tuning multimodal — conversations, raisonner, répondre ;
    • Audio : tokens discrets de spectrogrammes ou de signaux (codec neural) injectés pareillement — même patron, autre modalité (module M2 pour la suite) ;
  • 3D : NeRF (esquisse) : un MLP \((x, d) \mapsto (\sigma, c)\) (densité, couleur) est optimisé par volume rendering différentiable : $$C(r) = \int_{t_n}^{t_f} T(t)\,\sigma\big(r(t)\big)\,c\big(r(t), d\big)\,dt, \qquad T(t) = \exp\!\Big(-\!\int_{t_n}^{t}\sigma\big(r(s)\big)ds\Big),$$ c'est-à-dire « l'opacité accumulée le long du rayon pondère les couleurs » ; les modèles génératifs 3D récents préfèrent la diffusion sur point clouds et meshes — discrétisation, opérateurs, correspondance : c'est exactement le programme du module M2 Geometric Deep Learning (lien direct) ;
  • World models : génération action-conditionnée de vidéos interactives (simulateurs appris ; lien module RL, monde latent ; mention Genie/Sora-like) ;
  • Données structurées génératives : text-to-graph (générer le schéma d'un réseau), graph-to-text (rapport depuis un graphe de connaissances) — l'intersection exacte des modules Graph ML et NLP ;
  • Agents multimodaux : percevoir (screenshot) et agir (clic, code) — les agents GUI combinent vision + LLM + outils (module RL, ch. 7).

Vicky Kalogeiton (CVLab — École Polytechnique / ÉCL ; ex-Inria Grenoble, équipe LEAR) travaille depuis sa thèse sur un programme cohérent : localiser et comprendre les objets et les actions dans les vidéos, puis, plus récemment, les générer. ACT-detector — Action Tubelet Detector (ICCV 2017) arXiv:1705.01861 — V. Kalogeiton, P. Weinzaepfel, V. Ferrari, C. Schmid. Problème. La détection d'action spatio-temporelle : pour chaque acteur, trouver où (boîtes par frame) et quand (segment temporel) il accomplit chaque action. Méthode. Étendre la détection par ancres (SSD) au domaine spatio-temporel : l'entrée est un tubelet — k frames consécutives — et le réseau régresse et score des ancres-cuboïdes 3D (position, échelle spatiale, durée), avec sur-échantillonnage des features frame-level pour les petits acteurs. Résultats. État de l'art de l'époque sur UCF-Sports, J-HMDB et UCF101 ; le formalisme tubelet a nourri le benchmark AVA. Positionnement dans le cours. C'est le «  avant  » des transformers : convolution 3D + ancres, quand les chapitres 3–4 de ce module décrivent le « après » (DiT) ; la notion d'échelle temporelle (pyramide de durées) annonce la pyramide temporelle des modèles vidéo-to-texte modernes.
Analysis of Classifier-Free Guidance Weight Schedulers (TMLR 2024) arXiv:2404.13040 — équipe CVLab. Problème. Le poids de guidance \(w\) du thm. 4.1 est constant dans la plupart des outils — pourquoi ne pas le faire varier au cours de l'échantillonnage ? Méthode. Analyse systématique d'ordonnances \(w(t)\) (croissantes, décroissantes, en cloche) sur diffusion text-to-image, avec mesures de fidélité (CLIPScore) et diversité.  Résultats. Des profils \(w(t)\) variables améliorent le compromis fidélité/diversité par rapport au \(w\) constant ; le behavior dépend du pas (début vs fin de chaîne). Positionnement. Le théorème 4.1 donne la théorie de la CFG à \(w\) fixe ; ce travail montre que le degré de liberté temporel est sous-exploité — exemple type de « ingénierie fine d'un hyperparamètre génératif », et sujet direct pour le projet du ch. 8.
Générer la vidéo : AKiRa et la distillation Di[M]o (2024–2025) AKiRa — arXiv:2412.14158 (CVPR 2025) et Di[M]o — arXiv:2503.15457 (ICCV 2025). AKiRa (Augmentation Kit on Rays) : un kit d'augmentation pour la génération vidéo optique — caméra sur des rayons, cohérence multi-vues ; la question du contrôle caméra (ch. 7) traitée côté entraînement. Di[M]o : distiller un modèle de diffusion masqué en un générateur un-pas — l'accélération du ch. 4 poussée à l'extrême (MDM → one-step generator). Positionnement. Les deux bouts de la chaîne valeur : qualité/cohérence (AKiRa) et latence (Di[M]o) — exactement les deux axes du compromis industriel du ch. 8. Mentionnons aussi Don't drop your samples! (CVPR 2024) : une perte de cohérence qui améliore l'entraînement des diffusion conditionnelles — le diagnostic de terrain des pathologies du ch. 3.

Corrigé 1 — Composition des bruits Récurrence : vrai en \(t=1\) par définition ; si \(x_{t-1}\mid x_0\) est gaussien de moyenne \(\sqrt{\bar\alpha_{t-1}}x_0\) et de variance \((1-\bar\alpha_{t-1})I\), alors \(x_t = \sqrt{\alpha_t}x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon\) avec \(\epsilon\) indépendant ; la prop. 0.1 (somme de gaussiennes indépendantes) donne moyenne \(\sqrt{\alpha_t\bar\alpha_{t-1}}x_0 = \sqrt{\bar\alpha_t}\,x_0\) et variance \(\alpha_t(1-\bar\alpha_{t-1}) + (1-\alpha_t) = 1-\bar\alpha_t\). La forme fermée rend l'entraînement efficace car on saute les \(t-1\) premiers pas : bruitage direct à n'importe quel \(t\), un seul forward par exemple d'entraînement.
Corrigé 2 — ELBO DDPM (plan) (1) Écrire l'ELBO de la chaîne \(p_\theta(x_{0:T})\) contre \(q\) et télescoper (chaîne de Markov) : \(L = L_T + \sum_t L_{t-1}\) avec \(L_{t-1} = \mathrm{KL}(q(x_{t-1}\mid x_t,x_0)\,\|\,p_\theta(x_{t-1}\mid x_t))\) . (2) \(q(x_{t-1}\mid x_t,x_0)\) est gaussien (produit de deux gaussiennes : Bayes + complétion du carré). (3) Chaque \(L_{t-1}\) est une KL de gaussiennes : fermée (prop. 0.4) ; avec \(\sigma_t^2 = \tilde\beta_t\) il reste l'écart des moyennes \(\propto \|\tilde\mu_t - \mu_\theta\|^2\). (4) La paramétrisation \(\mu_\theta = \frac{1}{\sqrt{\alpha_t}}(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta)\) échange l'écart des moyennes contre la MSE de bruit — détails complets dans la preuve du modèle 3.2.
Corrigé 3 — KL gaussiennes (cas scalaire) \(\mathrm{KL} = \mathbb{E}_q[\log q - \log p]\) avec \(\log q(x) = -\frac12\log(2\pi\sigma_1^2) - \frac{(x-\mu_1)^2}{2\sigma_1^2}\) et de même pour \(p\). Différence : \(\log q - \log p = \frac12\log\frac{\sigma_2^2}{\sigma_1^2} - \frac{(x-\mu_1)^2}{2\sigma_1^2} + \frac{(x-\mu_2)^2}{2\sigma_2^2}\). Or \(\mathbb{E}_q[(x-\mu_1)^2] = \sigma_1^2\) et \(\mathbb{E}_q[(x-\mu_2)^2] = \mathbb{E}[((x-\mu_1) + (\mu_1-\mu_2))^2] = \sigma_1^2 + (\mu_1-\mu_2)^2\) (terme croisé nul). D'où \(\mathrm{KL}(q\|p) = \frac12\big[\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{\sigma_2^2} - 1\big]\). C'est \(\frac12[u - 1 - \log u] \ge 0\) avec \(u = \sigma_2^2/\sigma_1^2\) (car \(\log u \le u - 1\)) plus un terme carré : nul ssi \((\mu_1,\sigma_1) = (\mu_2,\sigma_2)\).
Corrigé 4 — Mini-GAN 2D (code) 
import torch
G = torch.nn.Sequential(torch.nn.Linear(2, 64), torch.nn.ReLU(),
                        torch.nn.Linear(64, 64), torch.nn.ReLU(),
                        torch.nn.Linear(64, 2))          # bruit -> point 2D
D = torch.nn.Sequential(torch.nn.Linear(2, 64), torch.nn.ReLU(),
                        torch.nn.Linear(64, 1))          # point -> logit

def sample_ring(n, r=1.0, noise=.05):                    # vraie loi : anneau
    a = torch.rand(n) * 2 * torch.pi
    return torch.stack([r*torch.cos(a), r*torch.sin(a)], 1) + noise*torch.randn(n, 2)

optG, optD = torch.optim.Adam(G.parameters(), 2e-4), torch.optim.Adam(D.parameters(), 2e-4)
bce = torch.nn.functional.binary_cross_entropy_with_logits
for step in range(5000):
    x = sample_ring(256); z = torch.randn(256, 2)
    lossD = bce(D(x), torch.ones(256, 1)) + bce(D(G(z)), torch.zeros(256, 1))
    optD.zero_grad(); lossD.backward(); optD.step()

    lossG = bce(D(G(z)), torch.ones(256, 1))             # forme non-saturee
    optG.zero_grad(); lossG.backward(); optG.step()
    if step % 1000 == 0: print(step, float(lossD), float(lossG))

Corrigé 5 — CFG \(\tilde\epsilon = \epsilon_\theta(\varnothing) + w(\epsilon_\theta(c) - \epsilon_\theta(\varnothing))\) : pour \(w = 0\), \(\tilde\epsilon = \epsilon_\theta(\varnothing)\) (inconditionnel) ; pour \(w = 1\), \(\tilde\epsilon = \epsilon_\theta(c)\) (conditionnel). Pour \(w > 1\), la preuve du thm. 4.1 montre que \(\tilde\epsilon\) est le score de \(p(x\mid c)^w p(x)^{1-w}\) : distribution conditionnelle « sur-pondérée », plus piquée — fidélité au prompt accrue, diversité réduite (moins d'échantillons explorés). Grille typique : à \(w=0\), images hors-sujet ; \(w=1\), correctes et variées ; \(w=5\), très conformes, répétitives ; \(w=10\), saturation (couleurs brûlées, artefacts).
Corrigé 7 — FID et W2 (Bures) Pour deux gaussiennes \(\mathcal{N}(\mu_1,\Sigma_1)\), \(\mathcal{N}(\mu_2,\Sigma_2)\) : $$W_2^2 = \|\mu_1 - \mu_2\|^2 + \mathrm{tr}\big(\Sigma_1 + \Sigma_2 - 2(\Sigma_1^{1/2}\Sigma_2\Sigma_1^{1/2})^{1/2}\big)$$ (démonstration : cas diagonal par rotation, puis général — module OT). Le FID est exactement cette formule appliquée aux gaussiennes ajustées sur les features Inception des deux jeux d'images — une approximation de \(W_2\) à la fois par les features (le transport n'a lieu que dans l'espace du backbone) et par l'estimation des moments (\(\hat\mu, \hat\Sigma\) sur N échantillons : le FID est biaisé vers le bas à petit N — toujours comparer à taille de cohorte égale).
Corrigé 8 — Epsilon = -sqrt(1-a_bar) x score Voir la preuve du théorème 3.3 : pour \(p(x_t\mid x_0) = \mathcal{N}(\sqrt{\bar\alpha_t}x_0, (1-\bar\alpha_t)I)\), \(\nabla_{x_t}\log p = -(x_t - \sqrt{\bar\alpha_t}x_0)/(1-\bar\alpha_t) = -\epsilon/\sqrt{1-\bar\alpha_t}\), d'où \(\epsilon = -\sqrt{1-\bar\alpha_t}\,\nabla_{x_t}\log p(x_t\mid x_0)\). Conséquence : la MSE de débruitage est une régression vers le score conditionnel ; en intégrant sur \(x_0\), elle cible le score marginal \(\nabla\log p_t(x_t)\) — le point de départ de la formulation SDE (ch. 4).
