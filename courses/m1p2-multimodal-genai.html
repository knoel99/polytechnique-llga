0. Rappels : le paysage génératif

Rappels des modules précédents

1. VAE et espaces latents

Définition 1.1 — VAE conditionnel & hiérarchique Conditionner la génération : \(p_\theta(x \mid c)\) avec \(c\) une classe, un texte (encodé), une autre modalité. Les VAE hiérarchiques empilent des latents ; les VQ-VAE quantifient le latent en un dictionnaire appris (codes discrets — l'ancêtre des tokens d'images ; vector quantization = K-means_dur dans la boucle) ; VQ-VAE-2 atteint la fidélité d'image avant la diffusion.
Ce que le latent achète Compresser \(512 \times 512 \times 3\) en \(64 \times 64\) latents = \(\times 64\) moins de calculs ; tous les gros modèles génératifs d'images (Stable Diffusion, DALL·E 2/3) génèrent en espace latent — l'autoencodeur (léger) et le générateur (lourd) sont découplés. Le même principe s'applique aux graphes : graphe latent, codes discrets (module Graph ML, ch. 7).

2. GAN et adversarial

Définition 2.1 — Rappel du minimax et ses raffinements $$\min_G \max_D\ \mathbb{E}_x[\log D(x)] + \mathbb{E}_{z}[\log(1 - D(G(z)))]$$ Pertes alternatives : least-squares GAN, hinge ; conditionnel : \(G(z, c)\), \(D(x, c)\) — Pix2Pix (image à image avec contrainte de reconstruction L1) ; CycleGAN (sans paires, cycle de consistence : \(G_{XY}(G_{YX}(y)) \approx y\)).
  • StyleGAN : injection de style par couche (AdaIN), mapping network — contrôle fin du style (coarse→fine) ; the « style » latent découple contenu/style ;
  • Diagnostic industriel : mode collapse (le générateur produit \(\sqrt{\;}\) toujours la même chose), oscillations ; monitoring par diversité (LPIPS) et FID ;
  • Pourquoi la diffusion a gagné : perte stable (simple MSE de débruitage), pas d'équilibre à maintenir, diversité naturelle — mais les GAN restent rapides (1 pas) et vivent dans la super-résolution et l'éditing.

3. Diffusion : DDPM

Modèle 3.1 — Processus avant (bruitage) Chaîne de Markov qui ajoute du bruit gaussien : $$q(x_t \mid x_{t-1}) = \mathcal{N}\big(\sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t I\big), \qquad t = 1, \dots, T,$$ avec variance calendar \(\beta_t\) croissante ; propriété clé (composition de gaussiennes) : $$q(x_t \mid x_0) = \mathcal{N}\big(\sqrt{\bar\alpha_t}\, x_0,\ (1 - \bar\alpha_t) I\big), \qquad \bar\alpha_t = \prod_{s \leq t}(1 - \beta_s).$$ Pour \(T = 1000\), \(\bar\alpha_T \approx 0\) : l'image est devenue du bruit pur.
Modèle 3.2 — Processus inverse appris (débruitage, Ho et al., 2020) $$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}\big(\mu_\theta(x_t, t),\ \sigma_t^2 I\big),$$ et l'entraînement se réduit à une simple MSE : $$\mathcal{L} = \mathbb{E}_{x_0, \epsilon, t}\big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\big], \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1 - \bar\alpha_t}\,\epsilon.$$ Le réseau \(\epsilon_\theta\) (U-Net ou Transformer — DiT) apprend à prédire le bruit. Échantillonnage : partir de \(x_T \sim \mathcal{N}(0, I)\) et débruiter \(T\) fois ; DDIM : sous-échantillonner les pas (déterministe, 20-50 pas) ; les score-based / SDE (Song et al.) unifient le point de vue (prédire \(\nabla_x \log p_t(x)\), le « score »). 
import torch

def forward_diffusion(x0, t, alphas_bar, eps=None):
    """x_t = sqrt(a_bar_t) x0 + sqrt(1 - a_bar_t) * eps   (en une etape !)"""
    if eps is None: eps = torch.randn_like(x0)
    return alphas_bar[t].sqrt()[:, None, None, None] * x0 \
         + (1 - alphas_bar[t]).sqrt()[:, None, None, None] * eps, eps

# Entrainement (boucle typique DDPM) :
# x0 = batch d'images ; t ~ U{1..T}
xt, eps = forward_diffusion(x0, t, alphas_bar)
loss = torch.nn.functional.mse_loss(unet(xt, t), eps)   # predire le bruit
loss.backward()
Analogies LLGA Le U-Net de diffusion utilise la self-attention (transformer sur grille) ; les DiT remplacent tout par des transformers sur patches ; et la diffusion sur graphes (DiGress) bruite/débruite types de nœuds et arêtes — le même algorithme, un autre espace (module Graph ML, ch. 7).

4. Échantillonnage guidé et latent

Classifier-free guidance (CFG) Entraîner \(\epsilon_\theta(x_t, t, c)\) avec \(c\) parfois remplacé par \(\varnothing\) (dropout de condition, ~10 %) ; à la génération, exagérer la direction conditionnelle : $$\tilde\epsilon = \epsilon_\theta(x_t, t, \varnothing) + w\big(\epsilon_\theta(x_t, t, c) - \epsilon_\theta(x_t, t, \varnothing)\big), \qquad w > 1.$$ \(w\) règle le compromis fidélité/diversité — le curseur « créativité » de tous les outils text-to-image.
  • Latent diffusion (Rombach et al., 2022) : autoencodeur + diffusion dans le latent ; cross-attention sur les tokens du prompt (text encoder CLIP) ; c'est l'architecture de Stable Diffusion ;
  • Contrôle : ControlNet (conditionner par contours/profondeur/pose) ; inpainting, img2img (départ partiellement bruité) ;
  • Accélération : distillation (1-few pas ; LCM), solveurs rapides (DPM-Solver) ; quantification — panorama engineering repris en M2 ML Ops.

5. CLIP et l'alignement vision-langage

CLIP (Radford et al., 2021) Encoder conjointement images et textes dans un espace partagé :
  • encodeur image (ViT) et encodeur texte (transformer) ; 400M paires (image, légende) collectées sur le web ;
  • apprentissage contrastif : dans un batch de \(N\) paires, maximiser les diagonales de la matrice de similarité \(S_{ij} = \langle v_i, t_j\rangle / \tau\) (softmax croisé = classification « la bonne légende parmi N ») ;
  • résultat : zero-shot : classifier en comparant l'image aux embeddings des libellés textuels — plus de classes fixes.
CLIP, le couteau suisse multimodal CLIP sert partout : text encoder des diffusion models ; juge de similarité (R-Precision) ; retrieval image-texte ; modération. Le pont avec le master : on peut aussi aligner graphes et texte dans un espace commun (embeddings GNN ↔ LLM, Graph ML ch. 8) — la « modalité » graphe entre dans la même machinerie d'alignement contrastif. 
from PIL import Image
from transformers import CLIPProcessor, CLIPModel
import torch

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
proc  = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

img = Image.open("graphe.png")
texts = ["a graph drawing", "a cat", "a molecule", "a city map"]
inputs = proc(text=texts, images=img, return_tensors="pt", padding=True)
with torch.no_grad():
    out = model(**inputs)
probs = out.logits_per_image.softmax(dim=1)   # zero-shot classification
print(dict(zip(texts, probs[0].tolist())))

6. Multimodalité : au-delà de l'image

  • Captioning / VQA : encodeur image (ViT) + décodeur texte (transformer) ; entraînés sur des paires ; les VQA graphiques (« quel est le plus court chemin ? ») — raisonnement visuel ;
  • LLMs multimodaux : tokens d'images (VQ) ou projecteurs de patches injectés dans le contexte du LLM (vision-language models) ; même patron pour l'audio ; module M2 pour la suite ;
  • Vidéo : latents spatio-temporels, attention 3D ; 3D/objets : diffusion sur points/meshes (lien M2 Geometric DL) ;
  • Données structurées génératives : text-to-graph (générer le schéma d'un réseau), graph-to-text (rapport depuis un graphe de connaissances) — l'intersection exacte des modules Graph ML et NLP ;
  • Agents multimodaux : percevoir (screenshot) et agir (clic, code) — les agents GUI combinent vision + LLM + outils (module RL, ch. 7).

7. Évaluation, coûts, éthique

  • Métriques : FID (Fréchet distance entre gaussiennes fitted sur features Inception — une application directe de la distance de Wasserstein-Bures du module OT !), LPIPS (diversité), CLIPScore (alignement), études humaines ;
  • Coûts : entraînement diffusion = milliers de GPU-heures ; inférence = N pas de U-Net ; le compromis qualité/latence gouverne le choix industriel ;
  • Éthique : deepfakes, watermarks (C2PA), biais des données web ; droits d'auteur et entraînement ; le cadre légal européen (AI Act) — croisé avec le séminaire d'éthique du M2.

Exercices

  1. Composition des bruits. Montrer par récurrence que \(q(x_t \mid x_0) = \mathcal{N}(\sqrt{\bar\alpha_t} x_0, (1-\bar\alpha_t) I)\) ; pourquoi cette forme fermée rend l'entraînement efficace ?
  2. ELBO DDPM. Décomposer la log-vraisemblance \(\log p_\theta(x_0) = \mathrm{ELBO}\) en termes par pas et montrer que la MSE de bruit domine (les KL entre gaussiennes sont fermées).
  3. Mode collapse. Simuler un GAN 2D gaussien→anneau ; observer le collapse ; comparer à une diffusion entraînée sur le même jeu (diversité par LPIPS).
  4. CFG. Montrer que \(w = 1\) redonne la prédiction conditionnelle et \(w = 0\) l'inconditionnelle ; générer une grille \(w \in \{0, 1, 5, 10\}\) et commenter le compromis.
  5. CLIP zero-shot. Mesurer l'accuracy zero-shot d'un CLIP fine-tuné vs ResNet entraîné sur 10 classes personnalisées en fonction de la taille d'entraînement ; où se croisent les courbes ?
  6. FID et Wasserstein. Rappeler la formule de \(W_2^2\) entre gaussiennes (module OT) et montrer que le FID en est une estimation (features ; biais d'échantillon).
