0. Rappels : théorie des graphes

Rappels L3 — l'objet « graphe » (cf. Refresher CS)
  • Définitions : \(G = (V, E)\) ; orienté/non orienté, pondéré ; degré \(d_v\), voisins \(\mathcal{N}(v)\), matrice d'adjacence \(A\), matrice de degrés \(D = \mathrm{diag}(d_v)\). Chemins, connexité, composantes, cycles, DAG.
  • Euler et Königsberg (1736) : la traversée des 7 ponts est impossible car plus de deux sommets sont de degré impair — premier théorème de la théorie des graphes ; l'abstraction (nœuds + arêtes) a fondé la discipline.
  • Algèbre linéaire : \((A^k)_{ij}\) compte les chemins de longueur \(k\) ; valeurs propres de \(A\) = spectre du graphe ; matrices symétriques diagonalisables en base orthonormée (rappel d'algèbre).
  • Matrices stochastiques : \(P = D^{-1}A\) = marche aléatoire ; distribution stationnaire, PageRank \(\pi \propto (I - \alpha P)^{-1}\mathbf{1}\).
Définition 0.1 — Isomorphisme, automorphisme, sous-graphe Deux graphes \(G = (V, E)\) et \(G' = (V', E')\) sont isomorphes s'il existe une bijection \(\pi : V \to V'\) telle que \((u, v) \in E \iff (\pi(u), \pi(v)) \in E'\). Un automorphisme est un isomorphisme de \(G\) sur lui-même ; leur ensemble forme un groupe \(\mathrm{Aut}(G)\). Un sous-graphe de \(G\) est formé de \(S \subseteq V\) et d'un sous-ensemble de \(E \cap (S \times S)\) ; le sous-graphe induit garde toutes les arêtes internes. Décider de l'isomorphisme est un problème ni connu NP-complet ni connu polynomial ; le test de Weisfeiler-Lehman (module M2, ch. 1) en est l'heuristique fondamentale — et la borne d'expressivité des GNN.
Proposition 0.2 — Connexité et plus courts chemins La relation «\(u \sim v\) s'il existe un chemin de \(u\) à \(v\)» est une relation d'équivalence ; ses classes sont les composantes connexes. Entre deux sommets d'une même composante, tout chemin de longueur minimale (plus court chemin) est un chemin simple (sans répétition de sommet).
Réflexivité (chemin de longueur 0), symétrie (graphe non orienté : renverser le chemin) et transitivité (concaténer) sont immédiates. Si un chemin de \(u\) à \(v\) visite deux fois un sommet \(w\), on supprime le cycle entre les deux visites : le chemin raccourcit strictement. Un chemin de longueur minimale ne peut donc contenir de cycle, donc tout sommet y apparaît une seule fois : il est simple, de longueur \(\leq n - 1\). ∎
Théorème 0.3 (théorème spectral) et comptage par la trace Toute matrice symétrique réelle \(S \in \mathbb{R}^{n \times n}\) s'écrit \(S = U \Lambda U^\top\) avec \(U\) orthogonale et \(\Lambda\) diagonale réelle. Pour l'adjacence d'un graphe simple, il en découle trois identités de comptage : $$\mathrm{tr}(A) = 0, \qquad \mathrm{tr}(A^2) = 2|E|, \qquad \mathrm{tr}(A^3) = 6\,|\{\text{triangles}\}|.$$
\(\mathrm{tr}(A^2) = \sum_i (A^2)_{ii} = \sum_i d_i\) chaque arête contribuant à deux degrés. \((A^3)_{ii}\) compte les chemins fermés de longueur 3 passant par \(i\) : ce sont exactement les triangles contenant \(i\), chacun parcouru dans deux sens depuis \(i\). Chaque triangle \(\{i, j, k\}\) produit ainsi 2 chemins fermés pour chacun de ses 3 sommets, soit 6 comptages ; réciproquement un chemin fermé de longueur 3 \(i \to j \to k \to i\) visite trois sommets distincts deux à deux adjacents. ∎
Application immédiate en apprentissage : compter des triangles (motifs) par produits matriciels — l'ingrédient de base des features structurelles du ch. 9 et de l'expressivité du module M2 (ch. 1).
Définition 0.4 — Le laplacien d'un graphe $$L = D - A, \qquad \text{ou normalisé : } L_{\mathrm{sym}} = I - D^{-1/2} A\, D^{-1/2}.$$ Pour tout vecteur \(x \in \mathbb{R}^n\) (\(n = |V|\)) : $$x^\top L x = \sum_{(u,v) \in E} (x_u - x_v)^2 \ \geq\ 0$$ — \(L\) est positive semi-définie ; ses valeurs propres \(0 = \lambda_1 \leq \lambda_2 \leq \dots \leq \lambda_n\) encodent la connectivité ; \(\lambda_2\) (trou spectral, Fiedler 1973) mesure la difficulté à couper le graphe, et le nombre de valeurs propres nulles égale le nombre de composantes connexes.
\(x^\top D x = \sum_v d_v x_v^2\) et \(x^\top A x = 2 \sum_{(u,v) \in E} x_u x_v\) (matrice symétrique) ; donc \(x^\top L x = \sum_{(u,v) \in E} (x_u^2 + x_v^2 - 2 x_u x_v)\). Pour la multiplicité de 0 : réordonner les sommets par composantes rend \(A\) (et \(L\)) bloc-diagonaux ; chaque bloc \(L_C\) a pour noyau l'indicateur \(\mathbf{1}_C\), car \(x^\top L_C x = 0\) impose \(x\) constant sur chaque composante connexe (la somme de carrés s'annule arête par arête, et la connexité propage la constante — prop. 0.2). ∎
Exemple 0.5 — Le spectre raconte l'histoire Chemin de \(n\) sommets : \(\lambda_k = 2(1 - \cos\frac{k\pi}{n})\) ; graphe complet : \(0\) puis \(n\) (multiplicité \(n-1\)) ; cycle : valeurs propres de \(2\cos\). Un graphe « deux communautés » a un petit \(\lambda_2\) ; le vecteur propre de Fiedler sépare les communautés — c'est le cœur du spectral clustering, développé au ch. 4 (pont direct avec l'ACP du module Machine Learning).
Proposition 0.6 — Marches aléatoires : stationnarité et ergodicité Soit \(G\) connexe non orienté, \(P = D^{-1}A\), \(m = |E|\). La distribution \(\pi_v = d_v / (2m)\) est stationnaire : \(\pi^\top P = \pi^\top\). Si de plus \(G\) n'est pas biparti, la chaîne est irréductible et apériodique, donc ergodique : $$P^t(x, \cdot) \xrightarrow[t \to \infty]{} \pi \qquad \text{quel que soit le départ } x.$$
Équilibre détaillé : \(\pi_u P_{uv} = \frac{d_u}{2m} \cdot \frac{\mathbb{1}[(u,v) \in E]}{d_u} = \frac{\mathbb{1}[(u,v) \in E]}{2m}\), quantité symétrique en \(u, v\) ; en sommant sur \(u\), \((\pi^\top P)_v = \pi_v\). Irréductibilité : la connexité rend tout sommet atteignable. Périodicité : sur un graphe biparti, toute marche a une parité fixe (\(P^t(x, x) = 0\) pour \(t\) impair) ; réciproquement, toute arête \((u,v)\) d'un graphe non biparti appartient à un cycle impair, fournissant des retours de périodes \(d(u,v)+1\) et \(d(u,v)-1\) premières entre elles — période 1. Le théorème de convergence des chaînes de Markov (cf. Refresher Statistics) conclut. ∎
Conséquence pratique : les marches de DeepWalk (ch. 3) « mélangent » la distribution vers \(\pi \propto\) degrés — d'où le biais des embeddings vers les hubs, corrigé en partie par node2vec et par NetMF.
Définition 0.7 — Modularité (Newman & Girvan, 2004) Pour une partition \(\mathcal{C} = \{C_1, \dots, C_k\}\) des sommets : $$Q(\mathcal{C}) = \frac{1}{2m} \sum_{i,j} \Big[ A_{ij} - \frac{d_i\, d_j}{2m} \Big]\, \delta(c_i, c_j),$$ où \(c_i\) est la communauté de \(i\) et \(\delta\) l'indicatrice. \(Q\) compare la densité observée des arêtes intra-communautés à celle attendue sous le modèle de configuration (arêtes redistribuées en conservant les degrés, terme \(d_i d_j / 2m\)). Esquisse de la maximisation : maximiser \(Q\) exactement est NP-difficile ; Louvain le fait gloutonnement — fusionner itérativement les paires (communauté, voisin) qui augmentent le plus \(\Delta Q = \frac{1}{2m}[\Sigma_{in} - \frac{(\Sigma_{tot} + d_i)^2}{4m}]\dots\), puis contracter — d'où des hiérarchies de communautés utilisées telles quelles par GraphRAG (ch. 11). Limite connue : résolution — \(Q\) ne « voit » pas les communautés plus petites que \(\sim \sqrt{2m}\) arêtes ; SBM (ch. 9) offre une alternative statistique mieux fondée.

1. Pourquoi les graphes ?

Les données du monde réel sont relationnelles : la structure porte une information que les méthodes iid ignorent. Les réseaux sociaux (amitiés), les molécules (liaisons), les réseaux de transactions (fraude !), les graphes de connaissances d'entreprise (clients, produits, processus), les réseaux informatiques, les grappes de citations, les ontologies juridiques… Tous sont naturellement des graphes, souvent hétérogènes (nœuds/arêtes typés : « achète », « possède », « travaille avec ») et dynamiques (arêtes horodatées : transactions seconde par seconde). Typiquement aussi : peu d'étiquettes (quelques dizaines de nœuds annotés sur des millions) — le régime semi-supervisé du ch. 5 — et des distributions biaisées par l'échantillonnage (les arêtes observées ne sont pas un échantillon uniforme des interactions).

Le positionnement LLGA Les LLMs excellent sur le texte mais peinent sur : les relations structurées, la fidélité factuelle (hallucinations), et les données non textuelles. Les graphes comblent exactement ces manques :
  • GraphRAG : connecter le LLM à des données propriétaires structurées — l'approche la plus efficace aujourd'hui pour fiabiliser un LLM en entreprise (ch. 11) ;
  • GNN + LLM : IA générative sur données structurées (générer des molécules, des plans, des recommandations) ;
  • Applications industrielles : pharma/biotech (molécules = graphes), finance (réseaux de transactions, risque systémique), recommandation, supply chain, systèmes multi-agents (les workflows d'agents sont des DAG — module RL).
Fil rouge du master Trois places du graphe dans l'IA générative : dans le modèle (l'attention des transformers est un graphe dynamique complet — module Deep Learning), pour le modèle (GraphRAG, encodage structurel — ch. 11), entre les modèles (orchestration d'agents = programmation de DAG). Ce module pose les fondations des trois ; le module M2 « Advanced GNN » prolonge chacune.

Définition 2.1 — Invariance et équivariance aux permutations Un graphe n'a ni taille fixe, ni ordre canonique des nœuds : le modèle doit être permutation-invariant (sortie de graphe) : \(f(P X, P A P^\top) = f(X, A)\), ou permutation-équivariant (sortie par nœud) : \(f(PX, PAP^\top) = P f(X, A)\), pour toute matrice de permutation \(P\). Les CNN (grille), les RNN (séquence) violent ces contraintes — d'où des architectures dédiées (ch. 5) et toute la théorie d'expressivité du module M2 (ch. 1).
Transductif vs inductif — une distinction qui structure tout le module
  • Transductif : entraîner et tester sur le même graphe (embeddings ch. 3) ; impossible de prédire pour un nœud arrivé après l'entraînement ;
  • Inductif : le modèle (ses poids) se réapplique à de nouveaux graphes (GraphSAGE, GNN ch. 5)  — indispensable en production ;
  • Semi-supervisé structurel : sur Cora (2 708 nœuds), 140 étiquettes suffisent — la structure relaie l'information (hypothèse d'homophilie : les voisins partagent l'étiquette ; quand elle est fausse, il faut des arêtes « virtuelles » ou des modèles hétérophiles).

3. Node embeddings

Objectif Apprendre \(z_v \in \mathbb{R}^d\) tel que la similarité des embeddings reflète la proximité dans le graphe : \(\mathrm{sim}(z_u, z_v) \approx P(u \text{ voisin de } v)\) — une factorisation implicite de la matrice d'adjacence (ou d'une matrice de proximités dérivées), en opposition aux GNN du ch. 5 qui conditionnent l'embedding aux features \(X\).
DeepWalk (Perozzi et al., 2014) et node2vec (Grover & Leskovec, 2016)
  1. générer des marches aléatoires depuis chaque nœud (longueur \(\ell\), \(r\) marches par nœud) ; node2vec biaisent la marche par \((p, q)\) — développé ci-dessous ;
  2. appliquer word2vec skip-gram aux marches : les « phrases » sont des suites de nœuds, la fenêtre \(b\) définit les paires (centre, contexte) ;
  3. ensuite : n'importe quelle méthode vectorielle (k-means, classification…).
La marche aléatoire définit la proximité : deux nœuds co-visités souvent obtiennent des embeddings proches — la théorie NetMF (Qiu et al., 2018) montre rétroactivement que DeepWalk factorise une matrice déterministe de marches (théorème 3.4).
Dérivation 3.1 — Skip-gram avec negative sampling : la loss et son gradient Pour une paire (centre \(c\), contexte \(o\)) et \(K\) négatifs \(v_1, \dots, v_K\) tirés d'une distribution de bruit \(P_n\) (loi unigramme élevée à la puissance 3/4, comme en NLP) : $$\mathcal{L}(c, o) = -\log \sigma(z_o^\top z_c) \; - \; \sum_{k=1}^{K} \log \sigma(-z_{v_k}^\top z_c),$$ avec \(\sigma(s) = 1/(1 + e^{-s})\). En notant \(s_k = z_{v_k}^\top z_c\) et en dérivant \(\frac{d}{ds}[-\log\sigma(s)] = \sigma(s) - 1\) : $$\frac{\partial \mathcal{L}}{\partial z_c} = \big(\sigma(z_o^\top z_c) - 1\big)\, z_o \; + \; \sum_{k=1}^K \sigma(s_k)\, z_{v_k}, \qquad \frac{\partial \mathcal{L}}{\partial z_o} = \big(\sigma(z_o^\top z_c) - 1\big)\, z_c.$$ Lecture : le terme \(-z_o\) (car \(\sigma < 1\)) attire le contexte vers le centre, chaque négatif repousse avec un poids \(\sigma(s_k) \in ]0,1[\) — fort si le négatif est déjà trop proche. Descente de gradient stochastique : coût par paire \(\mathcal{O}(K d)\), indépendant de \(n\) — c'est ce qui a rendu word2vec (et donc DeepWalk) scalable ; l'astuce softmax hiérarchique remplace le \(\mathcal{O}(n)\) du softmax complet par \(\mathcal{O}(\log n)\).
Dérivation 3.2 — node2vec : les biais \(p\) et \(q\) par probabilités de transition À l'étape \(i\), la marche vient de \(t\), est en \(v\) ; pour le candidat \(x \in \mathcal{N}(v)\) : $$\pi_{tx} = \frac{w_{tx}}{Z}\, \alpha_{pq}(t, x), \qquad \alpha_{pq}(t, x) = \begin{cases} 1/p & \text{si } d_{tx} = 0 \\ 1 & \text{si } d_{tx} = 1 \\ 1/q & \text{si } d_{tx} = 2 \end{cases}$$ (\(d_{tx}\) = distance dans le graphe ; \(Z\) normalise sur \(\mathcal{N}(v)\) ; dans un graphe simple, \(d_{tx} \leq 2\) pour tout \(x \in \mathcal{N}(v) \cup \{t\}\) si \(t\) et \(v\) sont adjacents). Trois régimes :
  • \(p \lt 1\) : retour vers \(t\) favorisé — la marche reste dans le voisinage proche (BFS) : deux nœuds de rôles structuraux analogues (hubs, ponts) obtiennent des embeddings proches — équivalence structurelle ;
  • \(q \lt 1\) : les sommets à \(d_{tx} = 2\) sont favorisés — la marche s'éloigne (DFS) : deux nœuds d'une même communauté/cluster sont proches — homophilie ;
  • \(p = q = 1\) : marche aléatoire uniforme — DeepWalk est un cas particulier de node2vec.
La preuve qualitative : avec \(p \to 0\), la probabilité de revenir en \(t\) domine et la marche échantillonne le voisinage à 2 sauts de \(t\) de façon quasi uniforme ; avec \(q \to 0\), la chaîne évite \(t\) et se comporte comme une marche exploratoire de grande ampleur — retrouvez ces comportements dans l'exercice 3.
Théorème 3.3 — NetMF : DeepWalk comme factorisation de matrices (Qiu et al., 2018) Quand la fenêtre \(b\) et le nombre de marches croissent, DeepWalk converge vers la factorisation (tronquée, élément par élément) de la matrice : $$M = \log\Big( \frac{\mathrm{vol}(G)}{b\, T} \Big( \sum_{r=1}^{T} P^r \Big) D^{-1} \Big), \qquad \mathrm{vol}(G) = \sum_v d_v = 2m,$$ c'est-à-dire que l'on cherche \(Z Z^\top \approx M\) ; \(T\) joue le rôle de l'horizon effectif des marches. Conséquences : (i) un pont théorique — DeepWalk, LINE, PTE et node2vec sont toutes des factorisations de variantes de \(M\) (d'où le nom « NetMF », Network Embedding as Matrix Factorization) ; (ii) un algorithme déterministe — factoriser \(M\) directement (SVD tronquée) égale ou bat DeepWalk sans tirer une seule marche ; (iii) un diagnostic — la matrice cible est construite sur \(P = D^{-1}A\) : les embeddings encodent les marches, pas les features, et restent transductifs (un nouveau nœud exige de tout recalculer — motivation directe des GNN inductifs du ch. 5).
L'intuition « word2vec sur le graphe » — et sa réciproque C'est le pont historique NLP ↔ graphes : un corpus de marches ≈ un corpus de phrases. L'équipe pédagogique a poussé l'idée inverse — Graph of Words (ch. 10) : représenter un document par un graphe de termes co-occurrents et le classifier avec des outils de graphes. Les deux directions convergent aujourd'hui dans les LLMs sur graphes (ch. 11). Pour aller au-delà des marches (avec répétitions) vers des chemins (simples), voir les Path Neural Networks (ch. 10 ; M2, ch. 1 et 8).
Exemple 3.4 — Karate Club : code complet Le graphe de Zachary (34 nœuds, 78 arêtes, 2 factions lors de la scission du club) est le « MNIST des graphes ». 
import numpy as np, networkx as nx
from gensim.models import Word2Vec
from sklearn.cluster import KMeans
from sklearn.metrics import normalized_mutual_info_score

G = nx.karate_club_graph()
y = np.array([0 if G.nodes[v]["club"] == "Mr. Hi" else 1 for v in G])

def biased_walk(G, v, p, q, length):
    walk, prev = [v], None
    for _ in range(length):
        cand = list(G.neighbors(walk[-1]))
        probs = []
        for x in cand:
            d = 0 if x == prev else nx.shortest_path_length(G, prev, x) if prev is not None else 1
            probs.append({0: 1/p, 1: 1.0, 2: 1/q}[d])
        probs = np.array(probs) / sum(probs)
        prev, nxt = walk[-1], np.random.choice(cand, p=probs)
        walk.append(nxt)
    return walk

walks = [ [str(u) for u in biased_walk(G, v, p=1, q=0.25, length=30)]
          for _ in range(80) for v in G.nodes() ]
model = Word2Vec(walks, vector_size=64, window=5, min_count=0, sg=1, epochs=10)
Z = np.array([model.wv[str(v)] for v in sorted(G.nodes())])
km = KMeans(n_clusters=2, n_init=10, random_state=0).fit(Z)
print("NMI :", normalized_mutual_info_score(y, km.labels_))   # ~0.5-0.8 selon p, q, seed
Exercice 3 : faire varier \((p, q)\) et relier le NMI au régime BFS/DFS.

4. Filtres spectraux et spectral clustering

Définition 4.1 — Transformée de Fourier sur graphe Soit \(L = U \Lambda U^\top\) (décomposition spectrale, \(U\) orthogonale, colonnes \(u_1, \dots, u_n\)). Pour un signal \(x \in \mathbb{R}^n\) porté par les nœuds : $$\hat x = U^\top x \quad (\text{analyse}), \qquad x = U \hat x \quad (\text{synthèse}).$$ Les « fréquences » sont les valeurs propres \(\lambda_k\) — petites = variations lentes sur le graphe (basses fréquences), grandes = alternances locales (hautes fréquences). C'est la convolution du module Signal Processing, avec le laplacien en lieu et place de \(-i\frac{d}{dt}\) : \(L\) y joue le rôle de l'opérateur différentiel.
Théorème 4.2 — Caractérisation variationnelle de \(\lambda_2\) (Fiedler) Pour un graphe connexe : $$\lambda_2 \;=\; \min_{x \neq 0,\ x \perp \mathbf{1}} \frac{x^\top L x}{x^\top x},$$ atteinte au vecteur de Fiedler \(u_2\). Plus \(\lambda_2\) est petit, plus il existe un signal quasi constant « presque orthogonal » à \(\mathbf{1}\) — c'est-à-dire deux grands blocs de valeurs opposées faiblement connectés.
Écrivons \(x = \sum_i c_i u_i\) (base orthonormée) ; \(x \perp \mathbf{1}\) impose \(c_1 = 0\) car \(u_1 = \mathbf{1}/\sqrt{n}\) (le noyau de \(L\) est exactement engendré par \(\mathbf{1}\), prop. 0.2 du calcul de multiplicité). Alors \(x^\top L x = \sum_{i \geq 2} \lambda_i c_i^2\) et \(x^\top x = \sum_{i \geq 2} c_i^2\) ; le quotient est une moyenne pondérée des \(\lambda_i, i \geq 2\), donc minorée par \(\lambda_2\), avec égalité pour \(x = u_2\). ∎
Exemple 4.3 — Vecteur de Fiedler sur deux cliques reliées (calcul exact) Deux \(K_5\) (\(\{u, x_1, \dots, x_4\}\) et \(\{v, y_1, \dots, y_4\}\)) reliés par le pont \((u, v)\). Par symétrie, cherchons un vecteur propre antisymétrique : \(x_i = a\) sur les 4 nœuds non-pont de gauche, \(u \mapsto b\), et valeurs opposées à droite. Les équations \(L x = \lambda x\) en un nœud non-pont (degré 4) et en \(u\) (degré 5) donnent : $$\lambda a = a - b \qquad \text{et} \qquad \lambda b = 6b - 4a \;\;\Rightarrow\;\; \lambda^2 - 7\lambda + 2 = 0.$$ D'où \(\lambda_2 = \frac{7 - \sqrt{41}}{2} \approx 0{,}298\) et \(b = (1 - \lambda_2)\, a \approx 0{,}70\, a\) ; le vecteur de Fiedler vaut, à normalisation près : $$(\underbrace{1, 1, 1, 1}_{x_i}, \underbrace{0{,}70}_{u}, \underbrace{-0{,}70}_{v}, \underbrace{-1, -1, -1, -1}_{y_j})$$ — le signe sépare exactement les deux communautés, et le nœud pont prend une valeur intermédiaire. C'est la image à retenir du spectral clustering.
Théorème 4.4 — Spectral clustering : algorithme complet et justification (relaxation de RatioCut) Algorithme (pour \(k\) communautés) :
  1. calculer les \(k\) premiers vecteurs propres \(u_1, \dots, u_k\) de \(L\) ; former \(F = [u_1 | \dots | u_k] \in \mathbb{R}^{n \times k}\) ;
  2. normaliser chaque ligne de \(F\) ;
  3. appliquer k-means aux \(n\) lignes de \(F\) (descripteur spectral).
Justification : le RatioCut d'une partition \(\{C_1, \dots, C_k\}\) est \(\mathrm{RatioCut} = \sum_{j=1}^{k} \frac{\mathrm{cut}(C_j, \bar{C}_j)}{|C_j|}\) (couper une petite communauté coûte cher — contrairement à la simple minimisation de cut). Notons \(H \in \mathbb{R}^{n \times k}\) les indicateurs renormalisés \(H_{ij} = \mathbb{1}[v_i \in C_j] / \sqrt{|C_j|}\).
(i) Exactitude sur la classe discrète. \(H^\top H = I\) (colonnes orthogonales de norme 1). De plus \(h_j^\top L h_j = \sum_{(u,v) \in E} (h_j(u) - h_j(v))^2 = \frac{1}{|C_j|} \times |\{(u,v) \in E : |\{u, v\} \cap C_j| = 1\}| = \frac{\mathrm{cut}(C_j, \bar{C_j})}{|C_j|}\). Donc \(\mathrm{tr}(H^\top L H) = \mathrm{RatioCut}\) : minimiser RatioCut = minimiser \(\mathrm{tr}(H^\top L H)\) sur les indicateurs orthonormés. (ii) Relaxation. On autorise tout \(F \in \mathbb{R}^{n \times k}\) avec \(F^\top F = I\) ; le problème relaxé \(\min_{F^\top F = I} \mathrm{tr}(F^\top L F)\) a pour solution les \(k\) premiers vecteurs propres (théorème de Ky Fan : montré en écrivant \(F^\top L F = \sum_{ij} (F^\top u_i)\,\lambda_i\,(u_j^\top F)\) et en échangeant l'ordre de sommation, puis en minimisant coefficients diagonalisés). (iii) Retour au discret. Les lignes de \(F\) restent proches des lignes d'indicateurs renormalisés ; k-means les regroupe. ∎
Variante Normalized Cut (Shi & Malik) : pondérer par les volumes \(d(C_j)\) conduit au problème généralisé \(L y = \lambda D y\), résolu par les vecteurs propres de \(L_{\mathrm{sym}}\) — c'est la version utilisée en pratique (et celle de scikit-learn). Liens : ACP (module Machine Learning — la matrice \(F\) est le pendant spectral de la projection) ; SBM (ch. 9) pour l'approche statistique ; ambiguïtés de signe des vecteurs propres — un vrai problème pour les GNN, résolu par SignNet (M2, ch. 3).
Théorème 4.5 — ChebNet : polynômes de Tchebychev (Defferrard et al., 2016) Filtrer exactement coûte \(y = U\, g_\theta(\Lambda)\, U^\top x\) — une décomposition complète (\(\mathcal{O}(n^3)\)) spécifique à chaque graphe. Astuce : prendre \(g_\theta\) polynomial de degré \(K\) dans la base de Tchebychev. Posons \(T_0(x) = 1\), \(T_1(x) = x\), \(T_{k+1}(x) = 2x T_k(x) - T_{k-1}(x)\), et \(\tilde\Lambda = \frac{2\Lambda}{\lambda_{\max}} - I\) (échelle vers \([-1, 1]\)) ; alors $$y = \sum_{k=0}^K \theta_k\, T_k(\tilde L)\, x, \qquad \tilde L = \frac{2L}{\lambda_{\max}} - I,$$ sans vecteurs propres : filtre \(K\)-localisé, poids \(\theta\) partagés par tous les graphes.
(i) Récurrence de Tchebychev. Pour \(x = \cos\theta\), \(T_k(x) = \cos(k\theta)\) ; la formule d'addition \(\cos((k{+}1)\theta) = 2\cos\theta \cos(k\theta) - \cos((k{-}1)\theta)\) donne la récurrence (elle se propage à tout \(x \in \mathbb{R}\) par identité polynomiale). (ii) Calcul fonctionnel. Montrons \(T_k(\tilde L) = U T_k(\tilde\Lambda) U^\top\) : c'est vrai pour les monômes par récurrence — \(\tilde L^m = (U \tilde\Lambda U^\top)^m = U \tilde\Lambda^m U^\top\), les produits internes \(U^\top U\) se simplifiant — donc pour tout polynôme. Ainsi \(y = U\, g_\theta(\tilde\Lambda)\, U^\top x = g_\theta(\tilde L)\, x\) : le filtre spectral s'exprime comme polynôme de \(L\) appliqué directement à \(x\). (iii) Localité. \(\tilde L x\) en un nœud ne combine que \(x_v\) et \(\{x_u : u \in \mathcal{N}(v)\}\) ; par récurrence sur la récurrence de Tchebychev (combinaison linéaire de \(\tilde L^k x\), \(k \leq K\)), la sortie en \(v\) ne dépend que du \(K\)-voisinage. ∎
Coût : \(\mathcal{O}(K |E|)\) par application — linéaire en la taille du graphe.
Proposition 4.6 — Du spectral au spatial : l'égalité démontrée Tout filtre polynomial de degré \(K\) en \(L\) est exactement un opérateur \(K\)-localisé, et réciproquement tout opérateur de message passing à \(K\) couches dont la propagation est un polynôme de \(A\) réalise un filtre spectral polynomial.
Sens direct : développé au (iii) ci-dessus. Réciproque : une couche locale \(y_v = \sum_{u \in \{v\} \cup \mathcal{N}(v)} c_{uv} x_u\) avec poids uniformes par symétrie s'écrit matriciellement \(y = \sum_{k \leq 1} c_k\, \Pi_k(A) x\) pour des polynômes \(\Pi_k\) de degré \(\leq 1\) (le terme diagonal est \(\Pi_0\), les arêtes \(\Pi_1\)) ; en composant \(K\) couches sans non-linéarité, \(y = \Pi(A) x\) avec \(\deg \Pi \leq K\), et comme \(L = D - A\) est lui-même polynomial en \(A\) (à \(D\) fixé par le graphe), \(\Pi(A) = g(L)\) pour un polynôme \(g\) de même degré. Les non-linéarités entre couches brisent l'égalité exacte — c'est précisément l'écart entre « CNN sur graphe » spectral et GNN spatial : le GNN généralise le filtre en insérant des point-par-point non linéaires, comme un CNN 1D. ∎

5. GNN et message passing

Définition 5.1 — La couche de message passing (MPNN, Gilmer et al., 2017) $$h_v^{(\ell+1)} = \phi\Big(h_v^{(\ell)},\ \underset{u \in \mathcal{N}(v)}{\mathrm{AGG}}\ \big\{\psi\big(h_v^{(\ell)}, h_u^{(\ell)}\big)\big\}\Big)$$ message \(\psi\) (calculé par le voisin), agrégation \(\mathrm{AGG}\) (permutation-invariante : somme, moyenne, max, attention), update \(\phi\). Une couche = un tour de message passing = une convolution = un pas de diffusion sur le graphe. Le choix de \(\mathrm{AGG}\) n'est pas anodin : moyenne/max perdent la cardinalité ({a, a} et {a} ont même moyenne et même max) ; c'est l'objet du théorème GIN (M2, ch. 1).
Dérivation 5.2 — GCN depuis la convolution spectrale (Kipf & Welling, 2017) Partons du filtre de Tchebychev tronqué à \(K = 1\) sur le laplacien renormalisé \(L_{\mathrm{sym}} = I - \tilde D^{-1/2} \tilde A \tilde D^{-1/2}\), \(\tilde A = A + I\), dont les valeurs propres vivent dans \([0, 2]\) (d'où le rescaling \(\tilde\Lambda \approx \Lambda - I\) en approchant \(\lambda_{\max} \approx 2\)) : $$g_\theta(\tilde\Lambda) \approx \theta_0\, T_0 + \theta_1\, T_1(\tilde\Lambda) = \theta_0 I + \theta_1 (\Lambda - I).$$ En fixant le renormalization trick \(\theta_0 = -\theta_1 = \theta\) (un seul paramètre, filtre croissant vers les basses fréquences, auto-boucles stabilisant la dynamique) : $$g_\theta \approx \theta\,(2I - L_{\mathrm{sym}}) = \theta\, \tilde D^{-1/2} \tilde A \tilde D^{-1/2}.$$ En rajoutant la non-linéarité, la dimension cachée et les features \(X\), on obtient la couche GCN : $$H^{(\ell+1)} = \sigma\Big(\tilde D^{-1/2}\, \tilde A\, \tilde D^{-1/2}\, H^{(\ell)}\, W^{(\ell)}\Big), \qquad H^{(0)} = X,$$ moyennée renormalisée des représentations transformées des voisins ; \(L\) couches = réceptive field de \(L\) sauts. La renormalisation (i) annule la valeur propre nulle (pas de composante constante injectée), (ii) garde les gains en \([-1, 1]\) — condition de stabilité de la profondeur, reliée à l'over-smoothing ci-dessous.
GraphSAGE (Hamilton et al., 2017) — algorithme et pseudo-code Pour chaque nœud, agréger un échantillon de voisins puis concaténer avec la représentation courante : 
entree : G, features X, profondeur K, tailles d'echantillon s_1..s_K
pour v dans V : h_v^(0) = x_v
pour l = 1 .. K :
    pour v dans V :
        S_v = echantillon uniforme de N(v) de taille s_l        # K voisins dans le papier
        a_v^(l) = AGG({ h_u^(l-1) : u in S_v })                 # mean / LSTM / pool
        h_v^(l) = sigma( W_l . [ h_v^(l-1) || a_v^(l) ] )       # concatenation !
        h_v^(l) = h_v^(l) / ||h_v^(l)||                          # normalisation L2
sortie : z_v = h_v^(K)
La concaténation préserve l'information propre au nœud (sinon la moyenne des voisins écrase le signal local) ; l'échantillonnage fixe par couche borne le minibatch (ch. 7) ; le tout est inductif : les poids \(W_l\) se réappliquent à des nœuds/graphes non vus. Cas particuliers : AGG = mean ≈ GCN sans renormalisation ; AGG = pool (MLP + max) ; AGG = LSTM sur voisins ordonnés aléatoirement (l'ordre rompt l'invariance… approximation assumée ; le problème de l'ordre est traité par GOAT, ch. 10).
GAT (Veličković et al., 2018) — équations et complexité Poids d'arête appris par attention : $$e_{uv} = \mathrm{LeakyReLU}\big(a^\top [\,W h_u \| W h_v\,]\big), \qquad \alpha_{uv} = \frac{\exp(e_{uv})}{\sum_{u' \in \mathcal{N}(v)} \exp(e_{uv'})}, \qquad h_v^{(\ell+1)} = \sigma\Big(\sum_{u \in \mathcal{N}(v)} \alpha_{uv}\, W h_u^{(\ell)}\Big)$$ avec \(T\) têtes d'attention parallèles (T projections \(W^{(t)}\)) concaténées ou moyennées. Complexité par couche : \(\mathcal{O}(|V| F F' + |E| F')\) — linéaire en arêtes, comparable à GCN, mais avec des poids adaptés à chaque arête : utile quand le graphe est bruité ou que certaines relations comptent plus (transactions suspectes !). Structurellement identique à l'attention des transformers (module Deep Learning) : ici le masque d'attention est donné par le graphe, là il est calculé — les graph transformers du M2 (ch. 4) ferment la boucle en apprenant l'attention et en la biaisant par la structure.
Au-delà du graphe homogène : R-GCN, features d'arêtes
  • R-GCN (Schlichtkrull et al., 2018) : graphe relationnel (types d'arêtes \(r\) dans \(\mathcal{R}\)) ; \(h_v^{(\ell+1)} = \sigma\big(W_0 h_v^{(\ell)} + \sum_{r \in \mathcal{R}} \sum_{u \in \mathcal{N}_r(v)} \frac{1}{c_{v,r}} W_r\, h_u^{(\ell)}\big)\). Pour éviter l'explosion paramétrique (\(|\mathcal{R}| \times F \times F'\)): décomposition en bases \(W_r = \sum_b a_{rb} V_b\) ou block-diagonale. Usage type : encodage de graphes de connaissances pour le link prediction (ch. 6).
  • Features d'arêtes : (a) graphe de ligne (chaque arête devient un nœud) ; (b) convolution sur arêtes (NNConv) : \(\psi(h_u, e_{uv})\) au lieu de \(\psi(h_u)\) — la liaison chimique porte un type ; (c) attention conditionnée (GAT peut injecter \(e_{uv}\) dans \(e_{uv}\)-score).
  • Pooling hiérarchique : DiffPool (Ying et al., 2018) apprend une matrice d'affectation douce \(S^{(\ell)} = \mathrm{softmax}(\mathrm{GNN}_A(H^{(\ell)}))\) et contracte le graphe : \(H^{(\ell+1)} = S^{(\ell)\top} H^{(\ell)}\), \(A^{(\ell+1)} = S^{(\ell)\top} A^{(\ell)} S^{(\ell)}\) — coarse-graining neuronal, coûteux mais hiérarchique ; alternatives : sort/TopK pooling, readout pyramidal.
Théorème 5.3 — Over-smoothing : démonstration sur graphe régulier Sur un graphe \(d\)-régulier connexe, la propagation GCN sans poids/non-linéarité vérifie \(H^{(\ell)} = P^\ell X\) avec \(P = \frac{A + I}{d + 1}\). Alors $$H^{(\ell)} \xrightarrow[\ell \to \infty]{} \frac{\mathbf{1}\mathbf{1}^\top}{n}\, X,$$ la solution harmonique (moyenne globale), à vitesse géométrique \(\big(\frac{\lambda_2(A) + 1}{d + 1}\big)^\ell\).
Sur un graphe \(d\)-régulier, \(D = (d+1)I\) pour \(\tilde A\), donc \(\tilde D^{-1/2} \tilde A \tilde D^{-1/2} = (A + I)/(d+1) =: P\). \(A\) étant symétrique réelle, écrivons \(X\) dans sa base propre : \(A = \sum_i \lambda_i u_i u_i^\top\) avec \(u_1 = \mathbf{1}/\sqrt{n}\), \(\lambda_1 = d > \lambda_2 \geq \dots\), et \(\lambda_i < d\) pour \(i \geq 2\) (égalité seulement si composante connexe distincte). Alors \(P^\ell = \sum_i \big(\frac{\lambda_i + 1}{d+1}\big)^\ell u_i u_i^\top\) ; le terme \(i = 1\) vaut exactement \(\frac{\mathbf{1}\mathbf{1}^\top}{n}\) ; tous les autres ont un rapport \(\frac{\lambda_i + 1}{d + 1} < 1\) (et \(\geq 0\) si le graphe n'est pas biparti ; sinon \(> -1\) en valeur absolue) et décroissent géométriquement. Toute la information des composantes non constantes est effacée : tous les nœuds convergent vers le même vecteur ligne-moyenne — les plongements s'effondrent. ∎
Avec poids et non-linéarités, le phénomène persiste (collapse de rang ; Oono & Suzuki, ICLR 2020) : c'est une limite structurelle de la profondeur GCN. Remèdes :
  • Jumping Knowledge (Xu et al., 2018) : la readout agrège toutes les profondeurs \(h_v = \mathrm{JK}(h_v^{(1)}, \dots, h_v^{(L)})\) (concat / max / LSTM-attention) : chaque nœud choisit son échelle ;
  • résidus et normalisations (GCNII, APPNP — développés au M2, ch. 2) ;
  • en pratique : 2-4 couches suffisent et suffisent souvent — la profondeur utile est celle de la dépendance statistique de la tâche.
Deuxième limite structurelle — l'over-squashing (goulots topologiques) — est différente : elle concerne le canal et non la représentation, et se traite par rewiring ; tout le sujet est au M2, ch. 2. Troisième limite : l'expressivité bornée par 1-WL (M2, ch. 1). 
import torch
from torch_geometric.nn import GCNConv, GATConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root="/tmp/Cora", name="Cora")   # 2708 noeuds, 5429 aretes, 7 classes
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self, d_in, d_hid, n_classes):
        super().__init__()
        self.c1, self.c2 = GCNConv(d_in, d_hid), GCNConv(d_hid, n_classes)
    def forward(self, x, edge_index):
        return self.c2(torch.relu(self.c1(x, edge_index)), edge_index)

model = GCN(dataset.num_features, 64, dataset.num_classes)
opt = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)
for epoch in range(200):
    opt.zero_grad()
    out = model(data.x, data.edge_index)
    loss = torch.nn.functional.cross_entropy(out[data.train_mask], data.y[data.train_mask])
    loss.backward(); opt.step()
acc = (model(data.x, data.edge_index).argmax(1)[data.test_mask]
       == data.y[data.test_mask]).float().mean()
print(f"Cora test accuracy : {acc:.3f}")   # ~0.81 avec ce reglage simple

6. Link prediction et auto-encodeurs de graphes

Définition 6.1 — Link prediction Prédire l'existence (ou le type) d'une arête manquante \((u, v)\) : la tâche la plus répandue en industrie — recommandation (« qui va aimer quoi ? »), complétion de graphes de connaissances (« ce médicament cible cette protéine ? »), prédiction d'interactions futures (ch. 5 du M2 pour le temporel). Protocole : masquer une fraction des arêtes (10 %), en échantillonner autant de « négatifs » (paires non adjacentes), scorer toutes les paires, mesurer AUC / Hits@k.
GAE / VGAE (Kipf & Welling, 2016) — auto-encodeurs de graphes GAE : encoder \(Z = \mathrm{GCN}(X, A)\) ; décoder par produit scalaire — la probabilité de reconstruction d'une arête : $$p(A_{uv} = 1 \mid z_u, z_v) = \sigma(z_u^\top z_v).$$ Entraînement : maximiser la vraisemblance des arêtes observées et minimiser celle des négatifs — la cross-entropy du negative sampling du ch. 3, transposée : $$\mathcal{L} = -\sum_{(u,v) \in E^+} \log \sigma(z_u^\top z_v) \; - \sum_{(u,v') \in E^-} \log \big(1 - \sigma(z_u^\top z_{v'})\big).$$ VGAE : encoder gaussien variationnel \(q(Z | X, A) = \prod_i \mathcal{N}(z_i;\ \mu_i, \mathrm{diag}(\sigma_i^2))\) avec \(\mu = \mathrm{GCN}_\mu(X, A)\), \(\log\sigma = \mathrm{GCN}_\sigma(X, A)\), prior \(\mathcal{N}(0, I)\) ; on maximise l'ELBO (module Deep Learning) : $$\mathcal{L} = \mathbb{E}_{q}[\log p(A | Z)] - \mathrm{KL}\big(q(Z|X,A)\,\|\,\mathcal{N}(0, I)\big),$$ reparamétrisation \(z_i = \mu_i + \sigma_i \odot \varepsilon\), \(\varepsilon \sim \mathcal{N}(0, I)\). Résultats : sur Cora, AUC \(\approx 0{,}91\) (GAE) et \(\approx 0{,}92\) (VGAE) — le prior régularise le produit scalaire (cf. le rapprochement avec l'inférence SBM, ch. 9).
Scorer des paires : le choix de la fonction de décision
  • produit scalaire \(z_u^\top z_v\) — décomposition de rang \(d\), symétrique, liée à NetMF (ch. 3) ;
  • MLP sur \((z_u \odot z_v, z_u - z_v)\) ou concaténation — asymétrique (important en recommandation : « A achète B » ≠ « B achète A ») ;
  • distances relationnelles (KGC, ci-dessous) ;
  • négatifs : uniformes (faciles) vs durs — paires partageant un voisin (popularity-biased) ; le choix des négatifs change le rang appris (module Deep Learning, contraste ; module NLP pour l'analogie word2vec).
PinSage (Ying et al., 2018) — la recommandation à l'échelle industrielle Le déploiement Pinterest de GraphSAGE : graphe utilisateur-épingle de 3 milliards de nœuds et 18 milliards d'arêtes, entraîné par minibatchs. Deux différences clés avec GraphSAGE :
  1. échantillonnage par importance : au lieu de voisins uniformes, les \(T\) voisins de plus haut score de PageRank normalisé par nœud — les mêmes « portes d'entrée » servent à tous les minibatchs, ce qui maximise la réutilisation du cache ;
  2. loss ranking (hinge margin) : \(\max(0, m - s(u, v^+) + s(u, v^-_h))\) avec \(v^-_h\) hard negative (épingle populaire mais non cliquée) ; la production exige des candidats classés par score approximé (recherche vectorielle — module NLP/Multimodal).
Lesson LLGA : à cette échelle, l'architecture compte moins que le système (échantillonnage, cache, GPU) — c'est le pont vers le ch. 7.
Complétion de graphes de connaissances (KGC) Le link prediction sur graphe hétérogène typé (têtes \(h\), relations \(r\), queues \(t\)) :
  • TransE (Bordes et al., 2013) : plongements dans \(\mathbb{R}^d\) avec le score d'énergie \(f(h, r, t) = -\|h + r - t\|\) — la relation est un translation ; entraînement marginal (positifs vs négatifs corrompus) ; illuminant mais limité (relations 1-N, symétriques) ;
  • R-GCN + score (ch. 5) : l'encodeur propage sur le graphe typé, un décodeur (DistMult : \(\langle h, \mathrm{diag}(r), t \rangle\)) score les triplets — l'architecture « encode-décode » domine ;
  • Lien GraphRAG : un KG d'entreprise complété par KGC devient requêtable par un LLM (ch. 11) ; les déficits de complétion guident la collecte de données — boucle donnée/modèle propre au métier LLGA.

7. GNN à l'échelle

Pourquoi le full-batch ne passe pas Le gradient d'une couche GCN mobilise tout le graphe : mémoire des activations \(\mathcal{O}((|V| + |E|) d)\) par couche, sans parler de la densification des couches profondes. Sur ogbn-products (2,4 millions de nœuds, 61,9 millions d'arêtes), le full-batch ne tient pas sur un GPU ; trois familles de solutions, toutes fondées sur le même constat : la dépendance d'un nœud à \(L\) couches se limite à son \(L\)-voisinage.
7.1 — Minibatching par voisinage (GraphSAGE / NeighborSampler) Pour un batch de nœuds cibles \(\mathcal{B}\) et une profondeur \(L\) avec des tailles d'échantillonnage \((s_L, \dots, s_1)\) (fanouts) : 
pour l = L .. 1 :                                    # de la couche profonde vers la surface
    N_l = union des voisins echantillonnes (s_l par noeud) des noeuds de N_{l+1}
    N_{l+1/2} = N_l echantillonne                    # sous-graphe de calcul
calculer les representations couche par couche sur le sous-graphe
mettre a jour les parametres avec la loss sur les sorties de B uniquement
Taille du sous-graphe : \(|\mathcal{B}| \times (1 + s_L (1 + s_{L-1}(\dots)))\) ; avec \(L = 2\), \(s_1 = s_2 = 10\), un batch de 1 nœud touche au plus \(1 + 10 + 100 = 111\) nœuds — borné, indépendant de \(n\). Deux subtilités : (i) l'estimateur est non biaisé en espérance pour la moyenne sur voisins, mais la variance explose dans les hubs (d'où des fanouts décroissants) ; (ii) les échantillonnages imbriqués créent du calcul redondant entre batchs (le « voisinage expansif » ; NeighborLoader de PyG implémente exactement ceci).
7.2 — Cluster-GCN (Chiang et al., 2019) : partitionner Partitionner le graphe en \(k\) clusters (METIS), chaque batch = un cluster entier : l'entraînement GCN sur le sous-graphe induit coûte \(\mathcal{O}(|E_c| d + |V_c| d^2)\) et chaque époque totale coûte \(\mathcal{O}(|E|)\) — comme le full-batch, mais en mémoire constante, et les GCN profonds redeviennent entraînables. Le prix : le biais de partition — les arêtes inter-clusters sont invisibles pendant le pas ; correction : matrice d'adjacence par blocs, \(\bar A = A + \lambda\,\mathrm{diag}(A)\) (relier chaque cluster à lui-même) et de temps en temps ré-échantillonner les partitions. Mieux encore : relier les clusters par un « graphe virtuel » des clusters — précurseur des hiérarchies de GraphRAG (ch. 11).
7.3 — GraphSAINT (Zeng et al., 2020) : échantillonner des sous-graphes, sans biais Renverser la perspective : échantillonner d'abord un sous-graphe \(\mathcal{G}_s\) (par nœuds, par arêtes, ou par marches aléatoires), y calculer un gradient corrigé. La clé est la normalisation par probabilité de couverture : si le sous-graphe inclut le nœud \(v\) avec ses arêtes couvertes avec probabilités \(p_v, p_{uv}\), l'estimateur repondéré $$\hat\nabla = \sum_{v \in \mathcal{G}_s} \frac{1}{p_v} \nabla_v + \sum_{(u,v) \in \mathcal{G}_s} \Big(\frac{1}{p_{uv}} - \frac{1}{p_u} - \frac{1}{p_v}\Big) \nabla_{uv}$$ est sans biais pour le gradient full-batch — le papier le démontre en développant l'espérance sur le schéma d'échantillonnage. Bénéfice caché : les batchs sont « denses » (pas de voisinage expansif), et le sampling par marches capture la structure communautaire. La figure générale : biais-variance-mémoire — neighbor-sampling (variance forte, biais nul) ; cluster-GCN (biais de partition, variance nulle) ; GraphSAINT (sans biais par repondération, variance contrôlée par le sampling RW). Ces compromis sont le pain quotidien du M2, ch. 6 (et du module Emerging ML pour le parallèle federated : partitions = clients).

9. Génération de graphes

Problème Échantillonner \(G \sim p_\theta(G)\) où \(p\) est appris sur une famille de graphes (molécules actives, réseaux routiers…) — éventuellement conditionné par une propriété cible (« génère une molécule avec cette activité ») ou par du texte (text-to-graph). C'est le versant « Generative AI » du titre du master. Trois difficultés propres aux graphes : (i) taille variable (\(n\) aléatoire) ; (ii) sorties discrètes (types d'atomes, d'arêtes) ; (iii) espace quotienté par l'isomorphisme — deux adjacences permutées sont le même graphe : il faut des modèles échangeables (théorie ci-dessous).
9.1 — Le modèle limite : graphons et échangeabilité Un graphon est une fonction mesurable \(W : [0,1]^2 \to [0,1]\). Étant donné \(W\) et \(n\) : tirer \(x_i \sim \mathcal{U}([0,1])\), puis chaque arête \((i, j)\) indépendamment avec probabilité \(W(x_i, x_j)\) — un graphe \(G_n\) à \(n\) sommets. Le théorème d'Aldous-Hoover garantit que toute suite de graphes échangeables (loi invariante par permutation des sommets) admet un graphon limite au sens de la métrique de coupe (Lovász, Large Networks and Graph Limits, 2012). Le lien apprentissage :
  • estimation : estimer \(W\) depuis un grand graphe = approcher par une fonction en escalier constant par blocs — partitionner les \(n\) sommets en \(k\) blocs de tailles \(n_b\), poser \(\hat W = \frac{e_{bb'}}{n_b n_{b'}}\) sur le bloc \((b, b')\) (densités empiriques) ; la partition est le problème — et SBM/clustering le résolvent ;
  • génération : un modèle de graphes appris vise implicitement un \(\hat W\) (grandes molécules : n grand, distribution cible structurée) ;
  • théorie des deep generative models de graphes : les architectures échangeables (invariantes aux permutations des nœuds) sont celles qui approximent des graphons — c'est le critère de cohérence des modèles ci-dessous.
9.2 — Modèles aléatoires classiques : ER et SBM (avec les maths)
  • Erdős-Rényi \(G(n, p)\) : toutes les arêtes iid de probabilité \(p\) ; degrés \(\sim \mathrm{Bin}(n-1, p)\), aucune communauté ; phénomènes de seuil (en \(\frac{\log n}{n}\)) pour la connexité — la référence « nulle » contre laquelle tester la structure (module Refresher Statistics) ;
  • SBM (Holland et al., 1983) : chaque nœud a un bloc latent \(z_i \in \{1..k\}\) (uniforme), et $$P(A_{ij} = 1 \mid z_i = a, z_j = b) = B_{ab}.$$ Vraisemblance : \(\log P(A | z, B) = \sum_{a,b} n_{ab} \log B_{ab} + (n_a n_b - n_{ab}) \log(1 - B_{ab})\) (avec \(n_{ab}\) = arêtes observées entre blocs \(a, b\)) ; inférence par maximum de vraisemblance (EM) ou bayésienne (échantillonnage MCMC) ; détectabilité : sous le seuil de Kesten-Stigum, aucun algorithme ne retrouve les blocs — la phase où le spectral clustering (ch. 4) est exactement à la frontière. Génération : échantillonner \(z\) puis \(A\) ; variante DCSBM (degrés corrigés). Le SBM sert dans les deux sens : générer des graphes synthétiques réalistes (bénéfice : contrôle total) et inférer les blocs (clustering statistiquement fondé, sans limite de résolution contrairement à la modularité du ch. 0) ; le topic modeling par SBM (TopSBM, Gerlach et al., 2018) traite un corpus documents-termes comme un SBM bipartite — la généralisation « statistique » du Graph of Words du ch. 10.
9.3 — VAE de graphes : GraphVAE et NeVAE GraphVAE (Simonovsky & Komodakis, 2018) : encoder un GNN, decoder en un bloc \(\hat A, \hat X, \hat E\) (adjacence entière) ; le décalage des sorties à la vérité exige une matrice de correspondance (matching hongrois) — le problème de l'ordre des nœuds se paye ici (cf. GOAT, ch. 10). NeVAE (Samanta et al., AAAI 2019) : VAE granulaire pensé pour la chimie :
  1. encodeur parcimonieux : un embedding par atome (pas d'adjacence pleine — mémoire \(\mathcal{O}(n)\) au lieu de \(\mathcal{O}(n^2)\)), messages MPNN entre atomes ;
  2. décodeur séquentiel contraint par valence : à chaque pas, un nouvel atome est ajouté et ses liaisons tirées par des têtes de probabilité conditionnées à la valence restante — un carbone ne peut pas recevoir 5 liaisons ; l'aromaticité est traitée par des têtes dédiées ;
  3. correction de bruit : rééchantillonnage local des liaisons invalides pendant l'entraînement — la pénalité des solutions interdites est adoucie ;
  4. résultat : validité chimique > 90 % avant post-traitement, là où les GraphVAE non contraints en produisent très peu.
Morale : injecter la connaissance du domaine (valence) dans l'architecture bat le post-traitement (sanitization RDKit) — réutilisée par toutes les méthodes suivantes.
9.4 — Autorégressifs : GraphRNN (You et al., 2018) Générer un graphe = générer une séquence. Ordonner les nœuds \(1, 2, \dots\) (tout ordre : le modèle doit être robuste à ce choix — en pratique ordres BFS canoniques) ; le graphe est alors la suite de lignes de l'adjacence \(S^i = (A_{i1}, \dots, A_{i,i-1}) \in \{0,1\}^{i-1}\). Deux niveaux : $$\text{niveau nœud : } h_i = \mathrm{RNN}_{node}(h_{i-1}, s_i), \qquad \text{niveau arête : } P(S^i | h_i) = \prod_{j < i} \mathrm{RNN}_{edge}(s_{ij}),$$ où l'état \(h_i\) conditionne le RNN d'arêtes qui émet \(S^i\) bit par bit (catégoriel Bernoulli par position) ; l'entraînement maximise la vraisemblance séquentielle (teacher forcing). Propriétés : échangeabilité approchée par l'usage d'ordres BFS (le préfixe est invariant aux permutations intra-niveaux) ; complexité \(\mathcal{O}(n)\) pas de décodage, \(\mathcal{O}(n)\) par pas → quadratique — très raisonnable pour \(n \leq 100\). Limites : sensibilité à l'ordre (les anneaux aromatiques dépendent du point de départ) ; conditionnement par propriétés malaisé (d'où les modèles ci-dessous). Ce schéma « séquentialiser le graphe » est exactement celui du LLM sur texte — la convergence text-to-graph est naturelle (ch. 11).
9.5 — Diffusion discrète : DiGress (Vignac et al., 2023) L'état de l'art moléculaire 2023-2026 transpose la diffusion du module Multimodal GenAI aux catégories (types d'atomes, types de liaisons). Processus avant (bruitage) : à chaque pas, chaque type de nœud et d'arête est re-tiré  $$q(X_t | X_{t-1}) = \mathrm{Cat}\big(X_t;\ Q_t X_{t-1}\big), \qquad q(E_t | E_{t-1}) = \mathrm{Cat}\big(E_t;\ \bar Q_t E_{t-1}\big),$$ où \(Q_t\) sont des matrices de transition (une ligne = loi du nouveau type sachant l'ancien) ; après \(T\) pas, la loi stationnaire est la marginale des datasets (distribution des atomes/liaisons). Processus arrière (débruitage) : un GNN \(\theta_\phi\) (MPNN + attention) prédit \(X_0\) et \(E_0\) propres à partir de \((X_t, E_t)\), puis un pas de débruitage bayésien \(q(X_{t-1}|X_t, \hat X_0)\) est dérivé en fermé ; perturbations : les arêtes sont aussi ajoutées/retirées pendant le bruitage (topologie discrète). Trois choix gagnants : pertes auxiliaires (valence, longueurs de liaisons) pour la chimie ; échangeabilité garantie — le modèle ne voit jamais d'ordre de nœuds (contrairement à GraphRNN) ; conditionnement par graphe (inpainting) : on fige un squelette et on génère le reste — génération conditionnelle « molécule cible ». Cousin 3D : EDM/EDT (positions équivariantes — M2, ch. 9). Le papier de l'équipe NGG (ch. 10) transpose cette recette dans l'espace latent pour conditionner par des features de graphe.
9.6 — Évaluer des graphes générés : fidélité distributionnelle Une génératrice n'est pas notée image par image mais distribution contre distribution :
  • validité / unicité / nouveauté (chimie) : % de molécules syntaxiquement valides, distinctes, absentes de l'entraînement — un modèle qui mémorise a une nouveauté de 0 ;
  • MMD structurels : distance maximale des moyennes \(\mathrm{MMD}^2 = \big\| \mathbb{E}_{G \sim p}[\phi(G)] - \mathbb{E}_{G \sim q}[\phi(G)] \big\|^2\) avec \(\phi\) = histogrammes de degrés, coefficients de clustering, comptages de motifs/orbites (les triangles du ch. 0 !) — la remarque : ces features sont exactement ce que 1-WL ne capture pas toujours (M2, ch. 1) ;
  • FCD (Fréchet ChemNet Distance) : distance de Fréchet entre les gaussiennes des embeddings ChemNet des molécules générées vs réelles — l'analogue exact du FID des images (module Multimodal GenAI) ;
  • distances OT : comparer des graphes sans correspondance de nœuds = transport optimal Gromov-Wasserstein (module Optimal Transport) ; les MMD ci-dessus en sont des cas particuliers à noyau.
9.7 — Génération conditionnelle : le vrai produit industriel Ordonner par propriété cible (solubilité, docking), conditionner par texte (« un antibiotique contre X »), par squelette (R-group optimization), par graphe partiel (inpainting) ; trois mécanismes : (i) conditionnement en entrée (concat du descripteur — NGG) ; (ii) guidage par gradient sur un prédicteur de propriété pendant l'échantillonnage (le classifier guidance des images) ; (iii) recherche dans l'espace latent (optimisation bayésienne — le pipeline classique QSAR). C'est ici que la rencontre GNN × LLM est la plus fertile (ch. 11) : le LLM propose, le GNN évalue, la boucle optimise.

10.1 — Graph of Words : du document au graphe (Rousseau & Vazirgiannis ; Tixier, Malliaros & Vazirgiannis) La représentation « sac de mots » (bag-of-words) ignore l'ordre des mots ; le graph of words le restaure partiellement :
  1. construction : fenêtre glissante de taille \(w\) (typiquement 2-10) ; nœuds = termes uniques (pondérés par fréquence) ; arête \((u, v)\) si \(u\) et \(v\) co-occurrent dans une fenêtre, pondérée par le nombre de co-occurrences ; un document = un graphe ;
  2. mots-clés : extraire les nœuds « centraux » du graphe ; Rousseau & Vazirgiannis (ECIR 2015) retiennent la k-core principale (le k-core maximal : le plus grand sous-graphe de degré min \(\geq k\)), Tixier et al. (EMNLP 2016) classent par dégénérescence (le cœur domine la classification) ;
  3. classification de documents : un corpus = un ensemble de graphes → classification de graphes (ch. 2) ; le passage bag-of-words → graph-of-words enrichit les features de co-occurrence et améliore les classifieurs textuels classiques.
Positionnement : c'est le jumeau symétrique du ch. 3 — DeepWalk applique word2vec aux graphes, Graph of Words applique les graphes au texte. Posterité : graph-of-words + CNN de graphes pour la classification hiérarchique ; topic modeling par SBM bipartite (TopSBM, Gerlach et al., 2018) ; et les index de GraphRAG (ch. 11) qui indexent entités et co-occurrences — un graph of words d'entreprise.
10.2 — Path Neural Networks (Michel, Nikolentzos, Lutzeyer & Vazirgiannis, ICML 2023) Idée : la couche GNN du ch. 5 agrège des marches de longueur 1 (les voisins) ; les chemins de longueur \(\ell\) portent plus d'information structurelle. L'opérateur de chemins : pour chaque nœud \(v\), on considère l'ensemble \(\mathcal{P}_v^{(\ell)}\) des chemins simples de longueur \(\ell\) partant de \(v\) ; chaque chemin \(p = (v, u_1, \dots, u_\ell)\) est encodé par un RNN (GRU) : $$m_p = \mathrm{GRU}\big(h_{u_\ell}^{(\ell)}, \mathrm{GRU}(\dots \mathrm{GRU}(h_{u_1}^{(0)}, h_v^{(0)})\dots)\big), \qquad h_v^{(\ell)} = \mathrm{AGG}\big(\{m_p : p \in \mathcal{P}_v^{(\ell)}\}\big).$$ Trois variantes selon \(\mathcal{P}_v\) : plus courts chemins (PathNN-s), marches aléatoires (PathNN-r), chemins échantillonnés dans le voisinage (PathNN-n) — l'échantillonnage borne le coût, car le nombre de chemins simples croît exponentiellement. Résultats : précisions supérieures ou égales aux GNN canoniques sur les benchmarks de classification (nœuds et graphes, dont ZINC pour les molécules), avec une complexité maîtrisée ; l'analyse d'expressivité (ce que les chemins voient que les marches ignorent — cycles, distances) est approfondie au M2, ch. 1 et 8. Positionnement dans le cours : la généralisation « naturelle » du ch. 3 (marches de DeepWalk) et du ch. 5 (voisinages à 1 saut).
10.3 — Graph Ordering Attention Networks (Chatzianastasis, Lutzeyer, Dasoulas & Vazirgiannis, AAAI 2023) — les travaux de J. Lutzeyer sur l'ordre et l'expressivité Les agrégateurs invariants (somme/moyenne/max) jettent toute information d'ordre — mais l'ordre local des voisins contient du signal (penser à un texte : le sac de mots perd la syntaxe). GOAT apprend un ordre local :
  1. une attention ordonne les voisins de \(v\) (scores appris sur \((h_v, h_u)\), tri) ;
  2. la séquence ordonnée est traitée par un RNN — modèle de séquence local, donc strictement plus expressif que l'agrégation invariante ;
  3. les niveaux GOAT (ordre à rayon croissant) se composent couche après couche.
Le double positionnement : en expressivité, GOAT distingue des graphes que 1-WL confond (rejoint le M2, ch. 1) ; en génération, le choix d'ordre est LE nœud gordien des modèles autorégressifs (GraphRNN, ch. 9.4 ; GraphVAE, ch. 9.3) — apprendre l'ordre plutôt que le subir est une contribution transversale. C'est aussi une réponse élégante à la question GraphSAGE-LSTM du ch. 5 (le voisinage y était ordonné aléatoirement).
10.4 — Deux ponts récents vers la GenAI : NGG et le pseudo-code prompting
  • NGG — Neural Graph Generator (Evdaimon et al., avec Nikolentzos & Vazirgiannis, 2024) : diffusion latente conditionnée par des features de graphe (spectre, degrés…) : un encodeur GNN comprime des graphes en vecteurs latents, un modèle de diffusion y apprend la distribution et le conditionnement ; on génère ensuite des graphes présentant les features demandées — le ch. 9.5 transposé dans l'espace latent, avec le spectre (ch. 4) comme descripteur ; applications : données synthétiques, anonymisation, détection d'anomalies distributionnelles ;
  • Pseudo-code prompting (Skianis, Nikolentzos & Vazirgiannis, 2024) : faire raisonner les LLMs sur des graphes (composantes connexes, plus courts chemins…) en leur donnant des instructions en pseudo-code plutôt qu'en langue — gains systématiques sur toutes les tailles de LLM testées ; détaillé au ch. 11.
Ces quatre axes (texte↔graphe, chemins, ordre, génération/diffusion, LLM) couvrent exactement la carte du master — le M2, ch. 8, les approfondit côté théorie.

11. Graphes × LLMs : GraphRAG et l'hybride

11.1 — Le pipeline GraphRAG industriel complet (d'après Edge et al., 2024)
  1. ingestion : découpage du corpus en morceaux (chunks) ; extraction par LLM des entités (NER) et relations (extraction de relations typées, cf. module NLP) au format triplet (sujet, relation, objet, passage source) ; résolution d'entités (aliases) ; le graphe se construit incrémentalement — chaque arête garde sa ou ses sources ;
  2. communautés : détection de communautés (Leiden — variante Louvain, ch. 0) sur le graphe d'entités ; pour chaque communauté (à chaque niveau de la hiérarchie), un LLM résume les entités, relations et thèmes ; les résumés s'agrègent de bas en haut ;
  3. index hybride : le graphe plus un index vectoriel des chunks et des résumés (le RAG classique reste utile pour les requêtes locales) ;
  4. requêtes globales (« quels sont les thèmes majeurs du corpus ? ») : map-reduce sur les résumés de communautés — chaque communauté répond partiellement, un LLM synthétise ; requêtes locales (« qui travaille avec qui sur X ? ») : élargissement du voisinage de l'entité X (entités liées, chunks sources) puis réponse ancrée ;
  5. évaluation : comparaison texte vectoriel RAG vs GraphRAG sur la complétude et la diversité des réponses ; coût : l'ingestion LLM est chère — amortie par des milliers de requêtes.
Lecture LLGA : chaque étage est un objet du cours — clustering (ch. 0), link prediction pour la complétion du KG (ch. 6), embeddings pour l'index vectoriel (ch. 3), échangeabilité des résumés (génération, ch. 9).
11.2 — Faire raisonner le LLM sur le graphe : encodage et pseudo-code
  • sérialisation : décrire le (sous-)graphe en texte (listes d'arêtes, adjacence, incidents) ; le benchmark NLGraph (Wang et al., 2023) montre que les LLMs échouent sur des tâches élémentaires (cycles, connexité, plus courts chemins) dès que la taille croît, même en few-shot ; l'étude « Talk like a Graph » (Fatemi et al., 2024) compare les encodages — aucun ne domine partout ;
  • pseudo-code prompting (Skianis, Nikolentzos & Vazirgiannis, 2024 — équipe du master) : fournir au LLM l'algorithme en pseudo-code plutôt qu'une description en langue ; 
    entree : liste d'aretes E, noeud s
visites = {s} ; pile = [s]
tant que pile non vide :
    v = pile.pop()
    pour u in voisins(v) dans E :
        si u non dans visites : visites.ajouter(u) ; pile.push(u)
sortie : visites   # composante connexe de s
    le LLM exécute la trace — gains systématiques par rapport aux instructions naturelles, toutes familles de LLM confondues ; la leçon : sur les structures discrètes, le langage de programmation est un meilleur « prompt » que le langage naturel ;
  • hybrides GNN + LLM : le GNN encode la structure (ch. 5) et injecte : (a) soft tokens dans le prompt (projeter les embeddings de GNN dans l'espace du LLM) ; (b) rappel structurel — le GNN retrouve les passages reliés (comme le KG de 11.1, mais appris) ; (c) distillation croisée — le LLM annoté entraîne le GNN, le GNN filtre les hallucinations du LLM.
11.3 — Limites et hygiène GraphRAG
  • l'extraction hallucine (entités inexistantes) : contrôler par double-passe et ancrage sur chunks ;
  • le graphe est une approximation — les requêtes dépendent de sa qualité ; blinder par KGC (ch. 6) avant de requêter ;
  • le coût d'ingestion vs le gain sur les requêtes relationnelles : pour un FAQ mono-document, le RAG vectoriel suffit ; GraphRAG paie quand les questions sont multi-sauts, agrégatives ou globales ;
  • privacy : le graphe agrège des faits dispersés — risque de réidentification (M2, ch. 7).
  • Agents sur graphes : le plan d'un système multi-agents est un graphe (DAG d'orchestration) ; le « graph engineering » (2026) = programmer la topologie des agents — la boucle master : le graphe dans le modèle (attention), le graphe pour le modèle (RAG), le graphe entre les modèles (agents).
