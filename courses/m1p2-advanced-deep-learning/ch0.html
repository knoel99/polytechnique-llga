0. Rappels : transformers, optimisation, normalisation

Rappels (module Deep Learning, chapitres 2–6)
  • Rétropropagation : règle de la chaîne appliquée au graphe de calcul ; différentiation automatique (autograd) — DL ch. 2 ;
  • Optimiseurs : SGD avec moment, Adam/AdamW (\(m_t, v_t\), corrections de biais) — DL ch. 3 ; planification de taux d'apprentissage ;
  • Attention : \(\mathrm{softmax}(QK^\top / \sqrt{d_k}) V\) — multi-têtes, encodage positionnel, l'architecture encodeur-décodeur — DL ch. 6 ; le module NLP l'applique au texte, le module M2 LLMs à l'échelle ;
  • Normalisation : batch norm (statistiques du lot) vs layer norm (par exemple, indépendante du lot) ; connexions résiduelles ;
  • Transfer learning : pré-entraînement + fine-tuning, têtes de classification — DL ch. 8.

Format du module : un séminaire de lecture. Chaque chapitre est centré sur un papier pivot que nous lisons intégralement : motivation, méthode, expérience — et nous critiquons les protocoles (jeux de données, graines, budgets de calcul) comme un relecteur. Les quatre enseignants interviennent chacun sur leur terrain (chapitre 10) : vision et vidéo (Kalogeiton), graphes (Lutzeyer), modèles de diffusion (Zhu), génération multimodale et vidéo (Wang). Les chapitres 7–8 outillent le projet final (chapitre 11) : répliquer un résultat publié dans un budget de calcul donné — l'épreuve de vérité du deep learning moderne.

Définition 0.1 — Notations du module Une couche d'auto-attention à \(h\) têtes sur une séquence de \(n\) tokens de dimension \(d\) (têtes de dimension \(d_k = d / h\)) ; un bloc = attention multi-têtes + MLP (facteur d'expansion \(4\)), chacun précédé de LayerNorm (pré-norme) et court-circuité par une connexion résiduelle. On note \(L\) le nombre de blocs, \(d_{\mathrm{ff}} = 4d\). Le « budget de calcul » d'un passage avant se mesure en FLOPs (opérations flottantes) ; convention approximative : un modèle à \(\theta\) paramètres entraîné sur \(D\) tokens coûte \(\approx 6\,\theta D\) FLOPs.
