0. Rappels : séries et analyse

Rappels L3 mobilisés
  • Séries trigonométriques : toute fonction périodique « raisonnable » se décompose en \(\sum_k c_k e^{ik\omega_0 t}\) — base orthogonale des exponentielles complexes.
  • Intégration et changement de variable : le théorème de Fubini (permuter \(\int\int\)) justifie tous les calculs de convolution.
  • Produit scalaire hermitien \(L^2\) : \(\langle f, g\rangle = \int f(t)\,\overline{g(t)}\,dt\) — Fourier = changement de base orthonormée infinie.
  • Convolution : \( (f*g)(t) = \int f(\tau) g(t - \tau)\,d\tau\) ; dérivation sous l'intégrale, \(\widehat{f'} = i\omega \hat f\).

1. Signaux et systèmes linéaires

Définition 1.1 — Signal, système LTI Un signal est une fonction \(x : \mathbb{R} \to \mathbb{R}\) (ou \(\mathbb{C}\)), ou une suite \(x : \mathbb{Z} \to \mathbb{R}\) (signal discret). Un système transforme un signal en un autre ; il est LTI (linéaire invariant dans le temps) si \(x \mapsto y\) vérifie : linéarité, et \(x(\cdot - \tau) \mapsto y(\cdot - \tau)\).
Proposition 1.2 — Représentation par convolution Tout système LTI est entièrement décrit par sa réponse à l'impulsion \(h = T(\delta)\), et $$y(t) = (x * h)(t) = \int_{\mathbb{R}} x(\tau)\, h(t - \tau)\, d\tau.$$ Preuve : écrire \(x = \int x(\tau)\,\delta_\tau\), invoquer la linéarité puis l'invariance. La convolution est commutative, associative, distributive.
Exemple 1.3 — Convolutions élémentaires Moyenne glissante (\(h = \frac1M \mathbf{1}_{[0,M]}\)) : lisse ; dérivation discrète (\(h = \delta_{1} - \delta_0\)) : accentue ; intégrateur (\(h = \mathbf{1}_{t \geq 0}\)) : accumule. Un filtre = un choix de \(h\) ; sa transformée de Fourier dira ce qu'il fait (chapitre 3).

2. La série de Fourier

Théorème 2.1 — Décomposition en série de Fourier Soit \(f\) \(T_0\)-périodique, de carré intégrable. Avec \(\omega_0 = 2\pi/T_0\) : $$f(t) = \sum_{k \in \mathbb{Z}} c_k\, e^{ik\omega_0 t}, \qquad c_k = \frac{1}{T_0}\int_0^{T_0} f(t)\, e^{-ik\omega_0 t}\, dt,$$ la convergence ayant lieu en norme \(L^2\) (et ponctuellement sous régularité). Les \(c_k\) sont le spectre : \(|c_k|\) module, \(\arg c_k\) phase.
  • Interprétation : \(c_k\) = coordonnée de \(f\) sur le vecteur de base \(e^{ik\omega_0 t}\). Fourier = projection orthogonale, exactement comme une base orthonormée en dimension finie (rappel L3 : \(c_k = \langle f, e_k\rangle / \|e_k\|^2\)).
  • Vitesse de décroissance : si \(f\) est \(C^p\) par morceaux, \(c_k = \mathcal{O}(1/k^{p+1})\) — un signal lisse a un spectre qui décroît vite : fondement de la compression et de l'échantillonnage.
  • Égalité de Parseval : \(\frac1{T_0}\int |f|^2 = \sum_k |c_k|^2\) — l'énergie se lit dans le spectre.
Exemple 2.2 — Le carré Pour le signal carré impair \(f = \mathrm{signe}(\sin)\), \(c_k = 0\) pour \(k\) pair et \(c_k \propto 1/k\) pour \(k\) impair : les discontinuités excitent les hautes fréquences en \(1/k\) (phénomène de Gibbs : 9 % d'overshoot aux bords, quelle que soit la troncature). Démonstration par calcul direct des intégrales — exercice 1.

3. La transformée de Fourier

Définition 3.1 — Transformée de Fourier $$\hat x(\nu) = \int_{\mathbb{R}} x(t)\, e^{-i 2\pi \nu t}\, dt, \qquad x(t) = \int_{\mathbb{R}} \hat x(\nu)\, e^{i 2\pi \nu t}\, d\nu.$$ \(\nu\) en Hz (ou \(\omega\) en rad/s avec un facteur \(2\pi\)) ; la transformée « continue » généralise les coefficients de Fourier aux signaux non périodiques.
Proposition 3.2 — Propriétés fondamentales

Le duo clé : convolution ↔ multiplication Filtrer = convoluer en temps = multiplier en fréquence : \(y = x*h \iff \hat y = \hat x\,\hat h\), où \(H(\nu) = \hat h(\nu)\) est la réponse en fréquence. Passe-bas : \(H \approx 1\) pour \(|\nu| < \nu_c\), \(\approx 0\) au-delà. C'est aussi pour ça que la FFT accélère les convolutions des CNN : complexité \(\mathcal{O}(n \log n)\) au lieu de \(\mathcal{O}(n^2)\).
Théorème 3.3 — Incertitude (Gabor) $$\sigma_t \, \sigma_\nu \ \geq\ \frac{1}{4\pi},$$ où \(\sigma_t, \sigma_\nu\) sont les écarts-types en temps et en fréquence. On ne peut pas être simultanément localisé en temps et en fréquence : le sinus parfait (fréquence exacte) est étalé sur tout l'axe des temps, et l'impulsion de Dirac occupe toutes les fréquences.

4. Échantillonnage : le théorème de Shannon

Théorème 4.1 — Shannon-Nyquist Soit \(x\) à bande limitée : \(\hat x(\nu) = 0\) pour \(|\nu| \geq B\). Alors les échantillons \(x_n = x(n/f_s)\) avec \(f_s > 2B\) suffisent à reconstruire exactement : $$x(t) = \sum_{n \in \mathbb{Z}} x_n\, \mathrm{sinc}\Big(f_s\, t - n\Big), \qquad \mathrm{sinc}(u) = \frac{\sin(\pi u)}{\pi u}.$$
  • Spectre replié : si \(f_s \leq 2B\), les copies du spectre se chevauchent (aliasing) et l'information est irrémédiablement perdue — roues qui semblent tourner à l'envers au cinéma, moiré d'images.
  • Chaîne de traitement : signal analogique → filtre anti-repliement → échantillonnage \(f_s\) → quantification (bits) → numérique. CD audio : \(B = 20\) kHz ⇒ \(f_s = 44{,}1\) kHz, 16 bits.
import numpy as np
fs = 200                       # frequence d'echantillonnage
t  = np.arange(0, 1, 1/fs)
f0 = 60                        # signal 60 Hz
x  = np.sin(2*np.pi*f0*t)

X = np.fft.rfft(x)             # spectre (frequences positives)
freqs = np.fft.rfftfreq(len(x), 1/fs)
peak = freqs[np.argmax(np.abs(X))]
print("frequence dominante :", peak, "Hz")

# Aliasing : echantillonner a 80 Hz un signal de 60 Hz le "voit" a 20 Hz
fs2 = 80; t2 = np.arange(0, 1, 1/fs2)
x2 = np.sin(2*np.pi*f0*t2)
print("vu a :", np.fft.rfftfreq(len(x2),1/fs2)[np.argmax(np.abs(np.fft.rfft(x2)))], "Hz")

5. DFT, FFT et filtrage numérique

Définition 5.1 — DFT et FFT Pour \(x_0, \dots, x_{N-1}\) : $$X_k = \sum_{n=0}^{N-1} x_n\, e^{-i 2\pi k n / N}, \qquad k = 0, \dots, N-1.$$ La FFT la calcule en \(\mathcal{O}(N \log N)\) (diviser pour régner : paire/impair). Convolution circulaire : \(\mathrm{DFT}(x \circledast h) = X \cdot H\) — d'où la convolution linéaire par zero-padding à \(N \geq n + m - 1\).
Filtres numériques FIR : \(y_n = \sum_{k=0}^{M} b_k x_{n-k}\) — toujours stables, phase linéaire possibles, conçus par fenêtrage de la réponse idéale ; IIR : \(y_n = \sum b_k x_{n-k} - \sum_{j\geq1} a_j y_{n-j}\) — plus sélectifs à coefficients égaux, mais sensibles à la stabilité (pôles dans le disque unité). Fenêtres : rectangulaire (lobes \(-13\) dB), Hann/Hamming/Blackman (compromis largeur principale / lobes secondaires).
Exemple 5.2 — Débruitage passe-bas 
sig = x + 0.5*rng.standard_normal(len(x))
SIG = np.fft.rfft(sig)
SIG[np.abs(freqs) > 80] = 0            # coupure brutale a 80 Hz (zero-phase)
clean = np.fft.irfft(SIG, n=len(sig))
# En pratique on prefere une coupure douce (Butterworth, fenetre de Hann)

6. Analyse temps-fréquence et ondelettes

Définition 6.1 — STFT et spectrogramme $$\mathrm{STFT}_x(t, \nu) = \int x(\tau)\, w(\tau - t)\, e^{-i2\pi\nu\tau}\, d\tau,$$ avec \(w\) une fenêtre (Hann). Le spectrogramme \(|\mathrm{STFT}_x|^2\) décrit l'énergie selon le temps et la fréquence ; la résolution dans chaque axe obéit à l'incertitude de Gabor (th. 3.3) : fenêtre longue ⇒ bonne résolution fréquentielle, mauvaise temporelle.
  • Ondelettes : fenêtre à échelle variable — bonne localisation temporelle en haute fréquence, fréquentielle en basse fréquence. Ondelette mère \(\psi_{a,b}(t) = \frac1{\sqrt a}\psi\big(\frac{t-b}{a}\big)\) ; la CWT échantillonne \((a, b)\), la DWT construit une base orthogonale multirésolution (approximations + détails).
  • Banc de filtres : la DWT = cascade de filtres passe-bas/passe-haut suivie de décimation — la compression JPEG2000 repose dessus.
Spectrogramme = image Le spectrogramme Mel (échelle fréquentielle perceptuelle) est l'image que les réseaux convolutifs et les transformeurs audio consomment : Speech Technology (M2), transcription, et même les LLMs multimodaux (audio-in). Le traitement du signal est ainsi la porte d'entrée du ML sur l'audio.

7. Le signal pour le ML moderne

  • Convolution des CNN = convolution discrète du cours : le noyau appris est un filtre dont la FFT explique le comportement (les CNN apprennent des bancs de filtres orientés bords/textures — exactement les réponses en fréquence de Gabor).
  • Convolution sur graphes : le message passing GNN \(h \leftarrow \sigma(\tilde D^{-1/2}\tilde A \tilde D^{-1/2} h W)\) est une convolution au sens spectral — le filtre de Kipf & Welling est un polynôme de degré 1 du laplacien ; approfondi au module Graph ML.
  • Distances entre distributions spectrales : comparer deux signaux = comparer deux spectres. La distance de Wasserstein barycentrique entre gaussiennes a une forme fermée (\(W_2^2 = \|\mu_1 - \mu_2\|^2 + \|\Sigma_1^{1/2} - \Sigma_2^{1/2}\|_F^2\)) et le « spectral loss » OT est devenu standard pour comparer spectrogrammes — le pont direct de ce module vers Computational Optimal Transport (enseigné par le même professeur).
  • Positional encodings : sinus/cosinus des transformers = bases de Fourier ; les encodages de position sur graphes (LapEig) réutilisent les vecteurs propres du laplacien — encore Fourier.

Exercices

  1. Série du carré. Calculer les \(c_k\) du signal carré impair, vérifier la décroissance en \(1/k\) et illustrer le phénomène de Gibbs (sommes partielles à 5, 21, 101 harmoniques).
  2. Parseval. Vérifier numériquement l'égalité de Parseval sur un signal périodique échantillonné (comparer \(\sum|x_n|^2/N\) et \(\sum|X_k|^2/N^2\)).
  3. Repliement. Générer un chirp \(f(t) = 100 + 400t\) Hz échantillonné à \(f_s = 500\) Hz ; calculer le spectrogramme et interpréter la trace « fantôme » qui redescend ; à quelle fréquence apparente correspond \(f = 350\) Hz ?
  4. Filtre de Hann. Conception FIR passe-bas par fenêtrage : réponse idéale \(H(\nu) = \mathbf{1}_{|\nu| \leq \nu_c}\), multiplication par une fenêtre de Hann, transformée inverse. Tracer la réponse en fréquence pour \(M = 31\) et commenter le compromis transition/repliement.
  5. Convolution par FFT. Implémenter la convolution linéaire par zero-padding + FFT, mesurer les temps contre np.convolve pour \(n = m = 2^{14}\), et expliquer le croisement des complexités.
  6. Projet. Débruiter un enregistrement (bruit blanc ajouté) : spectrogramme → masquage temps-fréquence (atténuer les cases sous un seuil d'énergie) → reconstruction par ISTFT. Comparer SNR avant/après et discuter les artefacts musicaux.
