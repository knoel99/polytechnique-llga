0. Rappels : convexité et dualité LP

Rappels L3 mobilisés
  • Ensembles et fonctions convexes : pour \(f\) convexe, tout point stationnaire est un minimum global ; pour \(f\) strictement convexe, le minimiseur (s'il existe) est unique — l'OT entropique du ch. 3 en profite ;
  • Programmation linéaire : minimiser \(c^\top x\) sous \(Ax = b\), \(x \geq 0\) ;
  • Théorie des mesures : probabilité, espérance \(\mathbb{E}_\mu[f] = \int f\,d\mu\), loi image ;
  • Entropie : divergence de Kullback-Leibler, inégalité de Jensen — le moteur de la régularisation entropique.
Théorème 0.1 — Dualité LP : faible (démontrée), forte, complémentarité (démontrée) Primal : \(\min\{c^\top x \ : \ Ax = b,\ x \geq 0\}\) ; dual : \(\max\{b^\top y \ : \ A^\top y \leq c\}\).
  • Dualité faible : pour tout couple de points réalisables, \(c^\top x \geq b^\top y\).
  • Dualité forte : si le primal est réalisable et borné, le dual atteint son optimum et les valeurs coïncident.
  • Complémentarité : aux optimaux \(x^\star, y^\star\) : \(x^\star_j > 0 \Rightarrow (A^\top y^\star)_j = c_j\).
Faible : \(c^\top x \geq (A^\top y)^\top x = y^\top (Ax) = y^\top b\) (sommation des contraintes duales pondérées par \(x_j \geq 0\)). Forte : admise (séparation des polyèdres). Complémentarité : à l'optimum, \(0 = c^\top x^\star - b^\top y^\star = (c - A^\top y^\star)^\top x^\star = \sum_j \underbrace{(c - A^\top y^\star)_j}_{\geq 0}\, \underbrace{x^\star_j}_{\geq 0}\) : chaque terme est nul, d'où l'implication.∎
Proposition 0.2 — Mesure image (pushforward) et lemme de transfert (démontré) Pour \(T : \mathbb{R}^d \to \mathbb{R}^d\) mesurable, la mesure image est \(T_\#\mu(A) = \mu\big(T^{-1}(A)\big)\) (« la masse de ce qui part dans \(A\) »). Lemme de transfert : pour toute \(f\) mesurable positive ou bornée, $$\int f\,d(T_\#\mu) = \int f \circ T\,d\mu.$$
Pour \(f = \mathbf{1}_A\) c'est la définition. Les deux membres sont linéaires en \(f\) : l'égalité passe aux fonctions étagées positives, puis à toute positive par convergence monotone, puis aux bornées par différence. Ce « déplacer le changement de variable dans la mesure » est utilisé à chaque page de ce cours.∎
Proposition 0.3 — Convexité stricte : unicité (démontrée) Si \(F\) strictement convexe atteint son minimum en \(x^\star\), alors \(x^\star\) est l'unique minimiseur.
Si \(x \neq x^\star\) était aussi minimiseur, le point milieu \(m = \tfrac12(x + x^\star)\) donnerait \(F(m) < \tfrac12F(x) + \tfrac12F(x^\star) = \min F\) — contradiction.∎
Proposition 0.4 — KL ≥ 0 (démontré par Gibbs/Jensen), avec cas d'égalité Pour des distributions discrètes \(p, q\) (ou des densités) : $$\mathrm{KL}(p \| q) = \sum_i p_i \log\frac{p_i}{q_i} \ \geq\ 0, \qquad \text{égalité} \iff p = q.$$
\(\mathrm{KL}(p\|q) = -\sum_i p_i \log\frac{q_i}{p_i}\). La fonction \(\log\) est concave : par Jensen pondérée par \(p\) (inégalité de Gibbs), \(\sum_i p_i \log\frac{q_i}{p_i} \leq \log\sum_i p_i\frac{q_i}{p_i} = \log\sum_i q_i = 0\). L'égalité dans Jensen (concavité stricte de \(\log\)) exige \(q_i/p_i\) constant sur \(\{p_i > 0\}\), et la constante vaut 1 car les deux sont des probabilités.∎
