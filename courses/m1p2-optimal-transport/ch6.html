6. Fairness par le transport

Définition 6.1 — Le cadre : attribut sensible, parité démographique, equalized odds Données \((X, S, Y)\) : features, attribut sensible \(S\) (genre, origine…), étiquette \(Y\) ; prédicteur \(\hat Y = h(X)\) (éventuellement randomisé). Deux critères emblématiques :
  • Parité démographique (DP) : \(\hat Y\) indépendant de \(S\) — mêmes taux de décision positifs par groupe ;
  • Equalized odds (EO, Hardt, Price & Srebro, 2016) : \(\hat Y\) indépendant de \(S\) sachant \(Y\) — mêmes taux de vrais positifs et de faux positifs par groupe.
L'OT entre dans les deux scénarios : (i) pré-traitement — réparer la distribution des features par barycentre de Wasserstein ; (ii) post-traitement — coupler les lois de scores par groupes. Dans les deux cas, l'objet central est un couplage, c'est-à-dire un plan de transport du ch. 1.
Théorème 6.2 — Repair par barycentre de Wasserstein (Gordaliza, Del Barrio, Gamboa & Loubes, ICML 2019) Algorithme (repair complet, cas scalaire puis multivarié).
  1. Estimer les lois conditionnelles \(\mu_s = \mathcal{L}(X \,|\, S = s)\) par les quantiles empiriques \(Q_s = \hat F_s^{-1}\) (tri, prop. 2.6).
  2. Former le barycentre des \(\mu_s\) pondérées par les proportions \(p_s = \mathbb{P}(S = s)\) ; en 1D, le corollaire 2.8 donne sa fonction quantile point par point : $$Q^\star(u) \;=\; \sum_s\ p_s\, Q_s(u).$$
  3. Repair : remplacer chaque observation par son homologue au même niveau de quantile dans le barycentre : \(\tilde X_i = Q^\star\big(\hat F_s(X_i)\big)\) pour \(S_i = s\). En multivarié, remplacer le transport 1D par un plan de Sinkhorn entre chaque nuage et un barycentre entropique commun (déf. 4.3), puis utiliser la projection barycentrique de l'algorithme OTDA (ch. 4).
  4. Réentraîner le modèle sur les \((\tilde X_i, Y_i)\) sans l'attribut sensible.
Le repair complet garantit la parité démographique. Soit \(U_s = \hat F_s(X)\) pour \(X \sim \mu_s\) : \(U_s\) est (asymptotiquement) uniforme sur \([0,1]\), et \(\tilde X = Q^\star(U_s)\). Donc \(\mathcal{L}(\tilde X\,|\,S = s) = \mathcal{L}\big(Q^\star(U)\big)\) est la même loi pour tout \(s\) — le barycentre. Des conditionnelles identiques donnent l'indépendance : \(\mathbb{P}(\tilde X \in A, S = s) = \mathbb{P}(\tilde X \in A\,|\,S = s)\, \mathbb{P}(S = s) = \mathbb{P}(\tilde X \in A)\,\mathbb{P}(S = s)\). Tout prédicteur \(h(\tilde X)\) hérite alors de l'indépendance avec \(S\) : DP, quel que soit le classifieur aval.∎
Repair partiel : interpoler les quantiles, \(\tilde X^{(\lambda)} = (1-\lambda)\, Q_s(U_s) + \lambda\, Q^\star(U_s)\) avec \(\lambda \in [0, 1]\) — \(\lambda = 0\) : données intactes ; \(\lambda = 1\) : repair complet. Compromis utility/fairness : en balayant \(\lambda\), l'écart de parité démographique décroît (les conditionnelles se rapprochent en distance de Wasserstein, linéairement en \(\lambda\) pour le transport interpolé) tandis que l'accuracy décroît d'autant plus vite que \(X\) porte du signal corrélé à \(S\) : la courbe (écart de DP en abscisse, accuracy en ordonnée) est typiquement décroissante avec un « genou » — on choisit \(\lambda\) au coude, où l'on a acheté beaucoup d'équité pour peu d'utilité. C'est la courbe tracée dans le TP ci-dessous.
Proposition 6.3 — OT bicausale, contre-factuels et post-traitement EO optimal par couplage (cas simple démontré) OT bicausale. Pour comparer deux individus « jumeaux » ne différant que par l'attribut sensible, on couple les lois jointes \(\mathcal{L}(S, X)\) par un plan \(\pi\) respectant la structure causale \(S \to X\) (couplage bicausal : la copie de \(X\) ne dépend de la copie de \(S\) que par le couplage des conditionnelles \(\mathcal{L}(X\,|\,S = s)\) — de Lara, González-Sanz, Asher, Risser & Loubes, JMLR 2024). Le contre-factuel \(X^\star(s')\) — « la valeur qu'aurait prise \(X\) si \(S\) valait \(s'\) » — est le point couplé : construit par OT entre \(\mathcal{L}(X\,|\,S = s)\) et \(\mathcal{L}(X\,|\,S = s')\). Applications : mesurer la discrimination \(\mathbb{E}\big[c(X, X^\star)\big]\), prédire sur le contre-factuel (fairness « counterfactual »).
Post-traitement EO : le couplage optimal est le couplage croissant. Cadre simple : \(Y \in \{0,1\}\), score réel \(R_s = f(X)\) par groupe, et un post-traitement randomisé \(\hat Y_s = g_s(R_s, U)\), \(U \sim \mathcal{U}[0,1]\) commun. (i) Un tel post-traitement est exactement un couplage entre la loi de \(R_s\,|\,Y = y\) et une loi de Bernoulli cible — le bruit \(U\) réalise le plan. (ii) EO impose que la loi de \(\hat Y_s\,|\,Y = y\) soit la même pour les deux groupes : on couple donc simultanément les deux lois de scores conditionnelles à une cible commune. (iii) Parmi ces couplages, celui qui maximise l'utilité (l'accuracy, croissante en le score dans chaque classe) est le couplage croissant — appariement des quantiles : l'argument de décroisement de la preuve de la prop. 2.6 s'applique mot pour mot : décroiser deux paires (rendre le couplage plus comonotone) ne peut pas diminuer une utilité croissante des deux scores. Concrètement : ramener chaque score à son rang \(U_s = \hat F_s(R_s)\) (quantile dans son groupe), puis appliquer la même règle de décision aux \(U_s\) — l'égalisation des lois conditionnelles se fait sur les quantiles, et le choix du point de fonctionnement (TPR, FPR) commun maximise l'utilité linéaire \(\mathbb{P}(Y{=}1)\,\mathrm{TPR} + \mathbb{P}(Y{=}0)\,(1 - \mathrm{FPR})\) sur l'ensemble réalisable (intersection des deux régions convexifiées par la randomisation — la procédure « mélange de prédicteurs » de Hardt et al., relue comme couplage OT).∎
Limites et débat : métriques incompatibles, utilité, hypothèses causales
  • Incompatibilités théoriques : quand les taux de base \(\mathbb{P}(Y = 1\,|\,S = s)\) diffèrent entre groupes, calibration et equalized odds sont mutuellement exclusifs (Kleinberg, Mullainathan & Raghavan 2016 ; Chouldechova 2017) : aucune méthode — OT comprise — ne peut satisfaire tous les critères ; choisir la métrique, c'est choisir le compromis.
  • Coût en utilité : le repair DP peut détruire un signal légitime (si \(S\) prédit réellement \(Y\), l'indépendance force une perte) ; le repair « aveugle » n'est pas toujours équitable au sens individuel.
  • Hypothèses causales : les contre-factuels par OT bicausale supposent une structure \(S \to X\) et l'absence de confusion non mesurée ; deux couplages bicausaux optimaux différents (non-unicité, cf. exemple 1.2) peuvent donner des contre-factuels différents — l'OT fournit une famille de modèles, à auditer (le papier JMLR 2024 en propose des tests statistiques).
  • Position du cours : l'OT n'est pas une réponse à la question de justice, mais un langage géométrique pour chiffrer les compromis : distances entre groupes, barycentres, couplages optimaux — les mêmes objets qu'aux ch. 1-5.

import numpy as np, ot
from sklearn.linear_model import LogisticRegression
# Adult : X = variables numeriques, S = genre, Y = revenu > 50k
# (charger pandas.read_csv("adult.data"), encoder les categorielles)

def repair_1d(x, s, lam):
    """Repair quantile partiel, feature par feature (th. 6.2)."""
    xR = x.copy()
    qs = {sv: np.sort(x[s == sv]) for sv in np.unique(s)}
    n = min(len(v) for v in qs.values())          # rangs communs
    bary = np.mean([v[np.linspace(0, len(v)-1, n).astype(int)]
                    for v in qs.values()], axis=0)  # Q* : moyenne des quantiles
    for sv in np.unique(s):
        v, idx = np.sort(x[s == sv]), np.argsort(x[s == sv])
        ranks = np.linspace(0, len(v)-1, n)
        rep = (1-lam) * np.interp(ranks, range(len(v)), v) + lam * bary
        xR[s == sv] = np.interp(np.argsort(np.argsort(x[s == sv])),
                                ranks, rep)[np.argsort(idx)]
    return xR
