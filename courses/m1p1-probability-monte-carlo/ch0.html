0. Rappels : mesure, variables aléatoires, convergences

Rappels L3 mobilisés
  • Espaces probabilisés : tribu, mesure de probabilité, variables aléatoires, loi image — le vocabulaire du module Refresher Statistics, chapitre 1 ; si ce vocabulaire est fragile, c'est le moment de le consolider ;
  • Lois usuelles : binomiale, Poisson, exponentielle, gaussienne, gamma — densités, espérances, variances (cf. module Refresher Statistics, chapitre 3) ; indépendance et produit de mesures ;
  • Inégalités élémentaires : Markov, Tchebychev ; loi des grands nombres et théorème central limite « utilitaires » (cf. module Refresher Statistics, chapitre 4) ;
  • Analyse réelle : séries numériques, convergence monotone, séries entières (développements de \(e^x\), \(\cos\), \(\sin\)), intégration par parties, calcul différentiel à plusieurs variables (Jacobien).
Définition 0.1 — Tribu, mesure, espace probabilisé Un espace probabilisable est un ensemble \(\Omega\) muni d'une tribu \(\mathcal{F} \subseteq 2^\Omega\) (contient \(\Omega\), stable par complémentaire et réunion dénombrable). Une probabilité \(\mathbb{P}\) est une mesure sur \((\Omega, \mathcal{F})\) de masse totale 1 : \(\mathbb{P}(\Omega)=1\), dénombrablement additive. Une variable aléatoire (v.a.) est une application \(X : \Omega \to \mathbb{R}\) mesurable (l'image réciproque d'un borélien est dans \(\mathcal{F}\)) ; sa loi est la mesure image \(\mathbb{P}_X = \mathbb{P} \circ X^{-1}\). Ce point de vue — la loi comme pushforward — est celui qui généralise sans douleur aux espaces fonctionnels du machine learning.
Proposition 0.2 — Markov et Tchebychev (démontrées) Soit \(X\) une v.a. réelle.
  • Markov : si \(X \geq 0\) et \(a > 0\), \(\mathbb{P}(X \geq a) \leq \mathbb{E}[X]/a\) ;
  • Tchebychev : si \(\mathrm{Var}(X) < \infty\) et \(t > 0\), $$\mathbb{P}\big(|X - \mathbb{E}X| \geq t\big) \leq \frac{\mathrm{Var}(X)}{t^2}.$$
Markov : \(\mathbb{E}[X] \geq \mathbb{E}[X\,\mathbf{1}_{X \geq a}] \geq a\,\mathbb{P}(X \geq a)\). Tchebychev : appliquer Markov à \((X - \mathbb{E}X)^2\) au niveau \(t^2\).∎
Pourquoi ce module Tout le machine learning probabiliste — VAE, diffusion, inférence bayésienne, entraînement stochastique — repose sur trois opérations : calculer des espérances (intégration), conditionner (espérance conditionnelle) et échantillonner (simulation, Monte Carlo, MCMC). Ce module construit ces trois piliers avec des hypothèses minimales, puis les relie aux algorithmes génératifs modernes (cf. module Multimodal GenAI, chapitre 3, pour la partie diffusion). Il complète le traitement « recette » du module Machine Learning, chapitre 6 (EM), en fournissant les fondements.
