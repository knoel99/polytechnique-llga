8. MCMC : Metropolis-Hastings, Gibbs, diagnostics, recuit

Définition 8.1 — Noyau de Metropolis-Hastings \(\pi\) une densité cible sur \(E\) (connue à une constante près : seul \(\pi(x)\) intervient, jamais sa masse totale) et \(q(x,dy)\) un noyau de proposition. L'algorithme Metropolis-Hastings construit une chaîne de Markov \((X_k)\) : depuis \(X_k = x\), tirer \(Y \sim q(x,\cdot)\) et \(U \sim \mathcal{U}[0,1]\) ; poser $$X_{k+1} = \begin{cases} Y & \text{si } U \leq \alpha(x,Y),\\ x & \text{sinon (rejet : la chaîne reste sur place),}\end{cases} \qquad \alpha(x,y) = \min\Big(1,\ \frac{\pi(y)\, q(y,x)}{\pi(x)\, q(x,y)}\Big),$$ où \(q(x,y)\) désigne la densité de \(q(x,\cdot)\) au point \(y\) (par rapport à une mesure de référence fixée). Cas particuliers : random walk MH (\(q(x,\cdot) = \mathcal{N}(x, s^2 I)\), \(q(y,x)=q(x,y)\) donc \(\alpha = \min(1,\pi(y)/\pi(x))\)) ; échantillonneur d'indépendance (\(q(x,\cdot) = g\) fixe) ; MALA (proposition issue de la dynamique de Langevin, ch. 9).
Théorème 8.2 — Équilibre détaillé du noyau MH (démontré) Le noyau de transition de Metropolis-Hastings, $$P(x,dy) = q(x,dy)\,\alpha(x,y) + \Big(1 - \int \alpha(x,z)\,q(x,dz)\Big)\,\delta_x(dy),$$ est \(\pi\)-réversible : \(\pi(dx)\,P(x,dy) = \pi(dy)\,P(y,dx)\). En particulier \(\pi\) est invariante.
Le terme de rejet ne charge que la diagonale \(\{x = y\}\), où l'égalité à démontrer est triviale. Pour le terme d'acceptation, posons \(\rho(x,y) = \pi(x)\,q(x,y)\) (densités par rapport à une mesure dominante commune, p.ex. Lebesgue ; le cas des noyaux généraux s'écrit avec les mesures \(\pi(dx)q(x,dy)\) et se traite identiquement). Vérifions que \(\rho(x,y)\,\alpha(x,y)\) est symétrique en \((x,y)\), par disjonction :
  • si \(\rho(y,x) \leq \rho(x,y)\) : \(\alpha(x,y) = \rho(y,x)/\rho(x,y)\) et \(\alpha(y,x) = 1\), d'où \(\rho(x,y)\alpha(x,y) = \rho(y,x) = \rho(y,x)\alpha(y,x)\) ;
  • si \(\rho(y,x) > \rho(x,y)\) : symétriquement \(\alpha(x,y) = 1\) et \(\alpha(y,x) = \rho(x,y)/\rho(y,x)\), même conclusion.
Dans les deux cas \(\rho(x,y)\alpha(x,y) = \min(\rho(x,y), \rho(y,x))\), expression symétrique en \((x,y)\) : l'équilibre détaillé \(\pi(dx)P(x,dy) = \pi(dy)P(y,dx)\) est démontré. Invariance : notons \(\mu(dx,dy) = \pi(dx)\,q(x,dy)\,\alpha(x,y)\) (symétrique) et \(r(x) = \int q(x,dz)\alpha(x,z)\). Pour tout borélien \(A\), $$(\pi P)(A) = \mu(E \times A) + \int_A \big(1 - r(x)\big)\,\pi(dx).$$ Par symétrie de \(\mu\), sa marginale en la seconde variable vaut \(\mu(E,dy) = \int \mu(dx,dy) = \int \mu(dy,dx) = \pi(dy)\,r(y)\), donc \(\mu(E\times A) = \int_A r\,d\pi\) et \((\pi P)(A) = \int_A r\,d\pi + \int_A (1-r)\,d\pi = \pi(A)\).∎
Seule la constance de \(\pi\) est requise : si \(\pi = \tilde\pi/Z\), \(Z\) se simplifie dans \(\alpha\) — d'où le succès de MH en inférence bayésienne (cf. module Refresher Statistics, chapitre 8).
Proposition 8.3 — Gibbs = Metropolis-Hastings par blocs (démontrée) Soit \(\pi\) une densité sur \(\mathbb{R}^d\) et, pour \(i \in \{1,\dots,d\}\), la loi conditionnelle complète \(\pi(x_i \mid x_{-i})\). Le noyau de Gibbs « coordonnée \(i\)» : \(x \to y = (x_{-i}, y_i)\) avec \(y_i \sim \pi(\cdot \mid x_{-i})\), est un noyau de MH d'acceptation 1.
C'est MH avec la proposition dégénérée \(q_i(x,dy) = \pi(y_i \mid x_{-i})\, \delta_{x_{-i}}(dy_{-i})\). Le rapport d'acceptation entre \(x\) et \(y\) (qui ne diffèrent que par la coordonnée \(i\)) vaut $$\frac{\pi(y)\,\pi(x_i \mid y_{-i})}{\pi(x)\,\pi(y_i \mid x_{-i})} = \frac{\pi(y_{-i})\,\pi(y_i \mid y_{-i})\,\pi(x_i \mid y_{-i})} {\pi(x_{-i})\,\pi(x_i \mid x_{-i})\,\pi(y_i \mid x_{-i})} = 1,$$ car \(y_{-i} = x_{-i}\) (décomposition \(\pi(x) = \pi(x_{-i})\pi(x_i\mid x_{-i})\)). Donc \(\alpha \equiv 1\) : on accepte toujours, et l'équilibre détaillé (thm 8.2) garantit l'invariance de \(\pi\) pour chaque balayage.∎
Le balayage systématique (coordonnées 1 à \(d\)) ou aléatoire (coordonnée uniforme) compose ces noyaux : composée de noyaux \(\pi\)-invariants = noyau \(\pi\)-invariant. Le Gibbs est la brique de l'échantillonnage bayésien conditionnel (modèles graphiques, modèles de mélanges — cf. module Machine Learning, chapitre 6, pour l'aspect EM).
Proposition 8.4 — Théorème ergodique appliqué et CLT de chaîne (énoncés) Si le noyau MH est \(\pi\)-irréductible et apériodique (vérifié dès que \(q\) charge un voisinage de 0 ou que la probabilité de rejet est non nulle) :
  • ergodicité (thm 4.3) : \(\frac1n\sum_{k=1}^n h(X_k) \to \pi(h)\) p.s. pour \(h \in L^1(\pi)\) ;
  • CLT de chaîne de Markov (sous réversibilité géométrique) : \(\sqrt n\,(\hat\mu_{\mathrm{MH}} - \pi(h)) \to \mathcal{N}(0, \sigma_{\mathrm{MH}}^2)\) avec \(\sigma_{\mathrm{MH}}^2 = \mathrm{Var}_\pi(h(X_0)) + 2\sum_{k\geq1} \mathrm{Cov}_\pi(h(X_0), h(X_k))\) : l'autocorrélation positive gonfle la variance effective — d'où le facteur correctif \(\tau = 1 + 2\sum_k \rho_k\) (« temps d'intégration »).
Définition 8.5 — Diagnostics de convergence et ESS de chaîne
  • Trace (trajectoire de \((X_k)\) par coordonnée) : mélange visible, mode-trapping (la chaîne reste coincée dans un mode d'une cible multimodale) ;
  • Autocorrélogramme : \(\rho_k\) en fonction du retard \(k\) ; décroissance lente = exploration lente ;
  • ESS de chaîne : \(\mathrm{ESS} = n/\tau\) avec \(\tau = 1 + 2\sum_{k=1}^{K}\rho_k\) (troncature par heuristique de Geyer) ; barre d'erreur MCMC \(\approx \hat\sigma_h \sqrt{\tau/n}\) ;
  • \(\hat R\) de Gelman-Rubin : plusieurs chaînes issues d'initialisations surdispersées ; convergence lorsque les variances inter-chaînes et intra-chaîne s'équilibrent (\(\hat R \to 1\), seuil usuel 1{,}01-1{,}1) ;
  • taux d'acceptation : pour le random walk MH, l'échelle optimale théorique est ~0{,}234 en grande dimension (0{,}44 en dimension 1) ; un pas trop petit explore lentement, trop grand rejette tout.
Proposition 8.6 — Recuit simulé (énoncé) Pour maximiser \(U\) (ou minimiser \(-U\)), on échantillonner \(\pi_T(x) \propto e^{U(x)/T}\) avec une température \(T\) décroissant comme \(T_k \sim c/\log k\) : sous ce calendrier (théorème de Hajek, énoncé), la chaîne converge vers l'ensemble des maxima globaux ; en pratique \(T_k = T_0 \times 0{,}95^k\) (géométrique, sans garantie). Le recuit est l'interface échantillonnage/optimisation : hautes températures pour explorer, basses pour exploiter — le même compromis que les schémas de température des modèles de diffusion (ch. 9). 
import numpy as np
rng = np.random.default_rng(0)

# cible : melange bimodal 0.5 N(-2.5, 0.7^2) + 0.5 N(2.5, 0.7^2)
logpi = lambda x: np.logaddexp(-((x+2.5)**2)/(2*0.49),
                               -((x-2.5)**2)/(2*0.49))

def rw_mh(x0, n, s):
    x = np.empty(n); x[0] = x0; acc = 0
    for k in range(n-1):
        y = x[k] + s * rng.standard_normal()
        if np.log(rng.random()) < logpi(y) - logpi(x[k]):
            x[k+1] = y; acc += 1
        else:
            x[k+1] = x[k]
    return x, acc/n

x, taux = rw_mh(0.0, 200_000, 4.0)     # grand pas pour sauter entre modes
print(f"acceptation {taux:.3f}, moyenne {x[1000:].mean():+.3f} (exacte 0)")

def ess(z):                            # autocorrelations positives tronquees
    z = z - z.mean(); n = len(z)
    acf = [1.0] + [np.corrcoef(z[:-k], z[k:])[0,1] for k in range(1, 200)]
    tau, s = 1.0, 0.0
    for k in range(1, len(acf), 2):    # paires de Geyer
        pair = acf[k] + acf[k+1] if k+1 < len(acf) else acf[k]
        if pair <= 0: break
        s += pair
    return n / (1 + 2*s)

print(f"ESS = {ess(x[1000:]):.0f} / 199000")
Exemple 8.7 — Lecture d'une expérience (chiffres) Sur le mélange ci-dessus avec \(s=4\) et \(n=2\times10^5\) : taux d'acceptation \(\approx 0{,}28\) (proche de la cible 0{,}234 en dimension 1-2), moyenne empirique \(\approx \pm 0{,}03\) autour de la valeur exacte 0, ESS \(\approx 3\,000\) (forte autocorrélation car les sauts inter-modes sont rares). Avec \(s = 0{,}7\) : acceptation ~0{,}7 mais mode-trapping — la chaîne reste 10⁴ itérations dans un mode (trace plate), \(\hat R\) très supérieur à 1 entre deux chaînes initialisées dans des modes opposés. Diagnostic : l'ESS seule ne suffit pas, il faut plusieurs chaînes surdispersées (référence [5]).
