9. Dynamique de Langevin et modèles génératifs

Définition 9.1 — Diffusion de Langevin suramortie Soit \(U : \mathbb{R}^d \to \mathbb{R}\) (le potentiel), \(\mathcal{C}^1\), avec \(e^{-U} \in L^1\). La diffusion de Langevin est l'EDS $$dX_t = -\nabla U(X_t)\,dt + \sqrt{2}\,dW_t,$$ où \((W_t)\) est un mouvement brownien \(d\)-dimensionnel. Sa loi invariante (si elle existe : c'est le cas si \(U\) est confinant, p.ex. \(U(x) \geq a\|x\| - b\)) est $$\pi(x) = \frac{e^{-U(x)}}{\int e^{-U}\,d\lambda},$$ la loi de Gibbs associée à \(U\). En ML, on écrit plutôt \(U = -\log \pi\) : la dérive \(-\nabla U = \nabla \log \pi\) est le score — quantité centrale des modèles génératifs (cf. module Multimodal GenAI, chapitre 3).
Proposition 9.2 — \(\pi\) invariante pour la diffusion de Langevin (démontrée) Pour toute fonction test \(\varphi \in \mathcal{C}^\infty_c\) et \(X \sim \pi\) : \(\mathbb{E}[\mathcal{A}\varphi(X)] = 0\), où \(\mathcal{A}\varphi = -\nabla U \cdot \nabla \varphi + \Delta \varphi\) est le générateur de la diffusion. C'est la caractérisation de l'invariance (les espérances se conservent le long des trajectoires).
Avec \(\pi = e^{-U}/Z\) et \(d\pi = Z^{-1}e^{-U(x)}dx\), intégrations par parties (les termes de bord s'annulent, \(\varphi\) étant à support compact) : $$\int (\Delta\varphi)\,e^{-U}\,dx = -\int \nabla\varphi \cdot \nabla(e^{-U})\,dx = \int \nabla\varphi \cdot \nabla U\; e^{-U}\,dx,$$ en utilisant \(\nabla(e^{-U}) = -(\nabla U)\,e^{-U}\). En reportant : $$Z\,\mathbb{E}_\pi[\mathcal{A}\varphi] = \int \big[-\nabla U\cdot\nabla\varphi + \Delta\varphi\big]\,e^{-U}dx = \int \big[-\nabla U\cdot\nabla\varphi + \nabla U \cdot \nabla\varphi\big]e^{-U}dx = 0.$$ ∎
Vérification directe dans le cas gaussien \(U(x) = \|x\|^2/2\) : la diffusion est une diffusion d'Ornstein-Uhlenbeck \(dX_t = -X_t dt + \sqrt2\,dW_t\), et \(\mathcal{N}(0,I_d)\) est stationnaire (chap. 4, exemple 4.5).
Définition 9.3 — ULA et MALA La discrétisation d'Euler-Maruyama du pas \(\gamma > 0\) donne l'algorithme ULA (unadjusted, sans correction) : $$X_{k+1} = X_k - \gamma\,\nabla U(X_k) + \sqrt{2\gamma}\,Z_{k+1}, \qquad Z_{k+1} \sim \mathcal{N}(0,I_d).$$ ULA est une chaîne de Markov biaisée : sa loi limite \(\pi_\gamma\) diffère de \(\pi\) (décalage \(\mathcal{O}(\gamma)\)). MALA ajoute une étape de Metropolis-Hastings (déf. 8.1) avec la proposition gaussienne ci-dessus, supprimant exactement le biais (au prix de rejets) ; le compromis biais/coût fait l'objet des travaux décrits au chapitre 10.
Exemple 9.4 — Le biais d'ULA calculé exactement (gaussienne) Pour \(\pi = \mathcal{N}(0,1)\) (\(U(x)=x^2/2\)) : \(X_{k+1} = (1-\gamma)X_k + \sqrt{2\gamma}Z_{k+1}\) — une AR(1) (exemple 4.5). Sa loi stationnaire est \(\mathcal{N}\big(0,\ \sigma_\gamma^2\big)\) avec $$\sigma_\gamma^2 = \frac{2\gamma}{1-(1-\gamma)^2} = \frac{2}{2-\gamma} \;\xrightarrow[\gamma \to 0]{}\; 1.$$ Chiffres : \(\gamma = 0{,}5 \Rightarrow \sigma_\gamma^2 = 1{,}33\) (biais +33 %) ; \(\gamma = 0{,}1 \Rightarrow 1{,}053\) (+5 %) ; \(\gamma = 0{,}01 \Rightarrow 1{,}005\) (+0{,}5 %). Le biais en variance est \(\gamma/(2-\gamma) \approx \gamma/2\) : diviser le biais par 2 double le nombre d'itérations pour atteindre une région donnée — le papier [1] du chapitre 10 quantifie précisément ce compromis (vitesse de convergence explicite en \(\gamma\), \(d\) et l'erreur cible).
Théorème 9.5 — Garanties non asymptotiques d'ULA (énoncé, [1]-[2]) Si \(U\) est \(L\)-lisse et fortement convexe, Durmus & Moulines (2017) montrent qu'après \(k\) itérations de pas \(\gamma\), en distance de Wasserstein \(W_2\) (cf. module Optimal Transport, chapitre 2) et en variation totale, $$W_2\big(\mathrm{loi}(X_k),\,\pi\big) \;\leq\; \mathcal{O}\!\Big(e^{-k\gamma m/2}\,\sqrt{d/m} + \sqrt{\gamma d/m}\Big) \quad\text{(ordres de grandeur, } m = \text{const. de convexité forte)},$$ c'est-à-dire une décroissance exponentielle vers un plateau de biais proportionnel à \(\sqrt\gamma\) ; avec pas décroissants, ULA converge (ergodicité) mais avec des vitesses dégradées. Ces bornes, explicites en la dimension \(d\), fondent l'analyse moderne de l'échantillonnage en grande dimension (ch. 10).
Proposition 9.6 — Le lien score / modèles génératifs Les modèles génératifs à base de diffusion (cf. module Multimodal GenAI, chapitre 3 ; module Deep Learning, chapitre 7, pour VAE/GAN) apprennent une famille de scores \(s_\theta(x,t) \approx \nabla_x \log p_t(x)\) des versions bruitées \(p_t\) de la donnée. La génération par Langevin amorcé (annealed Langevin) exécute, pour \(t\) décroissant, $$X_{k+1} = X_k + \tfrac{\varepsilon_t}{2}\,s_\theta(X_k,t) + \sqrt{\varepsilon_t}\,Z_{k+1} \qquad (\text{ULA de potentiel } -\log p_t),$$ en partant d'un bruit blanc : température décroissante = recuit simulé (prop. 8.6) appliqué à la dynamique de Langevin. Le réseau apprend la dérive de la diffusion ; l'aléa final \(\sqrt{\varepsilon}\,Z\) fait le reste. Les quantités de ce chapitre — biais d'Euler, pas optimal, calibration du bruit — sont donc les mêmes boutiques de réglage que celles des modèles de diffusion. 
import numpy as np
rng = np.random.default_rng(3)

def ula(gamma, n=200_000):             # cible N(0,1) : U(x) = x^2/2
    x = 3.0
    for k in range(n):
        x = x - gamma*x + np.sqrt(2*gamma)*rng.standard_normal()
        if k >= n//2:                  # burn-in ignore
            yield x

for g in (0.5, 0.1, 0.01):
    v = np.fromiter(ula(g), float)
    print(f"gamma={g:4.2f}  var stationnaire {v.var():.4f}"
          f"  theorie {2/(2-g):.4f}")

def mala(gamma, n=200_000):            # meme proposition + acceptation MH
    x, out = 3.0, []
    U, dU = lambda z: z*z/2, lambda z: z
    q = lambda a, b: -(b - a + gamma*dU(a))**2 / (4*gamma)
    for k in range(n):
        y = x - gamma*dU(x) + np.sqrt(2*gamma)*rng.standard_normal()
        loga = U(x) - U(y) + q(x, y) - q(y, x)
        if np.log(rng.random()) < loga: x = y
        if k >= n//2: out.append(x)
    return np.array(out)

print(f"MALA gamma=0.5 : var {mala(0.5).var():.4f} (exacte 1)")
Pourquoi ce chapitre est le cœur du module La boucle est bouclée : mesure/intégration (ch. 1) → espérances et erreurs (ch. 2-3) → chaînes et invariance (ch. 4) → simulation (ch. 5) → estimation par trajectoires (ch. 6-8) → dynamiques de diffusion (ch. 9). Le score \(\nabla\log\pi\) est à la fois « dérive optimale pour échantillonner » et « objet appris par les modèles génératifs » : ce double statut, formalisé par les garanties de convergence de l'équipe pédagogique, est l'articulation exacte entre ce module et les modules Multimodal GenAI et Deep Learning. Les questions de réglage — pas, biais, stabilité — y sont les mêmes leviers.
