8. Évaluation, coûts, éthique

Le FID hérite de la géométrie de \(W_2\) (module OT) : la partie \(\mathrm{tr}\big(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2}\big)\) est la distance de Bures entre covariances. Deux pièges pratiques : (i) le nombre d'échantillons — le FID décroît mécaniquement avec la taille de cohorte ; (ii) les features — InceptionV3 vs CLIP réordonnent parfois les classements. Toujours annoncer (backbone, N, protocole).
  • Coûts : entraînement diffusion = milliers de GPU-heures ; inférence = N pas de débruiteur + décodage ; le compromis qualité/latence gouverne le choix industriel (solveurs rapides, distillation, quantification) ;
  • Éthique — une note équilibrée :
    • Deepfakes : détecteurs (dont des détecteurs utilisant la diffusion elle-même), provenance ;
    • Watermarking et provenance : métadonnées signées C2PA (coalition industrielle : appareil → éditeur → publication), tatouages invisibles robustes à la re-compression — aucun n'est infaillible seul, la défense est en profondeur ;
    • Copyright : entraînement sur données web — débats légaux en cours (opt-out, licences de datasets, filtrage) ; côté génération : similarité avec les œuvres d'entraînement à surveiller ;
    • Biais : les biais des corpus (représentation, stéréotypes) se retrouvent amplifiés à la génération — audit des sorties, documentation des données ;
    • AI Act européen : approche par niveaux de risque ; les générateurs synthétiques y sont visés via transparence (marquage du contenu généré, documentation des modèles) — croisé avec le séminaire d'éthique du M2.
Projet Pipeline complet : fine-tuner léger d'un modèle latent diffusion sur un petit jeu thématique (LoRA sur l'attention croisée), avec CFG paramétrable ; évaluer FID/CLIPScore avant/après et analyser l'effet du poids de guidance \(w\) (et d'ordonnances \(w(t)\) — cf. ch. 9).
