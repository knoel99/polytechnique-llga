6. Text-to-image : le pipeline complet

Architecture 6.1 — De la phrase au pixel Le pipeline industriel d'un générateur text-to-image latent :
ÉtapeComposantRôle / détails
1. TokenisationBPE / SentencePieceprompt → séquence de tokens (module NLP) ; tronqué à 77–225 selon les modèles
2. Text encodingCLIP text encoder + T5/ByT5tokens → tenseur \((L \times d)\) ; le pooled embedding de CLIP conditionne aussi adaLN (DiT)
3. Diffusion latenteU-Net ou DiT + cross-attentionbruit → latent débruité (20–50 pas, solveur du ch. 4, CFG \(\tilde\epsilon\))
4. DécodageDécodeur VAElatent \((64\times64)\) → image \((512\times512)\) en un passage
5. Raffinementrefiner / super-résolutionupsampling ×2–4 (par diffusion à plus haute résolution ou GAN de super-résolution — ch. 2)
L'entraînement des grands modèles fige souvent l'encodeur de texte et le VAE, et n'apprend que le débruiteur ; le LoRA (Low-Rank Adaptation) fige même le débruiteur et n'apprend que des corrections de faible rang dans les poids de l'attention croisée — le fine-tuning thématique « domestique » (quelques dizaines d'images, quelques minutes GPU).
  • Prompt engineering, quantitativement : le prompt est un gradient sur le conditionnement : ajouter « photorealistic, 85 mm » déplace les embeddings et donc chaque pas de CFG. Effets mesurables : position (les premiers tokens pèsent plus), saturation (au-delà de ~50 tokens effectifs, rendement décroissant), pondération syntaxique « (mot:1.3) » = rescaling du logit d'attention pendant l'entraînement de l'inférence ;
  • Prompt négatif : la version générale du CFG à deux conditions — on remplace \(\varnothing\) par \(c_-\) : $$\tilde\epsilon = \epsilon_\theta(x_t,t,c_-) + w\big(\epsilon_\theta(x_t,t,c_+) - \epsilon_\theta(x_t,t,c_-)\big),$$ la direction négative est repoussée (thm. 4.1) : « flou, watermark, extra fingers » ;
  • Seeds : la graine fixe \(x_T\) (et les aléas du solveur) ; même seed + même prompt = même image en DDIM déterministe ; on balaye les seeds pour choisir la meilleure réalisation avant d'affiner le prompt — le flux de travail réel des praticiens ;
  • Coût d'inférence : (nombre de pas) × (coût du débruiteur) + décodage ; la latence gouverne le choix industriel (solveurs rapides, distillation 1-pas quand la diversité importe moins).
