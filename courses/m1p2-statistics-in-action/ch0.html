0. Rappels : le kit de survie du statisticien

Rappels L3 mobilisés (cf. module Refresher Statistics)
  • Convergences et théorèmes limites (ch. 4) : loi des grands nombres, TCL \(\sqrt{n}(\bar X_n - \mu) \Rightarrow \mathcal{N}(0, \sigma^2)\), méthodes delta et bootstrap — le moteur de presque toutes les approximations de ce module ;
  • Estimation paramétrique (ch. 5) : biais, variance, erreur quadratique, estimateurs du maximum de vraisemblance et leurs propriétés asymptotiques ;
  • Intervalles de confiance et tests (ch. 6) : niveau, puissance, p-value, erreurs de type I et II, test de Student à deux échantillons, test du khi-deux ;
  • Régression linéaire (ch. 7) : moindres carrés ordinaires, Gauss-Markov, tests sur les coefficients, \(R^2\) — le chapitre 5 du présent module reprend ce socle « sur données qui vont mal » ;
  • Simulation Monte Carlo : générer des Lois, vérifier une méthode par simulation — l'outil de travail permanent du statisticien appliqué (et de tous les TP de ce cours).
Définition 0.1 — Modèle statistique et données Un modèle statistique pour des données \(x_1, \dots, x_n\) est une famille \((P_\theta)_{\theta \in \Theta}\) de lois candidates. En pratique, la question n'est pas « le modèle est-il vrai ? » (il ne l'est jamais) mais : quelle question pose-t-on aux données, et quelle quantité \(\psi(\theta)\) — effet moyen, différence de taux, quantile, coefficient — répond à cette question ? Tout le module est organisé autour de ce triptyque : question → plan de collecte → estimation + incertitude. La formule \(\bar x \pm 1{,}96\, s/\sqrt{n}\) du Refresher Statistics n'est légitime que si le plan de collecte l'est : ce module traite ce qui se passe avant et autour de la formule.
Proposition 0.2 — L'identité biais-variance et ce qu'elle implique Pour tout estimateur \(\hat\theta\) de \(\theta\) de carré intégrable : $$\mathbb{E}\big[(\hat\theta - \theta)^2\big] = \underbrace{\big(\mathbb{E}\hat\theta - \theta\big)^2}_{\text{biais}^2} + \underbrace{\mathrm{Var}(\hat\theta)}_{\text{variance}}.$$
Poser \(\mu = \mathbb{E}\hat\theta\) et développer \(\mathbb{E}[(\hat\theta-\mu) + (\mu - \theta)]^2 = \mathbb{E}(\hat\theta-\mu)^2 + 2(\mu-\theta)\underbrace{\mathbb{E}(\hat\theta - \mu)}_{=0} + (\mu-\theta)^2\). Le terme croisé est nul car \(\mu\) est l'espérance de \(\hat\theta\). ∎
En pratique, le biais vient surtout du plan (sélection, confusion) et la variance de la taille d'échantillon : augmenter \(n\) ne corrige jamais un biais de sélection — c'est le message central des chapitres 2 et 3.
Position dans le master Ce module est le complément « métier » du Refresher Statistics : moins de théorie nouvelle, davantage de décisions. Il prépare aussi le module M2 « Privacy and Uncertainty Quantification », qui pousse la question de l'incertitude jusqu'à la calibration des modèles prédictifs ; le pont statistique–ML est assuré par le module Machine Learning (ch. 1 et 7), le traitement des données textuelles par le module NLP.
