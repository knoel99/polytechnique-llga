7. Génération conditionnelle et text-to-graph

7.1 Trois mécanismes de conditionnement

Définition 7.1 — Conditionner une génératrice de graphes On passe de \(p_\theta(G)\) à \(p_\theta(G \mid c)\) où \(c\) est le conditionnement ; trois mécanismes, aux propriétés différentes :
  • en entrée (concat/fusion) : le GNN reçoit \(c\) (vecteur de propriétés, embedding de texte) — entraîné sur paires \((G, c)\) ou par classifier-free (dropout de \(c\)) ; simple, contrôle mou ;
  • par guidance : un prédicteur \(Q(c \mid G)\) ou un classifieur oriente l'échantillonnage (gradients pour les flows ch. 4, CFG pour la diffusion ch. 5) ; contrôle fort, ré-entraînement nul ou léger, prix : diversité ;
  • par recherche : générer massivement puis filtrer/optimiser (optimisation bayésienne dans l'espace latent — le pipeline QSAR classique) ; contrôle exact a posteriori, coût d'échantillonnage élevé.
Le compromis fidélité au contrôle / diversité est quantifié au ch. 9 du module Control in Generative AI ; ici on retient : pour les graphes, le conditionnement « dur » (squelette, valences) et « mou » (propriétés, texte) se combinent — inpainting + CFG dans DiGress.

7.2 Text-to-graph : la rencontre LLM × graphes

Théorème 7.2 — Quatre voies text-to-graph (2022-2026)
  1. Traduction molécule ↔ texte : MolT5 (Edwards et al., EMNLP 2022) pré-entraîne un T5 sur texte + SMILES et traite la description → molécule comme une traduction ; le texte est le conditionnement, le SMILES la cible ; la génération de graphe est déléguée à la grammaire SMILES (valence ≈ gratuite) ;
  2. LLM qui écrit le générateur : au lieu de générer le graphe directement, l'LLM écrit du code (NetworkX) qui génère le graphe ; « Demystifying the Power of LLMs in Graph Generation » (Wang et al., Findings NAACL 2025) montre que le prompting réseau-science (clustering, motifs) suffit à égaler des génératrices entraînées sur des familles classiques ; l'agent produit des propriétés cibles, le code les implémente — le contrôle monte d'un niveau d'abstraction ;
  3. Agents simulateurs : générer des réseaux dynamiques en faisant interagir des agents LLM (relations, citations, conversations) : « Dynamic and Textual Graph Generation via Large-Scale LLM-based Agent Simulation » (Ji et al., 2024) atteint 105 nœuds — la structure émerge de l'interaction, le texte anime les nœuds ;
  4. Hybride LLM + GNN : l'LLM propose, le GNN évalue, la boucle optimise (Chen et al., 2023 ; ChemCrow, Bran et al., 2023 : 18 outils dont prédicteurs de propriétés et docking) — la boucle « proposition/évaluation » du ch. 9 du Graph ML M1, industrialisée par les outils d'agents (cf. module LLMs M2 ch. 8).
Pourquoi le SMILES a gagné (pour l'instant) Générer des graphes par LLM direct (listes d'arêtes) échoue à petite échelle : contraintes de cohérence locales (valence) globales (connectivité) noyées dans la longue séquence ; le SMILES encode la valence dans la grammaire (parenthèses, aromaticité) : le token suivant a peu de liberté illégale — la même leçon que NeVAE (ch. 3) : déplacer les contraintes du post-traitement vers la syntaxe. La contrepartie : le SMILES n'est pas canonique (une molécule, plusieurs encodages ; cf. GOAT, ch. 9, sur le coût des ordres) ; SELFIES (Krenn et al., 2020) rend la grammaire totalement valide : toute séquence décode — la référence pratique des labs 2026.
Exemple 7.3 — CFG moléculaire jouet (papier-crayon) Pour la cible \(c =\) « logP élevé » ; logits du pas \(t\) du débruiteur sans condition : \((C: 2{,}0,\ O: 1{,}5,\ N: 0{,}5)\) ; avec condition : \((C: 3{,}0,\ O: 0{,}5,\ N: 0{,}5)\) ; guidance \(w = 3\) : logits guidés = uncond + \(w\)(cond − uncond) = \((C: 5{,}0,\ O: -1{,}0,\ N: 0{,}5)\) ; probabilités \(\approx (0{,}95,\ 0{,}007,\ 0{,}04)\) ; le carbone domine : logP élevé = chaînes carbonées — chimiquement cohérent. Augmenter \(w\) → collapse sur le carbone (diversité chute) : la courbe fidélité/diversité du module Control, lisible sur un seul pas.
