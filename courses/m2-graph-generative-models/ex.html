Exercices / Labs

  1. TP guidé : une évaluation complète « maison » (le lab du module, ch. 6). (a) Construire trois familles de référence : 500 graphes Erdős-Rényi \(G(n, p{=}0{,}15)\), 500 SBM à deux blocs (\(p_{in} = 0{,}3\), \(p_{out} = 0{,}05\)), 500 Barabási-Albert (\(m = 2\)), avec \(n \sim \mathcal{U}\{20, \dots, 40\}\) ; (b) implémenter les features (histogrammes de degrés, coefficients de clustering, comptages de 4 motifs : triangle, chemin de longueur 3, étoile) et le MMD à noyau gaussien (déf. 6.1), estimateur non biaisé ; (c) calculer les 3×3 MMD familles contre familles ; (d) refaire (c) avec \(n = 50\) puis \(n = 2\,000\) échantillons et tracer le biais ; (e) bootstrap : intervalles à 95 % sur chaque MMD (200 rééchantillonnages) ; (f) rédiger le tableau du ch. 6 et conclure : quelles familles le MMD-spectre sépare-t-il, lesquelles confond-il ? 
    # squelette du TP (networkx + numpy)
import networkx as nx, numpy as np

def features(gs):                     # gs : liste de graphes
    return np.array([[np.mean(list(nx.degree(g))),                  # a degre moyen
                      np.mean(list(nx.clustering(g).values())),     # b clustering
                      sum(nx.triangles(g).values()) / g.number_of_nodes()]  # c triangles
                     for g in gs])

def mmd(X, Y, sigma=None):            # noyau gaussien, largeur mediane
    Z = np.vstack([X, Y]); n, m = len(X), len(Y)
    sigma = sigma or np.median(np.linalg.norm(Z[:, None] - Z[None], axis=-1))
    K = np.exp(-np.linalg.norm(Z[:, None] - Z[None], axis=-1) ** 2 / (2 * sigma ** 2))
    return np.sqrt(K[:n, :n].sum() / (n * (n - 1)) + K[n:, n:].sum() / (m * (m - 1))
                   - 2 * K[:n, n:].mean())                          # diagonales retirees
    Guidage (résultats attendus) : le MMD sépare nettement ER des deux autres sur les degrés (distribution de Poisson contre queue lourde) ; SBM et BA se distinguent par le clustering (fort dans le SBM, faible dans le BA) ; à features fixées, le MMD décroît grossièrement en \(1/\sqrt{n}\) — comparer deux modèles à tailles d'échantillon différentes est invalide (ch. 6, piège 2), le TP le mesure. Les triangles seules ne séparent pas ER de SBM à \(p\) moyen égal : toujours rapporter plusieurs features. Le bootstrap montre des recouvrements d'intervalles entre familles proches : un MMD sans intervalle n'est pas une conclusion. ∎
  2. Masque de valence (ch. 3). Alphabet \(\{C, O, N\}\) de valences \(\{4, 2, 3\}\), liaisons simples uniquement. (a) Écrire le décodeur séquentiel masqué (état = valences restantes \(r_v\), proposition 3.3) ; (b) sampler 1 000 molécules sans masque (têtes non contraintes, logits \(\mathcal{N}(0,1)\)) puis avec masque, jusqu'à 12 atomes ; (c) mesurer la validité (toutes valences exactement nulles en fin de génération) et la comparer au raisonnement de la proposition 3.3.
    Solution : sans masque, chaque liaison tirée viole une valence avec probabilité croissante au fil de la génération (les \(r_v\) ne sont plus respectés) ; la validité observée est typiquement de quelques pourcents à 12 atomes — et \(1-(1-\varepsilon)^T \to 1\) explique l'effondrement (prop. 3.3). Avec masque : validité 100 % par construction (le support est restreint aux sorties légales), au prix d'un léger biais si les logits sont mal calibrés — la renormalisation redistribue la masse des interdits sur les légaux. Le code : maintenir \(r_v\), interdire les liaisons \(b\) avec \(b > r_u\) ou \(b > r_v\), resampler parmi les légales — huit lignes, l'investissement le plus rentable du module. ∎
  3. Le posterior absorbant, en forme fermée (ch. 5). Pour le noyau absorbant (rester dans l'état \(k\) avec probabilité \(\alpha_t = 1 - \beta_t\), être masqué sinon : état puits \([\textsf{MASK}]\)), démontrer : $$q(X_{t-1} = X_0 \mid X_t = \textsf{MASK},\ X_0) = \frac{A_{t-1}\,\beta_t}{1 - A_t}, \qquad A_t = \prod_{s \leq t} \alpha_s,$$ et vérifier que la masse restante porte sur \(X_{t-1} = \textsf{MASK}\).
    Solution : \(X_t = \textsf{MASK}\) advient avec probabilité \(1 - A_t\) (complément de « jamais masqué jusqu'à t ») ; conjointement \(X_{t-1} = X_0, X_t = \textsf{MASK}\) exige « jamais masqué jusqu'à \(t-1\)  puis masqué exactement en \(t\) » : probabilité \(A_{t-1}\beta_t\). Le quotient donne la formule ; la masse restante vaut \((1 - A_{t-1})/(1 - A_t)\) — les deux somment à 1 car \(1 - A_t = (1 - A_{t-1}) + A_{t-1}\beta_t\). C'est le posterior de D3PM-absorbant : quand \(X_t\) est masqué, \(X_{t-1}\) n'est jamais révélé — le réseau doit le deviner (\(\hat X_0\)) puis l'échantillonner avec ces probabilités : la machine à inpainting du ch. 5. ∎
  4. Flow et guidance (ch. 4). (a) Pour le CouplingStep du ch. 4, montrer que le log-déterminant du jacobien vaut \(\sum_i \log s_i\) et se calcule en \(\mathcal{O}(d)\) ; (b) dériver le pas de guidage : pour maximiser \(Q(G_t)\), montrer que $$\nabla_{z_t} Q\big(G_t\big) = J_{f_\theta}(z_t)^\top\, \nabla_{x_t}\, Q\big(\mathrm{disc}(x_t)\big),$$ où \(\mathrm{disc}\) est la discrétisation (argmax/échantillonnage) ; discuter le passage par la discrétisation (gradient droit / Gumbel-softmax).
    Indications : (a) le jacobien est triangulaire par blocs \(\begin{pmatrix} I & 0 \\ \ast & \mathrm{diag}(s) \end{pmatrix}\) (prop. 4.2) : le déterminant est le produit des diagonales ; (b) règle de la chaîne sur \(z_t \mapsto x_t = f_\theta(z_t) \mapsto G_t\) ; la discrétisation n'étant pas différentiable, on la remplace par une relaxation (softmax à température) ou on remonte le gradient du prédicteur continu : le pas de guidage déplace \(z_t\) sans changer les poids — mais chaque déplacement écarte la trajectoire de la loi apprise : trop grand, il fabrique des graphes hors distribution que le prédicteur note bien mais que la chimie rejette (le compromis fidélité/diversité du module Control ch. 9). ∎
  5. Le balayage CFG (ch. 7). Reprendre l'exemple 7.3 (logits non conditionnés \((2{,}0\,;\ 1{,}5\,;\ 0{,}5)\), conditionnés \((3{,}0\,;\ 0{,}5\,; 0{,}5)\)) et tracer \(w \mapsto\) (probabilité du carbone, entropie) pour \(w \in \{0, 1, 2, 3, 8\}\). Où est le « coude » ?
    Solution : logits guidés \(u + w(c - u) = (2 + w\,;\ 1{,}5 - w\,;\ 0{,}5)\). \(w = 0\) : probs \((0{,}55\,;\ 0{,}33\,;\ 0{,}12)\), \(H \approx 1{,}15\) nat ; \(w = 1\) : \((0{,}86\,;\ 0{,}07\,;\ 0{,}07)\), \(H \approx 0{,}50\) ; \(w = 2\) : \((0{,}96\,;\ 0{,}01\,;\ 0{,}03)\), \(H \approx 0{,}19\) ; \(w = 3\) : \((0{,}987\,;\ 0{,}002\,;\ 0{,}011)\), \(H \approx 0{,}08\) ; \(w = 8\) : carbone à 99{,}99 %, \(H \approx 0\). La fidélité (probabilité du carbone) est déjà quasi maximale à \(w = 2\) tandis que l'entropie a été divisée par six : le coude est à \(w \approx 2\) — au-delà, on paie la diversité sans gagner la cible. La courbe exacte du théorème 9.2 du module Control, sur un seul pas. ∎
  6. Graphon en escalier et densité de triangles (ch. 1 et 6). Soit \(W\) constante par blocs sur \([0,1]^2\) avec deux blocs : densité \(p\) dans le bloc 1 (\(x, y \leq \tfrac{1}{2}\)), \(q\) dans le bloc 2, \(r\) entre blocs. (a) Montrer $$t(K_3, W) = \tfrac{1}{8}\big(p^3 + q^3 + 3 p r^2 + 3 q r^2\big)$$ (intégrale sur les 8 combinaisons de blocs) ; (b) vérifier numériquement avec \(p = 0{,}9\), \(q = 0{,}6\), \(r = 0{,}05\) et par échantillonnage d'un graphe de \(n = 100\) nœuds (50/50) — pourquoi les deux coïncident-ils à \(\mathcal{O}(1/\sqrt{n})\) près ?
    Solution : chaque triplet \((a, b, c)\) de blocs contribue \(\tfrac{1}{8} W_{ab} W_{bc} W_{ac}\) ; \((1,1,1)\) donne \(p^3\), \((2,2,2)\) donne \(q^3\), les trois permutations de \((1,1,2)\) donnent \(p r^2\) chacune, celles de \((2,2,1)\) donnent \(q r^2\). Numériquement \(t = (0{,}729 + 0{,}216 + 0{,}0068 + 0{,}0045)/8 \approx 0{,}1195\). L'échantillonnage réalise des Bernoulli de paramètres \(W(x_i, x_j)\) iid conditionnellement aux latents : la densité de triangles empirique est une moyenne de variables bornées — concentration (Hoeffding) autour de \(t(K_3, W)\) en \(\mathcal{O}(1/\sqrt{n})\) : c'est le lemme de comptage du théorème 1.4, vérifié les mains dans le cambouis. ∎
  7. FCD en dimension 2 (ch. 6). Deux familles d'embeddings gaussiens de \(\mathbb{R}^2\) diagonaux : \(\mu_1 = (0, 0)\), \(\Sigma_1 = \mathrm{diag}(1, 4)\) ; \(\mu_2 = (1, 0)\), \(\Sigma_2 = \mathrm{diag}(4, 9)\). Calculer la distance de Fréchet ; que devient-elle si les deux familles ont même moyenne ?
    Solution : pour des covariances diagonales, \((\Sigma_1 \Sigma_2)^{1/2}\) est diagonale de racines des produits : \(\sqrt{1 \times 4} = 2\), \(\sqrt{4 \times 9} = 6\). D'où \(\|\mu_1 - \mu_2\|^2 = 1\) et \(\mathrm{tr}(\Sigma_1 + \Sigma_2 - 2(\Sigma_1\Sigma_2)^{1/2}) = (1 + 4 + 4 + 9) - 2(2 + 6) = 2\) : FCD \(= 3\). À moyennes égales, seule la trace subsiste (ici 2) : la FCD sépare moyennes et covariances — pourquoi elle détecte à la fois un décalage de propriétés moyennes (logP…) et un appauvrissement de la diversité (variances réduites), les deux échecs types des génératrices. ∎
  8. Ouvert : text-to-graph et features cibles (ch. 7, 9). (a) Demander à un LLM de produire du code NetworkX générant 500 graphes avec un cahier des charges statistique (degré moyen 4, clustering 0{,}3, n entre 20 et 40) — la voie « Demystifying » du ch. 7 ; (b) évaluer avec le MMD du TP 1 contre une famille SBM calibrée aux mêmes features ; (c) critiquer : le LLM a-t-il optimisé les features (en les lisant dans le prompt) ou généré une loi (propriétés distributionnelles non demandées) ? Comparer à la démarche NGG (conditionnement par features, ch. 9) : quelles garanties supplémentaires donne le modèle entraîné ? (Question de synthèse — soutenance.)
    Indications : mesurer aussi des features non demandées (spectre, diamètre, motifs) : la différence LLM/SBM y est la preuve que le LLM satisfait la lettre du cahier des charges sans en capturer l'esprit distributionnel (ou l'inverse) ; NGG, lui, apprend la loi conditionnelle aux features sur données réelles — les corrélations non spécifiées viennent des données, pas du prompt. C'est la frontière exacte du problème ouvert 10.4. ∎
