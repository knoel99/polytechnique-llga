Références

  • E. F. Codd, « A Relational Model of Data for Large Shared Data Banks », Communications of the ACM 13(6), 1970 — l'article fondateur du modèle relationnel.
  • S. Abiteboul, R. Hull, V. Vianu, Foundations of Databases, Addison-Wesley, 1995 — la référence théorique : algèbre/calcul (th. 1.7), dépendances, chase, formes normales.
  • A. Silberschatz, H. Korth, S. Sudarshan, Database System Concepts, 7e éd., McGraw-Hill, 2019 — le manuel du cours : stockage, B+, transactions, ARIES, distributed.
  • H. Garcia-Molina, J. Ullman, J. Widom, Database Systems: The Complete Book, 2e éd., Prentice Hall, 2008 — ch. 13-14 (B+), 17-18 (concurrence), 15-16 (reprise).
  • D. Comer, « The Ubiquitous B-Tree », ACM Computing Surveys 11(2), 1979 — la synthèse classique sur les B-arbres.
  • G. Graefe, « Query Evaluation Techniques for Large Databases », ACM Computing Surveys 25(2), 1993 — jointures, coûts, optimisation, la source du ch. 8.
  • P. Bernstein, V. Hadzilacos, N. Goodman, Concurrency Control and Recovery in Database Systems, Addison-Wesley, 1987 — les théorèmes du ch. 6 (2PL, sérialisabilité), librement consultable en ligne.
  • C. Mohan, D. Haderle, B. Lindsay, H. Pirahesh, P. Schwarz, « ARIES: A Transaction Recovery Method Supporting Fine-Granularity Locking and Roll-Backs Using Write-Ahead Logging », ACM TODS 17(1), 1992 — le papier du ch. 7.
  • S. Gilbert, N. Lynch, « Brewer's Conjecture and the Feasibility of Consistent, Available, Partition-Tolerant Web Services », SIGACT News 33(2), 2002 — la formalisation de CAP (th. 9.1).
  • N. Francis et al., « Cypher: An Evolving Query Language for Property Graphs », SIGMOD 2018 — le langage des property graphs ; côté RDF : W3C, RDF 1.1 Concepts et SPARQL 1.1.
  • Y. Malkov, D. Yashunin, « Efficient and Robust Approximate Nearest Neighbor Search Using Hierarchical Navigable Small World Graphs », IEEE TPAMI 2018 — arXiv 1603.09320 ; H. Jégou, M. Douze, C. Schmid, « Product Quantization for Nearest Neighbor Search », IEEE TPAMI 33(1), 2011 — les deux piliers du ch. 9.
  • J. Johnson, M. Douze, H. Jégou, « Billion-scale Similarity Search with GPUs », IEEE Trans. Big Data 2017 — arXiv 1702.08734 : la bibliothèque FAISS, outil standard des TP vectoriels.
  • S. Abiteboul, I. Manolescu, P. Rigaux, M.-C. Rousset, P. Senellart, Web Data Management, Cambridge University Press, 2011 — édition libre en ligne ; T. Kaoudi, I. Manolescu, M. Zampetakis, Cloud-Based RDF Data Management, Morgan & Claypool, 2020.
  • T. Chanial et al., « ConnectionLens: Finding Connections across Heterogeneous Data Sources », PVLDB 11(12), 2018 ; A. Anadiotis et al., « Graph integration of structured, semistructured and unstructured data for data journalism », Information Systems 104, 2022 — l'équipe CEDAR en action (ch. 10-11) ; liste complète des publications sur dblp.
  • Documentation : SQLite window functions, MVCC dans PostgreSQL, manuel MongoDB, pgvector.
