6. Efficacité : speculative decoding, quantification

Rappel — module LLMs ch. 6
Inférence : memory-bound au décodage, KV cache, quantification des poids (INT8/4). Ici on démontre les deux mécanismes stars du test-time : le décodage spéculatif (qui achète de la latence avec un petit modèle) et la quantification aware des activations (GPTQ, AWQ). Côté coûts et green ops : cf. module ML Ops ch. 4 et 10.
Lectures du jour Y. Leviathan, M. Kalman, Y. Matias, Fast Inference from Transformers via Speculative Decoding, ICML 2023 (arXiv:2211.17192) ; C. Chen et al., Accelerating Large Language Model Decoding with Speculative Sampling, 2023 (arXiv:2302.01318) ; E. Frantar et al., GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers, ICLR 2023 (arXiv:2210.17323) ; J. Lin et al., AWQ: Activation-aware Weight Quantization, MLSys 2024 (arXiv:2306.00978).

6.1. Decodage spéculatif : le petit propose, le gros dispose

Définition 6.1 — Speculative decoding (Leviathan et al., 2023) Un modèle brouillon \(q\) (petit, rapide) génère \(\gamma\) tokens ; le modèle cible \(p\) (gros, lent) les vérifie en une seule passe parallèle (les \(\gamma\) positions se vérifient simultanément — pré-remplissage) ; chaque token accepté est gratuit, le premier rejeté est corrigé par un échantillon résiduel ; la distribution de \(p\) est préservée exactement (le papier le prouve : correction par sampling selon \(\mathrm{norm}(\max(0, p - q))\) au point de rejet). Accélération ×2-3 typiques à qualité identique.
Théorème 6.2 — Nombre attendu de tokens par itération Si \(\alpha\) est la probabilité (moyenne) qu'un token de \(q\) soit accepté par \(p\), le nombre attendu de tokens générés par itération complète (vérification + correction) vaut $$\mathbb{E}[\#\text{tokens}] \;=\; \frac{1 - \alpha^{\gamma + 1}}{1 - \alpha}.$$ Avec \(\alpha = 0{,}8\) et \(\gamma = 4\) : ≈ 3,36 tokens par passe cible au lieu de 1.
Soit \(A\) le nombre de tokens acceptés avant le premier rejet. L'acceptation de chaque token est modélisée comme indépendante de probabilité \(\alpha\) ; alors \(A \sim \mathrm{Geo}(\alpha)\) tronqué à \(\gamma\) : en cas de rejet en position \(j < \gamma\), l'itération produit \(j\) tokens acceptés plus le token corrigé, soit \(j+1\) tokens ; si tous les \(\gamma\) sont acceptés, la passe produit \(\gamma\) tokens plus un token bonus échantillonné de \(p\) (la position \(\gamma{+}1\) est directement générée par la cible dans la même passe) : \(j+1\) tokens pour tout \(j \leq \gamma\). D'où \[ \mathbb{E} = \sum_{j=0}^{\gamma-1} (1-\alpha)\,\alpha^{j}\,(j+1) \;+\; \alpha^{\gamma}\,(\gamma + 1). \] On reconnaît la série tronquée de l'espérance géométrique : en utilisant \(\sum_{j=0}^{m} \alpha^j = \frac{1-\alpha^{m+1}}{1-\alpha}\) et sa dérivée pour le facteur \((j+1)\), la somme se réduit exactement à \(\frac{1-\alpha^{\gamma+1}}{1-\alpha}\). ∎
Analyse critique Le gain dépend de trois horloges : \(\alpha\) (accord petit/gros — fort sur du texte courant, faible sur du code pointu ou des sorties créatives) ; le ratio de coûts \(c\) (la vérification \(\gamma\) tokens coûte plus qu'un pas de décodage — pré-remplissage) ; \(\gamma\) (trop grand = beaucoup de rejets au dernier rang). Leviathan et al. donnent le \(\gamma\) optimal en fonction de \((\alpha, c)\) — un exercice du lab. Descendants : self-speculation (le modèle se vérifie lui-même via couches sautées), têtes multiples (Medusa), arbres — à documenter en veille.

6.2. Quantification : GPTQ et AWQ

Proposition 6.3 — GPTQ (Frantar et al., 2023) : couche par couche, Hessian à l'appui Quantifier \(W\) en \(\hat W\) (p. ex. 4 bits, avec une erreur \(\Delta = W - \hat W\)) en minimisant l'erreur sur les sorties effectivement produites : $$\min_{\hat W}\; \bigl\| W X - \hat W X \bigr\|_F^2 \;=\; \min_{\Delta}\; \mathrm{tr}\bigl(\Delta\, X X^\top\, \Delta^\top\bigr), \qquad H = 2 X X^\top,$$ où \(X\) est un échantillon d'activations calibrées. L'algorithme procède colonne par colonne (greedy) : quantifier un bloc de poids, calculer l'erreur sur les sorties, la répercuter sur les colonnes restantes via l'inverse de Cholesky de \(H\) — approximation de la méthode exacte (OBS/OBD, cf. module ML ch. régularisation) rendue compatible GPU. Des modèles de milliards de paramètres sont quantifiés en ~4 bits en quelques heures de GPU, avec des pertes de perplexité faibles.
Proposition 6.4 — AWQ (Lin et al., 2024) : protéger les canaux salients Observation : ~1 % des canaux d'activation (par matrice) portent des amplitudes extrêmes ; les quantifier naïvement détruit la performance. AWQ ne les quantifie pas spécialement — il rééchelonne : multiplier un canal d'entrée par \(s\) et diviser la colonne de poids par \(s\) préserve la mathématique exacte de la couche tout en déplaçant l'erreur de quantification hors des canaux salients (le scale optimal est estimé par recherche sur les activations de calibration, sans rétropropagation). Résultat : 4 bits robuste, aucune reconstruction hybride par groupe exotique, déploiement commodity.
