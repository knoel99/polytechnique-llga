Exercices / Labs

  1. Notes de lecture (fil rouge). Une fiche par séance (claim / preuves / coûts / reproductibilité / lien LLGA) sur le papier pivot ; deux fiches notées en profondeur : DeepSeek-R1 (ch. 1) et G-Retriever (ch. 7).
  2. Self-consistency (ch. 1). Sur un échantillon GSM8K : greedy vs self-consistency (k = 5, 20) ; tracer précision vs k et précision vs coût (tokens) ; vérifier que voter sur la réponse finale extraite bat voter sur la chaîne brute — pourquoi ?
  3. RLVR jouet (ch. 1). Implémenter un mini-GRPO (cf. module LLMs ch. 5) avec récompense binaire de format sur un petit modèle ; observer l'allongement des générations — un « aha moment » domestique ; discuter reward hacking (le modèle triche le format ?).
  4. RoPE et extension (ch. 2). Vérifier numériquement la prop. 2.2 (produits scalaires invariants par translation) ; étendre un petit modèle 512 → 2048 par interpolation puis par YaRN ; comparer perplexité et une tâche de rappel (needle) avant/après.
  5. Ring attention simulé (ch. 2). Implémenter l'attention par blocs avec passage d'anneau sur 4 « GPU » simulés (processus) ; vérifier l'exactitude vs attention dense ; mesurer communication vs calcul (recouvrement).
  6. Mémoire d'agent (ch. 3). Construire un memory stream avec le triptyque récence/importance/pertinence (prop. 3.1) ; ajouter la boucle de réflexion ; tester sur 20 sessions simulées ; ablation de chaque composant du score.
  7. MoE routing (ch. 4). Charger Mixtral (poids ouverts) et instrumenter le routeur ; mesurer la distribution de charge par expert sur 3 corpus (code, math, prose) ; reproduire la figure de spécialisation — et sa variabilité ; implémenter la perte auxiliaire de Switch sur un MoE jouet et montrer l'équilibrage.
  8. Scan SSM (ch. 5). Implémenter la récurrence SSM puis le scan préfixe (prop. 5.2 pour le cas LTI ; version sélective pour Mamba) ; comparer la mémoire GPU des trois modes (récurrence / convolution FFT / scan) sur L = 8k ; tester le rappel exact d'une association lointaine — transformer vs SSM (la critique du ch. 5).
  9. Spéculatif (ch. 6). Coder le schema brouillon/vérification avec re-sampling résiduel ; vérifier empiriquement le thm. 6.2 (compter les tokens/itération pour \(\alpha\) mesuré) ; trouver le \(\gamma\) optimal pour \((\alpha, c)\) mesurés sur votre machine.
  10. Encodages de graphes (ch. 7). Reproduire « Talk like a Graph » sur 3 tâches NLGraph × 4 encodages (code du ch. 7) ; tester l'hypothèse « c'est la structure, pas la longueur » en appariant les longueurs ; G-Retriever léger : remplacer le PCST par un plus court chemin pondéré et comparer.
  11. Agents (ch. 8). Un agent ReAct avec 3 outils dont un peu fiable (mauvaise sortie) ; mesurer \(p\) par étape et la loi \(p^k\) (prop. 8.2) ; ajouter Reflexion et mesurer le gain vs coût ; ablation multi-agents : 2 agents « spécialisés » vs 1 agent avec le même budget de tokens.
  12. Contamination (ch. 9). Détecteur n-grammes du ch. 9 sur un petit corpus ; construire 20 variantes re-générées d'un benchmark jouet ; mesurer l'écart brut/variante pour deux modèles — et l'asymétrie des juges (ordre alterné) sur MT-Bench-like.
  13. Mini-review (ch. 10). Rédiger une « position paper » de 4 pages : « En 2030, la connaissance vivra-t-elle dans les poids, le contexte ou l'index ? » — en mobilisant au moins six chapitres du séminaire et deux modules du master.
