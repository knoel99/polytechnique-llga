2. Descente de gradient : convergence démontrée

L'algorithme le plus utilisé au monde — chaque pas de la descente suivante exécutée quelque part en ce moment même :

$$x_{k+1} = x_k - t\, \nabla f(x_k), \qquad t > 0 \text{ le pas.}$$
Lemme 2.1 — Descente garantie (descent lemma) Si \(f\) est \(L\)-lisse et \(0 < t \leq 1/L\) : $$f(x_{k+1}) \;\leq\; f(x_k) - \tfrac{t}{2}\,\|\nabla f(x_k)\|^2.$$
Par le majorant quadratique en \(y = x_{k+1} = x_k - t\nabla f(x_k)\) : \(f(x_{k+1}) \leq f(x_k) + \langle\nabla f(x_k), -t\nabla f(x_k)\rangle + \tfrac{L}{2}t^2\|\nabla f(x_k)\|^2 = f(x_k) - t(1 - \tfrac{Lt}{2})\|\nabla f(x_k)\|^2\), et \(t(1-\tfrac{Lt}{2}) \geq \tfrac{t}{2}\) dès que \(t \leq 1/L\). ∎
Théorème 2.2 — Convergence \(O(1/k)\) (cas convexe lisse, démontré) Soit \(f\) convexe \(L\)-lisse, \(x^\star\) un minimiseur, \(R = \|x_0 - x^\star\|\), \(t = 1/L\). Alors $$f(x_{k+1}) - f(x^\star) \;\leq\; \frac{L R^2}{2\,(k+1)}.$$
Étape 1 (inégalité à trois points). Pour tout \(y\) — majorant quadratique de \(f\) en \(x_k\) évalué en \(x_{k+1}\), combiné à la convexité \(f(x_k) \leq f(y) + \langle\nabla f(x_k), x_k - y\rangle\) — : $$f(x_{k+1}) \;\leq\; f(y) + \langle\nabla f(x_k), x_{k+1} - y\rangle + \frac{L}{2}\|x_{k+1} - x_k\|^2.$$ Étape 2 (y = x^\star et polarisation). Avec \(\nabla f(x_k) = L\,(x_k - x_{k+1})\) et \(y = x^\star\), puis l'identité \(\langle a, b\rangle = \tfrac12(\|a+b\|^2 - \|a\|^2 - \|b\|^2)\) appliquée à \(a = x_k - x_{k+1}\), \(b = x_{k+1} - x^\star\) (donc \(\|a+b\| = \|x_k - x^\star\| = R_k\)) : $$f(x_{k+1}) - f^\star \;\leq\; L\langle x_k - x_{k+1},\, x_{k+1} - x^\star\rangle + \frac{L}{2}\|x_{k+1}-x_k\|^2 \;=\; \frac{L}{2}\big(R_k^2 - R_{k+1}^2\big).$$ Étape 3 (télescopage). En sommant de \(0\) à \(T-1\) et en utilisant \(\|x_T - x^\star\|^2 \geq 0\) : \(\sum_{k=0}^{T-1} (f(x_{k+1}) - f^\star) \leq \tfrac{L}{2}R_0^2\). La suite \(f(x_k)\) étant décroissante (lemme 2.1), chaque terme minore la moyenne : \(f(x_T) - f^\star \leq \tfrac{L R^2}{2T}\). ∎
Théorème 2.3 — Convergence linéaire (cas \(\mu\)-fortement convexe, démontré) Soit \(f\) \(\mu\)-fortement convexe et \(L\)-lisse, \(t = 1/L\). Alors, avec \(\kappa = L/\mu\) le conditionnement : $$f(x_{k+1}) - f(x^\star) \;\leq\; \Big(1 - \frac{1}{\kappa}\Big)\,\big(f(x_k) - f(x^\star)\big), \qquad f(x_k) - f^\star \;\leq\; e^{-k/\kappa}\,\big(f(x_0)-f^\star\big).$$
La forte convexité implique (en minimisant le minorant quadratique \(f(x_k) + \langle\nabla f(x_k), x - x_k\rangle + \tfrac{\mu}{2}\|x - x_k\|^2\) sur \(x\)) l'inégalité de Polyak–Łojasiewicz : \(f(x_k) - f^\star \leq \tfrac{1}{2\mu}\|\nabla f(x_k)\|^2\), i.e. \(\|\nabla f(x_k)\|^2 \geq 2\mu\,(f(x_k)-f^\star)\). En injectant dans le lemme 2.1 : $$f(x_{k+1}) \leq f(x_k) - \frac{1}{2L}\|\nabla f(x_k)\|^2 \leq f(x_k) - \frac{\mu}{L}(f(x_k)-f^\star).$$ L'erreur décroît géométriquement de facteur \(1-\mu/L = 1-1/\kappa \leq e^{-1/\kappa}\). ∎
Lecture des deux taux — ce que \(\kappa\) raconte Convexe seulement : erreur en \(1/k\) — pour diviser l'erreur par 100, 100 itérations de plus. Fortement convexe : erreur en \((1-1/\kappa)^k \approx e^{-k/\kappa}\) — pour gagner un facteur \(e\), \(\kappa\) itérations. Avec \(\kappa = 10^4\) (régression mal conditionnée, chapitre suivant), c'est la nuit : la descente « de base » est exponentiellement pénalisée par le conditionnement. Pas optimal : pour une quadratique, \(t = 2/(\mu+L)\) donne le facteur \(\big(\tfrac{\kappa-1}{\kappa+1}\big)^2\) sur les valeurs (exercice 2) : mieux, mais toujours en \(O(\kappa)\). Briser cette barrière est l'objet du chapitre 3.
Exemple 2.4 — Voir le conditionnement en deux dimensions \(f(u,v) = \tfrac{1}{2}(u^2 + \kappa v^2)\) : \(\kappa = L/\mu\) exactement, avec \(\nabla f = (u, \kappa v)\). Au pas \(1/L = 1/\kappa\), la direction raide \(v\) est annulée en une itération (\(v_1 = v_0 - \tfrac{1}{\kappa}\kappa v_0 = 0\)), mais la direction plate \(u\) ne décroît que de \((1-1/\kappa)\) par pas : c'est elle — la vallée allongée — qui fixe le rythme (\(\kappa\) itérations). Dès que la quadratique est tournée (axes non alignés), la trajectoire zigzague à travers la vallée. C'est le plot à retenir du module : toutes les figures « loss landscape » des réseaux (cf. module Deep Learning, ch. 3) montrent ces vallées — d'où le momentum. 
import numpy as np

def gradient_descent(grad, x0, step, n_iter=200):
    x, traj = x0.copy(), [x0.copy()]
    for _ in range(n_iter):
        x = x - step * grad(x)
        traj.append(x.copy())
    return np.array(traj)

kappa = 200.0
A = np.diag([1.0, kappa])          # L = kappa, mu = 1, conditionnement = kappa
grad = lambda x: A @ x
traj = gradient_descent(grad, np.array([9.0, 9.0]), step=1.0/kappa)
err = 0.5 * np.sum(traj**2 * np.array([1.0, kappa]), axis=1)
print(err[-1] / err[0])   # ~ (1 - 1/kappa)**400 ~ 0.14 : lent !
# pas optimal pour une quadratique : 2/(mu + L)
traj_opt = gradient_descent(grad, np.array([9.0, 9.0]), step=2.0/(1.0+kappa))
err_opt = 0.5 * np.sum(traj_opt**2 * np.array([1.0, kappa]), axis=1)
print(err_opt[-1] / err_opt[0])    # ~ ((kappa-1)/(kappa+1))**400 ~ 0.02 : mieux
