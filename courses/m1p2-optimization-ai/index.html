0. Refresher: convexity and duality

L3 reminders — the essentials of convex analysis (see Machine Learning module, ch. 0; Optimal Transport module, ch. 0)

  • Convexity: f\colon \mathbb{R}^d \to \mathbb{R} is convex if f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda) f(y) for all \lambda \in [0,1]; in finite dimension with f differentiable, this is equivalent to f(y) \geq f(x) + \langle \nabla f(x), y - x \rangle (subgradient inequality).
  • Strong convexity: x \mapsto f(x) - \tfrac{\mu}{2}\|x\|^2 is convex for some \mu > 0 — the subgradient inequality becomes strict by a quadratic term; this is what will yield linear (geometric) convergence.
  • Smoothness: \nabla f L-Lipschitz — that is, \|\nabla f(x) - \nabla f(y)\| \leq L \|x - y\|; equivalent to the quadratic upper bound f(y) \leq f(x) + \langle \nabla f(x), y-x\rangle + \tfrac{L}{2}\|y-x\|^2.
  • LP/KKT duality: primal problem \min f(x) subject to g_i(x) \leq 0, Lagrangian \mathcal{L}(x, \lambda) = f(x) + \sum_i \lambda_i g_i(x), dual function d(\lambda) = \inf_x \mathcal{L}(x,\lambda), dual \max_{\lambda \geq 0} d(\lambda); KKT conditions: feasibility, stationarity, complementary slackness \lambda_i g_i(x) = 0, \lambda \geq 0.

Proposition 0.1 — Weak duality (proved) For every feasible x and every \lambda \geq 0: d(\lambda) \leq f(x). In particular \max_\lambda d(\lambda) \leq \min_{x \text{ feasible}} f(x): the dual always provides lower bounds.

Proof. For feasible x, g_i(x) \leq 0 and \lambda_i \geq 0 give \mathcal{L}(x, \lambda) = f(x) + \sum_i \lambda_i g_i(x) \leq f(x). Taking the infimum over x on the left and then the supremum over \lambda, we get d(\lambda) \leq f(x) for every pair, hence \sup_\lambda d(\lambda) \leq \inf_{x \text{ feasible}} f(x). ∎

Theorem 0.2 — Strong duality (Slater) If the problem is convex (functions f, g_i convex) and there exists a strictly feasible point (g_i(x_0) < 0 for all active constraints), then the optimal dual value equals the primal value and the minimum of the dual is attained. The duality gap (the difference between the two) is zero: this is the key that allows, in chapter 8, replacing a constrained problem with a sequence of unconstrained problems playing on \lambda.

Why this refresher opens the module All of supervised learning is an optimization problem: minimize an empirical risk \frac{1}{n}\sum_i \ell(f_\theta(x_i), y_i) over \theta. The three structures of the refresher — convexity, smoothness, duality — determine the choice of algorithm (chapters 2–8) and its speed. Duality will return twice: for constraints (ch. 8, and L. Chamon’s work on learning under constraints, ch. 11) and to understand what “learning” means when one imposes requirements (fairness, safety) rather than a mere average cost.

1. Optimization inside the AI loop

Concrete scene: a fine-tune that “stops descending” while the gradient is not zero — conditioning. This chapter sets the frame.

What breaks Ignoring conditioning; confusing expected rates with practice; forgetting proximal on constraint / regularization.

Before the algorithms, the framework. Public enemy number one of the practitioner: conditioning; main ally: structure (convexity, separability, sparsity). This chapter fixes the vocabulary and the examples that will serve the whole module.

Definition 1.1 — Training problem Given data (x_i, y_i)_{i \leq n}, a parametric model h_\theta and a loss \ell, training solves \min_{\theta \in \mathbb{R}^d}\; F(\theta) = \frac{1}{n}\sum_{i=1}^n \ell(h_\theta(x_i), y_i) \;+\; \Omega(\theta), where \Omega (penalty) encodes a prior — sparsity \Omega = \lambda\|\theta\|_1, stability \Omega = \tfrac{\lambda}{2}\|\theta\|_2^2. Let f denote the differentiable part (the empirical risk) and g = \Omega the possibly non-differentiable part: this decomposition F = f + g structures chapters 4 and 8.

Proposition 1.2 — First-order optimality condition Let F be convex. Then \theta^\star minimizes F if and only if 0 \in \partial F(\theta^\star), where \partial F is the subdifferential (reduced to the singleton \{\nabla F(\theta)\} if F is differentiable).

Proof. (\Leftarrow) If 0 \in \partial F(\theta^\star), then for every \theta, F(\theta) \geq F(\theta^\star) + \langle 0, \theta - \theta^\star\rangle = F(\theta^\star). (\Rightarrow) If \theta^\star minimizes, the direction \theta - \theta^\star cannot be a descent direction for any \theta: the rate of increase [F(\theta^\star + t(\theta-\theta^\star)) - F(\theta^\star)]/t (t \downarrow 0) is \geq 0, which is exactly \langle v, \theta - \theta^\star \rangle \geq 0 for every v \in \partial F(\theta^\star) and every \theta — taking \theta = \theta^\star + v, it follows that \|v\|^2 \leq 0. ∎

Definition 1.3 — Subdifferential, reference examples \partial F(\theta) = \{v : F(\theta') \geq F(\theta) + \langle v, \theta'-\theta\rangle \;\forall \theta'\}. Examples: \partial \|\theta\| = \{\mathrm{sign}(\theta)\} if \theta \neq 0, =[-1,1] if \theta = 0; \partial (\tfrac{1}{2}\|\theta\|^2) = \{\theta\}; \partial \max(\theta_1,\theta_2) = \{e_{i^\star}\} if a unique argmax, a segment otherwise. Summation rule: if one of the two terms is continuous, \partial(F_1+F_2) = \partial F_1 + \partial F_2.

Example 1.4 — One-dimensional LASSO, by hand Minimize \frac{1}{2}(z - \theta)^2 + \lambda\|\theta\| with z \in \mathbb{R}. Optimality conditions: either \theta \neq 0 and \theta - z + \lambda\,\mathrm{sign}(\theta) = 0, hence \theta = z - \lambda\mathrm{sign}(\theta); or \theta = 0 and -z \in [-\lambda, \lambda]. We recover soft thresholding \theta^\star = \mathrm{sign}(z)\,\max(\|z\|-\lambda,\,0) = S_\lambda(z), the central operation of chapter 4: sparsity comes from the fact that the optimum “sticks” to zero for all \|z\| \leq \lambda — which the \ell_2 penalty never does.

What the module proves, and why At the end of the module, the student must be able to prove: the O(1/k) convergence of gradient descent (ch. 2), its linear convergence under strong convexity (ch. 2), the optimality of the \sqrt{\kappa} factor of acceleration (ch. 3), the rates of ISTA and FISTA (ch. 4), the stationary regime of constant-step SGD (ch. 5) and the local quadratic convergence of Newton (ch. 7). Each proof fits in a few lines of well-chosen inequalities — that is the point: making these rates reasonable, not esoteric.

2. Gradient descent: convergence proved

The most widely used algorithm in the world — each step of the following descent being executed somewhere right now:

x_{k+1} = x_k - t\, \nabla f(x_k), \qquad t > 0 \text{ the step.}

Lemma 2.1 — Guaranteed descent (descent lemma) If f is L-smooth and 0 < t \leq 1/L: f(x_{k+1}) \;\leq\; f(x_k) - \tfrac{t}{2}\,\|\nabla f(x_k)\|^2.

Proof. By the quadratic upper bound at y = x_{k+1} = x_k - t\nabla f(x_k): f(x_{k+1}) \leq f(x_k) + \langle\nabla f(x_k), -t\nabla f(x_k)\rangle + \tfrac{L}{2}t^2\|\nabla f(x_k)\|^2 = f(x_k) - t(1 - \tfrac{Lt}{2})\|\nabla f(x_k)\|^2, and t(1-\tfrac{Lt}{2}) \geq \tfrac{t}{2} whenever t \leq 1/L. ∎

Theorem 2.2 — O(1/k) convergence (smooth convex case, proved) Let f be convex and L-smooth, x^\star a minimizer, R = \|x_0 - x^\star\|, t = 1/L. Then f(x_{k+1}) - f(x^\star) \;\leq\; \frac{L R^2}{2\,(k+1)}.

Proof. Step 1 (three-point inequality). For every y — quadratic upper bound of f at x_k evaluated at x_{k+1}, combined with convexity f(x_k) \leq f(y) + \langle\nabla f(x_k), x_k - y\rangle —: f(x_{k+1}) \;\leq\; f(y) + \langle\nabla f(x_k), x_{k+1} - y\rangle + \frac{L}{2}\|x_{k+1} - x_k\|^2. Step 2 (y = x^\star and polarization). With \nabla f(x_k) = L\,(x_k - x_{k+1}) and y = x^\star, then the identity \langle a, b\rangle = \tfrac12(\|a+b\|^2 - \|a\|^2 - \|b\|^2) applied to a = x_k - x_{k+1}, b = x_{k+1} - x^\star (so that \|a+b\| = \|x_k - x^\star\| = R_k): f(x_{k+1}) - f^\star \;\leq\; L\langle x_k - x_{k+1},\, x_{k+1} - x^\star\rangle + \frac{L}{2}\|x_{k+1}-x_k\|^2 \;=\; \frac{L}{2}\big(R_k^2 - R_{k+1}^2\big). Step 3 (telescoping). Summing from 0 to T-1 and using \|x_T - x^\star\|^2 \geq 0: \sum_{k=0}^{T-1} (f(x_{k+1}) - f^\star) \leq \tfrac{L}{2}R_0^2. Since the sequence f(x_k) is decreasing (lemma 2.1), each term is bounded by the average: f(x_T) - f^\star \leq \tfrac{L R^2}{2T}. ∎

Theorem 2.3 — Linear convergence (\mu-strongly convex case, proved) Let f be \mu-strongly convex and L-smooth, t = 1/L. Then, with \kappa = L/\mu the condition number: f(x_{k+1}) - f(x^\star) \;\leq\; \Big(1 - \frac{1}{\kappa}\Big)\,\big(f(x_k) - f(x^\star)\big), \qquad f(x_k) - f^\star \;\leq\; e^{-k/\kappa}\,\big(f(x_0)-f^\star\big).

Proof. Strong convexity implies (by minimizing the quadratic lower bound f(x_k) + \langle\nabla f(x_k), x - x_k\rangle + \tfrac{\mu}{2}\|x - x_k\|^2 over x) the Polyak–Łojasiewicz inequality: f(x_k) - f^\star \leq \tfrac{1}{2\mu}\|\nabla f(x_k)\|^2, i.e. \|\nabla f(x_k)\|^2 \geq 2\mu\,(f(x_k)-f^\star). Injecting into lemma 2.1: f(x_{k+1}) \leq f(x_k) - \frac{1}{2L}\|\nabla f(x_k)\|^2 \leq f(x_k) - \frac{\mu}{L}(f(x_k)-f^\star). The error decreases geometrically by the factor 1-\mu/L = 1-1/\kappa \leq e^{-1/\kappa}. ∎

Reading the two rates — what \kappa tells us Merely convex: error in 1/k — to divide the error by 100, 100 more iterations. Strongly convex: error in (1-1/\kappa)^k \approx e^{-k/\kappa} — to gain a factor e, \kappa iterations. With \kappa = 10^4 (ill-conditioned regression, next chapter), it is night: the “basic” descent is exponentially penalized by the condition number. Not optimal: for a quadratic, t = 2/(\mu+L) yields the factor \big(\tfrac{\kappa-1}{\kappa+1}\big)^2 on the values (exercise 2): better, but still O(\kappa). Breaking this barrier is the subject of chapter 3.

Example 2.4 — Seeing the condition number in two dimensions f(u,v) = \tfrac{1}{2}(u^2 + \kappa v^2): \kappa = L/\mu exactly, with \nabla f = (u, \kappa v). At step 1/L = 1/\kappa, the steep direction v is canceled in one iteration (v_1 = v_0 - \tfrac{1}{\kappa}\kappa v_0 = 0), but the flat direction u decreases only by (1-1/\kappa) per step: it — the elongated valley — sets the pace (\kappa iterations). As soon as the quadratic is rotated (axes not aligned), the trajectory zigzags across the valley. This is the plot to remember from the module: all the “loss landscape” figures of networks (see the Deep Learning module, ch. 3) show these valleys — hence momentum.

import numpy as np

def gradient_descent(grad, x0, step, n_iter=200):
    x, traj = x0.copy(), [x0.copy()]
    for _ in range(n_iter):
        x = x - step * grad(x)
        traj.append(x.copy())
    return np.array(traj)

kappa = 200.0
A = np.diag([1.0, kappa])          # L = kappa, mu = 1, condition number = kappa
grad = lambda x: A @ x
traj = gradient_descent(grad, np.array([9.0, 9.0]), step=1.0/kappa)
err = 0.5 * np.sum(traj**2 * np.array([1.0, kappa]), axis=1)
print(err[-1] / err[0])   # ~ (1 - 1/kappa)**400 ~ 0.14: slow!
# optimal step for a quadratic: 2/(mu + L)
traj_opt = gradient_descent(grad, np.array([9.0, 9.0]), step=2.0/(1.0+kappa))
err_opt = 0.5 * np.sum(traj_opt**2 * np.array([1.0, kappa]), axis=1)
print(err_opt[-1] / err_opt[0])    # ~ ((kappa-1)/(kappa+1))**400 ~ 0.02: better

3. Conditioning and Nesterov acceleration

Can we go faster without second-order information (no Hessian)? Nesterov’s answer (1983): yes, by a factor \sqrt{\kappa} — and this is optimal: no first-order algorithm can do better on the class of smooth convex functions. This is one of the rare results of the discipline where optimality is known and achieved by a usable algorithm.

Theorem 3.1 — First-order lower bound (Nesterov 1983; Nemirovski–Yudin 1983) For any first-order method (having access only to gradients at the visited points), there exists a \mu-strongly convex and L-smooth function such that, after T iterations, f(x_T) - f(x^\star) \;\geq\; \Big(1 - \frac{1}{\sqrt{\kappa}}\Big)^{2T}\,\big(f(x_0)-f(x^\star)\big) \quad\text{(up to constants).} In other words: \Omega\!\big(\sqrt{\kappa}\,\log(1/\varepsilon)\big) iterations are necessary, versus \Omega(\kappa \log(1/\varepsilon)) for gradient descent; and \Omega(1/\sqrt{\varepsilon}) iterations in the general smooth convex case (vs \Omega(1/\varepsilon)). The proofs construct a blockwise quadratic “trap function” whose information propagates only one coordinate per iteration: they can be found in Nesterov (2004, §2.1) and Bubeck (2015, §3.5).

Definition 3.2 — Accelerated scheme (Nesterov, strongly convex case) With \gamma = \frac{1 - \sqrt{\mu/L}}{1 + \sqrt{\mu/L}} and step t = 1/L: y_k = x_k + \gamma\,(x_k - x_{k-1}), \qquad x_{k+1} = y_k - t\,\nabla f(y_k), and the initialization y_0 = x_0. Convergence is linear with factor 1 - \sqrt{\mu/L} = 1 - 1/\sqrt{\kappa} — the promised \sqrt{\kappa} factor. “Smooth convex” variant: \gamma_k = \frac{k-1}{k+2} (growing momentum), rate f(x_k) - f^\star \leq \frac{2L\|x_0-x^\star\|^2}{(k+1)^2}.

Theorem 3.3 — Intuition of the proof: estimate sequences The idea (detailed in Nesterov 2004, §2.2): build a family of quadratics \phi_k(x) = \ell_k + \frac{\gamma_k}{2}\|x - v_k\|^2 that (i) lower bound f everywhere, (ii) approach f(x_k) from above via the recursion \phi_{k+1}(x) = (1-\alpha_k)\,\phi_k(x) + \alpha_k\Big(f(y_k) + \langle\nabla f(y_k), x - y_k\rangle\Big), where the “look-ahead” point y_k minimizes \phi_k shifted by the latest linearization. Two recurrences fight each other: the mass \gamma_k grows (at best quadratically, \gamma_{k+1} = (1-\alpha_k)\gamma_k, \alpha_k^2/\gamma_{k+1} \leq 2L), while the gap \phi_k^\star \leq f(x_k) closes at the pace of the \alpha_k \sim 2/k. Result: f(x_k) - \phi_k^\star = O(L R^2/k^2). In continuous time (t = \varepsilon k), the scheme converges to the ODE \ddot{x} + \tfrac{3}{t}\dot{x} + \nabla f(x) = 0 — a ball in the valley with vanishing friction: the energy decreases like 1/t^2, the signature of acceleration.

4. Proximal methods: ISTA and FISTA

Gradient descent requires a gradient — impossible for F = f + \lambda\|\theta\|_1. The proximal trick: handle the smooth part with a gradient step, the non-smooth part with an explicit operation.

Definition 4.1 — Proximal operator For g\colon \mathbb{R}^d \to \mathbb{R} \cup \{+\infty\} convex lower semi-continuous: \mathrm{prox}_{t g}(v) = \arg\min_x \;\Big\{ g(x) + \frac{1}{2t}\|x - v\|^2 \Big\}. Special cases: g = 0 gives v (gradient descent); g = \iota_C (indicator of a closed convex set C) gives the projection \Pi_C(v); g = \lambda\|\cdot\|_1 gives componentwise soft thresholding (example 1.4).

Proposition 4.2 — Firm non-expansiveness (proved) For all v, w: \|\mathrm{prox}_{tg}(v) - \mathrm{prox}_{tg}(w)\| \;\leq\; \|v - w\|.

Proof. Write p = \mathrm{prox}_{tg}(v), q = \mathrm{prox}_{tg}(w). The optimality condition 1.2 gives 0 \in \partial g(p) + \tfrac{1}{t}(p - v) and 0 \in \partial g(q) + \tfrac{1}{t}(q-w), that is \tfrac{1}{t}(v - p) \in \partial g(p) and \tfrac{1}{t}(w-q) \in \partial g(q). Monotonicity of the subdifferential (\langle u - u', x - x'\rangle \geq 0 for u \in \partial g(x), u' \in \partial g(x')) yields \langle (v-p) - (w-q),\, p - q\rangle \geq 0, i.e. \langle v - w, p - q\rangle \geq \|p-q\|^2. By Cauchy–Schwarz, \|v-w\| \geq \|p-q\|. ∎

Definition 4.3 — ISTA and FISTA (Beck–Teboulle 2009; Daubechies et al. 2004) ISTA (iterative shrinkage-thresholding): x_{k+1} = \mathrm{prox}_{t g}\big(x_k - t\,\nabla f(x_k)\big), \qquad t \leq 1/L. FISTA (fast ISTA): ISTA + the Nesterov acceleration stage — y_k = x_k + \frac{k-1}{k+2}\,(x_k - x_{k-1}), \qquad x_{k+1} = \mathrm{prox}_{t g}\big(y_k - t\,\nabla f(y_k)\big).

Theorem 4.4 — Rates of ISTA (proved) and FISTA (admitted here) Let F = f + g with f convex L-smooth and g convex, and let R = \|x_0 - x^\star\|. ISTA at step 1/L satisfies F(x_k) - F(x^\star) \;\leq\; \frac{L R^2}{2k} \qquad\text{(and } F(x_{k+1}) \leq F(x^\star) + \tfrac{L}{2}\|x_{k+1}-x^\star\|^2 \text{ propagates as in ch. 2).} FISTA achieves F(x_k) - F(x^\star) \leq \frac{2L R^2}{(k+1)^2} — the \sqrt{\cdot} factor gained on the iteration count, exactly as in chapter 3.

Proof. Set u_k = x_k - t\nabla f(x_k), x_{k+1} = \mathrm{prox}_{tg}(u_k). (i) Proximal optimality. Writing 1.2 for the proximal problem at x_{k+1} against an arbitrary competitor y gives, after expanding the squares: g(x_{k+1}) \;\leq\; g(y) + \frac{1}{2t}\Big(\|y - x_k\|^2 - \|x_{k+1} - x_k\|^2\Big) + \langle \nabla f(x_k),\, y - x_{k+1}\rangle. (ii) Smoothness of f. f(x_{k+1}) \leq f(x_k) + \langle\nabla f(x_k), x_{k+1}-x_k\rangle + \tfrac{L}{2}\|x_{k+1}-x_k\|^2. (iii) Sum with y = x^\star, t = 1/L. The cross terms cancel and there remains F(x_{k+1}) - F(x^\star) \leq \tfrac{L}{2}\big(\|x^\star - x_k\|^2 - \|x_{k+1}-x_k\|^2\big) - \tfrac{1}{2L}\dots then the same telescoping as in theorem 2.2 (the distances to x^\star decrease by convexity of F and the proximal inequality) gives the sum in O(LR^2), hence the 1/k. The FISTA proof (Beck–Teboulle 2009, th. 4.4) propagates the estimate sequence of ch. 3 through the same pair (i)+(ii). ∎

Example 4.5 — LASSO: ISTA vs FISTA in practice

import numpy as np
rng = np.random.default_rng(0)
n, d, s = 60, 200, 8                       # underdetermined, sparse support
X = rng.normal(size=(n, d)); X /= np.sqrt(n)
theta_true = np.zeros(d); theta_true[:s] = rng.normal(size=s)
y = X @ theta_true + 0.05 * rng.normal(size=n)

L = np.linalg.norm(X, 2) ** 2              # Lipschitz constant of f = 0.5||Xt-y||^2
lam = 0.1 * np.linalg.norm(X.T @ y, np.inf)

def soft(v, t): return np.sign(v) * np.maximum(np.abs(v) - t, 0)

def ista(x, iters):
    for _ in range(iters):
        x = soft(x - (1/L) * X.T @ (X @ x - y), lam/L)
    return x

def fista(x, iters):
    z, t = x.copy(), 1.0
    for k in range(1, iters+1):
        xn = soft(z - (1/L) * X.T @ (X @ z - y), lam/L)
        t_next = (1 + np.sqrt(1 + 4*t*t)) / 2
        z = xn + ((t-1)/t_next) * (xn - x)   # Nesterov momentum
        x, t = xn, t_next
    return x

F = lambda th: 0.5*np.sum((X@th - y)**2) + lam*np.abs(th).sum()
x0 = np.zeros(d)
for it in (100, 1000):
    print(it, "ISTA:", F(ista(x0.copy(), it)), "FISTA:", F(fista(x0.copy(), it)))
# expected: at 1000 iterations, FISTA ~ 1e2--1e3 times closer to the optimum

The 1/k^2 vs 1/k factor is literally visible: same computations per iteration, radically different horizons. This is also the foundation of compressed sensing solvers and of large-scale LASSO (see the Machine Learning module, ch. 2).

Beyond: ADMM in one sentence When even f decomposes badly (f = f_1 + f_2 with two easy proxes but coupled variables), the ADMM method (augmented duality: rewrite \min f_1(x) + f_2(z) subject to x = z, alternate a prox over x, a prox over z, a dual step on the multiplier) inherits O(1/k) rates and reigns over problems with massive constraints. The loop is closed with ch. 0: this is applied duality, hence the augmented Lagrangian — see ch. 8.

5. Stochastic gradient descent

When n = 10^9, computing \nabla f costs 10^9 evaluations — per iteration. The founding gesture of modern learning (Robbins–Monro, 1951): accept a noisy but cheap gradient.

Definition 5.1 — SGD and assumptions Draw i_k uniformly from \{1,\dots,n\} (or from the batch): x_{k+1} = x_k - \eta_k\, g_k, \qquad g_k = \nabla \ell(h_{x_k}(x_{i_k}), y_{i_k}) + \nabla\Omega\text{ (when applicable).} Assumptions: (H1) unbiasedness \mathbb{E}[g_k \mid x_k] = \nabla f(x_k); (H2) bounded variance \mathbb{E}\|g_k - \nabla f(x_k)\|^2 \leq \sigma^2; (H3) Robbins–Monro \sum \eta_k = \infty, \sum \eta_k^2 < \infty for decreasing steps.

Theorem 5.2 — What can be proved simply (proof) Let f be convex L-smooth, (H1)–(H2), constant step \eta \leq 1/L. Then \mathbb{E}\big[f(x_{k+1})\big] \;\leq\; \mathbb{E}\big[f(x_k)\big] - \frac{\eta}{2}\,\mathbb{E}\|\nabla f(x_k)\|^2 + \frac{\eta^2 L \sigma^2}{2}. Consequences: (i) \liminf \mathbb{E}\|\nabla f(x_k)\|^2 \leq L\sigma^2\eta; (ii) at constant step, SGD converges to a neighborhood of the solution of radius O(\eta\sigma^2) — not to the solution.

Proof. Conditionally on x_k, the mean step equals -\eta\nabla f(x_k) (unbiasedness) and the noise \zeta_k = g_k - \nabla f(x_k) is centered. The descent lemma 2.1 applied to x_k - \eta g_k, then expanding the squares: \mathbb{E}_k[f(x_{k+1})] \leq f(x_k) - \eta\big(1 - \tfrac{L\eta}{2}\big)\|\nabla f(x_k)\|^2 + \tfrac{L\eta^2}{2}\,\mathbb{E}_k\|\zeta_k\|^2 \leq f(x_k) - \tfrac{\eta}{2}\|\nabla f(x_k)\|^2 + \tfrac{L\eta^2\sigma^2}{2}. (i) follows by summing and using the bounded decrease of the errors; (ii) by injecting back into the Polyak–Łojasiewicz inequality of ch. 2. ∎

Minibatching: buying variance with compute A mini-batch B of size b replaces g_k with the average over B: the variance drops to \sigma^2/b (independent draws), the cost rises to b gradients. At a fixed compute budget, large b = less noise but fewer steps — the optimal trade-off depends on the regime: in the convex case, steps of modest size b often dominate (Bottou–Curtis–Nocedal 2018, §5.3); in deep learning, very large batches require correcting the step (LARS, ch. 10). Hence the question of the next chapter: can we kill the variance without paying b or n at every step?

Proposition 5.3 — Noise is not (only) an evil The stationary regime O(\eta\sigma^2) of theorem 5.2 has a positive side: the fluctuations around the minimum sweep the “passes” of the landscape and experience (see the Deep Learning module, ch. 3) shows that the “flat” minima found by SGD often generalize better than the narrow valleys reached by deterministic methods. The very sigma² that sets the stationary error acts as an implicit regularizer — an active research theme (see ch. 11, A. Dieuleveut’s work on constant-step SGD).

import numpy as np
rng = np.random.default_rng(1)
n, d = 20_000, 50
X = rng.normal(size=(n, d)) / np.sqrt(d)
y = X @ rng.normal(size=d) + 0.3*rng.normal(size=n)

def sgd_logreg(eta, epochs=20, b=32):
    w = np.zeros(d); losses = []
    sig = lambda z: 1/(1+np.exp(-z))
    for ep in range(epochs):
        idx = rng.permutation(n)
        for s in range(0, n, b):
            B = idx[s:s+b]
            p = sig(X[B] @ w)
            g = X[B].T @ (p - y[B]) / b      # mini-batch gradient
            w = w - eta * g
        losses.append(np.mean(np.logaddexp(0, -(2*y-1)*(X@w))))  # exact risk
    return losses

for eta in (0.01, 0.1, 1.0):
    print(eta, "->", sgd_logreg(eta)[-1])
# expected: step too small = slow; too large = high plateau (eta*sigma^2 term)

6. Variance reduction: SAGA and SVRG

Between the “complete but expensive” and the “stochastic but noisy” gradient, a third way: keep memory of past gradients to build an unbiased estimator whose variance vanishes by itself.

Definition 6.1 — SAGA (Defazio, Bach, Lacoste-Julien, 2014) One maintains a table \phi_i \approx \nabla f_i(x) of the latest gradient computed for each term, and \bar\phi = \frac{1}{n}\sum_i \phi_i. At each iteration, draw i, update the table, then: x_{k+1} = x_k - \eta\Big(\nabla f_i(x_k) - \phi_i + \bar\phi\Big). The estimator is unbiased (the table does not depend on the current draw); its variance is \frac{1}{n}\sum_i \|\nabla f_i(x_k) - \phi_i\|^2 \to 0 at convergence — instead of SGD’s permanent \sigma^2.

Definition 6.2 — SVRG (Johnson–Zhang, 2013) Without a table: every m steps, recompute a full gradient \tilde\nabla = \nabla f(\tilde{x}) at a “viewpoint” \tilde x (snapshot), then use x_{k+1} = x_k - \eta\Big(\nabla f_i(x_k) - \nabla f_i(\tilde x) + \tilde\nabla\Big). Also unbiased; variance \propto \|\nabla f_i(x_k) - \nabla f_i(\tilde x)\|^2, small when x_k stays near the snapshot. Memory cost: O(d) — the big industrial argument.

Theorem 6.3 — Linear convergence (statement, sketch) For f = \frac{1}{n}\sum f_i \mu-strongly convex, each f_i L-smooth, SAGA and SVRG with step \eta \asymp 1/L converge linearly: \mathbb{E}\big[F(x_k) - F(x^\star)\big] \;\leq\; \Big(1 - c\,\min\Big(\frac{1}{n}, \frac{\mu}{L}\Big)\Big)^{k}\,\big(F(x_0)-F(x^\star)\big), that is O\big((n + \kappa)\log\frac{1}{\varepsilon}\big) evaluations of individual gradients — versus O(n\kappa\log\frac{1}{\varepsilon}) for deterministic descent. Sketch. The proof couples two recurrences: the decrease in function value (as in ch. 2, via unbiasedness) and the decrease of the estimator’s variance (extra contraction provided by the table/snapshot); the variance becoming multiplicative, it converts SGD’s O(\eta\sigma^2) plateau into a geometric contraction. ∎

Where theory stops (and deep learning begins) In deep learning, f_i is not convex, the SAGA table explodes (n gradient-sized models), and SGD noise is an ally (prop. 5.3): strict variance reduction is little used there. But the structure of the trade-off — variance vs cost per iteration — governs the batch choices, step schedules and Adam variants (ch. 10). Convex theory is the compass, not the territory.

7. Newton and quasi-Newton

Changing markets: pay for second-order information (Hessian) in exchange for quadratic local convergence — the number of correct digits doubles at every iteration.

Theorem 7.1 — Local quadratic convergence (proved) Let f be twice differentiable, \mu I \preceq \nabla^2 f(x) \preceq LI everywhere (f therefore strongly convex), Hessian M-Lipschitz. Newton’s method x_{k+1} = x_k - \nabla^2 f(x_k)^{-1} \nabla f(x_k) satisfies, as soon as \|x_0 - x^\star\| \leq \mu/M: \|x_{k+1} - x^\star\| \;\leq\; \frac{M}{2\mu}\,\|x_k - x^\star\|^2.

Proof. Write e_k = x_k - x^\star and expand \nabla f at x_k around x^\star (where \nabla f(x^\star) = 0): 0 = \nabla f(x^\star) = \nabla f(x_k) - \int_0^1 \nabla^2 f(x^\star + s e_k)\, e_k \, ds \;\Rightarrow\; \nabla f(x_k) = H_k e_k - \rho_k,\quad \|\rho_k\| \leq \frac{M}{2}\|e_k\|^2, where H_k = \nabla^2 f(x_k) and \rho_k = \int_0^1 (H_k - \nabla^2 f(x^\star+se_k))e_k\,ds collects the Hessian gap (\leq M \|e_k\| in operator norm, hence the \tfrac{M}{2}\|e_k\|^2 after integration). Then e_{k+1} = e_k - H_k^{-1}\nabla f(x_k) = H_k^{-1}\rho_k \;\Rightarrow\; \|e_{k+1}\| \leq \|H_k^{-1}\| \,\frac{M}{2}\|e_k\|^2 \leq \frac{M}{2\mu}\|e_k\|^2. \;\blacksquare If \|e_0\| \leq \mu/M, the error at least halves at every step — and then decreases quadratically once below 1. ∎

Definition 7.2 — BFGS in three ideas (1) Goal: replace \nabla^2 f with B_k \succ 0 updated at cost O(d^2). (2) Secant equation: impose B_{k+1} s_k = y_k with s_k = x_{k+1}-x_k, y_k = \nabla f(x_{k+1})-\nabla f(x_k) — the only second-order information extractable from gradients. (3) Rank-2 update (closest to B_k in the Frobenius sense under these constraints): B_{k+1} = B_k - \frac{B_k s_k s_k^\top B_k}{s_k^\top B_k s_k} + \frac{y_k y_k^\top}{y_k^\top s_k}. L-BFGS stores only the last m pairs (s_k, y_k) and reconstructs the product B_k^{-1}\nabla f by recursion: it is the standard weapon for smooth convex losses in high dimension (and the default solver of scipy.optimize.minimize(method="L-BFGS-B")).

8. Constraints in machine learning

Real life: “error rate \leq 5\,\% and demographic disparity \leq \delta and latency \leq 100 ms”. The average loss alone cannot express requirements; constraints are needed — and hence the duality of ch. 0, applied.

Definition 8.1 — Learning under constraints \min_{\theta}\; \frac{1}{n}\sum_i \ell(h_\theta(x_i), y_i) \quad\text{subject to}\quad \frac{1}{n}\sum_i c_j(h_\theta(x_i), x_i) \leq 0, \quad j = 1, \dots, m. Examples: demographic parity (gap of positive rates between groups), memory/latency budget at inference, false-negative rate in health. The empirical Lagrangian \mathcal{L}(\theta,\lambda) and the dual \max_{\lambda \geq 0} d(\lambda) are formed as in ch. 0.

Proof. Projection lemma. Example 8.4 — SVM: the constraint that becomes a penalty, that becomes a dual Hard-margin SVM (see the Machine Learning module, ch. 3): \min \tfrac12\|w\|^2 subject to y_i w^\top x_i \geq 1. (i) The Wolfe dual gives the box problem \max_\alpha -\tfrac12\|X^\top(\alpha\odot y)\|^2 + \mathbf{1}^\top\alpha subject to \alpha \geq 0, \alpha \perp y — a projection onto a simplex: projected descent of theorem 8.3. (ii) The regularized primal (hinge): \min \tfrac1n\sum \max(0, 1 - y_i w^\top x_i) + \lambda\|w\|^2 is a special case of the f + g form of ch. 4 — this time with a non-smooth f, solved by subgradient or by duality (SVRG shines there too). Three chapters of the module, a single problem.

Beyond the empirical optimum: “PAC” constrained learning Satisfying the constraints on average over the training set does not guarantee they will hold in test. This is the question addressed by L. Chamon (ch. 11): do generalization guarantees exist for learning under requirements? Positive answer (in the PAC framework, under conditions); and the empirical dual approaches the population dual well (empirical duality gap zero under good assumptions). Until ch. 11, remember: duality is not a computational artifact — it is what makes requirements learnable.

9. Hyperparameter optimization

The step t, the penalty \lambda, the batch size, the learning rate schedule: so many hyperparameters that the module has so far treated as given. Yet experience shows they are often worth more performance points than the choice of algorithm itself. Optimizing the optimizer.

Definition 9.1 — The problem (and why it is hard) \max_{h \in \mathcal{H}}\; v(h), \qquad v(h) = \text{validation score of a model trained with } h, an expensive function (each evaluation = one training run), noisy, non-convex, with no gradient available. Typically 5 to 50 dimensions, a budget of 10 to 1,000 evaluations. This is the territory of Bayesian derivative-free optimization.

Proposition 9.2 — Grid vs random (Bergstra–Bengio, argument) With a budget of B trials and p “important” hyperparameters out of d: the grid explores B^{1/d} values per dimension, random sampling explores B per dimension (but only once per draw). If only p \ll d parameters really matter, random search hits a good combination on those p with much higher probability: in a grid, every “good” cell on the p useful axes is duplicated across the d-p useless ones — a wasted budget.

Proof. Model: a cell is “good” if its coordinates on the p useful axes are good, probability q^p per random draw (q = fraction of good values per axis) — after B draws, the probability of touching none: (1-q^p)^B. In a regular grid of m = B^{1/d} values per axis: the number of combinations explored on the useful axes is m^p = B^{p/d} \ll B. As soon as p < d, B^{p/d} < B: the grid visits fewer useful regions at equal budget. ∎

Definition 9.3 — Bayesian optimization (GP-EI) (1) Model: v \sim \mathrm{GP}(0, k) over \mathcal{H}; after k evaluations, Gaussian predictions (\mu_k(h), \sigma_k(h)) at every point. (2) Expected improvement acquisition: with v_k^\star = \max_j v(h_j), \mathrm{EI}_k(h) = \mathbb{E}\big[(v(h) - v_k^\star)_+\big] = (\mu_k(h) - v_k^\star)\,\Phi(z_k(h)) + \sigma_k(h)\,\varphi(z_k(h)), \quad z_k = \frac{\mu_k - v_k^\star}{\sigma_k}. (3) Loop: evaluate h_{k+1} = \arg\max_h \mathrm{EI}_k(h), update the GP. The closed-form formula shows the exploitation/exploration mechanics: \mathrm{EI} grows when \mu exceeds the record (exploit) and when \sigma is large (explore).

Multi-fidelity: Hyperband, pragmatism When the evaluation has a “quality setting” (epochs, data subsample), launching many configurations cheaply and only pursuing the promising ones often dominates pure GP: this is Successive Halving and Hyperband (Li et al., 2017), ubiquitous in practice (optuna, ray tune). The practitioner’s reference trio: random to scout, Hyperband to dig, GP-EI for the 5–10 truly sensitive parameters.

import numpy as np
rng = np.random.default_rng(0)

    # ... real training replaced by a rugged function
    peak = 0.92 - 0.4*np.abs(np.log10(lr) + 1.5) - 0.15*np.log10(1+lam)

                for e in np.linspace(-4, -1, 8) for l in np.linspace(0, 3, 8))

                for _ in range(64))           # same budget: 64 trials

Definition 10.1 — Adam, reread and taken apart (cross-reference: Deep Learning module, ch. 3) Adam (Kingma–Ba, 2015) accumulates two exponential moments of the stochastic gradient g_k: m_k = \beta_1 m_{k-1} + (1-\beta_1)g_k, v_k = \beta_2 v_{k-1} + (1-\beta_2)g_k^2, and updates x_{k+1} = x_k - \eta\, \hat m_k / (\sqrt{\hat v_k} + \varepsilon). “Module” reading: m_k is Nesterov-heavy-ball (ch. 3); 1/\sqrt{v_k} is a per-coordinate step adapted to the observed variance (ch. 5: countering it); the bias correction \hat\cdot fixes the initialization. AdamW (Loshchilov–Hutter, 2019) corrects the weight-decay interaction — weight decay is not an additive term of the gradient, but a proximal step (ch. 4) on \tfrac{\lambda}{2}\|x\|^2: the difference changes the trajectories.

Learning rate schedule: warmup, cosine, large batch

  • Warmup: in the first iterations, the moments v_k are poorly estimated and the activations of deep networks poorly calibrated (variance that explodes with depth — see Deep Learning, ch. 1); ramping \eta linearly over 0.5–2% of the budget avoids destructive first steps.
  • Cosine / step decay: reducing \eta at the end of training shrinks the O(\eta\sigma^2) neighborhood of theorem 5.2 — exactly the Robbins–Monro logic, in practical form.
  • Large batch: with the batch multiplied by k, variance \sigma^2/k, but fewer steps per epoch; the “linear rule” (\eta \to k\eta) fails beyond a threshold; LARS/LAMB (You et al., 2017–2020) normalize the step by the per-layer weight/gradient norm — a heuristic, but the one that trained BERT and the LLMs.

Proposition 10.2 — Why it works anyway (overview) Three shock absorbers explain why non-convexity is not prohibitive: (i) overparameterization: with more parameters than constraints, local minima become rare — all connected and of similar value; (ii) local PL inequality: along trajectories, an analogue of the Polyak–Łojasiewicz condition (ch. 2) often holds empirically, which restores local linear convergence “as if”; (iii) SGD noise: the stationary regime (prop. 5.3) sweeps narrow passes and selects flat minima that generalize better. None of the three is a general theorem — this is precisely the research frontier of the field (and the angle of attack of the Deep Learning P2 module for the efficiency part, see Deep Learning P2 module, ch. 2).

The engineer’s reflex sheet Diagnosing a diverging training run: (1) \eta too large — divide by 10 (th. 5.2: the neighborhood grows as \eta\sigma^2); (2) no warmup; (3) faulty initialization/normalization (see Deep Learning, ch. 1); (4) exploding gradient — clipping (\|g\| \mapsto \min(1, c/\|g\|)\|g\|, a projection of ch. 8 onto a ball). A “flat” training run: step too small, batch too large, or missing momentum. These reflexes are chapters 2, 3 and 5.

Exercises

  1. Valley. For f(u,v)=\tfrac12(u^2+\kappa v^2), \kappa = 100, x_0 = (10, 1): compute the first three iterates of descent at step 1/L, plot the trajectory, and verify that the steep direction is canceled in one step while the flat direction decreases by 1 - 1/\kappa per step. Solution: \nabla f = (u, \kappa v), hence (10, 1) \to (9{,}9,\, 0) \to (9{,}801,\, 0) \to (9{,}703,\, 0) — v_1 = 0 but u_k = 10\,(1-1/\kappa)^k; to compare with Nesterov (\gamma = \tfrac{1-1/\sqrt\kappa}{1+1/\sqrt\kappa}) which reaches the target accuracy in \sqrt\kappa steps.
  2. Optimal step on a quadratic. Show that for f(x) = \tfrac12 x^\top A x with eigenvalues in [\mu, L], the constant step minimizing the contraction factor \rho(t) = \max_i \|1 - t\lambda_i\| equals t = 2/(\mu+L) and gives \rho = \frac{\kappa-1}{\kappa+1} — in x, hence \big(\tfrac{\kappa-1}{\kappa+1}\big)^2 on the values of f. Verify that this factor remains \geq 1 - \frac{2}{\kappa+1} and conclude that descent cannot beat O(\kappa) on this class.
  3. Soft thresholding. Prove the formula \mathrm{prox}_{\lambda\|\cdot\|}(z) = \mathrm{sign}(z)\max(\|z\|-\lambda, 0) (use example 1.4), then compute the \mathrm{prox} of the indicator of [a,b], of the \ell_2 ball, and of the probability simplex (algorithm of Duchi et al., 2008).
  4. ISTA/FISTA in practice. Take up the code of ch. 4: plot F(x_k)-F(x^\star) (reference: 5,000 ISTA iterations) on a log scale for ISTA, FISTA and FISTA+adaptive restart (reset the momentum to zero when F(x_{k+1}) > F(x_k)). Measure the experimental slopes and compare with 1/k and 1/k^2. Expected: FISTA+restart beats FISTA as soon as the solution is sparse (local strong convexity).
  5. SGD neighborhood. Prove claim (ii) of theorem 5.2: at constant step \eta, under strong convexity, \limsup \mathbb{E}[f(x_k)] - f^\star \leq \frac{\eta L\sigma^2}{2\mu}. Hint: combine the PL inequality f - f^\star \geq \frac{1}{2L}\|\nabla f\|^2 and f - f^\star \leq \frac{1}{2\mu}\|\nabla f\|^2 with theorem 5.2, in the stationary regime. Simulate with the code of ch. 5 for \eta \in \{0{,}01; 0{,}1; 1\}.
  6. Minimum viable SAGA. Implement SAGA (table of n gradients) for \ell_2-regularized logistic regression, n = 1\,000, d = 50, \mu chosen so that \kappa = 100. Plot the variance of the estimator \|g_k - \nabla f(x_k)\|^2 along the iterations and compare it with that of SGD; verify the linear convergence of theorem 6.3 (slope in log). Pitfall: the average \bar\phi must be maintained incrementally, not recomputed.
  7. Quadratic Newton. For f(x) = \frac{x^4}{4} (convex, Hessian 3x^2, Lipschitz M=6 locally, local \mu): show that x_{k+1} = x_k - \tfrac{x_k}{3} = \tfrac23 x_k (linear convergence, not quadratic: why?) and then that for f(x)=\frac{x^2}{2}+e^{-x} convergence is quadratic from the start. Compare scipy.optimize.minimize (Newton-CG, BFGS, L-BFGS-B) on the smoothed LASSO of ch. 4 in d = 200: iteration count, time, final accuracy.
  8. Constraints: penalty vs duality. Solve \min \tfrac12\|x\|^2 subject to Ax = b in two ways: (a) quadratic penalty \tfrac{\rho}{2}\|Ax-b\|^2, \rho \to \infty; (b) Uzawa \lambda_{k+1} = \lambda_k + \rho(Ax_{k+1}-b) with x_{k+1} minimizing the Lagrangian. Show that the dual is smooth with constant \rho\|A\|^2 + 1… and measure the conditioning of the two approaches; conclude on the superiority of the multiplier (which “remembers” the constraint) over the penalty (which forgets it).
  9. Random search. Reproduce proposition 9.2: build a dummy function in d = 6 dimensions of which only p = 2 matter, compare a truncated exhaustive 8^6 grid at equal budget vs random draws, over 20 repetitions; plot the distribution of the best score. Then test skopt.gp_minimize (GP-EI) at small budget: when does it beat random?
