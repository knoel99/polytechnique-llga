4. Méthodes proximales : ISTA et FISTA

La descente de gradient exige un gradient — impossible pour \(F = f + \lambda\|\theta\|_1\). L'astuce proximale : gérer la partie lisse par un pas de gradient, la partie non lisse par une opération explicite.

Définition 4.1 — Opérateur proximal Pour \(g\colon \mathbb{R}^d \to \mathbb{R} \cup \{+\infty\}\) convexe semi-continue inférieurement : $$\mathrm{prox}_{t g}(v) = \arg\min_x \;\Big\{ g(x) + \frac{1}{2t}\|x - v\|^2 \Big\}.$$ Cas particuliers : \(g = 0\) donne \(v\) (descente de gradient) ; \(g = \iota_C\) (indicateur d'un convexe fermé \(C\)) donne la projection \(\Pi_C(v)\) ; \(g = \lambda\|\cdot\|_1\) donne le seuillage doux composante par composante (exemple 1.4).
Proposition 4.2 — Ferme non-expansivité (démontrée) Pour tout \(v, w\) : \(\|\mathrm{prox}_{tg}(v) - \mathrm{prox}_{tg}(w)\| \;\leq\; \|v - w\|\).
Notons \(p = \mathrm{prox}_{tg}(v)\), \(q = \mathrm{prox}_{tg}(w)\). La condition d'optimalité 1.2 donne \(0 \in \partial g(p) + \tfrac{1}{t}(p - v)\) et \(0 \in \partial g(q) + \tfrac{1}{t}(q-w)\), soit \(\tfrac{1}{t}(v - p) \in \partial g(p)\) et \(\tfrac{1}{t}(w-q) \in \partial g(q)\). La monotonie du sous-différentiel (\(\langle u - u', x - x'\rangle \geq 0\) pour \(u \in \partial g(x)\), \(u' \in \partial g(x')\)) fournit \(\langle (v-p) - (w-q),\, p - q\rangle \geq 0\), i.e. \(\langle v - w, p - q\rangle \geq \|p-q\|^2\). Par Cauchy–Schwarz, \(\|v-w\| \geq \|p-q\|\). ∎
Définition 4.3 — ISTA et FISTA (Beck–Teboulle 2009 ; Daubechies et al. 2004) ISTA (iterative shrinkage-thresholding) : $$x_{k+1} = \mathrm{prox}_{t g}\big(x_k - t\,\nabla f(x_k)\big), \qquad t \leq 1/L.$$ FISTA (fast ISTA) : ISTA + l'étage d'accélération de Nesterov — $$y_k = x_k + \frac{k-1}{k+2}\,(x_k - x_{k-1}), \qquad x_{k+1} = \mathrm{prox}_{t g}\big(y_k - t\,\nabla f(y_k)\big).$$
Théorème 4.4 — Taux d'ISTA (démontré) et de FISTA (admis ici) Soit \(F = f + g\) avec \(f\) convexe \(L\)-lisse et \(g\) convexe, et soit \(R = \|x_0 - x^\star\|\). ISTA au pas \(1/L\) vérifie $$F(x_k) - F(x^\star) \;\leq\; \frac{L R^2}{2k} \qquad\text{(et } F(x_{k+1}) \leq F(x^\star) + \tfrac{L}{2}\|x_{k+1}-x^\star\|^2 \text{ se propage comme au ch. 2).}$$ FISTA atteint \(F(x_k) - F(x^\star) \leq \frac{2L R^2}{(k+1)^2}\) — le facteur \(\sqrt{\cdot}\) gagné sur le nombre d'itérations, exactement comme au chapitre 3.
Posons \(u_k = x_k - t\nabla f(x_k)\), \(x_{k+1} = \mathrm{prox}_{tg}(u_k)\). (i) Optim proximale. Écrire 1.2 pour le problème proximal en \(x_{k+1}\) contre un compétiteur arbitraire \(y\) donne, après développement des carrés : $$g(x_{k+1}) \;\leq\; g(y) + \frac{1}{2t}\Big(\|y - x_k\|^2 - \|x_{k+1} - x_k\|^2\Big) + \langle \nabla f(x_k),\, y - x_{k+1}\rangle.$$ (ii) Lissité de \(f\). \(f(x_{k+1}) \leq f(x_k) + \langle\nabla f(x_k), x_{k+1}-x_k\rangle + \tfrac{L}{2}\|x_{k+1}-x_k\|^2\). (iii) Somme avec \(y = x^\star\), \(t = 1/L\). Les termes croisés se compensent et il reste \(F(x_{k+1}) - F(x^\star) \leq \tfrac{L}{2}\big(\|x^\star - x_k\|^2 - \|x_{k+1}-x_k\|^2\big) - \tfrac{1}{2L}\dots\) puis le même télescopage qu'au théorème 2.2 (les distances à \(x^\star\) décroissent par convexité de \(F\) et l'inégalité proximale) donne la somme en \(O(LR^2)\), donc le \(1/k\). La preuve FISTA (Beck–Teboulle 2009, th. 4.4) propage l'estimate-sequence du ch. 3 à travers le même couple (i)+(ii). ∎
Exemple 4.5 — LASSO : ISTA vs FISTA en pratique 
import numpy as np
rng = np.random.default_rng(0)
n, d, s = 60, 200, 8                       # sous-determine, support parcimonieux
X = rng.normal(size=(n, d)); X /= np.sqrt(n)
theta_true = np.zeros(d); theta_true[:s] = rng.normal(size=s)
y = X @ theta_true + 0.05 * rng.normal(size=n)

L = np.linalg.norm(X, 2) ** 2              # constante de Lipschitz de f = 0.5||Xt-y||^2
lam = 0.1 * np.linalg.norm(X.T @ y, np.inf)

def soft(v, t): return np.sign(v) * np.maximum(np.abs(v) - t, 0)

def ista(x, iters):
    for _ in range(iters):
        x = soft(x - (1/L) * X.T @ (X @ x - y), lam/L)
    return x

def fista(x, iters):
    z, t = x.copy(), 1.0
    for k in range(1, iters+1):
        xn = soft(z - (1/L) * X.T @ (X @ z - y), lam/L)
        t_next = (1 + np.sqrt(1 + 4*t*t)) / 2
        z = xn + ((t-1)/t_next) * (xn - x)   # momentum de Nesterov
        x, t = xn, t_next
    return x

F = lambda th: 0.5*np.sum((X@th - y)**2) + lam*np.abs(th).sum()
x0 = np.zeros(d)
for it in (100, 1000):
    print(it, "ISTA:", F(ista(x0.copy(), it)), "FISTA:", F(fista(x0.copy(), it)))
# attendu : a 1000 iterations, FISTA ~ 1e2--1e3 fois plus proche de l'optimum
Le facteur \(1/k^2\) vs \(1/k\) se voit littéralement : mêmes calculs par itération, horizons radicalement différents. C'est aussi le socle des solveurs de compressed sensing et du LASSO « à grande échelle » (cf. module Machine Learning, ch. 2).
Au-delà : ADMM en une phrase Quand même \(f\) se décompose mal (\(f = f_1 + f_2\) avec deux prox faciles mais des variables couplées), la méthode ADMM (dualité augmentée : réécrire \(\min f_1(x) + f_2(z)\) sous \(x = z\), alterner prox sur \(x\), prox sur \(z\), pas dual sur le multiplicateur) hérite de taux \(O(1/k)\) et règne sur les problèmes à contraintes massives. La boucle est bouclée avec le ch. 0 : c'est de la dualité appliquée, donc du Lagrangien augmenté — cf. ch. 8.
