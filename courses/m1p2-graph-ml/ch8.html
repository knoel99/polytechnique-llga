8. Applications et mise en œuvre

  • Recommandation : graphe utilisateur-item, link prediction (ch. 6) ; PinSage (3 Md nœuds, 18 Md arêtes) = GraphSAGE à l'échelle industrielle ; cold-start = le cas inductif par excellence ;
  • Détection de fraude : classification de nœuds sur le graphe de transactions ; signaux typiques : proximités de compteurs, cycles de blanchiment (les motifs comptent !), hub de carte — les GNN capturent le voisinage multihops qu'un modèle iid ignore ; version temporelle au M2 (ch. 5) ;
  • Chimie / biotech : molécule = graphe (atomes = nœuds, liaisons = arêtes) ; classification de graphes pour prédire des propriétés (toxicité, solubilité, activité VIH) ; benchmarks : ZINC, QM9, ogbg-mol* ; la 3D et l'équivariance sont au M2 (ch. 3 et 9) ;
  • Complétion de graphes de connaissances : link prediction sur KG hétérogènes (TransE, R-GCN — ch. 6) ; base du RAG « entreprise » (ch. 11) ;
  • Passez à l'échelle : minibatching par voisinage, clustering, sampling (ch. 7), GPU multi-nœuds (M2, ch. 6) ; benchmarks ouverts : OGB.
Choix d'architecture — feuille de décision rapide Graphe homogène, features riches : GCN (baseline) ; arêtes bruitées/hétérogènes (fraude) : GAT / R-GCN ; production inductive : GraphSAGE ; besoin de distinguer des structures locales (cycles) : GIN + features de motifs (M2, ch. 1) ; dépendances longues (molécules, QA sur KG) : graph transformer (M2, ch. 4). Toujours : 2-4 couches, skip connections, dropedge léger en première intention.
