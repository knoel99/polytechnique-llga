Définition 2.1 — Invariance et équivariance aux permutations Un graphe n'a ni taille fixe, ni ordre canonique des nœuds : le modèle doit être permutation-invariant (sortie de graphe) : \(f(P X, P A P^\top) = f(X, A)\), ou permutation-équivariant (sortie par nœud) : \(f(PX, PAP^\top) = P f(X, A)\), pour toute matrice de permutation \(P\). Les CNN (grille), les RNN (séquence) violent ces contraintes — d'où des architectures dédiées (ch. 5) et toute la théorie d'expressivité du module M2 (ch. 1).
Transductif vs inductif — une distinction qui structure tout le module
  • Transductif : entraîner et tester sur le même graphe (embeddings ch. 3) ; impossible de prédire pour un nœud arrivé après l'entraînement ;
  • Inductif : le modèle (ses poids) se réapplique à de nouveaux graphes (GraphSAGE, GNN ch. 5)  — indispensable en production ;
  • Semi-supervisé structurel : sur Cora (2 708 nœuds), 140 étiquettes suffisent — la structure relaie l'information (hypothèse d'homophilie : les voisins partagent l'étiquette ; quand elle est fausse, il faut des arêtes « virtuelles » ou des modèles hétérophiles).
