5. GNN et message passing

Définition 5.1 — La couche de message passing (MPNN, Gilmer et al., 2017) $$h_v^{(\ell+1)} = \phi\Big(h_v^{(\ell)},\ \underset{u \in \mathcal{N}(v)}{\mathrm{AGG}}\ \big\{\psi\big(h_v^{(\ell)}, h_u^{(\ell)}\big)\big\}\Big)$$ message \(\psi\) (calculé par le voisin), agrégation \(\mathrm{AGG}\) (permutation-invariante : somme, moyenne, max, attention), update \(\phi\). Une couche = un tour de message passing = une convolution = un pas de diffusion sur le graphe. Le choix de \(\mathrm{AGG}\) n'est pas anodin : moyenne/max perdent la cardinalité ({a, a} et {a} ont même moyenne et même max) ; c'est l'objet du théorème GIN (M2, ch. 1).
Dérivation 5.2 — GCN depuis la convolution spectrale (Kipf & Welling, 2017) Partons du filtre de Tchebychev tronqué à \(K = 1\) sur le laplacien renormalisé \(L_{\mathrm{sym}} = I - \tilde D^{-1/2} \tilde A \tilde D^{-1/2}\), \(\tilde A = A + I\), dont les valeurs propres vivent dans \([0, 2]\) (d'où le rescaling \(\tilde\Lambda \approx \Lambda - I\) en approchant \(\lambda_{\max} \approx 2\)) : $$g_\theta(\tilde\Lambda) \approx \theta_0\, T_0 + \theta_1\, T_1(\tilde\Lambda) = \theta_0 I + \theta_1 (\Lambda - I).$$ En fixant le renormalization trick \(\theta_0 = -\theta_1 = \theta\) (un seul paramètre, filtre croissant vers les basses fréquences, auto-boucles stabilisant la dynamique) : $$g_\theta \approx \theta\,(2I - L_{\mathrm{sym}}) = \theta\, \tilde D^{-1/2} \tilde A \tilde D^{-1/2}.$$ En rajoutant la non-linéarité, la dimension cachée et les features \(X\), on obtient la couche GCN : $$H^{(\ell+1)} = \sigma\Big(\tilde D^{-1/2}\, \tilde A\, \tilde D^{-1/2}\, H^{(\ell)}\, W^{(\ell)}\Big), \qquad H^{(0)} = X,$$ moyennée renormalisée des représentations transformées des voisins ; \(L\) couches = réceptive field de \(L\) sauts. La renormalisation (i) annule la valeur propre nulle (pas de composante constante injectée), (ii) garde les gains en \([-1, 1]\) — condition de stabilité de la profondeur, reliée à l'over-smoothing ci-dessous.
GraphSAGE (Hamilton et al., 2017) — algorithme et pseudo-code Pour chaque nœud, agréger un échantillon de voisins puis concaténer avec la représentation courante : 
entree : G, features X, profondeur K, tailles d'echantillon s_1..s_K
pour v dans V : h_v^(0) = x_v
pour l = 1 .. K :
    pour v dans V :
        S_v = echantillon uniforme de N(v) de taille s_l        # K voisins dans le papier
        a_v^(l) = AGG({ h_u^(l-1) : u in S_v })                 # mean / LSTM / pool
        h_v^(l) = sigma( W_l . [ h_v^(l-1) || a_v^(l) ] )       # concatenation !
        h_v^(l) = h_v^(l) / ||h_v^(l)||                          # normalisation L2
sortie : z_v = h_v^(K)
La concaténation préserve l'information propre au nœud (sinon la moyenne des voisins écrase le signal local) ; l'échantillonnage fixe par couche borne le minibatch (ch. 7) ; le tout est inductif : les poids \(W_l\) se réappliquent à des nœuds/graphes non vus. Cas particuliers : AGG = mean ≈ GCN sans renormalisation ; AGG = pool (MLP + max) ; AGG = LSTM sur voisins ordonnés aléatoirement (l'ordre rompt l'invariance… approximation assumée ; le problème de l'ordre est traité par GOAT, ch. 10).
GAT (Veličković et al., 2018) — équations et complexité Poids d'arête appris par attention : $$e_{uv} = \mathrm{LeakyReLU}\big(a^\top [\,W h_u \| W h_v\,]\big), \qquad \alpha_{uv} = \frac{\exp(e_{uv})}{\sum_{u' \in \mathcal{N}(v)} \exp(e_{uv'})}, \qquad h_v^{(\ell+1)} = \sigma\Big(\sum_{u \in \mathcal{N}(v)} \alpha_{uv}\, W h_u^{(\ell)}\Big)$$ avec \(T\) têtes d'attention parallèles (T projections \(W^{(t)}\)) concaténées ou moyennées. Complexité par couche : \(\mathcal{O}(|V| F F' + |E| F')\) — linéaire en arêtes, comparable à GCN, mais avec des poids adaptés à chaque arête : utile quand le graphe est bruité ou que certaines relations comptent plus (transactions suspectes !). Structurellement identique à l'attention des transformers (module Deep Learning) : ici le masque d'attention est donné par le graphe, là il est calculé — les graph transformers du M2 (ch. 4) ferment la boucle en apprenant l'attention et en la biaisant par la structure.
Au-delà du graphe homogène : R-GCN, features d'arêtes
  • R-GCN (Schlichtkrull et al., 2018) : graphe relationnel (types d'arêtes \(r\) dans \(\mathcal{R}\)) ; \(h_v^{(\ell+1)} = \sigma\big(W_0 h_v^{(\ell)} + \sum_{r \in \mathcal{R}} \sum_{u \in \mathcal{N}_r(v)} \frac{1}{c_{v,r}} W_r\, h_u^{(\ell)}\big)\). Pour éviter l'explosion paramétrique (\(|\mathcal{R}| \times F \times F'\)): décomposition en bases \(W_r = \sum_b a_{rb} V_b\) ou block-diagonale. Usage type : encodage de graphes de connaissances pour le link prediction (ch. 6).
  • Features d'arêtes : (a) graphe de ligne (chaque arête devient un nœud) ; (b) convolution sur arêtes (NNConv) : \(\psi(h_u, e_{uv})\) au lieu de \(\psi(h_u)\) — la liaison chimique porte un type ; (c) attention conditionnée (GAT peut injecter \(e_{uv}\) dans \(e_{uv}\)-score).
  • Pooling hiérarchique : DiffPool (Ying et al., 2018) apprend une matrice d'affectation douce \(S^{(\ell)} = \mathrm{softmax}(\mathrm{GNN}_A(H^{(\ell)}))\) et contracte le graphe : \(H^{(\ell+1)} = S^{(\ell)\top} H^{(\ell)}\), \(A^{(\ell+1)} = S^{(\ell)\top} A^{(\ell)} S^{(\ell)}\) — coarse-graining neuronal, coûteux mais hiérarchique ; alternatives : sort/TopK pooling, readout pyramidal.
Théorème 5.3 — Over-smoothing : démonstration sur graphe régulier Sur un graphe \(d\)-régulier connexe, la propagation GCN sans poids/non-linéarité vérifie \(H^{(\ell)} = P^\ell X\) avec \(P = \frac{A + I}{d + 1}\). Alors $$H^{(\ell)} \xrightarrow[\ell \to \infty]{} \frac{\mathbf{1}\mathbf{1}^\top}{n}\, X,$$ la solution harmonique (moyenne globale), à vitesse géométrique \(\big(\frac{\lambda_2(A) + 1}{d + 1}\big)^\ell\).
Sur un graphe \(d\)-régulier, \(D = (d+1)I\) pour \(\tilde A\), donc \(\tilde D^{-1/2} \tilde A \tilde D^{-1/2} = (A + I)/(d+1) =: P\). \(A\) étant symétrique réelle, écrivons \(X\) dans sa base propre : \(A = \sum_i \lambda_i u_i u_i^\top\) avec \(u_1 = \mathbf{1}/\sqrt{n}\), \(\lambda_1 = d > \lambda_2 \geq \dots\), et \(\lambda_i < d\) pour \(i \geq 2\) (égalité seulement si composante connexe distincte). Alors \(P^\ell = \sum_i \big(\frac{\lambda_i + 1}{d+1}\big)^\ell u_i u_i^\top\) ; le terme \(i = 1\) vaut exactement \(\frac{\mathbf{1}\mathbf{1}^\top}{n}\) ; tous les autres ont un rapport \(\frac{\lambda_i + 1}{d + 1} < 1\) (et \(\geq 0\) si le graphe n'est pas biparti ; sinon \(> -1\) en valeur absolue) et décroissent géométriquement. Toute la information des composantes non constantes est effacée : tous les nœuds convergent vers le même vecteur ligne-moyenne — les plongements s'effondrent. ∎
Avec poids et non-linéarités, le phénomène persiste (collapse de rang ; Oono & Suzuki, ICLR 2020) : c'est une limite structurelle de la profondeur GCN. Remèdes :
  • Jumping Knowledge (Xu et al., 2018) : la readout agrège toutes les profondeurs \(h_v = \mathrm{JK}(h_v^{(1)}, \dots, h_v^{(L)})\) (concat / max / LSTM-attention) : chaque nœud choisit son échelle ;
  • résidus et normalisations (GCNII, APPNP — développés au M2, ch. 2) ;
  • en pratique : 2-4 couches suffisent et suffisent souvent — la profondeur utile est celle de la dépendance statistique de la tâche.
Deuxième limite structurelle — l'over-squashing (goulots topologiques) — est différente : elle concerne le canal et non la représentation, et se traite par rewiring ; tout le sujet est au M2, ch. 2. Troisième limite : l'expressivité bornée par 1-WL (M2, ch. 1). 
import torch
from torch_geometric.nn import GCNConv, GATConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root="/tmp/Cora", name="Cora")   # 2708 noeuds, 5429 aretes, 7 classes
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self, d_in, d_hid, n_classes):
        super().__init__()
        self.c1, self.c2 = GCNConv(d_in, d_hid), GCNConv(d_hid, n_classes)
    def forward(self, x, edge_index):
        return self.c2(torch.relu(self.c1(x, edge_index)), edge_index)

model = GCN(dataset.num_features, 64, dataset.num_classes)
opt = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)
for epoch in range(200):
    opt.zero_grad()
    out = model(data.x, data.edge_index)
    loss = torch.nn.functional.cross_entropy(out[data.train_mask], data.y[data.train_mask])
    loss.backward(); opt.step()
acc = (model(data.x, data.edge_index).argmax(1)[data.test_mask]
       == data.y[data.test_mask]).float().mean()
print(f"Cora test accuracy : {acc:.3f}")   # ~0.81 avec ce reglage simple
