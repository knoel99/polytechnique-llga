3. Node embeddings

Objectif Apprendre \(z_v \in \mathbb{R}^d\) tel que la similarité des embeddings reflète la proximité dans le graphe : \(\mathrm{sim}(z_u, z_v) \approx P(u \text{ voisin de } v)\) — une factorisation implicite de la matrice d'adjacence (ou d'une matrice de proximités dérivées), en opposition aux GNN du ch. 5 qui conditionnent l'embedding aux features \(X\).
DeepWalk (Perozzi et al., 2014) et node2vec (Grover & Leskovec, 2016)
  1. générer des marches aléatoires depuis chaque nœud (longueur \(\ell\), \(r\) marches par nœud) ; node2vec biaisent la marche par \((p, q)\) — développé ci-dessous ;
  2. appliquer word2vec skip-gram aux marches : les « phrases » sont des suites de nœuds, la fenêtre \(b\) définit les paires (centre, contexte) ;
  3. ensuite : n'importe quelle méthode vectorielle (k-means, classification…).
La marche aléatoire définit la proximité : deux nœuds co-visités souvent obtiennent des embeddings proches — la théorie NetMF (Qiu et al., 2018) montre rétroactivement que DeepWalk factorise une matrice déterministe de marches (théorème 3.4).
Dérivation 3.1 — Skip-gram avec negative sampling : la loss et son gradient Pour une paire (centre \(c\), contexte \(o\)) et \(K\) négatifs \(v_1, \dots, v_K\) tirés d'une distribution de bruit \(P_n\) (loi unigramme élevée à la puissance 3/4, comme en NLP) : $$\mathcal{L}(c, o) = -\log \sigma(z_o^\top z_c) \; - \; \sum_{k=1}^{K} \log \sigma(-z_{v_k}^\top z_c),$$ avec \(\sigma(s) = 1/(1 + e^{-s})\). En notant \(s_k = z_{v_k}^\top z_c\) et en dérivant \(\frac{d}{ds}[-\log\sigma(s)] = \sigma(s) - 1\) : $$\frac{\partial \mathcal{L}}{\partial z_c} = \big(\sigma(z_o^\top z_c) - 1\big)\, z_o \; + \; \sum_{k=1}^K \sigma(s_k)\, z_{v_k}, \qquad \frac{\partial \mathcal{L}}{\partial z_o} = \big(\sigma(z_o^\top z_c) - 1\big)\, z_c.$$ Lecture : le terme \(-z_o\) (car \(\sigma < 1\)) attire le contexte vers le centre, chaque négatif repousse avec un poids \(\sigma(s_k) \in ]0,1[\) — fort si le négatif est déjà trop proche. Descente de gradient stochastique : coût par paire \(\mathcal{O}(K d)\), indépendant de \(n\) — c'est ce qui a rendu word2vec (et donc DeepWalk) scalable ; l'astuce softmax hiérarchique remplace le \(\mathcal{O}(n)\) du softmax complet par \(\mathcal{O}(\log n)\).
Dérivation 3.2 — node2vec : les biais \(p\) et \(q\) par probabilités de transition À l'étape \(i\), la marche vient de \(t\), est en \(v\) ; pour le candidat \(x \in \mathcal{N}(v)\) : $$\pi_{tx} = \frac{w_{tx}}{Z}\, \alpha_{pq}(t, x), \qquad \alpha_{pq}(t, x) = \begin{cases} 1/p & \text{si } d_{tx} = 0 \\ 1 & \text{si } d_{tx} = 1 \\ 1/q & \text{si } d_{tx} = 2 \end{cases}$$ (\(d_{tx}\) = distance dans le graphe ; \(Z\) normalise sur \(\mathcal{N}(v)\) ; dans un graphe simple, \(d_{tx} \leq 2\) pour tout \(x \in \mathcal{N}(v) \cup \{t\}\) si \(t\) et \(v\) sont adjacents). Trois régimes :
  • \(p \lt 1\) : retour vers \(t\) favorisé — la marche reste dans le voisinage proche (BFS) : deux nœuds de rôles structuraux analogues (hubs, ponts) obtiennent des embeddings proches — équivalence structurelle ;
  • \(q \lt 1\) : les sommets à \(d_{tx} = 2\) sont favorisés — la marche s'éloigne (DFS) : deux nœuds d'une même communauté/cluster sont proches — homophilie ;
  • \(p = q = 1\) : marche aléatoire uniforme — DeepWalk est un cas particulier de node2vec.
La preuve qualitative : avec \(p \to 0\), la probabilité de revenir en \(t\) domine et la marche échantillonne le voisinage à 2 sauts de \(t\) de façon quasi uniforme ; avec \(q \to 0\), la chaîne évite \(t\) et se comporte comme une marche exploratoire de grande ampleur — retrouvez ces comportements dans l'exercice 3.
Théorème 3.3 — NetMF : DeepWalk comme factorisation de matrices (Qiu et al., 2018) Quand la fenêtre \(b\) et le nombre de marches croissent, DeepWalk converge vers la factorisation (tronquée, élément par élément) de la matrice : $$M = \log\Big( \frac{\mathrm{vol}(G)}{b\, T} \Big( \sum_{r=1}^{T} P^r \Big) D^{-1} \Big), \qquad \mathrm{vol}(G) = \sum_v d_v = 2m,$$ c'est-à-dire que l'on cherche \(Z Z^\top \approx M\) ; \(T\) joue le rôle de l'horizon effectif des marches. Conséquences : (i) un pont théorique — DeepWalk, LINE, PTE et node2vec sont toutes des factorisations de variantes de \(M\) (d'où le nom « NetMF », Network Embedding as Matrix Factorization) ; (ii) un algorithme déterministe — factoriser \(M\) directement (SVD tronquée) égale ou bat DeepWalk sans tirer une seule marche ; (iii) un diagnostic — la matrice cible est construite sur \(P = D^{-1}A\) : les embeddings encodent les marches, pas les features, et restent transductifs (un nouveau nœud exige de tout recalculer — motivation directe des GNN inductifs du ch. 5).
L'intuition « word2vec sur le graphe » — et sa réciproque C'est le pont historique NLP ↔ graphes : un corpus de marches ≈ un corpus de phrases. L'équipe pédagogique a poussé l'idée inverse — Graph of Words (ch. 10) : représenter un document par un graphe de termes co-occurrents et le classifier avec des outils de graphes. Les deux directions convergent aujourd'hui dans les LLMs sur graphes (ch. 11). Pour aller au-delà des marches (avec répétitions) vers des chemins (simples), voir les Path Neural Networks (ch. 10 ; M2, ch. 1 et 8).
Exemple 3.4 — Karate Club : code complet Le graphe de Zachary (34 nœuds, 78 arêtes, 2 factions lors de la scission du club) est le « MNIST des graphes ». 
import numpy as np, networkx as nx
from gensim.models import Word2Vec
from sklearn.cluster import KMeans
from sklearn.metrics import normalized_mutual_info_score

G = nx.karate_club_graph()
y = np.array([0 if G.nodes[v]["club"] == "Mr. Hi" else 1 for v in G])

def biased_walk(G, v, p, q, length):
    walk, prev = [v], None
    for _ in range(length):
        cand = list(G.neighbors(walk[-1]))
        probs = []
        for x in cand:
            d = 0 if x == prev else nx.shortest_path_length(G, prev, x) if prev is not None else 1
            probs.append({0: 1/p, 1: 1.0, 2: 1/q}[d])
        probs = np.array(probs) / sum(probs)
        prev, nxt = walk[-1], np.random.choice(cand, p=probs)
        walk.append(nxt)
    return walk

walks = [ [str(u) for u in biased_walk(G, v, p=1, q=0.25, length=30)]
          for _ in range(80) for v in G.nodes() ]
model = Word2Vec(walks, vector_size=64, window=5, min_count=0, sg=1, epochs=10)
Z = np.array([model.wv[str(v)] for v in sorted(G.nodes())])
km = KMeans(n_clusters=2, n_init=10, random_state=0).fit(Z)
print("NMI :", normalized_mutual_info_score(y, km.labels_))   # ~0.5-0.8 selon p, q, seed
