Exercices

  1. Laplacien. Montrer \(x^\top L x = \sum_{(u,v) \in E}(x_u - x_v)^2\), puis que \(\lambda_2 > 0 \iff\) connexe. Calculer le spectre du chemin et du cycle. Corrigé (esquisse) : développer \(x^\top D x - x^\top A x = \sum_v d_v x_v^2 - 2\sum_{(u,v)} x_u x_v\) et regrouper par arêtes ; \(\lambda_2 = 0\) équivaut à l'existence de \(x \perp \mathbf{1}\) non nul constant par composante (th. 0.3 du calcul de multiplicité), donc \(\lambda_2 > 0\) \(\iff\) une seule composante. Chemin : \(2(1 - \cos\frac{k\pi}{n})\) ; cycle : \(2(1 - \cos\frac{2k\pi}{n})\).
  2. Triangles par la trace. À partir de \(\mathrm{tr}(A^3)\), compter les triangles du graphe « deux \(K_4\) partagant une arête ». Généraliser : que compte \(\mathrm{tr}(A^4)\) ? Corrigé : les deux \(K_4\) contiennent chacun 4 triangles, aucun ne passe par l'arête partagée seule ; total 8, donc \(\mathrm{tr}(A^3) = 48\). \(\mathrm{tr}(A^4)\) compte les chemins fermés de longueur 4 (carrés, allers-retours…) — pas seulement les carrés ; il faut retrancher les contributions de degrés (formule de \(\sum_v d_v^2\) pour les allers-retours).
  3. node2vec. Simuler des marches avec \((p, q) = (1, 1)\), \((0{,}25, 4)\), \((4, 0{,}25)\) sur le graphe du club de karaté (code 3.4) ; projeter les embeddings en 2D (t-SNE) et relier \(p, q\) aux stratégies BFS/DFS. Corrigé (attendu) : \((p,q) = (0{,}25, 4)\) — retour fort, exploration faible → BFS, embeddings groupés par rôle (les deux hubs « Mr. Hi » et « Officer » se rapprochent) ; \((4, 0{,}25)\) → DFS, clustering par factions (homophilie), NMI plus élevé pour la tâche de scission ; \((1,1)\) intermédiaire.
  4. NetMF à la main. Pour le triangle \(K_3\), calculer \(M = \log\big(\frac{\mathrm{vol}}{bT}(\sum_{r=1}^T P^r) D^{-1}\big)\) avec \(T = 2\), \(b = 1\), et interpréter les signes. Corrigé : \(P = J - I\) (adjacence moins identité) ; \(P^2 = \frac{1}{2} I + \frac{1}{2} J\) ; \(\sum_{r\leq 2} P^r\) est strictement positive, \(D^{-1} = \frac13 I\), \(\mathrm{vol} = 6\) → \(M\) constante hors diagonale \(=\log(1{,}5)\), diagonale plus faible — DeepWalk sur un graphe sans structure ne peut que refléter les degrés ; conclusion : la matrice cible est le signal.
  5. Permutation-équivariance. Vérifier que la couche GCN satisfait \(f(PX, PAP^\top) = P f(X, A)\) et interpréter ; montrer qu'une couche dense classique (MLP sur features concaténées) ne la satisfait pas. Corrigé (esquisse) : \(\tilde D_{PAP^\top} = P \tilde D P^\top\) (les degrés suivent la permutation), donc \(\tilde D_{PAP}^{-1/2} (P\tilde A P^\top) \tilde D_{PAP}^{-1/2} P X = P \tilde D^{-1/2} \tilde A \tilde D^{-1/2} X\) ; un MLP dense sur la concaténation \([x_1 \| \dots \| x_n]\) applique des poids différents à chaque position — permuter les nœuds change la sortie autrement que par \(P\).
  6. GCN à la main. Implémenter une couche GCN sans PyG (calculer \(\tilde A\), \(\tilde D\)), vérifier l'égalité des sorties avec GCNConv à poids fixés, puis mesurer l'over-smoothing : similarité cosinus moyenne des embeddings en fonction du nombre de couches (1 à 10). Corrigé (guidé PyG) : 
    import torch, torch_geometric
from torch_geometric.datasets import Planetoid
data = Planetoid(root="/tmp/Cora", name="Cora")[0]
A = torch.zeros(2708, 2708)
A[data.edge_index[0], data.edge_index[1]] = 1.0
A_tilde = A + torch.eye(2708)
D_inv_sqrt = A_tilde.sum(1).pow(-0.5).diag()
P = D_inv_sqrt @ A_tilde @ D_inv_sqrt            # propagateur renormalise
X = data.x
for L in range(1, 11):
    H = X
    for _ in range(L):
        H = P @ H                                 # propagation pure (th. 5.3)
    cos = torch.nn.functional.cosine_similarity(
        H.unsqueeze(1), H.unsqueeze(0), dim=-1)
    print(L, (cos.sum() - 2708) / (2708 * 2707))  # -> converge vers 1
  7. Spectral clustering. Appliquer l'algorithme 4.4 (k = 2) au graphe « deux \(K_5\) + pont » en validant le vecteur de Fiedler de l'exemple 4.3 ; comparer Ncut et RatioCut pour la partition trouvée. Corrigé : signes du vecteur \((1,1,1,1,0{,}70,-0{,}70,-1,-1,-1,-1)\) → partition exacte ; \(\mathrm{cut} = 1\), RatioCut \(= \frac{1}{5} + \frac{1}{5} = 0{,}4\) ; Ncut \(= \frac{1}{16} + \frac{1}{16}\) (volumes 16) = 0,125 ; toute coupe séparant un seul nœud a un RatioCut \(\frac{5}{1} + \frac{5}{9}\) bien plus grand — la pondération par taille fait le travail.
  8. GAT. Montrer que la complexité mémoire de l'attention à \(T\) têtes est \(\mathcal{O}(T |E| F')\), et qu'avec des self-loops GCN s'obtient comme cas particulier d'attention uniforme. Comment GAT gère-t-il les graphes non réguliers que GCN normalise mal ?
  9. Link prediction. Sur Cora : masquer 10 % des arêtes, encoder avec un GAE (ch. 6), scorer les paires par \(\sigma(z_u^\top z_v)\) ; évaluer AUC contre des négatifs échantillonnés ; comparer GAE vs VGAE vs embeddings DeepWalk (ch. 3). Corrigé (guidé PyG) : 
    import torch.nn as nn
from torch_geometric.nn import GCNConv
from torch_geometric.utils import negative_sampling

class GAE(nn.Module):
    def __init__(self, d_in, d_hid):
        super().__init__()
        self.e1, self.e2 = GCNConv(d_in, d_hid), GCNConv(d_hid, d_hid)
    def forward(self, x, ei):
        return self.e2(torch.relu(self.e1(x, ei)), ei)

model, opt = GAE(1433, 64), None
opt = torch.optim.Adam(model.parameters(), lr=0.01)
# split : train_pos = 90 % des aretes ; test_pos = 10 % + autant de negatives
for ep in range(200):
    Z = model(data.x, train_pos_ei)
    neg = negative_sampling(train_pos_ei, num_nodes=2708)
    ei_all = torch.cat([train_pos_ei, neg], dim=1)
    lbl = torch.cat([torch.ones(train_pos_ei.size(1)),
                     torch.zeros(neg.size(1))])
    score = (Z[ei_all[0]] * Z[ei_all[1]]).sum(-1)
    loss = nn.functional.binary_cross_entropy_with_logits(score, lbl)
    opt.zero_grad(); loss.backward(); opt.step()
# AUC : trier les scores des aretes test et de nouveaux negatifs
    Attendu : AUC \(\approx 0{,}90\)–0,92.
  10. Échelle. Dériver la borne \(1 + s_L(1 + s_{L-1}(\dots))\) du NeighborSampler ; pour ogbn-arxiv (degrés moyens \(\approx\) 7, max 200+), quel fanout \((s_1, s_2)\) recommandez-vous et pourquoi ? Évaluer l'écart de précision vs full-batch sur Cora en augmentant la variance (fanouts (2,2), (5,5), (10,10)).
  11. Génération aléatoire. Implémenter ER et SBM (SBM : 4 blocs, \(B_{aa} = 0{,}8\), \(B_{ab} = 0{,}05\)), générer 500 graphes, et vérifier au MMD-degrés que ER ne reproduit pas la distribution de degrés du SBM. Quel \(k\) minimal du k-means spectral (ch. 4) retrouve les blocs ?
  12. Génération neuronale. Entraîner un petit modèle autorégressif (ajout séquentiel de nœuds/arêtes, MLP + softmax — schéma GraphRNN du ch. 9.4) sur des molécules de ZINC ; mesurer validité (valence chimique) et unicité des graphes générés ; comparer à un échantillonneur Erdős-Rényi de même densité. Pistes : coder les \(S^i\) binaires (4 types d'atomes max), teacher forcing, 200 époques suffisent pour le TME ; lecture : validité faible (\(< 50\,\%\)) sans contrainte de valence — expliquer pourquoi l'architecture de NeVAE (ch. 9.3) change tout.
