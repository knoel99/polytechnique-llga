2. Variables aléatoires

Définition 2.1 — Variable aléatoire Une variable aléatoire réelle est une application mesurable \(X : \Omega \to \mathbb{R}\) (i.e. \(X^{-1}(B) \in \mathcal{F}\) pour tout borélien \(B\)). Elle est discrète si son image est au plus dénombrable, à densité (continue) s'il existe \(f \geq 0\) avec \(\int f = 1\) telle que \(\mathbb{P}(X \in A) = \int_A f(x)\,dx\). La loi de \(X\) est la mesure image \(\mathbb{P}_X\) : tout ce qui se calcule avec \(X\) ne dépend que de sa loi, pas de \(\Omega\).

Un jeu de données standard en apprentissage est un \(n\)-uplet \(X_1, \dots, X_n\) iid (indépendants, identiquement distribués) selon une loi inconnue \(P\) : tout le chapitre 4 consiste à décrire ce qui se passe quand \(n\) grandit.

2.1. Fonction de répartition

Définition 2.2 \(F(t) = \mathbb{P}(X \leq t)\), définie sur \(\mathbb{R}\).
Théorème 2.3 — Propriétés caractéristiques \(F\) est croissante, càdlàg (continue à droite, limitée à gauche), avec \(\lim_{t \to -\infty} F(t) = 0\) et \(\lim_{t \to +\infty} F(t) = 1\). Réciproquement, toute fonction vérifiant ces propriétés est la fonction de répartition d'une unique loi. En outre \(\mathbb{P}(a \lt X \leq b) = F(b) - F(a)\) et \(\mathbb{P}(X = a) = F(a) - F(a^-)\) : \(F\) détermine entièrement la loi.
Croissance : si \(s \leq t\) alors \(\{X \leq s\} \subseteq \{X \leq t\}\), donc \(F(s) \leq F(t)\) par monotonie (proposition 1.3). Différence : \(\{X \leq b\} = \{X \leq a\} \sqcup \{a \lt X \leq b\}\), d'où la formule par additivité. Limites : \(\{X \leq n\} \uparrow \Omega\) quand \(n \to \infty\), donc \(F(n) \to 1\) par continuité croissante ; de même \(\{X \leq -n\} \downarrow \varnothing\) donne \(F(-n) \to 0\). Masse en un point : \(\{a - \tfrac1m \lt X \leq a\} \downarrow \{X = a\}\), donc \(\mathbb{P}(X=a) = F(a) - \lim_m F(a - \tfrac1m)\). Pour l'unicité (réciproque), on vérifie que la formule \(\mathbb{P}((a,b]) = F(b)-F(a)\) se prolonge en une probabilité sur les boréliens — c'est le théorème d'extension de Carathéodory, admis ici. ∎
Usage : la méthode inverse de simulation Si \(U \sim \mathcal{U}[0,1]\) et \(F\) est une fonction de répartition continue strictement croissante, alors \(X = F^{-1}(U)\) a pour loi \(F\) : en effet \(\mathbb{P}(F^{-1}(U) \leq x) = \mathbb{P}(U \leq F(x)) = F(x)\). C'est ainsi que les générateurs pseudo-aléatoires produisent toutes les lois à partir d'uniformes — cœur de toute simulation Monte Carlo et de l'échantillonnage des modèles génératifs (cf. module Deep Learning, échantillonnage par inversion de CDF ou par transformée).

2.2. Variables à densité : changement de variables

Théorème 2.4 — Formule de la jacobienne Soit \(X\) à densité \(f_X\) sur un ouvert \(D \subseteq \mathbb{R}^d\) et \(g : D \to \mathbb{R}^d\) un \(C^1\)-difféomorphisme. Alors \(Y = g(X)\) a pour densité $$f_Y(y) \;=\; f_X\big(g^{-1}(y)\big)\,\Big|\det J_{g^{-1}}(y)\Big|,$$ où \(J_{g^{-1}}\) est la matrice jacobienne de \(g^{-1}\).
Cas \(d=1\), \(g\) croissante : pour tout \(t\), \(\mathbb{P}(Y \leq t) = \mathbb{P}(g(X) \leq t) = \mathbb{P}(X \leq g^{-1}(t)) = F_X(g^{-1}(t))\). En dérivant (composée) : \(f_Y(t) = f_X(g^{-1}(t)) \cdot (g^{-1})'(t)\). Si \(g\) est décroissante, le sens de l'inégalité s'inverse et la dérivée est négative : la valeur absolue restaure la formule. Cas vectoriel : même raisonnement avec le théorème de changement de variables dans les intégrales multiples, qui introduit \(|\det J|\) ; l'aire locale se dilate exactement du facteur jacobien, et une densité doit se compenser inversement pour que la masse reste 1. ∎
Exemple 2.5 — Deux transformations à savoir refaire (a) Exponentielle par inversion. \(U \sim \mathcal{U}[0,1]\), \(X = -\tfrac1\lambda \ln U\). Ici \(g(u) = -\ln(\lambda u)/\lambda\)... prenons le chemin direct : \(F_X(x) = 1 - e^{-\lambda x}\) pour \(x \geq 0\), réciproque \(F^{-1}(u) = -\tfrac1\lambda\ln(1-u)\) : \(X = -\tfrac{1}{\lambda}\ln(1-U)\) suit \(\mathcal{E}(\lambda)\). Comme \(1-U \sim \mathcal{U}[0,1]\), on écrit aussi \(X = -\tfrac1\lambda \ln U\). (b) Standardisation gaussienne. \(X \sim \mathcal{N}(\mu, \sigma^2)\), \(Y = \tfrac{X - \mu}{\sigma}\) : \(g^{-1}(y) = \sigma y + \mu\), \((g^{-1})'(y) = \sigma\), donc \(f_Y(y) = \tfrac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(\sigma y + \mu - \mu)^2}{2\sigma^2}} \cdot \sigma = \tfrac{1}{\sqrt{2\pi}} e^{-y^2/2}\) : \(Y \sim \mathcal{N}(0,1)\).

2.3. Espérance, moments, fonction génératrice des moments

Définition 2.6 — Espérance Discrète : \(\mathbb{E}[X] = \sum_x x\, p(x)\) (si \(\sum |x| p(x) \lt \infty\)). À densité : \(\mathbb{E}[X] = \int x f(x)\,dx\) (si \(\int |x| f \lt \infty\)). Plus généralement \(\mathbb{E}[h(X)] = \int h \,d\mathbb{P}_X\) — la formule de transfert.
Proposition 2.7 — Linéarité, positivité, Tonelli \(\mathbb{E}[aX+bY] = a\,\mathbb{E}[X]+b\,\mathbb{E}[Y]\) sans hypothèse d'indépendance. Positivité : \(X \geq 0 \Rightarrow \mathbb{E}[X] \geq 0\), avec égalité ssi \(X = 0\) ps. Théorème de Tonelli : pour \(h \geq 0\) mesurable, \(\int h\,d(\mathbb{P}_X \otimes \mathbb{P}_Y) = \iint h\,d\mathbb{P}_X d\mathbb{P}_Y\) s'interpète en toute liberté (Fubini sans hypothèse d'intégrabilité dès que tout est positif) ; Fubini généralise aux fonctions intégrables. Conséquence : si \(X \perp Y\), \(\mathbb{E}[XY] = \mathbb{E}[X]\mathbb{E}[Y]\).
Proposition 2.8 — Variance et moments \(\mathrm{Var}(X) = \mathbb{E}[(X-\mathbb{E}X)^2] = \mathbb{E}[X^2] - (\mathbb{E}X)^2\) (formule de König-Huygens, à redémontrer en développant le carré) ; \(\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)\) ; \(\mathrm{Var}(aX+bY) = a^2\mathrm{Var}(X) + b^2\mathrm{Var}(Y) + 2ab\,\mathrm{Cov}(X,Y)\), qui se réduit à la somme quand \(\mathrm{Cov}=0\). Le k-ième moment est \(\mathbb{E}[X^k]\) ; moment centré d'ordre 3 normalisé = skewness, d'ordre 4 = kurtosis (diagnostics de loi, cf. module Signal Processing).
Définition 2.9 — Fonction génératrice des moments (MGF) \(M_X(t) = \mathbb{E}[e^{tX}]\), définie sur un voisinage de \(0\) si \(X\) a des moments de tous ordres à croissance exponentielle modérée. Propriétés : (i) \(M_X^{(k)}(0) = \mathbb{E}[X^k]\) — d'où son nom : on « lit » les moments en dérivant ; (ii) si \(X \perp Y\), \(\boxed{M_{X+Y}(t) = M_X(t)\,M_Y(t)}\) ; (iii) si \(M_X\) existe autour de 0, elle caractérise la loi (théorème de continuité de Lévy).
(ii) : par Tonelli/Fubini justifié par l'indépendance, \(\mathbb{E}[e^{t(X+Y)}] = \mathbb{E}[e^{tX}e^{tY}] = \mathbb{E}[e^{tX}]\,\mathbb{E}[e^{tY}]\). (i) : on dérive sous l'espérance \(\frac{d^k}{dt^k}\mathbb{E}[e^{tX}] = \mathbb{E}[X^k e^{tX}]\) puis on évalue en \(t=0\). Exemples à connaître : Bernoulli(\(p\)) : \(1-p+pe^t\) ; Poisson(\(\lambda\)) : \(e^{\lambda(e^t-1)}\) ; \(\mathcal{N}(\mu,\sigma^2)\) : \(e^{\mu t + \sigma^2 t^2/2}\) ; exponentielle : \(\frac{\lambda}{\lambda - t}\) (\(t \lt \lambda\)). ∎

2.4. Inégalités de base

Théorème 2.10 — Markov Si \(X \geq 0\) et \(a > 0\) : \(\mathbb{P}(X \geq a) \leq \dfrac{\mathbb{E}[X]}{a}\).
\(\mathbb{E}[X] = \mathbb{E}[X\,\mathbf{1}_{X \lt a}] + \mathbb{E}[X\,\mathbf{1}_{X \geq a}] \geq 0 + a\,\mathbb{P}(X \geq a)\), car sur l'événement \(\{X \geq a\}\) on a \(X \geq a\) et \(\mathbb{E}[X\mathbf{1}_{X\geq a}] \geq a\,\mathbb{E}[\mathbf{1}_{X \geq a}]\) par positivité. On isole \(\mathbb{P}(X \geq a)\). ∎
Théorème 2.11 — Tchebychev (et Bienaymé) Si \(\mathrm{Var}(X) \lt \infty\) et \(t > 0\) : \(\mathbb{P}\big(|X - \mathbb{E}X| \geq t\big) \leq \dfrac{\mathrm{Var}(X)}{t^2}\).
On applique Markov à la variable non négative \(Y = (X - \mathbb{E}X)^2\) avec \(a = t^2\) : \(\mathbb{P}(|X-\mathbb{E}X| \geq t) = \mathbb{P}(Y \geq t^2) \leq \mathbb{E}[Y]/t^2 = \mathrm{Var}(X)/t^2\). ∎
Théorème 2.12 — Cauchy-Schwarz \(|\mathbb{E}[XY]| \leq \sqrt{\mathbb{E}[X^2]\,\mathbb{E}[Y^2]}\), avec égalité ssi \(X\) et \(Y\) sont colinéaires dans \(L^2\). En particulier \(|\rho_{X,Y}| \leq 1\) pour tout couple de corrélation.
Pour tout \(\lambda \in \mathbb{R}\), \(0 \leq \mathbb{E}[(X + \lambda Y)^2] = \mathbb{E}[X^2] + 2\lambda\,\mathbb{E}[XY] + \lambda^2\mathbb{E}[Y^2]\) : c'est un trinôme en \(\lambda\) positif ou nul, donc de discriminant \(\leq 0\), soit \(4\,\mathbb{E}[XY]^2 - 4\,\mathbb{E}[X^2]\mathbb{E}[Y^2] \leq 0\). ∎

2.5. Covariance, corrélation, indépendance : démêler

Définition 2.13 \(\mathrm{Cov}(X,Y) = \mathbb{E}[(X-\mathbb{E}X)(Y-\mathbb{E}Y)] = \mathbb{E}[XY] - \mathbb{E}X\,\mathbb{E}Y\) ; \(\rho_{X,Y} = \mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y) \in [-1,1]\).
Proposition 2.14 — Le sens des implications Indépendance \(\Rightarrow\) \(\mathrm{Cov}(X,Y) = 0\) (et plus : factorisation de toutes les fonctions). Les réciproques sont fausses :
  • Décorrélé mais lié. \(X\) uniforme sur \(\{-1,0,1\}\), \(Y = X^2\). Alors \(\mathrm{Cov}(X,Y) = \mathbb{E}[X^3] - \mathbb{E}[X]\mathbb{E}[X^2] = 0 - 0 = 0\), alors que \(Y\) est une fonction déterministe de \(X\). La corrélation linéaire ne voit pas les dépendances non linéaires — défaut exploité par certaines adversarial attacks et excuse des « maximum entropy » features.
  • Corrélation sans lien direct. Deux variables provoquées par une troisième (confusion) peuvent être très corrélées (cf. Simpson, exemple 1.11).
  • \( |\rho| = 1\) \(\iff\) il existe \(a,b\) avec \(Y = aX+b\) ps : la corrélation extrême est uniquement l'affine.

2.6. Vecteurs aléatoires et espérance conditionnelle

Un vecteur aléatoire \(X = (X_1, \dots, X_d) \in \mathbb{R}^d\) admet une densité jointe \(f(x_1,\dots,x_d)\). Les lois marginales s'obtiennent en intégrant les autres variables : \(f_{X_1}(x_1) = \int f(x_1, x_2,\dots,x_d)\,dx_2 \dots dx_d\), et la densité conditionnelle est \(f_{X|Y}(x \mid y) = f(x,y)/f_Y(y)\). La version bayésienne du conditionnement s'écrit \(f_{Y|X}(y \mid x) \propto f_{X|Y}(x\mid y)\, f_Y(y)\) : exactement Bayes en densités.

Définition 2.15 — Espérance conditionnelle L'espérance conditionnelle de \(X\) sachant \(Y=y\) est \(g(y) = \mathbb{E}[X \mid Y = y] = \int x \, f_{X|Y}(x\mid y)\,dx\). La variable \(\mathbb{E}[X \mid Y] = g(Y)\) est la meilleure approximation de \(X\) par une fonction de \(Y\) au sens des moindres carrés : pour toute \(h\), \(\mathbb{E}[(X - h(Y))^2] \geq \mathbb{E}[(X - g(Y))^2]\) — c'est le théorème de projection dans \(L^2\). Propriété de la tour (tower property) : \(\mathbb{E}[\mathbb{E}[X \mid Y]] = \mathbb{E}[X]\), et \(\mathrm{Var}(X) = \mathbb{E}[\mathrm{Var}(X\mid Y)] + \mathrm{Var}(\mathbb{E}[X \mid Y])\) (variance totale : variance au sein + variance entre groupes — c'est l'identité au cœur de l'ANOVA, chapitre 6).
Lien avec la régression En apprentissage supervisé, on cherche à prédire \(Y\) à partir de \(X\). Le prédicteur optimal au sens de l'erreur quadratique moyenne est exactement la fonction de régression \(x \mapsto \mathbb{E}[Y \mid X = x]\). C'est l'objet que tous nos modèles (linéaire, réseaux de neurones, forêts…) tentent d'approcher ; l'erreur irréductible est \(\mathbb{E}[\mathrm{Var}(Y\mid X)]\).

2.7. Générer et manipuler des lois en Python

import numpy as np

rng = np.random.default_rng(seed=42)          # générateur moderne (PCG64)
x = rng.normal(loc=0.0, scale=1.0, size=1000) # 1000 tirages N(0,1)
u = rng.uniform(0, 1, size=100_000)

# Méthode inverse (théorème 2.4 + note 2.1) : U uniforme -> exponentielle
lam = 2.0
expo = -np.log(1.0 - u) / lam
print(expo.mean().round(4), (1/lam))          # ~0.5 = E[X] de E(2)

# Fonction de répartition empirique, histogramme (densité empirique)
import matplotlib.pyplot as plt
plt.hist(x, bins=40, density=True, alpha=.6, label='échantillon')
grid = np.linspace(-4, 4, 200)
plt.plot(grid, np.exp(-grid**2/2)/np.sqrt(2*np.pi), 'r', label='densité N(0,1)')
plt.legend(); plt.show()

print(x.mean(), x.var(ddof=1))   # moyenne empirique, variance (non biaisée)
print(np.quantile(x, [0.25, 0.5, 0.75]))  # statistiques d'ordre (chap. 3)

À retenir — chapitre 2

  • La fonction de répartition caractérise la loi ; la méthode inverse simule toute loi continue depuis des uniformes.
  • Changement de variables : \(f_Y(y) = f_X(g^{-1}(y))\,|\!\det J_{g^{-1}}(y)|\) — la jacobienne compense la dilatation locale.
  • MGF : moments par dérivation, produit pour les sommes d'indépendantes.
  • Markov \(\to\) Tchebychev \(\to\) (chapitre 4) la loi des grands nombres : la chaîne des inégalités est aussi une chaîne de preuves.
  • Décorrélé \(\neq\) indépendant (contre-exemple \(Y = X^2\)).
