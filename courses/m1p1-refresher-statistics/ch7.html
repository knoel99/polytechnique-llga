7. Régression linéaire

La régression linéaire est le premier modèle supervisé du master et le socle conceptuel de toute la suite : fonction de perte, optimisation, biais-variance, régularisation. On observe \(y = X\beta^\star + \varepsilon\) avec \(X \in \mathbb{R}^{n \times p}\) (chaque ligne un exemple), \(\beta^\star \in \mathbb{R}^p\), \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I_n)\) (hypothèse gaussienne à des fins d'inférence ; l'estimation n'en a pas besoin).

7.1 Moindres carrés : géométrie de la projection

Théorème 7.1 — Caractérisation géométrique Le minimiseur de \(\|y - X\beta\|^2\) — quand il existe — est caractérisé par $$X^\top(y - X\hat\beta) = 0 \qquad (\text{équations normales}),$$ i.e. le résidu est orthogonal aux colonnes de \(X\) : \(\hat y = X\hat\beta\) est la projection orthogonale de \(y\) sur \(\mathrm{Im}(X)\), et \(\hat\beta = (X^\top X)^{-1}X^\top y\) si les colonnes de \(X\) sont indépendantes.
Par le calcul : \(f(\beta) = \|y - X\beta\|^2\) est différentiable et strictement convexe sur l'espace des solutions ; \(\nabla f(\beta) = 2X^\top(X\beta - y)\), d'où le point stationnaire. Par la géométrie : décomposons \(y = \Pi_{\mathrm{Im}(X)} y + (I - \Pi) y\) (projection orthogonale, théorème de Pythagore dans \(\mathbb{R}^n\)). Pour tout \(\beta\) : \(\|y - X\beta\|^2 = \|(I-\Pi)y\|^2 + \|\Pi y - X\beta\|^2\) car les deux vecteurs sont orthogonaux (l'un dans \(\mathrm{Im}(X)^\perp\), l'autre dans \(\mathrm{Im}(X)\)). Le premier terme ne dépend pas de \(\beta\) ; on minimise donc le second, nul ssi \(X\beta = \Pi y\). D'où : le résidu \(y - \hat y = (I - \Pi)y\) est dans \(\mathrm{Im}(X)^\perp\), c'est-à-dire orthogonal aux colonnes (ce qui réécrit \(X^\top(y - X\hat\beta) = 0\)). On en tire aussi la décomposition de Pythagore \(\|y\|^2 = \|\hat y\|^2 + \|y - \hat y\|^2\) — base du \(R^2\). ∎
Théorème 7.2 — Gauss-Markov Parmi les estimateurs linéaires en \(y\) et sans biais de \(\beta^\star\), \(\hat\beta\) est de variance minimale (« BLUE »), au sens de l'ordre matriciel des covariances. De plus, sous bruit gaussien, \(\hat\beta\) est exactement le MLE.
Linéarité + non-biais : \(\delta = Cy\) avec \(CX = I_p\). Posons \(D = C - (X^\top X)^{-1}X^\top\), de sorte que \(DX = 0\). Alors \(C y = (X^\top X)^{-1}X^\top y + Dy = \hat\beta + Dy\), et \(\mathrm{Cov}(\delta) = \sigma^2 CC^\top\). Or \(CC^\top = \big[(X^\top X)^{-1}X^\top + D\big]\big[(X^\top X)^{-1}X^\top + D\big]^\top = (X^\top X)^{-1} + D D^\top\), car le terme croisé \((X^\top X)^{-1}X^\top D^\top = (X^\top X)^{-1}(DX)^\top = 0\). Donc $$\mathrm{Cov}(\delta) = \mathrm{Cov}(\hat\beta) + \sigma^2 DD^\top \;\succcurlyeq\; \mathrm{Cov}(\hat\beta) = \sigma^2 (X^\top X)^{-1},$$ \(DD^\top\) étant semi-définie positive : \(\mathrm{Var}(\text{toute forme linéaire de } \delta) \geq\) celle de \(\hat\beta\). MLE : la log-vraisemblance gaussienne en \(\beta\) vaut \(-\frac{1}{2\sigma^2}\|y - X\beta\|^2 + \text{cte}\) — maximiser revient à minimiser les moindres carrés. ∎

7.2 Inférence sur les coefficients

Théorème 7.3 — Loi exacte de \(\hat\beta\) sous bruit gaussien $$\hat\beta \sim \mathcal{N}\big(\beta^\star,\; \sigma^2 (X^\top X)^{-1}\big), \qquad \frac{(n - p)\,\hat\sigma^2}{\sigma^2} \sim \chi^2_{n-p} \;\; \text{indépendant de } \hat\beta, \qquad \hat\sigma^2 = \frac{\|y - X\hat\beta\|^2}{n - p}.$$
\(\hat\beta = (X^\top X)^{-1}X^\top y = \beta^\star + \underbrace{(X^\top X)^{-1}X^\top \varepsilon}_{\text{combinaison linéaire du gaussien } \varepsilon}\) : c'est donc un vecteur gaussien, de moyenne \(\beta^\star\) et de covariance \(\sigma^2 (X^\top X)^{-1} X^\top X (X^\top X)^{-1} = \sigma^2(X^\top X)^{-1}\) (définition 3.1, caractérisation linéaire). Pour \(\hat\sigma^2\) : le résidu \(r = (I - H)\varepsilon\) avec \(H = X(X^\top X)^{-1}X^\top\) le projecteur orthogonal ; \(I - H\) étant un projecteur de rang \(n - p\), \(\|r\|^2 = \varepsilon^\top (I-H)\varepsilon \sim \sigma^2 \chi^2_{n-p}\) (forme quadratique d'un gaussien blanc sur un sous-espace de dimension \(n-p\)). L'indépendance vient de \(H(I - H) = 0\) : deux gaussiens de covariance croisée nulle sont indépendants. On reconnaît au passage la perte de degrés de liberté : on estime \(p\) paramètres, il reste \(n - p\) dimensions de bruit — exactement le \(n-1\) de l'exemple 5.3 quand \(p = 1\). ∎
Proposition 7.4 — Tests t et intervalles par coefficient En standardisant \(\hat\beta_j\) par son écart-type estimé : $$t_j = \frac{\hat\beta_j}{\hat\sigma\sqrt{[(X^\top X)^{-1}]_{jj}}} \;\sim\; t_{n-p} \;\;\text{sous } H_0 : \beta_j = 0,$$ d'où tests et IC \(\hat\beta_j \pm t_{1-\alpha/2,\,n-p}\,\hat\sigma \sqrt{[(X^\top X)^{-1}]_{jj}}\). C'est la mécanique exacte derrière les tableaux de régression de statsmodels. 
import numpy as np
from scipy import stats
rng = np.random.default_rng(1)
n, p = 200, 3
X = np.column_stack([np.ones(n), rng.uniform(0, 10, n), rng.normal(0, 1, n)])
beta_star = np.array([1.0, 2.0, -0.5])
y = X @ beta_star + rng.normal(0, 2.0, n)

# Moindres carrés + inférence complète à la main (théorème 7.3)
XtX_inv = np.linalg.inv(X.T @ X)
beta_hat = XtX_inv @ X.T @ y
resid = y - X @ beta_hat
sigma2_hat = resid @ resid / (n - p)
se = np.sqrt(np.diag(XtX_inv) * sigma2_hat)
t_stat = beta_hat / se
pvals = 2 * stats.t.sf(np.abs(t_stat), df=n - p)
print(np.c_[beta_hat, se, t_stat, pvals].round(4))
# Chaque coefficient est récupéré avec |t| grand et p minuscule ; si l'on
# ajoute une colonne de bruit pur, son |t| ~ 1 et p ~ 0.3 : c'est le test
# de significativité que l'on appliquera aux features en ML.

# Même chose en 4 lignes avec scikit-learn (estimation seule)
from sklearn.linear_model import LinearRegression
print(LinearRegression().fit(X[:, 1:], y).coef_.round(3))

7.3 Qualité d'ajustement et diagnostics

Proposition 7.5 — \(R^2\) et \(R^2\) ajusté \(R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2} = \frac{\mathrm{SCI}}{\mathrm{SCT}}\) (part de variance expliquée ; dans le cadre gaussien, \(F = \frac{R^2/(p-1)}{(1-R^2)/(n-p)}\) — l'ANOVA du modèle). Il augmente mécaniquement avec le nombre de variables (le résidu ne peut que diminuer sur l'espace croissant \(\mathrm{Im}(X)\)) ; le \(R^2\) ajusté \(1 - (1-R^2)\frac{n-1}{n-p}\) pénalise ce « gratuit », mais la vraie réponse est la validation croisée — introduite dans le module Machine Learning.
Proposition 7.6 — Diagnostics à vérifier systématiquement
  • Résidus vs valeurs prédites : nuage sans structure (moyenne nulle, dispersion constante). Un entonnoir = hétéroscédasticité (les tests t ci-dessus sont alors approximatifs) ; une courbure = biais du modèle (il manque des termes).
  • QQ-plot des résidus : normalité (hypothèse des lois exactes t/F).
  • Leverages : \(h_{ii} = [H]_{ii} \in [0,1]\), \(\sum_i h_{ii} = p\). Une observation à fort leverage (valeur extrême en \(x\)) tire la droite à elle seule ; règle usuelle : s'inquiéter si \(h_{ii} > 2p/n\). Les résidus studentisés et la distance de Cook combinent leverage et résidu pour détecter les points influents.
  • Multicolinéarité : colonnes presque dépendantes \(\Rightarrow\) \((X^\top X)^{-1}\) explosive, \(\hat\beta\) instable (grosses variances, signes contraires à l'intuition). Remèdes : supprimer/redondancer, ridge (module Machine Learning).
Proposition 7.7 — Intervalle de confiance vs intervalle de prédiction Pour un nouveau point \(x_0\) : l'IC porte sur la moyenne \(\mathbb{E}[y \mid x_0] = x_0^\top\beta^\star\) : \(\hat y_0 \pm t_{1-\alpha/2,n-p}\,\hat\sigma\sqrt{x_0^\top (X^\top X)^{-1} x_0}\) ; l'intervalle de prédiction porte sur l'observation \(y_0\) elle-même et rajoute le bruit individuel : \(\hat y_0 \pm t_{1-\alpha/2,n-p}\,\hat\sigma\sqrt{1 + x_0^\top (X^\top X)^{-1} x_0}\). Le « \(1 + \) » rend le second toujours plus large : prédire une observation individuelle est plus incertain que prédire sa moyenne — confusion fréquente en industrie (promettre un CA moyen vs promettre une vente individuelle).

À retenir — chapitre 7

  • OLS = projection orthogonale : résidu \(\perp\) colonnes de \(X\), équations normales, Pythagore pour le \(R^2\).
  • Gauss-Markov : BLUE (preuve par \(C = S + D\), \(DX = 0\)) ; MLE si bruit gaussien.
  • \(\hat\beta\) gaussien exact, \(\hat\sigma^2\) en \(\chi^2_{n-p}\) indépendant, tests t standardisés — tout le tableau de régression découle de ces deux lois.
  • IC de moyenne ≠ intervalle de prédiction (le « 1+ ») ; diagnostics avant toute conclusion.
