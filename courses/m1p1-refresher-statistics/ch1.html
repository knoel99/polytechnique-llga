1. Le langage des probabilités

Le machine learning est, avant tout, un calculus de l'incertitude : on modélise des données comme réalisations de phénomènes aléatoires, puis on raisonne sur ces modèles. On reprend ici le vocabulaire avec le niveau de rigueur attendu en master, mais en gardant l'intuition L3. Chaque définition est accompagnée d'exemples numériques : ce cours doit vous rendre opérationnel pour tous les modules suivants.

Définition 1.1 — Espace probabilisable Un espace probabilisable est un couple \((\Omega, \mathcal{F})\) où \(\Omega\) est l'ensemble des résultats possibles (univers) et \(\mathcal{F} \subseteq 2^\Omega\) est une tribu : une famille de parties de \(\Omega\) contenant \(\Omega\), stable par passage au complémentaire et par union dénombrable. Les éléments de \(\mathcal{F}\) sont les événements : ce sont exactement les questions auxquelles le modèle autorise une réponse probabiliste.
Intuition : la tribu comme « information disponible » Pourquoi ne pas prendre simplement \(\mathcal{F} = 2^\Omega\) ? Deux raisons. (i) Techniquement, sur \(\Omega = [0,1]\) muni de la longueur, il existe des parties non mesurables (construction de Vitali) : vouloir mesurer tous les sous-ensembles mène à des contradictions. (ii) Conceptuellement, une tribu encode une information : si l'expérience est « lancer un dé » mais que l'observateur ne voit que la parité, la tribu pertinente est \(\{\varnothing, \{1,3,5\}, \{2,4,6\}, \Omega\}\). Cette lecture « tribu = information » est la clé des filtrations \((\mathcal{F}_t)\) en processus, du conditionnement et des modèles à données manquantes du chapitre 9.
Définition 1.2 — Probabilité Une probabilité sur \((\Omega,\mathcal{F})\) est une application \(\mathbb{P} : \mathcal{F} \to [0,1]\) telle que \(\mathbb{P}(\Omega)=1\) et, pour toute famille \((A_n)\) d'événements deux à deux disjoints : $$\mathbb{P}\Big(\bigcup_{n} A_n\Big) = \sum_{n} \mathbb{P}(A_n) \qquad (\sigma\text{-additivité}).$$ Le triplet \((\Omega, \mathcal{F}, \mathbb{P})\) est un espace probabilisé.
Proposition 1.3 — Propriétés immédiates Pour tous événements \(A, B\) : \(\mathbb{P}(A^c) = 1 - \mathbb{P}(A)\) ; \(A \subseteq B \Rightarrow \mathbb{P}(A) \leq \mathbb{P}(B)\) (monotonie) ; union bornée : \(\mathbb{P}(A \cup B) \leq \mathbb{P}(A) + \mathbb{P}(B)\) ; et pour une suite croissante \((A_n) \uparrow A\) : \(\mathbb{P}(A_n) \uparrow \mathbb{P}(A)\) (continuité séquentielle croissante).
Complémentaire : \(\Omega = A \sqcup A^c\), donc \(1 = \mathbb{P}(A) + \mathbb{P}(A^c)\). Monotonie : \(B = A \sqcup (B \setminus A)\) et \(\mathbb{P}(B\setminus A) \geq 0\). Union bornée : \(A \cup B = A \sqcup (B \setminus A)\) et \(B \setminus A \subseteq B\). Continuité croissante : poser \(C_1 = A_1\), \(C_n = A_n \setminus A_{n-1}\) ; les \(C_n\) sont disjoints, de réunion \(A\), et \(\sum_{k \leq n} \mathbb{P}(C_k) = \mathbb{P}(A_n)\) ; on conclut par σ-additivité. ∎

1.1 Conditionnement et probabilités totales

Définition 1.4 — Probabilité conditionnelle Si \(\mathbb{P}(B) > 0\) : \(\mathbb{P}(A \mid B) = \dfrac{\mathbb{P}(A \cap B)}{\mathbb{P}(B)}\). L'application \(A \mapsto \mathbb{P}(A \mid B)\) est elle-même une probabilité sur \((\Omega, \mathcal{F})\) : tout ce qui suit s'y applique.
Théorème 1.5 — Probabilités totales Si \((B_i)_{i \in I}\) est une partition de \(\Omega\) en événements de probabilité non nulle, alors pour tout événement \(A\) : $$\mathbb{P}(A) \;=\; \sum_{i \in I} \mathbb{P}(A \mid B_i)\,\mathbb{P}(B_i).$$
Les ensembles \(A \cap B_i\) sont deux à deux disjoints (car les \(B_i\) le sont) et leur réunion est \(A\) (car \(\bigcup_i B_i = \Omega\)). Par σ-additivité puis par définition du conditionnement, \(\mathbb{P}(A) = \sum_i \mathbb{P}(A \cap B_i) = \sum_i \mathbb{P}(A \mid B_i)\,\mathbb{P}(B_i)\). ∎

La formule de multiplication s'en détourne immédiatement : \(\mathbb{P}(A \cap B) = \mathbb{P}(A \mid B)\mathbb{P}(B)\), itérée en \(\mathbb{P}(A \cap B \cap C) = \mathbb{P}(C \mid A \cap B)\,\mathbb{P}(B \mid A)\,\mathbb{P}(A)\) — c'est le squelette des modèles séquentiels (chaînes de Markov, arbres de décision, autoregression des LLMs).

1.2 Indépendance

Définition 1.6 — Indépendance (trois niveaux)
  • Événements : \(A\) et \(B\) sont indépendants si \(\mathbb{P}(A \cap B) = \mathbb{P}(A)\,\mathbb{P}(B)\) — « connaître \(B\) ne change rien à \(A\) ». Une famille est mutuellement indépendante si toute sous-famille finie factorise ; l'indépendance deux à deux ne suffit pas (voir la note ci-dessous).
  • Variables : \(X\) et \(Y\) sont indépendantes si \(\mathbb{P}(X \in A, Y \in B) = \mathbb{P}(X \in A)\,\mathbb{P}(Y \in B)\) pour tous boréliens \(A, B\). En termes de densités : \(f(x,y) = f_X(x) f_Y(y)\).
  • Tribus : \(\mathcal{G}\) et \(\mathcal{H}\) sont indépendantes si \(\mathbb{P}(G \cap H) = \mathbb{P}(G)\mathbb{P}(H)\) pour tous \(G \in \mathcal{G}, H \in \mathcal{H}\). C'est le bon niveau pour les processus : « le futur est indépendant du passé sachant le présent ».
Deux pièges classiques Indépendance ≠ incompatibilité. Deux événements disjoints de probabilités non nulles ne sont jamais indépendants : \(\mathbb{P}(A \cap B) = 0 \neq \mathbb{P}(A)\mathbb{P}(B)\). Deux à deux ≠ mutuelle. Deux dés équitables : \(A\) = « le premier dé est pair », \(B\) = « le second dé est pair », \(C\) = « la somme est paire ». Alors \(\mathbb{P}(A)=\mathbb{P}(B)=\mathbb{P}(C)=\tfrac12\), chaque paire factorise (\(\mathbb{P}(A \cap B) = \tfrac14\), etc.), mais \(\mathbb{P}(A \cap B \cap C) = \tfrac14 \neq \tfrac18\) : la famille n'est pas mutuellement indépendante. En apprentissage, les caractéristiques « presque indépendantes » se comportent souvent ainsi — c'est exactement ce que le classifieur naïf bayésien du module NLP choisit d'ignorer.

1.3 Formule de Bayes

Théorème 1.7 — Formule de Bayes Si \((B_i)_{i\in I}\) est une partition de \(\Omega\) (événements disjoints de probabilités non nulles et de réunion \(\Omega\)), alors pour tout événement \(A\) de probabilité non nulle : $$\mathbb{P}(B_k \mid A) \;=\; \frac{\mathbb{P}(A \mid B_k)\,\mathbb{P}(B_k)}{\sum_{i\in I} \mathbb{P}(A \mid B_i)\,\mathbb{P}(B_i)}.$$
Numérateur : \(\mathbb{P}(A \mid B_k)\mathbb{P}(B_k) = \mathbb{P}(A \cap B_k) = \mathbb{P}(B_k \mid A)\mathbb{P}(A)\). Dénominateur : probabilités totales (théorème 1.5) appliquées à \(\mathbb{P}(A)\). On divise. ∎
Exemple 1.8 — Test médical (l'exemple à retenir à vie) Une maladie touche 1 % de la population (prior). Un test a une sensibilité de 99 % (\(\mathbb{P}(+ \mid M) = 0{,}99\)) et une spécificité de 95 % (\(\mathbb{P}(- \mid M^c) = 0{,}95\), donc \(\mathbb{P}(+ \mid M^c) = 0{,}05\)). Un patient tire un positif : quelle est la probabilité qu'il soit malade ? $$\mathbb{P}(M \mid +) = \frac{0{,}99 \times 0{,}01}{0{,}99 \times 0{,}01 + 0{,}05 \times 0{,}99} = \frac{0{,}0099}{0{,}0594} \approx 0{,}167.$$ Seulement 17 % ! Sur 10 000 personnes : ~99 malades testés positifs, mais ~495 faux positifs. L'intuition échoue car elle ignore la prévalence ; la formule de Bayes la réintroduit automatiquement. C'est la raison pour laquelle on ne dépiste pas n'importe quelle maladie rare dans n'importe quelle population.
Exemple 1.9 — Filtre anti-spam (Bayes naïf, avec chiffres) Base : 40 % des mails sont des spam. Le mot « gratuit » apparaît dans 70 % des spam et 5 % des mails légitimes. Partition \(\{S, S^c\}\) : $$\mathbb{P}(S \mid \text{mot}) = \frac{0{,}7 \times 0{,}4}{0{,}7 \times 0{,}4 + 0{,}05 \times 0{,}6} = \frac{0{,}28}{0{,}31} \approx 0{,}90.$$ Avec plusieurs mots supposés (approximativement) indépendants sachant la classe, on multiplie les vraisemblances : c'est le classifieur naïf bayésien, encore une baseline redoutable en NLP (cf. module NLP). L'exemple montre aussi la direction du raisonnement génératif : on spécule \(\mathbb{P}(\text{mail} \mid S)\) — facile à estimer par comptage — et on inverse par Bayes pour obtenir \(\mathbb{P}(S \mid \text{mail})\) — ce dont l'utilisateur a besoin.
Exemple 1.10 — Classification : règle de Bayes Pour classer un \(x\) among \(K\) classes, la théorie recommande de prédire $$\hat{y}(x) \;=\; \arg\max_k\; \mathbb{P}(y = k \mid x) \;\overset{\text{Bayes}}{=}\; \arg\max_k\; \underbrace{\mathbb{P}(x \mid y = k)}_{\text{vraisemblance}}\; \underbrace{\mathbb{P}(y = k)}_{\text{prior de classe}}.$$ Ce prédicteur, dit règle de Bayes, minimise l'erreur de classification ; son taux d'erreur est l'erreur de Bayes, plancher inatteignable. Chaque classifieur du master (régression logistique, softmax, LLM qui choisit le token suivant) est une façon d'estimer \(\mathbb{P}(y \mid x)\) puis d'appliquer l'argmax.

1.4 Le paradoxe de Simpson

Exemple 1.11 — Une corrélation qui s'inverse Un hôpital teste deux protocoles, A et B. Résultats (patients guéris / traités) :
GroupeProtocole AProtocole B
Cas légers95 / 100 = 95 %470 / 500 = 94 %
Cas sévères80 / 200 = 40 %8 / 50 = 16 %
Ensemble175 / 300 = 58 %478 / 550 = 87 %
A est meilleur dans chaque sous-groupe, mais B est meilleur sur l'ensemble ! Mécanisme : A a reçu surtout des cas sévères (200/300) et B surtout des cas légers (500/550) ; la gravité est un facteur de confusion, et le tableau global la mélange.
Simpson, fairness et ML Le paradoxe de Simpson est l'exemple le plus simple de corrélation non causale. Il hante le fairness : un modèle d'embauche « neutre en moyenne » par genre peut être discriminatoire dans chaque filière d'origine, ou l'inverse ; de même pour un modèle médical « calibré globalement » mais biaisé par sous-groupe ethnique. Moralité technique : toujours stratifier avant de conclure, et se rappeler qu'un modèle entraîné sur des données biaisées par un facteur de confusion apprend la confusion. Ce thème est approfondi dans le module Machine Learning (chapitre sur l'évaluation et les biais) et préparé par le chapitre 9 du présent cours.

À retenir — chapitre 1

  • Tribu = ensemble d'événements et niveau d'information ; probabilité = masse totale 1, σ-additive.
  • Probabilités totales : découper selon une partition ; Bayes : inverser conditionnement, le prior pèse autant que la vraisemblance.
  • Indépendance mutuelle (pas seulement deux à deux) ; indépendance ≠ incompatibilité.
  • Simpson : une association agrégée peut s'inverser par stratification — penser facteur de confusion.
