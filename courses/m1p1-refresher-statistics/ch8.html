8. Statistique bayésienne

Le cadre fréquentiste traite \(\theta\) comme une constante inconnue. Le cadre bayésien le traite comme une variable aléatoire dont on encode la connaissance a priori, puis la met à jour par les données. Ce chapitre — nouveau par rapport à un L3 standard — est indispensable au master : VAE, diffusion et calibration de LLMs sont des machines bayésiennes déguisées.

Définition 8.1 — Prior, posterior $$\pi(\theta \mid X_1, \dots, X_n) \;=\; \frac{L(\theta)\,\pi(\theta)} {\int L(u)\,\pi(u)\,du} \qquad (\text{posterior} \propto \text{vraisemblance} \times \text{prior}).$$ Le dénominateur (évidence) ne dépend pas de \(\theta\) : on travaille souvent à constante près. Le posterior d'aujourd'hui est le prior de demain : l'inférence est séquentielle par nature.

8.1. Conjugaison : Bernoulli-Beta

Théorème 8.2 Si \(\theta \sim \mathrm{Beta}(a, b)\) (prior) et \(X_i \mid \theta \sim \mathrm{Bernoulli}(\theta)\) iid, alors $$\theta \mid X_1, \dots, X_n \;\sim\; \mathrm{Beta}\big(a + k,\; b + n - k\big), \qquad k = \sum_i X_i.$$
Densité du prior : \(\pi(\theta) \propto \theta^{a-1}(1-\theta)^{b-1}\) sur \([0,1]\). Vraisemblance : \(L(\theta) = \theta^k (1-\theta)^{n-k}\). Produit : $$\pi(\theta \mid x) \propto \theta^{a + k - 1}(1-\theta)^{b + n - k - 1},$$ qu'on reconnaît comme la densité (non normalisée) d'une \(\mathrm{Beta}(a+k, b+n-k)\) — la constante de normalisation est fournie par la fonction beta d'Euler. Aucun calcul d'intégrale : la famille Beta est fermée sous l'opération « multiplier par la vraisemblance bernoullienne », c'est la conjugaison. ∎
Exemple 8.3 — Mise à jour séquentielle, avec chiffres Prior \(\mathrm{Beta}(1,1)\) (= uniforme, « on ne sait rien »). On observe 8 succès en 10 essais : posterior \(\mathrm{Beta}(9, 3)\). Moyenne posterior : \(\frac{9}{12} = 0{,}75\) (vs MLE \(0{,}8\) : le prior tire légèrement vers \(1/2\)). IC crédible à 95 % : quantiles 2,5 % et 97,5 % de \(\mathrm{Beta}(9,3)\), environ \([0{,}43 ; 0{,}94]\). Chaque nouvel essai met à jour \((a,b)\) : c'est exactement la structure des compteurs de spam de l'exemple 1.9 et des bandits bayésiens (module RL, Thompson sampling). 
from scipy import stats
post = stats.beta(9, 3)
print(post.mean().round(3), post.ppf([0.025, 0.975]).round(3))

8.2. Conjugaison gaussienne-gaussienne

Théorème 8.4 Modèle : \(X_i \mid \mu \sim \mathcal{N}(\mu, \sigma^2)\) (\(\sigma\) connu), prior \(\mu \sim \mathcal{N}(\mu_0, \tau^2)\). Alors $$\mu \mid \bar X_n \;\sim\; \mathcal{N}\!\left(\frac{\mu_0/\tau^2 + n\bar X_n/\sigma^2} {1/\tau^2 + n/\sigma^2},\;\; \frac{1}{1/\tau^2 + n/\sigma^2}\right).$$
En notant \(p = 1/\tau^2\), \(q = n/\sigma^2\) (les précisions), la densité jointe en \((\mu, \text{données})\) vue comme fonction de \(\mu\) est proportionnelle à \(\exp\big(-\frac{p}{2}(\mu - \mu_0)^2 - \frac{q}{2}(\mu - \bar X_n)^2\big)\). On complète le carré : la somme des deux termes quadratiques en \(\mu\) vaut \(-\frac{p+q}{2}\Big(\mu - \frac{p\mu_0 + q\bar X_n}{p+q}\Big)^2 + \text{cte}(\mu)\), où la constante ne dépend pas de \(\mu\). On reconnaît un noyau gaussien de précision \(p + q\) et de moyenne la moyenne pondérée par les précisions — moyenne posterior harmonique entre prior et données. ∎
Les précisions s'additionnent La variance posterior est plus petite que chacune : \(1/(p+q) \lt 1/p\). Quand \(n \to \infty\), \(q = n/\sigma^2\) écrase \(p\) : la moyenne posterior tend vers \(\bar X_n\), la variance vers \(\sigma^2/n\) — le bayésien retrouve le fréquentiste (et l'IC z du théorème 6.2). Le prior ne compte que sur petits \(n\). Cette phrase — « le prior est une donnée virtuelle de précision \(1/\tau^2\) » — est le meilleur moyen de paramétrer un prior honnêtement.

8.3. Intervalle crédible vs intervalle de confiance

Définition 8.5 — Intervalle crédible Un intervalle crédible à \(1-\alpha\) est un ensemble \(C\) tel que \(\mathbb{P}(\theta \in C \mid \text{données}) = 1 - \alpha\) — une probabilité sur \(\theta\), conditionnellement aux données observées. L'intervalle de confiance (définition 6.1) est une probabilité sur les données, avant observation, pour un \(\theta\) fixe.
Exemple 8.6 — La même expérience, deux lectures \(\sigma = 1\) connu, \(n = 1\) observation \(x = 0{,}7\), prior plat. Fréquentiste : l'intervalle \([x - 1{,}96, x + 1{,}96] = [-1{,}26, 2{,}66]\) a une propriété de procédure : sur 100 répétitions de l'expérience, ~95 des intervalles construits contiendront le \(\mu\) fixe. Dire « \(\mu\) a 95 % de chances d'être dans celui-ci » n'a pas de sens fréquentiste (\(\mu\) n'est pas aléatoire). Bayésien (prior plat) : \(\mu \mid x \sim \mathcal{N}(x, 1)\) et \([-1{,}26, 2{,}66]\) vérifie réellement \(\mathbb{P}(\mu \in C \mid x) = 0{,}95\) — c'est une déclaration de croyance rationalisée. Les nombres coïncident ici (prior plat + pivot), mais la sémantique diffère, et ils diffèrent dès que le prior n'est plus plat ou le modèle non gaussien. En pratique industrielle, la question posée (« quelle est la probabilité que le paramètre soit dans cette plage, sachant ce que j'ai vu ? ») est bayésienne ; savoir laquelle des deux vous calculer est une compétence du master.

8.4. MAP vs MLE

Définition 8.7 — Estimateur MAP Le maximum a posteriori maximise \(\pi(\theta)L(\theta)\) au lieu de \(L(\theta)\) seul : \(\hat\theta_{\mathrm{MAP}} = \arg\max_\theta \big[\log L(\theta) + \log \pi(\theta)\big]\). Le MLE est le MAP d'un prior uniforme. Exemple : Beta(2,2) et 3 succès en 4 essais : MAP \(= \frac{3+1}{4+2} = \frac23\) contre MLE \(= \frac34\).
MAP = MLE régularisé \(\log \pi(\theta)\) se comporte comme une pénalité ajoutée à la log-vraisemblance. Prior gaussien sur \(\theta\) \(\Leftrightarrow\) pénalité \(\ell_2\) (ridge) ; prior de Laplace \(\Leftrightarrow\) pénalité \(\ell_1\) (lasso). Toute la régularisation du module Machine Learning se relit bayésiennement : régulariser = exprimer un prior. Cette double lecture est systématiquement exploitée en deep learning (weight decay = prior gaussien sur les poids).

8.5. Le bayésien en génération

Pont vers les modules avancés
  • VAE (module Deep Learning) : le posterior \(\pi(z \mid x)\) est intractable ; on l'approxime par \(q_\phi(z\mid x)\) gaussien et l'on maximise l'ELBO — une version approximée de la mise à jour bayésienne du théorème 8.4, faite par réseau de neurones.
  • Diffusion : prior gaussien sur le bruit, chaîne de conditionnements gaussiens (théorème 3.2 appliqué en cascade).
  • Calibration et incertitude : les intervals crédibles quantifient l'incertitude épistémique (réductible par données) — objet du module Emerging ML.

À retenir — chapitre 8

  • Posterior \(\propto\) vraisemblance × prior ; conjugaison : Beta-Bernoulli et Gaussien-Gaussien (les deux à savoir démontrer).
  • Précisions additives : le prior est une donnée virtuelle ; asymptotiquement les données gagnent.
  • Crédible (probabilité sur \(\theta\)) ≠ confiance (probabilité sur la procédure).
  • MAP = MLE + pénalité ; ridge/lasso sont des MAP.
