3. Dimension de Vapnik-Chervonenkis et lemme de Sauer

Définition 3.1 — Pulvérisation, dimension VC, fonction de croissance Soit \(\mathcal{H}\) une classe de classeurs \(\mathcal{X} \to \{0,1\}\) (ou de fonctions réelles dont on prend le signe).
  • Un ensemble fini \(S = \{x_1, \dots, x_N\} \subset \mathcal{X}\) est pulvérisé (shattered) si toute étiquetage binaire de \(S\) est réalisé : \(|\mathcal{H} \cap S| = 2^N\), où \(\mathcal{H} \cap S = \{(h(x_1),\dots,h(x_N)) : h \in \mathcal{H}\}\) ;
  • la dimension VC \(d = \mathrm{VC}(\mathcal{H})\) est la taille maximale d'un ensemble pulvérisé (ou \(\infty\)) ;
  • la fonction de croissance \(\Pi_{\mathcal{H}}(N) = \max_{|S| = N} |\mathcal{H} \cap S|\) compte les dichotomies réalisables sur \(N\) points au pire cas.
Exemple 3.2 — Calculs de dimensions VC
  • Seuils sur \(\mathbb{R}\) (exemple 1.4) : deux points sont pulvérisés (4 dichotomies via le placement de \(t\)), trois points \(x_1 < x_2 < x_3\) ne le sont pas (impossible d'étiqueter \(\{x_1, x_3\}\) sans \(x_2\) : un seuil renvoie un intervalle de la forme \((-\infty,t]\)) : \(d = 2\). De même intervalles : \(d = 2\) ; unions de \(k\) intervalles : \(d = 2k\) ;
  • Hyperplans affines dans \(\mathbb{R}^p\) : \(d = p + 1\). \(\geq\) : les \(p+1\) points \(0, e_1, \dots, e_p\) sont pulvérisés par les hyperplans \(\langle w, x\rangle = b\) (autour de chaque sommet du simplexe, on isole n'importe quel sous-ensemble : pour une étiquette \(y \in \{0,1\}^{p+1}\) prendre \(w = \sum_j (2y_j - 1)e_j\), \(b\) bien choisi) ; \(\leq\) : \(p+2\) points en position générale sont liés par une dépendance affine \(\sum_j \alpha_j x_j = 0\) avec \(\sum \alpha_j = 0\) ; l'étiquetage \(y_j = \mathrm{sign}(\alpha_j)\) n'est pas réalisable (produit scalaire des signes avec les \(\alpha_j\) strictement positif interdit la séparation stricte). D'où, pour le perceptron et la régression logistique non régularisée, une complexité qui croît avec la dimension — à contraster avec la marge (ch. 6) ;
  • Rectangles alignés dans \(\mathbb{R}^2\) : \(d = 4\) (les 4 « points cardinaux » d'une configuration en croix) ; sinusoïdes \(\{x \mapsto \mathbf{1}_{\sin(tx) > 0}\}\) : \(d = \infty\) (pour tout \(N\), des points bien placés suivent le signe de n'importe quelle alternance) : croissance exponentielle \(\Pi(N) = 2^N\), pas d'apprentissage universel.
Théorème 3.3 — Lemme de Sauer-Shelah (démontré) Si \(\mathrm{VC}(\mathcal{H}) = d\), alors pour tout \(N \geq d\) : $$\Pi_{\mathcal{H}}(N) \;\leq\; \sum_{k=0}^{d} \binom{N}{k} \;\leq\; \Big(\frac{eN}{d}\Big)^{d}.$$
La majoration polynomial par \((eN/d)^d\) est l'inégalité classique sur les sommes binomiales (chaque \(\binom{N}{k} \leq (eN/k)^k\), somme dominée par \(k = d\) ; admise). Démontrons la première par double récurrence sur \(N\) et \(d\). Notons \(s(N,d) = \sum_{k=0}^{d}\binom{N}{k}\). Base : \(s(N,0) = 1\) (classe réduite à une fonction) ; \(s(0,d) = 1\) (un point vide : une seule dichotomie). Hérédité : fixons \(S = \{x_1, \dots, x_N\}\) et notons \(S' = \{x_1, \dots, x_{N-1}\}\). Partitionnons les traces sur \(S'\) en deux familles :
  • \(\mathcal{A}\) : traces réalisables des deux façons sur \(x_N\) (il existe \(h, h' \in \mathcal{H}\) coïncidant sur \(S'\) avec \(h(x_N) = 0\), \(h'(x_N) = 1\)) ;
  • \(\mathcal{B}\) : traces réalisables d'au moins une façon sur \(x_N\) (le complémentaire de \(\mathcal{A}\) dans les traces).
Alors \(|\mathcal{H} \cap S| = |\mathcal{A}| + |\mathcal{B}|\) : chaque trace de \(\mathcal{B}\) donne une dichotomie (label 0 sur \(x_N\)), chaque trace de \(\mathcal{A}\) en donne une de plus (label 1). Or :
  • \(\mathrm{VC}(\mathcal{B}) \leq d\) (sous-famille) : par récurrence, \(|\mathcal{B}| \leq s(N-1, d)\) ;
  • \(\mathrm{VC}(\mathcal{A}) \leq d - 1\) : si \(\mathcal{A}\) pulvérisait \(T \subseteq S'\) avec \(|T| = d\), alors \(T \cup \{x_N\}\) (taille \(d+1\)) serait pulvérisé par \(\mathcal{H}\) — les traces de \(\mathcal{A}\) sur \(T\) donnent tout et le point \(x_N\) se sépare des deux façons : contradiction avec \(\mathrm{VC}(\mathcal{H}) = d\). D'où \(|\mathcal{A}| \leq s(N-1, d-1)\).
Conclusion par l'identité de Pascal : \(s(N-1,d) + s(N-1,d-1) = s(N,d)\).∎
Message : une classe de dimension VC \(d\) n'émet que \((eN/d)^d\) dichotomies sur \(N\) points — croissance polynomiale d'exposant \(d\), contre \(2^N\) dans le pire cas. Le « nombre effectif d'hypothèses » est fini et contrôlé. 
import numpy as np
from itertools import combinations

# fonction de croissance des seuils sur R : exactement N+1 dichotomies
def croissance_seuils(N):
    return N + 1        # sur N points tries, un seuil coupe apres le k-ieme

def sauer(N, d):        # majoration de Sauer-Shelah
    return sum(len(list(combinations(range(N), k))) for k in range(d + 1))

for N in (5, 10, 20):
    print(f"N={N:3d}  seuils: {croissance_seuils(N):3d}  "
          f"Sauer(N,2)={sauer(N,2):4d}")   # N+1 <= 1 + N + N(N-1)/2
