8. Haute dimension : parcimonie et Lasso

Définition 8.1 — Modèle linéaire sparse et Lasso \(Y = X\beta^\star + \varepsilon\) avec \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I_n)\), matrice de design \(X \in \mathbb{R}^{n \times p}\) normalisée (\(\|X_{\cdot j}\|_2^2/n = 1\)), \(p \gg n\), vecteur parcimonieux \(\beta^\star\) supporté par \(S\), \(|S| = s \ll n\). Le Lasso (Tibshirani 1996 ; cf. module Machine Learning, chapitre 2) est $$\hat\beta \in \arg\min_{b \in \mathbb{R}^p} \Big\{ \frac{1}{2n}\|Y - Xb\|_2^2 + \lambda \|b\|_1 \Big\}.$$ Le Dantzig selector (Candès-Tao) remplace la minimisation par \(\min \|b\|_1\) sous \(\|X^\top(Y - Xb)\|_\infty \leq \lambda\) — les deux sont asymptotiquement équivalents (Bickel, Ritov et Tsybakov, 2009).
Proposition 8.2 — Conditions KKT du Lasso (démontrées) \(\hat\beta\) est solution si et seulement si $$\frac{1}{n} X^\top\big(Y - X\hat\beta\big) = \lambda\, \hat z, \qquad \hat z_j = \mathrm{sign}(\hat\beta_j) \text{ si } \hat\beta_j \neq 0, \quad \hat z_j \in [-1,1] \text{ sinon.}$$
La fonction objectif est convexe, propre ; son sous-différentiel en \(b\) est \(\frac1n X^\top(Y - Xb) + \lambda\,\partial\|b\|_1\) avec \(\partial\|b\|_1 = \prod_j \partial|b_j|\) et \(\partial|t| = \{\mathrm{sign}(t)\}\) si \(t \neq 0\), \([-1,1]\) si \(t = 0\). \(b \mapsto \frac{1}{2n}\|Y-Xb\|^2 + \lambda\|b\|_1\) atteint son minimum en \(\hat\beta\) ssi \(0\) appartient à ce sous-différentiel.∎
Ces conditions sont la tige de toutes les preuves : appliquées au « bruit empirique » \(z^\star_j = \frac1n X_{\cdot j}^\top \varepsilon\), elles montrent que le choix \(\lambda \geq 2\sigma\sqrt{2\log(2p)/n}\) rend l'événement \(\{|z^\star_j| \leq \lambda/2,\ \forall j\}\) très probable : chaque \(z^\star_j\) est \(\mathcal{N}(0,\sigma^2/n)\), donc \(\mathbb{P}(|z^\star_j| > \lambda/2) \leq 1/(2p)\) (queue gaussienne), et l'union bound (prop. 0.1) donne au moins \(1/2\) — ou \(1-\delta\) en remplaçant \(\log(2p)\) par \(\log(2p/\delta)\) (module Probability Theory for ML, chapitre 2, pour les queues gaussiennes).
Définition 8.3 — Condition de compatibilité Le design \(X\) satisfait la condition de compatibilité sur les cônes de parcimonie s'il existe \(\kappa > 0\) tel que, pour tout \(h \in \mathbb{R}^p\) avec \(\|h_{S^c}\|_1 \leq 3\|h_S\|_1\) : $$\frac{1}{n}\|Xh\|_2^2 \;\geq\; \kappa^2\, \|h_S\|_2^2.$$ Interprétation : les colonnes liées au support doivent transporter une norme euclidienne suffisante, même dans les directions presque opposées à \(S\) — une version localisée (sur le cône) de l'inversibilité. Vérifiée avec grande probabilité pour des designs gaussiens ou bornés dès que \(n \gtrsim s\log p\) (cf. Wainwright, High-Dimensional Statistics, chapitre 7).
Théorème 8.4 — Inégalité oracle du Lasso (énoncée, squelette de preuve) Sur l'événement \(\{|z^\star_j| \leq \lambda/2\ \forall j\}\) et sous la condition de compatibilité, avec \(\lambda = 2\sigma\sqrt{2\log(2p)/n}\) : $$\frac{\|X(\hat\beta - \beta^\star)\|_2^2}{n} \;\leq\; \frac{72}{\kappa^2}\, \frac{\sigma^2 s \log(2p)}{n}, \qquad \|\hat\beta - \beta^\star\|_1 \;\leq\; \frac{24}{\kappa^2}\, \sigma s \sqrt{\frac{2\log(2p)}{n}}$$ (constantes non optimales, cohérentes avec le squelette ci-dessous ; la version sharp de Bickel, Ritov et Tsybakov, 2009, a la même structure). Squelette (les quatre pas à compléter en exercice) :
  • (a) Inégalité de base : optimabilité de \(\hat\beta\) contre \(b = \beta^\star\) donne, avec \(h = \hat\beta - \beta^\star\) : \(\frac{1}{2n}\|Xh\|^2 \leq \frac1n h^\top X^\top\varepsilon + \lambda(\|\beta^\star\|_1 - \|\beta^\star + h\|_1)\) ;
  • (b) Cône : les conditions KKT (prop. 8.2) et l'événement \(\{|z^\star_j| \leq \lambda/2\}\) transforment (a) en \(\frac{1}{2n}\|Xh\|^2 + \frac{\lambda}{2}\|h_{S^c}\|_1 \leq \frac{3\lambda}{2}\|h_S\|_1\) : en particulier \(h\) est dans le cône \(\|h_{S^c}\|_1 \leq 3\|h_S\|_1\) ;
  • (c) Conversion : en abandonnant le terme positif de (b), puis Cauchy-Schwarz \(\|h_S\|_1 \leq \sqrt s\,\|h_S\|_2\), puis compatibilité (déf. 8.3) sur le cône : \(\kappa^2\|h_S\|_2^2 \leq \|Xh\|^2/n \leq 3\lambda\sqrt s\,\|h_S\|_2\) ;
  • (d) Assemblage : l'inégalité du second degré de (c) donne \(\|h_S\|_2 \leq 3\lambda\sqrt s/\kappa^2\) ; d'où la prédiction \(\|Xh\|^2/n \leq 9\lambda^2 s/\kappa^2\), et retour à (b) pour la norme \(\ell_1\) complète : \(\|h\|_1 \leq 4\|h_S\|_1 \leq 12\lambda s/\kappa^2\).
Vitesse « rapide » \(s\log p/n\) : le Lasso estime aussi bien que si le vrai support \(S\) était connu, au logarithme près. Chiffres (\(n = 100\), \(p = 1000\), \(s = 5\), \(\sigma = 1\)) : \(s\log(2p)/n \approx 0{,}38\) ; moindres carrés ordinaires : non définis (\(p > n\)) ; régression sur le vrai support : \(s/n = 0{,}05\) — le surcoût logarithmique est le prix de la recherche parmi \(\binom{1000}{5} \approx 8{,}3\times10^{12}\) supports possibles.
Au-delà de la prédiction : sélection et inférence L'inégalité oracle contrôle la prédiction ; la sélection de variables exige plus : borne en norme sup \(\|\hat\beta - \beta^\star\|_\infty \lesssim \sigma\sqrt{\log p/n}\) et « concentration des signes » (récupération exacte du support sous \(\beta_{\min}\)-condition) — exactement les résultats de Lounici 2008, voir ch. 10 ; pour l'inférence (p-values, bandes de confiance) en grande dimension : débiaisage, et les résultats du ch. 10 sur le group Lasso. En pratique : le \(\lambda\) théorique est un point de départ ; la calibration passe par validation croisée (ch. 9, code ci-dessous). 
import numpy as np
from sklearn.linear_model import Lasso, LassoCV
rng = np.random.default_rng(20)

n, p, s, sigma = 100, 1000, 5, 1.0
X = rng.normal(size=(n, p)) / np.sqrt(n)          # colonnes normalisees
beta = np.zeros(p); beta[:s] = rng.choice([-1,1], s) * 1.5
y = X @ beta + sigma * rng.standard_normal(n)

lam_theo = 2*sigma*np.sqrt(2*np.log(2*p)/n)        # prop. 8.2
lasso = Lasso(alpha=lam_theo/2).fit(X, y)          # sklearn penalise 1/(2n)
support = np.flatnonzero(lasso.coef_)
print(f"lambda theo {lam_theo:.3f}  support {support} (vrai [:5])")

cv = LassoCV(cv=5, n_alphas=60).fit(X, y)         # calibration empirique
err = np.linalg.norm(X @ cv.coef_ - X @ beta)**2 / n
print(f"lambda CV {cv.alpha_:.3f}  erreur prediction {err:.3f}"
      f"  (oracle s/n = {s/n:.3f})")
