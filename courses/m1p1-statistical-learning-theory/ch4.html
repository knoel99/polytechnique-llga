4. Bornes de généralisation VC

Théorème 4.1 — Inégalité de Vapnik-Chervonenkis (énoncé, preuve esquissée) Soit \(\mathcal{H}\) de dimension VC \(d \geq 1\), pertes dans \([0,1]\). Avec probabilité au moins \(1 - \delta\), simultanément pour tout \(h \in \mathcal{H}\) : $$\big|L(h) - \hat L(h)\big| \;\leq\; \varepsilon_n(\delta) = \sqrt{\frac{32}{n}\Big(d\,\log\frac{2en}{d} + \log\frac{4}{\delta}\Big)}.$$
Esquisse (double échantillon). Les constantes ne sont pas optimales ; la structure est ce qui compte.
  • Étape 1 — symétrisation : on introduit un échantillon fantôme \(D'_n\) i.i.d. de même loi. Sur l'événement de déviation \(\{L - \hat L \geq \varepsilon\}\), la version fantôme \(\hat L'\) est à distance \(\geq \varepsilon/2\) de \(\hat L\) avec probabilité \(\geq 1 - e^{-n\varepsilon^2/8}\) : pour \(n\varepsilon^2\) grand, contrôler \(L - \hat L\) revient à contrôler \(\hat L' - \hat L\) — deux quantités empiriques, donc ne dépendant des lois que par les \(2n\) points tirés ;
  • Étape 2 — réduction combinatoire : conditionnellement aux \(2n\) points, \(\hat L' - \hat L\) est une moyenne de variables de Bernoulli (chaque donnée fantôme est un tirage uniforme parmi les \(2n\) points) ; le supremum sur \(\mathcal{H}\) ne porte plus que sur les \(\Pi_{\mathcal{H}}(2n) \leq (2en/d)^d\) dichotomies réalisables ; concentration binomiale (Hoeffding, thm 2.3) puis union bound (prop. 0.1) sur ces dichotomies ;
  • Étape 3 — assemblage : en choisissant les seuils pour que les trois probabilités d'échec (symétrisation, binomiale, union) se somment en \(\delta\), on inverse \(\varepsilon\) et l'on obtient la borne annoncée (forme classique de Vapnik-Chervonenkis 1974 ; voir Devroye, Györfi et Lugosi, A Probabilistic Theory of Pattern Recognition, théorème 12.5, pour les détails).
∎
Corollaire 4.2 — Borne de risque pour ERM Combinant prop. 1.2 et thm 4.1 : avec probabilité \(1 - \delta\), $$L(\hat h) \;\leq\; \hat L(\hat h) + 2\,\varepsilon_n(\delta) \;\leq\; L(h^\star_\mathcal{H}) + 4\,\varepsilon_n(\delta).$$ Conséquences : (i) toute classe de dimension VC finie est universellement cohérente (déf. 1.3) ; (ii) le coût d'échantillon pour garantir un excès de risque \(\varepsilon\) est \(n = \tilde{\mathcal{O}}(d/\varepsilon^2)\) (à logarithmes près) ; (iii) il suffit que \(d \ll n\) — et non \(p \ll n\) — pour apprendre : c'est la première apparition du « curse » inversé de la grande dimension.
Exemple 4.3 — Lecture chiffrée (honnêteté des constantes) Avec \(\delta = 0{,}05\), \(\varepsilon_n = \sqrt{32\,(d\log(2en/d) + \log 80)/n}\) :

Les constantes classiques rendent la borne non informative aux petites tailles d'échantillon (à \(n = 10^3\), elle dépasse 1 dès \(d = 10\) ; à \(n = 10^4\) dès \(d = 50\)) : le théorème est un théorème de vitesse (\(\varepsilon_n \sim \sqrt{d/n}\)), pas un outil de calibration pratique — rôle dévolu à la validation croisée (ch. 9 ; module Machine Learning, chapitre 9). Les versions modernes (Rademacher, ch. 5) resserreront les constantes et le logarithme.
Théorème 4.4 — « No free lunch » (énoncé) Pour toute règle d'apprentissage \(h_n\), il existe une loi \(\mathbb{P}\) sur \(\mathcal{X} \times \{0,1\}\) avec \(L^\star = 0\) (données séparables !) telle que \(\mathbb{E}[L(h_n)] \geq 1/8\) dès que \(n \leq d/2\), où \(d\) est la taille d'un ensemble pulvérisé par la classe utilisée. Sans restriction de classe (ou sans hypothèse de régularité), l'apprentissage sur toutes les lois est impossible : la dimension VC (ou toute mesure de complexité) est la monnaie avec laquelle on paie la généralisation. Preuve par un argument de comptage sur les \(2^{2n}\) étiquetages cohérents (voir Shalev-Shwartz et Ben-David, chapitre 5).
