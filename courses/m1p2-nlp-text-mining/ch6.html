6. Séquences : NER, HMM, CRF

Définition 6.1 — Étiquetage de séquences Attribuer à chaque token une étiquette : POS (catégorie grammaticale) ou NER (entités nommées : PER, ORG, LOC…) en BIO (« Begin/Inside/Outside ») : « Kim » = B-PER, « Noel » = I-PER. Le NER est la porte d'entrée de la construction de graphes de connaissances (extraction d'entités + relations).
HMM : forward, backward, Viterbi — les récurrences démontrées HMM : états cachés \(z_t\) (étiquettes), émissions \(\mathbb{P}(w_t\mid z_t)\), transitions \(\mathbb{P}(z_t\mid z_{t-1})\). Notations : \(\alpha_t(z)=\mathbb{P}(w_1,\dots,w_t,\,z_t=z)\) (forward) et \(\beta_t(z)=\mathbb{P}(w_{t+1},\dots,w_T\mid z_t=z)\) (backward) : $$\alpha_t(z)=\mathbb{P}(w_t\mid z)\sum_{z'}\alpha_{t-1}(z')\,\mathbb{P}(z\mid z'), \qquad \beta_t(z)=\sum_{z'}\mathbb{P}(z'\mid z)\,\mathbb{P}(w_{t+1}\mid z')\,\beta_{t+1}(z').$$
Forward : conditionner sur \(z_{t-1}\). \(\alpha_t(z)=\sum_{z'}\mathbb{P}(w_{1:t},z_{t-1}=z',z_t=z) =\sum_{z'}\underbrace{\mathbb{P}(w_{1:t-1},z_{t-1}=z')}_{\alpha_{t-1}(z')} \,\mathbb{P}(z\mid z')\,\mathbb{P}(w_t\mid z)\) — markovien : le passé ne dépend que de \(z_t\). Backward : symétrique en conditionnant sur \(z_{t+1}\). Usages : vraisemblance \(\mathbb{P}(w_{1:T})=\sum_z \alpha_T(z)\) ; posteriors marginaux \(\mathbb{P}(z_t\mid w)=\alpha_t(z)\beta_t(z)/\mathbb{P}(w)\) — c'est l'E-step d'un EM pour entraîner l'HMM (module ML). Tout en \(\mathcal{O}(T K^2)\). ∎
Algorithme 6.2 — Viterbi : optimalité par sous-structure Le chemin d'étiquettes le plus vraisemblable satisfait la récurrence $$\delta_t(z) = \max_{z'} \big[\delta_{t-1}(z')\, \mathbb{P}(z \mid z')\big]\ \mathbb{P}(w_t \mid z),\qquad \delta_0(z)=\mathbb{P}(z)\mathbb{P}(w_1\mid z),$$ et l'étiquetage optimal se relit en remontant les argmax — \(\mathcal{O}(T K^2)\) au lieu de \(\mathcal{O}(K^T)\).
Optimalité : tout chemin optimal arrivant en \((t,z)\) a un préfixe optimal jusqu'à \((t-1,z')\) — sinon remplacer le préfixe par un meilleur augmente la probabilité totale (argument d'échange : les facteurs futurs ne dépendent que de \(z\), markovien). Donc il suffit de suivre le meilleur prédécesseur : c'est Bellman (module RL, ch. 2) sur une chaîne de Markov, avec max au lieu d'espérance. ∎
CRF (Lafferty et al., 2001) : le discriminatif HMM modélise conjointement \(\mathbb{P}(w,z)\) (génératif) ; la CRF modèle directement \(\mathbb{P}(z\mid w)\) : $$\mathbb{P}(z\mid w)=\frac{\exp\big(\sum_{t}\theta^\top f(z_{t-1},z_t,w,t)\big)}{Z(w)}, \qquad \nabla_\theta \log\mathbb{P} = \mathbb{E}_{p(z\mid w)}[f]-f(z^\star)$$ — features arbitraires sur toute la séquence : identité du mot, suffixes, majuscule, forme du voisin, tiret, position…, plus des features de transition \(z_{t-1}\to z_t\) (qui interdisent O→I-PER : un début d'entité doit être B). Inférence : forward-backward pour \(Z(w)\) et l'espérance des features ; Viterbi pour la prédiction. Le gain sur HMM : pas de « gaspillage » à modéliser les mots, features riches, interactions arbitraires — longtemps l'état de l'art NER (CoNLL-2003).
Décodage BIO et évaluation NER au niveau entité Les prédictions par token doivent être converties en spans : une entité = séquence B-X (I-X)*. Évaluation entité (pas token) : une entité est correcte ssi type et bornes exactes ; $$\mathrm{P}=\frac{\#\text{correctes}}{\#\text{prédites}},\qquad \mathrm{R}=\frac{\#\text{correctes}}{\#\text{réelles}},\qquad F_1=\frac{2PR}{P+R}.$$ Le F1 token (indulgent sur les bornes) surestime toujours le F1 entité — toujours rapporter le F1 entité (standard conlleval). Réflexe industriel : auditer les erreurs de bornes (« Banque de France » tronqué) séparément des erreurs de type (PER vs ORG).
Aujourd'hui Les transformers étiquettent token par token (per-token softmax + décodage BIO ; la tête est souvent une linear-chain CRF ou un simple softmax avec contraintes BIO en post-traitement) ; les librairies spaCy et transformers (pipeline ner) donnent l'état de l'art en quelques lignes ; le TP construit un extracteur entités-relations qui alimente le mini-GraphRAG du module Graph ML — ch. 8 du présent cours pour le pipeline complet. 
# Viterbi jouet : POS tagging a 2 etats (N nom, V verbe), vocabulaire de 4 mots
import numpy as np
W = ["le", "chat", "mange", "souris"]
p_z0  = np.array([.9, .1])                      # P(z1)
A     = np.array([[.8,.2],[.3,.7]])             # P(z_t | z_{t-1})  lignes=prec
B     = np.array([[.6,.3,.02,.08],
                  [.0,.02,.9,.08]])             # P(w | z)  colonnes=mots
seq   = [0,1,2,3]                               # "le chat mange souris"

delta = B[:, seq[0]] * p_z0                     # initialisation
back  = []
for w in seq[1:]:
    m = delta[:, None] * A * B[:, w][None, :]   # (prec, cur)
    back.append(m.argmax(0)); delta = m.max(0)
z = [delta.argmax()]
for bp in reversed(back): z.append(bp[z[-1]])
print("etiquettes :", [["N","V"][i] for i in reversed(z)])
