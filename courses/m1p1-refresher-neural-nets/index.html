1. Re-reading your MNIST MLP — what already works

Assumed starting point : a fully connected network trained on flattened 28×28 digits in NumPy, in the spirit of MNIST_from_scratch.ipynb. We do not rewrite the notebook ; we read it like an engineer.

1.1. The model in one line

For an image x \in \mathbb{R}^{784} and classes y \in \{0,\dots,9\} :

z^{(1)} = W^{(1)} x + b^{(1)}, \quad h = \sigma\!\big(z^{(1)}\big), \quad z^{(2)} = W^{(2)} h + b^{(2)}, \quad \hat p = \mathrm{softmax}(z^{(2)}).

Definition 1.1 — Multilayer perceptron (MLP) An MLP of depth L composes affine maps and elementwise activations : h^{(\ell)} = \sigma\!\big(W^{(\ell)} h^{(\ell-1)} + b^{(\ell)}\big), with h^{(0)}=x. The last layer is often linear + softmax (classification) or linear (regression).

  • Vectorized forward : batches (B, 784).
  • A cost : cross-entropy (often via log-softmax for stability).
  • An update rule : SGD on mini-batches.
  • An empirical check : ~97%+ test accuracy on MNIST is enough to trust that gradients “work”.

Quick diagnostic If your MLP stalls around ~10% (chance on 10 classes) : absurd learning rate, softmax/numerics, or mis-encoded labels. If it reaches ~90% train and ~70% test : capacity is OK, revisit regularization / data. If it reaches 99% train and test on MNIST : the benchmark is too easy to judge generalization — hence Fashion-MNIST or CIFAR later in Deep Learning.

import numpy as np

def softmax(z):
    z = z - z.max(axis=1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

def forward(x, W1, b1, W2, b2, kind="relu"):
    z1 = x @ W1 + b1
    h = np.maximum(z1, 0.0) if kind == "relu" else 1.0 / (1.0 + np.exp(-z1))
    logits = h @ W2 + b2
    return softmax(logits), h, z1

2. Forward, loss, training loop — what breaks

Definition 2.1 — Empirical risk \hat{\mathcal{R}}(\theta) = \frac1n \sum_{i=1}^n \ell\big(f_\theta(x_i), y_i\big). Training minimizes \hat{\mathcal{R}} (often on mini-batches). Generalization concerns the true risk — hence train/val/test.

Softmax + cross-entropy yields the convenient logit gradient \hat p - y.

  1. Learning rate too large : NaNs. Too small : flat plateau.
  2. Sigmoid saturation : vanishing gradients in early layers.
  3. Extreme batch size : noise vs oversmoothing.
  4. Test leakage : always keep a separate validation set.

Experiment 2.2 (a) \eta=3 for 5 epochs. (b) \eta=10^{-3}. (c) Swap ReLU for sigmoid without retuning. Write three sentences on what broke (link to ch. 4).

3. Gradients and backpropagation, without magic

Proposition 3.1 — Chain rule on a graph \frac{\partial\mathcal{L}}{\partial z} = \frac{\partial\mathcal{L}}{\partial h}\cdot \phi'(z), \qquad \nabla_W \mathcal{L} = (\nabla_z \mathcal{L})\, h^\top.

With \delta^{(2)}=\hat p-y, backprop pushes deltas toward the input via W^\top and activation derivatives — the same “backward” as your from-scratch notebook.

delta2 = (p - y_onehot) / B
dW2 = h.T @ delta2
delta1 = (delta2 @ W2.T) * (z1 > 0)
dW1 = x.T @ delta1

Engineer’s doctoral reading The computation graph is a DAG; backprop is reverse-topology VJP. When debugging a transformer you still ask which edge multiplies the gradient by ~0.

4. Activations, initialization, depth

Definition 4.1 — Common activations \mathrm{ReLU}(z)=\max(z,0), \sigma(z)=(1+e^{-z})^{-1}, \tanh(z). ReLU avoids positive saturation ; sigmoid/tanh saturate at \pm\infty.

4.1. Initialization : why the draw matters

If W_{ij} \sim \mathcal{N}(0,1) at large width, pre-activations explode (variance \propto fan-in). Xavier/Glorot (tanh) and He (ReLU) schemes calibrate \mathrm{Var}(W) to keep stable variances on the forward (and roughly on the backward) pass.

rng = np.random.default_rng(0)
# He for ReLU : Var = 2 / fan_in
W1 = rng.normal(0, np.sqrt(2 / 784), size=(784, 128))
W2 = rng.normal(0, np.sqrt(2 / 128), size=(128, 10))

4.2. When depth hurts

Stacking sigmoids carelessly ⇒ vanishing gradients. ReLU helps but introduces “dead” units. Deep Learning will answer with BatchNorm, residual connections, and LayerNorm — here, remember the symptom : \\|\delta^{(\ell)}\\| collapsing toward the input.

5. Optimization in practice (SGD → Adam)

Definition 5.1 — Mini-batch SGD \theta_{t+1} = \theta_t - \eta \nabla_\theta \hat{\mathcal{R}}_{B_t}(\theta_t), where B_t is a mini-batch. Sampling noise can help in non-convex landscapes.

Momentum accumulates a velocity : v \leftarrow \mu v + \nabla, \theta \leftarrow \theta - \eta v. Adam mixes first- and second-order moments with bias correction — a sensible DL default, not an excuse to ignore \eta.

def adam(param, grad, m, v, t, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
    m = beta1 * m + (1 - beta1) * grad
    v = beta2 * v + (1 - beta2) * (grad * grad)
    mhat = m / (1 - beta1 ** t)
    vhat = v / (1 - beta2 ** t)
    param = param - lr * mhat / (np.sqrt(vhat) + eps)
    return param, m, v

Engineer reflexes Log train/val loss and accuracy ; start with \eta too large then divide by 3 ; decay \eta when val stalls ; fix seeds to reproduce a bug. PyTorch is welcome once shapes get painful — a NumPy MLP backward remains the ground-truth exercise.

6. From MLP to a toy transformer — LLM intuition

Goal : not to train an LLM. Only to see that attention is a bilinear combination of vectors, a few NumPy lines, and that a transformer block is attention + MLP — ingredients you already know.

Definition 6.1 — Attention (single head, pedagogical) For queries Q, keys K, values V (matrices T\times d) : \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\Big(\frac{QK^\top}{\sqrt{d}}\Big) V. Each position aggregates other positions’ values with content-dependent weights — message passing on a complete graph of tokens (Graph ML reading).

def attention(Q, K, V):
    # Q,K,V: (T, d)
    d = Q.shape[1]
    scores = (Q @ K.T) / np.sqrt(d)
    weights = softmax(scores[None, :, :])[0]
    return weights @ V, weights

rng = np.random.default_rng(1)
X = rng.normal(size=(4, 8))
Wq, Wk, Wv = (rng.normal(size=(8, 8)) * 0.1 for _ in range(3))
out, w = attention(X @ Wq, X @ Wk, X @ Wv)
print(out.shape, w.round(2))

A transformer block (sketch) : LayerNorm → attention → residual → LayerNorm → position-wise MLP → residual. LLMs stack these blocks and train next-token prediction (cross-entropy, like MNIST but over a vocabulary). Your digits MLP = same loss family ; attention adds routing across positions.

Experiment 6.2 — no GPU Build T=5, d=16. Compute attention weights. Force a key K_2 strongly aligned with Q_0 and check that row 0 of w concentrates on column 2.

Exercises

  1. MNIST shapes. For B=64, H=256, write shapes of x,W^{(1)},z^{(1)},h,W^{(2)},\hat p and FLOPs order of magnitude.

    Dominant cost \approx 1.3\cdot10^7 mul-adds per forward.

  2. Softmax-CE gradient. Show \nabla_z \ell = p-y and check with finite differences.

    Direct differentiation yields p-y.

  3. Saturation. Bad Gaussian init + sigmoid; then fix with He/ReLU.

    Large variance saturates units; proper init restores learning.

  4. Hand backprop. Scalar net y=\sigma(w_2\sigma(w_1 x)), squared loss; compute \partial\mathcal{L}/\partial w_1 at x=1,t=0,w_1=w_2=1.

    Chain \sigma' factors; numerical value ~0.03.

  5. Adam vs SGD. Compare 2–3 epochs on your MLP at fixed seed.

    Well-tuned SGD often suffices on small MNIST MLPs; protocol matters more than a winner.

  6. Toy attention. Implement attention; add a causal mask; check lower-triangular weights.

    Set scores[i,j]=-1e9 for j>i before softmax.

  7. Graph ML bridge. Half a page : attention as message passing on the complete token graph vs 1-hop GCN.

    Attention uses content-dependent weights on all pairs; GCN restricts to structural neighbors.

  8. (Optional PyTorch) Match NumPy backward grads to autograd within 10^{-5}.

    Copy weights to tensors with requires_grad and compare.
