4. Cartographies fonctionnelles

Théorème/Concept 4.1 — Functional Maps (Ovsjanikov et al., 2012) Au lieu de chercher la correspondance point-à-point (application discrète combinatoire, coûteuse), transporter des fonctions définies sur les surfaces : $$T_F : \mathcal{F}(M) \to \mathcal{F}(N), \qquad T_F(g) = g \circ T^{-1}$$ Restreinte aux bases spectrales \(\Phi_M, \Phi_N\) (les \(k\) premières fonctions propres), la carte devient une petite matrice \(C \in \mathbb{R}^{k \times k}\) : $$b_N \approx C\, b_M \quad (b = \Phi^\top f).$$ Une correspondance de \(10^5\) points est remplacée par \(k^2\) nombres (\(k \sim 30\)) : c'est le changement de paradigme du domaine.
Contraintes 4.2 — ce que C doit satisfaire
  • Préservation de descripteurs : si \(D_M \in \mathbb{R}^{k \times q}\) sont les coefficients de \(q\) descripteurs (HKS, WKS...) sur \(M\) et \(D_N\) sur \(N\) (dans le même ordre) : $$C\,D_M \approx D_N \qquad (k \times q \text{ équations}) ;$$
  • Commutation avec les opérateurs : $$C\,\Lambda_M \approx \Lambda_N\,C$$ (régularisation spectrale — l'objet de la démonstration ci-dessous) ;
  • Orthogonalité : si l'on croit en une isométrie, \(C^\top C \approx I\) (préserve les produits scalaires de fonctions ; suit de \(\Phi_N^\top C = \Phi_M^\top\) pour bases orthonormées) ;
  • Couplage de correspondances : si quelques paires de points sont connues, \(\Phi_N^\top \Pi^\top \Phi_M \approx C\) avec \(\Pi\) la matrice de permutation (contrainte dure vs moindres carrés).
Commutation : démontrée. Supposons \(T : M \to N\) isométrie et notons \(T_F\) le transport de fonctions. Le théorème d'invariance du ch. 2 (démonstration complète en 2.5) dit : \(\Delta_M(f \circ T) = (\Delta_N f)\circ T\), autrement dit $$\Delta_M \, T_F = T_F\, \Delta_N \quad\text{(après identification des sens)}.$$ Appliquons à \(f = \phi_k^N\) (fonction propre de \(N\), \(\Delta_N\phi_k^N = -\lambda_k^N\phi_k^N\)) : \(\Delta_M\,T_F\phi_k^N = T_F(-\lambda_k^N\phi_k^N) = -\lambda_k^N\,T_F\phi_k^N\) : le transport d'une fonction propre est fonction propre de la même valeur propre. Si le spectre est simple, \(T_F\phi_k^N = \pm\phi_k^M\) ; en base propre, la matrice de \(T_F\) est donc quasi diagonale : \(C_{ij} \ne 0\) seulement si \(\lambda_i^M\) et \(\lambda_j^N\) coïncident — d'où la contrainte \(C\Lambda_M \approx \Lambda_N C\) (faible : au sens des moindres carrés, car les surfaces réelles ne sont qu'approximativement isométriques et les valeurs propres multiples créent des blocs). ∎
Résolution 4.3 — moindres carrés et équations normales $$C^* = \arg\min_C\ \big\|C D_M - D_N\big\|_F^2 + \alpha\big\|C\Lambda_M - \Lambda_N C\big\|_F^2 + \beta\big\|C^\top C - I\big\|_F^2 + \mu\|C\|_F^2.$$ Sans le terme d'orthogonalité, chaque ligne \(c_i\) de \(C\) se résout indépendamment par équations normales : $$c_i = \big(D_M D_M^\top + \alpha\,\Omega + \mu I\big)^{-1} D_M d_i^{\;N\top},$$ avec \(\Omega\) la matrice de régularisation dérivée de la commutation — un système linéaire \(k \times k\) résolu en quelques millisecondes. Avec orthogonalité, on projette sur les rotations (SVD : \(C \leftarrow UV^\top\) — projection de Procruste).
Conversion en correspondance point-à-point + raffinement Correspondance douce : $$P = \Phi_N\, C\, \Phi_M^\top \in \mathbb{R}^{|V_N| \times |V_M|}, \qquad \Pi(x) = \arg\max_y P_{yx}$$ — la matrice \(P\) (peu dense, produit de trois matrices longues) encode la « probabilité » que \(y\) corresponde à \(x\). Raffinement (l'esprit ZoomOut, ch. 8) : itérativement, (1) augmenter \(k\) d'un cran ; (2) recalculer \(C\) en utilisant la correspondance dure courante comme contrainte de couplage ; (3) re-déduire \(P\). La résolution spectrale croissante agit comme un recuit : les grandes structures se fixent à petit \(k\) (régularisation forte), les détails s'ajustent ensuite — algorithme : 
C = least_squares(k=k0, descripteurs)          # demarrage grossier
for k in range(k0, kmax, pas):
    Pi = argmax_par_colonne(Phi_N[k] @ C @ Phi_M[k].T)   # dur
    C = resoudre(constraintes + couplage(Pi), dim=k)     # doux
return Pi                                          # correspondance finale
  • Maps partielles : quand seule une partie de \(M\) correspond à \(N\), \(T_F\) devient une restriction ; la matrice \(C\) est alors rectangulaire (ou l'on plonge \(M\) dans \(N\) via un opérateur de prolongement) ; les contraintes s'adaptent (descripteurs uniquement sur la partie visible) ;
  • Extensions apprises : les descripteurs \(D\) peuvent être produits par un réseau (SpectralNet, puis GeomFMaps — deep geometric functional maps) : le réseau apprend des descripteurs optimaux pour la matrice C, la résolution restant un moindres carrés différentiable ; le graphe de calcul complet (réseau → C → loss de correspondance) s'entraîne bout en bout ;
  • Supervisé vs non-supervisé : avec des paires annotées (FAUST), on supervise directement l'erreur géodésique de \(\Pi\) ; sinon, on maximise l'orthogonalité et la préservation (HKS des deux côtés) : le non-supervisé marche bien pour les quasi-isométries (humains) ;
  • Applications : texture transfer : la texture (fonction couleur !) sur \(M\) est transportée par \(b_N = C\,b_M\) — une multiplication matricielle ; transfer de poses (les coordonnées de correspondance), morphing ;
  • Lien LLGA : une functional map ≈ un transport optimal entre bases réduites ; l'alignement de formes ≈ l'alignement de graphes par Gromov-Wasserstein (module OT, ch. 5) ; les trois langages — GNN, OT, functional maps — décrivent la même opération de correspondance structurelle.
