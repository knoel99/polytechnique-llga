9. Applications et passerelles LLGA

  • Molécules 3D : une molécule est un nuage équivariant (EGNN, ch. 7) — prédiction de conformères (les géométries d'équilibre minimisent l'énergie ; la génération par diffusion équivariante rejoint le module Multimodal GenAI, ch. 7) ; propriétés (solvabilité, toxicité) par descripteurs géométriques (HKS/WKS moléculaires) ;
  • Protéines : interfaces de liaison = correspondance de surfaces moléculaires (complémentarité de forme — functional maps partielles) ; docking ; la géométrie rencontre le pipeline molécules-graphes du master (Graph ML) ;
  • Industrie : CAO/mesh retrieval, scan 3D (reverse engineering : Poisson reconstruction du ch. 5), contrôle qualité par comparaison aux tolérances, dentaire/orthopédie (couronnes = formes quasi-isométriques) ; autonomes (lidars = nuages → PointNet++/DGCNN) ; AR/VR : avatars (correspondance corps humain — FAUST en production), compression de maillages (coordonnées spectrales) ;
  • Génération de formes : diffusion sur point clouds et maillages (bruiter/débruiter des positions et connectivités — exactement le DDPM du module Multimodal GenAI, ch. 3, dans \(\mathbb{R}^{3n}\) avec équivariance) ; l'avenir « shape-GPT » : tokens de surfaces ;
  • Passerelle 1 — graphes : un maillage est un graphe ; les opérateurs (laplacien, diffusion, eigendecomposition) sont partagés avec Graph ML/Advanced GNN ;
  • Passerelle 2 — OT : correspondance de formes ≈ transport ; Gromov-Wasserstein compare des métriques intrinsèques (OT ch. 5) ;
  • Passerelle 3 — LLM : les LLMs multimodaux commencent à « voir » des objets ; les tokens 3D (patches de surfaces) rejoignent les tokens d'images ; un « shape-GPT » générant de la géométrie ? — sujet de projet transverse.
