3. Learning : TD, SARSA, Q-learning (modèle inconnu)

En pratique on ne connaît ni \(P\) ni \(r\) : on interagit. Le temporal-difference learning apprend en corrigeant chaque prédiction vers l'observation :

Algorithme 3.1 — TD(0), SARSA, Q-learning
  • TD(0) (évaluation) : \(V(S_t) \leftarrow V(S_t) + \alpha\big[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\big]\) ; le bracket est l'erreur TD \(\delta_t\).
  • SARSA (on-policy) : \(Q(S_t, A_t) \leftarrow Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t,A_t)\big]\).
  • Q-learning (off-policy) : $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\Big[R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t)\Big].$$
Théorème 3.2 — Convergence du TD(0) et du Q-learning (esquisse via Robbins-Monro) Sous exploration suffisante (chaque paire \((s,a)\) visitée infiniment souvent) et pas \(\alpha_t(s,a) \in (0,1)\) avec \(\sum_t \alpha_t = \infty\), \(\sum_t \alpha_t^2 < \infty\) : \(V_t \to V^\pi\) (TD(0), Tsitsiklis 1994) et \(Q_t \to Q^\star\) (Q-learning, Watkins & Dayan 1992) presque sûrement.
TD(0) est une récursion de Robbins-Monro. La mise à jour s'écrit \(V(s) \leftarrow V(s) + \alpha\,\delta_t\) avec \(\delta_t = r + \gamma V(S') - V(s)\). À l'état \((S_t, S_{t+1})\) fixé, l'espérance de \(\delta_t\) sachant \(V\) vaut \(r(S_t) + \gamma \sum_{s'} P^\pi(s'|S_t) V(s') - V(S_t) = (T_\pi V - V)(S_t)\) — l'erreur TD est un bruit non biaisé autour du résidu de Bellman. L'équation cible est donc \(h(V) = T_\pi V - V = 0\), dont l'unique zéro est \(V^\pi\) (théorème 1.5). Le reste vérifie les hypothèses du théorème 0.5 : la contraction de \(T_\pi\) (module \(\gamma\)) fournit la monotonie \((V - V^\pi)^\top (T_\pi V - V) \leq -(1-\gamma)\|V - V^\pi\|^2_2\)... on normalise par la fréquence de visite de \(s\), et le théorème 0.4 (Robbins-Siegmund) conclut. Q-learning : même schéma avec deux ingrédients en plus. (i) l'opérateur \(\mathcal{T}\) (avec max) reste une contraction de module \(\gamma\) (théorème 1.6) ; (ii) le max introduit un biais conditionnellement à l'échantillon, mais pas à l'asymptote : à la limite, l'argmax est stable et l'itération converge vers l'unique point fixe \(Q^\star\). D'où le résultat : Q-learning converge quelle que soit la politique d'exploration (tant qu'elle visite tout) — c'est la propriété off-policy. ∎
Définition 3.3 — Retours à n pas et traces d'éligibilité Le retour à \(n\) pas mélange bootstrap et Monte-Carlo : $$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^{n} V(S_{t+n}).$$ TD(\(\lambda\)), vue « avant » (forward view) : moyenner géométriquement les retours à \(n\) pas : $$G_t^\lambda = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_t^{(n)}.$$ Vue « arrière » (backward view), implémentable en ligne avec une trace d'éligibilité par état : $$e_t(s) = \gamma \lambda\, e_{t-1}(s) + \mathbb{1}[S_t = s], \qquad V_{t+1}(s) = V_t(s) + \alpha\, \delta_t\, e_t(s) \quad \forall s.$$ La trace accumule les états « responsables » du reward courant et s'évanouit en \((\gamma\lambda)^k\). Théorème d'équivalence (Sutton & Barto, ch. 12) : pour l'évaluation tabulaire avec pas fixes, les deux vues réalisent la même mise à jour cumulée sur un épisode — équivalence énoncée ici sans preuve.
Proposition 3.4 — GAE : dérivation de l'estimateur d'avantage généralisé Posons l'erreur TD pour le critique \(V\) : \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\). Alors :
Étape 1 (télescopage). Par récurrence immédiate, $$G_t^{(n)} - V(S_t) = \sum_{l=0}^{n-1} \gamma^l\, \delta_{t+l} \qquad (\text{avantage à } n \text{ pas, } A_t^{(n)}).$$ Étape 2 (mélange géométrique). L'estimateur GAE est la combinaison \((1-\lambda)\sum_n \lambda^{n-1} A_t^{(n)}\) — le même que TD(\(\lambda\)) — et le télescopage se propage à la somme : $$\hat A_t^{\mathrm{GAE}(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l\, \delta_{t+l}.$$ Lecture biais-variance. \(\lambda = 0\) donne \(\hat A_t = \delta_t\) : un pas de bootstrap, fort biais (si \(V\) est mauvais), faible variance. \(\lambda = 1\) donne \(\hat A_t = G_t - V(S_t)\) : Monte-Carlo, sans biais de bootstrap, variance maximale. GAE permet de se placer entre les deux — c'est l'estimateur standard des algorithmes des chapitres 4 et 5 (Schulman et al., 2016). ∎
Théorème 3.5 — Surestimation du Q-learning : le biais du max, démontré Pour toutes variables aléatoires réelles \(X, Y\) d'espérances finies : $$\mathbb{E}[\max(X, Y)] \;\geq\; \max\big(\mathbb{E}[X], \mathbb{E}[Y]\big),$$ avec inégalité stricte dès que \(X \neq Y\) avec probabilité positive.
On écrit \(\max(x,y) = \tfrac12\big(x + y + |x - y|\big)\). La fonction \((x,y) \mapsto |x - y|\) est convexe, donc par Jensen \(\mathbb{E}|X - Y| \geq |\mathbb{E}X - \mathbb{E}Y|\). D'où : $$\mathbb{E}[\max(X,Y)] = \tfrac12\big(\mathbb{E}X + \mathbb{E}Y + \mathbb{E}|X-Y|\big) \geq \tfrac12\big(\mathbb{E}X + \mathbb{E}Y + |\mathbb{E}X - \mathbb{E}Y|\big) = \max(\mathbb{E}X, \mathbb{E}Y),$$ stricte si \(\mathbb{E}|X-Y| > |\mathbb{E}X - \mathbb{E}Y|\), i.e. si \(X - Y\) n'est pas p.s. constant. De plus \(\mathbb{E}[\max(X,Y)] \leq \max(\mathbb{E}X, \mathbb{E}Y) + \tfrac12\sqrt{\mathbb{E}[(X - Y)^2]}\) : le biais croît avec le bruit. ∎
Application : la cible du Q-learning, \(y = r + \gamma \max_{a'} Q(s', a')\), prend l'espérance d'un max de \(Q\)-valeurs bruitées (réseau, échantillonnage) : le max sélectionne préférentiellement les surestimations, et le bootstrap propage le biais — d'où des valeurs systématiquement optimistes et des politiques surexcitées.
Algorithme 3.6 — Double Q-learning : la correction Entretenir deux estimateurs indépendants \(Q_A, Q_B\) (chacun mis à jour sur la moitié des transitions, ou permutés aléatoirement), et découpler sélection et évaluation : $$a^\star = \arg\max_a Q_A(s', a), \qquad y = r + \gamma\, Q_B(s', a^\star), \qquad Q_A(s,a) \leftarrow Q_A(s,a) + \alpha\big[y - Q_A(s,a)\big]$$ (et symétriquement en échangeant \(A \leftrightarrow B\)). Puisque \(\mathbb{E}[Q_B(s', a^\star)]\) est prise sans max sur le bruit de \(Q_B\), le biais positif du théorème 3.5 disparaît (l'argmax reste calculé sur \(Q_A\), mais l'évaluation ne « choisit plus le bruit qui l'arrange »). C'est la version tabulaire de van Hasselt (2010) ; la version deep (Double DQN, chapitre 5) utilise réseau courant et réseau cible comme les deux estimateurs.
Exploration : politique \(\varepsilon\)-gloutonne Avec probabilité \(\varepsilon\) : action aléatoire ; sinon \(\arg\max_a Q(s, a)\). Sans exploration, le signal d'apprentissage s'éteint ; \(\varepsilon\) décroissant est le réglage standard — le chapitre 6 systématise ce choix.
La triade mortelle (deadly triad) Approximation de fonction (réseaux) + bootstrap (cibles TD) + off-policy (Q-learning) : la réunion des trois peut faire diverger l'itération (contre-exemple de Baird, 1995). La preuve de convergence du théorème 3.2 s'effondre dès que l'opérateur n'est plus une contraction dans la classe d'approximation. Tout le chapitre 5 est un art de vivre avec cette triade : replay, réseaux cibles, clipping, double Q.
Q-learning ≠ SARSA en une phrase Q-learning apprend la politique optimale quelle que soit la politique d'exploration (off-policy) ; SARSA évalue la politique effectivement suivie (y compris l'exploration) — plus prudent près des falaises ! (TP classique : Cliff Walking, exercice 4.)
