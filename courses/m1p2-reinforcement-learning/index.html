0. Refresher: Markov chains, martingales, dynamic programming

L3 prerequisites — Markov chains

  • Markov chain: X_{t+1} \sim P(\cdot \mid X_t) — the future depends only on the present. Stochastic transition matrix (rows summing to 1).
  • Stationary distribution: \pi = \pi P; exists and is unique for an irreducible aperiodic chain (Perron-Frobenius theorem).
  • Random walks on graphs: P = D^{-1}A — the random walker; \pi(v) \propto \deg(v); to be connected to PageRank and node embeddings (Graph ML module).
  • Conditional expectation: \mathbb{E}[X \mid Y] (cf. Refresher Statistics module) — the value function is one.

0.1. Classification of states, ergodicity

Definition 0.1 — Irreducibility, aperiodicity, recurrence A chain on \mathcal{S} is irreducible if for all i, j there exists t with P^t(i, j) \> 0 (every state is reachable from every state). It is aperiodic if the gcd of the return times to each state equals 1. A state is positive recurrent if the expected return time \mathbb{E}[T_{i \to i}] is finite. An irreducible, aperiodic, positive recurrent chain is called ergodic.

Theorem 0.2 — Ergodic theorem for Markov chains Let (X_t) be an ergodic chain with stationary distribution \pi. Then, for every bounded function f : \mathcal{S} \to \mathbb{R}, \frac{1}{n} \sum_{t=1}^{n} f(X_t) \;\xrightarrow{\text{a.s.}}\; \sum_{s \in \mathcal{S}} \pi(s)\, f(s), and moreover \\|P^t(i, \cdot) - \pi\\|_{\mathrm{TV}} \to 0 at geometric speed (the rate is given by the second eigenvalue module of P). RL reading: in the long run, the visit frequency of a state does not depend on the initial state — this is what justifies learning “over the course of episodes”.

0.2. Martingales and stochastic approximation

Definition 0.3 — Martingale (M_t) is a martingale adapted to the filtration (\mathcal{F}_t) if \mathbb{E}[M_{t+1} \mid \mathcal{F}_t] = M_t. Martingales model “fair noise”; the TD error of chapter 3 will be almost one.

Theorem 0.4 — Robbins-Siegmund (quasi-martingale convergence) Let V_t \geq 0 be adapted, with \mathbb{E}[V_{t+1} \mid \mathcal{F}_t] \leq V_t + a_t where \sum_t a_t \< \infty. Then V_t converges a.s. to a finite random variable. This is the central tool of the convergence proofs of this course’s algorithms: one shows that the distance to the fixed point decreases “on average”, and one concludes.

Theorem 0.5 — Robbins-Monro (precise statement) Consider the recursion x_{t+1} = x_t + \gamma_{t+1}\big(h(x_t) + \eta_{t+1}\big) where h : \mathbb{R}^d \to \mathbb{R}^d is continuous, x^\star the unique zero of h, and: (i) steps \sum_t \gamma_t = \infty, \sum_t \gamma_t^2 \< \infty; (ii) unbiased noise \mathbb{E}[\eta_{t+1} \mid \mathcal{F}_t] = 0, bounded variance; (iii) (x_t - x^\star)^\top\big(h(x_t)\big) \< 0 as soon as x_t \neq x^\star (monotonicity). Then x_t \to x^\star a.s. This is exactly the regime of TD-learning: h will be the Bellman operator minus the identity, and Theorem 0.4 will provide the decrease.

0.3. Deterministic dynamic programming

Principle of optimality (Bellman, 1957) “An optimal policy has the property that, whatever the initial state and the first decision, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision.” Formally, for a sequential additive cost, the optimal value satisfies a fixed-point equation: V^\star(x) = \min_u\{c(x, u) + V^\star(\mathrm{succ}(x, u))\}. Usage reminders: shortest paths (Bellman-Ford), memoization (Refresher CS), temporal decomposition. The MDP of chapter 1 adds: random transitions (hence expectations) and a maximization (hence \max operators).

1. Markov decision processes

Concrete scene: a pricing agent updates Q(s,a) online. After 10 k episodes the curve rises, then collapses when you change the seed — return variance ×3 across runs. This chapter sets the MDP before any deep trick.

What breaks Misspecified reward (the agent maximises the wrong thing); too little exploration (frozen policy); off-policy training without replay / target network (divergence). All three sabotage RLHF as much as a toy FrozenLake.

Definition 1.1 — MDP An MDP is a tuple (\mathcal{S}, \mathcal{A}, P, r, \gamma): states \mathcal{S}, actions \mathcal{A}, transition kernel P(s' \mid s, a), reward r(s, a, s') (we write r(s,a) for its expectation), discount factor \gamma \in [0, 1). A policy \pi(a \mid s) governs the choice of actions; the objective is the discounted expected return J(\pi) = \mathbb{E}_\pi\Big[\sum_{t=0}^{\infty} \gamma^t R_t\Big]. Fixing a policy \pi in an MDP induces a Markov chain with kernel P^\pi(s' \mid s) = \sum_a \pi(a \mid s) P(s' \mid s, a) — chapter 0 applies literally; \gamma \< 1 guarantees that all the sums converge.

Proposition 1.2 — Stationary deterministic policies It suffices to search among deterministic policies \pi : \mathcal{S} \to \mathcal{A} and stationary ones (not depending on t): for every mixed non-stationary policy, there exists a stationary deterministic policy with at least equal value in every state. (Proof: backward induction on the horizon then \gamma-discounted limiting passage; see Puterman, 2005.) The search space is finite: \|\mathcal{A}\|^{\|\mathcal{S}\|} candidates — too large for enumeration, hence chapters 2 and following.

Definition 1.3 — Value functions V^\pi(s) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big\|\, S_0 = s\Big], \qquad Q^\pi(s, a) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big\|\, S_0 = s, A_0 = a\Big]. V^\pi = “how much the state is worth”; Q^\pi = “how much the state-action pair is worth”. We have V^\pi(s) = \sum_a \pi(a\mid s)\, Q^\pi(s,a) and Q^\pi(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s').

Definition 1.4 — Occupancy measures The occupancy measure of \pi (from \mu_0) is \rho_\pi(s, a) = (1 - \gamma)\sum_{t=0}^{\infty} \gamma^t\, \mathbb{P}_\pi[S_t = s, A_t = a], \qquad \text{so that} \qquad J(\pi) = \frac{1}{1-\gamma}\sum_{s,a} \rho_\pi(s,a)\, r(s,a). \rho_\pi is a probability distribution over \mathcal{S} \times \mathcal{A}; it describes “where the policy lives”. It is the natural bridge toward the LP formulation below and toward the importance ratios of chapter 4 (sampling under \pi, evaluating under \pi').

Theorem 1.5 — Bellman equations (evaluation) Q^\pi(s, a) = r(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s'), \qquad V^\pi(s) = \sum_a \pi(a \mid s)\Big[r(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s')\Big]. This is dynamic programming applied to time: today’s value = immediate gain + discounted value of tomorrow. Writing T_\pi for the operator (T_\pi V)(s) = \sum_a \pi(a\|s)\big[r(s,a) + \gamma \sum_{s'} P(s'\|s,a) V(s')\big], the equation rewrites as V^\pi = T_\pi V^\pi — a linear system of \|\mathcal{S}\| equations ((I - \gamma P^\pi) V = r^\pi, invertible since \gamma \< 1).

Theorem 1.6 — Optimality: existence, uniqueness (complete proof) Consider the optimal Bellman operator (\mathcal{T}V)(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V(s') \Big\}. (1) \mathcal{T} is a contraction of modulus \gamma on (\mathbb{R}^{\|\mathcal{S}\|}, \\|\cdot\\|_\infty) (a complete space). Proof in two lemmas:

Proof. Lemma (max-Lipschitz). For all bounded families (u_a)_a, (v_a)_a: \|\max_a u_a - \max_a v_a\| \leq \max_a \|u_a - v_a\|. Indeed, for every a, u_a \leq v_a + \max_b \|u_b - v_b\|, so \max_a u_a \leq \max_a v_a + \max_b \|u_b - v_b\|; exchanging the roles, \|\max_a u_a - \max_a v_a\| \leq \max_b \|u_b - v_b\|. Contraction. For each s, setting u_a = r(s,a) + \gamma \sum_{s'} P(s'\|s,a) V(s') and v_a the analogue for V': \big\|(\mathcal{T}V)(s) - (\mathcal{T}V')(s)\big\| \leq \max_a \gamma \Big\|\sum_{s'} P(s'\|s,a)\big(V(s') - V'(s')\big)\Big\| \leq \gamma\, \\|V - V'\\|_\infty, since P(\cdot\|s,a) is a probability distribution. Taking the max over s: \\|\mathcal{T}V - \mathcal{T}V'\\|_\infty \leq \gamma \\|V - V'\\|_\infty. (2) Fixed point. By Banach’s fixed-point theorem (L3 reminder: contraction on a complete space), \mathcal{T} admits a unique fixed point V^\star, and \mathcal{T}^k V \to V^\star for every starting V, at geometric speed \gamma^k. We set Q^\star = r + \gamma P V^\star, which satisfies Q^\star(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, \max_{a'} Q^\star(s', a'). (3) Optimal policy. Let \pi^\star be greedy for V^\star: \pi^\star(s) \in \arg\max_a Q^\star(s,a). Then T_{\pi^\star} V^\star = \mathcal{T}V^\star = V^\star, so \\|T_{\pi^\star}^k V^\star - V^\star\\|_\infty \leq \gamma^k \\|T_{\pi^\star} V^\star - V^\star\\|_\infty = 0 for every k; in the limit V^{\pi^\star} = V^\star. Hence \pi^\star attains the supremum \sup_\pi V^\pi in every state: it is an optimal stationary deterministic policy. ∎

Proposition 1.7 — Linear (LP) formulation of MDPs Solving an MDP amounts to solving the (dual) linear program: \max_{\mu \geq 0}\ \sum_{s,a} \mu(s,a)\, r(s,a) \quad \text{s.t.} \quad \sum_a \mu(s', a) \;=\; \nu(s') + \gamma \sum_{s,a} P(s' \mid s, a)\, \mu(s,a) \ \ \forall s', where \nu is the initial distribution. The variables \mu are the occupancy measures = \rho_\pi/(1-\gamma); the constraints are “flow equations” (what enters a state = initial distribution + what leaves it, discounted). An extreme optimal solution of the polytope is attained at a deterministic policy, and \pi^\star(s) = \arg\max_a \mu^\star(s, a). Interest: LPs are solved in polynomial time (but polynomial in \|\mathcal{S}\| \|\mathcal{A}\|, quickly enormous); the dual viewpoint also sheds light on the linear approximation methods for the value. The primal writes \min_V \sum_s \nu(s) V(s) s.t. V(s) \geq r(s,a) + \gamma \sum_{s'} P V for all (s, a) — the constraints are the Bellman inequalities.

Role of \gamma \gamma discounts the future but also conditions the whole theory: contraction of modulus \gamma, error bounds in 1/(1-\gamma) (chapter 2), variance of the returns. When \gamma \to 1, one tends toward the average criterion \lim_T \frac{1}{T}\sum_t R_t — related to the ergodic theorem 0.2 — but all the rates degrade: RL lives with this tension.

2. Dynamic programming (known model)

Theorem 2.1 — Value iteration: convergence demonstrated Repeat until convergence: V_{k+1}(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V_k(s')\Big\} \qquad \text{i.e.} \qquad V_{k+1} = \mathcal{T}V_k.

Proof. For every k (writing V^\star = \mathcal{T}V^\star): \\|V_{k+1} - V^\star\\|_\infty = \\|\mathcal{T}V_k - \mathcal{T}V^\star\\|_\infty \leq \gamma\, \\|V_k - V^\star\\|_\infty \ \Rightarrow\ \\|V_k - V^\star\\|_\infty \leq \gamma^k \\|V_0 - V^\star\\|_\infty. The convergence is geometric with ratio \gamma: each iteration removes a factor \gamma from the error. Exploitable stopping criterion. \\|V_{k+1} - V_k\\|_\infty \leq \varepsilon implies \\|V_k - V^\star\\|_\infty \leq \frac{\gamma\,\varepsilon}{1-\gamma}: to guarantee an error \delta on the value, a residual \varepsilon = \delta(1-\gamma)/\gamma is needed — the factor 1/(1-\gamma) “amplifies” any approximation error. ∎

Theorem 2.2 — Policy iteration: monotone improvement demonstrated Alternate: (i) exact evaluation V^{\pi_k} = T_{\pi_k} V^{\pi_k} (linear system); (ii) greedy improvement \pi_{k+1}(s) \in \arg\max_a r(s,a) + \gamma \sum_{s'} P(s'\|s,a) V^{\pi_k}(s'), that is, \pi_{k+1} greedy for V^{\pi_k}.

Proof. Monotonicity. First T_{\pi_{k+1}} V^{\pi_k} = \mathcal{T}V^{\pi_k} \geq V^{\pi_k} component by component (the max over the actions dominates the action played by \pi_k). Next, T_{\pi_{k+1}} is monotone (U \geq V \Rightarrow T_{\pi} U \geq T_\pi V, by positive linearity of the expectation), so by induction T_{\pi_{k+1}}^{j+1} V^{\pi_k} \geq T_{\pi_{k+1}}^{j} V^{\pi_k} \geq V^{\pi_k}; in the limit V^{\pi_{k+1}} = \lim_j T_{\pi_{k+1}}^j V^{\pi_k} \geq V^{\pi_k}. Finite termination. If V^{\pi_{k+1}} = V^{\pi_k}, then \mathcal{T}V^{\pi_k} = T_{\pi_{k+1}} V^{\pi_k} = V^{\pi_k}: V^{\pi_k} is a fixed point of \mathcal{T}, hence equal to V^\star (uniqueness, Th. 1.6). Since the value increases strictly at every non-terminal iteration and there is a finite number (\|\mathcal{A}\|^{\|\mathcal{S}\|}) of deterministic policies, the algorithm stops after a finite number of iterations on an optimal policy. ∎

Value vs policy iteration — costs and trade-offs Value iteration: cheap iterations (O(\|\mathcal{S}\|^2 \|\mathcal{A}\|)) but very many; policy iteration: few iterations (often < 20) but each one requires solving a linear system (O(\|\mathcal{S}\|^3)). In practice on large \mathcal{S}: neither is exactly tractable — but all of modern RL is a “noisy and approximated” version of these two schemes.

Proposition 2.3 — Modified policy iteration and asynchronous dynamic programming Modified PI (Puterman & Shin, 1978): replace the exact evaluation of \pi_k by m applications of T_{\pi_k} (with m small). m = \infty gives back PI, small m gets closer to VI; one interpolates the cost per iteration and the number of iterations — often the best compromise in practice. Asynchronous DP (Bertsekas & Tsitsiklis): update a freely chosen state s (Gauss-Seidel, partial sweeps, priority to relevant states). Theorem: if every state is visited infinitely often, asynchronous DP converges to V^\star. This is the gateway to RL: the algorithms of chapters 3–5 are “sampled” asynchronous DPs, where the update is made on the state actually visited.

Proposition 2.4 — Propagation of approximation errors Suppose that at every iteration a bounded error sneaks in: \tilde V_{k+1} = \mathcal{T}\tilde V_k + \varepsilon_k, with \\|\varepsilon_k\\|_\infty \leq \varepsilon. Then \\|\tilde V_k - V^\star\\|_\infty \;\leq\; \gamma^k \\|\tilde V_0 - V^\star\\|_\infty \;+\; \frac{\varepsilon}{1-\gamma}.

Proof. By recursion and contraction: \\|\tilde V_{k+1} - V^\star\\| \leq \gamma \\|\tilde V_k - V^\star\\| + \varepsilon, then by telescoping \\|\tilde V_k - V^\star\\| \leq \sum_{i\<k} \gamma^i \varepsilon + \gamma^k \\|\tilde V_0 - V^\star\\| and geometric sum. ∎

Major consequence for deep RL: any approximation error (network, sampling) is multiplied by \frac{1}{1-\gamma}. With \gamma = 0.99, a factor of 100: this is why approximating V or Q is difficult, and why the choice of \gamma is a genuine design choice.

import numpy as np

# 4x4 gridworld: states 0..15, actions 0..3 (up, down, left, right)
S, A, gamma = 16, 4, 0.95
goal = 15
P = np.zeros((S, A, S)); r = -np.ones((S, A))
def step(s, a):
    i, j = divmod(s, 4)
    di, dj = [(-1,0),(1,0),(0,-1),(0,1)][a]
    return 4*min(max(i+di,0),3) + min(max(j+dj,0),3)
for s in range(S):
    for a in range(A):
        s2 = step(s, a)
        P[s, a, s2] = 1.0
        if s2 == goal or s == goal: r[s, a] = 0.0
r[goal] = 0.0

def T_op(V):                      # optimal Bellman operator
    return (r + gamma * (P @ V)).max(axis=1)

# --- Value iteration (th. 2.1) ---
V = np.zeros(S)
for _ in range(200):
    V_new = T_op(V)
    if np.abs(V_new - V).max() < 1e-10: break   # stopping criterion th. 2.1
    V = V_new
Q = r + gamma * (P @ V)
print("VI :", V.reshape(4,4).round(2))

# --- Policy iteration (th. 2.2) ---
pi = np.zeros(S, dtype=int); V = np.zeros(S)
while True:
    # (i) exact evaluation: (I - gamma P^pi) V = r^pi
    R = r[np.arange(S), pi]
    Ppi = P[np.arange(S), pi]
    V = np.linalg.solve(np.eye(S) - gamma * Ppi, R)
    # (ii) greedy improvement
    Q = r + gamma * (P @ V)
    pi_new = Q.argmax(axis=1)
    if (pi_new == pi).all(): break              # stable policy: optimal
    pi = pi_new
print("PI :", V.reshape(4,4).round(2))

3. Learning: TD, SARSA, Q-learning (unknown model)

In practice we know neither P nor r: we interact. Temporal-difference learning learns by correcting each prediction toward the observation:

Algorithm 3.1 — TD(0), SARSA, Q-learning

  • TD(0) (evaluation): V(S_t) \leftarrow V(S_t) + \alpha\big[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\big]; the bracket is the TD error \delta_t.
  • SARSA (on-policy): Q(S_t, A_t) \leftarrow Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t,A_t)\big].
  • Q-learning (off-policy): Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\Big[R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t)\Big].

Theorem 3.2 — Convergence of TD(0) and Q-learning (sketch via Robbins-Monro) Under sufficient exploration (every pair (s,a) visited infinitely often) and steps \alpha_t(s,a) \in (0,1) with \sum_t \alpha_t = \infty, \sum_t \alpha_t^2 \< \infty: V_t \to V^\pi (TD(0), Tsitsiklis 1994) and Q_t \to Q^\star (Q-learning, Watkins & Dayan 1992) almost surely.

Proof. TD(0) is a Robbins-Monro recursion. The update writes V(s) \leftarrow V(s) + \alpha\,\delta_t with \delta_t = r + \gamma V(S') - V(s). With the state (S_t, S_{t+1}) fixed, the expectation of \delta_t given V equals r(S_t) + \gamma \sum_{s'} P^\pi(s'\|S_t) V(s') - V(S_t) = (T_\pi V - V)(S_t) — the TD error is unbiased noise around the Bellman residual. The target equation is therefore h(V) = T_\pi V - V = 0, whose unique zero is V^\pi (Theorem 1.5). The remainder satisfies the hypotheses of Theorem 0.5: the contraction of T_\pi (modulus \gamma) provides the monotonicity (V - V^\pi)^\top (T_\pi V - V) \leq -(1-\gamma)\\|V - V^\pi\\|^2_2… we normalize by the visit frequency of s, and Theorem 0.4 (Robbins-Siegmund) concludes. Q-learning: same scheme with two extra ingredients. (i) the operator \mathcal{T} (with max) remains a contraction of modulus \gamma (Theorem 1.6); (ii) the max introduces a bias conditional on the sample, but not asymptotically: in the limit, the argmax is stable and the iteration converges to the unique fixed point Q^\star. Hence the result: Q-learning converges whatever the exploration policy (as long as it visits everything) — this is the off-policy property. ∎

Definition 3.3 — n-step returns and eligibility traces The n-step return mixes bootstrapping and Monte-Carlo: G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^{n} V(S_{t+n}). TD(\lambda), “forward” view: geometrically average the n-step returns: G_t^\lambda = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_t^{(n)}. “Backward” view, implementable online with one eligibility trace per state: e_t(s) = \gamma \lambda\, e_{t-1}(s) + \mathbb{1}[S_t = s], \qquad V_{t+1}(s) = V_t(s) + \alpha\, \delta_t\, e_t(s) \quad \forall s. The trace accumulates the states “responsible” for the current reward and fades as (\gamma\lambda)^k. Equivalence theorem (Sutton & Barto, ch. 12): for tabular evaluation with fixed steps, the two views realize the same cumulative update over an episode — equivalence stated here without proof.

Proposition 3.4 — GAE: derivation of the generalized advantage estimator Set the TD error for the critic V: \delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t). Then:

Proof. Step 1 (telescoping). By immediate recursion, G_t^{(n)} - V(S_t) = \sum_{l=0}^{n-1} \gamma^l\, \delta_{t+l} \qquad (\text{n-step advantage, } A_t^{(n)}). Step 2 (geometric mixing). The GAE estimator is the combination (1-\lambda)\sum_n \lambda^{n-1} A_t^{(n)} — the same as TD(\lambda) — and the telescoping propagates to the sum: \hat A_t^{\mathrm{GAE}(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l\, \delta_{t+l}. Bias-variance reading. \lambda = 0 gives \hat A_t = \delta_t: one bootstrap step, strong bias (if V is poor), low variance. \lambda = 1 gives \hat A_t = G_t - V(S_t): Monte-Carlo, no bootstrap bias, maximal variance. GAE allows positioning oneself between the two — it is the standard estimator of the algorithms of chapters 4 and 5 (Schulman et al., 2016). ∎

Theorem 3.5 — Q-learning overestimation: the bias of the max, demonstrated For all real random variables X, Y with finite expectations: \mathbb{E}[\max(X, Y)] \;\geq\; \max\big(\mathbb{E}[X], \mathbb{E}[Y]\big), with strict inequality as soon as X \neq Y with positive probability.

Proof. We write \max(x,y) = \tfrac12\big(x + y + \|x - y\|\big). The function (x,y) \mapsto \|x - y\| is convex, so by Jensen \mathbb{E}\|X - Y\| \geq \|\mathbb{E}X - \mathbb{E}Y\|. Hence: \mathbb{E}[\max(X,Y)] = \tfrac12\big(\mathbb{E}X + \mathbb{E}Y + \mathbb{E}\|X-Y\|\big) \geq \tfrac12\big(\mathbb{E}X + \mathbb{E}Y + \|\mathbb{E}X - \mathbb{E}Y\|\big) = \max(\mathbb{E}X, \mathbb{E}Y), strict if \mathbb{E}\|X-Y\| \> \|\mathbb{E}X - \mathbb{E}Y\|, i.e. if X - Y is not a.s. constant. Moreover \mathbb{E}[\max(X,Y)] \leq \max(\mathbb{E}X, \mathbb{E}Y) + \tfrac12\sqrt{\mathbb{E}[(X - Y)^2]}: the bias grows with the noise. ∎

Application: the Q-learning target, y = r + \gamma \max_{a'} Q(s', a'), takes the expectation of a max of noisy Q-values (network, sampling): the max preferentially selects overestimates, and the bootstrap propagates the bias — hence systematically optimistic values and overexcited policies.

Algorithm 3.6 — Double Q-learning: the correction Maintain two independent estimators Q_A, Q_B (each updated on half of the transitions, or randomly swapped), and decouple selection and evaluation: a^\star = \arg\max_a Q_A(s', a), \qquad y = r + \gamma\, Q_B(s', a^\star), \qquad Q_A(s,a) \leftarrow Q_A(s,a) + \alpha\big[y - Q_A(s,a)\big] (and symmetrically by swapping A \leftrightarrow B). Since \mathbb{E}[Q_B(s', a^\star)] is taken without a max over the noise of Q_B, the positive bias of Theorem 3.5 disappears (the argmax is still computed on Q_A, but the evaluation no longer “picks the noise that suits it”). This is the tabular version of van Hasselt (2010); the deep version (Double DQN, chapter 5) uses the current network and the target network as the two estimators.

Exploration: \varepsilon-greedy policy With probability \varepsilon: random action; otherwise \arg\max_a Q(s, a). Without exploration, the learning signal dies out; decreasing \varepsilon is the standard setting — chapter 6 systematizes this choice.

The deadly triad Function approximation (networks) + bootstrapping (TD targets) + off-policy (Q-learning): combining the three can make the iteration diverge (Baird’s counterexample, 1995). The convergence proof of Theorem 3.2 collapses as soon as the operator is no longer a contraction within the approximation class. The whole of chapter 5 is an art of living with this triad: replay, target networks, clipping, double Q.

Q-learning ≠ SARSA in one sentence Q-learning learns the optimal policy whatever the exploration policy (off-policy); SARSA evaluates the policy actually followed (including exploration) — more cautious near cliffs! (Classic lab: Cliff Walking, exercise 4.)

4. Policy gradients and actor-critic

4.1. REINFORCE: the proof step by step

Theorem 4.1 — REINFORCE (Williams, 1992), complete proof Let \pi_\theta be differentiable, \tau = (S_0, A_0, \dots, S_{T}) a trajectory of return G(\tau) = \sum_{t=0}^T \gamma^t R_t, and J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[G(\tau)]. Then \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\Big[\Big(\sum_{t=0}^{T} \nabla_\theta \log \pi_\theta(A_t \mid S_t)\Big) G(\tau)\Big].

Proof. Step 1 (law of the trajectory). By the chain rule of probabilities (each transition depends only on (S_t, A_t) — Markov): p_\theta(\tau) = \mu(S_0) \prod_{t=0}^{T-1} \pi_\theta(A_t \mid S_t)\, P(S_{t+1} \mid S_t, A_t). Step 2 (log-derivative). We differentiate J = \int p_\theta(\tau) G(\tau)\, d\tau permuting derivative and integral (domination): \nabla_\theta J = \int G(\tau)\, \nabla_\theta p_\theta(\tau)\, d\tau = \int p_\theta(\tau)\, G(\tau)\, \nabla_\theta \log p_\theta(\tau)\, d\tau, using the identity \nabla p = p\, \nabla \log p — the log-derivative trick. This is an expectation under \pi_\theta: it can be estimated by Monte-Carlo with trajectories sampled by the current policy. Step 3 (the dynamics vanish). \log p_\theta(\tau) = \log \mu(S_0) + \sum_t \log \pi_\theta(A_t \mid S_t) + \sum_t \log P(S_{t+1} \mid S_t, A_t), and the first and last terms do not depend on \theta: their gradient is zero. Only the action scores remain: \nabla_\theta J = \mathbb{E}\Big[G(\tau) \sum_t \nabla_\theta \log \pi_\theta(A_t \mid S_t)\Big]. \qquad \blacksquare Reading: raise the probability of rich trajectories (large G), lower the poor ones — the world model is useless, only the actions are accountable.

Proposition 4.2 — Unbiased baseline: demonstration For every function b : \mathcal{S} \to \mathbb{R} (not depending on the action): \mathbb{E}_{\tau \sim \pi_\theta}\Big[b(S_t)\, \nabla_\theta \log \pi_\theta(A_t \mid S_t)\Big] = 0 \qquad \text{for each } t, so subtracting b does not change \nabla_\theta J.

Proof. Condition on S_t = s (with law d_t(s) under \pi_\theta): \mathbb{E}\big[b(S_t)\, \nabla \log \pi_\theta(A_t \mid S_t)\big] = \sum_s d_t(s)\, b(s) \sum_a \pi_\theta(a \mid s)\, \nabla_\theta \log \pi_\theta(a \mid s). Now \pi_\theta(a\|s)\, \nabla_\theta \log \pi_\theta(a\|s) = \nabla_\theta \pi_\theta(a\|s) (same identity as in step 2), so the inner sum equals \nabla_\theta \sum_a \pi_\theta(a \mid s) = \nabla_\theta 1 = 0. ∎

Variance analysis. The empirical gradient (G - b)\nabla\log\pi has variance \mathrm{Var}[G \nabla\log\pi] + \mathrm{Var}[b\nabla\log\pi] - 2\,\mathrm{Cov}: choosing b(s) close to \mathbb{E}[G \mid S_t = s] makes the covariance maximal and almost cancels the first order. The optimal constant baseline (minimizing the variance of the estimator for a given state) equals b^\star = \mathbb{E}\big[G^2 \\|\nabla \log \pi\\|^2\big] / \mathbb{E}\big[\\|\nabla \log \pi\\|^2\big] — and the natural choice b(s) = V^\pi(s) turns G - b into the advantage A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s): same expectation, drastically reduced variance (policy gradient theorem, Sutton et al. 1999: \nabla J = \mathbb{E}_{s \sim d^\pi, a \sim \pi}[\nabla\log\pi(a\|s)\, Q^\pi(s,a)], where Q^\pi can replace G).

4.2. Actor-critic

Algorithm 4.3 — A2C: semi-gradients Two networks: the actor \pi_\theta and the critic V_w. At each transition: \delta_t = R_{t+1} + \gamma V_w(S_{t+1}) - V_w(S_t) \quad (\text{TD error, chapter 3}), w \leftarrow w + \alpha_w\, \delta_t\, \nabla_w V_w(S_t) \quad (\text{critic: TD(0) semi-gradient}), \theta \leftarrow \theta + \alpha_\theta\, \delta_t\, \nabla_\theta \log \pi_\theta(A_t \mid S_t) \quad (\text{actor: REINFORCE with } \delta_t \text{ as advantage}). We say semi-gradient because the target V_w(S_{t+1}) depends on w but is not differentiated (the true gradient of the TD loss would bring the unstable “double sampling” — cf. deadly triad, ch. 3). Two step scales \alpha_w \gg \alpha_\theta (the critic must keep up); the estimated advantage \hat A_t = \delta_t is replaced in practice by GAE (Proposition 3.4). A3C (Mnih et al., 2016): parallel actors explore independent environments and push their gradients to a shared parameter — asynchronous hence without replay; A2C is its synchronized (batched) variant, simpler and equivalent in performance.

4.3. From trust region to PPO

Proposition 4.4 — Natural gradient and TRPO (sketch) The relevant geometry on policies is the KL divergence, not the Euclidean distance on \theta (a reparameterization changes the algorithm). The natural gradient corrects this: \tilde\nabla J = G(\theta)^{-1} \nabla_\theta J, where G(\theta) = \mathbb{E}[\nabla\log\pi_\theta \nabla\log\pi_\theta^\top] is the Fisher matrix. Kakade & Langford (2002) prove a monotone improvement: the gain of any new policy \pi' is lower-bounded by the one-step surrogate gain \mathbb{E}_{s \sim d^\pi, a \sim \pi}\big[ \tfrac{\pi'(a\|s)}{\pi(a\|s)} Q^\pi(s,a)\big] minus a penalty term in \max_s \mathrm{KL}(\pi(\cdot\|s) \,\\|\, \pi'(\cdot\|s)). TRPO (Schulman et al., 2015) maximizes this surrogate under a KL constraint (trust region), solved by interior point + conjugate natural gradient — effective but heavy.

Theorem 4.5 — PPO-clip (Schulman et al., 2017): a pessimistic bound of the surrogate With the importance ratio r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_\text{old}}(a_t \mid s_t)} and the advantage \hat A_t (GAE): L^{\mathrm{CLIP}}(\theta) = \mathbb{E}_t\big[\min\big(r_t(\theta)\, \hat A_t,\ \ \mathrm{clip}(r_t(\theta), 1{-}\epsilon, 1{+}\epsilon)\, \hat A_t\big)\big].

Proof. PPO-clip lower-bounds the importance surrogate L^{\mathrm{IS}} = \mathbb{E}[r_t \hat A_t], point by point:

  • if \hat A_t \> 0 (good action): \min(r \hat A, \mathrm{clip}(r)\hat A) \leq r \hat A trivially, and the clip caps the incentive at 1 + \epsilon: no motivation to blow up the probability of an already rewarded action;
  • if \hat A_t \< 0 (bad action): if r_t \geq 1 - \epsilon, the min equals r_t \hat A_t (equality); if r_t \< 1 - \epsilon, the min equals (1-\epsilon)\hat A_t \leq r_t \hat A_t (since \hat A_t \< 0 and 1 - \epsilon \> r_t): the gradient vanishes — one does not “over-punish” beyond the region.

So L^{\mathrm{CLIP}} \leq L^{\mathrm{IS}}: maximizing the pessimistic bound of a valid approximation of the true gain (Proposition 4.4) — an improvement of the lower bound cannot destroy the policy, hence the monotone improvement intuition without explicit KL constraint or second derivative; the clipping suffices to keep the ratios in the region where the surrogate is faithful. ∎

Implementation details: a few epochs of gradient ascent per batch of trajectories, normalized advantages, entropy bonus, masking of truncated trajectories. PPO is the method behind LLM alignment (RLHF/PPO, then GRPO — cf. M2 Large Language Models module, post-training chapter; the importance ratio there is exactly the same object, applied to tokens).

5. Deep RL: DQN, Rainbow, continuous methods and offline RL

Algorithm 5.1 — DQN (Mnih et al., 2015) Q-learning where Q(s, a; \theta) is a network; stabilized by:

  • experience replay: resampling past transitions (breaks the temporal correlation and approaches the i.i.d. assumption of SGD);
  • target network \theta^- frozen and periodically synchronized: target y = r + \gamma \max_{a'} Q(s', a'; \theta^-) (avoids chasing a moving target — the deadly triad, ch. 3);
  • loss \big(y - Q(s, a; \theta)\big)^2.

5.1. Continuous actions: DDPG and SAC

Algorithm 5.3 — DDPG (Lillicrap et al., 2016) The \max_a is impossible in continuous spaces; DDPG learns two networks: a critic Q_w(s,a) and a deterministic actor \mu_\theta(s) trained by the deterministic policy gradient \nabla_\theta J = \mathbb{E}\big[\nabla_a Q_w(s, a)\big\|_{a = \mu_\theta(s)}\, \nabla_\theta \mu_\theta(s)\big] — the max of Q-learning is replaced by gradient ascent of Q through the actor. Off-policy (replay + targets), but fragile: the Q/actor pair can settle on erroneous maxima of Q (overestimation, again); TD3 adds double Q and noisy targets.

Algorithm 5.4 — SAC: maximum entropy, derivation SAC (Haarnoja et al., 2018) maximizes the return and the entropy: J(\pi) = \mathbb{E}\Big[\sum_t \gamma^t \big(r_t + \alpha\, \mathcal{H}(\pi(\cdot \mid S_t))\big)\Big], \qquad \mathcal{H}(\pi) = -\mathbb{E}_{a \sim \pi}[\log \pi(a \mid s)].

Proof. Optimal softmax policy. For a fixed Q, let us maximize F(\pi) = \mathbb{E}_{a\sim\pi}[Q(s,a)] + \alpha \mathcal{H}(\pi(\cdot\|s)) over distributions. Set \pi^\star(a\|s) \propto \exp(Q(s,a)/\alpha), with normalization constant Z(s) = \sum_a e^{Q(s,a)/\alpha}. Then: F(\pi) = -\alpha\, \mathbb{E}_\pi\Big[\log \frac{\pi(a\|s)}{\pi^\star(a\|s)}\Big] + \alpha \log Z(s) = -\alpha\, \mathrm{KL}(\pi \,\\|\, \pi^\star) + \alpha\log Z(s), (identification by expanding \log \pi^\star = Q/\alpha - \log Z). The unique maximum is attained at \pi = \pi^\star, with value \alpha \log Z(s): the optimal policy weights the actions by a softmax of temperature \alpha of the Q-values — exploring is literally optimal in this criterion. “Soft” Bellman operator. The target equation becomes Q^\star(s,a) = r(s,a) + \gamma\, \mathbb{E}_{s'}[V(s')] with the soft value V(s') = \alpha \log \sum_{a'} e^{Q(s',a')/\alpha} — the max is replaced by a log-sum-exp of temperature \alpha; the log-sum-exp is 1-Lipschitz for \\|\cdot\\|_\infty, so \mathcal{T}_{\mathrm{soft}} remains a \gamma-contraction: the whole theory of chapter 1 survives. ∎

Auto-learned temperature \alpha. \alpha tunes the exploration/exploitation trade-off; SAC treats it by a Lagrangian: minimize J(\alpha) = \mathbb{E}[-\alpha \log \pi(a\|s)] - \alpha\, \bar{\mathcal{H}}, where \bar{\mathcal{H}} is the target entropy: \alpha rises when the actual entropy falls below the target (forced exploration), falls otherwise. Implementation: three networks (actor + two critics, min against overestimation), reparameterization to backpropagate through sampling, GAE useless (off-policy). SAC is the standard for continuous environments (robotics, control).

5.2. Offline RL and sim-to-real

Offline RL (batch learning): the distribution shift Data: a fixed dataset \mathcal{D} of transitions (teleoperator, logs, simulator); no interaction. The danger: Q is evaluated on out-of-distribution actions (never tried in \mathcal{D}); the \max_{a'} of Q-learning queries the network where it has seen nothing — uncorrected overestimation (Theorem 3.5, aggravated). Conservative Q-Learning (Kumar et al., 2020, sketch): regularize Q so that it is low on out-of-dataset actions and high on dataset actions: \mathcal{L}(\theta) = \mathbb{E}_{\mathcal{D}}\big[(y - Q_\theta)^2\big] + \alpha\Big(\mathbb{E}_{a' \sim \pi, s' \sim \mathcal{D}}[Q_\theta(s', a')] - \mathbb{E}_{(s,a) \sim \mathcal{D}}[Q_\theta(s,a)]\Big). The policy is then extracted from the regularized Q — it no longer dares to leave the support of the data. Other approaches: BCQ (restricting to actions close to the data), IQL (expectile regression, no out-of-support query). Offline RL is the bridge toward RLHF: learning a reward/policy from fixed preferences is an offline problem (cf. M2 LLMs module).

Sim-to-real In robotics, training happens in a simulator (cheap, parallelizable) then transfers to the real robot — whose dynamics differ (friction, latency, sensors). Tools: domain randomization (randomizing mass/friction/texture to make the policy robust to discrepancies, Tobin et al., 2017), system identification, online adaptation (short real fine-tuning). The unifying theme: robustness to model errors — the same tension as the 1/(1-\gamma) error propagation of Proposition 2.4.

LLGA cross-references Off-policy vs on-policy (DQN reuses the whole past, PPO discards after one batch): exactly the sample-efficiency/stability trade-off found again in LLM post-training — cf. M2 Large Language Models module. Multi-worker distributed RL (A3C, IMPALA) is a special case of distributed SGD — cf. Emerging Subjects in ML module, chapter 2. High-dimensional exploration (count-based, RND) is treated in chapter 6.

6. Bandits and exploration

Definition 6.1 — K-armed bandit An MDP with a single state: at each step choose an arm a and receive r \sim \nu_a (independent of the past). Objective: minimize the cumulative regret R_T = T\,\mu^\star - \mathbb{E}\Big[\sum_{t=1}^T \mu_{A_t}\Big] = \sum_{a : \Delta_a \> 0} \Delta_a\, \mathbb{E}[N_a(T)], \qquad \Delta_a = \mu^\star - \mu_a, where N_a(T) counts the pulls of arm a. The bandit isolates the exploration/exploitation trade-off without state generalization cost — and it is already a hard sequential problem: every datum received depends on the past action.

Theorem 6.2 — UCB1: logarithmic regret, proof sketch UCB1 (Auer, Cesa-Bianchi & Fischer, 2002): play each arm once, then at each step A_t = \arg\max_a \Big[\hat\mu_a(t) + \sqrt{\tfrac{2 \log t}{N_a(t)}}\Big] (“optimism in the face of uncertainty”: the bonus decreases in 1/\sqrt{N_a}). For rewards in [0,1]: R_T \;\leq\; \sum_{a \neq a^\star} \frac{8 \log T}{\Delta_a} + \Big(1 + \frac{\pi^2}{3}\Big) \sum_a \Delta_a.

Proof. Step 1 (concentration, Hoeffding). For an arm a pulled n times, \mathbb{P}\big(\hat\mu_a \leq \mu_a - u\big) \leq e^{-2 n u^2} — the empirical means concentrate around the true mean. Step 2 (optimism is reliable). With u = \sqrt{2\log t / N_a}, the event “\hat\mu_a + u \< \mu_a” (pessimistic index) has probability \leq t^{-4}; union bound over t (the series \sum t^{-4} is finite, hence the \pi^2/3 term): outside rare events, the index always upper-bounds the true mean, so the optimal arm has an index \geq \mu^\star and a suboptimal arm can only be chosen if its estimate is too high. Step 3 (counting bad choices). If a \neq a^\star is chosen at time t, then (indices compared) \hat\mu_a + \sqrt{2\log t / N_a} \geq \hat\mu_{a^\star} + \sqrt{2\log t/N_{a^\star}} \geq \mu^\star, hence \hat\mu_a \geq \mu^\star - \sqrt{2\log t/N_a} — but \hat\mu_a \leq \mu_a + \sqrt{2\log t/N_a} outside rare events; combining, N_a(t) \leq 8 \log T / \Delta_a^2 before the arm is definitively dominated. Step 4 (regret). Inject into R_T = \sum_a \Delta_a \mathbb{E}[N_a(T)]. ∎

Theorem 6.3 — Lai-Robbins lower bound (1985) For every consistent strategy (regret sub-polynomial in T on all instances): \liminf_{T \to \infty} \frac{R_T}{\log T} \;\geq\; \sum_{a : \Delta_a \> 0} \frac{\Delta_a}{\mathrm{KL}(\nu_a \,\\|\, \nu_{a^\star})}. Interpretation: distinguishing \nu_a from \nu_{a^\star} requires \Omega(\mathrm{KL}^{-1} \log T) samples — information-theoretically. UCB1 loses at most a constant factor against this bound; optimized indices (KL-UCB) and Thompson sampling attain it asymptotically. Regret in \Theta(\log T) is therefore the law of the problem.

Algorithm 6.4 — Thompson sampling: derived posteriors Maintain a posterior over each \mu_a; at each step, sample \tilde\mu_a from each posterior and play \arg\max_a \tilde\mu_a. Pulls of a dominated arm naturally become rare: exploration emerges from the algorithm.

Proof. Bernoulli case: Beta conjugation. Prior \mathrm{Beta}(\alpha, \beta) of density \propto \theta^{\alpha-1}(1-\theta)^{\beta-1}, likelihood \theta^{S}(1-\theta)^{F} (S successes, F failures): the posterior is \propto \theta^{\alpha + S - 1}(1-\theta)^{\beta + F - 1}, that is, \mu_a \mid \text{data} \sim \mathrm{Beta}(\alpha + S_a,\ \beta + F_a) — the update is a simple counting (uniform prior: \alpha = \beta = 1). Gaussian case: completing the square. Rewards \mathcal{N}(\mu_a, \sigma^2), prior \mu_a \sim \mathcal{N}(0, \tau^2). The posterior is Gaussian: v_n = \Big(\frac{1}{\tau^2} + \frac{n}{\sigma^2}\Big)^{-1}, \qquad m_n = v_n\, \frac{n\, \bar r}{\sigma^2}, \qquad \mu_a \mid \text{data} \sim \mathcal{N}(m_n, v_n)\,: precisions (inverses of the variances) add up — one recovers the empirical estimator in the limit n \to \infty. ∎

Thompson sampling attains the Lai-Robbins bound (asymptotically, exponential families) and empirically dominates UCB — it is the industrial choice (recommendation, A/B tests). Chapelle & Li (2011) for the reference empirical study.

Algorithm 6.5 — Linear contextual bandits: LinUCB Context x_t \in \mathbb{R}^d (user, article), expected reward linear per action: \mathbb{E}[r \mid x, a] = x_{t,a}^\top \theta^\star. Ridge estimation: A_t = \lambda I + \sum_{\tau \< t} x_{\tau} x_{\tau}^\top, \qquad b_t = \sum_{\tau \< t} x_\tau\, r_\tau, \qquad \hat\theta_t = A_t^{-1} b_t, and index rule (confidence ellipsoid): a_t = \arg\max_a\ x_{t,a}^\top \hat\theta_t + \alpha \sqrt{x_{t,a}^\top A_t^{-1} x_{t,a}}. The bonus \sqrt{x^\top A^{-1} x} is the directional uncertainty (small in often-observed directions); regret \tilde{\mathcal{O}}(d\sqrt{T}) (Abbasi-Yadkori et al., 2011). LinUCB (Li et al., 2010) deployed this idea at scale for news article recommendation — the context = user/article features, exactly the schema of modern recommender systems (network variants: NeuralTS, etc.).

6.1. Exploring beyond bandits

  • Three families of exploration: \varepsilon-greedy (blind, learns nothing from the structure); optimism (UCB, count-based: bonus \beta/\sqrt{N(s,a)} — explore what is uncertain); posterior (Thompson: explore what is plausible). In MDPs, optimism yields the UCT/Monte-Carlo Tree Search algorithms (the heart of AlphaGo).
  • Intrinsic exploration in high dimension: when the count N(s,a) is empty (states almost all distinct — images), replace novelty by a prediction error: RND (Burda et al., 2019, sketch): a random frozen target network f and a predictor g trained to imitate f on visited states; the intrinsic reward r_{\mathrm{int}}(s) = \\|f(s) - g(s)\\|_2^2 is large on new states (never seen by g) and fades with familiarity — a similarity-based generalization of count-based exploration;
  • Exploration in LLMs: RLHF and LLM evaluation (best-of-n, jury voting) are bandit problems (arms = answers, context = prompt); RLVR (RL from verifiable rewards) uses exploration for reasoning-chain search (verifiable reward = binomial oracle); SAC-like policy entropy and sampling temperature play the role of the temperature \alpha — chapter taken up again in the M2 Large Language Models module.

7. Autonomous agents in the era of LLMs

Definition 7.1 — POMDP: when the state is not observable A POMDP is a tuple (\mathcal{S}, \mathcal{A}, \mathcal{O}, P, \Omega, r, \gamma): like an MDP, but the agent only observes O_t \sim \Omega(\cdot \mid S_{t+1}, A_t) — not the latent state. The central object is the belief b_t(s) = \mathbb{P}[S_t = s \mid O_1, \dots, O_t, A_1, \dots, A_{t-1}], updated by Bayes at each observation. Fundamental result: the POMDP rewrites as an MDP over the (continuous) space of beliefs, with reward \bar r(b, a) = \sum_s b(s) r(s, a) — optimality preserved, but a continuous state space and a PSPACE-hard problem in general. Every real agent is a POMDP: perception is always partial (noisy sensors, screen, text).

  • Defining an agent: perceive → decide → act → observe, in a loop (the agent = policy \pi over a POMDP); perception = context (text, memory), action = tool calls, APIs, code. The memory/state estimation of the POMDP materializes as: context window (short-term memory — bounded), vector memories (similarity retrieval = approximate belief estimation), recurrent networks/hidden state (literally a learned filter);
  • LLM + tools: the LLM is the decision engine; the “prompt” = observation; function calling = action space. The ReAct loop (Yao et al., 2023) alternates explicit reasoning and actions:

GraphRAG: index knowledge as a graph (entity-relation) and query by neighborhood/multi-hop — retrieval becomes a query over a knowledge graph; exact intersection of the master’s program: NLP × Graph ML × LLM (cf. Graph Machine and Deep Learning for Generative AI module, chapter 8, and the NLP module for retrieval-conditioned generation);

8. Course research notes (Jesse Read)

Jesse Read (professor at LIX, École Polytechnique) is one of the founding authors of multi-label learning and a central player in stream learning (data streams). His themes — multi-label and extreme classification, adaptive stream learning — are directly connected to the program of this course: they are problems of sequential decisions under non-stationarity.

8.1. Multi-label classification: classifier chains

Definition 8.1 — Multi-label and the dependency problem In multi-label learning, each instance x receives a set of labels Y \subseteq \{1, \dots, K\} — encoding y \in \{0,1\}^K. The naive approach (binary relevance) trains K independent classifiers; it ignores that labels are correlated (medications prescribed together, co-occurring tags). Domain taxonomies distinguish: problem transformation (recoding the problem — binary relevance, label powerset, chains) vs algorithm adaptation (adapting an existing algorithm — trees, multi-label SVMs; cf. Read et al., 2011; Read & Perez-Cruz, 2014).

Idea 8.2 — Classifier chains (Read, Pfahringer, Holmes & Frank, 2011) Order the labels 1, \dots, K and train a chain: classifier j predicts y_j from (x, y_1, \dots, y_{j-1}). By the chain rule of probabilities: p(y \mid x) = \prod_{j=1}^{K} p\big(y_j \,\big\|\, x, y_1, \dots, y_{j-1}\big), each link models the conditional dependence on the previous labels — the predictors share their structure. Difficulties: the choice of order and the cascading error along the chain (a wrong link contaminates the rest); ensembles of chains (random orders, voting) and probabilistic variants (sampling multiple paths) mitigate these two defects. This is a sequential decision process: the set of prefixes (y_1, \dots, y_{j-1}) is a path in a decision tree, and the label order plays the role of the horizon — exactly the “state-action-reward” structure of chapter 1, without environmental stochasticity.

Extreme classification When K \sim 10^5–10^6 (tagging Wikipedia, predicting search queries), multi-label becomes extreme: impossible to train K classifiers; one projects labels and instances into a common latent space (embeddings), subsamples rare labels (negative sampling), organizes prediction with trees. Read & Perez-Cruz (2014) study the contribution of deep learning for this regime — and the connection with chapter 5 of this course is literal: approximating a value/action function in very high dimension.

8.2. Stream learning: concept drift and adaptation

Definition 8.3 — Streams, drift, prequential evaluation Data arrives as a stream (x_t, y_t)_{t \geq 1}, through a distribution that changes (concept drift: abrupt — a new spam; gradual — shifting usage patterns; recurring — seasonality). The standard evaluation is prequential: predict y_t with the current model, then learn from (x_t, y_t), accumulating the test error before training — each datum is used once, never any retrospective replay: this is the criterion of an agent that lives in time. The tools: adaptive sliding windows, drift detectors, ensembles of weighted and replaced learners (Gomes, Read, Bifet et al., 2019; Read & Žliobaitė, 2022).

Proposition 8.4 — The link with RL: positioning A stream classifier is exactly a policy in a non-stationary environment: the state = the current model and the recent window, the action = the prediction (and the update); drift makes P and r functions of time — the MDP of chapter 1 becomes non-stationary, and the convergence theorems (Robbins-Monro, Th. 0.5) lose their fixed-point uniqueness hypothesis: the algorithm must track rather than converge — constant steps or finite windows rather than decay. The three points of contact with the course:

  • bandits (ch. 6): drift is a non-stationary bandit (resetting posteriors, windows over \hat\mu_a); active learning — choosing which datum to label in a stream — is a contextual bandit;
  • exploration (ch. 6): maintaining the exploitation/exploration trade-off when everything moves (“optimism” as regularization of change);
  • agents (ch. 7): an LLM agent in production sees its world change (tools, sources): the same detection and adaptation issues — the perception-action loop of chapter 7 is a stream.

Solutions — exercises 1, 2, 4 (hints), 6, 7, 10

1. States \{c, s\} (continue, stop). Bellman: V^\star(s) = 0; V^\star(c) = \max\{0,\ c + \gamma V^\star(c)\}. If c + \gamma V^\star(c) \geq 0 then V^\star(c) = c/(1-\gamma) (geometric series), valid if and only if c \geq 0; otherwise V^\star(c) = 0 and the optimal policy is to stop immediately. Instructive variant: if stopping yields b once, continuing is optimal if and only if \frac{c}{1-\gamma} \geq b, i.e. c \geq b(1-\gamma): the closer \gamma is to 1, the lower the threshold — weak discounting values distant gains, so one continues all the more willingly; at \gamma = 0, only the immediate gain counts and the threshold is c \geq b.

2. Lemma: for every a, u_a \leq v_a + \max_b\|u_b - v_b\| so \max_a u_a \leq \max_a v_a + \max_b \|u_b - v_b\|; symmetry. Stopping: \\|V_k - V^\star\\| \leq \\|\mathcal{T}V_{k-1} - \mathcal{T}V_k\\| + \\|\mathcal{T}V_k - \mathcal{T}V^\star\\| \leq \gamma\\|V_{k-1} - V_k\\| + \gamma\\|V_k - V^\star\\|, hence (1-\gamma)\\|V_k - V^\star\\| \leq \gamma \\|V_{k-1} - V_k\\|.

4 (hints). Update Q(S_t, A_t) with the target R + \gamma\max_{a'} Q(S_{t+1}, a') (Q-learning) or R + \gamma Q(S_{t+1}, A_{t+1}) where A_{t+1} is the action actually played by the \varepsilon-greedy policy (SARSA). Expected phenomenon: Q-learning converges to the optimal path along the cliff (the max “believes” the agent will never fall), SARSA to a set-back path (random exploration makes the followed policy fall); with \varepsilon \to 0 the two coincide.

6. \max(X, Y) with X, Y i.i.d. \mathcal{N}(0, \sigma^2): \max = \tfrac{X+Y}{2} + \tfrac{\|X - Y\|}{2}; X + Y is \mathcal{N}(0, 2\sigma^2) and X - Y is \mathcal{N}(0, 2\sigma^2), so \mathbb{E}\|X - Y\| = \sqrt{2}\sigma\sqrt{2/\pi} and \mathbb{E}[\max] = \sigma/\sqrt{\pi} \> 0 = \max(\mathbb{E}X, \mathbb{E}Y): the bias equals \sigma/\sqrt{\pi}, purely created by the estimation noise — this is the continuous version of Theorem 3.5.

7. Without baseline, the estimator \widehat{\nabla J} = G\,\nabla\log\pi has variance with a factor \mathrm{Var}[G] (large: the return accumulates the noise of the whole episode); with b = V_w(s), the “value of the state” part cancels (Proposition 4.2); in practice on CartPole, learning without baseline is slow and irregular (gradient variance an order of magnitude higher), with baseline it is smooth and 3-5× faster; verify numerically that \widehat{\mathrm{Var}}[\hat\nabla J] decreases by a factor ~10 after advantage normalization.

10. Lai-Robbins for Bernoullis: the asymptotic bound is \sum_{a \neq a^\star} \Delta_a \mathrm{KL}(\mathrm{Bern}(\mu_a)\\|\mathrm{Bern}(\mu^\star)) ^{-1} \log T with \mathrm{KL} = \mu_a \log\frac{\mu_a}{\mu^\star} + (1-\mu_a) \log\frac{1-\mu_a}{1-\mu^\star}; compute the two KLs (arm 0.2: \approx 0.53; arm 0.5: \approx 0.09), plot R_T / \log T for UCB and Thompson: both curves flatten toward the Lai-Robbins constant (Thompson closer), \varepsilon-greedy diverges linearly (regret \Theta(\varepsilon T)).
