1. Processus de décision markovien

Définition 1.1 — MDP Un MDP est un tuple \((\mathcal{S}, \mathcal{A}, P, r, \gamma)\) : états \(\mathcal{S}\), actions \(\mathcal{A}\), noyau de transition \(P(s' \mid s, a)\), récompense \(r(s, a, s')\) (on note \(r(s,a)\) son espérance), facteur d'actualisation \(\gamma \in [0, 1)\). Une politique \(\pi(a \mid s)\) règle le choix des actions ; l'objectif est le retour espéré actualisé $$J(\pi) = \mathbb{E}_\pi\Big[\sum_{t=0}^{\infty} \gamma^t R_t\Big].$$ Fixer une politique \(\pi\) dans un MDP induit une chaîne de Markov de noyau \(P^\pi(s' \mid s) = \sum_a \pi(a \mid s) P(s' \mid s, a)\) — le chapitre 0 s'applique littéralement ; \(\gamma < 1\) garantit que toutes les sommes convergent.
Proposition 1.2 — Politiques déterministes stationnaires Il suffit de chercher parmi les politiques déterministes \(\pi : \mathcal{S} \to \mathcal{A}\) et stationnaires (ne dépendant pas de \(t\)) : pour toute politique mixte et non stationnaire, il existe une politique déterministe stationnaire de valeur au moins égale en tout état. (Preuve : récurrence arrière sur l'horizon puis passage à la limite \(\gamma\)-actualisée ; voir Puterman, 2005.) L'espace de recherche est fini : \(|\mathcal{A}|^{|\mathcal{S}|}\) candidats — trop grand pour l'énumération, d'où les chapitres 2 et suivants.
Définition 1.3 — Fonctions de valeur $$V^\pi(s) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s\Big], \qquad Q^\pi(s, a) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s, A_0 = a\Big].$$ \(V^\pi\) = « combien vaut l'état » ; \(Q^\pi\) = « combien vaut le couple état-action ». On a \(V^\pi(s) = \sum_a \pi(a\mid s)\, Q^\pi(s,a)\) et \(Q^\pi(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s')\).
Définition 1.4 — Mesures d'occupation La mesure d'occupation de \(\pi\) (depuis \(\mu_0\)) est $$\rho_\pi(s, a) = (1 - \gamma)\sum_{t=0}^{\infty} \gamma^t\, \mathbb{P}_\pi[S_t = s, A_t = a], \qquad \text{de sorte que} \qquad J(\pi) = \frac{1}{1-\gamma}\sum_{s,a} \rho_\pi(s,a)\, r(s,a).$$ \(\rho_\pi\) est une distribution de probabilité sur \(\mathcal{S} \times \mathcal{A}\) ; elle décrit « où vit » la politique. C'est le pont naturel vers la formulation LP ci-dessous et vers les ratios d'importance du chapitre 4 (échantillonner sous \(\pi\), évaluer sous \(\pi'\)).
Théorème 1.5 — Équations de Bellman (évaluation) $$Q^\pi(s, a) = r(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s'), \qquad V^\pi(s) = \sum_a \pi(a \mid s)\Big[r(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s')\Big].$$ C'est la programmation dynamique appliquée au temps : la valeur d'aujourd'hui = gain immédiat + valeur actualisée de demain. En notant \(T_\pi\) l'opérateur \((T_\pi V)(s) = \sum_a \pi(a|s)\big[r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')\big]\), l'équation se réécrit \(V^\pi = T_\pi V^\pi\) — un système linéaire de \(|\mathcal{S}|\) équations (\((I - \gamma P^\pi) V = r^\pi\), inversible car \(\gamma < 1\)).
Théorème 1.6 — Optimalité : existence, unicité (preuve complète) Soit l'opérateur de Bellman optimal $$(\mathcal{T}V)(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V(s') \Big\}.$$ (1) \(\mathcal{T}\) est une contraction de module \(\gamma\) sur \((\mathbb{R}^{|\mathcal{S}|}, \|\cdot\|_\infty)\) (espace complet). Preuve en deux lemmes :
Lemme (max-Lipschitz). Pour toutes familles bornées \((u_a)_a\), \((v_a)_a\) : \(|\max_a u_a - \max_a v_a| \leq \max_a |u_a - v_a|\). En effet, pour tout \(a\), \(u_a \leq v_a + \max_b |u_b - v_b|\), donc \(\max_a u_a \leq \max_a v_a + \max_b |u_b - v_b|\) ; en échangeant les rôles, \(|\max_a u_a - \max_a v_a| \leq \max_b |u_b - v_b|\). Contraction. Pour chaque \(s\), en posant \(u_a = r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')\) et \(v_a\) l'analogue pour \(V'\) : $$\big|(\mathcal{T}V)(s) - (\mathcal{T}V')(s)\big| \leq \max_a \gamma \Big|\sum_{s'} P(s'|s,a)\big(V(s') - V'(s')\big)\Big| \leq \gamma\, \|V - V'\|_\infty,$$ car \(P(\cdot|s,a)\) est une distribution de probabilité. En prenant le max sur \(s\) : \(\|\mathcal{T}V - \mathcal{T}V'\|_\infty \leq \gamma \|V - V'\|_\infty\). (2) Point fixe. Par le théorème du point fixe de Banach (rappel L3 : contraction sur un espace complet), \(\mathcal{T}\) admet un unique point fixe \(V^\star\), et \(\mathcal{T}^k V \to V^\star\) pour tout \(V\) de départ, à vitesse géométrique \(\gamma^k\). On pose \(Q^\star = r + \gamma P V^\star\), qui vérifie $$Q^\star(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, \max_{a'} Q^\star(s', a').$$ (3) Politique optimale. Soit \(\pi^\star\) gloutonne pour \(V^\star\) : \(\pi^\star(s) \in \arg\max_a Q^\star(s,a)\). Alors \(T_{\pi^\star} V^\star = \mathcal{T}V^\star = V^\star\), donc \(\|T_{\pi^\star}^k V^\star - V^\star\|_\infty \leq \gamma^k \|T_{\pi^\star} V^\star - V^\star\|_\infty = 0\) pour tout \(k\) ; à la limite \(V^{\pi^\star} = V^\star\). Donc \(\pi^\star\) atteint la borne supérieure \(\sup_\pi V^\pi\) en tout état : c'est une politique optimale déterministe stationnaire. ∎
Proposition 1.7 — Formulation linéaire (LP) des MDP Résoudre un MDP revient à résoudre le programme linéaire (dual) : $$\max_{\mu \geq 0}\ \sum_{s,a} \mu(s,a)\, r(s,a) \quad \text{s.c.} \quad \sum_a \mu(s', a) \;=\; \nu(s') + \gamma \sum_{s,a} P(s' \mid s, a)\, \mu(s,a) \ \ \forall s',$$ où \(\nu\) est la distribution initiale. Les variables \(\mu\) sont les mesures d'occupation \(= \rho_\pi/(1-\gamma)\) ; les contraintes sont des « équations de flot » (ce qui entre dans un état = distribution initiale + ce qui en sort actualisé). Une solution optimale extrémale du polytope est atteinte en une politique déterministe, et \(\pi^\star(s) = \arg\max_a \mu^\star(s, a)\). Intérêt : les LP se résolvent en polynomial (mais polynomial en \(|\mathcal{S}| |\mathcal{A}|\), vite énorme) ; le point de vue dual éclaire aussi les méthodes d'approximation linéaire de la valeur. Le primal s'écrit \(\min_V \sum_s \nu(s) V(s)\) s.c. \(V(s) \geq r(s,a) + \gamma \sum_{s'} P V\) pour tout \((s, a)\) — les contraintes sont les inégalités de Bellman.
Rôle de \(\gamma\) \(\gamma\) actualise le futur mais conditionne aussi toute la théorie : contraction de module \(\gamma\), bornes d'erreur en \(1/(1-\gamma)\) (chapitre 2), variance des retours. Quand \(\gamma \to 1\), on tend vers le critère moyen \(\lim_T \frac{1}{T}\sum_t R_t\) — lié au théorème ergodique 0.2 — mais tous les taux se dégradent : le RL vit avec cette tension.
