9. Passerelles LLGA : 3D, raisonnement algorithmique, GNN × LLM

9.1 — Molécules 3D : EGNN et l'équivariance E(n) (Satorras, Hoogeboom & Welling, 2021) Les positions \(x_i \in \mathbb{R}^3\) rendent le graphe moléculaire géométrique ; la physique est invariante par rotations/translations (E(3)) ; un GNN qui respecte cette symétrie par construction apprend mieux avec moins de données (Bronstein et al., la « charte » du Geometric DL). EGNN : $$m_{ij} = \phi_e\big(h_i, h_j, \|x_i - x_j\|^2, e_{ij}\big),$$ $$x_i^{(\ell+1)} = x_i^{(\ell)} + C \sum_{j \in \mathcal{N}(i)} (x_i^{(\ell)} - x_j^{(\ell)})\, \phi_x(m_{ij}),$$ $$h_i^{(\ell+1)} = \phi_h\big(h_i^{(\ell)}, \textstyle\sum_{j} m_{ij}\big).$$ Preuve d'équivariance (esquisse) : sous \(x \mapsto Rx + t\) (\(R\) orthogonale), les distances \(\|x_i - x_j\|\) sont invariantes donc \(m_{ij}\) aussi ; le pas de position \(\sum_j (x_i - x_j)\phi_x\) se transforme en \(R \sum_j (x_i - x_j)\phi_x\) — équivariance exacte ; le facteur \(C\) borne le pas. Applications : prédiction de propriétés 3D, dynamique moléculaire apprise, génération 3D (EDM — diffusion équivariante ; le module Geometric DL M2 généralise aux groupes ; le M1 ch. 9 couvre la version 2D).
9.2 — Neural algorithmic reasoning (Veličković et al.) Apprendre à exécuter des algorithmes par GNN : encodage des entrées en graphe (tri : liste = graphe de comparaisons ; plus courts chemins : le graphe lui-même), exécution par couches de message passing, décodage des sorties — le black-box remplace le code. Le benchmark CLRS (Veličković et al., ICML 2023) teste l'exécution fidèle d'algorithmes classiques (CLRS = Cormen, Leiserson, Rivest, Stein) ; résultats : les processors GNN généralisent à des tailles non vues mieux que les transformers sur certaines familles (induction structurelle) ; la leçon LLGA : un algorithme appris est différentiable (on peut l'insérer dans un pipeline entraîné de bout en bout : routing, scheduling, matching) et approximativement robuste (entrées bruitées) ; au prix de l'exactitude — le trade-off à maîtriser. Boucle avec le Refresher CS : qu'est-ce qu'un « algorithme appris » peut de plus qu'un algorithme ? Répondre : s'entraîner sur des données, s'insérer dans la descente de gradient — et le pseudo-code prompting du ch. 8.4 est le chemin dual (le LLM simule l'exécution ; le NAR l'incarne).
9.3 — GNN × LLM : encoders injectés et benchmarks Trois architectures d'injection (M1, ch. 11.2, approfondies) :
  • tokens structurels : les sorties d'un GNN (embeddings de nœuds/graphes) sont projetées dans l'espace d'embedding du LLM comme des soft tokens ; le LLM lit la structure comme une langue ;
  • rappel structurel : le GNN (ou le parcours de graphe) retrouve les faits pertinents, le LLM rédige — le RAG devient « graph-RAG » ; dans les deux cas, la question de l'alignement des espaces se pose (contrastif : rapprocher l'embedding GNN du texte qui décrit le même nœud) ;
  • LLM-annotateur : le LLM enrichit les features de nœuds (résumés, types) pour le GNN — le graphe devient text-attribué (le régime « TAG ») ; benchmarks : NLGraph (raisonnement sérialisé — M1, ch. 11.2), Talk like a Graph (encodages : aucun ne domine partout), et les suites GraphRAG industrielles.
GraphRAG industriel (synthèse ; détail au M1, ch. 11) : extraction LLM → graphe d'entités → communautés Leiden + résumés → requêtes locales/globales ; le rôle du M2 : la qualité du graphe (communautés robustes — ch. 7 ; complétion KGC — M1 ch. 6) est le goulot du système ; la spécialité rare que le master fabrique : à la fois la théorie GNN et le pipeline LLM.
9.4 — Ce que le master attend de vous ici Savoir choisir : MPNN vs transformer (ch. 4), avec ou sans PE (ch. 3), profond ou rewiré (ch. 2), certifié ou non (ch. 7) — et savoir démontrer les théorèmes de ch. 1, reproduire les expériences du ch. 8, et lire un papier du domaine en une heure. C'est le niveau « entrée recherche / R&D avancée ».
