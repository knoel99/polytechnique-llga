1. Expressivité : le test de Weisfeiler-Lehman

Définition 1.1 — 1-WL (color refinement) Initialiser une couleur \(c_v^{(0)}\) par les features ; itérer : $$c_v^{(k+1)} = \mathrm{HASH}\Big(c_v^{(k)},\ \mathrm{SORT}\big\{c_u^{(k)} : u \in \mathcal{N}(v)\big\}\Big).$$ Deux graphes sont 1-WL-équivalents si les multisets de couleurs coïncident à convergence. Le 1-WL distingue presque tous les graphes aléatoires (Babai-Erdős-Selkow) ; mais échoue sur des familles simples : graphes réguliers de même degré, cycles, paires de molécules discutées depuis les années 60 (CIR : chemical identity recognition).
Théorème 1.2 — GNN ≤ 1-WL (Xu et al., 2019 ; Morris et al., 2019) Tout GNN de message passing dont l'agrégation et l'update sont des fonctions (continues, calculables) ne peut pas distinguer deux graphes 1-WL-équivalents : si les couleurs initiales coïncident et que les couches saturent le test, les embeddings coïncident à chaque profondeur.
Par récurrence sur \(\ell\). Initialisation : couleurs initiales = features, identiques par hypothèse, donc \(h_v^{(0)} = h_{v'}^{(0)}\) pour tout couple \((v, v')\) de même couleur. Hérédité : si tous les nœuds de couleur \(c\) ont même représentation \(h_c\), alors l'entrée de l'agrégation en \(v\) est le multiset \(\{h_c : c \in \mathrm{multicol}_v\}\) ; or 1-WL-équivalence = égalité des multisets de couleurs et des multisets de couleurs de voisins à chaque itération — donc AGG reçoit des entrées identiques, et \(h_v^{(\ell+1)} = h_{v'}^{(\ell+1)}\). À la fin, les readouts (permutation-invariants par construction, M1 ch. 2) ne voient que le multiset des \(h_v\) — identique sur les deux graphes. ∎
Théorème 1.3 — GIN atteint exactement 1-WL (Xu et al., 2019) Avec somme + MLP et features discrètes, $$h_v^{(k+1)} = \mathrm{MLP}^{(k)}\Big((1 + \epsilon^{(k)})\, h_v^{(k)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k)}\Big)$$ le GNN distingue exactement ce que 1-WL distingue.
L'ingrédient : sur un domaine dénombrable, il existe une fonction \(f : \text{multisets finis} \to \mathbb{R}\) injective : encoder chaque élément par un entier (log canonique d'un prime : \(c \mapsto \log p_c\)) donne \(\sum_i \log p_{c_i}\), et l'unicité de la décomposition en facteurs premiers assure l'injectivité ; un MLP universel l'approxime. Alors la couche somme+MLP est injective en \((h_v, \mathrm{multiset}(h_u))\) — le couple (couleur propre, multiset de voisins) est encodé sans collision : par récurrence, deux nœuds ont même embedding \(\iff\) même couleur 1-WL. Le readout par somme injective conclut : GIN = 1-WL. ∎
Conséquences immédiates : moyenne et max ne sont pas injectives — \(\{a, a, a\}\) et \(\{a\}\) ont même moyenne ; \(\{a, a\}\) et \(\{a\}\) même max — donc GCN/GraphSAGE (moyenne) sont strictement moins puissants que GIN sur les features catégorielles ; en pratique la différence se voit surtout sur les tâches où compter les voisins compte (molécules : \(\mathrm{CH}_4\) vs \(\mathrm{CH}_3\)-\(\mathrm{CH}_3\)).
Exemple 1.4 — C6 vs 2×C3 : 1-WL échoue, 2-WL sépare (démonstration) 1-WL : tous les nœuds sont de degré 2 ; par récurrence, à chaque tour chaque nœud voit (sa couleur, {sa couleur, sa couleur}) — les couleurs restent uniformes sur chaque graphe, et identiques entre les deux graphes : indistinguables. 2-WL (coloration des paires) : considérons une paire adjacente \((u, v)\). Dans le triangle, \(\{w : w \sim u, w \sim v\}\) compte 1 sommet commun ; dans C6, ce compte vaut 0 (pas de triangles) ; la règle de mise à jour du 2-WL, qui agrège pour la paire \((u,v)\) les couleurs des paires \((u, w)\) et \((w, v)\) pour tous les \(w\), encode le nombre de triangles — les histogrammes de paires diffèrent : séparés. ∎ Moralité : le 2-WL (donc un 2-GNN) « compte les moments » que la somme locale ne voit pas. À coder en TP (exercice 1).
Hiérarchie k-WL et k-GNN Le k-WL colore les k-uplets de nœuds : \(k = 2\) : paires (ci-dessus) ; la hiérarchie est stricte : (k+1)-WL distingue des paires que k-WL confond (pour \(k \geq 1\), le 2-WL étant déjà strictement plus fort que le 1-WL) ; au sommet, k = n+1 → test d'isomorphisme exact (exponentiel). Les k-GNN (Morris et al., 2019) implémentent (une variante locale de) k-WL : messages entre k-uplets voisins — coût mémoire et calcul \(\mathcal{O}(n^k)\) : k = 2 praticable, k = 3 réservé aux petits graphes (molécules). Le survey de Morris et al. (2023) dresse la carte complète (Weisfeiler-Lehman « go machine learning »).

Alternatives pragmatiques : sous-graphes et comptage de motifs
  • ESGNN (Equivariant Subgraph Aggregation, Bevilacqua et al., 2022) : chaque nœud est décrit par la collection de sous-graphes (ego-nets de rayon croissant, ou « node-deletion » — le graphe privé de \(v\)) ; un GNN 1-WL partagé les encode, l'agrégation entre sous-graphes ajoute de l'expressivité sans coût \(\mathcal{O}(n^k)\) complet — strictement entre 1-WL et 3-WL ;
  • Comptage de motifs (Bouritsas et al., 2020) : pré-calculer des comptages de sous-graphes isomorphes (triangles, chemins, cycles) et les injecter comme features — « les moments comptent » : lever expressivité par pré-traitement plutôt que par architecture ; lien direct avec l'exemple 1.4 (triangles) et avec les MMD de l'évaluation générative (M1, ch. 9.6) ;
  • Limites pratiques : plus d'expressivité = plus de variance d'estimation et de coût ; sur les benchmarks réels (Dwivedi et al., 2023), GIN vs GCN se joue à quelques dixièmes — l'expressivité n'est le goulot que sur les tâches structurelles (compter, distinguer) — cf. ch. 6.
