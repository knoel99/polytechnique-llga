Exercices

  1. 1-WL à la main. Exécuter 1-WL sur C6 et 2×C3 et vérifier l'indistinguabilité (détailler l'exemple 1.4) ; puis sur le graphe « maison » (carré + toit) vs pentagone ; conclure sur la famille exacte des paires indiscernables. Corrigé partiel : maison vs pentagone — tous les nœuds de degré 2 sauf le sommet du toit (degré 3) ; le pentagone est 2-régulier, la maison non → 1-WL les distingue dès l'itération 1 (couleur initiale = degré) ; généralisation : 1-WL échoue exactement sur certaines paires de graphes réguliers de même suite de degrés (plus finement : même arbre d'itération ; les 2-réguliers connexes = cycles, tous indistinguables entre eux).
  2. GIN vs GCN. Montrer que la moyenne n'est pas injective sur les multisets (donner les contre-exemples {a, a, a} vs {a} et {a, a, b, b} vs {a, b}) et que somme+MLP l'est (features discrètes) ; vérifier expérimentalement : entraîner GIN et GCN sur une paire 1-WL-indistinguable et mesurer. Corrigé partiel : moyenne : {a, a, a} → a et {a} → a (collision) ; somme discrète : encoder a par \(\log 2\), b par \(\log 3\) — \(\{a,a,b,b\} \mapsto 2\log 2 + 2\log 3 = \log 36\) et \(\{a, b\} \mapsto \log 6\) — pas de collision par unicité de la factorisation (th. 1.3) ; en pratique, la moyenne s'en sort mieux sur les features réelles continues — discuter pourquoi (variance d'estimation).
  3. 2-GNN minimal. Implémenter un 2-GNN sur les paires (représentation \(h_{ij}\), messages entre paires adjacentes) et vérifier qu'il sépare C6 et 2C3 (sorties de readout disjointes) là où GIN échoue. Indication : commencer par les couleurs hashées (2-WL exact) avant d'apprendre.
  4. Over-squashing. Construire deux « communautés » reliées par un seul nœud-bottleneck ; mesurer la performance de classification d'un GCN en fonction de la distance au bottleneck ; comparer GPS (ch. 4) et GCN + arêtes virtuelles (DIGL) ; tracer \(\lambda_{\max}\) avant/après rewiring. Corrigé partiel (attendu) : gradient de précision avec la distance pour le GCN ; GPS quasi uniforme ; après DIGL, \(\lambda_{\max}\) baisse de plusieurs pourcents et l'écart se réduit — la courbe \(\lambda_{\max}\) vs précision est le graphique à produire.
  5. LapEig. Calculer les 2 premiers vecteurs propres non triviaux du laplacien du graphe du club de karaté ; projeter les nœuds ; vérifier que la séparation visualisée ≈ la partition réelle ; relancer 5 fois et observer les flips de signe ; implémenter la correction SignNet (ch. 3.1) et mesurer la stabilité (distance entre encodages de deux exécutions). Corrigé partiel : \(\rho(V) = \mathrm{MLP}(\sum_i \phi(v_i) + \phi(-v_i))\) — la somme des deux parités est invariante par flip ; comparer à la baseline « signe fixé par la première composante positive » (instable aux nœuds de valeur quasi nulle).
  6. RWSE à la main et au code. Retrouver les calculs de l'exemple 3.2 (triangle vs hexagone), puis calculer les RWSE (\(K = 4\)) de tous les nœuds du graphe du club de karaté ; montrer que deux nœuds 1-WL-équivalents d'un graphe régulier obtiennent le même RWSE — et expliquer pourquoi c'est une feature (invariance par automorphisme) et un bug (expressivité).
  7. Graphormer-PE. Implémenter le biais d'attention par distance de plus court chemin (matrice de distances par BFS ; table de biais apprise — squelette au ch. 4.1) ; entraîner sur ogbg-molhiv et comparer GCN / GIN / Graphormer-mini ; rapporter moyennes ± écarts-types sur 5 seeds. Corrigé partiel : BFS \(\mathcal{O}(n(|V| + |E|))\) par graph — pré-calculer ; clamp des distances à 5 (loi de pareto des SPD moléculaires) ; attendu : petit mais systématique gain du biais SPD sur GCN.
  8. Temporel. Sur un dataset TGN standard (Wikipedia/Reddit) : entraîner un TGN (bibliothèque pytorch_geometric.nn.models.TGNMemory ou code du papier) ; ablation : retirer la mémoire (garder l'embedding TGAT) ; tracer l'AUC de link prediction future en fonction de l'horizon \(\Delta t\). Corrigé partiel (attendu) : la mémoire domine sur les interactions récentes ; sans mémoire, l'AUC chute de plusieurs points aux petits \(\Delta t\) (l'information des derniers événements n'est plus compressée).
  9. Attaque. Implémenter une attaque par retrait/ajout de \(k\) arêtes ciblant un nœud (gradient sur les arêtes non existantes — ch. 7.1, surrogate linéarisé) ; mesurer le taux de flip de prédiction vs budget ; tester une défense (RGCN ou entraînement sur graphes perturbés). Corrigé partiel : score = |gradient de la perte d'attaque par arête| ; prendre le top-k ; le surrogate suffit (transfert) ; avec RGCN, le budget nécessaire double environ — jamais zéro ; conclure sur la certification (ch. 7.3).
  10. Edge-DP. Démontrer que la randomized response (retourner chaque arête avec probabilité \(p\)) est \((\varepsilon, 0)\)-DP avec \(\varepsilon = \log \frac{p}{1-p}\) (analyser les deux mécanismes de sortie par arête) ; en déduire le bruit de Laplace équivalent pour un comptage d'arêtes. Corrigé : pour deux graphes voisins en une arête, le rapport de vraisemblance de n'importe quelle sortie borné par \(\frac{p}{1-p}\) (cas défavorable : l'arête retournée) ; d'où l'\(\varepsilon\) ; comptage : chaque arête contribue Bernoulli(\(1-p\)) vs Bernoulli(\(p\)), la somme de \(m\) Bernoulli a un bruit binomial — approché par Laplace de variance \(m\,p(1-p)\), i.e. échelle \(\sqrt{m\,p(1-p)}\).
  11. Projet recherche. Reproduire une expérience d'un article parmi (PathNN / GOAT / GPS / TGN / NGG) sur OGB ou TU ; rapport : protocole, seeds, comparaison aux chiffres publiés, analyse d'échec — l'exercice « papier » du M2 ; pour PathNN : comparer les trois variantes (s/r/n) sur un dataset moléculaire et expliquer la hiérarchie observée via le ch. 8.1.
