5. Le stochastic block model

Communautés : des groupes de sommets mieux connectés à l'intérieur qu'entre eux. Le stochastic block model (SBM) en est le modèle génératif canonique — l'équivalent, pour les graphes, des gaussiennes pour les nuages. Il permet de poser les bonnes questions : quand la structure de blocs est-elle détectable ? Quel algorithme l'atteint ? Les réponses font intervenir des seuils exacts — dont deux sont dus à l'enseignant du module (ch. 8).

Définition 5.1 — SBM Paramètres : \(n\) sommets, \(q\) blocs, proportions \((\pi_1, \dots, \pi_q)\), matrice de connectivité \(P = (p_{ab}) \in [0, 1]^{q \times q}\). Génération : chaque sommet reçoit un bloc \(\sigma(v) \sim \pi\) indépendamment ; chaque paire \((u, v)\) est reliée avec probabilité \(p_{\sigma(u)\sigma(v)}\), indépendamment. Cas d'école « deux blocs symétriques » : \(q = 2\), \(\pi = (1/2, 1/2)\), \(p_{\mathrm{in}} = a/n\), \(p_{\mathrm{out}} = b/n\) (deux communautés de degré moyen \(\frac{a+b}{2}\), d'autant plus séparées que \(a > b\)). Le SBM avec degrés hétérogènes dans les blocs (DC-SBM, Karrer–Newman 2011) corrige le biais « les hubs deviennent des blocs ».
Définition 5.2 — Les trois régimes de difficulté
  • Détection (sparse, degrés \(O(1)\)) : partition \(\hat\sigma\) mieux corrélée à \(\sigma\) que le hasard (plus de 50 % de bonnes paires en \(q = 2\)). Régime réaliste pour les grands réseaux.
  • Récupération partielle : fraction d'erreur \(\to 0\) asymptotiquement.
  • Récupération exacte (dense, degrés \(\Theta(\log n)\)) : \(\mathbb{P}(\hat\sigma = \sigma) \to 1\). Pour deux blocs symétriques avec \(p_{\mathrm{in}} = a \log n/n\), \(p_{\mathrm{out}} = b \log n / n\) : le seuil exact est \(\sqrt a - \sqrt b > \sqrt 2\) (Abbe, Bandeira, Hall ; Mossel, Neeman, Sly) : au-dessus, le maximum de vraisemblance — NP-difficile en général — y est atteignable par relaxation semi-définie.
Théorème 5.3 — Seuils de Kesten–Stigum et de détection (énoncés) Pour deux blocs symétriques \((a, b)/n\) :
  1. Impossibilité sous KS. Si \((a - b)^2 \leq 2(a + b)\), aucune méthode ne fait mieux que le hasard (le modèle est « contigu » à Erdős–Rényi de degré \(\frac{a+b}{2}\)) — conjecturé par Decelle, Krzakala, Moore, Zdeborová (2011) ; l'impossibilité est prouvée par Mossel, Neeman, Sly.
  2. Faisabilité au-dessus. Si \((a-b)^2 > 2(a+b)\), la détection est possible — c'est le théorème de Massoulié (STOC 2014, ch. 8) : les graphes aléatoires y vérifient la propriété de Ramanujan faible, et un algorithme spectral non-retour détecte.
La quantité \(\frac{(a-b)^2}{2(a+b)}\) joue le rôle d'un rapport signal/bruit ; le seuil est celui où l'information survit au bruit spectral du degré.
Définition 5.4 — La matrice non-retour (hashimoto) Indexons les arêtes orientées \((u \to v)\) du graphe (il y en a \(2m\)). La matrice non-retour \(B \in \{0,1\}^{2m \times 2m}\) est définie par $$B_{(u \to v),\, (v \to w)} = \mathbf{1}\{ w \neq u \}, \qquad 0 \text{ sinon : un chemin qui ne revient pas sur ses pas.}$$ \(B\) code les marches non-retour (non-backtracking) : la puissance \(B^r\) compte les marches sans demi-tour de longueur \(r\). Lien avec le cours : c'est l'opérateur compagnon de l'adjacence \(A\), insensible au « bruit de degré » qui pollue \(A\) — une marche sans demi-tour ne peut pas faire des allers-retours sur un hub.
Théorème 5.5 (Bordenave, Lelarge, Massoulié, FOCS 2015 / Ann. Probab. 2018) — spectre non-retour du SBM Pour le SBM \((a, b)/n\) et son extension à \(q\) blocs, avec grande probabilité :
  1. le spectre de \(B\) est constitué d'un bulk contenu dans le disque de rayon \(\sqrt{d}\) (où \(d\) est le degré moyen), plus valeurs propres réelles porteuses d'information ;
  2. une valeur propre informative s'échappe du bulk (\(|\lambda| > \sqrt d\)) si et seulement si le seuil de Kesten–Stigum est franchi ;
  3. en conséquence, l'algorithme spectral non-retour — calculer les premiers vecteurs propres de \(B\), faire un k-moyennes dessus — détecte les blocs exactement jusqu'au seuil d'information ; la même matrice prouve que les graphes aléatoires sont asymptotiquement « Ramanujan non réguliers ».
Pourquoi \(A\) échoue là où \(B\) réussit : sous le régime \(\log\)-libre (degrés \(O(1)\)), le plus haut degré est \(\Theta(\frac{\log n}{\log \log n})\) et crée des valeurs propres parasites du même ordre que le signal ; l'opérateur \(B\) annule précisément la contribution de ces allers-retours locaux. C'est la réponse théorique au problème pratique du spectral clustering sur réseaux creux à hubs (module Graph ML, ch. 4 ; module Machine Learning, ch. 6).
Exemple 5.6 — MLE et lien EM Écrire la log-vraisemblance du SBM (blocs latents inconnus) : $$\ell(\sigma) = \sum_{a, b} \Big[ m_{ab}(\sigma) \log \tfrac{a \vee b}{n} + (\text{non-arêtes}) \log(1 - \tfrac{a\vee b}{n}) \Big],$$ et le MLE est la partition maximisant \(\ell\) — un problème combinatoire (discrétisation des coupes). L'EM variationnel (module Machine Learning, ch. 6) approche ce MLE : étape E — responsabilités des blocs ; étape M — re-estimation de \(P\) et \(\pi\) ; initialisation spectrale (5.5) pour échapper aux points selles. C'est le pipeline des bibliothèques graph-tool / sbm.
