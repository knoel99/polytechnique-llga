The Extrapolons route, on top of the tree

A reading order for the Graph × LLM spine — it selects inside the official tree, it does not replace it:

  1. Refreshers on demand — use the readiness checks; skip what you can already demonstrate.
  2. Machine Learning → Deep Learning — fix the split and metric; keep a simple baseline before learned representations.
  3. Two branches — Graph ML and NLP on the same small technical corpus and its dependency graph; keep text-only and graph-only baselines.
  4. Large Language Models + Advanced GNN — deepen both sides; couple only when evidence justifies it.
  5. Selective levers — Optimal Transport, Geometric Deep Learning when the task needs them.
  6. Generation, ops and safety — Graph Generative Models, ML Ops / LLM Engineering, Security and Robustness, LLM Explainability, Security and Privacy.
  7. Synthesise — organise a reproducible comparison via the research-internship, transverse project, ethics framing and end-of-studies internship pages, then the exit checkpoints.

Common experiment. On one held-out task, compare a text baseline, a graph-only model and a coupled system. Fix the split and allowed graph information; include a removed-edge or shuffled-edge ablation; report quality with latency and memory.
