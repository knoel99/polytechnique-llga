Graph × LLM on a business case

When does a graph + LLM pipeline beat tabular or text-only models on a business case (fraud, recommendation, knowledge graph)?

The LLGA core is exactly this diagnosis: homophily, relational structure, textual vs structural signal. After the track, one should argue why adding a GNN or a document graph changes (or does not change) the business decision.

Payment fraud: account features alone vs co-occurrence graph + LLM on transaction text. Where does message-passing yield a measurable lift?

Notes: Graph ML for Generative AI · Large Language Models · Advanced Graph Neural Networks · Machine Learning

Natural extrapolation from Graph ML + NLP + LLM modules: chunking, semantic edges, multi-hop reasoning, hallucination checks with neighborhood constraints.

Technical corpus + product dependency graph: should retrieval follow “depends on” links before concatenating passages?

Notes: Graph ML for Generative AI · Text Mining & NLP · Large Language Models · Graph Generative Models

GNNs & message-passing at scale

How do you size a GNN / message-passing stack for an industrial graph (neighborhood sampling, over-squashing, depth)?

Advanced GNN notes cover expressivity (WL), over-squashing, deep GNNs: in production these decide batching, fan-out and GPU budget — not “just add layers”.

Social / transaction graph with billions of edges, hourly updates: full-batch is impossible. Which sampling scheme, and which degradation metrics?

Notes: Advanced Graph Neural Networks · Graph ML for Generative AI · DataBase Management System

Knowledge graph × LLM

Entity linking, structured queries vs free generation, ontology governance: the track changes the answer relative to a generic “stuff the prompt with FAQ” approach.

Product catalog + compliance rules: must the LLM cite KG nodes, or may it paraphrase freely?

Geometric DL, shapes, TDA

When does geometric deep learning (or shapes / TDA) change the answer versus a flat CNN or LLM on geometric data?

Meshes, point clouds, signals on manifolds, topological persistence: cases where geometry/topology is the signal — typical of LLGA, not of a generic LLM bootcamp.

3D quality control or molecules: geometric GNN embedding vs descriptors + LLM reports. Which inductive bias wins?

Robustness, privacy, explainability (graph / generation context)

How do you assess robustness or privacy of an LLM inside a graph-augmented pipeline or controlled generation (M2 modules in this repo)?

Not generic “standalone LLM safety”: attacks on graph retrieval, leakage via sensitive subgraphs, explainability of message-passing paths + LLM citations, uncertainty on OOD nodes.

The model cites a confidential KG neighbor. Is that an LLM filter issue, a graph access-policy issue, or both?

Notes: Explainability, Security, Privacy of LLMs · Security and Robustness for AI · Privacy and Uncertainty Quantification · Control in Generative AI · Graph ML

How do you explain a decision that combines a GNN score and an LLM generation to business stakeholders — without overselling interpretability?

Typical LLGA synthesis: edge/subgraph attributions, retrieval traces, limits of post-hoc LLM explanations. Explainability + Graph ML + ML (statistical frame) prepare that discourse.

Notes: Explainability, Security, Privacy of LLMs · Advanced GNN · Machine Learning · Optimal Transport & Fairness

Here MLOps is not generic: version the graph and embeddings, non-regression-test a GNN+RAG, budget message-passing inference + tokens. Anchored in ML Ops and LLM Engineering with the graph/LLM courses.
