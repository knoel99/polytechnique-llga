2. Autoregressive models: DeepGMG and GraphRNN in depth

The founding idea (You et al., 2018; Li et al., 2018): sequentialize the construction — a graph becomes a trajectory of local decisions (add a node, add an edge, choose a type), and all the machinery of sequential models (RNNs, then transformers) applies. Two competing formalizations: by nodes (GraphRNN) and by neighborhood expansion (DeepGMG).

Theorem 2.1 — DeepGMG (Li et al., ICML 2018): factorization by graph states Let \(G_t\) denote the partial graph after \(t\) decisions. The construction chain defines the factorization $$p_\theta(G) = \prod_{t=1}^{T} p_\theta(a_t \mid G_{t-1}),$$ where \(a_t \in \{\textsf{ADDNODE}(x),\ \textsf{ADDEDGE}(e),\ \textsf{STOP}\}\), each decision being a categorical parameterized by a graph network: $$h_{G_{t-1}} = \mathrm{GN}\big(\{h_v\}, \{h_{uv}\}, u\big) \quad\text{(node, edge, and global states)},$$ and the heads \(p(a_t \mid h_{G_{t-1}}, h_v)\) read these states — e.g. \(p(\textsf{ADDEDGE}(u,v)) = \mathrm{softmax}\big(f_e(h_u \oplus h_v)\big)\). Three technical points: (i) training follows a canonical order of the data (a fixed arbitrary order, e.g. that of the file); (ii) the likelihood is exact — no variational bound; (iii) the model is exchangeable only on average: if one trains on several random orders (\(\mathbb{E}_{\pi}[p(G \mid \pi)]\)), the marginal law is exchangeable.
Proposition 2.2 — GraphRNN (You et al., ICML 2018): two nested RNNs, proven complexity With the BFS order of the nodes, the graph is the sequence of adjacency rows \(S^i = (A_{i,1}, \dots, A_{i,i-1}) \in \{0,1\}^{i-1}\): $$h_i = \mathrm{RNN}_{node}(h_{i-1}, s_i), \qquad P(S^i \mid h_i) = \prod_{j < i} \mathrm{Bern}\big(\mathrm{RNN}_{edge}(h_i, s^i_{<j})\big).$$
Complexity. The edge level emits \(i-1\) bits for node \(i\), each in one RNN step: \(\sum_{i \leq n} (i-1) = \Theta(n^2)\) steps in total, each in \(\mathcal{O}(1)\) with respect to \(n\) (the state \(h_i\) has fixed size); the node level adds \(\Theta(n)\) steps. Training cost per graph: \(\Theta(n^2)\) RNN steps versus \(\Theta(n^3)\) for a decoder that would recompute the whole history; memory \(\mathcal{O}(n)\) states. Why BFS? an arbitrary order makes the prefix \(S^1..S^k\) depend on the numbering; the BFS order depends only on the explored neighborhood: two BFS numberings of the same graph differ only by intra-level permutations, and the prefixes remain identical in law — exchangeability is approximate, not exact; aromatic rings "closed at the end of the order" remain the textbook failure case. ∎
Modern variants: when the "token" becomes a node Autoregressive graph generation has been absorbed by the LLM wave: (i) textual representation — generate SMILES (a linearized molecule) with an LLM: this is today's industrial production (ch. 7); (ii) graph tokenization — define a vocabulary of fragments (scaffolds, synthesis motifs) and generate the graph fragment by fragment, the generalization of junction trees (Jin et al., 2018: decompose the molecule into a tree of chemically valid fragments, generate the tree — structural validity guaranteed by construction); (iii) action-by-action — the chemical agent ChemCrow (Bran et al., 2023) orchestrates tools (synthesis NMR, docking) rather than atoms: the "local decision" becomes a tool call — cf. LLMs module (M2) ch. 8 for the agent layer. The loop is closed: GraphRNN sequentialized the graph for an RNN; LLMs industrialize the same sequentialization.
  • Strengths of autoregressive models: exact likelihood, sequential sampling with natural stopping, local constraints injectable at every step (ch. 8 of the Control in Generative AI module);
  • Limits: \(\Theta(n^2)\) cost in steps, exposure to the order, errors that propagate (a wrong node-type choice contaminates everything after it); diffusion (ch. 5) answers exactly these last two limits.
