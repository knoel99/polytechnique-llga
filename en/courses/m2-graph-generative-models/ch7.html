7. Conditional generation and text-to-graph

7.1. Three conditioning mechanisms

Definition 7.1 — Conditioning a graph generator One goes from \(p_\theta(G)\) to \(p_\theta(G \mid c)\) where \(c\) is the conditioning; three mechanisms, with different properties:
  • at the input (concat/fusion): the GNN receives \(c\) (property vector, text embedding) — trained on pairs \((G, c)\) or classifier-free (dropout of \(c\)); simple, soft control;
  • by guidance: a predictor \(Q(c \mid G)\) or a classifier steers the sampling (gradients for flows ch. 4, CFG for diffusion ch. 5); strong control, zero or light retraining, price: diversity;
  • by search: generate massively then filter/optimize (Bayesian optimization in the latent space — the classic QSAR pipeline); exact control a posteriori, high sampling cost.
The control-fidelity / diversity trade-off is quantified in ch. 9 of the Control in Generative AI module; here we retain: for graphs, "hard" conditioning (scaffold, valences) and "soft" (properties, text) combine — inpainting + CFG in DiGress.

7.2. Text-to-graph: the LLM × graphs encounter

Theorem 7.2 — Four text-to-graph routes (2022-2026)
  1. Molecule ↔ text translation: MolT5 (Edwards et al., EMNLP 2022) pre-trains a T5 on text + SMILES and treats description → molecule as a translation; the text is the conditioning, the SMILES the target; graph generation is delegated to the SMILES grammar (valence ≈ free);
  2. The LLM writes the generator: instead of generating the graph directly, the LLM writes code (NetworkX) that generates the graph; "Demystifying the Power of LLMs in Graph Generation" (Wang et al., Findings NAACL 2025) shows that network-science prompting (clustering, motifs) suffices to match generators trained on classic families; the agent produces target properties, the code implements them — control moves up one level of abstraction;
  3. Simulator agents: generate dynamic networks by making LLM agents interact (relations, citations, conversations): "Dynamic and Textual Graph Generation via Large-Scale LLM-based Agent Simulation" (Ji et al., 2024) reaches 105 nodes — the structure emerges from the interaction, the text animates the nodes;
  4. LLM + GNN hybrid: the LLM proposes, the GNN evaluates, the loop optimizes (Chen et al., 2023; ChemCrow, Bran et al., 2023: 18 tools including property predictors and docking) — the "proposal/evaluation" loop of ch. 9 of the M1 Graph ML, industrialized by agent tools (cf. LLMs module M2 ch. 8).
Why SMILES won (for now) Generating graphs by direct LLM (edge lists) fails at small scale: local (valence) and global (connectivity) coherence constraints drowned in the long sequence; SMILES encodes valence in the grammar (parentheses, aromaticity): the next token has little illegal freedom — the same lesson as NeVAE (ch. 3): move the constraints from post-processing into the syntax. The counterpart: SMILES is not canonical (one molecule, several encodings; cf. GOAT, ch. 9, on the cost of orders); SELFIES (Krenn et al., 2020) makes the grammar totally valid: every sequence decodes — the practical reference for the 2026 labs.
Example 7.3 — Toy molecular CFG (pen and paper) For the target \(c =\) "high logP"; logits of step \(t\) of the denoiser without conditioning: \((C: 2.0,\ O: 1.5,\ N: 0.5)\); with conditioning: \((C: 3.0,\ O: 0.5,\ N: 0.5)\); guidance \(w = 3\): guided logits = uncond + \(w\)(cond − uncond) = \((C: 5.0,\ O: -1.0,\ N: 0.5)\); probabilities \(\approx (0.95,\ 0.007,\ 0.04)\); carbon dominates: high logP = carbon chains — chemically coherent. Increasing \(w\) → collapse onto carbon (diversity drops): the fidelity/diversity curve of the Control module, readable on a single step.
