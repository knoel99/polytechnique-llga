2. The architecture in depth

Definition 2.1 — The decoder block An LLM stacks \(N\) blocks: $$x \leftarrow x + \mathrm{MHA}(\mathrm{LN}(x)), \qquad x \leftarrow x + \mathrm{MLP}(\mathrm{LN}(x)),$$ with causal attention (triangular mask: token \(i\) sees only \(j \leq i\)), grouped heads (grouped-query attention for inference), a gated MLP (SwiGLU, ~4× expansion), RoPE positional embeddings (rotations; relative generalization to long contexts), and a final LN.
Proposition 2.2 — Pre-norm vs post-norm: the gradient flow Post-LN (original transformer): \(x_{l+1}=\mathrm{LN}(x_l+F(x_l))\) — each block renormalizes the residual itself; the gradient of \(x_L\) to \(x_0\) crosses \(L\) LN Jacobians whose product decays/explodes exponentially with \(L\): warmup mandatory, fragile depth. Pre-LN (GPT-2+, all modern LLMs): \(x_{l+1}=x_l+F(\mathrm{LN}(x_l))\) — the residual path is the identity: $$\frac{\partial x_L}{\partial x_l} = I + \sum_{l'\,>\,l}\frac{\partial F_{l'}}{\partial x_l}$$ → a gradient that reaches every layer without multiplicative attenuation: stable training without fine warmup. Price: the norm \(\|x_l\|\) grows with depth (additive contributions), hence the final LN. (Xiong et al., ICML 2020.)
Theorem 2.3 — RoPE derived (Su et al., 2021) Position is injected by rotation: the dimension-\(d\) vector is viewed as \(d/2\) 2D pairs; pair \(i\) of the token at position \(m\) undergoes \(R(m\theta_i)\) with \(\theta_i = 10000^{-2i/d}\): $$R(\varphi)=\begin{pmatrix}\cos\varphi & -\sin\varphi\\ \sin\varphi & \cos\varphi\end{pmatrix}, \qquad q^{(i)}_m = R(m\theta_i)\,q^{(i)},\quad k^{(i)}_n = R(n\theta_i)\,k^{(i)}.$$
Relative property: the dot product of a pair depends only on the difference of positions: \(\langle q^{(i)}_m,k^{(i)}_n\rangle = q^{(i)\top} R(m\theta_i)^\top R(n\theta_i)\, k^{(i)} = q^{(i)\top} R\big((n-m)\theta_i\big)\,k^{(i)}\), since 2D rotations commute and \(R(a)^\top R(b)=R(b-a)\). Summing over pairs = an attention score depending on \((n-m)\) and the contents — a "soft" generalization of relative embeddings. Practical bonus: to extend the context, one interpolates the angles (\(m\to m/L\)) instead of relearning. ∎
Proposition 2.4 — MQA/GQA: the memory arithmetic of the KV-cache The cache stores keys and values of all past tokens: $$\text{bytes/token} = 2\ (\text{K and V}) \times N_{\text{layers}} \times n_{\text{KV heads}} \times d_{\text{head}} \times \text{bytes/element}.$$ Multi-Query Attention (Shazeer, 2019): a single shared KV head; Grouped-Query (Ainslie et al., 2023): \(n_{\text{KV}} < n_{\text{heads}}\) — e.g. Llama-3-8B: 32 heads, 8 KV heads, 32 layers, \(d_{\text{head}}=128\), fp16 → \(2\times32\times8\times128\times2 = 128\,\text{KiB/token}\); a 100k-token context ≈ 12.8 GB of cache (versus ~51 GB with full attention — a 4× reduction, nearly identical quality). This is THE lever of long context (ch. 6).
Mixture-of-Experts (MoE): routing and balancing Each MLP block is replaced by \(E\) experts \(\{E_i\}\); a router \(g(x)=\mathrm{softmax}(W_g x)\) activates only the top-\(k\): $$y = \sum_{i\in \mathrm{top}\text{-}k} g_i(x)\,E_i(x), \qquad \#\text{active params} \ll \#\text{total params}.$$ Capacity decorrelated from inference cost (Switch Transformer: Fedus et al. 2021; DeepSeek-V3: 671B total, ~37B active). Trap: routing collapse — the winning experts attract everything. Auxiliary balancing loss (Switch): $$\mathcal{L}_{\text{aux}} = \alpha\, E \sum_{i=1}^{E} f_i\,P_i,$$ \(f_i\) = fraction of tokens routed to \(i\), \(P_i=\frac{1}{T}\sum_t g_i(x_t)\) = mean router probability; minimum reached at the uniform distribution (\(f_i=P_i=1/E\)) — zero penalty iff the router is balanced and confident. Modern variants: fine experts + shared experts, balancing without an auxiliary loss (dynamically adjusted bias, DeepSeek-V3).
Efficient attention: FlashAttention and IO complexity Exact attention costs \(\mathcal{O}(n^2)\) compute but is dominated in practice by input/output: the naive implementation writes the \(n\times n\) matrix to HBM (large, slow memory). FlashAttention (Dao et al., 2022): exact tiled computation that fits in SRAM, "online" softmax with an accumulator (running max \(m\) and sum \(\ell\) updated per tile: \(m_{\text{new}}=\max(m,x)\), \(\ell_{\text{new}}=e^{m-m_{\text{new}}}\ell+e^{x-m_{\text{new}}}\)) — the \(n^2\) matrix is never materialized; HBM reads reduced from \(\Theta(n^2)\) to \(\Theta(n^2d^2/M)\) (\(M\) = SRAM size). The general lesson: optimize memory access, not just FLOPs (cf. Signal Processing module for the memory hierarchy).
Beyond: SSM/Mamba (state equation sketch) A state-space model discretizes a linear system \(x'(t)=Ax(t)+Bu(t),\ y=Cx\): $$x_k = \bar A x_{k-1} + \bar B u_k,\qquad y_k = C x_k,\qquad \bar A = e^{\Delta A},\ \bar B \approx \Delta B,$$ computable in \(\mathcal{O}(n)\) by a scan (no \(n^2\) matrix). The selectivity of Mamba (Gu & Dao, 2023): \(\bar B, C, \Delta\) depend on the input → content-dependent (selective forgetting), which yields attention quality at linear cost. SSD duality (Mamba-2, 2024): the same computation rewrites as \(y_k=\sum_{s\le k} C_k^\top\big(\prod_{s<k'}\bar A\big)\bar B_s\,u_s\) — a "attention" with a causal kernel; hence the attention+SSM hybrid architectures.
