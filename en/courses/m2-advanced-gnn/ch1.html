1. Expressive power: the Weisfeiler-Lehman test

Definition 1.1 — 1-WL (color refinement) Initialize a color \(c_v^{(0)}\) from the features; iterate: $$c_v^{(k+1)} = \mathrm{HASH}\Big(c_v^{(k)},\ \mathrm{SORT}\big\{c_u^{(k)} : u \in \mathcal{N}(v)\big\}\Big).$$ Two graphs are 1-WL-equivalent if the multisets of colors coincide at convergence. 1-WL distinguishes almost all random graphs (Babai-Erdős-Selkow); but fails on simple families: regular graphs of the same degree, cycles, pairs of molecules discussed since the 1960s (CIR: chemical identity recognition).
Theorem 1.2 — GNN ≤ 1-WL (Xu et al., 2019; Morris et al., 2019) Any message passing GNN whose aggregation and update are functions (continuous, computable) cannot distinguish two 1-WL-equivalent graphs: if the initial colors coincide and the layers saturate the test, the embeddings coincide at every depth.
By induction on \(\ell\). Initialization: initial colors = features, identical by assumption, so \(h_v^{(0)} = h_{v'}^{(0)}\) for every pair \((v, v')\) of the same color. Heredity: if all nodes of color \(c\) have the same representation \(h_c\), then the input of the aggregation at \(v\) is the multiset \(\{h_c : c \in \mathrm{multicol}_v\}\); now 1-WL-equivalence = equality of color multisets and of neighbor color multisets at each iteration — so AGG receives identical inputs, and \(h_v^{(\ell+1)} = h_{v'}^{(\ell+1)}\). In the end, the readouts (permutation-invariant by construction, M1 ch. 2) see only the multiset of the \(h_v\) — identical on both graphs. ∎
Theorem 1.3 — GIN reaches exactly 1-WL (Xu et al., 2019) With sum + MLP and discrete features, $$h_v^{(k+1)} = \mathrm{MLP}^{(k)}\Big((1 + \epsilon^{(k)})\, h_v^{(k)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k)}\Big)$$ the GNN distinguishes exactly what 1-WL distinguishes.
The ingredient: on a countable domain, there exists an injective function \(f : \text{finite multisets} \to \mathbb{R}\): encoding each element by an integer (canonical log of a prime: \(c \mapsto \log p_c\)) gives \(\sum_i \log p_{c_i}\), and the uniqueness of prime factorization ensures injectivity; a universal MLP approximates it. Then the sum+MLP layer is injective in \((h_v, \mathrm{multiset}(h_u))\) — the pair (own color, neighbor multiset) is encoded without collision: by induction, two nodes have the same embedding \(\iff\) same 1-WL color. The injective sum readout concludes: GIN = 1-WL. ∎
Immediate consequences: mean and max are not injective — \(\{a, a, a\}\) and \(\{a\}\) have the same mean; \(\{a, a\}\) and \(\{a\}\) the same max — so GCN/GraphSAGE (mean) are strictly less powerful than GIN on categorical features; in practice the difference shows up mainly on tasks where counting neighbors matters (molecules: \(\mathrm{CH}_4\) vs \(\mathrm{CH}_3\)-\(\mathrm{CH}_3\)).
Example 1.4 — C6 vs 2×C3: 1-WL fails, 2-WL separates (demonstration) 1-WL: all nodes have degree 2; by induction, at each round each node sees (its color, {its color, its color}) — the colors remain uniform on each graph, and identical between the two graphs: indistinguishable. 2-WL (pair coloring): consider an adjacent pair \((u, v)\). In the triangle, \(\{w : w \sim u, w \sim v\}\) counts 1 common vertex; in C6, this count is 0 (no triangles); the 2-WL update rule, which aggregates for the pair \((u,v)\) the colors of the pairs \((u, w)\) and \((w, v)\) for all \(w\), encodes the number of triangles — the pair histograms differ: separated. ∎ Moral: 2-WL (hence a 2-GNN) "counts the moments" that the local sum cannot see. To code in the lab (exercise 1).
k-WL and k-GNN hierarchy k-WL colors k-tuples of nodes: \(k = 2\): pairs (above); the hierarchy is strict: (k+1)-WL distinguishes pairs that k-WL confuses (for \(k \geq 1\), 2-WL already being strictly stronger than 1-WL); at the top, k = n+1 → exact isomorphism test (exponential). The k-GNNs (Morris et al., 2019) implement (a local variant of) k-WL: messages between neighboring k-tuples — memory and compute cost \(\mathcal{O}(n^k)\): k = 2 practical, k = 3 reserved for small graphs (molecules). Morris et al.'s survey (2023) draws the complete map (Weisfeiler-Lehman "go machine learning").

Pragmatic alternatives: subgraphs and motif counting
  • ESGNN (Equivariant Subgraph Aggregation, Bevilacqua et al., 2022): each node is described by the collection of subgraphs (ego-nets of increasing radius, or "node-deletion" — the graph deprived of \(v\)); a shared 1-WL GNN encodes them, aggregation across subgraphs adds expressive power without full \(\mathcal{O}(n^k)\) cost — strictly between 1-WL and 3-WL;
  • Motif counting (Bouritsas et al., 2020): precompute counts of isomorphic subgraphs (triangles, paths, cycles) and inject them as features — "moments matter": raising expressive power by preprocessing rather than by architecture; direct link with Example 1.4 (triangles) and with the MMDs of generative evaluation (M1, ch. 9.6);
  • Practical limits: more expressive power = more estimation variance and cost; on real benchmarks (Dwivedi et al., 2023), GIN vs GCN is decided by tenths — expressive power is the bottleneck only on structural tasks (counting, distinguishing) — cf. ch. 6.
