4. Graph transformers

Idea: all-all attention + structural bias Global attention \(\mathcal{O}(n^2)\) removes bottlenecks and over-squashing at once (ch. 2); but without an encoding of the graph, a transformer on features alone is blind to structure: the topology must be reinjected via (i) positional encodings (ch. 3) and (ii) additive attention biases in the scores — structure steers attention rather than masking it.
4.1 — Graphormer (Ying et al., 2021) — the three structural encoders
  1. centrality encoding: an embedding of the degree (in/out if directed) added to the features — degree is the first "where am I";
  2. spatial encoding: a bias learned per shortest-path distance: $$\mathrm{Attention}(Q, K)_{ij} = \frac{q_i^\top k_j}{\sqrt{d}} + b_{\phi(d_{ij})}, \qquad d_{ij} = \mathrm{SPD}(i, j), \quad b_{\phi(\cdot)} \text{ learned (table)},$$ with a dedicated value for \(d_{ij} = \infty\) (disconnected nodes); the bias is additive before the softmax — structure conditions attention;
  3. edge encoding: on the shortest path \(i \rightsquigarrow j\), the mean of the embeddings of the crossed edges is added to the score — for molecules, the type of the bonds along the path matters.
Plus a global virtual node (connected to all) for the readout. Result: 1st rank on OGB-LSC PCQM4M (3.7M molecules) at its release. Implementation: 
import torch, torch.nn as nn
from torch_geometric.utils import shortest_path_distance   # PyG >= 2.6 (or homemade BFS)

class GraphormerLayer(nn.Module):
    def __init__(self, d, h, max_spd=5):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, h, batch_first=True)
        self.bias = nn.Embedding(max_spd + 2, h)     # b_phi table: SPD -> h heads
        self.ffn = nn.Sequential(nn.Linear(d, 2*d), nn.GELU(), nn.Linear(2*d, d))
    def forward(self, x, spd):                       # spd: (n, n) integer distances
        b = self.bias(spd.clamp(max=5).long()).permute(2, 0, 1)  # (h, n, n)
        x = self.attn(x, x, x, attn_bias=b)[0] + x
        return self.ffn(x) + x
PyG trick: the per-head bias is built with an embedding table indexed by the distance matrix (exercise 5).
4.2 — GPS (Rampasek et al., 2022): the two channels, layer by layer $$H^{(\ell+1)} = \mathrm{MLP}\Big( \mathrm{BN}\big(\underbrace{\mathrm{MSA}(H^{(\ell)} + \mathrm{PE})}_{\text{global channel}} \;+\; \underbrace{\mathrm{MPNN}(H^{(\ell)}, A)}_{\text{local channel}}\big) \Big)$$ — global attention (all-all; kills over-squashing) + local message passing (locality bias, convolution); PE injected at the input (ch. 3); graph batches by concatenation-padding. Per-layer complexity: \(\mathcal{O}(n^2 d)\) (attention) + \(\mathcal{O}(|E| d)\) (MPNN) — the global channel dominates. GPS is a recipe: any MPNN (GCN, GINE, GAT) and any PE (RWSE, LapEig+SignNet) plug into it — hence its status as the reference framework.
4.3 — Efficient transformers: Exphormer and sampled attention For large \(n\) (ogbn-products…), \(\mathcal{O}(n^2)\) no longer fits; Exphormer (Shirzad et al., 2023) replaces full attention with a sparse attention graph: (i) the edges of the real graph; (ii) the neighbors of a random \(d\)-regular expander graph — an expander has logarithmic diameter: information crosses the graph in \(\mathcal{O}(\log n)\) layers, precisely what ch. 2 demands (expansion!); (iii) global virtual nodes. Complexity linear in \(n + |E|\); combined with the local MPNN, this gives "Exphormer-GPS", the scalable state of the art. Generalization: sampled attention (neighborhood, kernels, hashing) — the same recipes as the long-context transformers of the M2 LLMs module, transposed: the graph transformer and the LLM live the same algorithmic life.
4.4 — When is an MPNN enough? (decision guide)
  • homophilous graph, local dependencies (Cora, transactional fraud): GCN/GAT 2-3 layers — no point paying \(n^2\);
  • motifs, distances, long-range dependencies (molecules, QA over KGs): transformer or ESGNN (ch. 1) — structure exceeds the neighborhood;
  • large \(n\): MPNN + sampling (ch. 6) or Exphormer;
  • empirical benchmark rule (Dwivedi et al., 2023): at equal size, the gain of the transformer over MPNN+PE is real but modest — the hybrid (GPS) wins most often; the PE is the dominant factor, the architecture second.
LLGA connection: "attention = complete dynamic graph" versus "GNN = attention on a given graph" (M1, ch. 5); Graphormer is the synthesis — a given and learned attention — the transformers ↔ GNN convergence is THE guiding thread of the master.
