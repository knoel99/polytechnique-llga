5. Dynamic and temporal graphs

Two formalisms: snapshots vs event-based
  • snapshots: \(G_1, G_2, \dots, G_T\) (graph aggregated per window); models: GCN+RNN (encode each snapshot, make recurrent); simple, but the granularity loses the order within the window;
  • event-based: the stream of timestamped interactions \((u, v, t_1), (u, w, t_2), \dots\) — the "true" formulation of the problem; it is the regime of fraud (millisecond) and sequential recommendation.
5.1 — TGAT (Xu et al., 2020): encoding time The first notable event-based architecture injects time into attention: a learned sinusoidal temporal encoding (in the spirit of Time2Vec) $$\phi(\Delta t) = \big[\cos(\omega_1 \Delta t), \sin(\omega_1 \Delta t), \dots, \cos(\omega_d \Delta t), \sin(\omega_d \Delta t)\big], \qquad \omega_i \text{ learned},$$ concatenated with the features; attention is computed over the strictly past neighborhood \(\mathcal{N}(v; t) = \{u : (u, v, t') \in E, t' \leq t\}\) — a causal GAT; inductive by construction (new nodes = new times).
5.2 — TGN (Rossi et al., 2020): the modules and their equations TGN factorizes temporal memory:
  1. memory \(s_i(t) \in \mathbb{R}^d\): a recurrent state per node, summarizing its history;
  2. message: at each event \((i, j, t)\), \(m_i^t = \mathrm{msg}(s_i(t^-), s_j(t^-), \Delta t, e_{ij})\) (likewise for \(j\), symmetric);
  3. update: \(s_i(t) = \mathrm{GRU}\big(s_i(t^-),\ \mathrm{agg}(\{m_i^{t'} : t' \leq t\})\big)\) — only the nodes touched by the batch are updated; "at rest" nodes receive a placeholder message to age their memory;
  4. embedding: \(z_i(t)\) computed by a TGAT-type module over the memory \(\{s_u(t^-) : u \in \mathcal{N}(i; t)\}\) + the time encoding \(\phi\) — memory is a compressed summary, the embedding an attentive reading.
Training: strictly causal — batches are ordered by time, and the masked teacher forcing technique (memorizing states between batches without backprop through the whole history, but "replaying" the stored states) makes the gradient practical; future link prediction loss: score \((i, j, t)\) against negatives (M1, ch. 6, temporal version). The paper's ablation: every module counts — remove memory, and everything collapses on distant interactions.
5.3 — LLGA application: real-time fraud The transaction graph is event-based by nature: a fraudulent card must be blocked in seconds; the pipeline: (i) TGN encodes the accounts (memory = past behavior); (ii) a head classifier reads \(z_i(t)\) at the moment of the transaction; (iii) the negatives are old legitimate transactions — beware temporal contamination (train strictly before \(t\): the temporal-split hygiene of the Emerging ML module); (iv) in production: incremental memory update, model drift to monitor. Lab datasets: Wikipedia edits / Reddit (TGN standards), and anonymized transaction banks. Variants: CAWN (attention by causal walks), compressed memorization; the state-of-the-art survey lives on the temporal graph learning side.
