8. Model stealing and membership inference

Definition 8.1 — Extraction / model stealing The attacker queries a prediction API to reconstruct the model (or a functional equivalent). Two regimes (Jagielski et al., 2020): high accuracy (a copy that predicts well on the task — functional counterfeiting) or high fidelity (a copy that imitates the boundary, including its errors — to build transferable adversarial examples).
Proposition 8.2 — Exact extraction of a logistic regression (Tramèr et al., 2016) If the API exposes \(p(y=1 \mid x) = \sigma(w^\top x + b)\), then \(d + 1\) queries on linearly independent \(x\)'s suffice to recover \((w, b)\) exactly.
From \(p = \sigma(w^\top x + b)\), one gets \(\mathrm{logit}(p) = \log \frac{p}{1-p} = w^\top x + b\) (the API gives \(p\), the logit is a function of \(p\)). Each query therefore provides a linear equation in \((w, b)\); with \(d+1\) independent points (with affine coordinate 1), the linear system has a unique solution. If the API rounds the probabilities, each equation becomes a bounding interval — one solves by linear programming, with a polynomial number of additional queries. ∎
Definition 8.3 — Membership inference (MIA, Shokri et al., 2017) The attacker wants to decide whether an individual \((x, y)\) was part of the training set — a confidentiality attack (membership itself can be sensitive: medical record, fraud). Canonical attack: train shadow models on similar data, label member/non-member, learn this membership classifier on the confidence scores. Modern version (Carlini et al., 2022, "LiRA"): likelihood ratio test — for each target, an ensemble of shadow models with/without the target estimates the two logit densities \(\mathcal{N}(\mu_{in}, \sigma_{in}^2)\), \(\mathcal{N}(\mu_{out}, \sigma_{out}^2)\); the optimal test is applied. Honest metric: TPR at low FPR (0.1\%) — that is where membership is dangerous.
Defenses and links Reduce the exposed precision (top-1 only, rounding — partial effectiveness, cf. prop. 8.2), limit/monitor queries (model stealing is a volume attack), model watermarking (cf. LLMs / Explainability-Security-Privacy module ch. 9); the only strong guarantee is training-time DP (DP-SGD, cf. Emerging ML module ch. 5; Privacy and Uncertainty M2 module): an \((\varepsilon, \delta)\) bounds the advantage of any MIA — at the price of a utility loss to be budgeted. MIA is also the auditing tool for synthetic data (cf. Boosting/Foundation Tabular module ch. 8): same box, same tool, two communities.
