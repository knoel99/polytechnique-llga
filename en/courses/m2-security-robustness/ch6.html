6. Trojans and backdoors

Definition 6.1 — Backdoor / Trojan horse (Gu et al., 2017) A backdoored model \(f\) behaves normally on clean inputs, but an \(\mathcal{A}(x)\) carrying the trigger (patch, high-frequency pattern, watermark) is classified into the target class: $$ f(x) \approx f_{clean}(x) \ \text{on the clean distribution}, \qquad f(x + \tau) = t \ \text{almost always}. $$ Unlike evasion (ch. 2-3), the attack is cast into training: BadNets obtains it by contaminating a fraction of the training data (legitimate examples + trigger + target label) — validation accuracy remains excellent, which makes the contamination undetectable by standard metrics.
Example 6.2 — Clean-label (Shafahi et al., 2018) "Poison Frogs": the attacker controls no labels. One fabricates a single poisoned example: starting from an image of the target class \(t\), it is optimized to enter into a feature collision with the victim image (close in the latent space of a pre-trained network) while remaining visibly of class \(t\). After fine-tuning, the victim (a clean image!) is classified as \(t\). A single data point suffices in transfer — the worst nightmare of collaborative data pipelines; cf. Emerging ML module ch. 4 for the federated case (malicious clients) and ch. 7 for poisoning at scale.
Definition 6.3 — Detection: trigger reverse-engineering (Neural Cleanse, Wang et al., 2019) For each class \(c\), one optimizes the minimal perturbation \(\delta_c\) that forces all inputs toward \(c\); a backdoored model exhibits an anomaly: for the target class \(t\), \(\|\delta_t\|_1\) is noticeably smaller (the existing trigger provides a "shortcut"). The anomaly is detected by median absolute deviation (MAD), the trigger is reconstructed, then one repairs: pruning the hyperactive neurons under the trigger, or fine-tuning/unlearning on the reconstructed inputs.
Limits and practice Existing defenses assume small, fixed, patch-shaped triggers: adaptive triggers (distributed, input-dependent, semantic — "a cap" — or sample-specific) escape reverse-engineering. The second family of detection is spectral (Spectral Signatures, Tran, Li & Madry, NeurIPS 2018): backdoored examples form a cluster in the space of last-layer activations — outliers are isolated in the principal directions (SVD of the activation matrix) and removed from the training set; complementary to reverse-engineering (it assumes no trigger shape), but broken by attacks that minimize their spectral signature. Deployment rules: traceable data chain, audited source models, dedicated tests ("does the model react oddly to this pattern?"), and above all monitoring the region around the model (ch. 10); cf. Explainability, Security and Privacy of LLMs module ch. 5 for the LLM variant (instruction poisoning).
