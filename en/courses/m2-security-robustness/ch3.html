3. Optimization-based attacks: FGSM, PGD, CW, AutoAttack

Definition 3.1 — The evasion problem Untargeted attack with budget \(\varepsilon\) (norm \(p\)): $$ \max_{\delta}\ \ell(f_\theta(x + \delta),\, y) \quad \text{subject to}\quad \|\delta\|_p \leq \varepsilon,\ x + \delta \in [0,1]^d, $$ where \(\ell\) is the cross-entropy. Targeted version: maximize \(\ell(f(x+\delta), y) - \ell(f(x+\delta), t)\) (push the target class \(t\) up and the true one down). The whole difficulty is the non-concave inner max — it cannot be evaluated exactly, only lower-bounded (attacks) or overestimated.
Theorem 3.2 — FGSM = linearization of the problem (Goodfellow et al., 2015) To first order in \(\delta\), \(\ell(x + \delta) \approx \ell(x) + \nabla_x \ell(x)^\top \delta\). The maximum of this linear approximation over the \(L_\infty\) ball is attained at $$ \delta^\star = \varepsilon\, \mathrm{sign}\big(\nabla_x \ell(x)\big) \qquad (\text{Fast Gradient Sign Method}), $$ with increase \(\varepsilon\, \|\nabla_x \ell(x)\|_1\). Over the \(L_2\) ball: \(\delta^\star = \varepsilon\, \nabla_x \ell(x) / \|\nabla_x \ell(x)\|_2\) (FGM).
Hölder: for every \(\delta\) with \(\|\delta\|_\infty \leq \varepsilon\), \(g^\top \delta \leq \sum_j |g_j|\,|\delta_j| \leq \varepsilon \sum_j |g_j| = \varepsilon \|g\|_1\), with \(g = \nabla_x \ell(x)\). There is equality iff \(|\delta_j| = \varepsilon\) and \(\mathrm{sign}(\delta_j) = \mathrm{sign}(g_j)\) for every nonzero \(j\) — which is exactly \(\delta^\star\). For \(L_2\): Cauchy-Schwarz \(g^\top\delta \leq \|g\|_2\|\delta\|_2 \leq \varepsilon\|g\|_2\), equality iff \(\delta\) is collinear with \(g\). ∎
Definition 3.3 — PGD (Madry et al., 2018) The linearization is only valid locally; one iterates while re-projecting onto the ball and onto \([0,1]^d\) (projection \(=\) clamping \(\min(\max(x+\delta - \varepsilon, x - \varepsilon), x + \varepsilon)\) for \(L_\infty\)): $$ \delta^{(k+1)} = \Pi_{B_\infty(\varepsilon)}\Big(\delta^{(k)} + \alpha\, \mathrm{sign}\big(\nabla_x \ell(x + \delta^{(k)})\big)\Big), \qquad \delta^{(0)} \in \{\,0,\ \text{or uniform in } B_\infty(\varepsilon)\,\}, $$ with step size \(\alpha \approx 2.5\,\varepsilon/K\) for \(K\) iterations, and multiple restarts (the inner objective is non-concave: several starting points are sampled). PGD is the qualitative standard: "robust to PGD" has become a (too convenient) synonym for robust.
Definition 3.4 — CW (Carlini & Wagner, 2017) Attack optimized on the logit margin \(Z(x)\), with the change of variable \(\delta = \tfrac{1}{2}(\tanh(w) + 1) - x\) to get rid of the box constraints: $$ \min_{w}\ \Big\| \tfrac{1}{2}(\tanh(w)+1) - x \Big\|_2^2 + c \cdot \max\big(Z(x+\delta)_y - \max_{t \neq y} Z(x+\delta)_t,\ -\kappa\big), $$ with a bisection search over \(c\) and confidence \(\kappa \geq 0\). CW-L2 long remained the most effective attack — and the tool that demolished the first generation of defenses (ch. 4).
Black box and standard evaluation Without gradients: (i) transfer (ch. 2); (ii) score-based attacks (gradient estimation by queries, random square attacks); (iii) decision-based attacks (random walk on the boundary). For evaluation, one no longer uses a single isolated attack but AutoAttack (Croce & Hein, 2020): a parameter-free ensemble — APGD-CE, APGD-T, FAB-T, Square — which cuts the displayed "robustness" of several defended models by more than 10 points. Rule of the module: any robustness measure is worth exactly the worst attack that has been tried. 
# FGSM and PGD in about ten lines (PyTorch)
def fgsm(model, x, y, eps):
    x.requires_grad_(True)
    loss = F.cross_entropy(model(x), y)
    loss.backward()
    return (x + eps * x.grad.sign()).clamp(0, 1).detach()

def pgd(model, x, y, eps, alpha, iters, restarts=1):
    worst, worst_loss = None, float("-inf")
    for _ in range(restarts):
        d = torch.zeros_like(x).uniform_(-eps, eps)      # random start
        for _ in range(iters):
            d.requires_grad_(True)
            loss = F.cross_entropy(model((x + d).clamp(0, 1)), y)
            g = torch.autograd.grad(loss, d)[0]          # gradient of the inner max
            with torch.no_grad():
                d = (d + alpha * g.sign()).clamp(-eps, eps)
        x_adv = (x + d).clamp(0, 1).detach()
        l = F.cross_entropy(model(x_adv), y).item()      # candidate loss
        if l > worst_loss:                               # keep the worst case
            worst, worst_loss = x_adv, l
    return worst
