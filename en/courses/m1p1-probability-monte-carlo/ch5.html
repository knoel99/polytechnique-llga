5. Simulating: inverse, rejection, Box-Muller

Proposition 5.1 — Inverse transform method (proved) Let \(F\) be a cumulative distribution function and \(F^{-1}(u) = \inf\{x : F(x) \geq u\}\) (generalized inverse). If \(U \sim \mathcal{U}[0,1]\), then \(X = F^{-1}(U)\) has distribution \(F\).
\(F^{-1}(u) \leq x\) is equivalent to \(u \leq F(x)\) (property of the infimum); hence \(\mathbb{P}(F^{-1}(U) \leq x) = \mathbb{P}(U \leq F(x)) = F(x)\).∎
Application: \(X = -\ln U \sim \mathcal{E}(1)\) (distribution \(1-e^{-x}\)), and \(X = \lfloor nU \rfloor + 1\) is uniform on \(\{1,\dots,n\}\). Conversely, every algorithm producing "random reals" on a machine truncates a uniform distribution — the only primitive source (together with physical generators) of the whole chapter.
Proposition 5.2 — Rejection method (correction proved) Let \(f\) be the target density (with respect to \(\lambda\)), and \(g\) a proposal density such that \(f \leq M g\) with \(M < \infty\). Algorithm: draw independent \(X \sim g\), \(U \sim \mathcal{U}[0,1]\); accept if \(U \leq f(X)/(Mg(X))\), otherwise start over. Then:
  • the acceptance probability at each trial equals \(1/M\);
  • the distribution of \(X\) conditional on acceptance is exactly \(f\).
For every Borel set \(A\): $$\mathbb{P}(X \in A,\ \text{accepted}) = \int_A g(x)\, \frac{f(x)}{Mg(x)}\,dx = \frac{1}{M}\int_A f(x)\,dx = \frac{\pi_f(A)}{M},$$ where we used the independence of \(U\) and \(X\) and then Fubini. Taking \(A = \mathbb{R}\): \(\mathbb{P}(\text{accepted}) = 1/M\). By Bayes' formula, \(\mathbb{P}(X \in A \mid \text{accepted}) = \frac{\pi_f(A)/M}{1/M} = \pi_f(A)\).∎
The number of trials follows a geometric distribution with parameter \(1/M\) (expectation \(M\)): all the art lies in choosing \(g\) close to \(f\) to minimize \(M\).
Example 5.3 — Simulating \(\mathcal{N}(0,1)\) with a Laplace proposal (numbers) Proposal: \(g(x) = \tfrac12 e^{-|x|}\). The ratio \(\frac{f(x)}{g(x)} = \sqrt{2/\pi}\; e^{-x^2/2 + |x|}\) is maximal at \(|x|=1\), where \(-x^2/2+|x| = 1/2\): \(M = \sqrt{2e/\pi} \approx 1.3155\), acceptance rate \(1/M = \sqrt{\pi/(2e)} \approx 76\,\%\). On average 1.31 proposals per accepted sample: very efficient, and requiring no knowledge of the normalization constant of \(f\) (a truncated distribution, for instance). It is the mechanism behind most generators of "exotic" distributions.
Proposition 5.4 — Box-Muller (proved by change of variables) Let \(U,V\) be i.i.d. \(\mathcal{U}[0,1]\). Set \(R = \sqrt{-2\ln U}\) and \(\Theta = 2\pi V\). Then \(Z_1 = R\cos\Theta\) and \(Z_2 = R\sin\Theta\) are i.i.d. \(\mathcal{N}(0,1)\).
\(\mathbb{P}(R \leq r) = \mathbb{P}(U \geq e^{-r^2/2}) = 1 - e^{-r^2/2}\), density \(f_R(r) = r e^{-r^2/2}\) (Rayleigh), independent of \(\Theta\) (uniform). The pair has density \(f_{R,\Theta}(r,\theta) = \frac{r}{2\pi} e^{-r^2/2}\) on \((0,\infty) \times (0,2\pi)\). Inverse polar change of variables \((r,\theta) \mapsto (x,y) = (r\cos\theta, r\sin\theta)\), with Jacobian \(\left|\det \frac{\partial(x,y)}{\partial(r,\theta)}\right| = r\) (direct computation): the density of the pair \((Z_1,Z_2)\) equals $$f_{Z_1,Z_2}(x,y) = \frac{f_{R,\Theta}(r,\theta)}{r} = \frac{1}{2\pi} e^{-(x^2+y^2)/2},$$ which is the product of the two densities \(\varphi(x)\varphi(y)\): independence and Gaussian marginals.∎
Example 1.5 (the Gaussian integral) provides the constant \(\frac{1}{2\pi}\): the chapters echo one another. 
import numpy as np
rng = np.random.default_rng(42)

def box_muller(n):                      # n standard Gaussians (n even)
    u = rng.random(n // 2); v = rng.random(n // 2)
    r = np.sqrt(-2.0 * np.log(u)); t = 2.0 * np.pi * v
    return np.concatenate([r * np.cos(t), r * np.sin(t)])

def gaussian_rejection(n, m=1.3155):    # N(0,1) by rejection with Laplace
    out = []
    while len(out) < n:
        x = rng.laplace(0.0, 1.0)       # density (1/2) exp(-|x|)
        u = rng.random()
        if u < np.exp(-x*x/2.0) / (m * 0.5 * np.exp(-abs(x))):
            out.append(x)
    return np.array(out)

z1, z2 = box_muller(200000), gaussian_rejection(200000)
print(z1.mean(), z1.var())              # ~0.000 , ~1.000
print(z2.mean(), z2.var())              # ~0.001 , ~1.000

def mixture(n):                          # 0.4 N(-2,0.5^2) + 0.6 N(2.5,0.8^2)
    j = rng.random(n) < 0.6
    return np.where(j, 2.5 + 0.8*rng.standard_normal(n),
                       -2.0 + 0.5*rng.standard_normal(n))
Practice In production one uses rng.standard_normal (ziggurat, an optimized rejection variant) — but Box-Muller and rejection remain the pedagogical building blocks and the fallback tools when the target is no longer standard: truncated distributions, distributions with an unknown normalization constant (typical in the Bayesian setting, ch. 8). All the methods in the rest of the module are generalizations of this program: target known up to a constant → i.i.d. samples (rejection, IS) or correlated ones (MCMC).
