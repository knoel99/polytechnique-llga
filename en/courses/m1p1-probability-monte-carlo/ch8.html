8. MCMC: Metropolis-Hastings, Gibbs, diagnostics, annealing

Definition 8.1 — Metropolis-Hastings kernel Let \(\pi\) be a target density on \(E\) (known up to a constant: only \(\pi(x)\) is involved, never its total mass) and \(q(x,dy)\) a proposal kernel. The Metropolis-Hastings algorithm builds a Markov chain \((X_k)\): from \(X_k = x\), draw \(Y \sim q(x,\cdot)\) and \(U \sim \mathcal{U}[0,1]\); set $$X_{k+1} = \begin{cases} Y & \text{if } U \leq \alpha(x,Y),\\ x & \text{otherwise (rejection: the chain stays put),}\end{cases} \qquad \alpha(x,y) = \min\Big(1,\ \frac{\pi(y)\, q(y,x)}{\pi(x)\, q(x,y)}\Big),$$ where \(q(x,y)\) denotes the density of \(q(x,\cdot)\) at the point \(y\) (with respect to some fixed reference measure). Special cases: random walk MH (\(q(x,\cdot) = \mathcal{N}(x, s^2 I)\), \(q(y,x)=q(x,y)\) so \(\alpha = \min(1,\pi(y)/\pi(x))\)); independence sampler (\(q(x,\cdot) = g\) fixed); MALA (proposal derived from Langevin dynamics, ch. 9).
Theorem 8.2 — Detailed balance of the MH kernel (proved) The Metropolis-Hastings transition kernel, $$P(x,dy) = q(x,dy)\,\alpha(x,y) + \Big(1 - \int \alpha(x,z)\,q(x,dz)\Big)\,\delta_x(dy),$$ is \(\pi\)-reversible: \(\pi(dx)\,P(x,dy) = \pi(dy)\,P(y,dx)\). In particular \(\pi\) is invariant.
The rejection term charges only the diagonal \(\{x = y\}\), where the equality to be proved is trivial. For the acceptance term, set \(\rho(x,y) = \pi(x)\,q(x,y)\) (densities with respect to a common dominating measure, e.g. Lebesgue; the case of general kernels is written with the measures \(\pi(dx)q(x,dy)\) and treated identically). Let us verify that \(\rho(x,y)\,\alpha(x,y)\) is symmetric in \((x,y)\), by case analysis:
  • if \(\rho(y,x) \leq \rho(x,y)\): \(\alpha(x,y) = \rho(y,x)/\rho(x,y)\) and \(\alpha(y,x) = 1\), hence \(\rho(x,y)\alpha(x,y) = \rho(y,x) = \rho(y,x)\alpha(y,x)\);
  • if \(\rho(y,x) > \rho(x,y)\): symmetrically \(\alpha(x,y) = 1\) and \(\alpha(y,x) = \rho(x,y)/\rho(y,x)\), same conclusion.
In both cases \(\rho(x,y)\alpha(x,y) = \min(\rho(x,y), \rho(y,x))\), an expression symmetric in \((x,y)\): the detailed balance \(\pi(dx)P(x,dy) = \pi(dy)P(y,dx)\) is proved. Invariance: write \(\mu(dx,dy) = \pi(dx)\,q(x,dy)\,\alpha(x,y)\) (symmetric) and \(r(x) = \int q(x,dz)\alpha(x,z)\). For every Borel set \(A\), $$(\pi P)(A) = \mu(E \times A) + \int_A \big(1 - r(x)\big)\,\pi(dx).$$ By symmetry of \(\mu\), its marginal in the second variable equals \(\mu(E,dy) = \int \mu(dx,dy) = \int \mu(dy,dx) = \pi(dy)\,r(y)\), hence \(\mu(E\times A) = \int_A r\,d\pi\) and \((\pi P)(A) = \int_A r\,d\pi + \int_A (1-r)\,d\pi = \pi(A)\).∎
Only \(\pi\) being known up to a constant is required: if \(\pi = \tilde\pi/Z\), \(Z\) cancels in \(\alpha\) — hence the success of MH in Bayesian inference (see the Refresher Statistics module, chapter 8).
Proposition 8.3 — Gibbs = block-wise Metropolis-Hastings (proved) Let \(\pi\) be a density on \(\mathbb{R}^d\) and, for \(i \in \{1,\dots,d\}\), the full conditional distribution \(\pi(x_i \mid x_{-i})\). The Gibbs kernel for "coordinate \(i\)": \(x \to y = (x_{-i}, y_i)\) with \(y_i \sim \pi(\cdot \mid x_{-i})\), is an MH kernel with acceptance probability 1.
This is MH with the degenerate proposal \(q_i(x,dy) = \pi(y_i \mid x_{-i})\, \delta_{x_{-i}}(dy_{-i})\). The acceptance ratio between \(x\) and \(y\) (which differ only in coordinate \(i\)) equals $$\frac{\pi(y)\,\pi(x_i \mid y_{-i})}{\pi(x)\,\pi(y_i \mid x_{-i})} = \frac{\pi(y_{-i})\,\pi(y_i \mid y_{-i})\,\pi(x_i \mid y_{-i})} {\pi(x_{-i})\,\pi(x_i \mid x_{-i})\,\pi(y_i \mid x_{-i})} = 1,$$ since \(y_{-i} = x_{-i}\) (decomposition \(\pi(x) = \pi(x_{-i})\pi(x_i\mid x_{-i})\)). Hence \(\alpha \equiv 1\): we always accept, and detailed balance (Thm 8.2) guarantees the invariance of \(\pi\) for each sweep.∎
The systematic scan (coordinates 1 to \(d\)) or random scan (uniform coordinate) composes these kernels: a composition of \(\pi\)-invariant kernels is a \(\pi\)-invariant kernel. Gibbs is the building block of conditional Bayesian sampling (graphical models, mixture models — see the Machine Learning module, chapter 6, for the EM side).
Proposition 8.4 — Applied ergodic theorem and chain CLT (statements) If the MH kernel is \(\pi\)-irreducible and aperiodic (checked as soon as \(q\) charges a neighborhood of 0 or the rejection probability is nonzero):
  • ergodicity (Thm 4.3): \(\frac1n\sum_{k=1}^n h(X_k) \to \pi(h)\) a.s. for \(h \in L^1(\pi)\);
  • Markov chain CLT (under geometric reversibility): \(\sqrt n\,(\hat\mu_{\mathrm{MH}} - \pi(h)) \to \mathcal{N}(0, \sigma_{\mathrm{MH}}^2)\) with \(\sigma_{\mathrm{MH}}^2 = \mathrm{Var}_\pi(h(X_0)) + 2\sum_{k\geq1} \mathrm{Cov}_\pi(h(X_0), h(X_k))\): positive autocorrelation inflates the effective variance — hence the correction factor \(\tau = 1 + 2\sum_k \rho_k\) ("integrated autocorrelation time").
Definition 8.5 — Convergence diagnostics and chain ESS
  • Trace (trajectory of \((X_k)\) per coordinate): visible mixing, mode trapping (the chain stays stuck in one mode of a multimodal target);
  • Autocorrelogram: \(\rho_k\) as a function of the lag \(k\); slow decay = slow exploration;
  • Chain ESS: \(\mathrm{ESS} = n/\tau\) with \(\tau = 1 + 2\sum_{k=1}^{K}\rho_k\) (truncation by Geyer's heuristic); MCMC error bar \(\approx \hat\sigma_h \sqrt{\tau/n}\);
  • Gelman-Rubin \(\hat R\): several chains started from overdispersed initializations; convergence when the between-chain and within-chain variances balance (\(\hat R \to 1\), usual threshold 1.01-1.1);
  • acceptance rate: for random walk MH, the theoretically optimal scale is ~0.234 in high dimension (0.44 in dimension 1); a step that is too small explores slowly, too large rejects everything.
Proposition 8.6 — Simulated annealing (statement) To maximize \(U\) (or minimize \(-U\)), one samples \(\pi_T(x) \propto e^{U(x)/T}\) with a temperature \(T\) decreasing like \(T_k \sim c/\log k\): under this schedule (Hajek's theorem, stated), the chain converges to the set of global maxima; in practice \(T_k = T_0 \times 0.95^k\) (geometric, no guarantee). Annealing is the interface between sampling and optimization: high temperatures to explore, low ones to exploit — the same trade-off as the temperature schedules of diffusion models (ch. 9). 
import numpy as np
rng = np.random.default_rng(0)

# target: bimodal mixture 0.5 N(-2.5, 0.7^2) + 0.5 N(2.5, 0.7^2)
logpi = lambda x: np.logaddexp(-((x+2.5)**2)/(2*0.49),
                               -((x-2.5)**2)/(2*0.49))

def rw_mh(x0, n, s):
    x = np.empty(n); x[0] = x0; acc = 0
    for k in range(n-1):
        y = x[k] + s * rng.standard_normal()
        if np.log(rng.random()) < logpi(y) - logpi(x[k]):
            x[k+1] = y; acc += 1
        else:
            x[k+1] = x[k]
    return x, acc/n

x, rate = rw_mh(0.0, 200_000, 4.0)     # large step to jump between modes
print(f"acceptance {rate:.3f}, mean {x[1000:].mean():+.3f} (exact 0)")

def ess(z):                            # truncated positive autocorrelations
    z = z - z.mean(); n = len(z)
    acf = [1.0] + [np.corrcoef(z[:-k], z[k:])[0,1] for k in range(1, 200)]
    tau, s = 1.0, 0.0
    for k in range(1, len(acf), 2):    # Geyer pairs
        pair = acf[k] + acf[k+1] if k+1 < len(acf) else acf[k]
        if pair <= 0: break
        s += pair
    return n / (1 + 2*s)

print(f"ESS = {ess(x[1000:]):.0f} / 199000")
Example 8.7 — Reading an experiment (numbers) On the mixture above with \(s=4\) and \(n=2\times10^5\): acceptance rate \(\approx 0.28\) (close to the 0.234 target in dimension 1-2), empirical mean \(\approx \pm 0.03\) around the exact value 0, ESS \(\approx 3\,000\) (strong autocorrelation because inter-mode jumps are rare). With \(s = 0.7\): acceptance ~0.7 but mode trapping — the chain spends 10⁴ iterations in one mode (flat trace), \(\hat R\) far above 1 between two chains initialized in opposite modes. Diagnosis: ESS alone is not enough; several overdispersed chains are needed (reference [5]).
