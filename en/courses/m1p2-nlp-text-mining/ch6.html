6. Sequences: NER, HMM, CRF

Definition 6.1 — Sequence labeling Assign a label to each token: POS (grammatical category) or NER (named entities: PER, ORG, LOC…) in BIO ("Begin/Inside/Outside"): "Kim" = B-PER, "Noel" = I-PER. NER is the gateway to building knowledge graphs (entity + relation extraction).
HMM: forward, backward, Viterbi — the recurrences derived HMM: hidden states \(z_t\) (labels), emissions \(\mathbb{P}(w_t\mid z_t)\), transitions \(\mathbb{P}(z_t\mid z_{t-1})\). Notation: \(\alpha_t(z)=\mathbb{P}(w_1,\dots,w_t,\,z_t=z)\) (forward) and \(\beta_t(z)=\mathbb{P}(w_{t+1},\dots,w_T\mid z_t=z)\) (backward): $$\alpha_t(z)=\mathbb{P}(w_t\mid z)\sum_{z'}\alpha_{t-1}(z')\,\mathbb{P}(z\mid z'), \qquad \beta_t(z)=\sum_{z'}\mathbb{P}(z'\mid z)\,\mathbb{P}(w_{t+1}\mid z')\,\beta_{t+1}(z').$$
Forward: condition on \(z_{t-1}\). \(\alpha_t(z)=\sum_{z'}\mathbb{P}(w_{1:t},z_{t-1}=z',z_t=z) =\sum_{z'}\underbrace{\mathbb{P}(w_{1:t-1},z_{t-1}=z')}_{\alpha_{t-1}(z')} \,\mathbb{P}(z\mid z')\,\mathbb{P}(w_t\mid z)\) — Markovian: the past depends only on \(z_t\). Backward: symmetric, conditioning on \(z_{t+1}\). Uses: likelihood \(\mathbb{P}(w_{1:T})=\sum_z \alpha_T(z)\); marginal posteriors \(\mathbb{P}(z_t\mid w)=\alpha_t(z)\beta_t(z)/\mathbb{P}(w)\) — this is the E-step of an EM to train the HMM (ML module). All in \(\mathcal{O}(T K^2)\). ∎
Algorithm 6.2 — Viterbi: optimality by substructure The most likely label path satisfies the recursion $$\delta_t(z) = \max_{z'} \big[\delta_{t-1}(z')\, \mathbb{P}(z \mid z')\big]\ \mathbb{P}(w_t \mid z),\qquad \delta_0(z)=\mathbb{P}(z)\mathbb{P}(w_1\mid z),$$ and the optimal labeling is read off by backtracking the argmaxes — \(\mathcal{O}(T K^2)\) instead of \(\mathcal{O}(K^T)\).
Optimality: any optimal path arriving at \((t,z)\) has an optimal prefix up to \((t-1,z')\) — otherwise replacing the prefix with a better one increases the total probability (exchange argument: the future factors depend only on \(z\), Markovian). So it suffices to follow the best predecessor: this is Bellman (RL module, ch. 2) on a Markov chain, with max instead of expectation. ∎
CRF (Lafferty et al., 2001): the discriminative approach An HMM models \(\mathbb{P}(w,z)\) jointly (generative); a CRF models \(\mathbb{P}(z\mid w)\) directly: $$\mathbb{P}(z\mid w)=\frac{\exp\big(\sum_{t}\theta^\top f(z_{t-1},z_t,w,t)\big)}{Z(w)}, \qquad \nabla_\theta \log\mathbb{P} = \mathbb{E}_{p(z\mid w)}[f]-f(z^\star)$$ — arbitrary features over the whole sequence: word identity, suffixes, capitalization, shape of the neighbor, hyphen, position…, plus transition features \(z_{t-1}\to z_t\) (which forbid O→I-PER: an entity start must be B). Inference: forward-backward for \(Z(w)\) and the feature expectation; Viterbi for prediction. The gain over HMM: no "waste" in modeling the words, rich features, arbitrary interactions — long the state of the art for NER (CoNLL-2003).
BIO decoding and entity-level NER evaluation Per-token predictions must be converted into spans: an entity = a B-X (I-X)* sequence. Entity evaluation (not token): an entity is correct iff both type and exact boundaries match; $$\mathrm{P}=\frac{\#\text{correct}}{\#\text{predicted}},\qquad \mathrm{R}=\frac{\#\text{correct}}{\#\text{gold}},\qquad F_1=\frac{2PR}{P+R}.$$ Token-level F1 (lenient about boundaries) always overestimates entity-level F1 — always report entity-level F1 (the conlleval standard). Industrial reflex: audit boundary errors ("Banque de France" truncated) separately from type errors (PER vs ORG).
Today Transformers label token by token (per-token softmax + BIO decoding; the head is often a linear-chain CRF or a simple softmax with BIO constraints in post-processing); the spaCy and transformers libraries (the ner pipeline) deliver the state of the art in a few lines; the lab builds an entity-relation extractor that feeds the mini-GraphRAG of the Graph ML module — ch. 8 of this course for the full pipeline. 
# Toy Viterbi: 2-state POS tagging (N noun, V verb), 4-word vocabulary
import numpy as np
W = ["le", "chat", "mange", "souris"]
p_z0  = np.array([.9, .1])                      # P(z1)
A     = np.array([[.8,.2],[.3,.7]])             # P(z_t | z_{t-1})  rows=prev
B     = np.array([[.6,.3,.02,.08],
                  [.0,.02,.9,.08]])             # P(w | z)  columns=words
seq   = [0,1,2,3]                               # "le chat mange souris"

delta = B[:, seq[0]] * p_z0                     # initialization
back  = []
for w in seq[1:]:
    m = delta[:, None] * A * B[:, w][None, :]   # (prev, cur)
    back.append(m.argmax(0)); delta = m.max(0)
z = [delta.argmax()]
for bp in reversed(back): z.append(bp[z[-1]])
print("etiquettes :", [["N","V"][i] for i in reversed(z)])
