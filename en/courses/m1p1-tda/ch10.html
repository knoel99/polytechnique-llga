10. Hands-on: GUDHI, scikit-tda, ripser

Three tools cover the workflow: GUDHI (complexes), ripser (fast Rips) and scikit-tda (persim: distances, visualizations). The lab: making the canonical shapes speak — circle, two circles, sphere, torus, noise — then measuring stability.

# Lab 1 -- Rips persistence with GUDHI: the noisy circle
import numpy as np, gudhi
from gudhi import RipsComplex

t = np.linspace(0, 2*np.pi, 200, endpoint=False)
X = np.stack([np.cos(t), np.sin(t)], 1) + 0.05*np.random.randn(200, 2)

rips = RipsComplex(points=X, max_edge_length=2.0)
st = rips.create_simplex_tree(max_dimension=2)
st.compute_persistence(homology_coeff_field=2, min_persistence=0)

dgm = {k: st.persistence_intervals_in_dimension(k) for k in (0, 1)}
h1 = dgm[1][np.argsort(dgm[1][:, 1] - dgm[1][:, 0])[-1]]   # longest H1 bar
print("main hole: birth %.3f, death %.3f" % tuple(h1))
# expected: birth ~1.0 (radius), death ~2.0 (diameter) -- cf. example 5.2
gudhi.plot_persistence_barcode(st.persistence()); gudhi.plot_persistence_diagram(st.persistence())
# Lab 2 -- ripser + persim: bottleneck and stability to resampling
from ripser import ripser
from persim import plot_diagrams, bottleneck

def sample_circle(n, r, sigma):
    t = np.random.rand(n) * 2*np.pi
    return np.stack([r*np.cos(t), r*np.sin(t)], 1) + sigma*np.random.randn(n, 2)

D0 = ripser(sample_circle(200, 1, .05))['dgms']
D1 = ripser(sample_circle(200, 1, .05))['dgms']
print("d_b(H1) =", round(bottleneck(D0[1], D1[1]), 3))   # ~ 0.05-0.1: order of the noise

# vary sigma: d_b grows linearly -- numerical illustration of th. 6.1
for sigma in (.01, .05, .1, .2):
    D = ripser(sample_circle(200, 1, sigma))['dgms']
    print(f"sigma={sigma:4.2f}  d_b={bottleneck(D0[1], D[1]):.3f}")
# Lab 3 -- landscapes and classification (sklearn): circle vs two circles
from gudhi.representations import Landscape, DiagramSelector
from sklearn.svm import SVC
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

def diag(n):
    """returns the H1 diagram of a cloud: 1 or 2 random circles"""
    k = np.random.randint(2) + 1
    pts = [sample_circle(n, r, .05) + np.random.randn(2)*2.5 for r in (.6, 1.3)][:k]
    return ripser(np.concatenate(pts))['dgms'][1]

X = [diag(100) for _ in range(60)]                 # 60 H1 diagrams
y = [1 if sum(p[1] - p[0] > .3 for p in d) > 1 else 0 for d in X]
                                                  # label = 2 circles iff 2 long bars
vec = make_pipeline(DiagramSelector(), Landscape(num_landscapes=3, resolution=100))
model = make_pipeline(vec, SVC(kernel='rbf'))
print(cross_val_score(model, [[d] for d in X], y, cv=5).mean())  # expected ~ 1.0
Points of attention
  1. max_edge_length truncates the filtration: classes not dead at the end are essential (death = inf), not bugs.
  2. Memory: limit max_dimension to 2 (or 3 for H2); the number of simplices grows like \(n^{k+1}\); ripser never materializes the boundary matrix — that is its strength (Bauer, 2021).
  3. Choice of field: homology_coeff_field=2 by default; try 3 to detect torsion on exotic examples.
  4. Consistency with the course: on Example 4.5, rebuild the filtration by hand (gudhi.SimplexTree, ordered insertion) and verify that persistence() returns exactly the pairs (2,5), (3,6), (4,7), (8,9) and the essential ones 1, 10 — exercise 4 of the lab.
