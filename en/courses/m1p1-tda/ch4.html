4. Persistent homology: the algorithm

Let us come back to the data. At which scale \(\varepsilon\) should we build the Rips complex? Too small: dust of points. Too large: one contractible ball. The answer of persistence: all scales at once, with a ledger that records, for each topological feature, its birth and its death. Features that live long are the "true hole" candidates; ephemeral ones are noise.

Definition 4.1 — Filtration and persistence module A filtration of a complex \(K\) is an increasing family $$\emptyset = K_{-1} \subseteq K_0 \subseteq K_1 \subseteq \dots \subseteq K_m = K$$ (each \(K_i\) is a subcomplex of \(K_{i+1}\)). In practice: we order the simplices \(\sigma_1 < \sigma_2 < \dots < \sigma_m\) by increasing value of a function \(\varphi\) (appearance distance in the Rips complex, gray level of an image, elevation of a terrain), faces before cofaces, and \(K_i = K_{i-1} \cup \{\sigma_i\}\). The persistence module is the family of spaces and linear maps $$H_k(K_0) \to H_k(K_1) \to \dots \to H_k(K_m)$$ induced by the inclusions. It is tame if these spaces are finite-dimensional — which the finiteness of \(K\) guarantees.
Theorem 4.2 (interval decomposition) Every tame persistence module over a field decomposes in a unique way (up to isomorphism and to the order of the factors) into a direct sum of interval modules \(\mathbb{I}[b, d)\): copies of the field placed at indices \(b \leq i < d\), connected by identities, zero elsewhere. The barcode is the multiset of these intervals \([b, d)\); each bar is a homology class born at \(b\) and dying at \(d\) (with \(d = \infty\) for essential classes).
(Structure, out of scope: this is Gabriel's theorem for quivers of type \(\mathbb{A}\) — the module is a representation of the linear quiver \(0 \to 1 \to \dots \to m\), all its indecomposable representations are the \(\mathbb{I}[b, d)\), and the decomposition is unique because the quiver is of finite type. Oudot's book, ch. 9, gives a self-contained proof — cf. ch. 9 of this module. ∎
Definition 4.3 — Boundary matrix of a filtration and low index Number the simplices \(\sigma_1, \dots, \sigma_m\) in the order of the filtration. The boundary matrix \(M \in \mathbb{F}_2^{m \times m}\) is defined by \(M[i, j] = 1\) if \(\sigma_i\) is a proper face of \(\sigma_j\), and 0 otherwise (strictly upper triangular matrix: a face always precedes its coface). For a non-zero column, the low index is $$\mathrm{low}(j) = \max \{ i : M[i, j] = 1 \}.$$
Theorem 4.4 (standard persistence algorithm) Let \(R\) be the matrix obtained by reducing \(M\) column by column, from left to right: as long as \(\mathrm{low}(j)\) is defined and already occupied by an earlier column \(j' < j\) (i.e. \(\mathrm{low}(j') = \mathrm{low}(j)\)), replace \(R_{:, j} \leftarrow R_{:, j} + R_{:, j'}\). Then:
  1. each column \(j\) with \(\mathrm{low}(j) = i\) associates the pair \((i, j)\): a class born at index \(i\) (the simplex \(\sigma_i\)) dies at index \(j\) — bar \([i, j)\);
  2. each zero (reduced) column \(j\) encodes an essential class born at \(j\) — bar \([j, \infty)\);
  3. the total complexity is \(O(m^3)\) in the worst case, \(O(m^2)\) in practice on real data (columns already almost reduced).
Dimensional consistency. If \(\sigma_j\) is a \(k\)-simplex, its column lives in the rows of the \((k-1)\)-simplices: a pair \((i, j)\) always connects two consecutive dimensions (\(\sigma_i\) is a \((k-1)\)-simplex).

A pair \((i, j)\) is a birth-then-death. At step \(i\), the simplex \(\sigma_i\) either creates a class (if it completes an independent cycle), or kills one (if it completes a chain whose boundary becomes a trivial cycle). The algorithm reproduces this alternative: \(\sigma_i\) kills a class exactly when the reduced column of \(\sigma_j\) has \(\mathrm{low}(j) = i\), that is, when \(\partial \sigma_j\) contains \(\sigma_i\) as the last unpaired face — the class carried by the cycle \(\partial \sigma_j + (\text{already paired boundaries})\) was born with \(\sigma_i\).

Zero columns = essential births. If the reduced column of \(\sigma_j\) is zero, \(\sigma_j\) completes a cycle \(z = \sigma_j + \dots\) of which no face is "available" to kill it later: no future coface will have \(\sigma_j\) as low index in its reduction (reductions never eliminate pivots already used). The class lives until the end: bar \([j, \infty)\).

Uniqueness. The choice of pivots is forced: at each step, there is at most one earlier column with the same low index (invariant maintained by the algorithm), so the matching depends on no arbitrary choice — it coincides with the interval decomposition of Theorem 4.2. ∎ 
# Standard persistence algorithm (Edelsbrunner-Letscher-Zomorodian,
# Zomorodian-Carlsson), over F2. low[j] = row of the last 1 of column j.
def persistence(M):                        # M : m x m boundary matrix (bits)
    m = M.shape[1]
    R = M.copy()
    pairs = []
    for j in range(m):
        while True:
            nz = np.nonzero(R[:, j])[0]
            if len(nz) == 0:
                pairs.append(None)         # zero column: bar [j, inf)
                break
            low = nz[-1]
            prev = [jj for jj in range(j)
                    if pairs[jj] == low]   # pivot already used
            if not prev:
                pairs.append(low)          # pair (low, j): bar [low, j)
                break
            R[:, j] ^= R[:, prev[0]]       # column addition (XOR in F2)
    return [(i, j) for j, i in enumerate(pairs) if i is not None]

Reduction, column by column.
  • Column 5: \(\{1, 2\}\), \(\mathrm{low} = 2\). No earlier pivot: pair \((2, 5)\). The component born with \(v_2\) dies when edge \([v_1v_2]\) merges it.
  • Column 6: \(\{2, 3\}\), \(\mathrm{low} = 3\) — pair \((3, 6)\). Likewise for \(v_3\).
  • Column 7: \(\{3, 4\}\), \(\mathrm{low} = 4\) — pair \((4, 7)\). Likewise for \(v_4\).
  • Column 8: \(\{1, 3\}\), \(\mathrm{low} = 3\): conflict with column 6. We add: \(\{1,3\} \oplus \{2,3\} = \{1,2\}\), \(\mathrm{low} = 2\): conflict with column 5. We add: \(\{1,2\} \oplus \{1,2\} = \emptyset\): zero column — a class of \(H_1\) is born at index 8 (the loop \(v_1 \to v_2 \to v_3 \to v_1\)). No pivot is destroyed: the existing matching is unchanged.
  • Column 9: \(\{5, 6, 8\}\), \(\mathrm{low} = 8\). Is pivot 8 occupied? Column 8 is now zero — it occupies nothing: no conflict, pair \((8, 9)\). The loop born at 8 is killed by the triangle \([v_1v_2v_3]\).
  • Column 10: \(\{1, 4\}\), \(\mathrm{low} = 4\): conflict with column 7 → \(\{1,4\} \oplus \{3,4\} = \{1,3\}\), \(\mathrm{low} = 3\): conflict with column 6 → \(\{1,3\} \oplus \{2,3\} = \{1,2\}\), \(\mathrm{low} = 2\): conflict with column 5 → \(\{1,2\} \oplus \{1,2\} = \emptyset\) — zero column: a class of \(H_1\) is born at 10 (the loop \(v_1 \to v_3 \to v_4 \to v_1\)) and never dies.
Final barcode. $$H_0 : [1, \infty),\; [2, 5),\; [3, 6),\; [4, 7) \qquad H_1 : [8, 9),\; [10, \infty).$$ Checks. (i) At the end, \(\beta_0 = 1\) and \(\beta_1 = 1\), consistent with the final graph (connected, two independent cycles — formula 3.4: \(m - n + c = 5 - 4 + 1 = 2\), one of which is killed by the triangle). (ii) Euler characteristic of the final complex: \(4 - 5 + 1 = 0 = \beta_0 - \beta_1\) (Theorem 3.7). (iii) Bar count: 4 H0 births (4 vertices), 3 H0 deaths (3 merging edges — the 4th edge \([v_1v_3]\) creates a loop instead of merging), 2 H1 births, 1 H1 death (the triangle). Everything connects.
From Euler to barcodes, and back The Euler–Poincaré characteristic can be reread through the algorithm: at filtration level \(i\), \(\chi(K_i)\) is the number of active H0 bars minus the number of active H1 bars, etc. The Betti curve \(\beta_k(i)\) — number of active bars — is a discrete summary of the barcode, strictly less fine but sometimes sufficient (and directly related to the counting functions of ch. 5). Remember: the barcode is the dynamic version of homology; the plain homology of ch. 3 is its slice frozen at \(i = m\).
Variants and limits (general culture) The "faces before cofaces" constraint makes the filtration increasing; to free oneself from it, one uses zigzag persistence (Carlsson, de Silva, Morozov): the arrows alternate left-right, and the algorithm is rewritten with "in-out" columns. For vector-valued functions, one enters multi-dimensional persistence — where Theorem 4.2 fails: no complete discrete barcode (Carlsson–Zomorodian negative structure theorem).
