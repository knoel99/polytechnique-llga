5. Memory efficiency: checkpointing, ZeRO, mixed precision

Theorem 5.1 — Activation checkpointing: \(O(\sqrt{L})\) memory (proved) A network of depth \(L\), activations \(a\) bytes per layer (per token/batch): (i) without precautions, the backward pass requires \(M_\mathrm{full} = L\,a\) bytes of activations; (ii) by storing only the inputs of a partition into \(\sqrt{L}\) segments of \(\sqrt{L}\) layers and recomputing each segment during the backward pass (gradient checkpointing, Chen et al. 2016): $$M_\mathrm{ckpt} \;\approx\; 2\sqrt{L}\,a \;+\; O(a), \qquad \text{additional cost} \approx +\tfrac{1}{3}\ \text{of time (one extra forward pass per segment).}$$
Memory. We store \(\sqrt L\) boundary activations; during the backward pass of a segment, we replay its local forward: at most \(\sqrt L\) simultaneous activations inside the segment (which can itself be recursively checkpointed: the memory/time trade-off can be tuned over the whole range \([a, La]\), see the \(\sqrt\) "compass"). Total \(\sqrt L + \sqrt L = 2\sqrt L\) live activations. Time. Each layer is recomputed exactly once more in the forward direction: the forward pass accounts for \(1/3\) of the total cost (theorem 1.3: 2ND vs 6ND), hence about +33%. ∎
Definition 5.2 — ZeRO (Rasley et al. 2020): partitioning the states Instead of replicating the training states on every GPU (classical DP: \(16N\) bytes per GPU), ZeRO partitions them:
StageWhat is partitionedMemory/GPU (states)Communication
ZeRO-1Adam states (\(m, v\), masters): 12N\(4N + 12N/P\)= DP
ZeRO-2+ gradients (\(2N\))\(4N + 14N/P\)= DP
ZeRO-3+ weights (\(2N\))\(16N/P\)slightly > DP (on-the-fly gathers)
Example 7B on 8 GPUs: ZeRO-3 brings the states down to \(112/8 = 14\) GB per GPU — the model becomes trainable on a single node, without TP or pipeline bubble (ch. 3); DeepSpeed/FSDP implement exactly this continuum.
Mixed precision: the "free" compression Computing in bf16 (2 bytes) instead of fp32 (4): half the memory and (on tensor cores) 2–8× the throughput; fp32 is kept for accumulators and master weights (long sums and small updates; historical fp16 additionally required loss scaling — see the Deep Learning module, ch. 10). Theorem 1.3 remains valid: we count FLOPs, precision changes the price of a FLOP. Integer quantization (int8/int4) only serves inference — ch. 6; its error analysis is in the Optimization and Responsible AI for Sustainability module, ch. 3 (proved proposition: error \(\leq \sum_\ell \frac{\Delta_\ell}{2}\prod_{m>\ell}\mathrm{Lip}_m\)).
