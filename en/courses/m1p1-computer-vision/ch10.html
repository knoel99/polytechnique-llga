10. 3D point clouds: ICP and urban analysis

Mobile or airborne LiDAR, photogrammetry, RGB-D depth: the world also arrives as point clouds — millions of 3D points, possibly colored, with no topology. The questions become geometric: register two clouds, estimate normals, segment, classify.

Definition 10.1 — LiDAR: time-of-flight measurement A laser rangefinder emits a pulse and measures the echo: \(d = c\,\Delta t/2\) with \(c \approx 3\times10^8\) m/s. A precision of 2 cm requires timing to \(2\times0.02/(3\times10^8) \approx 0.13\) ns — and the echo is integrated over surfaces at varied incidence, hence the "comb" noise at edges. A mobile LiDAR (on a vehicle, IGN's Stéréopolis for example) combines rangefinders, cameras, and an inertial/GNSS unit: fused odometry (Kalman filter) gives the trajectory, each position adds a "cap" of points to the global cloud; an urban network easily produces \(10^9\) points.
Proposition 10.2 — Neighborhoods, normals, complexities On a cloud of \(n\) points: the nearest neighbor is obtained with a kd-tree (or octree in 3D) in \(O(\log n)\) on average (construction \(O(n\log n)\)) versus \(O(n)\) by brute force — with the same dimensional caveat as in ch. 4. The local normal at point \(p\) is estimated by PCA of the neighborhood: the eigenvector associated with the smallest eigenvalue of the covariance matrix \(\sum_{q \in \mathcal{N}(p)} (q - \bar q)(q - \bar q)^\top\) (the residual variance to the tangent plane is minimal — a direct consequence of the Eckart-Young theorem of ch. 0). Cost per point: \(O(k)\) once the neighborhood is found.
Theorem 10.3 — ICP: optimal rigid transform (Kabsch) Given two paired sets \(\{p_i\}, \{q_i\}\), \(i = 1..n\), seeking \(R \in SO(3)\) and \(t\) minimizing \(\sum_i \|R\,p_i + t - q_i\|^2\) has an exact solution: \(t = \bar q - R\bar p\) (centroids) and, setting \(H = \sum_i (p_i - \bar p)(q_i - \bar q)^\top = U\Lambda V^\top\) (SVD), \(R = V\,U^\top\) (and \(R = V\,\mathrm{diag}(1, 1, \det(VU^\top))\,U^\top\) if \(\det(VU^\top) = -1\), the "reflection" case).
The term in \(t\) is quadratic: setting the derivative to zero gives \(t = \bar q - R\bar p\). Substituting, the sum becomes \(\sum_i \|R\,\tilde p_i - \tilde q_i\|^2 = \sum \|\tilde p_i\|^2 + \sum\|\tilde q_i\|^2 - 2\sum \tilde q_i^\top R\tilde p_i\), where the \(\tilde{}\) denote centered points: minimizing amounts to maximizing \(\sum_i \tilde q_i^\top R \tilde p_i = \mathrm{tr}(RH)\). Now \(\mathrm{tr}(RH) = \mathrm{tr}(R\,U\Lambda V^\top) = \mathrm{tr}(\underbrace{V^\top R U}_{=\,Z}\,\Lambda) = \sum_i Z_{ii}\, \lambda_i\) with \(Z\) orthogonal, so \(Z_{ii} \leq 1\) and \(\lambda_i \geq 0\) give \(\mathrm{tr}(RH) \leq \sum_i \lambda_i\), attained for \(Z = I\), i.e. \(R = VU^\top\). The negative-determinant correction maximizes under the constraint \(\det R = +1\) by zeroing \(Z_{33}\) (smallest singular value). ∎
Proposition 10.4 — ICP: the algorithm and its local convergence ICP (Iterative Closest Point, Besl-McKay 1992) alternates: (1) matching: each point of \(P\) is associated with its nearest neighbor in \(Q\) (kd-tree, \(O(n\log n)\)); (2) alignment: optimal rigid transform of the pairs (Theorem 10.3); (3) application — until convergence.
The objective \(E(R, t) = \sum_i \|R p_i + t - \mathrm{nn}_Q(Rp_i + t)\|^2\) decreases at every iteration: step (1) can only improve (or leave unchanged) each term by choosing the current nearest neighbor, and step (2) exactly minimizes the sum over these fixed matches. Combination of a decreasing sequence bounded below (by 0): convergence — to a local minimum, depending on the initialization. ∎
Remedies: coarse initialization (GPS, global descriptors, RANSAC over quadruplets), rejected matches (distance > quantile, incompatible normals), the point-to-plane variant (minimize distances to tangent planes — once linearized, it gives a more precise 6×6 least squares), or robust formulations: trimmed ICP, robust optimal transport (see below).
Example 10.5 — ICP and matching in Python 
import numpy as np
from scipy.spatial import cKDTree

def best_rigid_transform(P, Q):            # theorem 10.3 (Kabsch)
    cp, cq = P.mean(0), Q.mean(0)
    H = (P - cp).T @ (Q - cq)              # 3x3
    U, S, Vt = np.linalg.svd(H)
    d = np.sign(np.linalg.det(Vt.T @ U.T))
    R = Vt.T @ np.diag([1, 1, d]) @ U.T
    return R, cq - R @ cp

def icp(P, Q, iters=50, tol=1e-7):
    tree = cKDTree(Q); R = np.eye(3); t = np.zeros(3); prev = np.inf
    for _ in range(iters):
        d, idx = tree.query(P @ R.T + t)          # (1) matching
        Rk, tk = best_rigid_transform(P, Q[idx])  # (2) Kabsch
        R, t = Rk @ R, Rk @ t + tk                # (3) accumulation
        err = np.mean(d**2)
        if prev - err < tol: break
        prev = err
    return R, t, np.sqrt(err)

# synthetic test: 25-degree rotation + 1 cm noise
rng = np.random.default_rng(0)
src = rng.normal(size=(3000, 3)) * [10, 10, 1]    # noisy "ground"
a = np.deg2rad(25)
Rt = np.array([[np.cos(a), -np.sin(a), 0],
               [np.sin(a),  np.cos(a), 0],
               [0, 0, 1]])
dst = src @ Rt.T + [2, -1, 0] + rng.normal(scale=.01, size=src.shape)
R, t, rms = icp(src, dst)
print("angle error (deg):", np.rad2deg(np.arccos((np.trace(R.T @ Rt)-1)/2)))
Note — ICP and optimal transport Replacing "nearest neighbor" with a global matching that minimizes a transport cost means reformulating registration as an optimal transport problem (the M1P2 module of the same master's program, ch. 1-2): the Wasserstein distance compares clouds as measures, not as labeled points — insensitive to differing densities, robust to noise with concave costs. This is the path explored by the recent literature on robust OT registration (RobOT, NeurIPS 2021; partial transport for incomplete clouds). The same formalism reappears to compare descriptor histograms or depth maps: a common language for ch. 6-10.
Proposition 10.6 — Representing a cloud for learning Three families of network inputs: (i) volumes (voxelize into a 3D grid — 3D convolutions possible but cubic cost; sparse trees/octrees for the worst case); (ii) raw points (PointNet: MLP per point + global max = symmetric function, permutation invariance; its successors add a local neighborhood); (iii) range images (range images: project the cloud onto a spherical image whose every pixel encodes the distance — 2D CNNs then apply as-is, see LU-Net in ch. 11). The choice is a memory/precision/speed trade-off — over \(10^9\) points, family (iii) is unbeatable and feeds the real-time systems of autonomous vehicles.
