5. Alternative architectures: SSM, Mamba, RWKV

Today's readings A. Gu, K. Goel, C. Ré, Efficiently Modeling Long Sequences with Structured State Spaces (S4), ICLR 2022 (arXiv:2111.00396); A. Gu & T. Dao, Mamba: Linear-Time Sequence Modeling with Selective State Spaces, 2023 (arXiv:2312.00752); B. Peng et al., RWKV: Reinventing RNNs for the Transformer Era, Findings of EMNLP 2023 (arXiv:2305.13048); S. De et al., Griffin: RecurrentGating Linear Networks (Hawk / Griffin), ICML 2024 (arXiv:2402.19427); AI21, Jamba: A Hybrid Transformer-Mamba Language Model, 2024 (arXiv:2403.19887).

5.1. From RNNs to state space models

Definition 5.1 — Discrete SSM A state space model maps the input \(u_t\) to the output \(y_t\) via a linear hidden state \(x_t \in \mathbb{R}^d\): $$x_{t} = \bar A\, x_{t-1} + \bar B\, u_t, \qquad y_t = C\, x_t,$$ where \((\bar A, \bar B)\) come from the (zero-order) discretization of the continuous system \(\dot x = A x + B u\) with step \(\Delta\): \(\bar A = \exp(\Delta A)\), \(\bar B = (\Delta A)^{-1}\bigl(\exp(\Delta A) - I\bigr)\,\Delta B\). The classic RNN reappears with a structured state matrix (S4: diagonal + low-rank terms, inherited from HiPPO to memorize the long history).
Proposition 5.2 — LTI ⇒ convolution (S4) If \((\bar A, \bar B, C)\) are constant (independent of time and input — LTI), then the system is a convolution product: $$y_t = \sum_{s=0}^{t} \overline{K}_s\, u_{t-s}, \qquad \overline{K} = \bigl(C\bar B,\; C\bar A \bar B,\; C\bar A^2 \bar B,\; \dots\bigr),$$ computable in \(\mathcal{O}(L \log L)\) via FFT (Signal Processing module): parallel training over the whole sequence, like a transformer.
Let us unroll the recurrence from \(x_{-1} = 0\) (zero initial state): \(x_0 = \bar B u_0\); \(x_1 = \bar A \bar B u_0 + \bar B u_1\); by immediate induction, \(x_t = \sum_{s=0}^{t} \bar A^{\,t-s}\, \bar B\, u_s\). Then \(y_t = C x_t = \sum_{s=0}^{t} (C \bar A^{\,t-s} \bar B)\, u_s = \sum_{s=0}^{t} \overline K_{t-s}\, u_s\) — a discrete convolution with kernel \(\overline K_s = C \bar A^s \bar B\), where the structure of \(\bar A\) (diagonal) makes each term computable in \(\mathcal{O}(d)\). ∎

5.2. Mamba: making the state selective

The LTI SSM is a fixed filter: it cannot choose to memorize or forget depending on the content. Mamba (Gu & Dao, 2023) makes \(\Delta_t, \bar B_t, C_t\) functions of the input (small MLPs on \(u_t\)): the selection. Cascade consequence: the convolution (prop. 5.2) is destroyed (the kernel depends on position) → back to a recurrence, but parallelizable via the prefix scan (associativity of \((\bar A_t, \bar B_t)\) — Blelloch's algorithm; cf. Refresher CS) with fused GPU kernels ("hardware-aware"): \(\mathcal{O}(L)\) training, \(\mathcal{O}(1)\) inference per token and constant state memory — the selling point against the transformer's KV cache (cf. ML Ops module ch. 3). Finally, Mamba embeds the SSM inside a gated MLP-style block. Mamba-2 (SSD) will reformulate the SSM × linear attention duality — the loop comes full circle with ch. 6.

5.3. RWKV and the hybrids

Proposition 5.3 — RWKV: linearizing attention into an RNN (Peng et al., 2023) RWKV rewrites attention as a recurrence with per-channel decay (time-mixing): $$w_t = \sigma(W_t)\odot w_{t-1} + k_t, \qquad y_t = r_t \odot \frac{v_t}{w_t + \epsilon},$$ (schematic form): the state \(w_t\) accumulates past values channel-wise with a learned exponential decay (\(r_t\) = receptance, \(v_t\) the step's value) — a linear attention normalized over time, trainable in parallel (like a transformer), executable as an RNN (constant memory). At scale: models up to 14B — the largest RNNs ever trained at its publication.

Hybrids: pure SSMs lose on exact recall tasks (copying an association seen a long time ago: the compressed state has no room to keep everything — a recurring critique, cf. the associative recall studies); hence mixed architectures: Jamba (AI21, 2024) interleaves attention + Mamba + MoE blocks (1:7:1) and shows that ~one attention layer in eight suffices to restore recall; Griffin/De et al. (2024) alternate recurrence (RG-LRU) and local attention. The 2024-2026 consensus: attention is irreplaceable for precise retrieval; the SSM excels at long context on a constant memory budget; the hybrid beats both.

Critical analysis (i) The "Mamba matches transformers at X times less memory" curves are established at calibrated data and compute sizes; transformers have an ecosystem (serving, quantization, ch. 6) that SSMs lack — the real adoption cost exceeds the paper. (ii) Exact recall is a limit case (one key among millions): needle-in-a-haystack-style benchmarks are highly sensitive to it, comprehension tasks far less so. (iii) RWKV illustrates the virtue of deployable simplicity (no KV cache, no keys/values); Mamba that of algorithmic design (the scan). (iv) A favorite exam question: "why is the transformer KV cache a feature and not just a cost?" — because it stores the history exactly (perfect recall), where the SSM state summarizes it.
