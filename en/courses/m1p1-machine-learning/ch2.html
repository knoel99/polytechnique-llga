2. Linear regression and regularization

2.1. Ordinary least squares

Definition 2.1 — Gaussian linear model One observes \(y = X\theta + \varepsilon\) where \(X \in \mathbb{R}^{n \times p}\) is fixed (the design), \(\theta \in \mathbb{R}^p\), and one assumes: (H1) \(\mathbb{E}[\varepsilon] = 0\); (H2) \(\mathrm{Var}(\varepsilon) = \sigma^2 I_n\) (homoscedasticity); (H3) independent components; (H4, optional) \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I_n)\). The least squares estimator minimizes \(\hat{\mathcal{R}}_n(\theta) = \tfrac1n \|y - X\theta\|^2\).
Proposition 2.2 — Normal equations If \(X^\top X\) is invertible, the unique minimizer is $$\hat\theta = (X^\top X)^{-1} X^\top y.$$
Expand \(\|y - X\theta\|^2 = \theta^\top X^\top X\,\theta - 2\,\theta^\top X^\top y + \|y\|^2\). The gradient in \(\theta\) is \(2X^\top X \theta - 2X^\top y\) (symmetric matrix for the quadratic term); setting it to zero gives the normal equations \(X^\top X\theta = X^\top y\). The Hessian \(2X^\top X \succeq 0\) is positive definite as soon as \(\mathrm{rank}(X) = p\): the function is strictly convex, the stationary point is the unique global minimum.∎
Geometry: an orthogonal projection \(\hat y = X\hat\theta = P y\) with \(P = X(X^\top X)^{-1}X^\top\) the orthogonal projection onto \(\mathrm{Im}(X)\). One checks \(P^2 = P = P^\top\); the residual \(e = y - \hat y\) satisfies \(X^\top e = 0\), i.e. \(e \perp \mathrm{Im}(X)\). The \(h_{ii} = P_{ii}\) (the leverages) measure the influence of each observation, with \(\sum_i h_{ii} = p\).
Theorem 2.3 — Gauss-Markov Under (H1)-(H3), for every \(c \in \mathbb{R}^p\), the estimator \(c^\top\hat\theta\) is the best linear unbiased estimator (BLUE) of \(c^\top\theta\): among the \(a^\top y\) with \(\mathbb{E}[a^\top y] = c^\top\theta\) for every \(\theta\), it has minimal variance.
A linear estimator \(a^\top y\) is unbiased for every \(\theta\) iff \(a^\top X = c^\top\). Set \(a_\star = X(X^\top X)^{-1}c \in \mathrm{Im}(X)\): \(a_\star^\top X = c^\top\), so \(a_\star\) is admissible, and \(\mathrm{Var}(a_\star^\top y) = \sigma^2 \|a_\star\|^2 = \sigma^2 c^\top(X^\top X)^{-1}c\), which is indeed the variance of \(c^\top\hat\theta\). Let \(a\) be any admissible vector and \(h = a - a_\star\); then \(h^\top X = 0\), so \(h \perp \mathrm{Im}(X) \ni a_\star\), hence $$\mathrm{Var}(a^\top y) = \sigma^2\|a\|^2 = \sigma^2\big(\|a_\star\|^2 + \|h\|^2\big) \geq \sigma^2\|a_\star\|^2 = \mathrm{Var}(c^\top\hat\theta),$$ with equality iff \(a = a_\star\).∎
Inference: confidence intervals (under H4) Under Gaussian noise, \(\hat\theta \sim \mathcal{N}\big(\theta,\ \sigma^2(X^\top X)^{-1}\big)\) (a linear variable of a Gaussian vector), and \(\hat\sigma^2 = \tfrac{1}{n-p}\|y - X\hat\theta\|^2\) is an unbiased estimator independent of \(\hat\theta\). Writing \(v_j = [(X^\top X)^{-1}]_{jj}\), the statistic \((\hat\theta_j - \theta_j)/(\hat\sigma\sqrt{v_j})\) follows a Student distribution with \(n - p\) degrees of freedom, giving the 95% confidence interval: $$\hat\theta_j \pm t_{0.975}^{\,n-p}\; \hat\sigma \sqrt{v_j}.$$ (Reminder on usual distributions: cf. Refresher Statistics module.) The (estimator, standard deviation) pair reported by any serious regressor is read here: a coefficient whose interval contains \(0\) is not "significant".
Residual analysis — the model's quality control The assumptions (H1)-(H4) are checked graphically on the residuals \(e_i = y_i - \hat y_i\) (standardized \(r_i = e_i/\big(\hat\sigma\sqrt{1 - h_{ii}}\big)\)): residuals vs fitted values (a curvature betrays a missing nonlinearity; a funnel, heteroscedasticity — think of transforming \(y\) or weighting); Gaussian quantile-quantile plot (departure of the noise from normality); spotting high-leverage points \(h_{ii} \gg 2p/n\) that "pull" the line.

2.2. Regularization: ridge and lasso

Definition 2.4 — Ridge and lasso $$\hat\theta_{\text{ridge}} = \arg\min_\theta \Big\{\tfrac1n\|y - X\theta\|^2 + \lambda \|\theta\|_2^2\Big\} = (X^\top X + n\lambda I)^{-1} X^\top y,$$ $$\hat\theta_{\text{lasso}} = \arg\min_\theta \Big\{\tfrac1n\|y - X\theta\|^2 + \lambda \|\theta\|_1\Big\}.$$ Ridge shrinks all coefficients (a solution always exists); the lasso produces coefficients that are exactly zero (variable selection).
Proposition 2.5 — Ridge: spectral effect Write the SVD \(X = U\,\mathrm{diag}(\sigma_j)\,V^\top\). Then $$\hat\theta_{\text{ridge}} = \sum_j \frac{\sigma_j\, u_j^\top y}{\sigma_j^2 + n\lambda}\; v_j, \qquad\text{whereas}\qquad \hat\theta = \sum_j \frac{u_j^\top y}{\sigma_j}\;v_j.$$ Ridge damps each direction \(v_j\) by the factor \(\sigma_j^2/(\sigma_j^2 + n\lambda)\): the well-explained directions (large \(\sigma_j\)) pass through, the ill-conditioned directions (collinearities, \(\sigma_j \to 0\)) are crushed — exactly the ones that made the least squares variance explode. In particular \(\|\hat\theta_{\text{ridge}}\|\) decreases from \(\|\hat\theta\)\) toward \(0\) as \(\lambda\) grows.
Proposition 2.6 — Lasso in orthogonal dimension 1: soft thresholding If \(X^\top X = I_p\) (orthonormal columns) and \(z = X^\top y\), then $$\hat\theta_{\text{lasso},j} = \mathrm{sign}(z_j)\,\big(|z_j| - \lambda/2\big)_+,$$
The functional separates: \(\sum_j \big\{\tfrac12(z_j - \theta_j)^2 + \tfrac{\lambda}{2}|\theta_j|\big\}\). For \(z_j > 0\), the optimum is either \(\theta_j = 0\) (cost \(z_j^2/2\)), or a stationary point in the region \(\theta_j > 0\) where the norm-1 term is differentiable: \(z_j - \theta_j = \lambda/2\), of cost \(\lambda z_j/2 - \lambda^2/8 < z_j^2/2\) as soon as \(z_j > \lambda/2\). Hence the thresholding; the case \(z_j < 0\) is symmetric.∎
It is this "dead zone" around zero that sets coefficients exactly to zero: in arbitrary dimension, the path \(\lambda \mapsto \hat\theta_{\text{lasso}}(\lambda)\) is piecewise linear (the LARS algorithm of Efron et al., 2004), which lasso_path visualizes.
Geometry of regularization Constraint \(\|\theta\|_1 \leq t\) = diamond: the corners on the axes explain the sparsity; \(\|\theta\|_2 \leq t\) = ball: isotropic shrinkage. Regularization is the first weapon against variance — and the ancestor of the weight decay of neural networks (\(\lambda\|\theta\|_2^2\) added to the loss in the Deep Learning module).
Proposition 2.7 — Bayesian reading: ridge = Gaussian prior, lasso = Laplacian prior Assume \(y = X\theta + \varepsilon\) with \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I)\). (i) If \(\theta \sim \mathcal{N}(0, \tau^2 I)\), the MAP (maximum a posteriori) is exactly \(\hat\theta_{\text{ridge}}\) with \(\lambda = \sigma^2/\tau^2\). (ii) If the coordinates of \(\theta\) are iid with Laplacian density \(p(\theta_j) = \tfrac{1}{2b}e^{-|\theta_j|/b}\), the MAP is \(\hat\theta_{\text{lasso}}\) with \(\lambda = \sigma^2/b\).
By Bayes' formula, \(-\log p(\theta \mid y) = \tfrac{1}{2\sigma^2}\|y - X\theta\|^2 - \sum_j \log p(\theta_j) + \text{const.}\) (i) \(-\log p(\theta_j) = \theta_j^2/(2\tau^2) + \text{const.}\): minimizing amounts to minimizing \(\|y - X\theta\|^2 + \tfrac{\sigma^2}{\tau^2}\|\theta\|_2^2\). (ii) \(-\log p(\theta_j) = |\theta_j|/b + \text{const.}\): minimize \(\|y - X\theta\|^2 + \tfrac{\sigma^2}{b}\|\theta\|_1\). In both cases, renormalizing by \(1/n\) and \(2\) identifies the announced \(\lambda\).∎
Moral: regularizing = encoding a prior (small / sparse coefficients); the Laplacian prior, peaked at zero, "pushes" coefficients toward zero more strongly than the Gaussian. 
from sklearn.linear_model import Ridge, Lasso, lasso_path
for lam in [1e-4, 1e-2, 1.0, 10.0]:
    l = Lasso(alpha=lam).fit(X, y)
    print(f"lambda={lam:8.3f}  nonzero coeffs = {(l.coef_ != 0).sum()}")

# lasso regularization path (piecewise linear, cf. LARS)
