3. Classification: logistic regression and SVM

3.1. Logistic regression

Definition 3.1 For \(Y \in \{0, 1\}\), one directly models $$\mathbb{P}(Y = 1 \mid X = x) = \sigma(\langle \theta, x\rangle) = \frac{1}{1 + e^{-\langle \theta, x\rangle}},$$ where \(\sigma\) is the sigmoid. The log-odds is linear: \(\log \tfrac{p}{1-p} = \langle\theta, x\rangle\) — hence an interpretable reading of the coefficients (odds ratio \(\approx e^{\theta_j}\) for \(x_j\) increased by one unit).
Proposition 3.2 — Likelihood and cross-entropy Maximizing the likelihood \(\prod_i \sigma(\theta^\top x_i)^{y_i}(1 - \sigma(\theta^\top x_i))^{1 - y_i}\) is equivalent to minimizing the cross-entropy $$\hat\theta = \arg\min_\theta \ \frac1n \sum_{i=1}^n \log\!\big(1 + e^{-y'_i \langle\theta, x_i\rangle}\big), \qquad y'_i \in \{-1, +1\}.$$
\(-\log\)-likelihood = \(\sum_i -y_i\log p_i - (1 - y_i)\log(1 - p_i)\) with \(p_i = \sigma(\theta^\top x_i)\). Writing \(y'_i = 2y_i - 1\), one checks \(-y_i \log p_i - (1-y_i)\log(1-p_i) = \log(1 + e^{-y'_i \theta^\top x_i})\): for \(y_i = 1\), \(1 - p_i = \sigma(-\theta^\top x_i)\) and \(1/(1-p_i) = 1 + e^{\theta^\top x_i}\).∎
Theorem 3.3 — Convexity, gradient, Hessian Set \(p_i(\theta) = \sigma(\theta^\top x_i)\) and \(L(\theta) = \tfrac1n\sum_i \log(1 + e^{-y'_i\theta^\top x_i})\). Then: (i) \(L\) is convex, and strictly convex if \(\ker X = \{0\}\); (ii) \(\nabla L(\theta) = \tfrac1n X^\top(p(\theta) - y)\); (iii) \(\nabla^2 L(\theta) = \tfrac1n X^\top \mathrm{diag}\big(w_i(\theta)\big) X\) with \(w_i = p_i(1 - p_i) \in \,]0, 1/4]\).
(i) Let \(g(z) = \log(1 + e^{-z})\). Then \(g'(z) = \tfrac{-e^{-z}}{1 + e^{-z}} = -\sigma(-z)\) and $$g''(z) = \sigma(-z)\big(1 - \sigma(-z)\big) = \frac{e^{-z}}{(1 + e^{-z})^2} > 0,$$ (the rate of change of \(\sigma'\) — or direct differentiation of \(\sigma' = \sigma(1-\sigma)\)). Hence \(g\) is convex; each \(g(\pm\theta^\top x_i)\) is convex in \(\theta\) (composition with an affine map), and \(L\), a sum, is convex. (ii) \(\nabla_\theta\, g(-y'_i\theta^\top x_i) = -y'_i x_i\, \sigma(y'_i \theta^\top x_i)\) (chain rule with \(g'\) above); noting that \(y'_i \sigma(y'_i\theta^\top x_i) \in \{p_i,\ p_i - 1\}\) depending on \(y_i\), everything compacts into \(\tfrac1n\sum_i x_i(p_i - y_i)\). (iii) The Jacobian of \(p(\theta)\) is \(\mathrm{diag}(w_i)X\) (since \(\sigma' = \sigma(1 - \sigma)\)), giving the announced Hessian, which is a positive scalar times \(X^\top X \succeq 0\); it is positive definite if the columns of \(X\) are independent.∎
Practical consequences Convex + smooth ⇒ a unique global optimum, reached by gradient descent or Newton. The Newton method here reads \(\theta \leftarrow \theta + (X^\top W X)^{-1} X^\top(y - p)\): this is exactly the iteratively reweighted regression (IRLS) well known from GLMs. This is the classification loss of neural networks (Deep Learning module) and of LLMs (softmax output = multiclass generalization \(\log\sum_k e^{s_k} - s_{y}\)).

3.2. Margin SVM

Definition 3.4 — SVM (soft margin, primal) $$\min_{\theta, b, \xi} \ \tfrac12 \|\theta\|^2 + C \sum_{i=1}^n \xi_i \quad \text{s.t.} \quad y'_i(\langle\theta, x_i\rangle + b) \geq 1 - \xi_i, \quad \xi_i \geq 0.$$ Maximize the margin \(\gamma = 1/\|\theta\|\) while tolerating the violations \(\xi_i\) (soft constraints, \(C\) = unit penalty). The classifier is \(x \mapsto \mathrm{sign}(\langle\theta, x\rangle + b)\).
Theorem 3.5 — Dual of the SVM The primal above has the same solution as the dual problem $$\max_{\alpha} \ \sum_{i=1}^n \alpha_i - \frac12 \sum_{i,j} \alpha_i\alpha_j y'_i y'_j \langle x_i, x_j\rangle \quad \text{s.t.} \quad 0 \leq \alpha_i \leq C, \ \sum_i \alpha_i y'_i = 0,$$ and the primal solution is reconstructed via \(\theta = \sum_i \alpha_i y'_i x_i\).
Lagrangian. Associate a multiplier \(\alpha_i \geq 0\) with each margin constraint and \(\mu_i \geq 0\) with \(\xi_i \geq 0\): $$\mathcal{L} = \tfrac12\|\theta\|^2 + C\textstyle\sum_i \xi_i - \sum_i \alpha_i\big[y'_i(\theta^\top x_i + b) - 1 + \xi_i\big] - \sum_i \mu_i \xi_i.$$ Stationary conditions (KKT). \(\partial_\theta \mathcal{L} = 0 \Rightarrow \theta = \sum_i \alpha_i y'_i x_i\) (the predictor is a combination of the data!); \(\partial_b \mathcal{L} = 0 \Rightarrow \sum_i \alpha_i y'_i = 0\); \(\partial_{\xi_i} \mathcal{L} = 0 \Rightarrow C = \alpha_i + \mu_i\), i.e. \(\alpha_i \leq C\). Substitute back: the term \(\theta^\top\theta\) against \(-\sum\alpha_i y'_i\theta^\top x_i\) gives \(-\tfrac12\|\theta\|^2\), then replacing \(\|\theta\|^2\) by the double sum; the \(\xi_i\) disappear exactly (\((C - \alpha_i - \mu_i)\xi_i = 0\)); what remains is the announced dual function with \(0 \leq \alpha_i \leq C\). The primal is convex with affine constraints: Slater (strictly feasible, \(C\) large enough or \(\xi\) large enough) guarantees strong duality — dual optimum = primal optimum, and the KKT conditions are necessary and sufficient.∎
Reading the complementarity conditions — who are the support vectors? The KKT complementarity conditions \(\alpha_i\,[y'_i(\theta^\top x_i + b) - 1 + \xi_i] = 0\) and \((C - \alpha_i)\,\xi_i = 0\) sort the points into three families:
CasePosition of the pointRole
\(\alpha_i = 0\)outside the margin band, well classifiednone — any data point
\(0 < \alpha_i < C\)exactly on the margin \((\xi_i = 0)\)"free" support vector
\(\alpha_i = C\)inside the band or misclassified \((\xi_i > 0)\)"paying" support vector
The solution depends only on the points with \(\alpha_i > 0\) (dual sparsity): this is the robustness of SVMs to distant data, and the \(\mathcal{O}(n_{\text{supp}})\) prediction cost. The constant \(b\) is recovered from any point on the margin: \(b = y'_i - \theta^\top x_i\).
Theorem 3.6 — Margin generalization bounds (sketch) Let \(\mathcal{F}_R = \{x \mapsto \langle\theta, x\rangle : \|\theta\| \leq R,\ \|x\| \leq 1\}\). Its Rademacher complexity (definition in chapter 7) satisfies \(\mathcal{R}_n(\mathcal{F}_R) \leq R/\sqrt{n}\), independently of the dimension of \(\mathcal{X}\). It follows, with high probability, for any score function with margin \(\gamma\) (losses dominated by the hinge): $$\mathcal{R}(f) \ \leq\ \hat{\mathcal{R}}_{n,\gamma}(f) + \frac{2R}{\gamma\sqrt{n}} + \sqrt{\tfrac{\log(2/\delta)}{2n}}.$$ Sketch. (i) The hinge \((1 - t)_+\) is 1-Lipschitz: the contraction lemma brings the loss back to the score. (ii) For the class of bounded scores, \(\mathbb{E}_\sigma \sup_{\|\theta\| \leq R} \tfrac1n\theta^\top\sum_i \sigma_i x_i = \tfrac{R}{n}\,\mathbb{E}_\sigma\big\|\sum_i \sigma_i x_i\big\| \leq \tfrac{R}{n}\sqrt{\mathbb{E}\big\|\sum_i\sigma_ix_i\big\|^2} = \tfrac{R}{n}\sqrt{n} = \tfrac{R}{\sqrt n}\) (Cauchy-Schwarz, then orthogonality of the \(\sigma_ix_i\) and \(\|x_i\| \leq 1\)).∎ This "margin, not dimension" viewpoint watches over overfitting; it is developed in chapter 7 and in the Statistical Learning Theory module (P1 option).
