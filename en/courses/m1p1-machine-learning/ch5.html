5. Trees, forests, boosting

5.1. Decision trees (CART)

Recursive partition of \(\mathcal{X}\) by axis-aligned cuts (binary questions "\(x_j \leq t\)?"). At each leaf, one predicts the mean (regression) or the majority class (classification). Growth: at each node, choose \((j, t)\) maximizing the impurity gain; then pruning to avoid overfitting. The exact impurity criteria, for a node \(D\) containing the classes in proportions \(p_1, \dots, p_K\):

Definition 5.1 — Usual impurities $$\text{entropy: } H(D) = -\sum_{k=1}^K p_k \log_2 p_k, \qquad \text{Gini: } G(D) = 1 - \sum_{k=1}^K p_k^2 = \sum_k p_k(1 - p_k).$$ In regression, one uses the squared error \(Q(D) = \frac{1}{|D|}\sum_{i \in D}(y_i - \bar y_D)^2\). For a split \(D = D_L \cup D_R\), the gain is $$\Delta(j, t) = I(D) - \frac{|D_L|}{|D|} I(D_L) - \frac{|D_R|}{|D|} I(D_R).$$
Gini and entropy are nearly interchangeable With two classes (\(p = p_1 = 1 - p_2\)): \(G(p) = 2p(1-p)\) and \(H(p) = -p\log_2 p - (1-p)\log_2(1-p)\). Both are maximal at \(p = 1/2\), zero at \(0\) and \(1\), and their expansion around \(1/2\) coincides to first order: \(H(p) = 1 - \frac{2}{\ln 2}(p - \tfrac12)^2 + o\big((p-\tfrac12)^2\big)\) and \(G(p) = \frac12 - 2(p - \tfrac12)^2\). CART uses Gini (no logarithm, direct computation); ID3/C4.5 use entropy (information gain). The choice is rarely decisive — pruning is. CART's cost-complexity pruning minimizes \(R_\alpha(T) = R(T) + \alpha\,|\text{leaves}(T)|\) over the family of subtrees: yet another fit/complexity trade-off (chapter 7).

5.2. Random forests (bagging)

Theorem 5.2 — Bagging reduces variance Let \(T_1, \dots, T_B\) be predictors with the same variance \(\sigma^2\), pairwise correlation \(\rho\). The average \(A_B = \frac1B\sum_b T_b\) satisfies $$\mathrm{Var}(A_B) = \rho\,\sigma^2 + \frac{1 - \rho}{B}\,\sigma^2.$$
\(\mathrm{Var}(A_B) = \frac{1}{B^2}\big[\sum_b \mathrm{Var}(T_b) + \sum_{b \neq b'} \mathrm{Cov}(T_b, T_{b'})\big] = \frac{1}{B^2}\big[B\sigma^2 + B(B-1)\rho\sigma^2\big] = \frac{\sigma^2}{B} + \frac{B-1}{B}\rho\sigma^2\), which rewrites as announced. iid case (\(\rho = 0\), for example Gaussian variables with the same law): \(\mathrm{Var} = \sigma^2/B\) — divide the variance by \(B\) by averaging independent replicates.∎
Why it works so well for trees As \(B \to \infty\), the residual variance tends toward the floor \(\rho\sigma^2\): the whole art consists in lowering \(\rho\). Random forests combine two mechanisms: (i) the bootstrap (resampling the rows); (ii) the random selection of \(m_{\text{try}} < d\) candidate variables at each split (decorrelation), which forces the trees to differ structurally. Unpruned trees have low bias and high variance — exactly the profile that bagging can correct. Bonus: each tree leaves out on average \(e^{-1} \approx 37\%\) of the data (out-of-bag), a free risk estimate — we return to this in chapter 9. Forests remain a hard-to-beat tabular baseline.

5.3. Boosting: gradient descent in function space

Definition 5.3 — The functional problem One seeks \(f : \mathcal{X} \to \mathbb{R}\) minimizing $$\Phi(f) = \frac1n \sum_{i=1}^n \ell\big(y_i, f(x_i)\big),$$ where \(\ell\) is convex and differentiable in its second variable (quadratic, logistic...). One builds \(f\) as a sum \(f_M = \sum_{m=0}^M \eta\, h_m\) of simple functions (typically small trees), chosen one at a time — a stagewise additive model.
Theorem 5.4 — Boosting is functional gradient descent Assume \(f_{m-1}\) built and set \(g_i = \frac{\partial\, \ell}{\partial f}(y_i, f_{m-1}(x_i))\) (pseudo-residuals, up to opposite sign). Then, to first order in \(\eta\): $$\Phi(f_{m-1} + \eta h) = \Phi(f_{m-1}) - \frac{\eta}{n}\sum_{i=1}^n h(x_i)\,\underbrace{(-g_i)}_{\text{pseudo-residuals}} + o(\eta),$$ so the direction \(h\) that lowers \(\Phi\) the most is the one aligned with the pseudo-residuals \(-g_i\). Gradient boosting fits \(h_m\) by regression (trees) on the pairs \((x_i, -g_i)\).
This is a Taylor expansion of the one-variable function \(s \mapsto \ell(y_i, f_{m-1}(x_i) + s\,h(x_i))\) around \(s = 0\), summed over \(i\) and divided by \(n\) (with \(s = \eta\)): \(\ell(y_i, f_{m-1}(x_i) + \eta h(x_i)) = \ell(y_i, f_{m-1}(x_i)) + \eta\, h(x_i)\, \frac{\partial \ell}{\partial f}(y_i, f_{m-1}(x_i)) + o(\eta)\). Quadratic case \(\ell(y, f) = \frac12(y - f)^2\): \(g_i = f_{m-1}(x_i) - y_i\), hence \(-g_i = y_i - f_{m-1}(x_i)\) — the true residuals: each tree predicts the residuals of the previous ones, and \(\Phi(f + \eta h)\) is exact (no remainder) for \(h\) = residuals. Logistic case \(\ell(y, p) = -y\log p - (1-y)\log(1-p)\) composed with the sigmoid: \(\frac{\partial \ell}{\partial f} = \sigma(f) - y\) (computation of chapter 3); pseudo-residuals \(y_i - p_i\).∎
Learning rate and early stopping The step \(\eta\) (typically \(0.01\)–\(0.1\)) is not the optimal descent constant: one gives up exact line search for a small step that (i) limits the variance of each tree, (ii) lets the following trees correct the previous ones — hence more iterations needed. The number \(M\) of iterations plays the role of effective capacity: \(\Phi(f_M)\) decreases mechanically with \(M\), but the generalization risk decreases then rises again; early stopping (choosing \(M\) on validation) is the true regularization of boosting — same logic as the norm \(\|\theta\|\) in ridge (chapter 7): an increasing \(M\) corresponds to a growing dictionary of directions. Friedman (2001) formalized this paradigm; XGBoost/LightGBM made it industrial (second order, leaf regularization, histograms); the M2 module "From Boosting to Foundation Models" starts from there. 
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier
from sklearn.model_selection import cross_val_score
rf  = RandomForestClassifier(n_estimators=300, min_samples_leaf=2, oob_score=True)
gbt = HistGradientBoostingClassifier(max_iter=300, learning_rate=0.06)
print(cross_val_score(rf, X, y, cv=5).mean(), cross_val_score(gbt, X, y, cv=5).mean())
print("forest OOB error:", 1 - rf.fit(X, y).oob_score_)  # free validation
