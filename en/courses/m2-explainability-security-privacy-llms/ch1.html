1. Internal interpretability: probing and control

Definition 1.1 — Probe A probe is a classifier (typically linear: logistic regression) trained to predict a linguistic property \(y\) (grammatical category, language, document topic, country of a capital...) from the activations \(h^{(l)}(x)\) of a layer \(l\) of the model, frozen. High probe accuracy reads as: "layer \(l\) (linearly) encodes the information necessary for \(y\)" — and only as that (see the warning below). 
import torch, torch.nn.functional as F
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

model = GPT2.from_pretrained("gpt2").eval()          # frozen

@torch.no_grad()
def states(texts, layer=6):                          # residual stream activations
    out = model(input_ids=tokenizer(texts, return_tensors="pt").input_ids,
                output_hidden_states=True)
    return out.hidden_states[layer][:, -1].numpy()   # last token

X = states(phrases)                                  # (n, d=768)
Xtr, Xte, ytr, yte = train_test_split(X, pos_tags, test_size=.2)
probe = LogisticRegression(max_iter=2000).fit(Xtr, ytr)
print("acc sonde :", probe.score(Xte, yte))          # ~0.9 on POS in layer 6-8

1.1. What probes have revealed

Alain & Bengio (2016) launched the method: the loss of a linear probe per layer decreases with depth, then rises again toward the output layer — the model "solves" the task at intermediate layers then projects onto the vocabulary. Since then, probes have mapped: early syntactic positions, named entities, world-fact relations ("the Eiffel Tower is in Paris") manipulated by subspace edits, linearly decodable language and sentiment... The emerging hypothesis: the residual stream is a communication channel where each head writes to and reads from relatively linear subspaces.

1.2. The trap: information ≠ use

Problem 1.2 — Control tasks (Hewitt & Liang, EMNLP 2019) A probe can learn \(y\) from \(h\) even if the model does not use this information — it suffices that it be decodable. The countermeasure: train the same probe on a control task \(y_{\text{ctrl}}\) — same statistical structure, but invented labels (shuffled type) that the model cannot "know". One reports the selectivity: $$\mathrm{sel} \;=\; \mathrm{acc}(\text{probe on } y) \;-\; \mathrm{acc}(\text{probe on } y_{\text{ctrl}}).$$ High accuracy with low selectivity = the probe memorizes, not the model; only a thin probe (low capacity) with good selectivity attests to an encoding that is linear and usable.
Correlation is not causation — and the causal proof To take the step, one intervenes: amnesia (remove the information from \(h\) by projection, re-measure the model's performance — if it drops, the information was used), head ablation, patching of activations between runs (activation patching). Rule of the module: an interpretability case is closed only when the intervention confirms the correlation. See Belinkov (2022) for a survey of the promises and failures of the method.
