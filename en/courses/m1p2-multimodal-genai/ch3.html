3. Diffusion: DDPM and score matching

Model 3.1 — Forward process (noising) A Markov chain that adds Gaussian noise: $$q(x_t \mid x_{t-1}) = \mathcal{N}\big(\sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t I\big), \qquad t = 1, \dots, T,$$ with increasing \(\beta_t\). Key property (composition of Gaussians): $$q(x_t \mid x_0) = \mathcal{N}\big(\sqrt{\bar\alpha_t}\, x_0,\ (1 - \bar\alpha_t) I\big), \qquad \alpha_t = 1 - \beta_t,\quad \bar\alpha_t = \prod_{s = 1}^{t}\alpha_s.$$ For \(T = 1000\), \(\bar\alpha_T \approx 0\): the image has become pure noise.
By induction on \(t\). Base case: \(t = 1\): \(x_1 = \sqrt{\alpha_1}\,x_0 + \sqrt{1 - \alpha_1}\,\epsilon\), so \(q(x_1 \mid x_0) = \mathcal{N}(\sqrt{\bar\alpha_1}x_0,\ (1-\bar\alpha_1)I)\) by definition. Inductive step: assume \(x_{t-1} \mid x_0 \sim \mathcal{N}(\sqrt{\bar\alpha_{t-1}}\,x_0,\ (1-\bar\alpha_{t-1})I)\). Then $$x_t = \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon, \qquad \epsilon \perp x_{t-1} \mid x_0.$$ By property 0.1 (sum of independent Gaussians): mean \(\sqrt{\alpha_t}\cdot\sqrt{\bar\alpha_{t-1}}\,x_0 = \sqrt{\bar\alpha_t}\,x_0\) (since \(\alpha_t \bar\alpha_{t-1} = \bar\alpha_t\)); variance \(\alpha_t(1-\bar\alpha_{t-1}) + (1-\alpha_t) = 1 - \bar\alpha_{t-1} + \alpha_t\bar\alpha_{t-1} = 1 - \bar\alpha_t\). ∎
Variance schedule: linear or cosine The choice of the \(\beta_t\) sets the speed of destruction. Linear (\(\beta_t: 10^{-4} \to 0.02\), original DDPM): high frequencies die too fast, and the end of the chain is needlessly noisy. Cosine (Nichol & Dhariwal, 2021): $$\bar\alpha_t = \frac{f(t)}{f(0)}, \qquad f(t) = \cos^2\!\left(\frac{t/T + 0.008}{1.008}\cdot\frac{\pi}{2}\right),$$ which gives a gently sloped decay of \(\bar\alpha_t\), effective also at low resolution. Rule of thumb: the schedule must destroy information uniformly across the scales of the image.
Model 3.2 — Learned reverse process and per-step ELBO $$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}\big(\mu_\theta(x_t, t),\ \sigma_t^2 I\big), \qquad p(x_T) = \mathcal{N}(0, I),$$ and training reduces to a simple MSE: $$\mathcal{L} = \mathbb{E}_{x_0, \epsilon, t}\big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\big], \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1 - \bar\alpha_t}\,\epsilon.$$
Step 1 — telescoping. Applying thm. 0.2 to the chain \(p_\theta(x_{0:T})\) with \(q(x_{1:T}\mid x_0)\), the ELBO rewrites (Markov chain, telescoped products): $$-\mathrm{ELBO} = \mathrm{KL}\big(q(x_T\mid x_0)\,\|\,\mathcal{N}(0,I)\big) + \sum_{t=1}^{T}\mathbb{E}_q\!\left[\mathrm{KL}\big(q(x_{t-1}\mid x_t, x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\big)\right] = L_T + \sum_t L_{t-1}.$$ Step 2 — closed-form forward posterior. By Bayes' rule \(q(x_{t-1}\mid x_t, x_0) \propto q(x_t \mid x_{t-1})\,q(x_{t-1}\mid x_0)\): a product of two Gaussians in \(x_{t-1}\), hence Gaussian; completing the square: $$q(x_{t-1}\mid x_t, x_0) = \mathcal{N}\big(\tilde\mu_t(x_t, x_0),\ \tilde\beta_t I\big), \quad \tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\,\beta_t,\quad \tilde\mu_t = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,x_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t.$$ Step 3 — every \(L_{t-1}\) is a KL of Gaussians: closed by prop. 0.4. If we set \(\sigma_t^2 = \tilde\beta_t\), what remains is to align the means: \(L_{t-1} = C + \frac{1}{2\sigma_t^2}\|\tilde\mu_t - \mu_\theta\|^2\). Step 4 — noise parameterization. We choose $$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t, t)\Big),$$ which amounts (substituting \(x_0 = (x_t - \sqrt{1-\bar\alpha_t}\,\epsilon)/\sqrt{\bar\alpha_t}\) into \(\tilde\mu_t\)) to requiring \(\epsilon_\theta \approx \epsilon\); all the remaining factors are known constants absorbed into the weighting. Hence the single MSE of model 3.2 — a remarkable result: five lines of theory for a one-line loss. ∎
Theorem 3.3 — Predicting the noise = predicting the score $$\epsilon = -\sqrt{1-\bar\alpha_t}\;\nabla_{x_t}\log p(x_t \mid x_0).$$ The denoising MSE is therefore a conditional score matching: the network learns \(\nabla_x \log p\) — exactly the object of the "score-based" family of Song et al. (2021), which unifies diffusion and SDEs (ch. 4).
For a Gaussian density \(p(x_t \mid x_0) = \mathcal{N}(x_t;\ m, s^2 I)\) with \(m = \sqrt{\bar\alpha_t}\,x_0\), \(s^2 = 1 - \bar\alpha_t\), we compute $$\nabla_{x_t}\log p(x_t\mid x_0) = \nabla_{x_t}\left[-\frac{\|x_t - m\|^2}{2s^2}\right] + 0 = -\frac{x_t - \sqrt{\bar\alpha_t}\,x_0}{1-\bar\alpha_t}.$$ Now \(x_t - \sqrt{\bar\alpha_t}\,x_0 = \sqrt{1-\bar\alpha_t}\,\epsilon\), so \(\nabla_{x_t}\log p = -\epsilon/\sqrt{1-\bar\alpha_t}\), that is \(\epsilon = -\sqrt{1-\bar\alpha_t}\,\nabla_{x_t}\log p(x_t \mid x_0)\). ∎ 
import torch

def forward_diffusion(x0, t, alphas_bar, eps=None):
    """x_t = sqrt(a_bar_t) x0 + sqrt(1 - a_bar_t) * eps   (in one step!)"""
    if eps is None: eps = torch.randn_like(x0)
    return alphas_bar[t].sqrt()[:, None, None, None] * x0 \
         + (1 - alphas_bar[t]).sqrt()[:, None, None, None] * eps, eps

# Training (typical DDPM loop):
# x0 = batch of images; t ~ U{1..T}
xt, eps = forward_diffusion(x0, t, alphas_bar)
loss = torch.nn.functional.mse_loss(unet(xt, t), eps)   # predict the noise
loss.backward()

# Sampling (T steps, formula of model 3.2):
x = torch.randn(n, c, h, w)                    # x_T ~ N(0, I)
for t in reversed(range(T)):
    eps = unet(x, t)
    mu = (x - beta[t].sqrt()/(1 - alphas_bar[t]).sqrt() * eps) / alpha[t].sqrt()
    x = mu + beta[t].sqrt() * torch.randn_like(x) if t > 0 else mu
LLGA analogies The diffusion U-Net uses self-attention (a transformer on a grid); DiTs replace everything with transformers on patches; and diffusion on graphs (DiGress) noises/denoises node and edge types — the same algorithm, another space (Graph ML module, ch. 7). The derivation "Markov chain → ELBO → per-step KL → MSE" we have just done is literally the same as the one in Deep Learning module ch. 7 for the VAE — diffusion is a VAE of depth \(T\) with shared parameters.
