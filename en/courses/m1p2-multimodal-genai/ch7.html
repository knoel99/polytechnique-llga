7. Beyond images: video, 3D, multimodal LLMs

  • Video: spatio-temporal latents (the VAE compresses time as well: 2–4 frames per latent token), the denoiser interleaves spatial attention (intra-frame) and temporal attention (inter-frames); cost grows like (frames × resolution²), hence the cascades (low resolution → temporal upsampling); camera control and long-horizon coherence: open problems (cf. ch. 9, AKiRa);
  • Captioning / VQA: image encoder (ViT) + text decoder (transformer); trained on pairs; graphical VQA ("what is the shortest path?") — visual reasoning;
  • Multimodal LLMs: how to make an LLM "see"?
    • Linear projector (LLaVA): \(h_v = W\,p_i + b\) on each ViT patch — the image "words" are projected into the LLM's embedding space: simple, effective, lots of tokens;
    • Q-Former (BLIP-2): 32 learned query vectors that cross-attend to the image features and produce 32 embeddings — a compact "visual summary"; freezes the LLM while pretraining the bridge;
    • Two-stage training protocol: (1) alignment pretraining on immense (image, caption) corpora — learning the correspondence; (2) multimodal instruction tuning — conversations, reasoning, answering;
    • Audio: discrete tokens of spectrograms or signals (neural codec) injected in the same way — same pattern, another modality (M2 module for the rest);
  • 3D: NeRF (sketch): an MLP \((x, d) \mapsto (\sigma, c)\) (density, color) is optimized by differentiable volume rendering: $$C(r) = \int_{t_n}^{t_f} T(t)\,\sigma\big(r(t)\big)\,c\big(r(t), d\big)\,dt, \qquad T(t) = \exp\!\Big(-\!\int_{t_n}^{t}\sigma\big(r(s)\big)ds\Big),$$ that is, "the opacity accumulated along the ray weights the colors"; recent 3D generative models prefer diffusion over point clouds and meshes — discretization, operators, correspondence: this is exactly the syllabus of the M2 Geometric Deep Learning module (direct link);
  • World models: action-conditioned generation of interactive videos (learned simulators; link with the RL module, latent world; mention of Genie/Sora-like systems);
  • Generative structured data: text-to-graph (generating the schema of a network), graph-to-text (a report from a knowledge graph) — the exact intersection of the Graph ML and NLP modules;
  • Multimodal agents: perceiving (screenshot) and acting (click, code) — GUI agents combine vision + LLM + tools (RL module, ch. 7).
