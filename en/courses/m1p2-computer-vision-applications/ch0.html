0. Review: convolution, CNNs, boxes

L3 review — what is assumed known
  • Digital image: an \(H \times W\) grid of pixels with \(C\) channels (3 in RGB), a tensor \(x \in \mathbb{R}^{C \times H \times W}\); grayscale, resolution, sampling (cf. Signal Processing module, chapter 2).
  • 2D convolution: \((I * k)(u, v) = \sum_{i,j} I(u-i, v-j)\,k(i, j)\); properties (commutativity, association with the product), Sobel / low-pass counterparts, correlation vs convolution (cf. Signal Processing module, chapter 3).
  • Convolutional networks: receptive fields, weight sharing, pooling, the ResNet architecture (residual connections) — cf. Deep Learning module, chapter 4; attention and transformers — cf. Deep Learning module, chapter 6.
  • Supervised learning: gradient descent, SGD/Adam, overfitting, regularization, transfer learning and fine-tuning — cf. Deep Learning module, chapters 3 and 8; cross-validation, ROC curves — cf. the Machine Learning module.

The P1 course "Image Analysis and Computer Vision" (CSC_51073_EP) laid the foundations: filtering, local features, projective geometry, reconstruction. The present module takes the systems and applications orientation: we build the complete pipeline of a vision product — from annotated data to a model deployed on constrained hardware — and study the building blocks industry actually uses (detectors, segmenters, trackers, 3D sensors, inference runtimes).

Definition 0.1 — Bounding box and IoU A bounding box is an axis-aligned rectangle \(b = (x_1, y_1, x_2, y_2)\) with \(x_1 < x_2\), \(y_1 < y_2\), encoding the top-left and bottom-right corners. For two boxes \(a\) and \(b\), let \(A(a)\) denote the area of the rectangle. The intersection-over-union is $$\mathrm{IoU}(a, b) \;=\; \frac{|a \cap b|}{|a \cup b|} \;=\; \frac{|a \cap b|}{A(a) + A(b) - |a \cap b|},$$ where \(|\cdot|\) denotes area. The intersection box has corners \((\max(x_1^a, x_1^b), \max(y_1^a, y_1^b))\) and \((\min(x_2^a, x_2^b), \min(y_2^a, y_2^b))\) if these coordinates are consistent, otherwise the intersection is empty and \(\mathrm{IoU} = 0\).
Proposition 0.2 — Properties of IoU For all axis-aligned boxes \(a, b\): (i) \(\mathrm{IoU}(a,b) \in [0, 1]\); (ii) \(\mathrm{IoU}(a,b) = \mathrm{IoU}(b,a)\); (iii) \(\mathrm{IoU}(a,b) = 1\) if and only if \(a = b\) (up to equality of pixel sets); (iv) \(\mathrm{IoU}(a,b) = 0\) if and only if the interiors of the two rectangles are disjoint.
(i) The intersection area is a rectangle area, positive and bounded by each of the areas, so \(0 \leq |a \cap b| \leq \min(A(a), A(b)) \leq |a \cup b|\). (ii) The intersection and union operations are symmetric. (iii) If \(\mathrm{IoU} = 1\) then \(|a \cap b| = |a \cup b|\), so \(|a \setminus b| = |b \setminus a| = 0\) and the rectangles coincide; the converse is immediate. (iv) If the intersection is empty, the numerator is zero; conversely a non-empty intersection rectangle has strictly positive area, hence \(\mathrm{IoU} > 0\). ∎
Example 0.3 — An IoU computation Let the ground truth be \(g = (0, 0, 10, 10)\) (area 100) and the prediction \(p = (5, 5, 15, 15)\) (area 100). The intersection is the square \((5,5,10,10)\) of area 25, the union equals \(100 + 100 - 25 = 175\), so \(\mathrm{IoU}(g, p) = 25/175 \approx 0.143\): the prediction is rejected at the usual threshold \(\tau = 0.5\). A prediction shifted by only 2 pixels, \(p' = (2, 2, 12, 12)\), gives an intersection of 64 and a union of 136, i.e. \(\mathrm{IoU} \approx 0.47\) — still below the threshold: on small objects the metric is unforgiving, which will justify the multiple thresholds of chapter 2.
