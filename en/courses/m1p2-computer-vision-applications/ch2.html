2. Evaluation (mAP) and modern detectors

2.1. Precision, recall and AP — computed on an example

Definition 2.1 — Precision, recall, AP and mAP For a given class, a detection is a true positive (TP) if \(\mathrm{IoU}(\text{prediction}, \text{ground truth}) \geq \tau\) (and if that ground truth is not already matched); otherwise it is a false positive (FP); an undetected ground truth is a false negative (FN). Then $$\text{precision} = \frac{TP}{TP + FP}, \qquad \text{recall} = \frac{TP}{TP + FN} = \frac{TP}{|\text{ground truths}|}.$$ The average precision (AP) is the area under the precision-recall curve obtained by sweeping the score threshold; the COCO mAP averages the APs over 80 classes and over 10 IoU thresholds \(\tau \in \{0.5,\, 0.55,\, \dots,\, 0.95\}\) — denoted \(\mathrm{mAP}@[0.5{:}0.95]\).
Example 2.2 — AP of one class by hand One class ("cat") with 3 ground truths and 5 detections sorted by decreasing score, evaluated at threshold \(\tau = 0.5\):
RankScoreVerdictCumulative TPPrecisionRecall

With "all-points" interpolation (precision clipped by the maximum to the right), the retained points are \((0.33; 1.00)\), \((0.67; 0.67)\) and \((1.00; 0.60)\), hence $$\mathrm{AP} \approx 0.33 \times 1.00 + 0.34 \times 0.67 + 0.33 \times 0.60 \approx 0.75.$$ The AP rewards both the ranking of the scores (an FP at high score is costly) and completeness; this is why it is more informative than a simple accuracy at a fixed threshold.
Note — Why multiple thresholds At \(\tau = 0.5\), a detector can be right "loosely": averaging over \([0.5{:}0.95]\) penalizes mediocre localizations. COCO also publishes \(\mathrm{mAP}_S, \mathrm{mAP}_M, \mathrm{mAP}_L\) by object size — a "globally" good industrial model can be very poor on small objects, a crucial point for video surveillance or microscopy.

2.2. Without anchors: anchor-free detectors

Anchors impose an arbitrary grid of hypotheses. Anchor-free detectors directly predict, per pixel of the feature map: (i) a probability of being an object center (centerness / center heatmap, cf. FCOS and CenterNet) and (ii) regressions of the distances to the four edges. The decoding becomes: $$b = (x_c - l, \; y_c - t, \; x_c + r, \; y_c + b'),$$ where \((x_c, y_c)\) is the position of the central pixel and \(l, t, r, b'\) the regressed distances — all of it without any reference box. Benefits: fewer hyperparameters (scales/ratios), no anchor/object imbalance, better on atypical shapes; cost: an NMS is still needed, and the center-to-ground-truth assignment requires zone rules (assignment by feature zone).

2.3. Detection as set prediction: DETR

Definition 2.3 — DETR (DEtection TRansformer) DETR treats detection as a set prediction problem: a CNN extracts features, a transformer encoder-decoder (cf. Deep Learning module, chapter 6) produces \(N\) object queries decoded into \(N\) (box, class) pairs; training matches predictions and ground truths by minimum-cost bipartite coupling (Hungarian algorithm): $$\hat\sigma = \arg\min_{\sigma \in \mathfrak{S}_N} \sum_{i=1}^{N} \Big( \mathcal{L}_{\mathrm{box}}(b_i, g_{\sigma(i)}) + \mathcal{L}_{\mathrm{cls}}(c_i, y_{\sigma(i)}) \Big),$$ then applies a "set prediction"-type loss (Hungarian loss) on the optimal matching. Since the output is a learned set without redundancy, DETR removes NMS and anchors.
Note — Why DETR converges slowly, and the fix Global attention struggles to precisely localize small boxes (attention spreads over the whole image): DETR needed ~500 epochs. Deformable DETR replaces dense attention with deformable attention that samples only a small set of relevant points per query, speeding up convergence by an order of magnitude. The Hungarian matching is a minimum-cost assignment coupling — exactly the discrete transport seen in the Computational Optimal Transport module, chapters 1–2 (there solved by the Hungarian method rather than by Sinkhorn).

Knowing how to read a detector's changelog — which modules change, which data, which licenses (GPL for the Ultralytics line, Apache-2.0 for others) — is part of the module's skills.
