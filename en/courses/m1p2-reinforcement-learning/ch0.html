0. Refresher: Markov chains, martingales, dynamic programming

L3 prerequisites — Markov chains
  • Markov chain: \(X_{t+1} \sim P(\cdot \mid X_t)\) — the future depends only on the present. Stochastic transition matrix (rows summing to 1).
  • Stationary distribution: \(\pi = \pi P\); exists and is unique for an irreducible aperiodic chain (Perron-Frobenius theorem).
  • Random walks on graphs: \(P = D^{-1}A\) — the random walker; \(\pi(v) \propto \deg(v)\); to be connected to PageRank and node embeddings (Graph ML module).
  • Conditional expectation: \(\mathbb{E}[X \mid Y]\) (cf. Refresher Statistics module) — the value function is one.

0.1. Classification of states, ergodicity

Definition 0.1 — Irreducibility, aperiodicity, recurrence A chain on \(\mathcal{S}\) is irreducible if for all \(i, j\) there exists \(t\) with \(P^t(i, j) > 0\) (every state is reachable from every state). It is aperiodic if the gcd of the return times to each state equals 1. A state is positive recurrent if the expected return time \(\mathbb{E}[T_{i \to i}]\) is finite. An irreducible, aperiodic, positive recurrent chain is called ergodic.
Theorem 0.2 — Ergodic theorem for Markov chains Let \((X_t)\) be an ergodic chain with stationary distribution \(\pi\). Then, for every bounded function \(f : \mathcal{S} \to \mathbb{R}\), $$\frac{1}{n} \sum_{t=1}^{n} f(X_t) \;\xrightarrow{\text{a.s.}}\; \sum_{s \in \mathcal{S}} \pi(s)\, f(s),$$ and moreover \(\|P^t(i, \cdot) - \pi\|_{\mathrm{TV}} \to 0\) at geometric speed (the rate is given by the second eigenvalue module of \(P\)). RL reading: in the long run, the visit frequency of a state does not depend on the initial state — this is what justifies learning "over the course of episodes".

0.2. Martingales and stochastic approximation

Definition 0.3 — Martingale \((M_t)\) is a martingale adapted to the filtration \((\mathcal{F}_t)\) if \(\mathbb{E}[M_{t+1} \mid \mathcal{F}_t] = M_t\). Martingales model "fair noise"; the TD error of chapter 3 will be almost one.
Theorem 0.4 — Robbins-Siegmund (quasi-martingale convergence) Let \(V_t \geq 0\) be adapted, with \(\mathbb{E}[V_{t+1} \mid \mathcal{F}_t] \leq V_t + a_t\) where \(\sum_t a_t < \infty\). Then \(V_t\) converges a.s. to a finite random variable. This is the central tool of the convergence proofs of this course's algorithms: one shows that the distance to the fixed point decreases "on average", and one concludes.
Theorem 0.5 — Robbins-Monro (precise statement) Consider the recursion \(x_{t+1} = x_t + \gamma_{t+1}\big(h(x_t) + \eta_{t+1}\big)\) where \(h : \mathbb{R}^d \to \mathbb{R}^d\) is continuous, \(x^\star\) the unique zero of \(h\), and: (i) steps \(\sum_t \gamma_t = \infty\), \(\sum_t \gamma_t^2 < \infty\); (ii) unbiased noise \(\mathbb{E}[\eta_{t+1} \mid \mathcal{F}_t] = 0\), bounded variance; (iii) \((x_t - x^\star)^\top\big(h(x_t)\big) < 0\) as soon as \(x_t \neq x^\star\) (monotonicity). Then \(x_t \to x^\star\) a.s. This is exactly the regime of TD-learning: \(h\) will be the Bellman operator minus the identity, and Theorem 0.4 will provide the decrease.

0.3. Deterministic dynamic programming

Principle of optimality (Bellman, 1957) "An optimal policy has the property that, whatever the initial state and the first decision, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision." Formally, for a sequential additive cost, the optimal value satisfies a fixed-point equation: \(V^\star(x) = \min_u\{c(x, u) + V^\star(\mathrm{succ}(x, u))\}\). Usage reminders: shortest paths (Bellman-Ford), memoization (Refresher CS), temporal decomposition. The MDP of chapter 1 adds: random transitions (hence expectations) and a maximization (hence \(\max\) operators).
