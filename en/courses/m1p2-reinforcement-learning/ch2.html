2. Dynamic programming (known model)

Theorem 2.1 — Value iteration: convergence demonstrated Repeat until convergence: $$V_{k+1}(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V_k(s')\Big\} \qquad \text{i.e.} \qquad V_{k+1} = \mathcal{T}V_k.$$
For every \(k\) (writing \(V^\star = \mathcal{T}V^\star\)): $$\|V_{k+1} - V^\star\|_\infty = \|\mathcal{T}V_k - \mathcal{T}V^\star\|_\infty \leq \gamma\, \|V_k - V^\star\|_\infty \ \Rightarrow\ \|V_k - V^\star\|_\infty \leq \gamma^k \|V_0 - V^\star\|_\infty.$$ The convergence is geometric with ratio \(\gamma\): each iteration removes a factor \(\gamma\) from the error. Exploitable stopping criterion. \(\|V_{k+1} - V_k\|_\infty \leq \varepsilon\) implies \(\|V_k - V^\star\|_\infty \leq \frac{\gamma\,\varepsilon}{1-\gamma}\): to guarantee an error \(\delta\) on the value, a residual \(\varepsilon = \delta(1-\gamma)/\gamma\) is needed — the factor \(1/(1-\gamma)\) "amplifies" any approximation error. ∎
Theorem 2.2 — Policy iteration: monotone improvement demonstrated Alternate: (i) exact evaluation \(V^{\pi_k} = T_{\pi_k} V^{\pi_k}\) (linear system); (ii) greedy improvement \(\pi_{k+1}(s) \in \arg\max_a r(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{\pi_k}(s')\), that is, \(\pi_{k+1}\) greedy for \(V^{\pi_k}\).
Monotonicity. First \(T_{\pi_{k+1}} V^{\pi_k} = \mathcal{T}V^{\pi_k} \geq V^{\pi_k}\) component by component (the max over the actions dominates the action played by \(\pi_k\)). Next, \(T_{\pi_{k+1}}\) is monotone (\(U \geq V \Rightarrow T_{\pi} U \geq T_\pi V\), by positive linearity of the expectation), so by induction \(T_{\pi_{k+1}}^{j+1} V^{\pi_k} \geq T_{\pi_{k+1}}^{j} V^{\pi_k} \geq V^{\pi_k}\); in the limit \(V^{\pi_{k+1}} = \lim_j T_{\pi_{k+1}}^j V^{\pi_k} \geq V^{\pi_k}\). Finite termination. If \(V^{\pi_{k+1}} = V^{\pi_k}\), then \(\mathcal{T}V^{\pi_k} = T_{\pi_{k+1}} V^{\pi_k} = V^{\pi_k}\): \(V^{\pi_k}\) is a fixed point of \(\mathcal{T}\), hence equal to \(V^\star\) (uniqueness, Th. 1.6). Since the value increases strictly at every non-terminal iteration and there is a finite number (\(|\mathcal{A}|^{|\mathcal{S}|}\)) of deterministic policies, the algorithm stops after a finite number of iterations on an optimal policy. ∎
Value vs policy iteration — costs and trade-offs Value iteration: cheap iterations (\(O(|\mathcal{S}|^2 |\mathcal{A}|)\)) but very many; policy iteration: few iterations (often < 20) but each one requires solving a linear system (\(O(|\mathcal{S}|^3)\)). In practice on large \(\mathcal{S}\): neither is exactly tractable — but all of modern RL is a "noisy and approximated" version of these two schemes.
Proposition 2.3 — Modified policy iteration and asynchronous dynamic programming Modified PI (Puterman & Shin, 1978): replace the exact evaluation of \(\pi_k\) by \(m\) applications of \(T_{\pi_k}\) (with \(m\) small). \(m = \infty\) gives back PI, small \(m\) gets closer to VI; one interpolates the cost per iteration and the number of iterations — often the best compromise in practice. Asynchronous DP (Bertsekas & Tsitsiklis): update a freely chosen state \(s\) (Gauss-Seidel, partial sweeps, priority to relevant states). Theorem: if every state is visited infinitely often, asynchronous DP converges to \(V^\star\). This is the gateway to RL: the algorithms of chapters 3–5 are "sampled" asynchronous DPs, where the update is made on the state actually visited.
Proposition 2.4 — Propagation of approximation errors Suppose that at every iteration a bounded error sneaks in: \(\tilde V_{k+1} = \mathcal{T}\tilde V_k + \varepsilon_k\), with \(\|\varepsilon_k\|_\infty \leq \varepsilon\). Then $$\|\tilde V_k - V^\star\|_\infty \;\leq\; \gamma^k \|\tilde V_0 - V^\star\|_\infty \;+\; \frac{\varepsilon}{1-\gamma}.$$
By recursion and contraction: \(\|\tilde V_{k+1} - V^\star\| \leq \gamma \|\tilde V_k - V^\star\| + \varepsilon\), then by telescoping \(\|\tilde V_k - V^\star\| \leq \sum_{i<k} \gamma^i \varepsilon + \gamma^k \|\tilde V_0 - V^\star\|\) and geometric sum. ∎
Major consequence for deep RL: any approximation error (network, sampling) is multiplied by \(\frac{1}{1-\gamma}\). With \(\gamma = 0.99\), a factor of 100: this is why approximating \(V\) or \(Q\) is difficult, and why the choice of \(\gamma\) is a genuine design choice. 
import numpy as np

# 4x4 gridworld: states 0..15, actions 0..3 (up, down, left, right)
S, A, gamma = 16, 4, 0.95
goal = 15
P = np.zeros((S, A, S)); r = -np.ones((S, A))
def step(s, a):
    i, j = divmod(s, 4)
    di, dj = [(-1,0),(1,0),(0,-1),(0,1)][a]
    return 4*min(max(i+di,0),3) + min(max(j+dj,0),3)
for s in range(S):
    for a in range(A):
        s2 = step(s, a)
        P[s, a, s2] = 1.0
        if s2 == goal or s == goal: r[s, a] = 0.0
r[goal] = 0.0

def T_op(V):                      # optimal Bellman operator
    return (r + gamma * (P @ V)).max(axis=1)

# --- Value iteration (th. 2.1) ---
V = np.zeros(S)
for _ in range(200):
    V_new = T_op(V)
    if np.abs(V_new - V).max() < 1e-10: break   # stopping criterion th. 2.1
    V = V_new
Q = r + gamma * (P @ V)
print("VI :", V.reshape(4,4).round(2))

# --- Policy iteration (th. 2.2) ---
pi = np.zeros(S, dtype=int); V = np.zeros(S)
while True:
    # (i) exact evaluation: (I - gamma P^pi) V = r^pi
    R = r[np.arange(S), pi]
    Ppi = P[np.arange(S), pi]
    V = np.linalg.solve(np.eye(S) - gamma * Ppi, R)
    # (ii) greedy improvement
    Q = r + gamma * (P @ V)
    pi_new = Q.argmax(axis=1)
    if (pi_new == pi).all(): break              # stable policy: optimal
    pi = pi_new
print("PI :", V.reshape(4,4).round(2))
