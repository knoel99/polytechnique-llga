1. Markov decision processes

Definition 1.1 — MDP An MDP is a tuple \((\mathcal{S}, \mathcal{A}, P, r, \gamma)\): states \(\mathcal{S}\), actions \(\mathcal{A}\), transition kernel \(P(s' \mid s, a)\), reward \(r(s, a, s')\) (we write \(r(s,a)\) for its expectation), discount factor \(\gamma \in [0, 1)\). A policy \(\pi(a \mid s)\) governs the choice of actions; the objective is the discounted expected return $$J(\pi) = \mathbb{E}_\pi\Big[\sum_{t=0}^{\infty} \gamma^t R_t\Big].$$ Fixing a policy \(\pi\) in an MDP induces a Markov chain with kernel \(P^\pi(s' \mid s) = \sum_a \pi(a \mid s) P(s' \mid s, a)\) — chapter 0 applies literally; \(\gamma < 1\) guarantees that all the sums converge.
Proposition 1.2 — Stationary deterministic policies It suffices to search among deterministic policies \(\pi : \mathcal{S} \to \mathcal{A}\) and stationary ones (not depending on \(t\)): for every mixed non-stationary policy, there exists a stationary deterministic policy with at least equal value in every state. (Proof: backward induction on the horizon then \(\gamma\)-discounted limiting passage; see Puterman, 2005.) The search space is finite: \(|\mathcal{A}|^{|\mathcal{S}|}\) candidates — too large for enumeration, hence chapters 2 and following.
Definition 1.3 — Value functions $$V^\pi(s) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s\Big], \qquad Q^\pi(s, a) = \mathbb{E}_\pi\Big[\sum_t \gamma^t R_t \,\Big|\, S_0 = s, A_0 = a\Big].$$ \(V^\pi\) = "how much the state is worth"; \(Q^\pi\) = "how much the state-action pair is worth". We have \(V^\pi(s) = \sum_a \pi(a\mid s)\, Q^\pi(s,a)\) and \(Q^\pi(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s')\).
Definition 1.4 — Occupancy measures The occupancy measure of \(\pi\) (from \(\mu_0\)) is $$\rho_\pi(s, a) = (1 - \gamma)\sum_{t=0}^{\infty} \gamma^t\, \mathbb{P}_\pi[S_t = s, A_t = a], \qquad \text{so that} \qquad J(\pi) = \frac{1}{1-\gamma}\sum_{s,a} \rho_\pi(s,a)\, r(s,a).$$ \(\rho_\pi\) is a probability distribution over \(\mathcal{S} \times \mathcal{A}\); it describes "where the policy lives". It is the natural bridge toward the LP formulation below and toward the importance ratios of chapter 4 (sampling under \(\pi\), evaluating under \(\pi'\)).
Theorem 1.5 — Bellman equations (evaluation) $$Q^\pi(s, a) = r(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^\pi(s'), \qquad V^\pi(s) = \sum_a \pi(a \mid s)\Big[r(s,a) + \gamma \sum_{s'} P(s'\mid s,a) V^\pi(s')\Big].$$ This is dynamic programming applied to time: today's value = immediate gain + discounted value of tomorrow. Writing \(T_\pi\) for the operator \((T_\pi V)(s) = \sum_a \pi(a|s)\big[r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')\big]\), the equation rewrites as \(V^\pi = T_\pi V^\pi\) — a linear system of \(|\mathcal{S}|\) equations (\((I - \gamma P^\pi) V = r^\pi\), invertible since \(\gamma < 1\)).
Theorem 1.6 — Optimality: existence, uniqueness (complete proof) Consider the optimal Bellman operator $$(\mathcal{T}V)(s) = \max_a \Big\{ r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V(s') \Big\}.$$ (1) \(\mathcal{T}\) is a contraction of modulus \(\gamma\) on \((\mathbb{R}^{|\mathcal{S}|}, \|\cdot\|_\infty)\) (a complete space). Proof in two lemmas:
Lemma (max-Lipschitz). For all bounded families \((u_a)_a\), \((v_a)_a\): \(|\max_a u_a - \max_a v_a| \leq \max_a |u_a - v_a|\). Indeed, for every \(a\), \(u_a \leq v_a + \max_b |u_b - v_b|\), so \(\max_a u_a \leq \max_a v_a + \max_b |u_b - v_b|\); exchanging the roles, \(|\max_a u_a - \max_a v_a| \leq \max_b |u_b - v_b|\). Contraction. For each \(s\), setting \(u_a = r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s')\) and \(v_a\) the analogue for \(V'\): $$\big|(\mathcal{T}V)(s) - (\mathcal{T}V')(s)\big| \leq \max_a \gamma \Big|\sum_{s'} P(s'|s,a)\big(V(s') - V'(s')\big)\Big| \leq \gamma\, \|V - V'\|_\infty,$$ since \(P(\cdot|s,a)\) is a probability distribution. Taking the max over \(s\): \(\|\mathcal{T}V - \mathcal{T}V'\|_\infty \leq \gamma \|V - V'\|_\infty\). (2) Fixed point. By Banach's fixed-point theorem (L3 reminder: contraction on a complete space), \(\mathcal{T}\) admits a unique fixed point \(V^\star\), and \(\mathcal{T}^k V \to V^\star\) for every starting \(V\), at geometric speed \(\gamma^k\). We set \(Q^\star = r + \gamma P V^\star\), which satisfies $$Q^\star(s, a) = r(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, \max_{a'} Q^\star(s', a').$$ (3) Optimal policy. Let \(\pi^\star\) be greedy for \(V^\star\): \(\pi^\star(s) \in \arg\max_a Q^\star(s,a)\). Then \(T_{\pi^\star} V^\star = \mathcal{T}V^\star = V^\star\), so \(\|T_{\pi^\star}^k V^\star - V^\star\|_\infty \leq \gamma^k \|T_{\pi^\star} V^\star - V^\star\|_\infty = 0\) for every \(k\); in the limit \(V^{\pi^\star} = V^\star\). Hence \(\pi^\star\) attains the supremum \(\sup_\pi V^\pi\) in every state: it is an optimal stationary deterministic policy. ∎
Proposition 1.7 — Linear (LP) formulation of MDPs Solving an MDP amounts to solving the (dual) linear program: $$\max_{\mu \geq 0}\ \sum_{s,a} \mu(s,a)\, r(s,a) \quad \text{s.t.} \quad \sum_a \mu(s', a) \;=\; \nu(s') + \gamma \sum_{s,a} P(s' \mid s, a)\, \mu(s,a) \ \ \forall s',$$ where \(\nu\) is the initial distribution. The variables \(\mu\) are the occupancy measures \(= \rho_\pi/(1-\gamma)\); the constraints are "flow equations" (what enters a state = initial distribution + what leaves it, discounted). An extreme optimal solution of the polytope is attained at a deterministic policy, and \(\pi^\star(s) = \arg\max_a \mu^\star(s, a)\). Interest: LPs are solved in polynomial time (but polynomial in \(|\mathcal{S}| |\mathcal{A}|\), quickly enormous); the dual viewpoint also sheds light on the linear approximation methods for the value. The primal writes \(\min_V \sum_s \nu(s) V(s)\) s.t. \(V(s) \geq r(s,a) + \gamma \sum_{s'} P V\) for all \((s, a)\) — the constraints are the Bellman inequalities.
Role of \(\gamma\) \(\gamma\) discounts the future but also conditions the whole theory: contraction of modulus \(\gamma\), error bounds in \(1/(1-\gamma)\) (chapter 2), variance of the returns. When \(\gamma \to 1\), one tends toward the average criterion \(\lim_T \frac{1}{T}\sum_t R_t\) — related to the ergodic theorem 0.2 — but all the rates degrade: RL lives with this tension.
