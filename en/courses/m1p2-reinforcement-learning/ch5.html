5. Deep RL: DQN, Rainbow, continuous methods and offline RL

Algorithm 5.1 — DQN (Mnih et al., 2015) Q-learning where \(Q(s, a; \theta)\) is a network; stabilized by:
  • experience replay: resampling past transitions (breaks the temporal correlation and approaches the i.i.d. assumption of SGD);
  • target network \(\theta^-\) frozen and periodically synchronized: target \(y = r + \gamma \max_{a'} Q(s', a'; \theta^-)\) (avoids chasing a moving target — the deadly triad, ch. 3);
  • loss \(\big(y - Q(s, a; \theta)\big)^2\).
# Minimal DQN (PyTorch) -- the three stabilizers in evidence
replay = deque(maxlen=100_000)            # 1. experience replay
def train_step(batch=128, gamma=0.99):
    s, a, r, s2, done = sample(replay, batch)
    with torch.no_grad():                 # 2. target network (frozen theta^-)
        y = r + gamma * (1 - done) * target_net(s2).max(1).values
    q = policy_net(s).gather(1, a).squeeze(1)
    loss = F.smooth_l1_loss(q, y)         # 3. TD loss (Huber, more robust)
    optimizer.zero_grad(); loss.backward()
    torch.nn.utils.clip_grad_norm_(policy_net.parameters(), 10)
    optimizer.step()
# Double DQN (algorithm 3.6): replace the 'y' line with
#   a2 = policy_net(s2).argmax(1, keepdim=True)          # selection: current network
#   y = r + gamma * (1 - done) * target_net(s2).gather(1, a2).squeeze(1)  # evaluation: target
Algorithm 5.2 — Rainbow (Hessel et al., 2018): six ingredients Rainbow combines six independent improvements of DQN, each attacking a precise weakness:
IngredientIdeaFixes
Double Q-learningdecouple selection/evaluation (Algorithm 3.6)overestimation bias (Th. 3.5)
Prioritized replaysample transitions proportionally to the TD error \(|\delta|\)uniform replay
Dueling architecturetwo heads \(V(s)\) and \(A(s,a)\), recombined \(Q = V + A - \mathrm{avg}_a A\)similar actions, state/value generalization
Multi-step (n-step)target with the \(G^{(n)}\) return (Def. 3.3), typically \(n=3\)slow reward propagation
Distributional (C51)predict the distribution of \(Z(s,a)\) over 51 atoms, Wasserstein losssignal variance, richer learning
Noisy netsnoisy biases/weights, explored by the learned noise itselfcrude \(\varepsilon\)-greedy
Rainbow's main contribution is to show that the gains compose: the combination reaches median human level on 57 Atari games in ~7M frames — 44M frames fewer than DQN.

5.1. Continuous actions: DDPG and SAC

Algorithm 5.3 — DDPG (Lillicrap et al., 2016) The \(\max_a\) is impossible in continuous spaces; DDPG learns two networks: a critic \(Q_w(s,a)\) and a deterministic actor \(\mu_\theta(s)\) trained by the deterministic policy gradient \(\nabla_\theta J = \mathbb{E}\big[\nabla_a Q_w(s, a)\big|_{a = \mu_\theta(s)}\, \nabla_\theta \mu_\theta(s)\big]\) — the max of Q-learning is replaced by gradient ascent of \(Q\) through the actor. Off-policy (replay + targets), but fragile: the \(Q\)/actor pair can settle on erroneous maxima of \(Q\) (overestimation, again); TD3 adds double Q and noisy targets.
Algorithm 5.4 — SAC: maximum entropy, derivation SAC (Haarnoja et al., 2018) maximizes the return and the entropy: $$J(\pi) = \mathbb{E}\Big[\sum_t \gamma^t \big(r_t + \alpha\, \mathcal{H}(\pi(\cdot \mid S_t))\big)\Big], \qquad \mathcal{H}(\pi) = -\mathbb{E}_{a \sim \pi}[\log \pi(a \mid s)].$$
Optimal softmax policy. For a fixed \(Q\), let us maximize \(F(\pi) = \mathbb{E}_{a\sim\pi}[Q(s,a)] + \alpha \mathcal{H}(\pi(\cdot|s))\) over distributions. Set \(\pi^\star(a|s) \propto \exp(Q(s,a)/\alpha)\), with normalization constant \(Z(s) = \sum_a e^{Q(s,a)/\alpha}\). Then: $$F(\pi) = -\alpha\, \mathbb{E}_\pi\Big[\log \frac{\pi(a|s)}{\pi^\star(a|s)}\Big] + \alpha \log Z(s) = -\alpha\, \mathrm{KL}(\pi \,\|\, \pi^\star) + \alpha\log Z(s),$$ (identification by expanding \(\log \pi^\star = Q/\alpha - \log Z\)). The unique maximum is attained at \(\pi = \pi^\star\), with value \(\alpha \log Z(s)\): the optimal policy weights the actions by a softmax of temperature \(\alpha\) of the Q-values — exploring is literally optimal in this criterion. "Soft" Bellman operator. The target equation becomes \(Q^\star(s,a) = r(s,a) + \gamma\, \mathbb{E}_{s'}[V(s')]\) with the soft value \(V(s') = \alpha \log \sum_{a'} e^{Q(s',a')/\alpha}\) — the max is replaced by a log-sum-exp of temperature \(\alpha\); the log-sum-exp is 1-Lipschitz for \(\|\cdot\|_\infty\), so \(\mathcal{T}_{\mathrm{soft}}\) remains a \(\gamma\)-contraction: the whole theory of chapter 1 survives. ∎
Auto-learned temperature \(\alpha\). \(\alpha\) tunes the exploration/exploitation trade-off; SAC treats it by a Lagrangian: minimize \(J(\alpha) = \mathbb{E}[-\alpha \log \pi(a|s)] - \alpha\, \bar{\mathcal{H}}\), where \(\bar{\mathcal{H}}\) is the target entropy: \(\alpha\) rises when the actual entropy falls below the target (forced exploration), falls otherwise. Implementation: three networks (actor + two critics, min against overestimation), reparameterization to backpropagate through sampling, GAE useless (off-policy). SAC is the standard for continuous environments (robotics, control).

5.2. Offline RL and sim-to-real

Offline RL (batch learning): the distribution shift Data: a fixed dataset \(\mathcal{D}\) of transitions (teleoperator, logs, simulator); no interaction. The danger: \(Q\) is evaluated on out-of-distribution actions (never tried in \(\mathcal{D}\)); the \(\max_{a'}\) of Q-learning queries the network where it has seen nothing — uncorrected overestimation (Theorem 3.5, aggravated). Conservative Q-Learning (Kumar et al., 2020, sketch): regularize \(Q\) so that it is low on out-of-dataset actions and high on dataset actions: $$\mathcal{L}(\theta) = \mathbb{E}_{\mathcal{D}}\big[(y - Q_\theta)^2\big] + \alpha\Big(\mathbb{E}_{a' \sim \pi, s' \sim \mathcal{D}}[Q_\theta(s', a')] - \mathbb{E}_{(s,a) \sim \mathcal{D}}[Q_\theta(s,a)]\Big).$$ The policy is then extracted from the regularized \(Q\) — it no longer dares to leave the support of the data. Other approaches: BCQ (restricting to actions close to the data), IQL (expectile regression, no out-of-support query). Offline RL is the bridge toward RLHF: learning a reward/policy from fixed preferences is an offline problem (cf. M2 LLMs module).
Sim-to-real In robotics, training happens in a simulator (cheap, parallelizable) then transfers to the real robot — whose dynamics differ (friction, latency, sensors). Tools: domain randomization (randomizing mass/friction/texture to make the policy robust to discrepancies, Tobin et al., 2017), system identification, online adaptation (short real fine-tuning). The unifying theme: robustness to model errors — the same tension as the \(1/(1-\gamma)\) error propagation of Proposition 2.4.
LLGA cross-references Off-policy vs on-policy (DQN reuses the whole past, PPO discards after one batch): exactly the sample-efficiency/stability trade-off found again in LLM post-training — cf. M2 Large Language Models module. Multi-worker distributed RL (A3C, IMPALA) is a special case of distributed SGD — cf. Emerging Subjects in ML module, chapter 2. High-dimensional exploration (count-based, RND) is treated in chapter 6.
