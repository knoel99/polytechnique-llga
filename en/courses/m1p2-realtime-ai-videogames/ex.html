Exercises

  1. Fixed step. Simulate by hand the accumulator loop with \(\Delta t = 1/30\) s and actual frames of 40, 25, 50 ms; how many ticks per frame; what happens if the anti-spiral bound is removed when a frame lasts 200 ms?
  2. Admissibility. On an 8-connected grid (straight moves 1, diagonals \(\sqrt 2\)), show that Manhattan can overestimate \(h^*\) (give a one-cell example) and prove that the octile heuristic is admissible.
  3. A* on a grid. A 6×6 grid with walls \(\{(1,2),(1,3),(2,3),(3,3),(4,3)\}\), start \((0,0)\), goal \((5,5)\); run octile A* by hand (open/closed table), then verify with the chapter's code; what changes with a terrain weight of 2 on column 4?
  4. FSM → BT. A Guard FSM: Patrol → (noise) → Inspect → (nothing) → Patrol; Patrol → (sees player) → Attack → (low hp) → Flee. Draw the equivalent BT (selector + guard sequences); add the interruption "alerted by a comrade" to it — why is it simpler in the BT?
  5. Ticking a BT. On the BT of the chapter 3 code, trace the status of each node for an agent (hp = 50, enemy visible, attack in progress) over three ticks, including the one where the enemy dies; identify the "running" nodes and the selector's re-evaluation.
  6. UCT by hand. Root with 15 visits; children A (n=10, w=7), B (n=3, w=3), C (n=2, w=0); c = 0.7, \(\ln 15 \approx 2{,}71\). Compute the three UCT values, say which one is explored; after a winning rollout on that node, recompute and comment on the "tightening".
  7. Rollouts. For tic-tac-toe: implement MCTS (1000 iterations) and measure the draw rate against a random player; compare budgets of 10 / 100 / 1000 / 10000 iterations; from what budget does the agent become unbeatable?
  8. Steering. An agent at \(p = (0,0)\), \(v = (2,0)\) m/s, \(a_{\max} = 6\) m/s², motionless target at \((8, 0)\), \(r_{\mathrm{arr}} = 3\) m, \(\tau = 0{,}2\) s; compute \(v_{\mathrm{des}}\), the arrive force and the position/velocity after a 0.1 s tick (Euler integration); why would pure seek oscillate here?
  9. Formations. A triangle formation of offsets \(\{(0,0), (-2,1), (-2,-1)\}\); leader at \((10, 5)\), heading \(\theta = 90°\). Compute the world positions of the slots; then assign by the Hungarian algorithm to three agents at \((8,4), (7,7), (12,3)\) (Euclidean cost); what happens if the assignment is greedy?
  10. Dynamic assistance. Design a rubber-banding controller: input = normalized distance \(d\) to the player; output = speed bonus \(v \in [0{,}9, 1{,}15]\); impose hysteresis (distinct rise/fall thresholds) and inertia — write the equations and discuss the tuning so that an average player notices nothing.
  11. AI budget. 300 agents; decision re-evaluation at 5 Hz (spread uniformly over frames), neighborhood by spatial grid (\(O(1)\) amortized), 60 fps; estimate the cost per frame (agents deciding per frame × cost of one BT) and the memory of the navigation data; compare with the "every agent every frame" option.
  12. Project. In Python (sandbox provided): a grid world with obstacles, 20 boids-navmesh agents; implement (a) A* + path following, (b) a survival BT (flee a predator, eat, wander), (c) an MCTS predator (5 ms per decision) on a discretized version of the game; measure survival rate per configuration and compute time per frame — deliver a report with the chapter 9 checklist.
