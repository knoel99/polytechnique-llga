9. Conformal prediction: theorem and algorithm

Question: can we build prediction sets with coverage guaranteed without any distributional assumption? Answer (Vovk): yes, provided one has exchangeable data and accepts marginal coverage. This is the most useful result of the UQ part.

Definition 9.1 — Non-conformity scores and exchangeability Any score \(s(x, y)\) (small = conforming): for classification, \(s = 1 - \hat p(y \mid x)\) (softmax of the true class); for regression, \(s = |y - \hat f(x)|\). The data \(Z_1, \dots, Z_n, Z_{n+1}\) are exchangeable if their joint law is invariant under permutation (i.i.d. ⇒ exchangeable; cf. Statistics in Action ch. 11 for the de Finetti connection — exchangeability, not i.i.d., is the true foundation). Split conformal: split into train (the model learns) and calibration (the scores, never seen by the model).
Theorem 9.2 — Exact marginal coverage (proved) Let \(s_1, \dots, s_n\) be the calibration scores and \(s_{\text{new}}\) the score of a new pair, exchangeable at \((n+1)\) with continuous values. For \(\alpha \in (0, 1)\), set \(k = \lceil (n+1)(1 - \alpha) \rceil\) and let \(\hat q\) be the \(k\)-th smallest calibration score. Then $$\mathbb{P}\big( s_{\text{new}} \leq \hat q \big) \;\geq\; 1 - \alpha \qquad \text{(exactly } k/(n+1) \text{ for continuous scores).}$$
By exchangeability, the rank of \(s_{\text{new}}\) in the multiset \(\{s_1, \dots, s_n, s_{\text{new}}\}\) is uniform over \(\{1, \dots, n+1\}\). Justification: for every permutation \(\sigma\) of \(\{1, \dots, n+1\}\), the law of \((Z_{\sigma(1)}, \dots, Z_{\sigma(n+1)})\) is that of \((Z_1, \dots, Z_{n+1})\); the event "the rank of the last coordinate equals \(r\)" is the image by permutation of "the rank equals \(r'\)" for all \(r, r'\) — same probability, and the sum of the \(n+1\) probabilities equals 1: each equals \(1/(n+1)\). With continuous scores, ties are almost surely absent, and the event \(\{s_{\text{new}} \leq \hat q\}\) is exactly \(\{\text{rank} \leq k\}\), of probability \(k/(n+1) \geq 1 - \alpha\) by definition of \(k\). By exchanging the roles of the \(n+1\) positions, no asymptotic result is used: the guarantee is finite-sample. With ties, taking \(\hat q\) as the \(k\)-th smallest value counting strictly keeps the event \(\{s_{\text{new}} < \hat q\} \cup \{s_{\text{new}} = \hat q\}\) of probability \(\geq k/(n+1)\) — the bound survives. ∎
Example 9.3 — Split conformal, algorithm and worked example Algorithm. (1) train \(\hat f\) on the train set; (2) compute the scores \(s_i\) on the \(n\) calibration points; (3) \(k = \lceil (n+1)(1-\alpha) \rceil\), \(\hat q\) = \(k\)-th smallest score; (4) predict, for a new \(x\), the set \(C(x) = \{y : s(x, y) \leq \hat q\}\) — in regression: \([\hat f(x) - \hat q, \hat f(x) + \hat q]\). Example (regression). \(n = 9\), \(\alpha = 0.1\) ⇒ \(k = \lceil 10 \times 0.9 \rceil = 9\). Absolute calibration residuals: 0.02 · 0.05 · 0.08 · 0.11 · 0.14 · 0.19 · 0.25 · 0.34 · 0.51 — the 9th (largest) is \(\hat q = 0.51\); the prediction for any new \(x\) is \(\hat f(x) \pm 0.51\), with \(\mathbb{P}(\text{cover}) \geq 90\%\) — exactly \(9/10 = 90\%\) if the future residuals resemble the calibration ones. Classification: same steps with \(s = 1 - \hat p(\text{candidate predicted class})\); the set \(C(x)\) contains the classes with sufficient softmax; typical size 1 where the model is confident, 2-3 at the boundaries — the map of set sizes is a free ambiguity detector. Effect of \(n\): the empirical \((1-\alpha)\)-quantile with finite-sample correction \(\lceil(n+1)(1-\alpha)\rceil\) — the reason for the \(+1\): without it, \(\alpha > 1/(n+1)\) would be impossible (e.g. \(\alpha = 0.1\), \(n = 5\): one needs \(k = \lceil 5.4 \rceil = 6 > n\)… in that case the set is all of \(\mathbb R\): the algorithm honestly admits its ignorance). 
import numpy as np
rng = np.random.default_rng(1)

n_cal, alpha = 3000, 0.1
Xtr, Xcal, Xte = ...           # exchangeable split
model.fit(Xtr, ytr)            # never the calibration set
s_cal = np.abs(y_cal - model.predict(X_cal))       # non-conformity scores
k = int(np.ceil((n_cal + 1) * (1 - alpha)))        # 9 for n=9; 2701 for n=3000
qhat = np.sort(s_cal)[k - 1]
lo, hi = model.predict(X_te) - qhat, model.predict(X_te) + qhat

# empirical check of the coverage (exercise 6)
cov = ((y_te >= lo) & (y_te <= hi)).mean()
print(f"qhat = {qhat:.3f}, observed coverage = {cov:.3f} (target >= {1-alpha})")
What the theorem says — and does not say Coverage is marginal: on average over the draws of the calibration set and of new pairs. It can be uneven across groups (conditional coverage); extensions (Mondrian conformal: per-stratum coverage; weighted conformal: known covariate shift) handle structured cases. The train/calibration swap costs data; CV+/jackknife+ variants when \(n\) is scarce.
