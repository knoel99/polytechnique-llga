7. Calibration: diagrams, ECE, Brier

Definition 7.1 — Reliability diagram, bins, ECE Partition \([0, 1]\) into \(B\) bins; bin \(b\) = predictions with mean confidence \(\mathrm{conf}_b\), observed accuracy \(\mathrm{acc}_b\), count \(n_b\). The reliability diagram plots \(\mathrm{acc}_b\) against \(\mathrm{conf}_b\) (the diagonal = perfect calibration); the expected calibration error: $$\mathrm{ECE} = \sum_{b=1}^{B} \frac{n_b}{n} \big| \mathrm{acc}_b - \mathrm{conf}_b \big|.$$ Precautions on binning: the partition influences the measure (10 bins is the de facto standard); kernel / isotonic-regression variants preferable in research (Naeini et al. 2015; see also the Machine Learning module ch. 9 for evaluation curves).

$$\mathrm{ECE} = 0.005 + 0.010 + 0.025 + 0.0325 + 0.0225 = \mathbf{0.095}.$$ Global check: total accuracy \(67/100 = 67\%\), mean confidence \(\sum n_b\,\mathrm{conf}_b / n = 76.5\%\) — a gap of \(9.5\) points, consistent: the model is systematically overconfident by ~10 points, and the reliability diagram would be a curve below the diagonal bending downward. This is the signature measured by Guo et al. (2017) on modern networks: more depth/capacity ⇒ more overconfidence, not less.
Definition 7.3 — Brier score and its decomposition (Brier 1950; Murphy 1973) $$\mathrm{BS} = \frac{1}{n}\sum_i (\hat p_i - y_i)^2, \qquad \text{decomposition:} \quad \mathrm{BS} = \underbrace{\text{reliability}}_{\text{calibration}} - \underbrace{\text{resolution}}_{\text{discrimination}} + \underbrace{\text{uncertainty}}_{\text{irreducible}}.$$ The reliability term \(= \sum_b \frac{n_b}{n}(\mathrm{conf}_b - \mathrm{acc}_b)^2\) (the squared, weighted ECE); resolution measures the deviation of the \(\mathrm{acc}_b\) from the prevalence; uncertainty \(= \bar y (1 - \bar y)\) does not depend on the model. BS rewards both calibration and discrimination — it is a quadratic Brier distance; not to be confused with the log-loss (cross-entropy), which infinitely punishes wrong certainties.
Example 7.4 — Brier computed, and the mirage of confidence Four predictions: \((0.9; y{=}1)\), \((0.9; y{=}1)\), \((0.9; y{=}0)\), \((0.3; y{=}1)\): $$\mathrm{BS} = \frac{0.1^2 + 0.1^2 + 0.9^2 + 0.7^2}{4} = \frac{0.01 + 0.01 + 0.81 + 0.49}{4} = 0.33.$$ The constant predictor equal to the prevalence \(3/4 = 0.75\) achieves \(\mathrm{BS} = 0.75 \times 0.25 = 0.1875 < 0.33\): without information, it is better to state the base rate than to assert 90% — exactly the problem of overenthusiastic models.
Procedure 7.5 — Temperature scaling (Guo, Pleiss, Sun, Weinberger, 2017) A single scalar \(T > 0\) recalibrates the logits: \(\hat p_T(y \mid x) = \mathrm{softmax}(z/T)\); \(T\) fitted by NLL on a validation set (a 1D optimization — which does not change the argmax, hence not the accuracy). Computed. Two classes, logits \(z = (4; 0)\): \(\mathrm{softmax}(z) = (0.982; 0.018)\); \(T = 2\): \(\mathrm{softmax}(2, 0) = (0.881; 0.119)\); \(T = 4\): \(\mathrm{softmax}(1, 0) = (0.731; 0.269)\). If the true frequency of class 1 in this neighborhood is ~75%, \(T \approx 4\) is the right calibration — the ranking of the predictions is intact, only the confidence scale is corrected. Limits: \(T\) is global, calibrated on a fixed distribution; local recalibration: isotonic, Platt per bin, or conformalized calibration (ch. 9-10). 
import numpy as np
def ece(conf, y, bins=15):
    edges = np.linspace(0, 1, bins + 1); idx = np.digitize(conf, edges[1:-1])
    n = len(conf); total = 0.0
    for b in range(bins):
        m = idx == b
        if m.sum() == 0: continue
        total += (m.sum()/n) * abs(y[m].mean() - conf[m].mean())
    return total

def fit_temperature(logits, y, grid=np.linspace(0.5, 10, 200)):
    # NLL on validation, one dimension, non-parametric and sufficient for labs
    best_T, best = 1.0, np.inf
    for T in grid:
        z = logits / T
        p = np.exp(z - z.max(1, keepdims=True))
        p /= p.sum(1, keepdims=True)
        nll = -np.log(np.clip(p[np.arange(len(y)), y], 1e-12, None)).mean()
        if nll < best: best, best_T = nll, T
    return best_T
