4. Proximal methods: ISTA and FISTA

Gradient descent requires a gradient — impossible for \(F = f + \lambda\|\theta\|_1\). The proximal trick: handle the smooth part with a gradient step, the non-smooth part with an explicit operation.

Definition 4.1 — Proximal operator For \(g\colon \mathbb{R}^d \to \mathbb{R} \cup \{+\infty\}\) convex lower semi-continuous: $$\mathrm{prox}_{t g}(v) = \arg\min_x \;\Big\{ g(x) + \frac{1}{2t}\|x - v\|^2 \Big\}.$$ Special cases: \(g = 0\) gives \(v\) (gradient descent); \(g = \iota_C\) (indicator of a closed convex set \(C\)) gives the projection \(\Pi_C(v)\); \(g = \lambda\|\cdot\|_1\) gives componentwise soft thresholding (example 1.4).
Proposition 4.2 — Firm non-expansiveness (proved) For all \(v, w\): \(\|\mathrm{prox}_{tg}(v) - \mathrm{prox}_{tg}(w)\| \;\leq\; \|v - w\|\).
Write \(p = \mathrm{prox}_{tg}(v)\), \(q = \mathrm{prox}_{tg}(w)\). The optimality condition 1.2 gives \(0 \in \partial g(p) + \tfrac{1}{t}(p - v)\) and \(0 \in \partial g(q) + \tfrac{1}{t}(q-w)\), that is \(\tfrac{1}{t}(v - p) \in \partial g(p)\) and \(\tfrac{1}{t}(w-q) \in \partial g(q)\). Monotonicity of the subdifferential (\(\langle u - u', x - x'\rangle \geq 0\) for \(u \in \partial g(x)\), \(u' \in \partial g(x')\)) yields \(\langle (v-p) - (w-q),\, p - q\rangle \geq 0\), i.e. \(\langle v - w, p - q\rangle \geq \|p-q\|^2\). By Cauchy–Schwarz, \(\|v-w\| \geq \|p-q\|\). ∎
Definition 4.3 — ISTA and FISTA (Beck–Teboulle 2009; Daubechies et al. 2004) ISTA (iterative shrinkage-thresholding): $$x_{k+1} = \mathrm{prox}_{t g}\big(x_k - t\,\nabla f(x_k)\big), \qquad t \leq 1/L.$$ FISTA (fast ISTA): ISTA + the Nesterov acceleration stage — $$y_k = x_k + \frac{k-1}{k+2}\,(x_k - x_{k-1}), \qquad x_{k+1} = \mathrm{prox}_{t g}\big(y_k - t\,\nabla f(y_k)\big).$$
Theorem 4.4 — Rates of ISTA (proved) and FISTA (admitted here) Let \(F = f + g\) with \(f\) convex \(L\)-smooth and \(g\) convex, and let \(R = \|x_0 - x^\star\|\). ISTA at step \(1/L\) satisfies $$F(x_k) - F(x^\star) \;\leq\; \frac{L R^2}{2k} \qquad\text{(and } F(x_{k+1}) \leq F(x^\star) + \tfrac{L}{2}\|x_{k+1}-x^\star\|^2 \text{ propagates as in ch. 2).}$$ FISTA achieves \(F(x_k) - F(x^\star) \leq \frac{2L R^2}{(k+1)^2}\) — the \(\sqrt{\cdot}\) factor gained on the iteration count, exactly as in chapter 3.
Set \(u_k = x_k - t\nabla f(x_k)\), \(x_{k+1} = \mathrm{prox}_{tg}(u_k)\). (i) Proximal optimality. Writing 1.2 for the proximal problem at \(x_{k+1}\) against an arbitrary competitor \(y\) gives, after expanding the squares: $$g(x_{k+1}) \;\leq\; g(y) + \frac{1}{2t}\Big(\|y - x_k\|^2 - \|x_{k+1} - x_k\|^2\Big) + \langle \nabla f(x_k),\, y - x_{k+1}\rangle.$$ (ii) Smoothness of \(f\). \(f(x_{k+1}) \leq f(x_k) + \langle\nabla f(x_k), x_{k+1}-x_k\rangle + \tfrac{L}{2}\|x_{k+1}-x_k\|^2\). (iii) Sum with \(y = x^\star\), \(t = 1/L\). The cross terms cancel and there remains \(F(x_{k+1}) - F(x^\star) \leq \tfrac{L}{2}\big(\|x^\star - x_k\|^2 - \|x_{k+1}-x_k\|^2\big) - \tfrac{1}{2L}\dots\) then the same telescoping as in theorem 2.2 (the distances to \(x^\star\) decrease by convexity of \(F\) and the proximal inequality) gives the sum in \(O(LR^2)\), hence the \(1/k\). The FISTA proof (Beck–Teboulle 2009, th. 4.4) propagates the estimate sequence of ch. 3 through the same pair (i)+(ii). ∎
Example 4.5 — LASSO: ISTA vs FISTA in practice 
import numpy as np
rng = np.random.default_rng(0)
n, d, s = 60, 200, 8                       # underdetermined, sparse support
X = rng.normal(size=(n, d)); X /= np.sqrt(n)
theta_true = np.zeros(d); theta_true[:s] = rng.normal(size=s)
y = X @ theta_true + 0.05 * rng.normal(size=n)

L = np.linalg.norm(X, 2) ** 2              # Lipschitz constant of f = 0.5||Xt-y||^2
lam = 0.1 * np.linalg.norm(X.T @ y, np.inf)

def soft(v, t): return np.sign(v) * np.maximum(np.abs(v) - t, 0)

def ista(x, iters):
    for _ in range(iters):
        x = soft(x - (1/L) * X.T @ (X @ x - y), lam/L)
    return x

def fista(x, iters):
    z, t = x.copy(), 1.0
    for k in range(1, iters+1):
        xn = soft(z - (1/L) * X.T @ (X @ z - y), lam/L)
        t_next = (1 + np.sqrt(1 + 4*t*t)) / 2
        z = xn + ((t-1)/t_next) * (xn - x)   # Nesterov momentum
        x, t = xn, t_next
    return x

F = lambda th: 0.5*np.sum((X@th - y)**2) + lam*np.abs(th).sum()
x0 = np.zeros(d)
for it in (100, 1000):
    print(it, "ISTA:", F(ista(x0.copy(), it)), "FISTA:", F(fista(x0.copy(), it)))
# expected: at 1000 iterations, FISTA ~ 1e2--1e3 times closer to the optimum
The \(1/k^2\) vs \(1/k\) factor is literally visible: same computations per iteration, radically different horizons. This is also the foundation of compressed sensing solvers and of large-scale LASSO (see the Machine Learning module, ch. 2).
Beyond: ADMM in one sentence When even \(f\) decomposes badly (\(f = f_1 + f_2\) with two easy proxes but coupled variables), the ADMM method (augmented duality: rewrite \(\min f_1(x) + f_2(z)\) subject to \(x = z\), alternate a prox over \(x\), a prox over \(z\), a dual step on the multiplier) inherits \(O(1/k)\) rates and reigns over problems with massive constraints. The loop is closed with ch. 0: this is applied duality, hence the augmented Lagrangian — see ch. 8.
