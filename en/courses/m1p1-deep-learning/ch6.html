6. Attention and transformers

6.1. Scaled dot-product: why \(\sqrt{d_k}\)

Definition 6.1 — Scaled dot-product attention (Vaswani et al., 2017) For tokens \(i = 1..n\) with embeddings \(x_i\), one computes $$q_i = W_q x_i,\quad k_i = W_k x_i,\quad v_i = W_v x_i,$$ $$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\Big(\frac{Q K^\top}{\sqrt{d_k}}\Big) V, \qquad \alpha_{ij} = \frac{\exp(q_i^\top k_j / \sqrt{d_k})}{\sum_{j'} \exp(q_i^\top k_{j'} / \sqrt{d_k})}.$$ Multi-head: \(h\) attention heads in parallel (projections \(W^q_m, W^k_m, W^v_m\), dimensions \(d_k = d/h\)), concatenated then projected — several independent "communication channels".
Proposition 6.2 — The variance of the scores grows like \(d_k\) If the components of \(q\) and \(k\) are iid, centered, with variance 1, then \(q^\top k = \sum_{\ell=1}^{d_k} q_\ell k_\ell\) is centered with variance exactly \(d_k\). Without normalization, the standard deviation of the scores is \(\sqrt{d_k}\) (32 for \(d_k = 1024\)): the softmax becomes a one-hot argmax, its gradients vanish — saturation, cf. chapter 0, proposition 0.3. Dividing by \(\sqrt{d_k}\) brings the variance back to 1, independent of the dimension.
Centering: \(\mathbb{E}[q_\ell k_\ell] = \mathbb{E}[q_\ell]\,\mathbb{E}[k_\ell] = 0\) (independence). Variance: the terms \(q_\ell k_\ell\) are mutually iid, so \(\mathrm{Var}(\sum_\ell q_\ell k_\ell) = \sum_\ell \mathrm{Var}(q_\ell k_\ell) = d_k\, \mathbb{E}[q_\ell^2]\mathbb{E}[k_\ell^2] = d_k\). After dividing by \(\sqrt{d_k}\), the variance of the normalized score equals \(1\). Consequence for saturation: the typical gaps between normalized scores are \(\mathcal{O}(1)\), the exponential ratios \(\exp(s_i - s_j)\) stay in a reasonable range and the softmax keeps a nonzero gradient; without scaling, gaps of order \(\sqrt{d_k} \gg 1\) produce a near one-hot distribution, whose gradient (\(\hat y_k(\delta_{kj} - \hat y_j)\)) tends to 0. ∎

6.2. Block architecture: pre-norm, RoPE

  • Post-norm (Vaswani et al., original): \(y = \mathrm{LN}(x + \mathrm{Att}(x))\) — the residual connection passes through the normalization. Pre-norm (GPT-2 and after): \(y = x + \mathrm{Att}(\mathrm{LN}(x))\) — the identity path is intact (proposition 4.6): the gradient reaches the input without attenuation, which makes training stable at large depth and reduces the need for warmup; a final LayerNorm compensates for the absence of output normalization. The current standard.
  • RoPE (rotary position embedding, Su et al., 2021): instead of adding a positional code, one rotates each pair of coordinates \((q_{2i}, q_{2i+1})\) by an angle \(m\,\theta_i\) depending on the position \(m\) of the token (and on \(i\)), with \(\theta_i = b^{-2i/d}\). Proof of the "relative" character: planar rotations commute and \(R(m)^\top R(n) = R(n - m)\), so $$\langle R(m)\, q,\; R(n)\, k \rangle = q^\top R(m)^\top R(n)\, k = q^\top R(n-m)\, k,$$ the score depends only on the gap \(n - m\): position is encoded within the interaction, with unbounded length support — this is the encoding of modern LLMs (cf. LLMs module, M2).

6.3. Costs and efficient attention

  • Complexity: \(\mathcal{O}(n^2 d)\) time and \(\mathcal{O}(n^2)\) memory (\(QK^\top\) matrix of size \(n \times n\) per head) — the LLM bottleneck. The MLP is \(\mathcal{O}(n d^2)\): attention dominates as soon as \(n \gtrsim d\).
  • FlashAttention (Dao et al., 2022): exact, but IO-aware — it tiles the computation of softmax(QK^T)V into blocks loaded into SRAM (the GPU's fast memory) and never writes the \(n \times n\) matrix to HBM, maintaining online log-sum-exp statistics (proposition 0.3 makes the softmax incremental: blocks are merged with \(m\) and the partial sum). Result: same FLOPs, \(\mathcal{O}(n)\) memory, ×2 to ×4 speed in practice.
  • Approximations: sparse, linear, sliding window (cf. LLMs module, M2).
"Graph" reading (Karpathy, 2025-2026) — the bridge to the Graph ML module A transformer is a neural network on a dynamic graph:
  • each token = a node carrying a vector;
  • attention computes weighted edges \(\alpha_{ij}\) from the data (dynamic graph, unlike GNNs);
  • \(\sum_j \alpha_{ij} v_j\) is a message passing: the nodes exchange their "values";
  • the MLP block = the local computation of each node; residual + LayerNorm = plumbing so that the "graph" stays trainable;
  • a transformer layer = communication (attention) then computation (MLP), exactly the alternation of a GNN.
The LLGA program exploits this double reading: the same mathematical object seen "from inside the LLM" (M2 module) and "on structured data" (Graph ML module).

6.4. A complete block in PyTorch

import torch, torch.nn as nn, torch.nn.functional as F

class Block(nn.Module):
    """A pre-norm transformer block: multi-head causal attention + MLP."""
    def __init__(self, d, n_heads, p_drop=0.1):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.n_heads, self.d_head = n_heads, d // n_heads
        self.qkv = nn.Linear(d, 3 * d)
        self.proj = nn.Linear(d, d)
        self.mlp = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))
        self.drop = nn.Dropout(p_drop)

    def forward(self, x):                          # x: (B, n, d)
        B, n, d = x.shape
        q, k, v = self.qkv(self.ln1(x)).chunk(3, -1)
        # multi-head: (B, n, d) -> (B, n, h, d_head) -> (B, h, n, d_head)
        def split(t): return t.view(B, n, self.n_heads, self.d_head).transpose(1, 2)
        q, k, v = split(q), split(k), split(v)
        mask = torch.tril(torch.ones(n, n, device=x.device))     # causal mask
        att = F.scaled_dot_product_attention(q, k, v,            # softmax(QK^T/sqrt(d_head))V
                                             attn_mask=mask, dropout_p=0.0)
        att = att.transpose(1, 2).reshape(B, n, d)               # merge the heads back
        x = x + self.drop(self.proj(att))                        # residual 1 (pre-norm)
        x = x + self.drop(self.mlp(self.ln2(x)))                 # residual 2
        return x

torch.manual_seed(0)
x = torch.randn(2, 16, 128)
model = nn.Sequential(*[Block(128, 4) for _ in range(4)])
print(model(x).shape)                              # [2, 16, 128]

  • MLP: two layers with GELU, expansion ratio ~4 — this is where most of the parameters live (~2/3);
  • Causal mask: forbid \(j > i\) for autoregression — exactly the factorization \(\mathbb{P}(x) = \prod_t \mathbb{P}(x_t \mid x_{<t})\) of chapter 7.
