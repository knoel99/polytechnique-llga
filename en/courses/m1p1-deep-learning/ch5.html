5. Sequences: RNN, LSTM

5.1. RNN and backpropagation through time

Definition 5.1 — RNN (Elman) $$h_t = \tanh(W_h h_{t-1} + W_x x_t + b), \qquad y_t = W_y h_t$$ A hidden state that summarizes the past; weights shared across time (like the CNN kernel across space). The sequence \((x_1, \dots, x_T)\) is processed by unrolling the network: \(T\) copies of the same block — the computation graph becomes acyclic again (chapter 2), and backprop applies to it "through time" (BPTT). Memory cost: \(\mathcal{O}(T)\) activations.
Theorem 5.2 — Exponential explosion or vanishing of the gradient For a loss at the final step \(T\), writing \(D_t = \mathrm{diag}\big(\tanh'(a_t)\big)\): $$\frac{\partial \mathcal{L}_T}{\partial h_0} = \Big( \prod_{t=1}^{T} D_t\, W_h^\top \Big) \frac{\partial \mathcal{L}_T}{\partial h_T} \quad\Rightarrow\quad \Big\| \frac{\partial \mathcal{L}_T}{\partial h_0} \Big\| \;\le\; \|W_h\|^{T}\, \prod_{t=1}^{T}\|\tanh'(a_t)\|_\infty\, \Big\| \frac{\partial \mathcal{L}_T}{\partial h_T} \Big\|.$$ If \(\|W_h\| \cdot \max_t \|\tanh'(a_t)\|_\infty < 1\), the gradient decays exponentially with \(T\) (vanishing); if \(\|W_h\| > 1\) with activations away from saturation, it explodes.
By theorem 2.1 applied to the unrolled graph, \(\partial \mathcal{L}_T/\partial h_{t-1} = (\partial h_t / \partial h_{t-1})^\top \partial \mathcal{L}_T/\partial h_t\) since \(h_{t-1}\) has only one successor \(h_t\). Now \(h_t = \tanh(W_h h_{t-1} + W_x x_t + b)\), so the Jacobian equals \(J_t = D_t W_h\) with \(D_t\) diagonal (derivative of tanh component by component). Composing from \(t = T\) down to \(t = 1\) and using sub-multiplicativity \(\|ABC\| \le \|A\|\,\|B\|\,\|C\|\) (operator norm): \(\|\prod_t J_t^\top\| \le \prod_t \|J_t^\top\| \le \prod_t \|D_t\|\,\|W_h\|\), and \(\|D_t\| = \max_i |\tanh'(a_{t,i})| \le 1\), with strict inequality < 1 as soon as one coordinate approaches saturation. Hence the bound: exponential decay in \(T\) as soon as the per-step factor is < 1, possible exponential growth when \(\|W_h\| > 1\) (the bound is only an upper bound, but experiments confirm both regimes; explosion is handled by gradient clipping — truncating \(\|\hat g\|\) at a threshold — vanishing, for its part, is structural). ∎

5.2. LSTM: complete equations and the role of the gates

Definition 5.3 — LSTM (Hochreiter & Schmidhuber, 1997) Four "gates" (vectors of \([0,1]^d\) via sigmoids, acting as multiplicative valves) and a cell state \(c_t\) that transitions additively: $$f_t = \sigma(W_f h_{t-1} + U_f x_t), \qquad i_t = \sigma(W_i h_{t-1} + U_i x_t),$$ $$o_t = \sigma(W_o h_{t-1} + U_o x_t), \qquad \tilde c_t = \tanh(W_c h_{t-1} + U_c x_t),$$ $$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t, \qquad h_t = o_t \odot \tanh(c_t).$$
  • \(f_t\), forget gate: fraction of the old memory kept — it is what carries long memory; often initialized with \(b_f > 0\) (positive forget bias) so that \(f \approx 1\) at the start.
  • \(i_t\), input gate: how much of the candidate \(\tilde c_t\) is written; \(\tilde c_t\): the proposed content.
  • \(o_t\), output gate: how much of the cell is exposed in \(h_t\).
  • Why it mitigates vanishing: the cell follows \(c_t = f_t \odot c_{t-1} + (\dots)\), an additive highway — the gradient \(\partial c_t/\partial c_{t-1} = \mathrm{diag}(f_t) + i_t\)-terms stays close to the identity when \(f_t \approx 1\) and \(i_t\) modest, where the RNN systematically multiplied by \(W_h^\top D_t\). The product of the Jacobians can stay ~1 over long horizons: long dependencies get through. (The problem is not solved: for very long dependencies, attention will fix it — chapter 6.)
GRU (Cho et al., 2014) and comparison $$z_t = \sigma(W_z h_{t-1} + U_z x_t), \quad r_t = \sigma(W_r h_{t-1} + U_r x_t), \quad h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tanh\big(W h_{t-1} \odot r_t + U x_t\big).$$ Two gates instead of three, no separate cell state (\(z_t\) merges forget and write, \(r_t\) filters the read past): ~25% fewer parameters, generally comparable performance. In practice LSTM for long series, GRU for small datasets.
Teacher forcing and exposure bias When training a sequence-to-sequence model, the decoder is fed the true tokens (teacher forcing): the loss is computed in a single parallel pass, but the model only learns to predict given the exact past. At inference, it feeds on its own (possibly wrong) outputs — an exposure mismatch that makes long generations drift; mitigated by scheduled sampling or reinforcement learning (cf. RL module, and NLP module).
