6. Collaboration, personalization, fairness

  • Personalization: a global model + local heads (light per-client fine-tuning); Bayesian interpretation (mixture of posteriors); multi-task formalization (Ditto, ch. 3);
  • Model fusion and mode connectivity: two networks trained from the same initialization are connected by a nearly flat path in the loss surface (low barrier along the segment — Frankle et al., 2020); consequence for collaboration: local models can be averaged… provided they stay in the same basin; realigning the neuron permutations between two models is the key to recent fusions (sketch); these are the theoretical foundations of FedAvg (the averaging of chapter 3 only makes sense in this regime);
  • Data markets: valuing a data source by its marginal contribution — Shapley value \(\phi_i = \sum_{S \ni i}\) [gain of the model with \(S\) minus without \(i\)] (estimated by Monte-Carlo permutations); data buyers/sellers, incentives for quality — game theory meets ML;
  • Vertical FL: clients hold different features about the same individuals (bank × retailer): split learning, exchanges of protected intermediate representations — a complement to the "horizontal" FL of ch. 3;
  • Fairness: performance per subgroup (demographic parity, equalized odds); in the federated setting, fairness cuts across clients; the Computational Optimal Transport module provides tools (barycenters, fairness via OT);
  • Toward multi-agent systems: when "workers" become LLM agents, collaboration becomes orchestration (roles, votes, verification) — the loop is closed with the Reinforcement Learning and Autonomous Agents module, chapter 7; the mechanisms of this module (robust aggregation, budgets, incentives) carry over directly.
