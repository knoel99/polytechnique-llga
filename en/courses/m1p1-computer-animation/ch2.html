2. Numerical integration of ODEs

Definition 2.1 — One integration step An integrator (or scheme) builds a sequence \(\mathbf{y}_{n} \approx \mathbf{y}(t_n)\), \(t_n = n h\), through a map \(\mathbf{y}_{n+1} = \Phi_h(\mathbf{y}_n)\). The module's three reference schemes, for \(\dot{\mathbf{y}} = f(\mathbf{y})\): $$\text{Explicit Euler}\ (EE)\ : \quad \mathbf{y}_{n+1} = \mathbf{y}_n + h f(\mathbf{y}_n)$$ $$\text{Symplectic Euler}\ (ES)\ : \quad \begin{cases} \mathbf{v}_{n+1} = \mathbf{v}_n + h\, \mathbf{a}(\mathbf{x}_n, \mathbf{v}_n)\\ \mathbf{x}_{n+1} = \mathbf{x}_n + h\, \mathbf{v}_{n+1} \end{cases}$$ $$\text{Implicit Euler}\ (EI)\ : \quad \mathbf{y}_{n+1} = \mathbf{y}_n + h f(\mathbf{y}_{n+1}) \ \ \text{(to be solved, e.g. by Newton)}$$ For Newton's second law \(\dot{\mathbf{x}} = \mathbf{v},\ \dot{\mathbf{v}} = \mathbf{a}(\mathbf{x})\), ES updates the velocity first, then the position with the new velocity — a single line of code different from EE, and a qualitatively different behavior (chapter 3).
Definition 2.2 — Local error and order The local error of a scheme is \(e(h) = \|\Phi_h(\mathbf{y}(t_n)) - \mathbf{y}(t_n + h)\|\) (a single step from the exact solution). The scheme is of order \(p\) if \(e(h) = O(h^{p+1})\); the global error accumulated over a fixed time interval is then \(O(h^p)\).
Theorem 2.3 — Explicit Euler is of order 1 If \(f\) is \(C^2\), the local error of explicit Euler is \(\mathbf{y}(t_n + h) - \Phi_h(\mathbf{y}(t_n)) = \tfrac{h^2}{2}\ddot{\mathbf{y}}(t_n) + O(h^3)\): the scheme is of order 1 (global error in \(O(h)\)).
Taylor: \(\mathbf{y}(t_n + h) = \mathbf{y}(t_n) + h\dot{\mathbf{y}}(t_n) + \tfrac{h^2}{2}\ddot{\mathbf{y}}(t_n) + O(h^3)\). Now \(\dot{\mathbf{y}}(t_n) = f(\mathbf{y}(t_n))\) and \(\Phi_h(\mathbf{y}(t_n)) = \mathbf{y}(t_n) + h f(\mathbf{y}(t_n))\): the difference is exactly the term \(\tfrac{h^2}{2}\ddot{\mathbf{y}} + O(h^3)\). ∎

The error decreases as equilibrium is approached (the system is dissipative); but if \(h > 2/(c/m) = 1\) s, the factor \(1 - 2h < -1\) and the sequence oscillates while diverging — a prelude to chapter 3. Note that RK4 (order 4, four evaluations of \(f\) per step) divides the error by \(\sim 10^3\) at equal \(h\) on this smooth example, without decisively changing the stability condition.
Which scheme for which animation? In production: symplectic Euler for particles and garments (free, stable, slightly damping), implicit Euler (or semi-implicit via Newton, a few iterations) for stiff systems — hair, fine cloth, fluids —, "leapfrog" Verlet (order 2, symplectic) in video games, RK4 rarely, because it is expensive and not symplectic. Order is not the first criterion in animation; stability and qualitative conservation (bounded energy) take precedence — this is the subject of the next chapter.
