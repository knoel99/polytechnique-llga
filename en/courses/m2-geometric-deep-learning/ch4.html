4. Functional maps

Theorem/Concept 4.1 — Functional Maps (Ovsjanikov et al., 2012) Instead of looking for the point-to-point correspondence (a combinatorial discrete map, costly), transport functions defined on the surfaces: $$T_F : \mathcal{F}(M) \to \mathcal{F}(N), \qquad T_F(g) = g \circ T^{-1}$$ Restricted to the spectral bases \(\Phi_M, \Phi_N\) (the first \(k\) eigenfunctions), the map becomes a small matrix \(C \in \mathbb{R}^{k \times k}\): $$b_N \approx C\, b_M \quad (b = \Phi^\top f).$$ A correspondence of \(10^5\) points is replaced by \(k^2\) numbers (\(k \sim 30\)): this is the paradigm shift of the field.
Constraints 4.2 — what C must satisfy
  • Descriptor preservation: if \(D_M \in \mathbb{R}^{k \times q}\) are the coefficients of \(q\) descriptors (HKS, WKS...) on \(M\) and \(D_N\) on \(N\) (in the same order): $$C\,D_M \approx D_N \qquad (k \times q \text{ equations});$$
  • Commutation with operators: $$C\,\Lambda_M \approx \Lambda_N\,C$$ (spectral regularization — the subject of the proof below);
  • Orthogonality: if one believes in an isometry, \(C^\top C \approx I\) (preserves inner products of functions; follows from \(\Phi_N^\top C = \Phi_M^\top\) for orthonormal bases);
  • Correspondence coupling: if a few pairs of points are known, \(\Phi_N^\top \Pi^\top \Phi_M \approx C\) with \(\Pi\) the permutation matrix (hard constraint vs least squares).
Commutation: proved. Assume \(T : M \to N\) is an isometry and let \(T_F\) denote the transport of functions. The invariance theorem of ch. 2 (full proof in 2.5) says: \(\Delta_M(f \circ T) = (\Delta_N f)\circ T\), in other words $$\Delta_M \, T_F = T_F\, \Delta_N \quad\text{(after identifying the directions)}.$$ Apply to \(f = \phi_k^N\) (eigenfunction of \(N\), \(\Delta_N\phi_k^N = -\lambda_k^N\phi_k^N\)): \(\Delta_M\,T_F\phi_k^N = T_F(-\lambda_k^N\phi_k^N) = -\lambda_k^N\,T_F\phi_k^N\): the transport of an eigenfunction is an eigenfunction for the same eigenvalue. If the spectrum is simple, \(T_F\phi_k^N = \pm\phi_k^M\); in the eigenbasis, the matrix of \(T_F\) is therefore almost diagonal: \(C_{ij} \ne 0\) only if \(\lambda_i^M\) and \(\lambda_j^N\) coincide — hence the constraint \(C\Lambda_M \approx \Lambda_N C\) (weak: in the least-squares sense, since real surfaces are only approximately isometric and multiple eigenvalues create blocks). ∎
Resolution 4.3 — least squares and normal equations $$C^* = \arg\min_C\ \big\|C D_M - D_N\big\|_F^2 + \alpha\big\|C\Lambda_M - \Lambda_N C\big\|_F^2 + \beta\big\|C^\top C - I\big\|_F^2 + \mu\|C\|_F^2.$$ Without the orthogonality term, each row \(c_i\) of \(C\) is solved independently by normal equations: $$c_i = \big(D_M D_M^\top + \alpha\,\Omega + \mu I\big)^{-1} D_M d_i^{\;N\top},$$ with \(\Omega\) the regularization matrix derived from commutation — a \(k \times k\) linear system solved in a few milliseconds. With orthogonality, one projects onto rotations (SVD: \(C \leftarrow UV^\top\) — Procrustes projection).
Conversion to point-to-point correspondence + refinement Soft correspondence: $$P = \Phi_N\, C\, \Phi_M^\top \in \mathbb{R}^{|V_N| \times |V_M|}, \qquad \Pi(x) = \arg\max_y P_{yx}$$ — the matrix \(P\) (barely dense, a product of three long matrices) encodes the "probability" that \(y\) corresponds to \(x\). Refinement (the ZoomOut spirit, ch. 8): iteratively, (1) increase \(k\) by one notch; (2) recompute \(C\) using the current hard correspondence as a coupling constraint; (3) re-derive \(P\). The growing spectral resolution acts as annealing: large structures settle at small \(k\) (strong regularization), details adjust afterwards — algorithm: 
C = least_squares(k=k0, descriptors)          # coarse start
for k in range(k0, kmax, step):
    Pi = argmax_per_column(Phi_N[k] @ C @ Phi_M[k].T)   # hard
    C = solve(constraints + coupling(Pi), dim=k)        # soft
return Pi                                          # final correspondence
  • Partial maps: when only a part of \(M\) corresponds to \(N\), \(T_F\) becomes a restriction; the matrix \(C\) is then rectangular (or one embeds \(M\) into \(N\) via a prolongation operator); the constraints adapt (descriptors only on the visible part);
  • Learned extensions: the descriptors \(D\) can be produced by a network (SpectralNet, then GeomFMaps — deep geometric functional maps): the network learns descriptors that are optimal for the matrix C, the resolution remaining a differentiable least squares; the complete computation graph (network → C → correspondence loss) is trained end to end;
  • Supervised vs unsupervised: with annotated pairs (FAUST), one directly supervises the geodesic error of \(\Pi\); otherwise, one maximizes orthogonality and preservation (HKS on both sides): unsupervised works well for quasi-isometries (humans);
  • Applications: texture transfer: the texture (a color function!) on \(M\) is transported by \(b_N = C\,b_M\) — a matrix multiplication; pose transfer (the correspondence coordinates), morphing;
  • LLGA connection: a functional map ≈ an optimal transport between reduced bases; shape alignment ≈ graph alignment by Gromov-Wasserstein (OT module, ch. 5); the three languages — GNN, OT, functional maps — describe the same operation of structural correspondence.
