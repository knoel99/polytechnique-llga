8. Applications and hands-on

  • Recommendation: user-item graph, link prediction (ch. 6); PinSage (3B nodes, 18B edges) = GraphSAGE at industrial scale; cold-start = the inductive case par excellence;
  • Fraud detection: node classification on the transaction graph; typical signals: counter proximities, money-laundering cycles (the motifs matter!), card hubs — GNNs capture the multihop neighborhood that an iid model ignores; temporal version in M2 (ch. 5);
  • Chemistry / biotech: molecule = graph (atoms = nodes, bonds = edges); graph classification to predict properties (toxicity, solubility, HIV activity); benchmarks: ZINC, QM9, ogbg-mol*; 3D and equivariance are in M2 (ch. 3 and 9);
  • Knowledge graph completion: link prediction on heterogeneous KGs (TransE, R-GCN — ch. 6); the basis of "enterprise" RAG (ch. 11);
  • Scale up: neighborhood minibatching, clustering, sampling (ch. 7), multi-node GPUs (M2, ch. 6); open benchmarks: OGB.
Architecture choice — quick decision sheet Homogeneous graph, rich features: GCN (baseline); noisy/heterogeneous edges (fraud): GAT / R-GCN; inductive production: GraphSAGE; need to distinguish local structures (cycles): GIN + motif features (M2, ch. 1); long-range dependencies (molecules, QA over KGs): graph transformer (M2, ch. 4). Always: 2-4 layers, skip connections, light dropedge as a first choice.
