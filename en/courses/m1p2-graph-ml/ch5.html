5. GNNs and message passing

Definition 5.1 — The message passing layer (MPNN, Gilmer et al., 2017) $$h_v^{(\ell+1)} = \phi\Big(h_v^{(\ell)},\ \underset{u \in \mathcal{N}(v)}{\mathrm{AGG}}\ \big\{\psi\big(h_v^{(\ell)}, h_u^{(\ell)}\big)\big\}\Big)$$ message \(\psi\) (computed by the neighbor), aggregation \(\mathrm{AGG}\) (permutation-invariant: sum, mean, max, attention), update \(\phi\). One layer = one round of message passing = one convolution = one diffusion step on the graph. The choice of \(\mathrm{AGG}\) is not innocent: mean/max lose cardinality ({a, a} and {a} have the same mean and the same max); this is the subject of the GIN theorem (M2, ch. 1).
Derivation 5.2 — GCN from spectral convolution (Kipf & Welling, 2017) Start from the Chebyshev filter truncated at \(K = 1\) on the renormalized Laplacian \(L_{\mathrm{sym}} = I - \tilde D^{-1/2} \tilde A \tilde D^{-1/2}\), \(\tilde A = A + I\), whose eigenvalues live in \([0, 2]\) (hence the rescaling \(\tilde\Lambda \approx \Lambda - I\) by approximating \(\lambda_{\max} \approx 2\)): $$g_\theta(\tilde\Lambda) \approx \theta_0\, T_0 + \theta_1\, T_1(\tilde\Lambda) = \theta_0 I + \theta_1 (\Lambda - I).$$ Fixing the renormalization trick \(\theta_0 = -\theta_1 = \theta\) (a single parameter, filter increasing toward the low frequencies, self-loops stabilizing the dynamics): $$g_\theta \approx \theta\,(2I - L_{\mathrm{sym}}) = \theta\, \tilde D^{-1/2} \tilde A \tilde D^{-1/2}.$$ Adding the non-linearity, the hidden dimension and the features \(X\), we obtain the GCN layer: $$H^{(\ell+1)} = \sigma\Big(\tilde D^{-1/2}\, \tilde A\, \tilde D^{-1/2}\, H^{(\ell)}\, W^{(\ell)}\Big), \qquad H^{(0)} = X,$$ a renormalized mean of the transformed representations of the neighbors; \(L\) layers = a receptive field of \(L\) hops. The renormalization (i) cancels the zero eigenvalue (no constant component injected), (ii) keeps the gains in \([-1, 1]\) — a stability condition for depth, related to the over-smoothing below.
GraphSAGE (Hamilton et al., 2017) — algorithm and pseudo-code For each node, aggregate a sample of neighbors then concatenate with the current representation: 
input : G, features X, depth K, sample sizes s_1..s_K
for v in V : h_v^(0) = x_v
for l = 1 .. K :
    for v in V :
        S_v = uniform sample of N(v) of size s_l               # K neighbors in the paper
        a_v^(l) = AGG({ h_u^(l-1) : u in S_v })                 # mean / LSTM / pool
        h_v^(l) = sigma( W_l . [ h_v^(l-1) || a_v^(l) ] )       # concatenation!
        h_v^(l) = h_v^(l) / ||h_v^(l)||                          # L2 normalization
output : z_v = h_v^(K)
The concatenation preserves the information specific to the node (otherwise the mean of the neighbors crushes the local signal); the fixed per-layer sampling bounds the minibatch (ch. 7); the whole scheme is inductive: the weights \(W_l\) are re-applied to unseen nodes/graphs. Special cases: AGG = mean ≈ GCN without renormalization; AGG = pool (MLP + max); AGG = LSTM over neighbors randomly ordered (the ordering breaks invariance… an accepted approximation; the ordering problem is addressed by GOAT, ch. 10).
GAT (Veličković et al., 2018) — equations and complexity Edge weights learned by attention: $$e_{uv} = \mathrm{LeakyReLU}\big(a^\top [\,W h_u \| W h_v\,]\big), \qquad \alpha_{uv} = \frac{\exp(e_{uv})}{\sum_{u' \in \mathcal{N}(v)} \exp(e_{uv'})}, \qquad h_v^{(\ell+1)} = \sigma\Big(\sum_{u \in \mathcal{N}(v)} \alpha_{uv}\, W h_u^{(\ell)}\Big)$$ with \(T\) parallel attention heads (T projections \(W^{(t)}\)) concatenated or averaged. Per-layer complexity: \(\mathcal{O}(|V| F F' + |E| F')\) — linear in edges, comparable to GCN, but with weights tailored to each edge: useful when the graph is noisy or some relations matter more (suspicious transactions!). Structurally identical to the attention of transformers (Deep Learning module): here the attention mask is given by the graph, there it is computed — the graph transformers of M2 (ch. 4) close the loop by learning the attention and biasing it with structure.
Beyond the homogeneous graph: R-GCN, edge features
  • R-GCN (Schlichtkrull et al., 2018): relational graph (edge types \(r\) in \(\mathcal{R}\)); \(h_v^{(\ell+1)} = \sigma\big(W_0 h_v^{(\ell)} + \sum_{r \in \mathcal{R}} \sum_{u \in \mathcal{N}_r(v)} \frac{1}{c_{v,r}} W_r\, h_u^{(\ell)}\big)\). To avoid the parameter explosion (\(|\mathcal{R}| \times F \times F'\)): basis decomposition \(W_r = \sum_b a_{rb} V_b\) or block-diagonal. Typical use: encoding knowledge graphs for link prediction (ch. 6).
  • Edge features: (a) line graph (each edge becomes a node); (b) convolution over edges (NNConv): \(\psi(h_u, e_{uv})\) instead of \(\psi(h_u)\) — the chemical bond carries a type; (c) conditioned attention (GAT can inject \(e_{uv}\) into the \(e_{uv}\)-score).
  • Hierarchical pooling: DiffPool (Ying et al., 2018) learns a soft assignment matrix \(S^{(\ell)} = \mathrm{softmax}(\mathrm{GNN}_A(H^{(\ell)}))\) and contracts the graph: \(H^{(\ell+1)} = S^{(\ell)\top} H^{(\ell)}\), \(A^{(\ell+1)} = S^{(\ell)\top} A^{(\ell)} S^{(\ell)}\) — neural coarse-graining, costly but hierarchical; alternatives: sort/TopK pooling, pyramidal readout.
Theorem 5.3 — Over-smoothing: proof on a regular graph On a connected \(d\)-regular graph, GCN propagation without weights/non-linearity satisfies \(H^{(\ell)} = P^\ell X\) with \(P = \frac{A + I}{d + 1}\). Then $$H^{(\ell)} \xrightarrow[\ell \to \infty]{} \frac{\mathbf{1}\mathbf{1}^\top}{n}\, X,$$ the harmonic solution (global mean), at geometric rate \(\big(\frac{\lambda_2(A) + 1}{d + 1}\big)^\ell\).
On a \(d\)-regular graph, \(D = (d+1)I\) for \(\tilde A\), hence \(\tilde D^{-1/2} \tilde A \tilde D^{-1/2} = (A + I)/(d+1) =: P\). Since \(A\) is real symmetric, write \(X\) in its eigenbasis: \(A = \sum_i \lambda_i u_i u_i^\top\) with \(u_1 = \mathbf{1}/\sqrt{n}\), \(\lambda_1 = d > \lambda_2 \geq \dots\), and \(\lambda_i < d\) for \(i \geq 2\) (equality only if there is a distinct connected component). Then \(P^\ell = \sum_i \big(\frac{\lambda_i + 1}{d+1}\big)^\ell u_i u_i^\top\); the \(i = 1\) term equals exactly \(\frac{\mathbf{1}\mathbf{1}^\top}{n}\); all the others have a ratio \(\frac{\lambda_i + 1}{d + 1} < 1\) (and \(\geq 0\) if the graph is not bipartite; otherwise \(> -1\) in absolute value) and decay geometrically. All the information of the non-constant components is erased: every node converges to the same mean row vector — the embeddings collapse. ∎
With weights and non-linearities, the phenomenon persists (rank collapse; Oono & Suzuki, ICLR 2020): this is a structural limit of GCN depth. Remedies:
  • Jumping Knowledge (Xu et al., 2018): the readout aggregates all the depths \(h_v = \mathrm{JK}(h_v^{(1)}, \dots, h_v^{(L)})\) (concat / max / LSTM-attention): each node chooses its scale;
  • residuals and normalizations (GCNII, APPNP — developed in M2, ch. 2);
  • in practice: 2-4 layers suffice, and often — the useful depth is that of the statistical dependence of the task.
A second structural limit — over-squashing (topological bottlenecks) — is different: it concerns the channel rather than the representation, and is addressed by rewiring; the whole topic is in M2, ch. 2. A third limit: expressivity bounded by 1-WL (M2, ch. 1). 
import torch
from torch_geometric.nn import GCNConv, GATConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root="/tmp/Cora", name="Cora")   # 2708 nodes, 5429 edges, 7 classes
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self, d_in, d_hid, n_classes):
        super().__init__()
        self.c1, self.c2 = GCNConv(d_in, d_hid), GCNConv(d_hid, n_classes)
    def forward(self, x, edge_index):
        return self.c2(torch.relu(self.c1(x, edge_index)), edge_index)

model = GCN(dataset.num_features, 64, dataset.num_classes)
opt = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)
for epoch in range(200):
    opt.zero_grad()
    out = model(data.x, data.edge_index)
    loss = torch.nn.functional.cross_entropy(out[data.train_mask], data.y[data.train_mask])
    loss.backward(); opt.step()
acc = (model(data.x, data.edge_index).argmax(1)[data.test_mask]
       == data.y[data.test_mask]).float().mean()
print(f"Cora test accuracy : {acc:.3f}")   # ~0.81 with this simple setting
