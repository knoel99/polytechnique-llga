Exercises

  1. Laplacian. Show \(x^\top L x = \sum_{(u,v) \in E}(x_u - x_v)^2\), then that \(\lambda_2 > 0 \iff\) connected. Compute the spectrum of the path and of the cycle. Solution (sketch): expand \(x^\top D x - x^\top A x = \sum_v d_v x_v^2 - 2\sum_{(u,v)} x_u x_v\) and group by edges; \(\lambda_2 = 0\) is equivalent to the existence of a non-zero \(x \perp \mathbf{1}\) constant per component (thm. 0.3 of the multiplicity computation), hence \(\lambda_2 > 0\) \(\iff\) a single component. Path: \(2(1 - \cos\frac{k\pi}{n})\); cycle: \(2(1 - \cos\frac{2k\pi}{n})\).
  2. Triangles by the trace. From \(\mathrm{tr}(A^3)\), count the triangles of the "two \(K_4\)s sharing an edge" graph. Generalize: what does \(\mathrm{tr}(A^4)\) count? Solution: the two \(K_4\)s contain 4 triangles each, none goes through the shared edge alone; total 8, hence \(\mathrm{tr}(A^3) = 48\). \(\mathrm{tr}(A^4)\) counts the closed walks of length 4 (squares, back-and-forths…) — not only the squares; one must subtract the degree contributions (formula with \(\sum_v d_v^2\) for the back-and-forths).
  3. node2vec. Simulate walks with \((p, q) = (1, 1)\), \((0.25, 4)\), \((4, 0.25)\) on the karate club graph (code 3.4); project the embeddings in 2D (t-SNE) and relate \(p, q\) to the BFS/DFS strategies. Expected solution: \((p,q) = (0.25, 4)\) — strong return, weak exploration → BFS, embeddings grouped by role (the two hubs "Mr. Hi" and "Officer" move closer); \((4, 0.25)\) → DFS, clustering by factions (homophily), higher NMI for the split task; \((1,1)\) intermediate.
  4. NetMF by hand. For the triangle \(K_3\), compute \(M = \log\big(\frac{\mathrm{vol}}{bT}(\sum_{r=1}^T P^r) D^{-1}\big)\) with \(T = 2\), \(b = 1\), and interpret the signs. Solution: \(P = J - I\) (adjacency minus identity); \(P^2 = \frac{1}{2} I + \frac{1}{2} J\); \(\sum_{r\leq 2} P^r\) is strictly positive, \(D^{-1} = \frac13 I\), \(\mathrm{vol} = 6\) → \(M\) constant off-diagonal \(=\log(1.5)\), weaker diagonal — DeepWalk on a structureless graph can only reflect the degrees; conclusion: the target matrix is the signal.
  5. Permutation equivariance. Check that the GCN layer satisfies \(f(PX, PAP^\top) = P f(X, A)\) and interpret; show that a classic dense layer (MLP over concatenated features) does not satisfy it. Solution (sketch): \(\tilde D_{PAP^\top} = P \tilde D P^\top\) (the degrees follow the permutation), hence \(\tilde D_{PAP}^{-1/2} (P\tilde A P^\top) \tilde D_{PAP}^{-1/2} P X = P \tilde D^{-1/2} \tilde A \tilde D^{-1/2} X\); a dense MLP over the concatenation \([x_1 \| \dots \| x_n]\) applies different weights to each position — permuting the nodes changes the output other than through \(P\).
  6. GCN by hand. Implement a GCN layer without PyG (compute \(\tilde A\), \(\tilde D\)), check the equality of the outputs with GCNConv at fixed weights, then measure the over-smoothing: mean cosine similarity of the embeddings as a function of the number of layers (1 to 10). Solution (PyG-guided): 
    import torch, torch_geometric
from torch_geometric.datasets import Planetoid
data = Planetoid(root="/tmp/Cora", name="Cora")[0]
A = torch.zeros(2708, 2708)
A[data.edge_index[0], data.edge_index[1]] = 1.0
A_tilde = A + torch.eye(2708)
D_inv_sqrt = A_tilde.sum(1).pow(-0.5).diag()
P = D_inv_sqrt @ A_tilde @ D_inv_sqrt            # renormalized propagator
X = data.x
for L in range(1, 11):
    H = X
    for _ in range(L):
        H = P @ H                                 # pure propagation (thm. 5.3)
    cos = torch.nn.functional.cosine_similarity(
        H.unsqueeze(1), H.unsqueeze(0), dim=-1)
    print(L, (cos.sum() - 2708) / (2708 * 2707))  # -> converges to 1
  7. Spectral clustering. Apply algorithm 4.4 (k = 2) to the "two \(K_5\)s + bridge" graph, validating the Fiedler vector of example 4.3; compare Ncut and RatioCut for the found partition. Solution: signs of the vector \((1,1,1,1,0.70,-0.70,-1,-1,-1,-1)\) → exact partition; \(\mathrm{cut} = 1\), RatioCut \(= \frac{1}{5} + \frac{1}{5} = 0.4\); Ncut \(= \frac{1}{16} + \frac{1}{16}\) (volumes 16) = 0.125; any cut separating a single node has a RatioCut \(\frac{5}{1} + \frac{5}{9}\) far larger — the weighting by size does the job.
  8. GAT. Show that the memory complexity of the \(T\)-head attention is \(\mathcal{O}(T |E| F')\), and that with self-loops GCN is obtained as a special case of uniform attention. How does GAT handle the irregular graphs that GCN normalizes poorly?
  9. Link prediction. On Cora: mask 10% of the edges, encode with a GAE (ch. 6), score the pairs by \(\sigma(z_u^\top z_v)\); evaluate the AUC against sampled negatives; compare GAE vs VGAE vs DeepWalk embeddings (ch. 3). Solution (PyG-guided): 
    import torch.nn as nn
from torch_geometric.nn import GCNConv
from torch_geometric.utils import negative_sampling

class GAE(nn.Module):
    def __init__(self, d_in, d_hid):
        super().__init__()
        self.e1, self.e2 = GCNConv(d_in, d_hid), GCNConv(d_hid, d_hid)
    def forward(self, x, ei):
        return self.e2(torch.relu(self.e1(x, ei)), ei)

model, opt = GAE(1433, 64), None
opt = torch.optim.Adam(model.parameters(), lr=0.01)
# split: train_pos = 90% of the edges; test_pos = 10% + as many negatives
for ep in range(200):
    Z = model(data.x, train_pos_ei)
    neg = negative_sampling(train_pos_ei, num_nodes=2708)
    ei_all = torch.cat([train_pos_ei, neg], dim=1)
    lbl = torch.cat([torch.ones(train_pos_ei.size(1)),
                     torch.zeros(neg.size(1))])
    score = (Z[ei_all[0]] * Z[ei_all[1]]).sum(-1)
    loss = nn.functional.binary_cross_entropy_with_logits(score, lbl)
    opt.zero_grad(); loss.backward(); opt.step()
# AUC: rank the scores of the test edges and of fresh negatives
    Expected: AUC \(\approx 0.90\)–0.92.
  10. Scale. Derive the bound \(1 + s_L(1 + s_{L-1}(\dots))\) of the NeighborSampler; for ogbn-arxiv (mean degrees \(\approx\) 7, max 200+), which fanout \((s_1, s_2)\) do you recommend and why? Evaluate the accuracy gap vs full-batch on Cora while increasing the variance (fanouts (2,2), (5,5), (10,10)).
  11. Random generation. Implement ER and SBM (SBM: 4 blocks, \(B_{aa} = 0.8\), \(B_{ab} = 0.05\)), generate 500 graphs, and check with degree-MMD that ER does not reproduce the degree distribution of the SBM. Which minimal \(k\) of the spectral k-means (ch. 4) recovers the blocks?
  12. Neural generation. Train a small autoregressive model (sequential addition of nodes/edges, MLP + softmax — the GraphRNN scheme of ch. 9.4) on ZINC molecules; measure validity (chemical valence) and uniqueness of the generated graphs; compare with an Erdős-Rényi sampler of the same density. Hints: encode the binary \(S^i\) (max 4 atom types), teacher forcing, 200 epochs are enough for the lab; reading: low validity (\(< 50\%\)) without a valence constraint — explain why the NeVAE architecture (ch. 9.3) changes everything.
  13. Paper. Choose a paper from ch. 10 (Graph of Words, PathNN, GOAT or NGG), read it, and present it in 10 minutes: problem, contribution, results, limits, position in the course. Grid: clarity of the key figure, reproduction of a number with commentary, one open question proposed.
