8. High dimension: sparsity and the Lasso

Definition 8.1 — Sparse linear model and the Lasso \(Y = X\beta^\star + \varepsilon\) with \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I_n)\), a normalized design matrix \(X \in \mathbb{R}^{n \times p}\) (\(\|X_{\cdot j}\|_2^2/n = 1\)), \(p \gg n\), and a sparse vector \(\beta^\star\) supported on \(S\), \(|S| = s \ll n\). The Lasso (Tibshirani 1996; see the Machine Learning module, chapter 2) is $$\hat\beta \in \arg\min_{b \in \mathbb{R}^p} \Big\{ \frac{1}{2n}\|Y - Xb\|_2^2 + \lambda \|b\|_1 \Big\}.$$ The Dantzig selector (Candès-Tao) replaces the minimization by \(\min \|b\|_1\) under \(\|X^\top(Y - Xb)\|_\infty \leq \lambda\) — the two are asymptotically equivalent (Bickel, Ritov and Tsybakov, 2009).
Proposition 8.2 — KKT conditions of the Lasso (proved) \(\hat\beta\) is a solution if and only if $$\frac{1}{n} X^\top\big(Y - X\hat\beta\big) = \lambda\, \hat z, \qquad \hat z_j = \mathrm{sign}(\hat\beta_j) \text{ if } \hat\beta_j \neq 0, \quad \hat z_j \in [-1,1] \text{ otherwise.}$$
The objective function is convex and proper; its subdifferential at \(b\) is \(\frac1n X^\top(Y - Xb) + \lambda\,\partial\|b\|_1\) with \(\partial\|b\|_1 = \prod_j \partial|b_j|\) and \(\partial|t| = \{\mathrm{sign}(t)\}\) if \(t \neq 0\), \([-1,1]\) if \(t = 0\). \(b \mapsto \frac{1}{2n}\|Y-Xb\|^2 + \lambda\|b\|_1\) attains its minimum at \(\hat\beta\) iff \(0\) belongs to this subdifferential.∎
These conditions are the stem of all the proofs: applied to the "empirical noise" \(z^\star_j = \frac1n X_{\cdot j}^\top \varepsilon\), they show that the choice \(\lambda \geq 2\sigma\sqrt{2\log(2p)/n}\) makes the event \(\{|z^\star_j| \leq \lambda/2,\ \forall j\}\) highly probable: each \(z^\star_j\) is \(\mathcal{N}(0,\sigma^2/n)\), so \(\mathbb{P}(|z^\star_j| > \lambda/2) \leq 1/(2p)\) (Gaussian tail), and the union bound (Prop. 0.1) gives at least \(1/2\) — or \(1-\delta\) by replacing \(\log(2p)\) with \(\log(2p/\delta)\) (Probability Theory for ML module, chapter 2, for Gaussian tails).
Definition 8.3 — Compatibility condition The design \(X\) satisfies the compatibility condition on the sparsity cones if there exists \(\kappa > 0\) such that, for every \(h \in \mathbb{R}^p\) with \(\|h_{S^c}\|_1 \leq 3\|h_S\|_1\): $$\frac{1}{n}\|Xh\|_2^2 \;\geq\; \kappa^2\, \|h_S\|_2^2.$$ Interpretation: the columns linked to the support must carry enough Euclidean norm, even in directions nearly orthogonal to \(S\) — a localized (on the cone) version of invertibility. Verified with high probability for Gaussian or bounded designs as soon as \(n \gtrsim s\log p\) (see Wainwright, High-Dimensional Statistics, chapter 7).
Theorem 8.4 — Oracle inequality of the Lasso (stated, proof skeleton) On the event \(\{|z^\star_j| \leq \lambda/2\ \forall j\}\) and under the compatibility condition, with \(\lambda = 2\sigma\sqrt{2\log(2p)/n}\): $$\frac{\|X(\hat\beta - \beta^\star)\|_2^2}{n} \;\leq\; \frac{72}{\kappa^2}\, \frac{\sigma^2 s \log(2p)}{n}, \qquad \|\hat\beta - \beta^\star\|_1 \;\leq\; \frac{24}{\kappa^2}\, \sigma s \sqrt{\frac{2\log(2p)}{n}}$$ (constants not optimal, consistent with the skeleton below; the sharp version of Bickel, Ritov and Tsybakov, 2009, has the same structure). Skeleton (the four steps to be completed as an exercise):
  • (a) Basic inequality: optimality of \(\hat\beta\) against \(b = \beta^\star\) gives, with \(h = \hat\beta - \beta^\star\): \(\frac{1}{2n}\|Xh\|^2 \leq \frac1n h^\top X^\top\varepsilon + \lambda(\|\beta^\star\|_1 - \|\beta^\star + h\|_1)\);
  • (b) Cone: the KKT conditions (Prop. 8.2) and the event \(\{|z^\star_j| \leq \lambda/2\}\) turn (a) into \(\frac{1}{2n}\|Xh\|^2 + \frac{\lambda}{2}\|h_{S^c}\|_1 \leq \frac{3\lambda}{2}\|h_S\|_1\): in particular \(h\) lies in the cone \(\|h_{S^c}\|_1 \leq 3\|h_S\|_1\);
  • (c) Conversion: dropping the positive term of (b), then Cauchy-Schwarz \(\|h_S\|_1 \leq \sqrt s\,\|h_S\|_2\), then compatibility (Def. 8.3) on the cone: \(\kappa^2\|h_S\|_2^2 \leq \|Xh\|^2/n \leq 3\lambda\sqrt s\,\|h_S\|_2\);
  • (d) Assembly: the quadratic inequality of (c) gives \(\|h_S\|_2 \leq 3\lambda\sqrt s/\kappa^2\); hence the prediction \(\|Xh\|^2/n \leq 9\lambda^2 s/\kappa^2\), and return to (b) for the full \(\ell_1\) norm: \(\|h\|_1 \leq 4\|h_S\|_1 \leq 12\lambda s/\kappa^2\).
"Fast" rate \(s\log p/n\): the Lasso estimates as well as if the true support \(S\) were known, up to the logarithm. Numbers (\(n = 100\), \(p = 1000\), \(s = 5\), \(\sigma = 1\)): \(s\log(2p)/n \approx 0.38\); ordinary least squares: not defined (\(p > n\)); regression on the true support: \(s/n = 0.05\) — the logarithmic surcharge is the price of the search among \(\binom{1000}{5} \approx 8.3\times10^{12}\) possible supports.
Beyond prediction: selection and inference The oracle inequality controls prediction; variable selection requires more: a sup-norm bound \(\|\hat\beta - \beta^\star\|_\infty \lesssim \sigma\sqrt{\log p/n}\) and "sign concentration" (exact support recovery under a \(\beta_{\min}\)-condition) — exactly the results of Lounici 2008, see ch. 10; for inference (p-values, confidence bands) in high dimension: debiasing, and the results of ch. 10 on the group Lasso. In practice: the theoretical \(\lambda\) is a starting point; calibration goes through cross-validation (ch. 9, code below). 
import numpy as np
from sklearn.linear_model import Lasso, LassoCV
rng = np.random.default_rng(20)

n, p, s, sigma = 100, 1000, 5, 1.0
X = rng.normal(size=(n, p)) / np.sqrt(n)          # normalized columns
beta = np.zeros(p); beta[:s] = rng.choice([-1,1], s) * 1.5
y = X @ beta + sigma * rng.standard_normal(n)

lam_theo = 2*sigma*np.sqrt(2*np.log(2*p)/n)        # prop. 8.2
lasso = Lasso(alpha=lam_theo/2).fit(X, y)          # sklearn penalizes 1/(2n)
support = np.flatnonzero(lasso.coef_)
print(f"theoretical lambda {lam_theo:.3f}  support {support} (true [:5])")

cv = LassoCV(cv=5, n_alphas=60).fit(X, y)         # empirical calibration
err = np.linalg.norm(X @ cv.coef_ - X @ beta)**2 / n
print(f"CV lambda {cv.alpha_:.3f}  prediction error {err:.3f}"
      f"  (oracle s/n = {s/n:.3f})")
