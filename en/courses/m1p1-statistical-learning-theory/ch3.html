3. Vapnik-Chervonenkis dimension and Sauer's lemma

Definition 3.1 — Shattering, VC dimension, growth function Let \(\mathcal{H}\) be a class of classifiers \(\mathcal{X} \to \{0,1\}\) (or of real functions of which we take the sign).
  • A finite set \(S = \{x_1, \dots, x_N\} \subset \mathcal{X}\) is shattered if every binary labeling of \(S\) is realized: \(|\mathcal{H} \cap S| = 2^N\), where \(\mathcal{H} \cap S = \{(h(x_1),\dots,h(x_N)) : h \in \mathcal{H}\}\);
  • the VC dimension \(d = \mathrm{VC}(\mathcal{H})\) is the maximal size of a shattered set (or \(\infty\));
  • the growth function \(\Pi_{\mathcal{H}}(N) = \max_{|S| = N} |\mathcal{H} \cap S|\) counts the realizable dichotomies on \(N\) points in the worst case.
Example 3.2 — Computing VC dimensions
  • Thresholds on \(\mathbb{R}\) (Example 1.4): two points are shattered (4 dichotomies via the placement of \(t\)), three points \(x_1 < x_2 < x_3\) are not (impossible to label \(\{x_1, x_3\}\) without \(x_2\): a threshold returns an interval of the form \((-\infty,t]\)): \(d = 2\). Likewise intervals: \(d = 2\); unions of \(k\) intervals: \(d = 2k\);
  • Affine hyperplanes in \(\mathbb{R}^p\): \(d = p + 1\). \(\geq\): the \(p+1\) points \(0, e_1, \dots, e_p\) are shattered by the hyperplanes \(\langle w, x\rangle = b\) (around each vertex of the simplex, one isolates any subset: for a label \(y \in \{0,1\}^{p+1}\) take \(w = \sum_j (2y_j - 1)e_j\), with \(b\) well chosen); \(\leq\): \(p+2\) points in general position are linked by an affine dependence \(\sum_j \alpha_j x_j = 0\) with \(\sum \alpha_j = 0\); the labeling \(y_j = \mathrm{sign}(\alpha_j)\) is not realizable (dot product of the signs with the \(\alpha_j\) strictly positive forbids strict separation). Hence, for the perceptron and unregularized logistic regression, a complexity that grows with the dimension — to be contrasted with the margin (ch. 6);
  • Axis-aligned rectangles in \(\mathbb{R}^2\): \(d = 4\) (the 4 "cardinal points" of a cross-shaped configuration); sinusoids \(\{x \mapsto \mathbf{1}_{\sin(tx) > 0}\}\): \(d = \infty\) (for every \(N\), well-placed points can follow the sign of any alternation): exponential growth \(\Pi(N) = 2^N\), no universal learnability.
Theorem 3.3 — Sauer-Shelah lemma (proved) If \(\mathrm{VC}(\mathcal{H}) = d\), then for every \(N \geq d\): $$\Pi_{\mathcal{H}}(N) \;\leq\; \sum_{k=0}^{d} \binom{N}{k} \;\leq\; \Big(\frac{eN}{d}\Big)^{d}.$$
The polynomial upper bound by \((eN/d)^d\) is the classic inequality on binomial sums (each \(\binom{N}{k} \leq (eN/k)^k\), sum dominated by \(k = d\); admitted). Let us prove the first inequality by double induction on \(N\) and \(d\). Write \(s(N,d) = \sum_{k=0}^{d}\binom{N}{k}\). Base: \(s(N,0) = 1\) (class reduced to a single function); \(s(0,d) = 1\) (an empty point set: a single dichotomy). Induction step: fix \(S = \{x_1, \dots, x_N\}\) and write \(S' = \{x_1, \dots, x_{N-1}\}\). Partition the traces on \(S'\) into two families:
  • \(\mathcal{A}\): traces realizable in both ways on \(x_N\) (there exist \(h, h' \in \mathcal{H}\) coinciding on \(S'\) with \(h(x_N) = 0\), \(h'(x_N) = 1\));
  • \(\mathcal{B}\): traces realizable in at least one way on \(x_N\) (the complement of \(\mathcal{A}\) within the traces).
Then \(|\mathcal{H} \cap S| = |\mathcal{A}| + |\mathcal{B}|\): each trace of \(\mathcal{B}\) gives one dichotomy (label 0 on \(x_N\)), each trace of \(\mathcal{A}\) gives one more (label 1). Now:
  • \(\mathrm{VC}(\mathcal{B}) \leq d\) (subfamily): by induction, \(|\mathcal{B}| \leq s(N-1, d)\);
  • \(\mathrm{VC}(\mathcal{A}) \leq d - 1\): if \(\mathcal{A}\) shattered \(T \subseteq S'\) with \(|T| = d\), then \(T \cup \{x_N\}\) (size \(d+1\)) would be shattered by \(\mathcal{H}\) — the traces of \(\mathcal{A}\) on \(T\) give everything and the point \(x_N\) separates in both ways: contradiction with \(\mathrm{VC}(\mathcal{H}) = d\). Hence \(|\mathcal{A}| \leq s(N-1, d-1)\).
Conclusion by Pascal's identity: \(s(N-1,d) + s(N-1,d-1) = s(N,d)\).∎
Message: a class of VC dimension \(d\) emits only \((eN/d)^d\) dichotomies on \(N\) points — polynomial growth with exponent \(d\), versus \(2^N\) in the worst case. The "effective number of hypotheses" is finite and controlled. 
import numpy as np
from itertools import combinations

# growth function of thresholds on R: exactly N+1 dichotomies
def threshold_growth(N):
    return N + 1        # on N sorted points, a threshold cuts after the k-th

def sauer(N, d):        # Sauer-Shelah upper bound
    return sum(len(list(combinations(range(N), k))) for k in range(d + 1))

for N in (5, 10, 20):
    print(f"N={N:3d}  thresholds: {threshold_growth(N):3d}  "
          f"Sauer(N,2)={sauer(N,2):4d}")   # N+1 <= 1 + N + N(N-1)/2
