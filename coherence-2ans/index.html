Lecture : « pour que cible tienne sans friction, avoir réellement digéré sources ». Officiellement beaucoup de fiches disent « prérequis non communiqués » — la colonne droite est une inférence de parcours.

DL ML + Refresher NN (hors brochure) Backprop / init / saturations = magie noire ; CNN et attention arrivent trop tôt.
Graph ML DL (ou NN solide) + ML Message-passing lu comme « encore une couche » sans lien avec le graphe de calcul.

Privacy / UQ ML + (OT / SLT utiles) + LLM si focus LLM DP / calibration collés en post-hoc sans modèle de risque.

3. Ponts forts (ce qui « clique »)

Refresher NN → DL → attention → LLM

  • Le support hors brochure pose MLP + rétroprop + intuition attention.
  • DL industrialise ; NLP ajoute le texte ; M2 LLM reprend l’attention comme message-passing sur graphe complet (pont explicite dans les notes LLM).

DL / Graph ML → Adv. GNN → graph gen.

  • P2 Graph ML = panorama GNN + apps genAI.
  • M2 Advanced GNN = expressivité, profondeur, scaling.
  • Graph generative models = data augmentation / liens manquants avant raisonnement LLM.

NLP × Graph ML → GraphRAG / KG×LLM

  • Même période P2 : document↔graphe de mots / entités.
  • Les capacités de sortie en font le diagnostic métier central.

OT → fairness → privacy / robustesse

  • OT P2 aligne des distributions ; M2 privacy/UQ et XAI/sécu prolongent le contrôle du risque.
  • Pont faible mais réel avec SLT (bornes) et ML (évaluation).

Shapes / TDA / Graph → Geometric DL

  • P1 latéraux préparent l’inductive bias géométrique / topologique du M2.
  • Sans eux, Geometric DL reste faisable via Graph ML, mais plus abstrait.

RL / agents → LLM outillés

  • RL P2 cadre politiques / exploration ; agents outillés M2 (LLM + outils / graphe d’état) réutilisent le vocabulaire.

4. Trous & risques de parcours

Trou 1 — sauter DL (ou NN) avant Graph ML Le curriculum autorise des choix P1 sans Deep Learning. Sur le track Graph×LLM, c’est le principal risque de friction : Graph ML assume des réseaux entraînés. Mitigation Extrapolons : prendre DL ou au minimum le Refresher Neural Nets avant / en parallèle de Graph ML.
Trou 2 — NLP « classique » seul avant LLM M2 NLP P2 couvre la chaîne jusqu’aux modèles neuronaux, mais le saut vers prétraining, alignement et eval LLM reste large. Mitigation : garder l’attention (DL / refresher NN) vivante ; ne pas traiter M2 LLM comme un cours de prompting isolé.
Trou 3 — Geometric DL sans shapes/TDA/graph Possible via DL seul, mais le pont géométrie/topo manque. Mitigation : au moins un latéral P1 (Shapes ou TDA) ou un Graph ML bien digéré avant Geometric DL.
Trou 4 — privacy / sécu LLM sans ancrage stats+OT Les modules M2 de sûreté deviennent des checklists si proba/évaluation P1 et OT fairness P2 sont absents. Mitigation : garder un fil « risque & distributions » (Stats → ML → OT → Privacy/XAI).

5. Redondances — utiles vs bruit

ChevauchementVerdict Extrapolons
Refresher NN ↔ ouverture DL Utile — rampe volontaire ; le hors-brochure évite de gonfler la brochure.
DL P1 ↔ Advanced DL / DL variante P2 Utile si approfondissement ; bruit si on empile sans projet (choisir un levier P2 : OT ou multimodal plutôt qu’un 3e DL générique sur le track Graph×LLM).
NLP P2 ↔ LLM M2 ↔ Advanced topics LLM Progression (pipeline → fondations LLM → sujets avancés), pas triplicata si chaque couche change d’échelle.
Graph ML ↔ Adv. GNN ↔ Graph gen. Progression panorama → théorie/échelle → génération.
CV P1 ↔ CV apps P2 ↔ multimodal Redondance acceptable sur un profil vision ; sur Graph×LLM, multimodal suffit souvent comme pont vision–langage.
Privacy / UQ ↔ XAI-sécu-privacy LLM ↔ Security-robustness Chevauchement thématique M2 : utile si l’on spécialise (UQ vs attaques vs privacy LLM) ; sinon en choisir 1–2 max.

6. Clarté des supports — D1–D3 vs reste du catalogue

Lots de clarification déjà mergés sur le cœur du track :

  • D1 — refreshers Stats / CS / NN + entrée ML
  • D2 — P1 scientifiques DL / Proba MC / SLT / CV (+ soft ML)
  • D3 — P2 Graph ML / NLP / OT + entrée M2 LLMs / Advanced GNN

Modules encore hors D1–D3 (clarté / voix / accroches empiriques à durcir dans un lot suivant, typiquement D4) : entre autres Signal, Collaborative / emerging ML, Shapes, TDA, DBMS, Computer Animation, RL, Multimodal, Advanced DL, Optimization for AI, Statistics in Action, Geometric DL, ainsi que le reste M2 ingénierie / speech / boosting / control, et une passe de purge des formulations type « équipe pédagogique » / « teaching team » encore présentes hors lots D1–D3.

Cette page E ne réécrit pas ces modules ; elle signale où la cohérence de parcours est déjà lisible, et où la clarté de support reste hétérogène.
