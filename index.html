Supports de cours du master MSc&T « Large Language Models, Graphs and Applications », rédigés module par module pour le track recommandé « profil équilibré » (cœur Graph + LLM). Structure alignée sur la brochure ; chaque cours listé mène à une page (scientifique ou cadrage Extrapolons).

Track recommandé — Graph + LLM

Quatre tracks sont possibles ; le cœur du master est le croisement LLM + graphes. Sélection rédigée ici : ML + DL / signal / collaborative (P1) ; RL, Graph ML, NLP + OT / multimodal (P2) ; LLM, Advanced GNN, geometric DL (M2).

Hints discrets brochure vs curriculum détaillé LLGA apparaissent sous les groupes de choix. Notes Extrapolons — pas une voix officielle du diplôme.
