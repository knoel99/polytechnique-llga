LLMs & Graphes — le parcours complet, module par module

Cette page recense l'intégralité des cours du master LLGA (curriculum officiel détaillé + brochure MSc&T). Les 14 modules du track recommandé sont rédigés en profondeur pour un lecteur ayant un bon niveau de mathématiques de licence (L3) : rappels L3, cours développé (définitions, théorèmes, démonstrations), code Python, exercices et références — dont les travaux de recherche des enseignants du master. Les autres cours de la brochure sont listés (cartes grises, « non couverts ») : cours de gestion, langues et humanités restent hors périmètre.

Le track recommandé — « profil équilibré », cœur Graph + LLM

L'analyse du curriculum distingue quatre tracks (Graph AI / Structured Generative AI · LLM Engineering & Agentic Systems · Hybrid Neuro-Symbolic / GraphRAG · Research/PhD). Le cœur du master — ce qui le rend unique — est le croisement LLM + graphes :

  • P1 : Machine Learning (obligatoire) + Deep Learning + Signal Processing + Emerging Subjects in ML (recommandés) ;
  • P2 : RL & Autonomous Agents, Graph ML & DL for Generative AI (cours central) et Text Mining & NLP (obligatoires), + Computational Optimal Transport et Multimodal Generative AI (recommandés) ;
  • M2 : Large Language Models, Advanced Graph Neural Networks, Analysis & Deep Learning on Geometric Data.
Légende : Obligatoire Recommandé Rappels L3 M2 Option Non couvert — les cartes cliquables (fond blanc) mènent au support rédigé ; les cartes grises en pointillés listent les cours de la brochure non rédigés dans ce dépôt.
